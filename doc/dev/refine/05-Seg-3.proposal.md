- 0x12a5 = Blue-Eyes Toon Dragon (pw=53183600)
- 0x1123 = Toon Alligator (pw=59383041)

### 块 C: 0x0804b250..0x0804b2db (0x8c bytes total, incl. switch table/stub) -- contains 2 THUMB functions

**FuncE: check_card_is_batteryman_type @ 0x0804b250** (0x1e bytes, bx lr at 0x0804b26a)

- 0x191c = Batteryman C (pw=19733961)

**FuncF: check_card_is_dark_world_range_type @ 0x0804b26c** (dispatch via switch table)

Switch dispatch. Computes `card_id + 0xffffe69f` (= card_id - 0x1961). If result in
[0x0..0x12] (card_id in [0x1961..0x1973]), jumps into 19-entry switch table at
PTR_DAT_0804b288 (0x0804b288). Table entries point to DAT_0804b2d4 (return 1) or
0x0804b2d8 (return 0). Out-of-range -> bhi -> 0x0804b2d8 (return 0).

Return-1 card_ids (0x1961 + index): 0x1961=Zure, 0x1965=Beiige, 0x1966=Broww,
0x1967=Brron, 0x1968=Sillva, 0x1969=Goldd, 0x196a=Scarr, 0x1970=Dark World Lightning,
0x1973=Gateway to Dark World.
Return-0 card_ids: 0x1962=BES Tetran, 0x1963=Nanobreaker, 0x1964=Rapid-Fire Magician,
0x196b..0x196e=Familiar-Possessed series, 0x196f=Pot of Avarice, 0x1971=unassigned,
0x1972=Boss Rush.

Note: The function is NOT a pure Dark World checker (also hits unrelated cards in the same
ID range). Neutral name `check_card_is_dark_world_range_type` acknowledges the BST range
covers the Dark World card cluster but with non-Dark-World cards interleaved.
3 BL callers: 0x0808cc18, 0x0808cd78, 0x0808ce04. Confidence: med (name reflects BST range,
not semantic purity).

Switch table (PTR_DAT_0804b288, 0x0804b288..0x0804b2d3): 19 entries x 4B = 0x4c bytes,
each pointing to either 0x0804b2d4 (case1: return 1) or 0x0804b2d8 (case2: return 0).
DAT_0804b2d4: inline THUMB code stub `movs r0,#1; b +0; movs r0,#0; bx lr` = 8 bytes.
