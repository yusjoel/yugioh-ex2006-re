## 数据块分类 (Rule 2/3) -- ref-scan 证据

| 块                      | ref-scan raw / THUMB+1  | 判定 | 理由 |
|------------------------|------------------------|------|------|
| 0x4aa5e sz=0xee (238B) | raw=0 thumb=0          | §5.1 | 0 引用; 内容是 THUMB 代码形态(ldr/cmp BST 树)但全 ROM 无任何 fn-ptr 或 bl 指向此范围内任何地址; 与相邻 check_card_pair_allowed (0x4ab4c) 结构相似但独立孤本; 三条硬规则规则3 适用 |

### switchD_0804a9ee 分类

位于 map_field8_to_card_type_category 函数体内 (0x4a9dc..0x4aa5c):

- DAT_0804a9f0 = 0x0804a9f4: 函数内跳转表基址指针 (1 ROM ref -- 仅函数自身 ldr r1 使用)
- switchdataD_0804a9f4: 16 entry .word 跳转表 (field8 索引 0..15 -> case handler 地址)
  - 所有 16 个目标均为同函数内的 case label (0x4aa34..0x4aa58 范围内), 无 +1 offset
  - 已由 Ghidra 正确标注 switchD_0804a9ee__switchdataD_0804a9f4 等子标签
  - 判定: **函数内 switch 跳转表**, 无需 carve/disasm, 只需 DAT_0804a9f0 符号化
