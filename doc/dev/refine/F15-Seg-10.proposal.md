# Refine Proposal: F15-Seg-10 [0x080c00f0..0x080c1448)

## 段测绘

- 范围: `[0x080c00f0, 0x080c1448)`, 4952B。
- 当前布局: 2041 个 InstructionDB（1936 条 2B、105 条 4B），4292B 指令；152 个 4B word，共 608B；26 段 2B 零填充，共 52B。三者连续覆盖，无 raw 块。
- 函数入口: 13 个；完整入口/名称/ABI/body/PLATE 前后态见 `F15-Seg-10.plates.tsv`。
- 152 个 word 全覆盖：126 个自动名槽和 26 个 switch word。动作由最终 TSV 派生：EQ_ADD=47，REF_ADD=30，REF_PRESERVE=49，PRESERVE=26。

## 符号化计划 (R1/R2/R3)

### EQ_SLOTS

47 个绑定，33 个唯一 Equate；其中新增 15 个对象，18 个对象复用。数值常量、既有 card-info 资源常量和 palette/VRAM 常量均先核 GNU 与 Ghidra 全局对象；完整逐槽合同见 TSV，完整 2461 -> 2476 对象图见 `f15-seg10-global-equates-plan.json`。

### REF_SLOTS

- REF_ADD=30：建立 USER_DEFINED DATA ref，保留静态 USER/ANALYSIS target ID；7 个 DEFAULT/无符号目标物化 USER label。
- REF_PRESERVE=49：旧 DATA CORE6、source、primary 和静态 target ID 全部原样保持，仅改 source slot label/EOL。
- 26 个 switch word 完整保持 `/pointer`、ANALYSIS namespace、qualified name、Symbol ID 和引用。
- source/target 重合地址使用单一 after state；新 DATA 的 source.refs_from 与 target.refs_to 双向闭合，见 `f15-seg10-target-plan.json`。

### RENAME_SLOTS

126 个自动名槽全部改为地址唯一的小写语义名并写 ASCII EOL；26 个 switch word 不新增同址 alias。
