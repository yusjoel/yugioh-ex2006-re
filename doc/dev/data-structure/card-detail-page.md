# 卡牌详情页 UI 布局

卡牌详情页的 VRAM 分层、BG 配置、tile 分类、OAM 精灵、字体 tile 位置。

---

## 触发

卡牌列表页选中一张卡牌按 A，进入详情页。画面显示：卡牌大图、卡名、星级图标、属性、种族、ATK/DEF 数值、卡牌说明文本。

进入时共 742 处 VRAM 条目发生变化（BG0 区 638，BG1 区 104）。

---

## 显示模式

| 寄存器 | 值 | 含义 |
|--------|-----|------|
| DISPCNT (`0x04000000`) | `0x1D00` | mode=0，启用 BG2+BG3+OBJ |

> 卡牌列表页使用 BG0+BG1；详情页切换为 BG2+BG3，完整的显示模式切换。

### BG 层配置

| 层 | BGnCNT 值 | 颜色数 | Tile 数据基址 | 地图基址 | 用途 |
|----|-----------|--------|--------------|---------|------|
| BG2 | `0x1E83` | 256 色 | `0x06000000`（char_block=0） | `0x0600F000`（map_block=30） | 卡牌图像 |
| BG3 | `0x1F0B` | 16 色 | `0x06008000`（char_block=2） | `0x0600F800`（map_block=31） | 文字 / UI 框架 |

---

## VRAM 布局

### BG2 — 卡牌图像层

| 项 | 值 |
|----|----|
| Tile 数据 | `0x06000000`，256 色（64 字节 / tile），tiles 1–36 有效 |
| 地图数据 | `0x0600F000`，3 列 × 12 行（24 px 宽 × 96 px 高）|

卡牌艺术图通过 **6bpp 解码器**（`FUN_0801d290`，见 [`card-image-big.md`](card-image-big.md)）写入 tiles 1–36；tile 0 为空白填充。

### BG3 — 文字 / UI 层

| 项 | 值 |
|----|----|
| Tile 数据 | `0x06008000`，16 色（32 字节 / tile），共约 154 个有效 tile |
| 地图数据 | `0x0600F800`，30 列 × 20 行（对应 GBA 240×160 分辨率） |

#### 地图行用途

| 行号 | 内容 |
|------|------|
| row 0–1 | 卡牌名称（tile 16–27 = 12 个字符）|
| row 2–4 | UI 分隔线 / 属性图标区 |
| row 5 | ATK / DEF 标签行 |
| row 6–17 | 卡牌说明文本（tile 100–153）|
| row 18–19 | 按钮区域（"返回"等操作提示）|

#### Tile 分类

| Tile 编号 | 内容 |
|-----------|------|
| 0 | 空白（全 0） |
| 1 | 背景填充 |
| 2–13 | UI 边框（调色板色 2 填充） |
| 14–15 | UI 边框变体（调色板色 E 填充） |
| **16–27** | **当前卡牌名称字符**（12 个字符对应 12 个 tile） |
| 28–99 | UI 图标（属性、种族、ATK/DEF 标签等）|
| **100–153** | **当前卡牌说明文本字符** |

## OAM 精灵

| 精灵编号 | Y 坐标 | X 坐标 | Tile | 用途 |
|----------|--------|--------|------|------|
| 22–27（6 个）| 116 | 16–96（步距 16）| 1021 | 星级图标（前半段） |
| 0–6（7 个） | 116 | 112–208（步距 16）| 1021 | 星级图标（后半段） |
| 9–21（13 个）| 92 | 16–208（步距 16）| 925 | ATK/DEF 数字或横向装饰条 |
| 7 | 92 | — | — | 纵向边框装饰 |
| 8 | 0 | — | — | 纵向边框装饰 |

星级图标共 13 个精灵横排，均使用 tile 1021（16×8 像素，横向精灵，调色板 16 色）。实际显示的星数通过哪些精灵可见来控制。

## 调色板

| 调色板编号 | 用途 |
|-----------|------|
| pal[0] | BG2 256 色（卡图专用，全量调色板）|
| pal[1] | BG3 UI 边框 / 背景色 |
| pal[2] | BG3 文字颜色 |
| pal[3] | BG3 特殊高亮色 |

---

## 字体 tile

| 项 | 值 |
|----|----|
| ROM 位置 | `0x01463480 – 0x014E3480` |
| 大小 | 512 KB |
| tile 数 | 16,384 个 4bpp tile（32 字节 / tile，未压缩）|
| 字符编码范围 | `0xF080 – 0xFEFE`（~790 字符，涵盖卡名与说明文本）|

> 字符编码 → tile 索引的映射公式尚未破解。VRAM tile 16 对应字体区 tile 索引 6330（`ROM + 0x1494BC0`），字节完全匹配，但映射关系不是简单线性。
