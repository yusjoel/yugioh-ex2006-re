Equip slot activation eligibility predicate. Evaluates eligibility only when this slot belongs to the active player and the duel is in phase 1. First takes player_id from slot byte[+0x2] bit0, reads gP1LifePoints[+0x1ce8] (active_player_id); if not equal to player_id returns 0 directly. Then reads gP1LifePoints[+0x1cf4] (duel_phase); if not equal to 1 returns 0. After both conditions hold, passes through the result of check_equip_slot_eligible_by_tier_and_field6(slot, arg). Statically dispatched from the equip eligibility scan chain, indeg=0.

Constants:
- ACTIVE_PLAYER_OFFSET=0x1ce8 (gP1LifePoints global active-player field)
- DUEL_PHASE_OFFSET=0x1cf4 (gP1LifePoints global phase field)
- DUEL_PHASE_MAIN1=1 (only phase 1 triggers)
- PLAYER_BIT_MASK=bit0 of slot byte[+0x2]
