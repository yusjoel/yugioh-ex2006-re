## plate comment (中文, ASCII 标点)
渲染拆包槽位封面 OAM sprite. 以固定偏移 0x80<<0xa=0x20000 (OAM 属性基值) 调用 compute_pack_oam_attr_by_type 获取属性编码. 读取 pack_ui_state+0xc+0x10c (动画帧计数), 若非零则根据 [+0x10c] / [+0x10e] 两字段做线性插值计算调整后的 x 偏移量; 若为零则直接使用原始属性. 最后用计算所得属性和 r1 (宽/高 packed = 0x0002000d) / r2 (tile 属性 0x00020090) 调用 render_overlay_oam_sprite_tiled 写入 OAM 条目, r3=r7(ctx_ptr). 被 9 个拆包场景步骤函数调用.

Constants:
- pack_ui_state = 0x03005850
- OAM_ATTR_BASE = 0x80<<0xa = 0x20000
- ANIM_COUNT_OFF = 0x10c (相对 pack_ui_state+0xc)
- ANIM_TOTAL_OFF = 0x10e
- INTERP_BASE = 0x86<<1 = 0x10c (anim elapsed offset, confirms field)
- INTERP_SRC = 0x86<<1 = 0x10c, 0x87<<1 = 0x10e
- SPRITE_WH = 0x0002000d (w=13, h=2)
- SPRITE_TILE_ATTR = 0x00020090
