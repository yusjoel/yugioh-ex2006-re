# Naming Proposal: 0x0801a984

## 提案
- **proposed_name**: render_banlist_text_col_cleared
- **confidence**: med

## plate comment (中文, ASCII 标点)
Function: 在渲染前清空 tile 缓冲区列范围, 然后将 banlist 文本渲染到指定列位置. 列索引经 __divsi3(col_idx, 5)+col_idx 调整后乘以 12 得到 tile 列起始位置, 从 gBanlistPasswordBuffer+0x663 读取字体高度倍率, 调用 init_font_jp_ctx_bg2_char_vram 初始化 BG2 字符 VRAM 上下文, 再调用 clear_tile_buf_col_range 清空目标列, 若文本非空则调用 dispatch_text_render_by_mode_banlist(mode=7) 渲染. 由 3 个 caller 在 banlist 密码输入文本更新时调用.
Side effects:
- tile buf col [col_tile..col_tile+width]: clear_tile_buf_col_range 清零
- BG2 char VRAM: init_font_jp_ctx_bg2_char_vram 初始化上下文
- OAM/VRAM: dispatch_text_render_by_mode_banlist 写入 (若 [r7] != 0)
Constants:
  COL_DIV = 0x5 // 列索引除数 (每 5 个密码字符对应一个显示列)
  TILE_COL_STRIDE = 0xc = 12 // 每列占 12 个 tile 宽度单位
  FONT_SCALE_OFFSET = 0x663 // gBanlistPasswordBuffer 字体缩放字节偏移
  RENDER_MODE = 0x7 // dispatch_text_render_by_mode_banlist 模式

## 参数签名
- r0: const char* text_ptr - 文本数据指针 (若 [r0]==0 跳过渲染)
- r1: s16 col_idx - 列索引 [0..14] (经 div5 + *12 换算为 tile 列偏移; caller FUN_0801a9f4 cmp #0xf 确认上界)
- r2: u16 x_step - 每字符 x 步进 (保存到 r9)
- r3: u16 extra_param - 额外参数 (保存到 r7)
- 返回: void (pop{r0};bx r0)

## 副作用
- tile buf: clear_tile_buf_col_range 清零 (tile 列 = (col_idx + col_idx/5) * 12)
- BG2 char VRAM: init_font_jp_ctx_bg2_char_vram 初始化
- OAM: dispatch_text_render_by_mode_banlist 条件渲染
