## plate comment (中文, ASCII 标注)
更新每个 player 的 zone 激活显示状态, 由 dispatch_card_display_op case 0x03 (write_zone_slot_oam_descriptor 之后) 调用. 外层循环 r6=[0..1] (两个 player), 内层对 slot_type [0..10] 调用 dispatch_zone_activation_by_state(is_active, slot_type, 0); 若返回 bit11 (0x800) 置位则将对应 bit 写入 r5 (bitmask). 最终将 r5 经 bit-field 处理后写入 gDuelZoneCtrl (0x020230c0) [base+0x30+player_offset] 的 dword, 并通过 query_player_slot_activation_bitmask 刷新 gDuelZoneCtrl 相关字段. 是 duel field zone 高亮/激活 UI 的驱动函数. Constants: gDuelZoneCtrl=0x020230c0, player_offset=4 (player1 对应 +0x34), slot_type_range=[0..10], FLAG_ACTIVATABLE=0x800, zone_id_mask=0x7ff.
