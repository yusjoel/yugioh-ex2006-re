# Naming Proposal: 0x080d2a08

## 提案
- **proposed_name**: dispatch_zone_card_anim_by_type_alt
- **confidence**: med

## plate comment (中文, ASCII 标点)
由 FUN_080d2ef4 在外层卡槽属性码 = 6 的分支中调用, 与 dispatch_zone_card_anim_by_type (0x080d1bb4) 结构对称但使用不同的行偏移字段和处理程序表. 从 gDuelCtx+0x2f53 提取 bits[7:5], 从 gDuelCtx+0x2f54 提取 bits[4:0] 左移 3 后合并, 得组合类型码 [0..6]; 若 >6 则跳转至 LAB_080d2c54 异常路径. 正常路径使用 gDuelCtx+0x2f56 (而非 0x2f58) 计算行偏移, 并以类型码为索引查询 PTR_DAT_080d2aa0 (7 项函数指针表) 通过 bx r8 尾调用对应子处理程序. 副作用由 7 个子处理程序间接产生, 写入对应卡槽的 VRAM/OAM 状态.
Constants: DUEL_CTX=0x02020160; CARD_STATUS_OFFSET=0x2f53; CARD_LOW_OFFSET=0x2f54; ROW_OFFSET=0x2f56 (区别于 0x080d1bb4 使用的 0x2f58); ZONE_OFFSET=0x2f4f; JUMP_TABLE_PTR=0x080d2a9c; TYPE_COUNT=7; LOW_MASK=0x1f.

## 参数签名
- r0: (void, 0x080d2a10 处 ldrb r0,[r0] 覆盖入参, 初始 r0 无效)
- 返回: r0 = u32, 子处理程序返回值 (透传): 0=子处理程序未完成 (caller 跳过 done 信号); 非0=子处理程序完成 (caller 调用 signal_zone_tick_done). bx r8 尾调用, 子处理程序直接返回至 FUN_080d2ef4.
- 备注: r4/r5 通过 prologue push {r4,r5,lr} 保存 caller 值; 函数体随即内部赋值: 0x080d2a14 ldr r4, DWORD_080d2a4c (偏移量 0x2f54), 0x080d2a22 adds r5,r1,#0 (gDuelCtx 别名); r4/r5 均为内部 working register, 不作为输入参数.

## 副作用
- [gDuelCtx+0x2f4f] byte 读取: ldrb r0,[r1] @ 0x080d2a80 (zone 字段, cmp r0,#6 校验)
- VRAM/OAM 写入: 通过 DAT_080d2abc 区间内 7 个子处理程序间接执行
- [0x080d2abc..0x080d2c54]: ROM INCBIN 区间 (0x198 字节) 内子处理程序的各自副作用

## 行级注释 (<=30 行精华)
- @ 080d2a08: push {r4,r5,lr} : 保存 3 个寄存器 (比 0x080d1bb4 少 r6,r7)
- @ 080d2a0a: r1 = 0x02020160 = gDuelCtx 基地址
- @ 080d2a10: ldrb r0,[gDuelCtx+0x2f53] : 读取 card_status 字节
- @ 080d2a12: lsrs r2,r0,#5 : card_high = bits[7:5]
- @ 080d2a14: r4 = 0x2f54 -> gDuelCtx+0x2f54 = card_type 字节
- @ 080d2a18: movs r0,#0x1f; ands r0,r4 : card_low = bits[4:0]
- @ 080d2a1e: lsls r0,r0,#3 : card_low <<3
- @ 080d2a20: orrs r0,r2 : type_combined = (low5<<3) | high3
- @ 080d2a22: adds r5,r1,#0 : r5 = gDuelCtx base (local alias)
- @ 080d2a24: cmp r0,#0; beq LAB_080d2a54 : type=0 -> 使用 0x2f56 分支路径
- @ 080d2a2e: r2 = 0x2f56 -> gDuelCtx+0x2f56 = 行偏移字段 (本函数与 0x080d1bb4 的关键差异)
- @ 080d2a80: ldrb r0,[gDuelCtx+0x2f4f]; cmp r0,#6; bls : zone 索引合法性校验 [0..6]
- @ 080d2a88: lsls r0,r0,#2 : zone_idx * 4 = 跳转表字节偏移
- @ 080d2a8a: ldr r1, PTR_PTR_080d2a9c; ldr r0,[r0+r1] : 读取子处理程序指针
- @ 080d2a90: mov r8, r0 : 保存指针; bx r8 尾调用子处理程序

## 置信度证据
- 层 结构: 与 dispatch_zone_card_anim_by_type (0x080d1bb4) 结构完全对称 (同 cmp r0,#6 + 7 项跳转表)
- 层 差异: 行偏移字段 0x2f56 (vs 0x2f58) 且跳转表 PTR_DAT_080d2aa0 不同, 证明为同族不同场景的 _alt 变体
- 层 caller: FUN_080d2ef4 @ 0x080d300c `bl FUN_080d2a08` 触发条件为外层属性码 = 6
