Leaf dispatcher that routes equip hand OAM or the type11 sprite by the effect slot's type field. Takes node+2 u16 type field AND mask 0xfc0: if equal to 0x80 calls invoke_equip_oam_for_hand_set_code_slot(node) to write hand OAM and returns. Otherwise takes node+2 bit0 as player, node+0 as card_id, extracts set_code (bits[14:6], 9 bits) from node+4 u16 field via shift left 0x11 shift right 0x17, and calls enqueue_sprite_attr_type11(player, card_id, 0x11, set_code) to enqueue the type11 sprite. The hand OAM path, after calling the callee, takes b LAB_0807be26 to bypass exit zeroing so r0 passes through invoke_equip_oam_for_hand_set_code_slot return value; the type11 path goes through 0807be24 movs r0,#0 returning 0. Statically dispatched via fn-ptr by the display main loop (indeg=0).
