## plate comment (中文, ASCII 标点)
统计玩家额外卡组 (Extra Deck) 中 card_id 等于 r6 (=r1 低 16 位) 的牌数.
流程: r6 = r1 & 0xffff (card_id 过滤值); 读 gP1LifePoints + player*0x868 + 0x14 = hand_count;
额外卡组基址: gP1LifePoints + player*0x868 + 0x83*8. 对 i=0..count-1:
ldr card_word=[base+i*4]; card_id=bits[12:0]; cmp card_id, r6; 命中则 r4++.
返回 r4=匹配数.
Non-APCS 说明: r1 参数的低 16 位作为 card_id 过滤值存入 r6; 函数入口
lsls r1,r1,0x10; lsrs r6,r1,0x10 完成该提取.
Constants: gP1LifePoints=0x0201c4e0, player_stride=0x868, extra_deck_count_offset=0x14,
extra_deck_base_offset=0x83*8=0x418.
