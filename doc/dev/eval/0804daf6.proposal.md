# Naming Proposal: 0x0804daf6

## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
将 sprite row 队列尾部控制字段批量清零/置位, 作为动画序列结束时的清理收尾动作.
基地址 0x0201b290: 清零 +0x48c (DAT_0804db48=0x48c), 将 +0x498 (DAT_0804db48+0xc = +0x498) 置 1, 清零 +0x49c (DAT_0804db4c=0x49c).
然后从 +0x4b8-2=+0x4b6 (0x8b<<3 - 0x18) 读取 halfword, 写入 +0x4b8 处, 实现 "上一帧 X 位置" 向 "当前帧 X 位置" 的传递.
还清零 +0x4d0 (0x9a<<3), +0x518 (0x4a34 偏移), 以及 +0x580 (0xb0<<3).
调用方: FUN_0804d1e4 (批次内同一 batch, 当动画序列状态为终止态时调用本函数重置尾部控制字段).
返回 r0=1 (固定, 成功标志).

Constants: base=0x0201b290, off_48c=0x48c, off_498=0x498, off_49c=0x49c, off_4b6=0x4b6, off_4b8=0x4b8, off_4d0=0x4d0, off_518=0x518, off_580=0x580.
