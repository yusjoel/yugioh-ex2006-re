# Naming Proposal: 08107198

## 提案
- **proposed_name**: render_card_frame_scene
- **confidence**: med

## plate comment (中文, ASCII 标点)
该函数是 banlist/card_frame/settings 场景的核心渲染入口, 由三个上层函数 (FUN_080ff824, FUN_081045c4, FUN_081047e8) 调用. 函数首先根据 lang_flag (IWRAM 0x0202f3c0 + offset 0x6c2c bits[2:0]) 选择 EN (0x09e606f4) 或 JP (0x09e60894) 卡片数据表并复制 0x120 字节 tile 数据到 VRAM 0x06009400 (copy_bytes_by_halfword); 然后对卡片外框网格每个单元格写入 OBJ tile 索引 (VRAM 0x06009800); 再写入 banlist/deck 状态标志对应的 OBJ 属性到 r9 偏移区; 切换调色板 (card_mini_frame_pal_144 至 0x05000160/0x05000166); 调用 select_charset_then_load_name 加载卡片名称; 最后调用 load_card_mini_frame_tile_and_pal (FUN_0810793c), render_jp_text_pair_with_flag (FUN_081078f8), calc_card_stat_bonus_by_type (FUN_08107a48), write_slot_display_coords (FUN_081044c0) 完成全帧渲染.

## 参数签名
- r0: u8 slot_idx (渲染目标 slot 索引 [5..25]: callers 实测传入 5/0xf/0x10..0x12/0x16/0x18/0x19, 传给 write_slot_display_coords)
- r1: s16 y_offset (行偏移, 传给 jp 文字渲染)
- 返回: r0 = u32 (1=成功)

## 副作用
- [VRAM 0x06009400]: 复制 0x120 字节 card tile 数据
- [VRAM 0x06009800]: 写入 card_frame 网格 OBJ 属性 (tile idx)
- [CRAM 0x05000160/0x05000166]: 写入 card_mini_frame_pal_144 调色板
- [0x02006ed0 + 0x8]: 经 render_jp_text_pair_with_flag 置位 bit1
