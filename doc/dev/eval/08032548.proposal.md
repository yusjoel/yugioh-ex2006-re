## plate comment (ASCII-only, 中文汉字 + ASCII 标点)
超高频工具函数 (indeg=57), 被 duel_field/card_frame/card_ids/card_stats/settings 等
几乎所有决斗场逻辑模块调用.
功能: 检查指定玩家侧 (r0 低 1 bit) 的指定场地格 (r1) 是否处于活跃状态并持有特定卡 (r2).
三个检查条件全部满足才返回 1:
  (1) slot.word[0] 低 13 位 == r2 (card_id 精确匹配);
  (2) slot.hword[0x8] != 0 (活跃性字段非零, 表示格已被激活/占用);
  (3) slot.word[0x10] bit5 == 0 且 bit1 == 0 (无配对禁用标志).
任一条件不满足则返回 0.
副作用: 仅读, 无写.

Constants:
  0x0201c510 = gDuelFieldSlots base (EWRAM)
  0x868 = 单玩家侧 slot stride
  stride 0x14 = 单 slot 条目字节数
  slot+0x0 word: 低 13 bit = card_id
  slot+0x8 hword: 活跃性字段 (非零 = 活跃)
  slot+0x10 word: bit5 = 配对禁用标志 A; bit1 = 配对禁用标志 B

## 参数签名
- r0: u8 side_flags -- 低 1 bit = player_side [0..1]
- r1: u16 slot_index -- 场地格索引 [0..0x44]; 用于 slot_index*0x14 + side*0x868 定位
- r2: u16 card_id -- 目标卡片 ID, 用于与格内 card_id 精确匹配
- 返回: r0 = u32 -- 1: 格处于活跃状态且持有 card_id; 0: 不符合
