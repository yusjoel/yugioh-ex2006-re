## plate comment (中文, ASCII 标点)
初始化 IWRAM 渲染状态结构体 [0x02006ed0] 中的行缓冲位置字段和字体指针字段,
为随后的字素渲染函数 (render_glyph_jp_dual_layer / blit_glyph_row_to_buffer 等) 准备上下文.
r0 传入 X 坐标 (低 8 bit 写入 OAM 位置字), r1 传入行号/Y 坐标,
函数通过多个 mask/orr 操作拼接 OAM 属性字 ([0x02006ed0+0x8]/[+0xa]/[+0xb]/[+0xc]),
最后从 font_jp_base_table 选取字体位图指针写入 [0x02006ed0+0x4].
indeg=57 确认其为所有 JP 字符渲染路径的公共 setup 入口.

- r1: u16 y_pos_or_row (Y 坐标/行号, 写入 OAM attr0 低 8 bit)
- 返回: r0 = void (无显式返回值)

## 副作用
- [0x02006ed0+0x8] halfword: 写入 OAM attr0 -- X 位置字段 (mask 0xfffffc03, orr x_pos<<2)
- [0x02006ed0+0x8] word: 再写 OAM attr1 -- Y/行字段 (mask 0xfffc03ff, orr y_pos<<10)
- [0x02006ed0+0xb] byte: 写 OAM attr2 低字节 -- tile 索引低位
- [0x02006ed0+0xc] byte: 写 OAM attr2 高字节 -- palette/priority
- [0x02006ed0+0x14]/[+0x15] byte: 清除字体标志位 (AND mask 0x7d/0xbe)
- [0x02006ed0+0x4] word: 写字体位图基地址 (从 font_jp_base_table 按标志位索引)
- [0x02006ed0+0x0] 可选: 若非 NULL 则循环调用 zero_fill_by_halfword 清空 tile
