# Naming Proposal: 0x080f0e0c

## 提案
- **proposed_name**: render_glyph_bitmap_to_tile_buf
- **confidence**: high

## plate comment (中文, ASCII 标点)
将源 4bpp 位图数据渲染到 EWRAM font_jp tile 缓冲区的指定位置. 被 FUN_080f0eec 两次调用 (分别偏移 +0 和 +0x8 行), 用于渲染单个字形的上半/下半 tile 行. 函数先用 copy_memory_dma3_with_cpu_fallback 将位图源数据拷贝到临时工作区, 再循环 (outer=0..7 行, inner=0..3 nibble) 提取每行 4 个像素 (每 4 位一 nibble), 计算目标 tile 缓冲区中的行列偏移 (公式: (x_tile>>3)*64 + (x&7)*4 + y_row*stride), 写入 strb 字节到 [glyph_buf+offset]. 支持宽字 (outer loop=0..1 outer group).

Constants:
- FONT_CTX=0x02006ed0 // EWRAM font_jp 上下文
- NIBBLE_PER_ROW=4 // 每行 4 nibble (4 像素 x 4bpp)

## 参数签名
- r0: u32 packed_xy (低 16 位=x_start, 高 16 位=x_start_hi or y_base)
- r1: u16 y_tile_offset (目标行 tile 起始偏移)
- r2: const u8* src_bitmap_ptr (4bpp 位图源)
- r3: u8 row_count [1..8] (渲染行数)
- r8 (caller-set via 0x4689=mov r9,r1 @ prologue): 保存 r1 的 callee-save -- 实为内部 spill
- r9 (via 0x4689 @ line 398925): y_tile_offset 的 callee-save copy
- 返回: void (pop {r0}; bx r0)

## 副作用
- [FONT_CTX vram_buf + 4bpp tile offset] := 4bpp nibble bytes (按行写)
