# Naming Proposal: 0x080f7f08

## 提案
- **proposed_name**: tick_aob_frame_counter
- **confidence**: high

## plate comment (中文, ASCII 标点)
推进 AOB 动画帧计数器并在帧切换时解析新的 pattern entry 指针. 由与 FUN_080f8000 相同的 11 个 caller 共享 (play_ui_effect_37/38/3b + FUN_080bede4/FUN_080bf5a0/FUN_080bf7f8 + FUN_0802dfb8 等). 入参 r0=aob_ctrl* (AOB 控制块). 流程: (1) 读 aob+0x12 bit5 (=0x20) 若置位则 aob_ptr 未初始化, 直接返回 0; (2) 读 aob+0xc (帧剩余计数), 若 =0 触发 assert (行 0xf1/0xf5); (3) aob+0xc -= 1; 若变为 0 则帧切换: 读 aob+0x13 bit3 (=0x8) 决定帧步进方向, 递增/递减 aob+0xd (frame_idx); 若 aob+0xd 超出 [0..aob.total_frames) 则循环/终止 (aob+0x12 bit4=0x10 控制是否循环); (4) 根据新 frame_idx 计算 ptn entry offset = frame_idx*4+4, 调用 resolve_aob_pattern_entry_ptr (r0=aob, r1=frame_idx entry halfword) 更新 aob+0x8; 返回 1 (帧计数成功).

Constants:
- aob+0xc = 帧剩余计数 (frame_ticks_remaining)
- aob+0xd = 当前帧索引 (frame_idx)
- aob+0x12 = flag 字节 0 (bit5=0x20 未初始化, bit4=0x10 循环控制)
- aob+0x13 = flag 字节 1 (bit3=0x8 反向步进)
- 0xf1/0xf5 = assert line numbers (suppress_assert_report 哨兵)

## 参数签名
- r0: ptr aob_ctrl* -- AOB 控制块指针 (r0+0x8 = ptn entry ptr, r0+0xc/0xd = 帧计数/索引字节)
- 返回: r0 = u32 (0=跳过/未初始化, 1=正常帧推进)

## 副作用
- [aob+0xc]: 帧计数 -1 (strb @ 080f7f3e)
- [aob+0xd]: 帧索引 +1 或 -1 (strb @ 080f7f6e/080f7fb4/080f7fda 等)
- [aob+0x12]: 若帧播放完毕设 bit4 (循环终止标志, strb @ 080f7fae)
- [aob+0x8]: resolve_aob_pattern_entry_ptr 写入新 pattern 指针
