## plate comment (中文, ASCII 标点)
sprite row 动画状态机调度入口. 读取 base (0x0201b290) + 0x494 处的状态码 (word), 若超过 0xe 则调用 reset_sprite_row_queue_tail 强制重置.
状态码 [0..0xe] 映射到跳转表 PTR_DAT_0804d258 (15 个 case), 涵盖各动画阶段 (初始化/渐入/播放/渐出/结束等).
若状态码为 0, 跳至 LAB_0804d220 (r7=0 空态), 否则根据 base+0x498*3<<3 + 0xba<<2 计算源条目指针, 再调用 reset_sprite_row_queue_tail (case 9/10) 或进入各 case handler.
调用方: FUN_0804f2e0 (tags: card_frame/duel_field) 和 FUN_0804f34c (无 tags).

Constants: base=0x0201b290, state_offset=0x494 (0x92<<3), entry_stride=0xba<<2=0x2e8, source_base=0xba<<2+base+count*stride.

## 参数签名
- 无 APCS 输入参数 (入口 .hword 0x4657/0x464e/0x4645 = mov r15,r7 / mov r14,r6 / mov r13,r5 为 callee-save; 随后 ldr r2 加载 base)
- 返回: r0 = u32 case_result -- 越界路径 (state>0xe): reset_sprite_row_queue_tail 返回值 (1=成功); case 0 (state==0) 路径: r7=0 (空态); 其余 case 0x1..0xe 由 PTR_DAT_0804d258 各 handler 决定; 两个已知 caller (0x0804f2ee/0x0804f3da) 均在 bl 后立即 b 跳走未使用返回值, 故对外语义为 void

## 副作用
- 若状态码 > 0xe: 调用 reset_sprite_row_queue_tail (写多个 base 偏移字段)
- 各 case handler 副作用通过 bx r15 跳转执行
