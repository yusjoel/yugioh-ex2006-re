- step=0: if [gP1LP+0x1daa] non-zero -> player_id bit0 * 0x868 + 0xc LP row pointer non-zero -> calls increment_lp_bar_display_counter; advances step; returns 0. If zero directly returns 1.

- step=2: calls decrement_lp_bar_display_counter; returns 1.
High-register prologue: mov r8,r0 (spills r0=player_id to r8); no r9/r10 read.

Side effects: [gP1LifePoints+0x1da8]:=hword from [+0x1d70] (step=1 confirmed path); [gP1LifePoints+0x1d94]+=1; increment_lp_bar_display_counter side effect.
