# Naming Proposal: 0x080f4ea4

## 提案
- **proposed_name**: copy_bytes_by_halfword
- **confidence**: high

## plate comment (中文)
通用内存复制工具函数, 以 16 位 (halfword) 步长为主循环单元, 处理末尾奇数字节. 由 card_info_page_init_bg0 (0x0801d45c), card_image_decode_wrapper (0x0801d998), card_info_page_finalize (0x0801e100) 等 150 个调用方在 VRAM/PALRAM/EWRAM 数据搬运场景下调用. 参数 r0=dst, r1=src, r2=byte_count; 先以 ldrh/strh 对拷 byte_count/2 次, 若 byte_count 为奇数则额外拷贝末 1 字节. 无返回值.

## 参数签名
- r0: ptr dst 目标地址 (任意内存区域; 调用方包含 VRAM/EWRAM/PALRAM)
- r1: ptr src 源地址
- r2: u32 byte_count 要复制的字节数 (0 时直接返回)
- 返回: void (无返回值)

## 副作用
- [dst, dst+byte_count): 复制 src 内容 (halfword 步长, 末字节用 byte 步长)
- 注: 写入目标地址完全由调用方决定 (可为 VRAM/PALRAM/EWRAM 等任意合法区域)

## 行级注释 (按 ROM 地址排)
- @ 0x080f4ea4: push {r4,lr} — 保存 r4 和返回地址
- @ 0x080f4ea6: r4 = r2 — 保存原始 byte_count 到 r4 (后续判断奇数字节用)
- @ 0x080f4ea8: r2 = r0 — r2 = dst (主循环写目标指针)
- @ 0x080f4eaa: r3 = r4 >> 1 — r3 = byte_count / 2 (halfword 循环次数)
- @ 0x080f4eac: cmp r3,#0 — byte_count < 2 时跳过主循环
- @ 0x080f4eb0: ldrh r0,[r1] — 读 2 字节 (src halfword)
- @ 0x080f4eb2: strh r0,[r2] — 写 2 字节 (dst halfword)
- @ 0x080f4eb4: r1 += 2 — src 指针步进 2
- @ 0x080f4eb6: r2 += 2 — dst 指针步进 2
- @ 0x080f4eb8: r3 -= 1 — halfword 计数器递减
- @ 0x080f4eba: r4 -= 2 — 剩余字节数递减 (最终 r4 = byte_count & 1)
- @ 0x080f4ec0: cmp r4,#0 — 判断是否有奇数末字节
- @ 0x080f4ec4: ldrb r0,[r1] — 读末 1 字节 (src)
- @ 0x080f4ec6: strb r0,[r2] — 写末 1 字节 (dst)
