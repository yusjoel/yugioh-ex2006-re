## plate comment (中文, ASCII 标点)
Function: 根据游标槽位信息从密码候选字符表中定位字符, 并调用 banlist_password_enter_char 写入目标缓冲区. 从 gBanlistPasswordBuffer+0x661 提取 bits[5:2] (4 位槽索引) 乘以 15 计算主偏移, 再从 gBanlistPasswordBuffer+0x660 (halfword) bits[9:6] 取列偏移叠加, 用 advance_text_ptr_by_charlen 在候选字符串中定位目标字符. 若候选字符为空格且全局模式标志 (gPrng+0x6c2c bits[2:0]) 为 0, 则改用备用字符串地址. 由 FUN_0801aa54 在用户选字时调用.
Side effects: [r0] (dest_char_buf) 通过 banlist_password_enter_char 写入选中字符.
Constants:
  CURSOR_SLOT_OFFSET = 0x661 // gBanlistPasswordBuffer cursor slot byte
  CURSOR_COL_OFFSET = 0x660 // gBanlistPasswordBuffer cursor halfword
  SLOT_STRIDE = 0xf = 15 // 每槽 15 字符间隔 (bits[5:2]*15)
  SPACE_CHAR = 0x20 // ASCII 空格, 检测是否为空字符
  MODE_FLAGS_PTR = 0x02000000 + 0x6c2c // 全局模式标志地址
  ALT_CHAR_TABLE = 0x09e3c040 // 备用字符表指针 (ROM 地址)
  CHAR_TABLE = 0x09e3bcb1 // 主字符表指针 (ROM 地址)
