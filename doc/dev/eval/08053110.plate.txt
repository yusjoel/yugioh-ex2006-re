Function: Equip slot eligibility check requiring equip card side != owner_bit (same-side reject), and card extended stat field6 != 0x17. Verifies: (1) chain_field nonzero; (2) owner_bit == card.side[bit0] => fail; (3) slot_idx in high zone index range [5..10] (subs r0,r4,#5; cmp r0,#5; bhi fail -- not monster slot [0..4]); (4) get_card_extended_stat_field6 return != 0x17; (5) field8 != 0; (6) check_zone_slot_equip_prerequisites. Returns 1 if all pass.

Params: r0=u8* card_ptr (equip card; [+0x2] bit0=side); r1=u8 owner_bit [0..1]; r2=u8 slot_idx [5..10] (high zone index, not monster slot)
Returns: r0=u32 eligible (0=ineligible, 1=eligible)
Side effects: none (pure query)
Constants: SLOT_IDX_MIN=5, SLOT_IDX_MAX=10, ZONE_BASE=0x0201c510, STRIDE=0x868, FIELD6_EXCLUDE=0x17
