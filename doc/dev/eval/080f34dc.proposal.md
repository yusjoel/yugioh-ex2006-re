# Naming Proposal: 0x080f34dc

## 提案
- **proposed_name**: blit_tile_nibble_row_msb
- **confidence**: high

## plate comment
将 4bpp 色彩索引 color 按高位优先(MSB nibble first)顺序展开为像素掩码, 并逐行 OR-写入目标 VRAM 地址 dst. 由 font_jp 渲染路径 (0x080dced0) 调用, 用于字符 tile 逐行着色. 先检查 gPrng+0x14 bit7(高色深模式), 若置位则透传给 blit_tile_color_to_vram_region; 否则将 color 展开为 0xfff0/0xff0f/0xf0ff/0x0fff 四段 AND 掩码, 对 16 列 * row_count 行依次 AND+OR 写 VRAM halfword.

Side effects: 写 VRAM[dst..dst+row_count*0x40*2] halfword (若 color != 0); 无 IO 寄存器副作用.

Constants:
- HIGH_COLOR_MODE_FLAG = 0x80 // gPrng+0x14 bit7
- MASK_NIBBLE0 = 0x0000fff0 // AND mask for nibble bits[7:4]
- MASK_NIBBLE1 = 0x0000ff0f // AND mask for nibble bits[11:8]
- MASK_NIBBLE2 = 0x0000f0ff // AND mask for nibble bits[15:12]
- MASK_NIBBLE3 = 0x00000fff // AND mask for nibble bits[3:0]

## 参数签名
- r0: u16* dst VRAM 行起始地址
- r1: u16 color 4bpp 颜色索引 [0x0..0xf]
- 返回: void (Pop {r0};bx r0 - r0 被 lr 覆盖)

## 副作用
- [r0..r0+row_count*0x80]: OR-write u16 像素行 (4 nibble 展开后着色)
