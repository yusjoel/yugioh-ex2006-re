## plate comment (中文, ASCII 标点)
综合检查玩家 r0 的 slot (r1+r2) 处的装备卡配对是否可以激活.
入口先检查 (r1+r2) <= 4; 超出则返回 0.
从 0x0201e4d0[0] (当前 player byte, bit0) 读取玩家标志, 再调用 check_slot_card_can_be_equipped 检查基础可装备性.
若可装备: 读 gDuelFieldSlots[r0][r1+r2] slot word 的 bit active (lsls #0x13 == 0x85e00000 标志);
若 active: 调用 count_available_monster_slots(player_bit0);
  若无空槽: 检查当前玩家是否与 r0 相同, 若不同返回 0;
  否则调用 check_slot_placement_blocked_by_field_effect.
通过后进入 set_code dispatch: 读 0x0201e4d0 word lsls #0x9 lsrs #0x11 得 set_code,
与 0xfdf (0x0fdf) / 0x0fe9 比较, 对应不同激活路径 (set_code 分支).
命中后调用 check_slot_card_pair_allowed(player, slot, set_code); 返回 0x800 (成功标志) 或 0.
调用方为 FUN_080a3a80 (两层循环扫描全场装备槽).
Constants: slot_max=4, active_flag=0x85e00000, set_code_a=0xfdf, set_code_b=0xfe9, success=0x800.
