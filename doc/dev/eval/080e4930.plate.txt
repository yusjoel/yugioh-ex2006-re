Pack candidate list eligibility gate. Iterates candidate list A (EWRAM+0x1154, count +0x1150). For each card: reads card_stats_table[icid*0x16] to get card_id (halfword field 0), calls get_card_field_summon_restriction(card_id); if return nonzero (summon restriction type 1 or 2) -> tail-call fail_pack_eligibility. All pass -> tail-call return_pack_handler_success. Called by FUN_080e3ee8 (pack scene dispatch). Enforces summon_restriction==0 for all cards in candidate list A. Constants: EWRAM_BASE=0x02000000; CAND_COUNT_A=EWRAM_BASE+0x1150; CAND_LIST_A=EWRAM_BASE+0x1154; CARD_STATS_STRIDE=0x16; RESTRICTION_NONE=0.
