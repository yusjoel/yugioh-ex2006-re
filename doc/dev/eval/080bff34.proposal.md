## plate comment (中文, ASCII 标点)
将输入 halfword (r0, 含 4 个 nibble 字段) 中每个 nibble (4 位调色板索引) 加上 palette 偏移量 (r1, 8 位), 重新打包为 GBA tile 属性 halfword 格式. 具体逻辑: 分解 r0 的 bits[3:0] / bits[7:4] / bits[11:8] / bits[15:12] 四个 nibble, 各自加 r1 后截断至 nibble, 再组合回 16 位输出. 被 FUN_080bff6c 多次调用 (4 次 bl FUN_080bff34), 用于将卡图调色板 tile 索引批量偏移.

Constants:
- NIBBLE_MASK = 0x0f0f = bits[3:0] + bits[11:8] (双 nibble 掩码)
- UPPER_NIBBLE_MASK = 0xf0 (bits[7:4] 提取)
- PALETTE_OFFSET_SHIFT: r1 以 lsls r1,r1,#0x18 / lsrs r1,r1,#0x18 截断至 u8

## 参数签名

- r1: u8 palette_offset [0..15] -- 调色板偏移量 (截断至 u8, 加到每个 nibble)
- 返回: r0 = u16 repacked_value (4 nibble 各加 offset 后重新打包的 halfword)
