Single-instruction function pointer trampoline: executes bx r3 to jump to the target function held in r3. Caller places function pointer in r3 before bl-ing here; r0/r1/r2 carry arguments. Called from 17 sites; key uses: (1) dispatch_effect_handler_by_card_id loads card handler fn ptr from effect table [ptr+4] and calls via this trampoline; (2) copy_with_waitcnt_and_verify_loop loads IWRAM verify stub from [0x02029ea4] and calls via this; (3) __srefill (stdio) calls FILE._read method pointer via this. Most semantically rich member of the trampoline family.
