# Naming Proposal: 0x08016238

## 提案
- **proposed_name**: get_objd_second_blob_ptr
- **confidence**: med

## plate comment (中文, ASCII 标点)

Function: 在 GFX 资源链表中按 "OBJD" (0x444a424f) 标签查找条目,
计算第二个内联数据 blob 的起始地址: entry_ptr + 0x20 + align_up([entry+0xc], 4).
其中 [entry+0xc] 为第一个 blob 字节大小 (四字节对齐), 跳过后定位第二个 blob.
与 get_bgdt_second_blob_ptr 同构, 差异仅在于起始偏移 0x20 (OBJD) vs 0x1c (BGDT).
indeg=0; 为 OBJD 多 blob 数据布局访问工具.

Side effects: 无 (纯地址计算).

Constants:
- OBJD_TAG = 0x444a424f ("OBJD", DWORD_08016254)
- OBJD_DATA_OFFSET = 0x20 (第一个 blob 起始偏移, OBJD 比 BGDT 多 4 字节头)
- SIZE_FIELD = [entry+0xc] (第一个 blob 字节大小)
- WORD_ALIGN = 4 (lsrs r0,r0,#2; lsls r0,r0,#2 = floor(x/4)*4 向下对齐)

## 参数签名

- 返回: r0 = void* second_blob_ptr (OBJD 第二个内联数据 blob 起始地址; pop {r1}; bx r1 = Sub-case E)
