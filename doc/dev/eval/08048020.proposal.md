## plate comment (中文, ASCII 标点)
对指定 slot 的卡牌执行完整 sprite 渲染流水线: 构造 OAM attr word, 提交卡牌 sprite, 扫描装备/附着 sprite, 触发 LP 条行更新和区域效果动作. 入口 r0=slot_ptr -> r4 (卡槽指针), r1=player_id -> r5. 若 r5==0 则从 0x0201bb90+0x0 读 turn word 到 r8; 否则从 +0x4 读. 随后从 gDuelFieldSlots 查槽内卡牌 card_id; 调用 query_slot_card_type_eligibility 确定卡类型; check_card_equip_eligibility_in_field 检查是否在装备路径; count_field_copies_of_card 计数场上副本; check_card_field8_is_9 判断特殊类型. 构造 OAM attr word r4 (含 priority/mode/type 字段); enqueue_sprite_attr_record 提交主 sprite; 若有装备卡则 scan_field_slots_for_equip_sprite; check_card_field5_is_nonzero/scan_field_slots_for_attached_sprite_by_id; dispatch_card_effect_sprite_render_by_card_id; submit_lp_bar_sprite_row_by_type(0x16/0x1b); dispatch_card_effect_zone_action_by_card_id. 返回 1 (成功) 或 0 (未渲染).

Side effects:
- OAM sprite 属性缓冲区: enqueue_sprite_attr_record 写入主 sprite
- LP 条缓冲区: submit_lp_bar_sprite_row_by_type 写入
- 效果区域 OAM: dispatch_card_effect_zone_action_by_card_id 触发

Constants: gDuelTurnStruct=0x0201bb90, gDuelFieldSlots_ext=0x0201bc54, SPRITE_ATTR_MASK=[多个位域].
