装备链手牌精灵分发函数. 接受 slot_ptr (r0=r5). 先检查 slot[3] bits[5:4] (mask 0x30): 若 !=0x20, 走快路径: 计算 player_id XOR facing_bit, 以 slot[0] card_id + xor_player + r2=1 + r3=0 调用 enqueue_sprite_attr_type11, 再调 trigger_card_display_op31_if_not_active(player_id, 0x9c); 返回 0.
若 slot[3] bits[5:4]==0x20, 读 gP1LifePoints+0x4a0 状态码分发:
  状态 0x7f: init_effect_slot_display_context(player_id, slot[0], mode=6, 0), 返回 0x7e.
  状态 0x7e: get_monster_slot_entry_ptr(player_id) x2, 从两个槽计算 tile_index 合计, 调 enqueue_hand_card_sprite_by_spell_type(player_id, tile_sum, r2=1). 先比较卡 id: reserved_icid_a(0x144c) 或 CARD_ID_RESERVED_A_MINUS3(0x1449) -> op=0x4c; 0x1452 -> op=0x4e; The Forgiving Maiden(0x1457) -> op=0x4d; 后者 >=0x144c: 判断墓地槽路径调 enqueue_graveyard_spell_sprite_with_zone_ref.
  状态 0x80: dispatch_effect_handler_by_card_id(1-player_id, slot[0], 0), 非零则比较四个 card_id 常量(RESERVED_ICID_A/CARD_ID_RESERVED_A_MINUS3/RESERVED_ICID_B/CARD_ID_THE_FORGIVING_MAIDEN) 调 trigger_card_display_op31_if_not_active; 返回 0x7f.
