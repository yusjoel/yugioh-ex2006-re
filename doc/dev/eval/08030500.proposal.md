## plate comment (中文, ASCII 标点)
将卡片 ID (halfword, 从 r2 指向的结构体偏移 0 读取) 映射为动画类型枚举值 [0..6].
通过大型二叉搜索 dispatch 树 (比较 DAT 常量后 beq/bgt/blt 分支) 对全部已知卡片 ID 分区间匹配, 最终汇聚到 6 个返回标签:
  - LAB_08030874: movs r0,#1 (anim_type=1, 普通/默认动画)
  - LAB_0803084c: movs r0,#4 (anim_type=4, 魔法/陷阱扩展动画)
  - LAB_08030850: 调用 count_equip_slots_active_only -> 若 >0 则 movs r0,#6 (anim_type=6, 装备激活动画), 否则 0
  - LAB_08030838: 调用 read_effect_slot_side_and_type -> 若 slot_type >4 则 movs r0,#2 (anim_type=2), 否则 0
  - LAB_08030866: 读 attr 字段检查范围 [0x1f..0x21] -> 返回 1 或 0
  - LAB_08030884: movs r0,#0 (anim_type=0, 无动画)
调用方: FUN_08036870 (批次内 C_util_high indeg=37), FUN_0805d118/FUN_080b40d8 (间接).

Constants: anim_type codes: NO_ANIM=0, DEFAULT=1, EXTRA=2, SPELL=4, EQUIP=6.

- 返回: r0 = u32 anim_type [0..6] (动画类型枚举: 0=无/1=默认/2=效果/4=魔法陷阱/6=装备)
