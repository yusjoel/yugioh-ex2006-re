## plate comment (中文, ASCII 标点)
在指定玩家的装备格链表中搜索类型码为 0xd 的节点并返回其 id. r0=player_key (bit0=player_id), r1=slot_index [0..4]. 计算槽偏移: slot_stride=0x14, player_stride=0x868, 基址=gDuelFieldSlots (0x0201c510). 读 [slot+0xa] (halfword) 作为初始链头; 若为 0 直接返回 0xffff (无节点). 否则进入循环: 以节点偏移 DAT_0802f918=0x14b0 为子表基址, 节点步长 8 (lsls #3), 每轮读 [node+0x2] byte 的低 4 bit (与 0xf and), 若等于 0xd 则返回 [node+0x0] halfword (entity id); 否则读 [node+0x6] halfword (next ptr), 若为 0 退出返回 0xffff. 4 个 caller: FUN_0804369c, FUN_0804888c, FUN_08050038, FUN_0805ca50 (均含 duel_field).

## 参数签名

- r1: u32 slot_index [0..4]
- 返回: r0 = u16 entity_id (找到 type=0xd 节点时); 0xffff (未找到)
