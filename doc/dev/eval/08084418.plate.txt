Equip state sprite attr enqueue function. Sibling pair with enqueue_equip_slot_sprite_if_equipped (0x08083824) -- structurally symmetric. Checks card_slot[+3] bits[5:4] == 0x20; if not, returns 0. If match: extracts player_id (byte[+2] bit0) and slot_idx (halfword[+0]); calls get_node_entity_id_in_slot(player_id, slot_idx, type=0xb); calls enqueue_equip_slot_sprite_attr(player_id, 0xb, slot_idx, 0) to write OAM sprite attr; if entity_id>=0, calls push_to_effect_slot_array. Returns 1. indeg=0: Sub-type A runtime fn-ptr dispatch.
Side effects: OAM attr write via enqueue_equip_slot_sprite_attr; effect_slot array append via push_to_effect_slot_array.
Constants: EQUIP_STATUS_BITS=0x30 (bits[5:4] of byte[+3]), EQUIP_FLAG=0x20, SLOT_TYPE=0x0b.
