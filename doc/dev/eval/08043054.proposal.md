# Naming Proposal: 0x08043054

## 提案
- **proposed_name**: enqueue_sprite_attr_with_mode
- **confidence**: high

## plate comment (中文, ASCII 标点)
核心 sprite OAM 属性入队原语, indeg=74. 将 5 个参数打包后调用 enqueue_sprite_attr_record 写入 OAM 缓冲.
r0 控制调色板模式选择: r0=0 时使用默认 attr2_palette=0x36, r0!=0 时从 DAT_08043088 (=0x8036) 读取扩展调色板值.
r1 (u8, callee-save r5) = sprite type/group, r2/r3 (u16 after mask) = x/y 坐标, sp[0x10] (u16) = extra attr.
将 r5 (type) 和 r3 (y) 拼合为 OAM attr1 word: (r5 << 24) | (r3 << 24) >> 8, 然后以 r2=x, r3=y, r4=extra 调用 enqueue_sprite_attr_record.
74 个 caller 覆盖 duel_field 中几乎所有 sprite 提交点, 是底层 OAM 写入的单一汇聚点.

Constants: default_palette=0x36, ext_palette=0x8036 (DAT_08043088), attr_pack: type_field=bits[23:16] of r1.

## 参数签名
- r0: u32 palette_mode - 0=default_palette(0x36), non-0=ext_palette(0x8036)
- r1: u8 sprite_type [0..0xff] - OAM group/type 字段, 存入 attr1 高字节
- r2: u16 x_pos [0..0x3ff] - OAM attr1 x 坐标 (lsls/lsrs mask 到 u16)
- r3: u16 y_pos [0..0x1ff] - OAM attr0 y 坐标 (lsls/lsrs mask 到 u16)
- sp[0x10]: u16 extra_attr [0..0xffff] - 附加 OAM attr (r4 = lsls/lsrs after load)
- 返回: r0 = void (无, bx r0 尾跳 enqueue_sprite_attr_record 的返回值透传)

## 副作用
- 通过 enqueue_sprite_attr_record 写入全局 OAM 缓冲 (间接副作用)
