Single-instruction function pointer trampoline: executes bx r0 to jump to the address in r0 (THUMB mode bit0=1). Callers load the target function pointer into r0 before bl-ing here; r1..r3 carry arguments passed through to the target. Called from 34 distinct sites covering scene-switch callbacks, card-effect table indirect calls, and display subsystem dispatch. Together with invoke_r1/r2/r3 (0x0810e5cc/d0/d4) forms the GBA ROM APCS-register function-pointer dispatch cluster.
