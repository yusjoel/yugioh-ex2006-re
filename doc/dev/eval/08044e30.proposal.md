## plate comment (中文, ASCII 标点)
为决斗场指定槽位(r0=player_id, r1=slot_idx, r2=side_flag)执行完整的精灵状态更新流程. 首先比对槽位 gP1LifePoints+offset 处的控制字 bit5 与 r2 是否匹配, 不匹配则直接跳出; 匹配后读取 card_id(lsrs #0x13 取低 13 位), 调用 set_field_slot_bit_with_sprite_update, 随后根据 slot_idx 范围(<=4 vs >4)和 side_flag 分派到多条子路径: 每条路径依次调用本批次中 enqueue_effect_card_slot_sprite_attr(FUN_08045314) / enqueue_equip_card_sprite_attr_for_slot(FUN_0804543c) / enqueue_equip_slot_sprite_attr(FUN_080431ac) / enqueue_equip_chain_all_slots_for_pair(FUN_0804317c) / enqueue_sprite_attrs_for_card_chain_list(FUN_08043644) 等函数以刷新 OAM 队列. 由 FUN_08044dcc(duel_field) 和 FUN_0805b990(duel_field) 触发. Side effects: 多次调用 enqueue_* 系列函数写入 OAM 精灵属性队列.

## 参数签名
- r0: u8 player_id [0..1] - 玩家侧 (存入 r8 via .hword 0x4680)
- r1: u8 slot_idx [0..9] - 卡槽索引 (存入 r6)
- r2: u8 side_flag [0..1] - 侧面标志 (存入 r7; 与 gP1LifePoints 字段 bit5 比对决定是否更新)
- 返回: r0 = void (无返回值, 仅副作用)

- 多次调用 enqueue_* 系列函数: 写入 OAM 精灵属性队列
