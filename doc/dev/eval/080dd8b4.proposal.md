# Naming Proposal: 0x080dd8b4

## 提案
- **proposed_name**: decode_overlay_color_channels
- **confidence**: high

## plate comment (中文, ASCII 标点)
将打包的 GBA 15-bit 颜色值拆解为 R/G/B 三通道, 并计算通道最大/中间值.
r0 = 打包颜色 (GBA RGB555 格式 bit[4:0]=R, bit[9:5]=G, bit[14:10]=B);
函数提取三通道, 找出最大值, 如果两通道相等则用 bios_div 计算插值比例,
结果写入 r2/r3 指向的输出槽.
被 FUN_080dda8c 等颜色插值函数调用, 用于 overlay 渐变效果.

Constants:
- 0x1f: GBA 颜色通道 5-bit 掩码
- 0xf8<<2 = 0x3e0: G 通道 mask (bits [9:5])
- 0xf8<<7 = 0x7c00: B 通道 mask (bits [14:10])

## 参数签名
- r0: u16 color 打包 GBA RGB555 颜色值 [0..0x7fff]
- r1: u16 (callee-save 别名, 0x4688=mov r8,r1 -> r8 spill; r1 来自 caller 设置)
- r2: u32* out_max_channel 输出最大通道值的地址
- r3: u32* out_mid_ratio 输出中间插值比例的地址
- 返回: void (pop {r0}; bx r0 透传 lr)

## 副作用
- [r2+0]: := max(R,G,B) (ldr/str 写出)
- [r3+0]: := mid_ratio (0 或计算值)
