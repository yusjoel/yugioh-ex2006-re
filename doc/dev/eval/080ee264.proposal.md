# Naming Proposal: 0x080ee264

## 提案
- **proposed_name**: upload_sprite_tiles_with_palette_blend
- **confidence**: med

## plate comment (ASCII-only)
被 FUN_08105bfc (同 080ee050 的 caller) 调用, 与 upload_sprite_tiles_and_write_oam
结构相似但新增调色板混合逻辑: 在写 OAM 前逐条目检查 attr1 的调色板 flag,
若置位则将调色板 ID 叠加到 attr1 高字节 (r4<<8), 否则直接写出. 使用
copy_bytes_by_halfword 复制 tile 数据后, 对每个 OAM 条目进行调色板调整再写 OAM.

## 参数签名
- r0: u16 x_base — 精灵基础 X 坐标
- r1: u16 y_base — 精灵基础 Y 坐标
- r2: u16 tile_slot — OBJ VRAM tile 目标槽号
- r3: u32 packed_pal — 调色板号 + 附加标志 (低字节=palette_id, 高字节=flags)
- [sp+0x30]: ptr sprite_frame_desc — 精灵帧描述结构体
- 返回: r0 = u16 — 写入 OAM 条目数

## 副作用
- [OBJ VRAM 0x06000000 + tile_slot*tile_size] := tile 数据 (通过 copy_bytes_by_halfword)
- [OBJ VRAM 0x05000000/0x06008000 附近] := 第二段 tile 数据
- [OAM 缓冲 各条目] := 经调色板混合调整后的 attr0/attr1/attr2 (strh)
