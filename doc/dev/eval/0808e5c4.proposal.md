# Naming Proposal: 0x0808e5c4

## 提案
- **proposed_name**: render_field_card_copy_count
- **confidence**: high

## plate comment (中文, ASCII 标点)
统计场地上某张卡的拷贝数量并将数量渲染为 sprite. 固定使用 base=0x132c (DAT_0808e5fc) 作为卡片查询对象.
首先调用 count_field_copies_of_card(base, ...) 获取场上拷贝数 (r4). 若 r4<=0 直接返回.
若 r4>0: 以 r0=-1, r1=base 调用 enqueue_sprite_attr_by_sign (0x080486b0) 提交一个"激活态"标记 sprite (palette=0x30).
再循环 r4 次调用 enqueue_sprite_clamped (0x08048750), r0=r6(=card_ptr), r1=0x1f4 (=0xfa<<1), 每次递减 r4 直到 0.
5 个 caller 含 FUN_0804a334 (duel_field), FUN_0807fde8 (多标签), FUN_08095ca0 (duel_field), FUN_080abbd8/FUN_080abe54.

Constants: CARD_BASE=0x132c (DAT_0808e5fc), COUNT_SPRITE_Y=0x1f4 (=0xfa<<1).

## 参数签名
- r0: ptr card_ptr - 卡片指针 (r6 保存, 传入 enqueue_sprite_attr_clamped 的 r0)
- 返回: r0 = void (bx r0, 无返回语义)

## 副作用
- 调用 count_field_copies_of_card (读 gDuelFieldSlots 区域, 只读)
- 调用 enqueue_sprite_attr_by_sign -> enqueue_sprite_attr_record (写 OAM 缓冲)
- 循环调用 enqueue_sprite_attr_clamped -> enqueue_sprite_attr_record (写 OAM 缓冲, 共 count 次)
