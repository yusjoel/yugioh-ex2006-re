Equip display state-code dispatcher. Reads the IWRAM state code (range 0x64..0x80), subtracts the base 0x64, and dispatches via a 29-entry jump table to each sub-handler path. Each case handles a different stage of the equip activation animation, returning the corresponding next state code (0x7f / 0x78 / 0x7e / 0x7d / 0x64 / 0). The central dispatch point of the equip display state machine.
