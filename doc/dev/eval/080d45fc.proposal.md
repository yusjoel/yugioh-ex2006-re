- **confidence**: high

## plate comment (中文, ASCII 标点)
pack 卡包选卡界面加载最多 3 张卡牌 tile 图像到 VRAM. 输入 r0 指向 3-card-ID 数组 (每项 4 字节), r1 保存 flags 供内部偏移计算. 对每个 card_id(若 <= 0x3ff): 以 id*0x20 为索引在 ROM 卡图表 (0x09ce822c+) 中查找 tile 行指针, 经 tile_2d_row_copy 写入 OBJ VRAM 0x06010000 (第 0/1/2 槽). 最后 DMA 复制对应调色板 (0x09ce824c 表) 至 0x05000200 (32 字节). 初始化 pack_ui_state 滚动子结构: [+0x6b0] 置 r1 原值保留的 flags; [+0x6b2/+0x6b4] := 0 (起始位置清零); [+0xe/+0x1e] := 特定默认值.

Constants:
- OBJ_VRAM_CARD_BASE = 0x06010000 (pack card 槽 OBJ tile 目标)
- ROM_CARD_TILE_TABLE = 0x09ce822c (card tile ROM 索引表)
- ROM_CARD_PAL_TABLE = 0x09ce824c (card palette ROM 索引表)
- PAL_DST = 0x05000200 (调色板目标槽)
- CARD_ID_VALID_MAX = 0x3ff [0..0x3ff] (有效 card_id 范围)
- TILE_ENTRY_STRIDE = 0x20 (card_id -> ROM 表项字节步长)
- pack_ui_state = 0x03005850 (IWRAM 状态基址)
- SCROLL_STRUCT_OFFSET = 0x6b0 (= 0xd6 << 3, 滚动子结构偏移)

## 参数签名
- r0: u32* card_id_array -- 指向含 3 个 card_id 的数组 (各项 [0..0x3ff])
- r1: u16 flags_or_aob_idx -- .hword 0x4688 (mov r8,r1) 保存; 内部用于 pack_ui_state 字段初始化 [+0x6b0]
- 返回: void (pop {r0}; bx r0 模式, 无独立 r0 写)

## 副作用
- [0x06010000]: := card 0 tile 数据 (tile_2d_row_copy, 若 card_id[0] <= 0x3ff)
- [0x06010000+slot_offset]: := card 1/2 tile 数据 (各自槽位)
- [0x05000200..+0x1f]: := ROM 调色板 32 字节 (DMA via copy_memory_dma3_with_cpu_fallback)
- [pack_ui_state+0x6b2]: := 0 (strh r7, 滚动 x 起始清零)
- [pack_ui_state+0x6b4]: := 0 (strh r7, 滚动 y 起始清零)
- [pack_ui_state+0x6b0+0xe]: := 0x100 (strh 0x80<<1)
- [pack_ui_state+0x6b0+0x1e]: := r8 (flags/aob_idx, .hword 0x4640 = mov r0,r8)
