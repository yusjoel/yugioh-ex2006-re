check_equip_eligible_by_lp_count_and_zone_offset
Extracts player_id (byte[+2] bit0) from slot_ptr (r0).
Dual LP state gate:
(1) gP1LifePoints + player*0x868 + 0x10 must be nonzero (own LP state active);
(2) gP1LifePoints + (1-player)*0x868 + 0xc must be nonzero (opponent LP state active).
Both pass -> call get_lp_count_minus_zone_slot_offset(slot_ptr, player_id);
if return > 0 -> return 1; else -> return 0.

Constants:
- gP1LifePoints_BASE = 0x0201c4e0
- PLAYER_STRIDE = 0x868
- LP_STATE_SELF_OFFSET = 0x10
- LP_STATE_OPP_OFFSET = 0xc

Inputs: r0 = SlotPtr* slot_ptr (byte[+2] bit0=player_id [0..1])
Returns: r0 = u32 -- 1 if LP states active and zone offset count > 0, 0 otherwise
Side effects: none (pure query)

Callers: indeg=0; grep ".word 0x0805f645" asm/all.s -> 0 hits (Sub-type A dead code)
Callees: get_lp_count_minus_zone_slot_offset
