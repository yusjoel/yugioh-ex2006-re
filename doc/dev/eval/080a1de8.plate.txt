LP display row type 16 (0x10) wrapper: loads LP row object pointer from gP1LifePoints+0x1ce8, truncates r0 (player_id) to u16 as third parameter, calls set_lp_display_row_fields with type=0x10/r3=0. r0=player_id is not passed as row object; row object address is fixed from global LP struct offset 0x1ce8. Called by LP status display paths (0x0806996e, 0x0806e6e6, 0x0806fdda, 0x0807075e, tags=[duel_field]).
Side effects: writes LP display row type=0x10 field via set_lp_display_row_fields.
Constants: ROW_TYPE=0x10 (16, fixed; movs r1,#0x10), LP_ROW_OFFSET=0x1ce8.
