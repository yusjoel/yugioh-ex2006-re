## plate comment (中文, ASCII 标点)
将字符串渲染到 BG tile VRAM 的指定行. 使用 setup_line_buf_pos_and_font 初始化 line buffer; 按 gSettings.lang 选择 font_jp_base_table 字体; 计算字符串宽度并与 r2 (max_width) 比较, 超宽时切换到窄字体; 调用 render_jp_string_nowrap 或 text_render_wrapper 渲染文本; 最终通过 write_line_buf_to_bg_tile_vram 写入 BG tile VRAM 0x06010000 + row*0x20 偏移. 由 FUN_080e2050 和 FUN_080e2224 在 duel_puzzle 场景文本渲染时调用.

Constants:
  FONT_BASE_PTR     = font_jp_base_table (0x09e5f854)
  gSettings_lang    = [0x02000000+0x6c2c]   // bits[2:0] = language enum
  BG_TILE_DEST_BASE = 0x06010000            // write_line_buf target
  ROW_STRIDE        = 0x20 halfwords (0x40 bytes/row)
  SP_STR_OFFSET     = 0x30 from sp         // 5th stack argument: string ptr
