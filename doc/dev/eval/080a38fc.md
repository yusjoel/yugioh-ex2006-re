## 修改清单

### #1 — R4 (高优先级)
**位置**: proposal 参数签名节 "返回:" 行
**问题**: "r0 = int32 (0=advance, 1=done)" 后缀 "-> void r0" 矛盾; 出口含 pop{r1};bx r1 Sub-case E 不 void r0
**当前**: `返回: r0 = int32 (0=advance, 1=done; 出口 pop{r3}; mov r8,r3; pop{r4,r5,r6,r7}; pop{r1}; bx r1 -> void r0)`
**应改为**: `返回: r0 = i32 (0=step=0 清零后继续, 1=step=1/2 以上序列完成; 出口 pop{r3}; mov r8,r3; pop{r4,r5,r6,r7}; pop{r1}; bx r1)`

### #2 — R6 (高优先级)
**位置**: proposal Constants 节
**问题**: (A) CARD_ID_159A/1766 无括号卡名; (B) SCORE_OFFSET 含 `?` 占位符; (C) CARD_ID_17BE 含 `?` 且算式错误 (0x159a+0xdc=0x1676≠0x17be); 须追踪 asm 中实际 cmp/ldr 字面量后直接写值
**当前**:
```
- CARD_ID_159A = 0x159a
- CARD_ID_17BE = 0x159a+0xdc? (first cmp offset)
- CARD_ID_1766 = 0x1766
- LP_SCORE_BASE = 0x0201afe0
- LP_DIVISOR = 0x3e8 (1000)
- SCORE_OFFSET = 0x1ea0-0x160=0x1d40 (0x1ea0? -> 0x1d40 field)
```
**应改为**:
```
- CARD_ID_159A = 0x159a (Reasoning)
- CARD_ID_XXXX = 0xXXXX (Card Name)  [追踪实际 cmp 字面量后填写; 若非 0x17be 则删除]
- CARD_ID_1766 = 0x1766 (Wall of Revealing Light)
- LP_SCORE_BASE = 0x0201afe0
- LP_DIVISOR = 0x3e8 (1000)
```
