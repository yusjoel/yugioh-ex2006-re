## plate comment (中文, ASCII 标点)
将卡名字符串渲染到 OBJ sprite tile VRAM 的函数. r0 = 卡名字符串指针, r1 = 目标 tile_idx (决定 OBJ VRAM 偏移 = 0x06004000 + tile_idx*32). 流程: setup_line_buf_pos_and_font(0x1a,2) 初始化; 按 gSettings.lang 选 font_jp_base_table 字体条目; count_bytes_until_null 测量字符串长度, 若 >0x21 字节则切换为窄体字体; 调用两次 text_render_wrapper(0x8,3,row=0/7,str) 渲染双行文本; zero_fill_by_halfword(0x06004000+tile_idx*0x20, 0xd0*3) 清空 tile 区; commit_line_buffer_to_sprite_vram 写入. 由 FUN_080e5ac8 (pack 卡名渲染循环) 调用.

  FONT_SIZE   = 2             // 字体尺寸参数
  ROW_B       = 7             // 第二行 y 偏移
  LEN_NARROW  = 0x21 = 33    // 超此长度切换窄体

  ZERO_SIZE   = 0xd0*3 = 0x270  // 清零区大小

## 参数签名

- r1: u16 tile_idx [0..N-1] (OBJ tile 索引; lsls/lsrs #0x10 截断为 16 位; 目标地址 = TILE_BASE + tile_idx*0x20)
- 返回: void (pop{r0}; bx r0)

## 副作用
- [0x06004000 + tile_idx*0x20, +0x270): zero_fill_by_halfword 清零
- [0x06004000 + tile_idx*0x20, +size): commit_line_buffer_to_sprite_vram 写渲染结果
