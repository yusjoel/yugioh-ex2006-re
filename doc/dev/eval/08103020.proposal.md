## plate comment (中文, ASCII 标点)
card_list 场景卡片槽数据按列表类型加载函数. r0=list_type [0..2], r1=card_index. list_type==0: 检查 0x02000000[+0x53f0+(index/32)*4] bit(index%32); 若未置则返回 0. list_type==1: 验证 card_index 在 format 范围内 (get_card_data_format_id); 越界返回 0. 验证通过后按 list_type 分三支: 0=从 0x02001250+index*0x118 复制 0x118 字节到 r6 (IWRAM 槽区); 1=调用 load_card_name_from_fs_by_index; 2+=从 0x02001138 复制. 最后调用 reinit_deck_slots_and_data. 返回 1 或 0.

Constants:
- 0x0202a4d0[+0x6c] = 目标槽数据区 (r6)
- 0x02001250 = 全库卡片数据表 (每条 0x118 字节)
- 0x02001138 = 备用卡片数据源
- 0x02000000[+0x53f0] = 已见卡位图基址
- 0x118 = 单卡数据大小

## 参数签名
- r0: int32 list_type (列表类型 [0..2]: 0=全库, 1=format, 2+=其他)
- r1: int32 card_index (卡片索引; list_type==0 时 [0..max_cards-1], list_type==1 时 [0..format_count-1])
- 返回: r0 = int32 (0=验证失败/越界, 1=加载成功)

## 副作用
- [0x0202a4d0+0x6c..+0x183]: copy_bytes_by_halfword 写入 0x118 字节 (条件: 验证通过)
- reinit_deck_slots_and_data 的副作用 (条件: 验证通过)
