# Naming Proposal: 0x0810dcc0

## 提案
- **proposed_name**: clear_freq_slot_dma_buf
- **confidence**: high

## plate comment (中文, ASCII 标点)
以 r0 (slot_index [0..2]) 定位 IWRAM 频率槽数组 (0x03005608, 步长 0x14=20 字节) 中的条目, 取 [slot+0] 处的数据指针 data_ptr. 若 data_ptr 为 null 则直接返回. 否则循环 8 次 (r4: 0..7): 以 DMA3 将 sp 零区 (512 halfword = 0x400 字节) 传输到 data_ptr, 每次 data_ptr += 0x400, 合计清零 0x2000 字节. 由 sound engine 主循环 (0x0810bc10) 在 channel 重置时调用.

Constants:
- FREQ_SLOT_BASE=0x03005608 (IWRAM 频率槽数组基址)
- SLOT_STRIDE=0x14 (20 字节/条目)
- DMA3SAD=0x040000D4
- DMA_CNT=0x81000200 (bit15=enable, count=0x200 halfword, 16-bit, src/dst increment)
- DMA_BLOCK=0x400 (每次 DMA 清零字节数, 0x200 hw * 2)
- DMA_ITERS=8 (0..7, 合计清零 0x2000 字节)

## 参数签名
- r0: u8 slot_index [0..2], 选择频率槽条目 (offset = slot_index * 20)
- 返回: void (pop {r4,r5,r6}; pop {r0}; bx r0 -- Sub-case E void)

## 副作用
- [data_ptr .. data_ptr+0x1fff] := 0 (DMA3 写零 8192 字节; data_ptr = FREQ_SLOT_BASE[slot_index].data_ptr)

## 行级注释 (<= 30 行精华)
- @ 0810dcc0: push {r4,r5,r6,lr}; sub sp,#4; load 0x03005608
- @ 0810dcc6: r1 = (r0*4+r0)*4 = r0*20 (slot offset)
- @ 0810dcce: r1 = [FREQ_SLOT_BASE + r1] = data_ptr
- @ 0810dcd0: if data_ptr==0: skip to return (no buffer allocated)
- @ 0810dcd4: r4=0 (iter); r3=DMA3SAD; r6=0 (zero src); r5=0x81000200 (DMA ctrl)
- @ 0810dcde: .hword 0x4668 = mov r0,sp (DMA source = stack zero word)
- @ 0810dce0: DMA3SAD:=sp; DMA3DAD:=data_ptr; DMA3CNT:=0x81000200 (fire)
- @ 0810dcf4: spin until DMA3CNT bit31 clear (DMA done)
- @ 0810dcfc: r0=0x80<<3=0x400; data_ptr+=0x400 (advance dest)
- @ 0810dd02: r4++; if r4<=7: loop (8 total iterations)
- @ 0810dd06: add sp,#4; pop; Sub-case E void return
