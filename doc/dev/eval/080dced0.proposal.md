## plate comment (中文, ASCII 标点)
将文字内容渲染到当前文字叠加层 (text overlay) 的 BG VRAM 区域. 从 gPrng+0x1d0 读取当前 overlay 结构体指针 (r7); 若为 null 或 r7+0x18 为 null 则直接返回. 根据 r7+0x14 flags bit1 确定字体宽度修饰 (2 或 4); 读 r7+0xe/r7+0x10 作为 overlay 内容区域宽/高 (各减 2); 调 setup_line_buf_font_with_align_and_slot 初始化行缓冲字体和对齐方式. 操作 0x02006ed0 字体控制字节 (orrs/ands 修改 bit0..2); 调 render_jp_string_nowrap_with_offset 渲染 JP 字符串并取返回宽度用于水平居中偏移. 随后两次调 text_render_wrapper 写出文字; 更新 r6+0xa overlay scroll 字段. 最后根据 flags bit0 决定调 blit_tile_nibble_row_msb 或 blit_tile_nibble_row_lsb 将结果写入 BG tile VRAM. 入参 r0=str_ptr, 存于 [sp+0x4]. 由 FUN_080dd4ac (overlay 尺寸更新) 和 text_overlay_create 调用.

Constants:
- gPrng+0x1d0: overlay 结构体指针 (gPrng+0xe8*2)
- 0x02006ed0: 行缓冲字体控制结构基址
- 0x06010420: blit_tile_nibble_row_lsb 默认目标基址 (DAT_080dd06c)
- 0x000003ff: tile 索引 mask (DAT_080dd040)
- 0xfffff003: tile 清除 mask (DAT_080dd044)

## 参数签名
- r0: const char* str_ptr - 要渲染的 JP 字符串指针 (存入 [sp+0x4])
- 返回: r0 = void (pop {r0}; bx r0)
