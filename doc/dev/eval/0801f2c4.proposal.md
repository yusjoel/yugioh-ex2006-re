## plate comment (中文, ASCII 标点)
将格式串 r1 中的 %s 占位符替换为字符串参数 r2, 结果写入目标缓冲区 r0. 若 r1 或 r2 的高 15 位为 0 (不带 RAW_ID_MASK=0xfffe0000 标记), 则先调用 resolve_game_str_ptr 将游戏字符串 ID 解析为真实指针. 字符逐一拷贝, 遇到 %s 时截断当前位置, 调用 append_game_text_if_raw 将 r2 内容插入, 再继续追加剩余格式串. 被 34 个调用方广泛使用 (C_util_high), 是游戏 UI 文本格式化的核心工具函数, 用于生成含卡名/玩家名等动态文本的界面字符串. Constants: RAW_ID_MASK=0xfffe0000 (区分原始 ID 与真实指针的高 15 位掩码).

- 返回: void (无返回值, 仅副作用)

## 副作用
