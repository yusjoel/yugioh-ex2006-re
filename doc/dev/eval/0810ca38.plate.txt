Sound engine per-frame tick and DMA channel volume compute driver. Called every frame by FUN_080f4a18 (tags: [sound,frame_driver]). Checks 0x030050cc+0x364 bit13 (DMA pending 0x2000); if set early-returns void. Otherwise calls tick_sound_engine_main(engine_base) to advance one frame. Reads playback position from 0x030055c0+0x42, +0x40 reads loop count r6; if position nonzero calls bios_div(r6, position) to compute volume r2. Writes [+0x40] := 0, [+0x44+0x0] := 0 (played frames), [+0x44] := r6, [+0x46] := r2. Returns void (Pattern B: pop{r0};bx r0).
