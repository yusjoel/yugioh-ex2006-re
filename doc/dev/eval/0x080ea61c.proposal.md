Constants: NNS_G2D_PLTT_BANK_16=3 (32-bytes/entry) / NNS_G2D_PLTT_BANK_256=4 (512-bytes/entry) / OBJ_PALETTE_VRAM=0x05000200 / PALETTE_VRAM_MASK=0x001fffff.
