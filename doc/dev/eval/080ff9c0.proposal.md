# Naming Proposal: 0x080ff9c0

## 提案
- **proposed_name**: reset_card_list_scroll_state
- **confidence**: med

## plate comment (中文, ASCII 标点)
card_list 场景滚动/选择状态重置函数. 将 IWRAM 0x0202f3c0 结构体中偏移 0xe-0x1a 共 7 个 halfword 字段清零, 唯独将偏移 0x12 设为 0xffff (无效/哨兵值). 随后返回 1. 被 card_list_screen_init 在初始化时调用一次, 也被 FUN_080ff4f0 / FUN_080ff980 / FUN_080ffaf8 (均为 scene_card_list) 在导航操作后调用, 说明这些字段记录当前滚动位置/光标/帧计数等状态, 每次切换显示模式时需整体归零并将某个字段置 sentinel.

## 参数签名
- 无参数
- 返回: r0 = 1 (始终成功)

- [0x0202f3c0 + 0x18]: strh 0 (清零)
