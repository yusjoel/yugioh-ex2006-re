- **confidence**: high

## plate comment (中文, ASCII 标点)
dlmalloc 互斥锁占位函数 (加锁桩): 函数体仅 bx lr, 不执行任何操作.
在 _free_r / _malloc_r / _malloc_trim_r / _realloc_r 进入临界区前被调用, 用于在单线程嵌入式环境中替代真正的互斥锁获取.
GBA 无 RTOS 上下文, 因此加锁为空操作; 与 stub_malloc_unlock (0x081119d4) 成对出现.
