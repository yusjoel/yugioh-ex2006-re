# Naming Proposal: 0x08100b70

## 提案
- **proposed_name**: render_card_list_visible_slots
- **confidence**: med

## plate comment (中文, ASCII 标点)
card_list 界面可见槽位 tile 渲染函数. 读取 0x0202f3c0[+0](slot_vis_flags, uint16), 若 bit4(0x10) 置位则先调用 zero_fill_by_halfword 清零 VRAM OBJ 0x0600e000(0x800 字节). 随后以 r3=0..5 循环, 每次从 slot_vis_flags 右移 r3 位取 bit0 判断槽是否可见; 若可见则进一步检查 0x0202a4d0[+0x16] & 1 (foil bit), 结合 slot 序号决定跳过条件(slot<=3 含 foil 保护). 可见槽按 display_mode(0x0202a4d0[+0])==0/1/2/3 分别从不同 ROM tile 表 (0x09e5ff98/0x09e5ffb0/0x09e5ffc8/0x09e5ffe0) 中取偏移, 加 VRAM 基址 (0x0600xxxx) 后将 tile 数据以 strh 写入 VRAM OBJ.

## 参数签名
- 无入参 (全部从 IWRAM 0x0202a4d0 / 0x0202f3c0 读取)
- 返回: r0 = uint32 1 (always)

## 副作用
- [VRAM OBJ 0x0600e000]: zero_fill_by_halfword 写 0x800 字节 (仅当 slot_vis_flags & 0x10)
- [VRAM OBJ 0x0600xxxx + slot_offset]: strh tile 索引写入可见槽对应 OBJ tile 位置
- [0x0202f3c0 + 0x0]: strh 0 (循环结束时清零 slot_vis_flags)
