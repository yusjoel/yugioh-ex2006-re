init_banlist_pass_input_bg2_page: BG2 init for banlist password-input scene. Steps: (1) get_bg2_screen_vram_addr + bios_cpu_fast_set zeros BG2 tilemap; (2) computes BG2 char VRAM offset (0xbd<<5=0x17a0*N+0x20), zeros it with bios_cpu_fast_set fill mode (bit17=1); (3) writes 0 to gBanlistPasswordBuffer+0x664 (clear scroll flag); (4) reads gBanlistPasswordBuffer+0x66e to compute initial scrollbar via __divsi3(input+0xe, 0xf); (5) init_banlist_scrollbar_oam_entry; (6) write_banlist_bg2_scroll_regs_biased(0) and write_banlist_bg3_vofs_with_bias(0); (7) fill_tilemap_rect_with_palette(0,0,27,21). Sibling of init_banlist_pass_input_bg0_page (0x08019d14).

Constants:
- BIOS_CPUSET_SCREEN = 0x01000200
- CHAR_VRAM_STRIDE = 0xbd<<5 = 0x17a0 = 6048
- FILL_CTRL = 0x80<<0x11 = 0x01000000
- PASS_BUF_SCROLL_OFF = 0x664
- PASS_BUF_TOTAL_OFF = 0x66e
- PAGE_SIZE = 0xf = 15
- TILEMAP_W = 0x1b = 27
- TILEMAP_H = 0x15 = 21
