# Naming Proposal: 0x08080d84

## 提案
- **proposed_name**: read_effect_slot_zone_type
- **confidence**: high

## plate comment (中文, ASCII 标点)
从 effect_node 的 slot 数组条目提取 zone_type 字段 (bits[13:5], 9-bit): addr = r0 + r1*2 + 8; ldr word; lsls #18; lsrs #23 = 提取 bits[13:5] (9 bits, 表示 zone 类型, 有效范围 [0..10]).

与同区域兄弟 read_effect_slot_side_and_type (0x08080d6c) 并列: 后者提取 bit0=side 和 bits[4:1]=type_nibble; 本函数提取更高位的 zone_type.

调用场景: 高频使用 (25+ callers), 覆盖全部 duel_field 模块. 调用方用结果作为 zone 查表索引 (x4 乘法后进 ROM 表).

副作用: 无外部写.

Constants: SLOT_ARRAY_BASE_OFFSET=8, SLOT_STRIDE=2, ZONE_TYPE_SHIFT=5, ZONE_TYPE_WIDTH=9 (bits[13:5]).

## 参数签名
- r0: effect_node* ptr  effect node 基址指针
- r1: u8 slot_index  slot 索引 [0..N-1], 其中 N = [r0+4].bits[17:15]
- 返回: r0 = u32 zone_type (bits[13:5] of slot entry, 范围 [0..10])

## 副作用
- 无
