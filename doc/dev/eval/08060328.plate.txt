Equip slot eligibility predicate. Neo Daedalus special-path branch.
Checks slot_ptr[+2] bits[10:4] (zone_type mask 0xfc0) against 0x3c0 (0xf0<<2).
If zone_type == 0x3c0 -> return 1 immediately (fast-pass path).
Else call check_neo_daedalus_lp_count_eligible(slot_ptr, r1_arg) and return its result.
Pure predicate, no external writes.

Constants:
  0xfc0 (0xfc<<4): zone_type mask bits[10:4]
  0x3c0 (0xf0<<2): zone_type target value (fast-pass)

Inputs: r0=SlotPtr* slot_ptr (ldrh[+2] bits[10:4]=zone_type), r1=u32 arg1 (forwarded)
Returns: r0 u32 (1=pass, 0=fail)
Callees: check_neo_daedalus_lp_count_eligible
