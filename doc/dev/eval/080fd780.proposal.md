title_ex 场景全批次 cell 动画槽帧驱动器.
r0 为原始动画参数, 以 0xb 除后得到上界 r7 = r0 / 11.

循环 r5=0..19 (20 次): 若 r5 <= r7 则以 slot_idx=r5, r1=-1, r2/r3 从表中读取,
调用 tick_title_ex_cell_anim_slot; 否则跳过.
退出: pop{r4,r5,r6,r7}; pop{r0}; bx r0 (Pattern B void).
Constants:
  CELL_ANIM_TABLE = 0x09e50777 (ROM 槽配置表, 0x28 字节)
  BATCH_SIZE = 20 (最大槽数 r5=0..19)
