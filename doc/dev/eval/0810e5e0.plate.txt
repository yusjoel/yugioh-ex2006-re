Single-instruction function pointer trampoline: executes bx r6 to jump to the target function held in r6. r6 is a non-APCS callee-save register; caller sets it via non-standard means (direct write or callee-save passing). indeg=1; sole caller is 0x080b70ac (select_equip_target_slot_by_card_id, tags: card_ids;duel_field) which uses r6 as a predicate function pointer during equip target selection. Part of the invoke_rN sibling family.
