## plate comment (中文, ASCII 标点)
Shuen/SHU_main.c 模块中单个 demo 精灵 cell 动画的逐帧推进函数. r0=anmID (动画序列索引 [0..10]), r1=playback_step (播放步数, -1 表示自动推进), r2/r3=屏幕坐标 (12.0 定点, lsls #0xC 移位). 首先通过 read_obj_id_field 验证 anmID 合法性, 超界则 suppress_assert_report 抑制报错 (assert: anmID < IG2D_GetAnmSequencesCount). 合法时: 当 playback_step==-1 时调用 dispatch_cell_anim_frame_advance 推进一帧, 通过 get_title_ex_obj_field8 检测动画是否完成; 若尚未完成则按 r5-5 是否在 [0..10] 范围选择序列步长 (r1=1 或 2), 调用 dispatch_cell_anim_sequence_step 跳到下一序列; 若 playback_step!=-1 则直接以 r6 低 16 位为步长调用 dispatch_cell_anim_sequence_step. 最终调用 dispatch_isd_cell_anim_oam_setup 提交 OAM 属性. 由 tick_demo_shuen_anim_slots 批量驱动. Constants: STEP_AUTO=-1(0xFFFFFFFF) / DEFAULT_STEP=1 / FAST_STEP=2 / SEQ_RANGE_MAX=0xA(10).

## 参数签名
- r0: u8 anm_id -- 动画序列索引 [0..10] (IG2D 内部序列编号; 由 read_obj_id_field 验证上界)
- r1: s32 playback_step -- 播放控制 (-1=自动帧推进模式; >=0=指定序列步长)
- r2: s32 screen_x_fp12 -- 屏幕 X 坐标 (12-bit 定点数; lsls #0xC 移位后存入 OAM 参数)
- r3: s32 screen_y_fp12 -- 屏幕 Y 坐标 (12-bit 定点数; lsls #0xC 移位后存入 OAM 参数)
- 返回: r0 = void (无返回值; bx r0 返回调用方 lr)

## 副作用
- [gDemoState+0x8+anm_id*4] OBJ cell anim 控制结构帧指针推进 (dispatch_cell_anim_frame_advance 内部)
- OBJ VRAM / OAM: dispatch_isd_cell_anim_oam_setup 提交 OAM attr0/1/2 及精灵 XY 坐标
