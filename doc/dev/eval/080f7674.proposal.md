# Naming Proposal: 0x080f7674

## 提案
- **proposed_name**: reset_display_and_obj_vram
- **confidence**: high

## plate comment (中文)
读取 DISPCNT (0x04000000) 当前视频模式 (bits 2:0)，将 OBJ PALRAM (0x05000200, 0x200 字节) 清零，再按模式分支清零对应的 VRAM OBJ tile 区域 (mode 0/1/2: 0x06010000 起 0x8000 字节；mode 3/4/5: 0x06014000 起 0x4000 字节)；若 r5 (r0 输入) 不为 0 则将其写入 gPrng+0x1bc (OBJ 列表指针槽)；最后调用 init_scene_obj_list (FUN_080f5ef4) 重建空 OBJ 列表。indeg=22，由 card_info_page_init_bg0 及多个 bg/vram/display/palette 场景初始化链在页面切换时调用，是显示状态完全重置的标准入口。

## 参数签名
- r0: ptr obj_list_base_or_zero  若不为 0，写入 gPrng+0x1bc 作为 OBJ 列表基址指针；为 0 时跳过写入
- 返回: void (无返回值，仅副作用)

## 副作用
- [OBJ PALRAM 0x05000200 .. 0x050003FF] := 0 (0x200 字节调色板清零，via zero_fill_halfword_wrapper)
- 若 DISPCNT bits[2:0] in {0,1,2}: [VRAM 0x06010000 .. 0x06017FFF] := 0 (0x8000 字节 OBJ tile 区清零)
- 若 DISPCNT bits[2:0] in {3,4}: [VRAM 0x06014000 .. 0x06017FFF] := 0 (0x4000 字节清零)
- 若 DISPCNT bits[2:0] == 5: [VRAM 0x06014000 .. 0x06017FFF] := 0 (0x4000 字节清零)
- 若 DISPCNT bits[2:0] > 5: default 分支 (无额外 VRAM 清零)
- 若 r0 != 0: [gPrng+0x1bc (0x030001fc)] := r0 (OBJ 列表基址指针更新)
- OBJ 列表全部 128 条目清零 + capacity/count 重置 (via init_scene_obj_list)
