# Naming Proposal: 0x08017478

## 提案
- **proposed_name**: unpack_bits_to_byte_buf
- **confidence**: med

## plate comment (中文, ASCII 标点)
Function: 从紧凑位域表格中提取像素/字节值并写入输出缓冲区. 输入参数包含源数据表基址 (r9:=r0, prologue 内部赋值)、输出字节缓冲区 (r7:=r1)、条目数 (r4:=r2) 和位步长 (r3 -> compute_floor_log2 -> log2 步进). 以步长 r3 遍历位域表, 对每个偏移位置提取一个字节值写入 [r7++]. 循环结束后再做一次最终 __divsi3 处理并返回商值. r8 为函数内部工作寄存器 (prologue 内 mov r8,r1 赋值, 来自 r3-1, 非 APCS 输入).
Trigger: 由 FUN_0801722c (字符帧解码管线) 在帧解压阶段调用, 将字体/字符数据从紧凑位域格式还原为逐字节格式.
Side effects: 写入 [r7..r7+count-1] 共 count 个字节 (output buffer).

Constants:
- BITS_MASK=0xf (低 4 位掩码, 用于从位域中提取半字节)

## 参数签名
- r0: u8* src_table_base 源位域数据表基址
- r1: u8* dst_buf 输出字节缓冲区
- r2: s32 entry_count 要提取的条目数 [>=0]
- r3: s32 bit_stride 位步长 (传入 compute_floor_log2 获得 log2 值)
- 返回: r0 = s32 最终 __divsi3(pos, log2_stride) 的商

## 副作用
- [r1..r1+entry_count-1]: 写入解包后的字节值 (位域提取结果)
