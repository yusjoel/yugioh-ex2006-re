Checks slot_ptr[+0x14] nonzero.
Reads gDuelEffectCtx (0x0201bb90): confirms ctx[0] == opponent (1-player_id).
Reads ctx[+0x1c] zone_idx, computes gDuelFieldSlots offset, extracts card_id (low 13 bits
via lsls#0x13; lsrs#0x13). If card_id nonzero, calls check_card_has_equip_placement_type
and check_card_field8_is_9; either nonzero -> return 0 (special equip restriction).
Finally checks slot descriptor bit11 (lsls#0x11 -> bit31 sign) is negative -> return 1; else 0.
