# Naming Proposal: 0x080dd2d0

## 提案
- **proposed_name**: apply_overlay_bg_scroll_offset
- **confidence**: high

## plate comment (中文, ASCII 标点)
为遮罩 overlay 对象设置 BG 水平/垂直滚动寄存器偏移量.
入参 r0=scroll_x, r1=scroll_y;
从 gPrng+0x1d0 取 overlay ptr, 读取 overlay [+0x3]flags 中的 BG 索引字段 bits[7:6],
计算对应 BGxHOFS/BGxVOFS 寄存器偏移 (+0..+6), 写入计算后的 scroll 值;
同时从 BGxCNT 读取 tile/map base, 并写回修改后的 BGxCNT 值, 置 DISPCNT 对应 BG bit.
被 FUN_080dd748 (BG mode != 0 时) 调用.

Constants:
- gPrng+0x1d0: overlay struct ptr
- BG0HOFS (0x04000010): BG0 水平滚动
- BG0VOFS (0x04000012): BG0 垂直滚动
- BG0CNT (0x04000008): BG0 控制
- DISPCNT (0x04000000): 显示控制
- 0x0000fffc: DAT_080dd374 = BGxCNT mask (清 tile base bits)

## 参数签名
- r0: s16 scroll_x 水平偏移 (signed 16-bit)
- r1: s16 scroll_y 垂直偏移 (signed 16-bit)
- 返回: void (pop {r0}; bx r0 透传 lr)

## 副作用
- [BG0HOFS + BG_idx*4]: := scroll_x_adjusted
- [BG0VOFS + BG_idx*4]: := scroll_y_adjusted
- [BG0CNT + BG_idx*2]: |= tile_base_bits (写回修改后的 BGxCNT)
- [DISPCNT 0x04000000]: |= (1 << (BG_idx + 8)) (开启对应 BG 层显示)
