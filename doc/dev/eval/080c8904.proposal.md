## plate comment (中文, ASCII 标点)
对 duel_field 所有 zone slot 循环刷新 tile 显示状态, 对应 dispatch_card_display_op case 0x24 的最终子步骤 (在 refresh_duel_field_zone_info + refresh_zone_effect_buff_cache + build_slot_activation_mask_for_player 之后调用). 函数遍历两个 player (r8 outer loop), 内层对 slot_type [0..4] 调用 get_zone_slot_entity_ref_by_type; 若返回 null 则调用 update_field_slot_tile_display(player, slot, 0). 再对 slot_type [5..10] 再次遍历同样逻辑. 数据来自 gDuelZoneDisplay (0x02023130), 槽类型上限 type=10 (0x0a). Constants: gDuelZoneDisplay=0x02023130, slot_type_lo=[0..4], slot_type_hi=[5..10], gDuelActivation_entry=0x0000021e (per-player zone ctrl stride).

## 副作用
- [VRAM/OAM]: 间接写入, 通过 update_field_slot_tile_display 完成每 slot 的 tile 刷新
- gDuelZoneDisplay (0x02023130): 读取 slot 条目以查询 zone 实体
