Puzzle scene state initialization entry function. Called by FUN_080f473c (tags: [puzzle,scene_init]). Calls zero_fill_by_halfword(0x02000000, 0x6ed0) to zero EWRAM low 0x6ed0 bytes. Checks ROM 0x080000ae language byte high byte; if 0x4a ('J') calls write_puzzle_charset_flag(0), else flag(1). Sequentially calls init_starter_deck_display_state/rebuild_all_challenge_unlock_flags/init_puzzle_cursor_state to init three sub-systems. Side-effects: EWRAM 0x02006c38 := 0xbb8, 0x02006e5c := 7. Returns void (Pattern B: pop{r0};bx r0).
