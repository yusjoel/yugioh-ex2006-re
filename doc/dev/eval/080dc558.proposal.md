## plate comment (中文, ASCII 标点)
清零包店 BG tile VRAM 中两个相邻槽的 OBJ 行缓冲区, 然后将标签文字渲染到 BG tile VRAM. 触发条件: 被 11 个 caller 在包店各子场景(banner/info/list)初始化时调用, 传入 r0=bg_tile_dest(BG tile VRAM 目标), r1=text_str_ptr(文字字符串指针, 可为 NULL). 函数先对 r0 和 r0+0x400 两个槽各调用 zero_fill_halfword_wrapper(r1=0x1a0 halfword); 若 r1==0 跳过文字渲染; 否则 setup_line_buf_pos_and_font + 设置 font ctx + measure_string_pixel_width + text_render_wrapper + write_line_buf_to_bg_tile_vram 渲染标签.

Constants:
- FILL_COUNT = 0xd0<<1 = 0x1a0 halfword (每槽清零量)
- SLOT_STRIDE = 0x80<<3 = 0x400 (两槽间距)
- FONT_CTX = 0x02006ed0
- X_CENTER_BASE = 0x68 (用于计算居中偏移 (0x68-width)/2)
- RENDER_ATTR = 0x107 (text render color attr)
