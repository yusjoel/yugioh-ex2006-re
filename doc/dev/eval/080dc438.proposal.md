## plate comment (中文, ASCII 标点)
将包店卡牌组(3 张)的 tile 数据批量从 ROM 复制到 OBJ VRAM, 并视需要复制调色板. 触发条件: 唯一 caller pack_list_page_init (0x080d971c) 在列表页初始化时调用, r0=指向 3 个 OBJ attr halfword 的数组首地址, r1=sprite_col_index(调色板/VRAM slot 基址). 函数循环 3 次(r5 0..2): 每次从 [r0] 读出 16 bit attr, *0x20 作 VRAM 偏移, 从 [0x09ce822c+0x14](tile ptr 第四字段) + r5*0x80 取 ROM tile ptr, 调用 tile_2d_row_copy(2x2); 循环结束后若 r6<=0xf 将 [0x09ce824c+0x14] 调色板 DMA 到 0x05000200+r6*0x20.

Constants:
- ROM_TILE_TABLE = 0x09ce822c (偏移 +0x14 = 第四字段)
- ROM_PAL_TABLE = 0x09ce824c (偏移 +0x14)
- OBJ_VRAM_BASE = 0x06010000
- OBJ_PAL_BASE = 0x05000200
- CARD_COUNT = 3 (循环上界 cmp r5,#2 bls -> [0..2])
- TILE_SLOT_STRIDE = 0x80 (每卡 tile slot 间隔)
- TILE_COPY_COLS = 2; TILE_COPY_ROWS = 2
- PAL_LIMIT = 0xf

## 参数签名
- r0: u16* attr_array (指向 3 个 OBJ tile attr halfword 的数组)
- r1: u8 sprite_col_index [0..0xf] (OBJ palette slot 索引; >0xf 跳过调色板)
- 返回: void (pop {r0}; bx r0)

## 副作用
- [0x06010000+attr[i]*0x20..]: 写 3 张卡 tile 数据 (via tile_2d_row_copy x3)
- [0x05000200+r1*0x20..+0x20]: 写调色板 (via copy_memory_dma3_with_cpu_fallback, 仅 r1<=0xf)
