## plate comment (中文, ASCII 标点)
装备槽白名单 + 区域位图联合验证谓词. 被装备目标选择链调用, 目的是确认目标怪兽槽位满足特定装备卡的白名单资格并且位图槽尚未被分配. 执行流: (1) 若 slot_idx <= 4, 先调用 check_slot_card_is_equip_whitelist(player_id, slot_idx) 检查白名单; 不通过则直接失败; (2) 区域表 is_present 位检测 (lsls r0,r0,#0x13); (3) 读取 card_entry[+8 + player_id*2] 的 u16 位图字, 用 asrs r0,r4 (slot_idx 位) 再 ands r0,r3 (#1) 提取该 bit; bit!=0 表示该槽已占用, 返回 0; (4) 调用 check_card_equip_eligible_for_slot(r3=0) 最终确认兼容性; 所有条件通过则返回 1.

Inputs: r0 = ptr equip_card_entry, r1 = player_id [0..1], r2 = slot_idx [0..4]
Outputs: r0 = 1 if whitelist pass + zone present + bitmap bit clear + type eligible, 0 otherwise
Side effects: none
Constants: SLOT_MAX=4, PLAYER_BLOCK=0x868, ZONE_BASE=0x0201c510, SLOT_STRIDE=20, BITMAP_WORD_OFFSET=+8
