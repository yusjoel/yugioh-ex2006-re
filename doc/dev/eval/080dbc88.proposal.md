## plate comment (中文, ASCII 标点)
向 OBJ VRAM 写入卡包图形的连续 tile 索引条带. 参数 r0=dst_ptr, r1=start_tile, r2=palette_flags, r3/high=row_base 等. 将 r2 左移 0xc 位得 OBJ palette bank 域 (r6). 对 r0 取模 0x30=48 得列偏移. 外层循环 2 次 (2 条 strip), 内层循环 0x20 次 (32 个 tile), 每次写 strh 到 [r4,#0], 递增 tile 号并在到达行末(=next_row_base)时回绕到同行起始. 被 pack banner 和 pack detail VRAM 填充路径调用.

Constants:
- STRIP_TILES=0x20 // 每条 strip 32 个 tile
- ROW_WIDTH=0x30 // 48: tile 行宽 (OBJ VRAM 64x64 tile 模式)
- PAL_SHIFT=0xc // r6 = r2<<0xc: OBJ attr2 palette bank 域

## 参数签名
- r0: ptr dst_vram [VRAM OBJ 地址, 按 2 字节对齐] (入口 adds r4,r0,#0; .hword 0x464f=mov r7,r9 epilogue)
- r1: u16 start_tile [0..246] (入口 .hword 0x4688=mov r8,r1; bios_div_remainder(r0,0x30) 计算列; callsite 传入值: 0/0x12/0xf6)
- r2: u8 palette_flags [0..15] (入口 lsls r2,r2,#0x1c -> r6=r2<<0xc as OBJ attr2 palette bank 4 位; GBA OBJ palette bank [0..15])
- r3: u16 tile_row_base_offset [0..0] (入口 .hword 0x4699=mov r9,r3; r9 用于 add r0,r9 tile 行基址偏移; 所有已知 callsite 均传入 0)
- 返回: r0 = void (pop{r0}; bx r0)

## 副作用
