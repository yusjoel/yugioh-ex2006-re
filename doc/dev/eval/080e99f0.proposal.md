# Naming Proposal: 0x080e99f0

## 提案
- **proposed_name**: check_vram_size_for_type
- **confidence**: high

## plate comment (中文, ASCII 标点)
来自 nnsys/g2d/g2d_Image.c 的 VRAM 大小范围验证函数. 由 load_img_proxy_to_vram (0x080e9de8) 调用, 根据 VRAM 类型 type 确定最大容量上界, 检查 offset 是否在该范围内. type==0/1 对应 2D MAIN/SUB (OBJ VRAM = 0xC0<<14 = 0x300000 = 192KB); type==2 对应 3D (0x80<<14 = 0x200000 = 128KB). 对 offset 做 subs r1,r1,#0x10 的偏置后比较, 返回 1 (合法) 或 0 (越界).

Constants: VRAM_2D_SIZE=0x300000 (0xC0<<14) / VRAM_3D_SIZE=0x200000 (0x80<<14).

## 参数签名
- r0: u32 type -- VRAM 类型 [0..2] (0=3D_MAIN, 1=2D_MAIN, 2=2D_SUB 含义由调用上下文决定)
- r1: u32 offset -- 待验证的偏移量 (字节, 含 -0x10 偏置)
- 返回: r0 = u32 -- 1 若 offset 在范围内, 0 若越界

## 副作用
- 无写操作, 纯计算

## 行级注释 (<=30 行精华)
- @ 080e99f0: type <= 1 -> 跳 LAB_080e99fc (2D 路径)
- @ 080e99f4: type == 2 -> 跳 LAB_080e9a06 (3D 路径)
