# Naming Proposal: 0x0805ec00

## 提案
- **proposed_name**: check_dark_magician_effect_zone_available
- **confidence**: high

## plate comment (中文, ASCII 标点)
激活判定谓词. 入参为卡槽指针 r0. 提取 player_id (flags +0x2 bit0).
以 card_id=0x0fc9 (Dark Magician) 和 sentinel=-1 (rsbs r5,r5,#0 将 1 取反为 -1) 为参数,
调用 count_available_effect_zones; 若返回值 > 0 则直接返回 1.
否则以 card_id=0x142d (Dark Magician icid) 再次调用 count_available_effect_zones;
若返回值 > 0 则返回 1, 否则返回 0.
sentinel=-1 表示在所有区范围内计数而不限定特定区索引.
出口为 pop{r4,r5}; pop{r1}; bx r1.

Inputs: r0 = card_slot_ptr (卡槽指针)
Outputs: r0 = 1 (Dark Magician 或其 icid 的效果区数量 > 0) / 0 (均无)
Side effects: 无外部写入.
Constants: CARD_ID_DARK_MAGICIAN=0x0fc9, CARD_ID_DARK_MAGICIAN_ICID=0x142d, SENTINEL_ALL_ZONES=-1 (rsbs r5,#1,#0)

## 参数签名
- r0: card_slot_ptr* 场地卡槽指针; 读取 +0x2(flags byte, bit0=player_id)
- 返回: r0 = u8 1(至少一个效果区可用) / 0(无)
