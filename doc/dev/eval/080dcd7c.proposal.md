## plate comment (中文, ASCII 标点)
FUN_080dcb54 的变体: 将遮罩对话框 BG tile 数据写入另一组 VRAM 地址.
从 gPrng+0x1d0 取 overlay 对象指针; 若为 NULL 直接返回;
以固定偏移 0x06010000/0x06010020/0x06010040 为目标, 复制多块 0x20 字节 tile 行,
随后继续复制后续 tile 行.
由 text_overlay_create (BG mode=0 时走此分支) 和 FUN_080dd464 调用.

Constants:
- gPrng+0x1d0: overlay struct ptr
- 0x09cede5c: overlay tile 源数据表 (ROM)
- 0x06010000: VRAM OBJ tile slot 0 (32 bytes)
- 0x06010020: VRAM OBJ tile slot 1 (32 bytes)
- 0x06010040: VRAM OBJ tile slot 2 (32 bytes)

## 参数签名
- r0: (入口第一条指令 `push {r4-r7,lr}` + `.hword 0x4682=mov r10,r0` -> r0 存入 r10 作 callee-save, r0 来自 caller 上文) u32 packed_size, 同 load_overlay_bg_tiles_to_vram
- 返回: void (pop {r0}; bx r0 透传 lr)

## 副作用
- [0x06010000..0x0601xxxx]: 多个 0x20 字节 DMA 写入 (OBJ VRAM tile area)
