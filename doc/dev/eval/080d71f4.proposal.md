## plate comment (中文, ASCII 标点)
向 OAM 影子写入 pack 卡牌 sprite 属性, 根据 r2 (affine_param) 分派到不同的写入路径. 从 packed_xy (r0 高16=y_raw, 低16=x_raw) 提取坐标并分别减去偏移 (x-=0x10, y-=0x20) 以对齐卡牌精灵基准点. 入口 `adds r3,r2,#0` 将 r2 转存到 r3 后参与 cmp. 若 r2==0x100 (OAM_AFFINE_BIT 未置位标准模式): 调用 write_oam_entry_with_tile_inc(packed_xy_adj, r1, OAM_BASE). 否则 (旋转缩放模式, r2 含旋转参数): 将 r3 左移 0x10 传入 write_pack_obj_attr_by_dir_stacked.

Constants:
- X_ADJUST = 0x10 (x 坐标减去的基准偏移, 16 px)
- Y_ADJUST = 0x20 (y 坐标减去的基准偏移, 32 px)
- OAM_AFFINE_BIT = 0x100 (OAM_ROT_SCALE_FLAG; movs r0,#0x80;lsls r0,r0,#1=0x100; r2==0x100 -> 标准非仿射路径)
- OAM_BASE = 0x000080c0 (pack OAM 影子基址)
