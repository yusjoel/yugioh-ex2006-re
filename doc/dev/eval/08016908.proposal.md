# Naming Proposal: 0x08016908

## 提案
- **proposed_name**: fill_vram_screen_rect_zero
- **confidence**: high

## plate comment (中文, ASCII 标点)

Function: 在 VRAM screen map 中以零填充一个矩形区域 (清空 tile 索引).
以 dest = base_ptr + row_idx*64 + col_idx*2 为起始行地址,
循环 row_count 次调用 bios_cpu_set (FILL 模式, fill_value=0) 每次填充 words_per_row 个字,
每次循环目标地址向下推进 0x40 字节 (= 32 halfwords = 一行 32 个 tile 的标准 GBA screen row).
indeg=0; VRAM screen map 矩形清零工具.

Side effects:
- [base_ptr + row_idx*64 + col_idx*2 + row_i*64 .. +words_per_row*4] := 0 (对每个 i in [0..row_count-1])

Constants:
- SCREEN_ROW_STRIDE = 0x40 (64 bytes = 32 halfwords per BG screen row)
- BIOS_CPUSET_FILL_BIT = 0x1000000 (bit24=1: fill mode)
- WORD_COUNT_MASK = 0x001fffff ([r3] & 0x001fffff = bios_cpu_set word count 字段)
- FILL_VALUE = 0 (strh 0 写至栈作为 bios_cpu_set fill 源)

## 参数签名
- r0: void* base_ptr (VRAM screen map 基址, 如 0x06000000 或 get_bgN_screen_vram_addr 结果)
- r1: u8 col_idx (列索引 [0..31], 单位 tile = 2 字节)
- r2: u16 row_idx (行索引 [0..31], 单位行 = 64 字节)
- r3: u32 words_per_row (每行填充的 32-bit 字数 [1..0x1fffff])
- [sp+0x20]: s32 row_count (行数, <= 0 时跳过整个循环)
- 返回: void (pop {r0}; bx r0 = Sub-case E)

## 副作用
- [base_ptr + row_idx*64 + col_idx*2 + i*64 .. +words_per_row*4] := 0 (i=0..row_count-1)
