# Naming Proposal: 0x080c0274

## 提案
- **proposed_name**: write_nibble_sequence_to_bg_tiles
- **confidence**: med

## plate comment (中文, ASCII 标点)
从 packed nibble 字节数组 (r2) 中逐字节读取双 nibble, 对每个非零 nibble (低 nibble 或高 nibble) 调用 write_nibble_to_bg_tile_cell 写入对应 BG tile VRAM 坐标. 外层循环遍历 8 个字符槽 (r7: 0..7), 内层循环遍历 nibble 序列 (r8, 步进 -1 直到 < 0), 坐标由 (r4=tile_x 偶, r5=tile_x 奇) 和 r1 (tile_y) 驱动. 被 FUN_080c0310 和 FUN_080c05b4 调用, 用于将卡图 nibble 序列写入 BG tile 区域.

Constants:
- OUTER_LOOP_COUNT = 8 (r7: 0..7, cmp r7,#7 ble)
- NIBBLE_LOW_MASK = 0x0f (低 nibble)
- NIBBLE_HIGH_MASK = 0xf0 (高 nibble)
- NIBBLE_HIGH_SHIFT = 4 (lsrs r0,r0,#0x1c 等价 >>4 after <<0x18)

## 参数签名
- r0: u32 packed_tile_x -- 打包的 tile 列坐标, lo16 = tile_x_even [6..80], hi16 = inner_row_base [5..6]. Callsite FUN_080c0310 @ 080c0342 传 0x00060006 (tile_x_even=6, inner_base=6); FUN_080c05b4 @ 080c0702 传 0x00050050 (tile_x_even=80, inner_base=5). 函数内: lo16 -> sp[4] (tile_x_even), hi16 -> r10 (用于内层 tile_y 计算).
- r1: u16 vram_row_param [470..516] -- 传给 write_nibble_to_bg_tile_cell 的 vram_row_base 参数 (u16 截断后存 sp[0]). Callsite FUN_080c0310 传 0x1d6=470 (0xeb<<1); FUN_080c05b4 传 0x204=516 (0x81<<2). 观测范围 [470..516].
- r2: u8* nibble_data_ptr -- packed nibble 字节数组指针 (每字节含 2 个 nibble)
- r3: u8 palette_base [0..15] -- 调色板基址 nibble (与 nibble 值 OR 合并作为 palette_nibble)
- 返回: void (pop 序列+bx)

## 副作用
- [VRAM 0x06010000 + computed]: 通过 write_nibble_to_bg_tile_cell 批量写入 nibble 到 BG tile VRAM

- L4 结构: 8 槽外层 + nibble 双路内层循环 = 标准 GBA nibble 序列写 BG tile 模式
- L5 调用方: FUN_080c05b4 含 card_image/card_stats/font_jp, 语义一致

R3 prologue callee-save 扫描:
- .hword 0x4657 = mov r7,r7 = nop, .hword 0x464e = nop, .hword 0x4645 = nop (对齐)

结论: r0/r1/r2/r3 为真实 APCS 输入; r4-r10 均为 callee-save 别名.
