Function: Equip slot eligibility check combining whitelist filter and setcode type match. If slot_idx [0..4] in range, first calls check_slot_card_is_equip_whitelist; whitelist hit skips setcode check and proceeds directly to prereqs. Otherwise reads zone slot data: checks chain_field nonzero, then extracts zone setcode field (bits[21:14] <<1 + bit[13]) and equip card [+0x4] setcode field (bits[14:7] <<1); different setcodes proceed to prereqs. Finally calls check_zone_slot_equip_prerequisites. Returns 1 if all pass.

Params: r0=u8* card_ptr (equip card; [+0x4] ldrh=card setcode word); r1=u8 owner_bit [0..1]; r2=u8 slot_idx [0..4]
Returns: r0=u32 eligible (0=ineligible, 1=eligible)
Side effects: none (pure query)
Constants: SLOT_IDX_MAX=4, ZONE_BASE=0x0201c510, STRIDE=0x868
