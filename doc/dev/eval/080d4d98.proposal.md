将卡包名称渲染到 OBJ sprite VRAM 行中. 调用方在卡包 UI 初始化或刷新时传入 r0=pack_name_ptr (卡包名称字符串指针), r1=player_idx (0/1 决定渲染目标行). 流程: 计算 OBJ VRAM 基址 (0xc0<<0x13 + row_offset*0x20); 调用 zero_fill_pack_obj_vram_region 清空目标区域; 调用 pack_name_text_render 渲染名称文字返回瓦片写入计数; 将计数写入 pack_ui_state+0xc+0x10/0x12; 最后调用 write_pack_obj_tile_strip 写入瓦片条.

Constants:
- OBJ_VRAM_BASE = 0xc0 << 0x13 = 0x6000000 (movs r4,#0xc0; lsls #0x13)
- ROW_STRIDE = 0x20 (lsls r5,r5,#5 -> row_offset * 32)
- pack_ui_state = 0x03005850 (DAT_080d4ddc)
- TILE_OBJ_BASE = 0x0600e000

## 参数签名

- r1: u32 player_idx [0..1] (0 = row 0, 1 = row 0xf6 -> same base)
- 返回: void (pop{r0};bx r0 Pattern B)

## 副作用

- [pack_ui_state+0xc+0x12] := 0
