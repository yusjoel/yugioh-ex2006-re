# Naming Proposal: 0x08014eb4

## 提案
- **proposed_name**: find_substr_offset
- **confidence**: high

## plate comment (中文)
由 `fs_load` 在 GL 文件系统路径解析阶段调用，依次以 `#`、`!`、`.LZ` 三种前缀魔数作为 pKey 探测 pSrc 路径字符串，从而判断文件名是否携带特定标记。函数实现朴素线性 strstr 搜索：先用两次 `measure_str_bytelen` 确定有效搜索窗口（`len_pSrc - len_pKey + 1`），再逐偏移比对，首字节匹配后继续全长比对，成功返回首次命中的字节偏移（≥0），未命中返回 -1。源文件归属 `GL/GL_File.c`（assert 字符串泄漏锚）。

## 参数签名
- r0: `const char *` pSrc — 被搜索的源字符串（haystack）；assert pSrc != NULL（GL/GL_File.c:38）
- r1: `const char *` pKey — 要查找的子串（needle）；assert pKey != NULL（GL/GL_File.c:39）
- 返回: r0 = `s32` byte_offset — pKey 在 pSrc 中首次出现的字节偏移（0-based），若未找到则返回 -1（`rsbs r0,r0,#0` 后得 0-1 = -1）

## 副作用
无外部副作用。纯只读查询，仅修改寄存器/本地栈。
