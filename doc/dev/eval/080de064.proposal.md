# Naming Proposal: 0x080de064

## 提案
- **proposed_name**: encode_pack_slot_oam_attr
- **confidence**: high

## plate comment (中文, ASCII 标点)
将牌包槽索引 (0-7) 编码为 OAM attr 打包值.
r0 = slot_index [0..7], 超范围截断到 7;
计算 y 坐标: slot_index << 0x14 + 0xe400000 -> 高位提取后得屏幕 y;
计算 x 坐标: 固定基准 0xc0<<0xe = 0x0300000;
返回 r0 = (x_attr << 16) | y_attr 打包 OAM 属性对.
被多个 scene_pack 渲染函数用于确定各牌包槽 OAM sprite 的 x/y 属性.

Constants:
- 0x7: slot_index 上限 (clamp to 7)
- 0xe4<<0xe = 0x0390000: OAM y base offset
- 0xc0<<0xe = 0x0300000: OAM x base (固定)

## 参数签名
- r0: u8 slot_index 牌包槽索引 [0..7] (超范围截断到 7)
- 返回: r0 = u32 packed_oam_attrs = (x_attr << 16) | y_attr
