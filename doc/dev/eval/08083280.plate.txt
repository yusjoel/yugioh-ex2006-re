Equip slot display state machine advance function. Reads display_state_code from gDuelCtx+0x4b0, dispatches on [0,1,2,3]: state=0: clear card_slot[+4] flags (mask 0xfffc7fff) and card_slot[+6] bits, trigger op=0x91 display op; state=1: if card id in special set (0x1368/0x1568/0x15de/0x16d3/0x1803 -- all reserved slots, no card assigned), call init_effect_slot_display_context with op_code 0x4a/0x4b/0x4c; state=2: read LP animation data pointer from gP1LifePoints+0x4d0, call LP helper if [ptr+player_idx*4+8]==1; state=3: if activation display state confirmed, read gP1LifePoints+0x1d68/0x1d6c/0x1d70 sum fields, call enqueue_equip_slot_sprite_with_code_rotation. Advances [gDuelCtx+0x4b0]++. Returns r0=0 (processed) or 1 (state mismatch, skipped).
Side effects: [card_slot_ptr+4] &= 0xfffc7fff; [card_slot_ptr+6] bits cleared; [gDuelCtx+0x4b0] := old+1 or old-1.
Constants: DUEL_CTX=0x0201b290, display_state_off=0x4b0 (0x96<<3), MASK_CARD_FLAGS=0xfffc7fff, CARD_ID_1=0x1368 (reserved -- cid=0x1368, no card assigned), CARD_ID_2=0x1568 (reserved -- cid=0x1568, no card assigned), CARD_ID_3=0x15de (reserved -- cid=0x15de, no card assigned), CARD_ID_4=0x16d3 (reserved -- cid=0x16d3, no card assigned), CARD_ID_5=0x1803 (reserved -- cid=0x1803, no card assigned).
