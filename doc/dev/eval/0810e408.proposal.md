# Naming Proposal: 0x0810e408

## 提案
- **proposed_name**: check_bios_checksum_parity
- **confidence**: high

## plate comment (中文, ASCII 标点)
调用 BIOS SVC 0xd (BiosCheckSum), 从返回值减去官方 GBA BIOS 校验常量 0xbaae187f, 再 AND 0x1 取 bit0 奇偶. 若 BIOS 完整且未修改, 返回 0; 否则返回 1. 用于运行时验证 BIOS 完整性. 由 FUN_080f4c14 (dma;sys;display 区域) 在 DMA / 显示系统初始化时调用.

Constants:
- BIOS_CHECKSUM_SVC=SVC 0xd (BiosCheckSum)
- OFFICIAL_CRC=0xbaae187f (官方 GBA BIOS 校验常量)
- PARITY_MASK=0x1 (bit0 奇偶掩码)

## 参数签名
- 无 APCS 参数 (入口无 push; SVC 0xd 自行读 BIOS)
- 返回: r0 = u32 parity_bit [0..1] (0=BIOS 校验通过, 1=BIOS 已修改或非官方)

## 副作用
- 无外部地址写入
