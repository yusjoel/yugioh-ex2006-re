check_equip_slot_eligible_by_opposite_field8_or_field6_and_type
Equip slot eligibility predicate requiring opposite side + ([+8] or [+6] at least one nonzero) + type compatible.
Caller: query_slot_card_type_eligibility (0x0803670c) during cross-side equip target selection.
Checks in order: (1) compute gDuelFieldSlots[player_id&1][slot_idx] slot address;
(2) card_icid != 0 (occupied) AND slot_idx <= 4;
(3) equip_slot[+2]bit0 = equip side; require player_id == 1 - equip_side (opposite side check);
(4) card_icid (bits[18:0]) != 0; (5) [slot+8] != 0 OR [slot+6] != 0 (if [+8]==0 requires [+6]!=0);
(6) query_slot_card_type_eligibility == 0.
Returns 1 if all pass. Pure predicate, no external writes.
Constants: SLOT_IDX_MAX=4, gDuelFieldSlots=0x0201c510, player_stride=0x868
Inputs: r0=ptr equip_card_slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..4]
Returns: r0=u32 bool (1=eligible, 0=rejected)
