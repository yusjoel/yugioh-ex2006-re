# Naming Proposal: 0x080f6ccc

## 提案
- **proposed_name**: write_pack_obj_attr_by_dir_stacked
- **confidence**: med

## plate comment (中文, ASCII 标点)
根据方向码调整坐标并写入 OBJ sprite OAM 属性 (pack 场景, r3 双 16-bit 均入栈变体).
与 write_pack_obj_attr_by_dir (0x080f6adc) / write_pack_obj_attr_by_dir_split (0x080f68ec) 三函数对称结构.
本变体特点: sub sp,#0x8 (额外 8 字节栈帧, 其他变体为 4 字节); r3 的高低 16 位分别保存到
sp+0 和 sp+4 (两个独立栈参数槽): r3[31:16]=affine_ctrl (0x8000|counter*8), r3[15:0]=scale_ramp [0..0x20].
方向码 dispatch 与前两变体相同 (0x0/0x40/0x80/0xc0/0x4040/0x8000/0x8080/0x80c0);
像素偏移调整 (4/8/16/32px) 也相同. 结束时同样写 attr0/attr1/attr2 并调用 affine 写入.
6 个 caller: play_ui_effect_21 (场景通用 UI), play_card_zoom_in (卡牌 zoom 动画),
FUN_080c4edc (card_ids/duel_field), FUN_080d0150 (scene_pack), FUN_080d71f4 (scene_pack).

Constants:
- gPrng+0x1bc (0xde<<1): OBJ 缓冲区基址
- DAT_080f6d50 = 0xfffffe00: attr1 X 坐标掩码
- DAT_080f6d58 = 0x4040: 方向码枚举之一; 0xc0<<2=0x300: OBJ affine 双尺寸标志

## 参数签名
- r0: u32 packed_pos - 高 16 bit = y [0..159], 低 16 bit = x [0..239]
- r1: u16 dir_code - 方向/角度离散枚举 {0x0, 0x40, 0x80, 0xc0, 0x4040, 0x8000, 0x8080, 0x80c0}
- r2: u16 tile_index - OBJ tile 索引 (写入 attr2 tile 字段); callsite 观察值: 0x100 (play_card_zoom_in @ 080c3e8e, 080c3f26, 080c526c), 0x104 (play_ui_effect_21 @ 080c1122, 080c50d0, 080c51b8), 0x18c (@ 080d022e), 0x1cc (@ 080d0266); range [0x100..0x1cc] (pack 场景 OBJ VRAM tile 区段)
- r3: u32 packed_r3 - [31:16]=affine_ctrl (0x8000 | counter*8) [0x8000..0x8078]; [15:0]=scale_ramp (0x20 - counter*2) [0..0x20]; 高低 16 均 str 至 sp+0/sp+4 (@ 080f6d06)
- 返回: void (无返回值)
