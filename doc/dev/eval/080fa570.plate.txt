tick_puzzle_prng_anim_entry
Tick callback registered as animation entry callback for EWRAM 0x0202a7d0 region (registered by FUN_080fa7e4 caseD_0 via FUN_080edd90, fn_ptr=0x080fa571). Each call checks [0x02029eb0+0xe] bit0: if already set skips (re-entry guard); otherwise sets bit0 (enter lock), calls dequeue_prng_anim_entry([ctx+0x12]) to fetch next anim frame index into [ctx+0x10], checks gPrng+0x1c0+0x584 byte bit0: if bit0=1 clears bit1 (non-dual-byte mode) and exits. If frame index nonzero, dispatches on magic 0x5731/0x5733: 0x5731 sets [ctx+0x0] bit0; 0x5733 does same plus copy_memory_dma3_with_cpu_fallback copies 8 bytes frame data. Finally clears bit1 of [ctx+0xe]. Invoked via function pointer, callgraph indeg=0.
Constants:
  MAGIC_ANIM_TYPE_A = 0x5731 (frame type A: set control byte only)
  MAGIC_ANIM_TYPE_B = 0x5733 (frame type B: set control byte + DMA copy frame data)
  EWRAM_CTX_A = 0x02029eb0 (puzzle/pack EWRAM context base)
