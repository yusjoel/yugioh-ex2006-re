# Naming Proposal: 0x08013bd4

## plate comment (中文, ASCII 标点)
由 FUN_08014398 和 play_ui_effect_3a 调用, 作为 demo 场景 (演示动画) 的每帧状态机驱动入口. 读取 gDemoState+0x8c 中 bits[22:15] 作为当前状态索引 (0-9), 通过 10 项跳转表分派到对应 case 处理: case0 加载 BG 图形集 0 + FS 资源, case1/2 检查 blend 进度并推进淡入步骤, case3/4 处理精灵动画帧步进, case5 加载 BG 图形集 1, case6-7 处理淡出窗口动画, case8-9 为结束态. 每个 case 末尾均递增状态计数器并跳回 default (不变状态). 副作用: 修改 gDemoState 状态字段, 写 DISPCNT/BG3CNT/BLDCNT 等 IO 寄存器.

## 参数签名
- 无参数 (void, 所有输入从 gDemoState EWRAM 结构体读取)
- 返回: 无返回值 (void)

## 副作用
- [gDemoState+0x8c] bits[23:9] := 状态计数递增 -- 驱动状态机推进
- [DISPCNT 0x04000000] bits[12:5] := 各 case 对应的 BG/win 模式 -- 多 case 写入
- [BG3CNT 0x0400000e] bits -- BG3 配置 (case5)
- [BLDCNT 0x04000050] := 混合模式掩码 -- case3/7 写入
- case0: 调用 load_demo_bg_gfx_set0, fs_load, dispatch_demo_sprite_setup_by_mode x3, gl_set_blend2_level
- case5: 调用 load_demo_bg_gfx_set1, fs_load, dispatch_demo_sprite_setup_by_mode x3
- case1/2/3: 调用 FUN_080148f4, FUN_08014754, FUN_08014914, gl_set_brightness
- case4/6: 调用 apply_demo_window_fade_in_step / apply_demo_window_fade_out_step
- case7: 调用 load_demo_obj_resource_by_slot
