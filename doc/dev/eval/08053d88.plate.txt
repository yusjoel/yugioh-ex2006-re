Equip slot eligibility predicate combining opposite-side, magic/trap zone, and zone chain checks. r0=card_slot_ptr, r1=player_id [0..1], r2=zone_slot_idx [5..0x14]. Fast path: if slot[+0xa]!=0, delegates directly to check_equip_slot_eligible_triple_predicate(r6) and returns its result. Main path: (1) reads slot[+2] bit0=owner_bit; if player_id==owner_bit (same side) rejects (opposite side required); (2) zone_slot_idx>4 check (target must be in magic/trap zone [5..0x14]); (3) gDuelFieldSlots[player&1][zone] bits[18:0] non-zero (target slot occupied); (4) extracts slot[+2] bits[4:0] type field, calls find_zone_chain_node_by_card_id_pair(r5,r4) to confirm chain node exists; (5) check_slot_card_special_activation_eligible(r5,r4); (6) count_zone_pair_hits_with_fn_ptr(r0=slot_ptr, r1=packed_key=(player<<8|zone), fn_ptr=0x0804f551) count non-zero. All conditions pass returns 1, any fail returns 0. Sub-case E exit: pop{r1}; bx r1.

Params: r0=ptr card_slot; r1=u32 player_id [0..1]; r2=u32 zone_slot_idx [5..0x14] (magic/trap zone)
Returns: r0=u32 bool (1=eligible, 0=rejected; Sub-case E: pop {r1}; bx r1)
Side effects: none (pure read-only predicate; all writes in callees are query-semantic only)
