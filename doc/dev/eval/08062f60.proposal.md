## plate comment (中文, ASCII 标点)
装备卡放置决策的高层过滤器, 被调用时判断场上是否存在超过 3 个"可多目标装备"区域. 函数双重遍历: 外层 r6 枚举两名玩家 (0..1), 内层 r5 枚举 5 个槽位 (0..4). 对每个槽位调用 check_slot_card_can_be_equipped; 若可装备且槽位归属玩家不同于外层遍历玩家 (即对手槽位) 且该槽的链接字段非零, 则调用 compute_slot_zone_eligibility_mask + count_set_bits_in_word 统计该槽对应的多目标候选数, 并累计到共享计数器. 最终若总多目标区域数 > 3 返回 1, 否则返回 0. 外层 r6 仅遍历到 1 (共 2 次).

Constants:
- MAX_SLOTS=4 (内层 cmp r5,#0x4 -> ble -> 5 槽 [0..4])
- MULTI_ELIGIBLE_THRESHOLD=3 (cmp r0,#0x3 -> ble, 超过 3 才返回 1)
- PLAYER_STRIDE=0x868
- SLOT_DATA_BASE=0x0201c510 (gDuelFieldSlots)

- 返回: r0 = uint32; 1=多目标区域数 > 3(条件满足), 0=不满足
