Drives the per-frame logic for displaying the card name after a pack reveal. Decrements pack_ui_state+0x10c (BG2 scale frame counter); if non-zero, computes the BG2 affine matrix (BG2X/BG2Y/BG2PA-PD) and BLDCNT/BLDALPHA blend weights for the current frame. When the frame count reaches zero or pack_ui_state+0x140 bit4 is set (display complete trigger): if bit4 is set, checks EWRAM[0x02000006+0x18] to decide whether to call apply_delta_to_hand_oam_entry to update hand OAM; then calls init_puzzle_wram_and_checksum and render_pack_info_to_vram, formats the card name via game_str_id=0x138e / select_charset_then_load_name / expand_format_text_to_buf, calls text_overlay_create to display the card name, and writes pack_ui_state+0x4:=0x1b and r7=1. Calls tick_pack_oam_slots_and_overlay(2). Returns r7. indeg=0.
