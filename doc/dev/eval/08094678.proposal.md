## plate comment (中文, ASCII 标注)
根据 field_type (r1 枚举值) 从 gP1LifePoints 结构中读取对应玩家的 LP 数值. r0 = player_bit (bit0 = player side, 0 or 1), r1 = field_type code [0xc..0xf]. 按 field_type 分派: 0xc -> [gP1LifePoints + player_bit*0x868 + 0x18], 0xd -> [+0x10], 0xe -> [+0x14], 0xf -> [+0x1c]. 各偏移对应不同 LP/stat 字段. 不在 [0xc..0xf] 范围则返回 0. 被 dispatch_card_display_op case 0x14 调用, 传给 render_field_zone_card_tile_by_type 作 zone_type 参数. Constants: gP1LifePoints=0x0201c4e0, player_stride=0x868, type_range=[0xc..0xf], offset_0xc=0x18, offset_0xd=0x10, offset_0xe=0x14, offset_0xf=0x1c.

## 参数签名
- r0: u32 player_bit_packed 含 player_id bit0 [0..1], 经 ands r0,r3 取 bit0 后 * player_stride
- r1: u8 field_type LP 字段类型 [0xc..0xf], 超出范围返回 0
- 返回: r0 = u32 lp_value 对应 LP/stat 字段值, 不匹配时 r0=0
