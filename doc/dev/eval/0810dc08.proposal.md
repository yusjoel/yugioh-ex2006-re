## plate comment (中文, ASCII 标点)
遍历 IWRAM DMA 通道槽数组 (0x03005390, stride=0x28, 8 个槽), 为所有 entity_id 匹配的活跃槽写入经 vol_a*vol_b 乘积计算的衰减字节. 公式: attenuation = 0x10 - (vol_a * vol_b >> 4). 槽活跃判断: [slot+0x1f] bit7=1; 实体匹配: [slot+0xe] 有符号半字 == entity_id. 写入目标: [slot+0x24] (音量/衰减字节字段). 返回计算出的衰减值 r4 (Sub-case E, pop{r1};bx r1 保留 r0).

调用场景: 音效引擎需要按实体 ID 批量更新所有活跃 DMA 通道的音量衰减量; 衰减量由音调深度 (vol_a) 与振幅 (vol_b) 的乘积决定.

Constants:
CHANNEL_ARRAY_BASE=0x03005390 (IWRAM DMA 通道槽数组基址)
ENTRY_COUNT=8 (槽数量 [0..7])
ENTRY_STRIDE=0x28 (每槽 40 字节)
ACTIVE_FLAG=0x80 (bit7 of [+0x1f])
ENTITY_ID_OFF=0xe (实体 ID 有符号半字字段)
VOL_OFF=0x24 (音量/衰减字节字段)
SCALE_SHIFT=0x4 (右移 4 位 = 除以 16, 固定点归一化)
VOL_MAX=0x10 (衰减基准值)

## 参数签名
- r0: s16 entity_id [-32768..32767] 目标实体 ID, 匹配 [slot+0xe]
- r1: u8 vol_a [0..0xff] 音量参数 A (乘数之一)
- r2: u8 vol_b [0..0xff] 音量参数 B (乘数之二)
- 返回: r0 = u8 attenuation_byte [0..0x10] 写入各匹配槽的衰减值 (=0x10-(vol_a*vol_b>>4))

## 副作用
