Per-frame driver for the pack cover card scroll animation. Sets DISPCNT OBJ enable bit (orr 0x80<<3=0x400). Reads pack_ui_state+0x10c (elapsed frames), decrements by 1 and writes back; computes the current BG2 horizontal scale (affine scale) as (total-elapsed)*0x800/total, then writes BG2X (0x04000028) and BG2PA/BG2PB (affine matrix) via multi-step linear mapping. Calls tick_pack_oam_slots_and_overlay(2) to drive OAM. When elapsed reaches zero, calls sync_state_and_init_sprite to init the sprite slot, writes pack_ui_state+0x4 := 0x11, and returns r7=1. Otherwise returns r7=0. Used by the pack scene state machine as the cover scroll-in animation step; indeg=0.
