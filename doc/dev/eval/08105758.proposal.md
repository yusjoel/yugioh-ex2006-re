## plate comment (中文, ASCII 标点)
根据当前 card_list 显示模式返回卡牌列表最大有效 index 上限的查询函数. 从 0x0202a4d0[+0x18] (s16 mode, 值 0..5) 读取显示模式: 若 mode==4 (全卡数据库), 调用 get_card_data_format_id 并返回其结果; 若 mode 在 [5..6] 范围 (EX/GB pack), 读 0x0202a4d0[+0x24] (s16 pack_card_count) 并加 0xc 返回; 其余 mode 返回固定值 0x3c (60 张). 被 pass_input 驱动 (FUN_081089d8) 和 card_list 场景驱动 (FUN_08108da4) 调用, 用于在滚动/选择时验证 index 是否越界. 与 setup_card_list_scene_bg_regs 中的内联逻辑等价, 但独立抽出供多个 caller 复用.
