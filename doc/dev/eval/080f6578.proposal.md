# Naming Proposal: 0x080f6578

## 提案
- **proposed_name**: write_obj_attr_with_priority
- **confidence**: med

## plate comment (中文, ASCII 标点)
与 write_obj_attr_packed (0x080f61e4) 同族, 向 gPrng+0x1bc OBJ 属性 shadow 缓冲写入一个精灵条目. 不同之处: attr0 合成时额外 OR 0x2400 (bit10=双大小模式, bit13=R/S 位, 具体语义为 priority 或 affine 标志); attr2 写法略有差异 (使用 [entry+4] 写 size/priority 合成字段). 最后同样将使用计数 byte 加 1. 被唯一 caller FUN_08107b90 调用, 用于需要特殊优先级或仿射参数的 OBJ 提交.

## 参数签名
- r0: u32 packed_attr (bits[15:0]=attr0 (Y/shape), bits[31:16]=attr_extra)
- r1: u16 attr1_x (X 坐标/flip/size)
- r2: u16 attr2_tile (tile_idx/palette/priority)
- 返回: void

## 副作用
- [gPrng+0x1bc + slot*8 + 0]: halfword := 合成 attr0 (含 0x2400 OR)
- [gPrng+0x1bc + slot*8 + 2]: halfword := attr2 tile 部分
- [gPrng+0x1bc + slot*8 + 4]: halfword := size/priority 合成字段
- [gPrng+0x1bc + slot + 0x400]: byte += 1
