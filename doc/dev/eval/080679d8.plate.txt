tick_equip_activation_sprite_state_with_eligibility: Three-state equip activation sprite state machine.
Entry: if slot[+0x4].bit2 set -> set slot[+0x4] |= 0x8 (ERROR_BIT) and return void.
Reads gDuelFieldState+0x4a0 state; three-way dispatch:
  state==0x80: store 0 to gDuelFieldState+0x4a4 (step_counter); increment_lp_bar;

    player mismatch; apply_slot_equip_activation_with_eligibility_check(slot, player, col, 0);
    [gDuelFieldState+0x4a4] += 1; return 0x7f.
  state==0x7f: read gDuelFieldState+0x4a4 as chain slot index; verify zone entry; find slot;
    check card valid + chain_head [+0x8] + player_id match;
    invoke_zone_slot_sprite_attr_for_equip_type; return 0x7e.
  state==0x7e: decrement_lp_bar; return void.
Error path: slot[+0x4] |= 0x8. indeg=0 (fn-ptr: 0 hits).
