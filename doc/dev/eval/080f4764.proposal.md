## plate comment
每帧读取 KEYINPUT (0x04000130) 取反得 cur_keys, 与 gPrng+0x146 (prev_keys) 异或得变化位. AND cur_keys -> new_pressed 存 gPrng+0x148; AND prev_keys -> released 存 gPrng+0x14a; 更新 prev_keys. 维护 gPrng+0x14c 的 5-bit 重复计数器 (+1 循环), 超阈时写 new_pressed 至 gPrng+0x150. 由 scene_duel_puzzle 帧驱动器 (0x080f4b78) 每帧调用.

Side effects:
- [gPrng+0x146] := cur_keys (prev_keys 更新为当前)
- [gPrng+0x148] := new_pressed
- [gPrng+0x14a] := released
- [gPrng+0x14c]: 重复输入计数字段 (5-bit +1 循环)
- [gPrng+0x14e]: 清 0 (当 prev!=cur 时)
- [gPrng+0x150]: := new_pressed (计数超阈时触发重复)

Constants:
- KEYINPUT = 0x04000130 // GBA key register (active low)
- REPEAT_COUNTER_MASK = 0x1f // 5-bit counter
- REPEAT_THRESH_OFFSET = 0x153 // gPrng+0x153 byte (repeat threshold)
