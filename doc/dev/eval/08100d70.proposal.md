# Naming Proposal: 0x08100d70

## 提案
- **proposed_name**: render_deck_count_diff_label
- **confidence**: high

## plate comment (中文, ASCII 标点)
card_list/settings 界面中展示卡组数量差值标签的渲染函数. 读取 IWRAM 0x0202a4d0[+0](mode, uint16), 若不等于 1 则直接退出. 读取 0x0202a4d0[0x1a16] 和 [0x1a1e] 两个 uint16 值相减得差值 r5. 从 0x02006ed0(game_ctx) 读取状态字节 [+8] 的 bit[1..0] 并更新(charset 选择), 通过 PTR_font_jp_base_table 配置字体. 调用 setup_line_buf_pos_and_font(0x19, 2). 根据 r5==0 查 game_str_id 0x6c1; r5!=0 分支按 bit[0..2] 符号选 format_decimal_with_sign_pos 或 format_decimal_with_sign_neg 格式化差值, 取 game_str_id 0x6c2/0x6c3. 连续调 text_render_wrapper 三次(含阴影), 最后 zero_fill_by_halfword + commit_line_buffer_to_sprite_vram 写入 sprite VRAM.

## 参数签名
- 无入参 (全部从 IWRAM 0x0202a4d0 读取)
- 返回: r0 = uint32 1 (always)

## 副作用
- [0x02006ed0 + 8]: &= ~0x03; |= charset_bits (字体 charset 字节更新)
- [VRAM 0x06008000 + offset]: zero_fill_by_halfword 清目标行 + commit_line_buffer_to_sprite_vram 写 tile; 0x06008000 为 BG/OBJ 重叠区, mode 0 场景下作为 OBJ tile 第二 bank 使用 (依据: DAT_08100f34 = 0x06008000 @ 08100ef8; 其他同类函数 0x08105bfc 亦注明 "OBJ VRAM 0x06008000 second bank"; 确切显示模式需检视 DISPCNT 初始化)
