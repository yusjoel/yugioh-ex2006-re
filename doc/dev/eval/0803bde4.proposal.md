## plate comment (中文, ASCII 标点)

Constants: gSpriteAttrBuf=0x0201b870, slot_a_offset=0xc1*4=0x304, slot_b_offset=DAT=0x306, slot_c_offset=0xc2*4=0x308+DAT=0x30a, slot_d_offset=0xc3*4=0x30c, flags_offset=0xc0*4=0x300, filled_bit=0x4.
