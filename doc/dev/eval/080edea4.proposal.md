# Naming Proposal: 0x080edea4

## 提案
- **proposed_name**: zero_fill_bg_vram_row_range
- **confidence**: high

## plate comment (中文, ASCII 标点)
清零 BG VRAM 中指定 tile 行范围. r1 高 11 位 (lsrs#0x15) = row_count, 低 5 位 (lsrs#0x10 & 0x1f) = x_tile. r2 高 11 位 = fill_count, 低 5 位 = tile_width. 计算起始地址: 0x06000000 (0xc0<<0x13) + x_tile + r0<<11 (行 * 0x800 每行字节数). 循环 row_count 次: 调用 zero_fill_by_halfword(addr, tile_width), addr += 0x20 (每行步进 32 字节). indeg=0, 无 ROM 函数指针引用.

Constants:
- BG_VRAM_BASE = 0x06000000 (0xc0<<0x13)
- ROW_STRIDE = 0x20 = 32 字节 (每行 tile 步进)
- x_tile = r1[4:0] (bits 0..4), row_count = r1[26:21] (bits 21..26)
- tile_width = r2[4:0], fill_count = r2[26:21]

## 参数签名
- r0: u32 bg_row_start 起始行号 (乘以 0x800 得字节偏移)
- r1: u32 packed_x_row 打包参数: bits[4:0]=x_tile [0..31], bits[26:21]=row_count [0..N]
- r2: u32 packed_w_cnt 打包参数: bits[4:0]=tile_width [0..31], bits[26:21]=fill_count [0..N]
- 返回: void

## 副作用
- [0x06000000 + x_tile + bg_row_start*0x800 .. +row_count*0x20]: := 0 (BG VRAM 行范围清零)
