## plate comment (中文, ASCII 标点)
在牌组槽 r0 的手牌列表中统计 card_id r1 出现次数. 入口检查 slot_index > 0x3b (59) 则返回 0. 否则用 280*n 公式计算 EWRAM 偏移, 读 [slot+0x126a]=hand_card_count(u8), 从 [slot+0x132a] 起每2字节遍历 hand_card_count 个手牌条目 halfword, 比较与 r7=r1(card_id), 相等则 r5 计数+1. 返回 r5. 被两个 caller (0x080f93c0, 0x080f943c) 调用, 这两个 caller 结构几乎相同, 仅偏移常量不同(0x1268 vs 0x126c, 0x130c vs 0x130c+4).

Constants:
- DECK_BASE = 0x02000000
- SLOT_STRIDE = 280
- HAND_COUNT_OFFSET = 0x126a (DAT_080f93ac)
- HAND_DATA_OFFSET = 0x132a (DAT_080f93b0)
- MAX_SLOT = 0x3b = 59 (越界返回 0)

## 参数签名
- r0: u8 slot_index[0..59] (牌组槽索引)
- r1: u16 card_id (要统计的目标卡牌 ID, lsls/lsrs#0x10 提取低16位)
- 返回: r0 = u8 count[0..255] (手牌中 card_id 出现次数, 若 slot_index>59 则0)
