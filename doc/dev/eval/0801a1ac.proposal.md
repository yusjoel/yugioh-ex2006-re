## plate comment (中文, ASCII 标点)
Function: banlist 背景滚动动画每帧步进处理. 读取 gBanlistPasswordBuffer+0x666 (滚动方向: -1=上/+1=下/0=停), 若方向非零则向 0 方向递减一步并计算对应像素偏移 (step_nibble*56 +/- 56), 最后调用 write_banlist_bg2_scroll_regs_biased 和 write_banlist_bg3_vofs_with_bias 更新 BG2/BG3 滚动寄存器. 每帧由帧更新函数 (0x08019fe4 / 0x0801b5d8) 调用.
Side effects:
- [gBanlistPasswordBuffer+0x666] := direction-1 (向 0 方向递减, 滚动完成时归零)
- BG2/BG3 scroll registers: 通过 write_banlist_bg2_scroll_regs_biased / write_banlist_bg3_vofs_with_bias 写入
Constants:
  SCROLL_DIR_OFFSET = 0x666 // 滚动方向字节
  SCROLL_STEP_OFFSET = 0x663 // low nibble = 当前步内像素阶段
  PIXEL_PER_STEP = 0x38 = 56 // 每步滚动像素数
  WRAP_MODULO = 0xff = 255 // __modsi3 对 255 取余做环绕

## 参数签名
- 返回: void (pop{r0};bx r0 退出, r0 来自 lr 恢复)

## 副作用

- BG2 scroll register: 由 write_banlist_bg2_scroll_regs_biased 更新
