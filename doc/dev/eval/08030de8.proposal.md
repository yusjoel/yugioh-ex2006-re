# Naming Proposal: 0x08030de8

## 提案
- **proposed_name**: find_zone_descriptor_by_slot_id
- **confidence**: high

## plate comment (中文, ASCII 标点)
根据 packed slot entity ID (r0) 在全部区域表中搜索对应格, 返回编码了区域类型和格索引的
packed zone descriptor. 搜索顺序: (1) gDuelFieldSlots 主格 (两玩家 x 10 格, stride 0x14);
(2) 五种辅助区域数组 (0x0201c4f4/0x0201c4fc/0x0201c4f0/0x0201c4f8/0x0201c4ec 各对应不同
区域类型, 每种数组包含两玩家条目); (3) 0x0201bc54 为基址的 default table (stride 0x114, 覆盖
墓地/手牌/额外牌库等). 每处遍历对 entry word 字段 `(bits[13..6]<<1 | bit[13])` 与 r7 做比较,
命中后将区域类型色码 (bits[31..24]) + 格索引 (bits[23..16]) 组合成 32 位返回值.
未找到时返回 0x1000 (sentinel). 高频被调用 (indeg=52), 主要由 card_display/card_frame 类
hub 函数调用, 用于确定卡牌当前所在区域以驱动渲染和规则判断.
Constants: 0x0201c510=gDuelFieldSlots, 0x868=player stride, 0x0201bc54=default zone table base,
sentinel=0x1000 (0x80<<5), zone_type_codes: 0xe00/0xf00/0xd00/0xc00/0xb00=各辅助区域类型.

## 参数签名
- r0: u32 slot_entity_id; zone entry word bits[13..6] (8-bit); 调用方从 zone entry 提取后传入; [0..0xFF]
- 返回: r0 = u32 zone_descriptor; bits[31..24]=zone_type_code, bits[23..16]=slot_idx, 或 0x1000 (未找到)

## 副作用
- 无外部写入; 纯读取 EWRAM 区域数组
