## plate comment (中文, ASCII 标点)
本函数是装备牌目标格筛选谓词, 含双 zone 激活标志检查.
从槽位 byte[+2] 提取 zone_idx (bits[5:1]) 和 player_id (bit0).
在 gP1LifePoints+0x40+zone_idx*20+player*0x868 处读取 word, 取 bit22 = active_flag1.
再在相同 zone 的 opp_player 偏移处读取 word, 取 bit23 = active_flag2.
若 active_flag1 + active_flag2 != 0 则直接返回 0.
若两者均为 0: 调用 check_equip_slot_chain_absent(slot_ptr, r1_passthrough),
返回其结果.
r1 输入通过 r12 透传到 check_equip_slot_chain_absent 第二参数.
