## plate comment (中文, ASCII 标点)
装备区目标位图扫描与精灵入队函数. 被场地渲染帧循环 (duel_field) 从 0x0806ea72 和 0x0807456c 两个位置调用, 入口 r0=player_id, r1=slot_idx, r2=zone_col, r3=state_flags (0x40). 调用 update_equip_target_bitmap_for_field 计算装备目标位图, 若未命中则返回 0. 命中后读取 gP1LifePoints+player_stride+zone_col 区域结构体, 检查 [slot+0xa] 链表头 halfword; 若为 0 跳至清除路径. 否则遍历链节点, 提取 byte+2 低 nibble 为 zone_type; zone_type<=5 才有效. 在 card_id 树 (0x17d5/0x1814 两个节点) 中匹配, 命中后调用 enqueue_sprite_attr_type11 入队 OAM 精灵. Side effects: OAM sprite attr buffer via enqueue_sprite_attr_type11. Constants: CARD_ID_A=0x17d5 (Dark Mimic LV1), CARD_ID_B=0x1814 (The All-Seeing White Tiger), PLAYER_STRIDE=0x868, gDuelFieldSlots_A=0x0201c510, gDuelFieldSlots_B=0x0201d9c0, BITMAP_MASK=0xf.

## 参数签名
- r0: u8 player_id [0..1] -- callee-save spill: .hword 0x464f=mov r7,r1, 0x4646=mov r6,r0
- r1: u8 slot_idx [0..10]
- r2: u8 zone_col [0..11]
- r3: u32 state_flags -- extra flags (callers pass 0x40)
- 返回: r0 = u32 (0=no sprite, 1=sprite enqueued)

## 副作用
- OAM sprite attr buffer (indirect): via enqueue_sprite_attr_type11 when card_id in {0x17d5, 0x1814}
