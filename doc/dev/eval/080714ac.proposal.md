## plate comment (中文, ASCII 标点)
Function: 接受 equip_data_ptr (r0) 和 slot_ptr (r1). 首先检查 [r0+0xc] hword 是否非零 (装备位图活跃标志); 若为零直接返回 0.

非零时: 在 [r1+4] byte 设置 bit2 (激活标志); 提取 slot 的 player_id (bit0) 和 zone_idx (bits[6:2]); 调用 enqueue_field_slot_sprite_with_state_update(player_id, zone_idx, [r1+4] bits[14:9]). 然后以 equip_data_ptr, player_id, zone_idx 调用 test_equip_target_slot_in_bitmap 检查装备目标槽位位图.

用于在装备链有活跃条目时, 更新场地槽精灵并验证装备目标位图. 副作用: 置位 [r1+4] bit2; 写精灵队列; 可能更新装备目标位图.

Constants:
- ENTRY_COUNT_OFFSET = 0xc (equip_data [+0xc] hword = 条目计数)
- SLOT_ACTIVE_BIT = 0x4 (bit2 of slot[+4])
- PLAYER_STRIDE = 0x868
