# Naming Proposal: 0x08100048

## 提案
- **proposed_name**: resolve_card_scroll_offset_by_mode
- **confidence**: high

## plate comment (中文, ASCII 标点)
card_list 界面多处调用, 以 IWRAM 0x0202a4d0[+4] (display_mode, int16, [0..3]) 和 0x0202f3c0 (scroll_state) 为输入, 按 mode 分支查找或计算当前卡片列表的滚动偏移量并写回 0x0202f3c0[+0x74]. mode==0 直接取固定基础偏移 0x4acc; mode==1 按卡片 foil bit (ldrb [r2+0x16] & 1) 选 4ede/4ed6, 再用 __divsi3 计算水平像素偏移并写入 +0x7a; mode==2/3 同理选不同 offset 表. 最终将解析到的滚动目标指针存入 [r4+0x74], 像素偏移写入 [r4+0x7a].

## 参数签名
- r0: (unused; state read from IWRAM 0x0202a4d0 直接)
- r4: ptr 0x0202f3c0 scroll_state 结构基址 (caller 提供; 非标准 ABI 隐式传参); 证据: FUN_080fffc4 @ 080fffc6 `ldr r4, DAT_080fffe0` (= 0x0202f3c0) 后紧接 bl FUN_08100048 @ 080fffca; FUN_080ffaf8 @ 080ffafe `adds r4,r7,#0x0` / @ 080ffb00 `adds r4,#0x78` (r7=0x0202f3c0 from DAT_080ffb2c) 后 bl FUN_08100048 @ 080ffb60
- 返回: r0 = uint32 1 (always success)

## 副作用
- [0x0202f3c0 + 0x74]: := 解析后的卡片滚动 tile 行指针
- [0x0202f3c0 + 0x7a]: := uint16 水平像素偏移量 (经 __divsi3 /10 计算)

## 行级注释 (≤ 30 行精华)
- @ 08100048: 读 0x0202a4d0[+4] display_mode 到 r0, 分支选路
- @ 08100076: mode==0: 取固定偏移 0x4acc, 写 [r4+0x74]
- @ 08100090: mode==1: ldrb [r2+0x16] & 1 判断 foil; 选 offset 4ede 或 4ed6
- @ 08100160: __divsi3 /10 计算水平像素位置, 写 [r4+0x7a]
- @ 081000d0: mode==2 分支, 同 foil 逻辑但用 offset 4ee0/4ed8
