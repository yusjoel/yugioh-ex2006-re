## plate comment (中文, ASCII 标点)

Side effects: 通过 setup_lp_display_row_with_data 写 LP 显示行 type=0xc 数据.
Constants: ROW_TYPE=0xc (12, 固定; movs r1,#0xc), LOCAL_BUF_SIZE=0x10 (sub sp,#0x10).
