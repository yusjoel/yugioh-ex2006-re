Iterates equip slot criteria array ([IWRAM+0x5ac], count=[IWRAM+0xb4*8]); for each criteria_code calls check_slot_card_equip_criteria_by_state_code(criteria_code, slot_ptr=r6, card_ptr=r5); returns 1 on any match, 0 if none. Symmetric to check_equip_slot_criteria_by_ext_field6_any (0x0807f800) but uses state_code path. Entry .hword 0x4688=mov r8,r1 saves IWRAM base. No side effects. Constants: IWRAM_BASE=0x0201b290, CRITERIA_ARRAY_OFFSET=0x5ac, COUNT_OFFSET=0xb4*8=0x5a0.
