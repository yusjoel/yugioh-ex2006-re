# Naming Proposal: 0x080186f0

## 提案
- **proposed_name**: read_banlist_char_at_scroll_pos
- **confidence**: med

## plate comment (中文, ASCII 标点)
Function: 根据滚动条当前值 (get_scrollbar_cur_value) 和辅助偏移字段 (gState[0x315] bits[5:2]) 计算当前行/列索引, 调用 advance_text_ptr_by_charlen 在 banlist 文字表 (gState+0x8d) 中定位对应的字符指针 r2; 若 r2 为 null 则向 r5 写 0; 否则检查 EN 模式下空格字符 (0x20) 并替换为 ROM 常量字节 (0x09e3b2b4), 最后调用 banlist_password_enter_char 将字符写入输出缓冲区 r5. 由 FUN_080187e0 和 FUN_08018938 (banlist/settings 字符输入) 在每次字符选择时调用.
Trigger: banlist 密码输入界面选定一个字符时 (scrollbar 位置确定字符); r0=output buf ptr.
Side effects: [r5..] 写入一个字符 (via banlist_password_enter_char); 若无效则 [r5]=0.

Constants:
- SCROLLBAR_OAM_OFFSET=0xc1<<2=0x304 (gState+0x304 scrollbar slot)
- BANLIST_TEXT_OFFSET=0x8d (gState+0x8d banlist 文字表起始)
- SCROLL_COL_FIELD=gState+0x315 (滚动列索引字段 bits[5:2])
- LANG_CHECK_OFFSET=gState+0x6c2c (language flag bits[2:0])
- COL_STRIDE=0xc=12 (每列字节步长: r2*3<<2=r2*12)
- SPACE_PLACEHOLDER=0x09e3b2b4 (ROM 地址: EN 模式空格替代字节)
- ENTER_FLAG=1 (banlist_password_enter_char 第 3 参数)

## 参数签名
- r0: u8* output_buf_ptr banlist 密码输出缓冲区 (透传给 banlist_password_enter_char r1=r5)
- 返回: void (pop {r0}; bx r0 Pattern-B exit)

## 副作用
- [r5..]: banlist_password_enter_char 写入选定字符; 若 null 则 [r5]=0
