## plate comment (中文, ASCII 标点)
当前函数是装备区 slot sprite 分发核心. 入口读取 slot 结构体 [r0] 的 card_id, 与 Armed Ninja (0x117b) 和 De-Spell (0x12eb) 两张卡比对; 若命中其中一张且 check_effect_slot_matches_zone_entry 返回非零, 则根据 chain_head 字段 [+0x8] 决定后续路径: chain_head==0 时直接 enqueue_zone_slot_sprite_attr_if_occupied + enqueue_sprite_attr_for_slot_indicator + enqueue_sprite_attr_type10_halfword (0x1e) 并再次调用 check_equip_slot_eligible_in_target_bitmap; chain_head!=0 时先取 get_card_extended_stat_field6 (field6==0x17 且 r8==1 走合法路径, field6==0 走另一路径) 然后 check_equip_slot_eligible_in_target_bitmap 或 enqueue_zone_slot_sprite_attr_if_occupied. 所有路径最终 movs r0,#0; pop; bx r1 (void 返回). 调用方通过函数指针调用 (indeg=0, 未见 fn-ptr 表赋值).

Constants:
- CARD_ID_ARMED_NINJA = 0x117b (Armed Ninja)
- CARD_ID_DE_SPELL = 0x12eb (De-Spell)
- PLAYER_STRIDE = 0x868 (gDuelFieldSlots player offset)
- gDuelFieldSlots = 0x0201c510
- INDICATOR_TYPE = 0x1e (enqueue_sprite_attr_type10_halfword arg)
- FIELD6_SWORD_OF_THUNDER = 0x17 (Sword of Thunder card type marker)

## 参数签名
- r0: ptr slot_ptr (effect slot struct pointer, [+0x0]=card_id halfword, [+0x2]=flags byte, [+0x8]=chain_head)
- 返回: r0 = void (movs r0,#0 fixed)

## 副作用
- 调用 enqueue_zone_slot_sprite_attr_if_occupied / enqueue_sprite_attr_for_slot_indicator / enqueue_sprite_attr_type10_halfword 间接写 OAM sprite 队列
