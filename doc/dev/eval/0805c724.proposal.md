(2) count_monster_slots_accepting_card(pair_player): 若非 0 跳过 (3); 若 0 且 pair_player==XOR_player 则 (3) check_slot_placement_blocked_by_field_effect(pair_player, pair_zone)

(5) count_zone_card_pair_allowed_for_card(pair_player, 0x1117) -- 检查特定卡对区域配对限制
全部通过返回 1, 任一失败返回 0. 通过函数指针调用 (indeg=0).
