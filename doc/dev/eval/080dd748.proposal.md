## plate comment (中文, ASCII 标点)
在进入 pack 场景初始化路径时被调用, 清除 GBA 显示控制寄存器 DISPCNT(0x04000000) 为 0
以关闭所有图层, 依次调用 reset_affine_bg_matrix_and_scroll / reset_display_and_obj_vram /
reset_all_bg_scroll_regs_and_shadows 复位所有 BG 仿射矩阵和卷轴影子寄存器,
最后调用 zero_fill_halfword_wrapper 将 VRAM 0x6000000 起 0x18000 halfwords 清零
(约 192KB, 覆盖全部 BG+OBJ tile 区域), 为新场景渲染做准备.

Constants:
- DISPCNT=0x04000000 (0x80<<0x13)
- VRAM_BASE=0x6000000 (0xc0<<0x13)
- VRAM_CLEAR_COUNT=0x18000 (0xc0<<0x9)

## 副作用
- [0x04000000] := 0x0000 (DISPCNT 清零, 关闭全部显示层)

- 调用 reset_all_bg_scroll_regs_and_shadows: 清零 BG 卷轴影子寄存器
- [0x06000000..+0x18000*2]: := 0 (VRAM 全清, 通过 zero_fill_halfword_wrapper)
