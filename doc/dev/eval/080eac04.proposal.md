## plate comment (中文, ASCII 标点)
nnsys/g2d/g2d_Image.c 第 810/811 行. 将 NNS_G2dPaletteData 的调色板数据上传到 2DMAIN 调色板 VRAM 区域 (0x05000200). type 必须为 1 (2DMAIN), 否则触发 assert. 从 pPltData[+0xc] 读取调色板数量 r0, 从 pPltData[+8] (r5) 得到原始数据指针. 计算写入字节数: r5*0x200/0x800 (lsls#9, lsrs#0xb). 调用 bios_cpu_fast_set 将数据 DMA 到 0x05000200 + type_offset.

Constants:
- PALETTE_2DMAIN_BASE = 0x05000200
- assert 行号 0x32a=810 (pPltData!=NULL), 0x32b=811 (type<=2)
- type 必须 = 1 (2DMAIN), type!=1 时 assert @ 0x080eac76, 行号 0x128=296

## 参数签名

- 返回: void

## 副作用
- [0x05000200 + r1]: 写入 pPltData->pRawData 的调色板数据 (via bios_cpu_fast_set)
