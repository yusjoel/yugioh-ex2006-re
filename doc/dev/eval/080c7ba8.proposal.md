## plate comment (中文, ASCII 标点)
卡片列表界面中卡面 tile 行渲染函数. 由 FUN_080c8688 (card list scene tick) 调用.
读取 gFontState+0x0a18 字节 (lsls #0xf / lsrs #0x18 提取 bits[24:15] -> 模式值 [0..2]).
mode=0: 遍历卡面 count 行 (gFontState+0x0a18 bytes[7:0]), 每行写 3 个 strh 条目至 gFontState+0x0a18 VRAM 映射区; 每列根据行号 (首行/尾行/中间) 选择 tile ID: 首行 0x013f, 尾行 0x01a2/0x01a2/0x01a3; 中间行 0x0141.
mode=1: 反向布局变体, tile ID 0x01a3/0x01a1/0x0143.
mode=2: 第三变体.
函数为卡片列表界面卡面显示框渲染的核心, 支撑 3 种卡片显示状态.
Constants: FONT_STATE_BASE=0x0201f440; MODE_OFFSET=0x0a18; TILE_TOP=0x013f; TILE_MID=0x0141; TILE_BOT=0x01a2; VRAM_BASE=0x0600f000; VRAM_ALT=0x0600f00a.

## 参数签名
- r0: (void) 无 APCS 输入; 函数入口后 mov r7,r10 / mov r6,r9 / mov r5,r8 均为 callee-save 保存, 非参数
- 返回: r0 = int32 0=已渲染完毕, 1=尚有待处理项 (render_in_progress)

## 副作用
