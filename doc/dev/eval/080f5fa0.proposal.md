# Naming Proposal: 0x080f5fa0

## 提案
- **proposed_name**: write_obj_affine_from_sin_table
- **confidence**: high

## plate comment
根据角度和比例参数, 从 rom_sin_table_q8 (128 项 Q8 定点) 查询 sin/cos 值, 计算 OAM 仿射矩阵 PA/PB/PC/PD 并写入 OBJ shadow list 指定槽位. 矩阵槽偏移 = affine_idx*32 (4 OBJ*8 字节). 角度 7-bit wrap: PA=sin[a+0x20], PB=sin[a], PC=sin[a+0x40], PD=PA. scale_idx (r1 bits[15:12]) <=7 时除以 (scale+1), >7 时乘以 (scale-8). 写入 OBJ shadow list +6/+14/+22/+30 (PA/PB/PC/PD, stride 8).

Side effects:
- [OBJ_shadow_list + r0*32 + 6]:  PA halfword (cos(angle)/scale)
- [OBJ_shadow_list + r0*32 + 14]: PB halfword (sin(angle)/scale)
- [OBJ_shadow_list + r0*32 + 22]: PC halfword (sin(angle+90)/scale)
- [OBJ_shadow_list + r0*32 + 30]: PD halfword (= PA)

Constants:
- SIN_TABLE = rom_sin_table_q8 // 0x09e5f8f0, 128 entries Q8 fixed-point
- SIN_LUT_MASK = 0x7f // 7-bit angle wrap
- AFFINE_STRIDE = 32 // 4 OBJ * 8 bytes per affine matrix
- PA_OFFSET = 6; PB_OFFSET = 14; PC_OFFSET = 22; PD_OFFSET = 30
- COS_PHASE = 0x20 // +32 entries = +90 deg in 128-entry table
- PC_PHASE = 0x40 // +64 entries = +180 deg

## 参数签名

- r1: u16 angle_scale 打包参数: bits[15:12]=scale_idx [0..15], bits[6:0]=angle [0..127]
