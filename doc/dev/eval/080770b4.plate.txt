Reads a word from effect node [r6+0x14], extracts player_id (bit9) and zone_type (bits[13:10]).
Computes gDuelFieldSlots[player_id][zone_type] offset r3, reads [r3+0] col/dir encoding and compares with [r6+0x14] low 9 bits (lsrs bits[8:0]).
On mismatch returns 0. On match checks [r3+8] != 0 (slot valid) and [r3+6] == 0 (byte 6 is 0 = not activated).
If all satisfied calls apply_slot_equip_activation_with_eligibility_check(effect_node, player_id, zone_type, 0).
Dispatched via runtime function pointer (indeg=0).

Constants:
- PLAYER_STRIDE=0x868 (DAT_08077110)
- gDuelFieldSlots=0x0201c510 (DAT_08077114)
- BIT_PLAYER=0x16 (lsls r0,r2,#0x16; lsrs r5,r0,#1f -- bit 9 of low 16)
- BIT_ZONE=0x12 (lsls r0,r2,#0x12; lsrs r4,r0,#0x1c -- bits[13:10])
- ZONE_FIELD_OFFSET=0x14 ([r6+0x14] = slot descriptor word)
