# Naming Proposal: 0x080c5b78

## 提案
- **proposed_name**: dispatch_duel_field_zone_oam_by_type
- **confidence**: med

## plate comment (中文, ASCII 标点)
根据区域槽位类型 (zone_type, [0..0xd]) 进行跳表分派, 为对应字段区域的 OAM 条目初始化坐标与属性. 入口从 gPrng+0x214 (0x0201ff30+0x214) 加载上下文基指针; 读取 offset 0x6c2c + player_state 处的 zone_type 字节, 提取低 3 bit 判断字体方向标志并写回 ctx+0x8 (strb @ 080c5bb0); 再从 font_jp_base_table 按方向/深度偏移加载字体数据写入 ctx+0x4 (str @ 080c5bc6). 随后进入 0x0d 分支跳表 (DWORD_080c5c00, 14 个 case), 每个 case 处理对应区域类型的 OAM 布局. 最终调用 measure_string_pixel_width 计算标签宽度后通过 write_oam_entry_from_packed_args 输出 OAM 条目 (副作用散布在各 case 分支). Constants: zone_type_max=0xd.

## 参数签名
- r0: void (无直接 APCS 输入; 函数从硬编码 DAT 地址加载上下文)
- 返回: r0 = void (无独立返回路径; 各 case 结束后直接返回)

## 副作用
- [0x0201ff30 + ctx_offset + 0x8] := 字体方向标志字节 (strb @ 080c5bb0)
- [0x0201ff30 + ctx_offset + 0x4] := font_jp_base_table 字体指针 (str @ 080c5bc6)
- 多个 OAM 条目 (通过各 case 内部 write_oam_entry_from_packed_args / write_tile_rows_to_vram_by_mode 等)
