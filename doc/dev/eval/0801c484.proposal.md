# Naming Proposal: 0x0801c484

- **confidence**: high

## plate comment (中文, ASCII 标点)
vija 场景 (play_ui_effect_3b 闭包) BG 图形资源加载调度器. 由 FUN_0801c6b0 (tags: bg, demo, fs) 和 FUN_0801cb00 (tags: display, palette, demo, fs) 调用. 函数以 r0 为模式选择子: r0==0 时调用 load_vija_bg_gfx_embedded (0x0801c310, 使用 ROM 嵌入数据); r0==1 时调用 load_vija_bg_gfx_from_fs (0x0801c3f4, 使用 fs_load); r0 为其他值时直接返回 (无操作). 其余参数 r1..r3 和两个栈参数原封不动地转发给被选中的加载子函数, 函数本身不产生 VRAM 副作用. 与 demo_shuen 族 load_shuen_sprite_gfx_guarded (0x0801b91c) 形成跨 scene 命名对称: 两者均为 mode 调度器 + 嵌入/FS 双变体结构.

## 参数签名
- r0: u8 load_mode [0..1] -- 资源加载方式; 0=嵌入 ROM 数据 (call c310), 1=文件系统加载 (call c3f4), 其他=no-op
- r1: u8 tile_group_index [0..3] -- BG tile 分组索引; 转发为 load_vija_bg_gfx_embedded.r0 / load_vija_bg_gfx_from_fs.r0; c310 body 中 adds r7,r0,#0 (asm:17800) 再经 lsls r2,r7,#1 作为 2 字节步长表索引 (表含 4 项); callsite: 0x0801cb5a movs r1,#0x0; 0x0801cba2 movs r1,#0x0; 0x0801cbb2 movs r1,#0x1
- r2: ptr oam_entry -- 目标 OAM 条目结构体指针; 转发为 load_vija_bg_gfx_embedded.r1 / load_vija_bg_gfx_from_fs.r1; c310 body 中 str r1,[sp,#0x3c] (asm:17801) 并经 strb r0,[r1,#0x14] (asm:17833) 写入 OAM 属性
- r3: u8 tile_base_idx [0..127] -- OAM attr1 tile 基址索引; callsite @ 0x0801cb58: movs r3,#2; 转发为子函数 r2 参数
- [sp+0x10]: u8 palette_bank [0..127] -- 转发为子函数 r3 参数 (ldr r5,[sp,#0x10])
- [sp+0x14]: u8 extra_param [0..127] -- 转发为子函数 [sp+0] 参数 (ldr r3,[sp,#0x14]; str r3,[sp,#0])
- 返回: void -- 无返回值; 副作用全部由子函数产生

## 副作用
- 无直接副作用; 所有 VRAM/OAM 写入由 load_vija_bg_gfx_embedded 或 load_vija_bg_gfx_from_fs 产生
