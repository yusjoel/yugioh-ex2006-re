# Naming Proposal: 0x08094e74

## 提案
- **proposed_name**: get_card_data_bit_by_index
- **confidence**: high

## plate comment (中文, ASCII 标点)
由多个 caller (result_screen, card_image, game_str, duel_field 等) 调用, 用于按索引号查询 ROM 卡数据表中的 1-bit 标志.
入口 r0=card_data_index [0..0x34]: 若 index <= 0x34, 直接从 EWRAM 表 0x0201b1b0 以 4 字节步长取 word; 否则进入位提取路径 -- 计算 word offset (index-0x36 或调整后值 右移5 得行), 从 offset 0xd4 起步的第二张表取 word, 再以 bit-shift 提取特定位, 返回 r0 = bit [0..1].
副作用: 仅读操作, 无写副作用.
Constants: table_base_a=0x0201b1b0, table_stride_a=4, max_idx_a=0x34, table_base_b=0x0201b1b0+0xd4, row_shift=5, offset_adjust_a=0x36, offset_adjust_b=0x17.

## 参数签名
- r0: u16 card_data_index [0..0x72] (卡数据项索引; [0..0x34] 走表 A, [0x35..0x72] 走位字段路径)
- 返回: r0 = u32 bit_value, [0..1] (指定索引对应的 1-bit 标志)

## 副作用
- 无外部写操作.

## 行级注释 (<=30 行精华)
- @ 08094e74: r0 先做 r1 别名, 然后与 0x34 比较分 A/B 路径
- @ 08094e7a: 路径 A -- 表基址 0x0201b1b0 + index*4 取 word
- @ 08094e82: A 路径直接跳到返回
- @ 08094e88: 路径 B -- index - 0x36 得相对偏移 r3
- @ 08094e92: r3 < 0 则用 index - 0x17 做 r2
- @ 08094e98: r2 >> 5 = 行号 r1; 行号*4+offset 取 word; r0 >>= (index % 32); 取最低位
