# Naming Proposal: 0x08113704

## 提案
- **proposed_name**: compare_double_ne
- **confidence**: med

## plate comment (中文, ASCII 标点)
GCC libgcc 双精度浮点不等比较函数 (__nedf2): 结构与 compare_double_eq (0x081136b8) 完全相同, 解包两 double 后检测 NaN (返回 1) 或调用 __fpcmp_parts_d.
GCC __nedf2 约定: 返回非零 = 不相等 (与 __eqdf2 返回值语义相同, 调用方用 beq/bne 区分用途).
该函数在静态调用图中 indeg=0 (未被任何函数直接调用), 无函数指针引用, 属于编译器生成的未使用符号 (dead code).

## 参数签名
- r0: u32 a_lo -- double A 低 32 位
- r1: u32 a_hi -- double A 高 32 位
- r2: u32 b_lo -- double B 低 32 位
- r3: u32 b_hi -- double B 高 32 位
- 返回: r0 = s32; 非零 = A!=B 或含 NaN, 0 = A==B

## 副作用
- 栈: 解包临时结构 (局部)
