Equip card eligibility predicate requiring target slot is monster type + equip chain score<=2. r0 param unused. Guards: (1) r2<=4; (2) gDuelFieldSlots[r1&1][r2] bits[18:0] non-zero; (3) ldrh [slot,#8]!=0 (equip valid flag); (4) check_slot_card_is_monster_type(r1,r2) -- non-monster rejects; (5) eval_equip_chain_score_for_slot(r1,r2) must return <=2 (already-equipped count limit). Returns 1=eligible, 0=rejected. Read-only predicate, no side effects.
Inputs: r0=ptr (unused), r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..4].
Outputs: r0=u32 bool (1=eligible, 0=rejected).
Side effects: none.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, chain_score_max=2.
