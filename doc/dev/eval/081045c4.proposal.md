## plate comment (中文, ASCII 标点)
card_list 场景 BG 寄存器及场景状态初始化函数. 连续向 BG0CNT/BG1CNT/BG2CNT/BG3CNT (0x04000008+) 写入 4 个预设控制字 (0x1c02/0x1d09/0x1e8f/0x1f0f), 将 BG0HOFS~BG3VOFS 共 8 个卷轴寄存器全部清零, 并将 BLDALPHA (0x04000052) 写入 0x5001 启用混合. 随后调用 apply_blend_fadeout_flat 执行 fade 动画, 清除 0x0202f3c0[+0x1f] 的 bit6/bit0, 将 gPrng+0x174 写入 0x5001. 接着 zero_fill_by_halfword 清空 5 块 VRAM 区域 (0x06004000~0x06013fff, 各 0x40 halfwords). 从 gSave 读取 deck_format 字段判断 card_type 格式以初始化 0x0202f3c0[+0x22] 的游标偏移. 被 FUN_081047e8 / FUN_0810890c / FUN_08108d70 / FUN_08108eb8 等多个场景入口调用.

## 副作用
- [BG0CNT 0x04000008] := 0x1c02 (BG0 控制字: charbase=0, priority=2, 16-color map=0x70000)
- [BG1CNT 0x0400000a] := 0x1d09
- [BG2CNT 0x0400000c] := 0x1e8f
- [BG3CNT 0x0400000e] := 0x1f0f
- [BG0HOFS~BG3VOFS 0x04000010..0x0400001e] := 0 (8 个卷轴寄存器清零)
- [BLDALPHA 0x04000052] := 0 (由 apply_blend_fadeout_flat 管理)
- [gPrng+0x174] := 0x5001 (混合 coeff)
- [VRAM 0x06004000..0x06013fff]: 5 块各 0x40 halfwords 清零
- [0x0202f3c0+0x1f] bit6/bit0 := 0 (场景状态标志位清除)
- [0x0202f3c0+0x22] := get_card_data_format_id() 或固定偏移 (card_type 游标)
- [0x0202f3c0+0x24] := 计算后的 card_index 偏移
- [0x0202f3c0+0x20] bit1 := 0 (mode 位清零)
