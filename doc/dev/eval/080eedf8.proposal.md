# Naming Proposal: 0x080eedf8

- **proposed_name**: get_card_extended_stat_field6
- **confidence**: high

## plate comment (中文, ASCII 标点)
从 ROM 扩展卡属性表读取指定卡牌的 field6 (u16). 入参 card_id <= 0x0fa6 (普通卡上界 4006) 时直接返回 0; 否则计算行偏移 row = card_id - 0xfa7, 以 row * 11 + 6 为字偏移乘 2, 加上表基址 0x09821e04, 读取一个 u16. 此函数是同一翻译单元 field5/field6/field7/field8/field9 getter 簇的一员, 各函数仅 adds r0,#N 中的 N 不同; 本函数 N=6. 调用方比较返回值与 0x16(22)/0x17(23), 暗示 field6 编码卡牌扩展属性类型码 (如 spell/trap 子类别). Constants: 0x0fa6=普通卡 ID 上界, 0x09821e04=扩展属性表基址, stride=11 字段/行, field_index=6.

## 参数签名
- r0: u16 card_id - 卡牌 ID [0..0x1770 (6000), 有效扩展区 [0xfa7..上界])
- 返回: r0 = u16 extended_stat_field6 - field6 属性值; card_id <= 0x0fa6 时固定返回 0

## 副作用
