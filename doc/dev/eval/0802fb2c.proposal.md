# Naming Proposal: 0x0802fb2c

## 提案
- **proposed_name**: find_node_by_value_and_zone_type
- **confidence**: med

## plate comment (中文, ASCII 标点)
从 EWRAM 节点池 (0x0201d9c0, 每节点 8 字节) 以链表方式遍历, 查找满足 [node+0]==value 且 [node+2]&0xF==zone_type (0..5 合法) 的节点. r0 为链表头索引 (0 表示空链表, 立即返回 NULL); r5=[value], r4=[zone_type]. 找到则返回节点指针, 未找到返回 NULL (0). 被 FUN_0802fdc0 封装调用 -- 后者负责计算 slot 的链表头索引后委托此函数完成节点搜索; 是整个 0x0802fxxx 区域链式节点查询簇的最底层叶子.

## 参数签名
- r0: u32 head_index; 链表头节点索引 (0 = 空链表); [1..139]; 节点池 0x0201d9c0 stride 8 字节, 下一已知 EWRAM 结构 0x0201e2a0, 池区间 0x8e0 字节最多 140 个节点 (index 0 保留), 故上界 139; FUN_0802e95c 分配器从索引 1 开始扫描 (asm:42544-42559)
- r1: u16 value; 要匹配的 [node+0] 字段值 (card_id 或 effect_code)
- r2: u8 zone_type; 要匹配的 [node+2] 低 4 位区域类型 [0..5]
- 返回: r0 = u32* 节点指针 (匹配节点地址) 或 0 (未找到)

## 副作用
无 (只读链式节点池 0x0201d9c0)
