## plate comment (中文, ASCII 标点)
同侧玩家装备槽类型不匹配谓词. 在装备目标候选选择中作为负向过滤条件使用: 返回 1 表示该槽位的卡牌类型"不"与装备卡期望的类型相符 (即可能作为装备目标). 执行流: (1) 读取 card_entry byte[+2] bit0 = card_owner; 若 player_id != card_owner 跳到正常检测; (2) 若 player_id == card_owner 且 slot_idx == 10 (特殊槽), 直接返回 0 (拒绝); (3) 区域表 is_present 检测; (4) card zone_word bits[9:2] (level 字段) 和 bit18 (type_subtype) 提取并合成比较值; (5) 与 card_entry[+4] u16 的 bits[14:8] (type 比较字) 对比: 两值相等 (类型已匹配) -> 返回 0; 不相等 -> 返回 1 (类型不同, 可作目标).

Inputs: r0 = ptr equip_card_entry, r1 = player_id [0..1], r2 = slot_idx [0..10]
Outputs: r0 = 1 if slot card type does NOT match equip card type, 0 otherwise
Side effects: none
Constants: SLOT_SPECIAL=10 (0xa, 特殊槽拒绝值), PLAYER_BLOCK=0x868, ZONE_BASE=0x0201c510, SLOT_STRIDE=20
