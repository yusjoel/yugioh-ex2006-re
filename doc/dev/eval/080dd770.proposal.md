- **confidence**: high

## plate comment (中文, ASCII 标点)
将遮罩 overlay 对象渲染为分块 OAM sprite 序列 (支持多行多列).
入参打包了 x/y 位置, 宽高, tile_base 和 palette 信息;
函数解包参数, 从 0x09e49558 tile 帧表查找合适的 POT 级别,
逐行逐列调用 write_oam_entry_from_packed_args 写入 OAM 属性.
被多个 pack/scene 相关渲染函数调用.

Constants:
- 0x09e49558: overlay tile frame 数据表 (ROM)
- 0x0000ffff: empty tile sentinel

## 参数签名

- r1: u32 packed_wh = (height << 16) | width  (tile 宽高, 各 16-bit)
- r2: u32 packed_attrs = (palette << 16) | tile_base  (OAM 属性)

## 副作用
