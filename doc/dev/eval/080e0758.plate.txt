Creates the pack purchase confirmation text overlay. Reads pack_ui_state+0xc+0x1a bit0/bit1 for the current purchase flags and selects the matching game string (str_id=0x138a confirm / 0x138b already-purchased / 0x138d price format). If bit1 is set, additionally reads price data from 0x02035eb0 and calls expand_format_decimal_width_to_buf to format the price into a stack buffer. Calls text_overlay_create at position (0x1e, 0x14) to display the text. Clears bit4 of the pack_ui_state+0x9a*2 (OAM enable byte), calls tick_pack_oam_slots_and_overlay(2), and writes pack_ui_state+0x4 := 0x13 (confirmation overlay display state). Returns fixed 1. indeg=0.
