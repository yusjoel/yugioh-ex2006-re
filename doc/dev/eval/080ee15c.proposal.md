# Naming Proposal: 0x080ee15c

## 提案
- **proposed_name**: upload_sprite_tiles_to_obj_vram_with_pal
- **confidence**: high

## plate comment (中文, ASCII 标点)
将 sprite tile 数据上传到 OBJ tile VRAM (0x06004000), 并写入带调色板混合的 OAM 属性. 入口保存 r10->r7->r9->r6->r8->r5; r3 保存到 r12 (.hword 0x469c). 对 sprite frame 描述结构两次调用 copy_bytes_by_halfword 上传 tile 数据. 然后遍历 sprite 帧的 attr1 数组: 若 attr1 高字节非零则将调色板索引 r6<<8 OR 入 halfword; 若低字节非零则加 r6. 写入到 OBJ VRAM 0xc0000000 (0xc0<<0x13) + tile_slot*2 区域. 被 FUN_080e6264 (scene_pack 相关) 独占调用.

Constants:
- OBJ_TILE_VRAM_BASE = 0x06004000 (DAT_080ee25c)
- VRAM_SECONDARY_BASE = 0x06000000 (0xc0<<0x13)
- PAL_MASK = 0xff00 (0xff<<8)
- TILE_SLOT_STRIDE = 0x40 (r3*32 byte offset for tile slot)
- OAM_ATTR_MASK = 0x0fff (DAT_080ee260)

## 参数签名
- r0: u16 tile_x 精灵 X 坐标 (截断到低 16 位)
- r1: u16 tile_y 精灵 Y 坐标 (截断到低 16 位, 保存到 r6)
- r2: void* pFrameDesc 精灵帧描述结构指针
- r3: u32 tile_slot OBJ tile 槽索引 (r3*32 = tile 偏移, 保存到 r12)
- 返回: r0 = u16 最终 attr1 halfword 值

## 副作用
- [OBJ_TILE_VRAM_BASE + tile_slot*32 ..]: 写入 tile 像素数据 (via copy_bytes_by_halfword)
- [0x06000000 + tile_x*2 + offset ..]: 写入带调色板合并的 tile attr halfword (strh 循环)
