## plate comment (中文, ASCII 标点)
注册为 SIO 中断回调 (地址 0x080ef535 存储于 [0x030003a0+0x042c], 由 init_sio_connection 写入). 每次 SIO 传输完成中断触发时被调用: 读取 SIODATA32 (0x04000120/0x04000124) 双字到 IWRAM 缓冲区 [0x030003a0+0x07a4], 验证帧头为 0xfefe, 若帧序号 [base-0xb8] > 9 则置 IWRAM 状态字为 -3, 更新轮次计数; 否则将两个玩家的卡牌槽位 (10 轮) 半字写入对应 IWRAM 偏移, 处理第 9 轮时额外拷贝卡牌 ID 和状态; 末尾更新帧序号并有条件停止 TM3 定时器/再触发 SIO.

Constants:
- SIO_STATE_BASE=0x030003a0 // IWRAM SIO 连接状态结构基址
- RECV_BUF_OFF=0x07a4 // 接收数据缓冲区偏移
- SIODATA32=0x04000120 // 串行数据寄存器基址
- FRAME_MAGIC=0xfefe // 合法帧头标识
- MAX_ROUNDS=0x9 // 最多 10 轮 (0..9) 数据交换
