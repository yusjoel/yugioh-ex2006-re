## plate comment (中文, ASCII 标点)
从打包的 OAM 控制字 (r0, 16 bit halfword) 中拆解 player_flag / x_coord / y_coord, 再根据 zone_type (低 4 bit, [0..0xf]) 跳表分派, 计算并返回对应区域数据结构的指针. 入口首先将 r0 零扩展为 16 bit (lsls/lsrs #0x10), 提取 bit7 为 player_flag ([0..1], r4), 低 7 bit 为 x_coord ([0..0x7f], r3), bits[14:8] & 0x7f 为 y_coord ([0..0x7f], r5). 随后读取 zone_type (r3 & 0xf) 并进行 16 路跳表分派: zone_type [0..4] 为普通怪兽区 (case_0: gPrng + 0x1cd0 * player + zone_slot_offset); zone_type [5..0xa] 为魔陷区 (case_5: 0x0201c600 + player*0x868 + slot_offset); zone_type 0xb 为装备区 (case_b: 0x0201c740 + player*0x868); zone_type 0xc/0xd/0xe/0xf 为字段区 (含 get_zone_slot_ptr 调用或直接偏移计算). 最终 r0 = 目标区域数据结构指针. Constants: x_mask=0x7f, y_mask=0x7f, player_flag_mask=0x80, zone_type_max=0xf, player_stride=0x868.
