check_equip_slot_eligible_neo_daedalus_with_state12_loop

Equip slot eligibility predicate. Three-stage check.
Stage 1: count_monster_slots_by_state_all(player_id, 0x12) -- if count == 0 -> return 0.
Stage 2: check_field_spell_neo_daedalus_group_placeable(player_id) -- if 0 -> return 0.
Stage 3: Loop over gP1LifePoints[player*0x868+0xc] slot count; for each slot calls
dispatch_effect_handler_by_card_id(player_id, slot.card_id, slot_idx).
Returns 1 if any dispatch call returns nonzero; if all fail returns 0.

Constants:
  SLOT_STATE_12 = 0x12 -- state_filter for count_monster_slots_by_state_all
  PLAYER_STRIDE = 0x868 -- per-player struct stride in gP1LifePoints
  SLOT_COUNT_OFFSET = 0xc -- slot count field offset in gP1LifePoints (+0xc word)

Inputs:  r0=SlotPtr* slot_ptr (byte[+2] bit0=player_id [0..1])
Returns: r0=u32 (1 if state12 exists AND neo_daedalus_ok AND any dispatch nonzero)
Callees: count_monster_slots_by_state_all, check_field_spell_neo_daedalus_group_placeable,
         dispatch_effect_handler_by_card_id
