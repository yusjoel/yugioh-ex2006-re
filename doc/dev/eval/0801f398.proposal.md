- **confidence**: high

## plate comment (中文, ASCII 标注)
由 FUN_08027f00 (campaign sprite 行构建函数) 和 FUN_08028194 (同类 campaign sprite 构建函数) 在构建 campaign row sprite 前检查 SIO 通信状态时调用. 读取 SIOCNT (0x04000128) 的 bits[5:4] (掩码 0x30), 若任一位被置 (SIO 忙/通信进行中) 则返回 r0=0 (未就绪); 若两位均清零 (SIO 空闲) 则返回 r0=1 (就绪). 用于在 campaign 界面刷新 sprite 前判断通信链路是否空闲, 防止在 SIO 传输中途更新显示数据.

Constants:
- SIOCNT = 0x04000128 (GBA SIO 控制寄存器)
- LINK_BUSY_MASK = 0x30 (bits[5:4]: bit4=start/busy, bit5=SIO mode select)
- READY = 1 (两位均清零 => 链路空闲)
- BUSY = 0 (任一位置 => 链路忙)

## 参数签名
- r0: (入口 movs r2,#0x0 -> ldr r0 覆盖 r0) 无 APCS 输入参数, void
- 返回: r0 = u32 link_ready (1=SIOCNT bits[5:4] 均为 0 => 链路空闲, 0=忙)
