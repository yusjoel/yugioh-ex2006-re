## plate comment (中文, ASCII 标点)
将包店卡牌 tile 行数据(扩展字段)以多行模式写入 OBJ VRAM 并视需要复制调色板. 触发条件: 唯一 caller FUN_080d50e4 (scene_pack) 在包店主页初始化时先调用本函数写 tile, 再批量初始化 AOB ctx. r0=card_slot_index(VRAM 偏移 slot*32), r1=sprite_attr(palette slot), r2 来自 pack_ui_state. 函数从 0x09ce822c+0x1c 取 ROM tile ptr, 以 write_tile_rows_to_vram_by_mode(r0=VRAM_dest, r1=tile_ptr, r2=8_cols, r3=6_rows, [sp]=0x10_rows) 写多行 tile; 若 r1<=0xf 再 DMA 复制调色板.

Constants:
- OBJ_VRAM_BASE = 0x06010000
- ROM_TILE_TABLE = 0x09ce822c (偏移 +0x1c = 第五字段)
- ROM_PAL_TABLE = 0x09ce824c (偏移 +0x1c)
- OBJ_PAL_BASE = 0x05000200
- MODE_ROWS_SP = 0x10 (stack 参数 row_count_mode)
- TILE_COLS = 8; TILE_ROWS = 6
- PAL_LIMIT = 0xf

## 参数签名
- r0: u16 tile_id_base [0..N] (tile 基准 ID, VRAM 偏移 = tile_id_base*32; caller 传入如 0xe4<<1=0x1c8)
- r1: u8 pal_slot_index [0..0xf] (OBJ palette slot 索引; >0xf 跳过调色板; caller 传 0xe)
- 返回: void (pop {r0}; bx r0)

## 副作用
- [0x06010000+r0*0x20..]: 写 ROM tile 行数据 (via write_tile_rows_to_vram_by_mode)
- [0x05000200+r1*0x20..+0x20]: 写调色板 (via copy_memory_dma3_with_cpu_fallback, 仅 r1<=0xf)
