Function: Effect-slot type_code branch state machine driving OAM refresh for type_code=1/2/3. State 0x80: branch by type_code -- type_code==2 takes single-path check_effect_slot_matches_zone_entry(0,0,0); type_code==1 or 3 takes dual-path checking zone_entry 0 and 1, on success reads both-side side/type, sets type_code=1->3, calls invoke_effect_node_with_active_flag_3arg twice (side0 and side1), check_value_in_slot_chain, find_first_available_monster_slot_for_player, update_equip_bitmap_with_cross_side_flag, enqueue_zone_slot_sprite_attr_by_card_type, then invoke_setup_equip_oam_with_attr2 or write_card_display_index_with_bit_offset. State 0x7f: checks gBase+0x4a8 count; if non-zero retrieves slot idx from gBase+0x4a4 then calls enqueue_sprite_attr_with_mode(mode=2). Success path returns 0x7f; failure/skip path returns 0.

Constants:
- DISPLAY_STATE_BASE=0x0201b290 -- display state machine base address
- DISPLAY_STATE_OFFSET=0x94*8=0x4a0 -- state field offset
- SLOT_CHAIN_ARG=0x00000fb6 -- third arg to check_value_in_slot_chain
- SLOT_FIELD_OFFSET=0x000004a4 -- gBase+0x4a4, equip iteration target slot
- SLOT_COUNT_OFFSET=0x000004a8 -- gBase+0x4a8, placeable slot count
- PLAYER_STRIDE=0x868 -- per-player data stride
- gDuelFieldSlots=0x0201c510 -- duel field slot base address
- gEffectContext=0x0201e2a0 -- effect context base address

Side effects:
- [0x0201b290+0x4a0] type_code field modified via strh (@ 08074dfa)
- [0x0201b290+0x4a4] := check_value_in_slot_chain result (target slot chain value, @ 08074e34/08074ed8)
- [0x0201b290+0x4a8] := find_first_available_monster_slot_for_player result (@ 08074e44/08074ee8)
- sprite attr queue: enqueue_zone_slot_sprite_attr_by_card_type / setup_equip_oam_entry_with_sprite_attr
- sprite attr queue: enqueue_sprite_attr_with_mode(mode=2, @ 08074f58)
