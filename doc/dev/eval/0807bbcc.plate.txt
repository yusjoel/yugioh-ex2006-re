Effect node LP display sequence state machine. Reads state code from LP_STATE_BASE=0x0201b290 + 0x94*8=0x4a0. State 0x80: calls dispatch_equip_draw_counter_sprite_tick(node) to update draw counter sprite, returns 0x7f (advance state). State 0x7f: reads LP value from gP1LifePoints + player*0x868 + 0xc; if nonzero calls set_lp_row_type6_with_value(player, card_id) to set LP row display, returns 0x7e; if LP is zero returns 0. State 0x7e: reads card_id from gP1LifePoints+0x1da8, calls enqueue_face_down_slot_sprite_attr(player, card_id, 0) to enqueue face-down slot sprite. All other states return 0. Called via function pointer table (Sub-type B, appears at 0x09e42710/0x09e44288).

Constants:
- LP_STATE_BASE=0x0201b290 (DAT_0807bbe8)
- STATE_OFFSET=0x94*8=0x4a0 (movs r2,#0x94; lsls r2,r2,#3)
- STATE_ACTIVE=0x80 (dispatch draw counter)
- STATE_LP_CHECK=0x7f (LP value check)
- STATE_FACE_DOWN=0x7e (face-down sprite)
- LP_CARD_OFF=0x1da8 (gP1LifePoints + 0x1da8, DAT_0807bc44)
- LP_COL_OFF=0xc (gP1LifePoints + player*0x868 + 0xc)
- PLAYER_STRIDE=0x868 (DAT_0807bc20)
