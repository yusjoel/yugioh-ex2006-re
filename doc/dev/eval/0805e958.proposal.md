## plate comment (中文, ASCII 标点)
激活判定谓词. 入参为卡槽指针 r0 (入口 adds r1,r0,#0 覆盖 r1, 非独立参数).
检查 flags +0x3 byte 的 bits[5:4] (mask 0x30) 是否等于 0x20 (面朝下标志);
若不是则返回 0. 提取 player_id (flags +0x2 bit0) 和 card_id (+0x0 halfword), zone_id=0xb.
调用 get_node_entity_id_in_slot 获取节点实体 ID; 若 < 0 则返回 0.
右移 1 位后调用 find_zone_descriptor_by_slot_id. 从描述符提取 zone_type (byte1 [bits[15:8]]);
检查 zone_type==0xf. 读取 gP1LifePoints + player_id*0x868 + 0xf1<<3 + zone_offset 偏移字节;
若该字节 == 0x40 则返回 1, 否则返回 0.
出口为 pop{r4}; pop{r1}; bx r1.

Inputs: r0 = card_slot_ptr (卡槽指针)
Outputs: r0 = 1 (面朝下 + 描述符区类型==0xf + 字节==0x40) / 0 (不满足)
Side effects: 无外部写入.
Constants: FACEDOWN_FLAG_MASK=0x30, FACEDOWN_FLAG_VALUE=0x20, ZONE_TYPE_TARGET=0xf, EQUIP_BYTE_ZONE_ID=0xb, EQUIP_BYTE_OFFSET=0x788 (0xf1<<3), EQUIP_ACTIVE_VALUE=0x40, PLAYER_STRUCT_STRIDE=0x868
