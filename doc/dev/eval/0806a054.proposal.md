## plate comment (中文, ASCII 标点)
依据卡牌 ID 区间分派装备槽精灵更新操作. 接收效果槽节点指针 (r5=r0) 和第二槽指针 (r2=r1). 首先将第二槽指针 [r2+4] bit2 置位 (guard_bit set, 标记已处理). 然后读取 card_id=[r5,#0] (halfword) 与多个特定卡 ID 比较进行分派: 0x12f7 路径调用 query_equip_target_bitmap_default; 0x12f5 路径调用 enqueue_field_slot_sprite_with_state_update, 再调用 tick_zone_sprite_pipeline_with_update_flag; 0x12f6 路径类似; 0x131c 路径调用 query_equip_zone_bitmap_with_active_flag 并调用 query_equip_target_bitmap_default; 0x162a 路径调用 enqueue_field_slot_sprite_with_state_update 并调用 tick_zone_sprite_pipeline_with_update_flag. 所有路径末尾均返回 0.

Constants:
- CARD_ID_A=0x12f7 (not in data.md; equip bitmap target card)
- CARD_ID_B=0x12f5 (0x12f7-2; field slot card variant A)
- CARD_ID_C=0x12f6 (0x12f7-1; field slot card variant B)
- CARD_ID_D=0x131c (reserved -- cid=0xFFFF, no card assigned; confirmed eval/0805c818+08067fa4)
- CARD_ID_E=0x162a (not in data.md; field slot card variant C)
- GUARD_BIT=0x4 (bit2 of [r2+4] flags byte, set on entry)

## 参数签名
- r0: ptr effect_slot_node_a (第一效果槽节点, [r0,#0]=card_id, [r0,#2] bit0=player_id, [r0,#4] flags)
- r1: ptr effect_slot_node_b (第二效果槽节点, [r1,#2]=player_side, [r1,#4] flags)
- 返回: r0 = 0 (固定返回 0)
