Second-layer BG tilemap renderer for the pack scroll list; symmetric sibling of
render_pack_scroll_list_tilemap (0x080e7cd4).
r0=reset_flag [0..1], r1=row_count_ptr.
First calls setup_pack_blend_callback.
Loop r4=0..deck_count-1: skip if r4==r6 (current slot).
  Computes delta = [+9] - r4 (uses byte 0x9 vs 0x8 in primary version).
  Queries ANIM_TABLE; calls write_scroll_list_tilemap_row_alt(r4, tile_calc, 2)
  with tile_calc including bits[6:4] from [0xb].
After loop (r7!=0 = decrement): reads [+9]; if 0, sets [+0xe] bit0 and returns 1;
  otherwise [+9]-=1.
After loop (r7==0 = increment): [+9]+=1; if >= deck_count+7 returns 1.
Called by FUN_080e7e0c (pack main scene switch dispatcher).

Constants:
  ANIM_TABLE    = 0x09e5ee14  (row animation tile attr table, shared with primary version)
  COUNTER_OFF   = 0x9         (gMenuState[0x9] second-layer animation counter)
  MAX_DELTA     = 7           (maximum table offset)
  TILE_ROW_BITS = [0xb] bits[6:4]  (determines row animation tile)

Inputs: r0=u32 reset_flag [0..1], r1=ptr row_count_ptr.
Returns: r0=u32 (1=animation complete; 0=still in progress; pop {r1}; bx r1).
Side effects: updates gMenuState[0x9] counter and [0xe] bit0;
              writes second-layer tile attributes via write_scroll_list_tilemap_row_alt.
