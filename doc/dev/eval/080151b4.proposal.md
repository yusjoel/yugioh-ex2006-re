## plate comment (中文, ASCII 标点)
由 alloc_palette_entry_slot (0x080151d8, palette 标签) 唯一调用, 负责在 EWRAM 调色板管理表中建立 slot_idx <-> palette_entry 的双向映射. 基地址 0x02023490: slot_record 数组位于 +0x800 偏移 (每项 1 字节), palette_map 数组位于 +0x880 偏移. 操作: 将 palette_map[palette_entry] 的旧值保存到 slot_record[slot_idx], 再将 slot_idx 写入 palette_map[palette_entry], 实现"占用槽位"的原子记录.

Constants: PALETTE_SLOT_RECORD=0x02023C90 / PALETTE_MAP=0x02023D10.

## 参数签名
- r0: u8 slot_idx -- 分配的调色板槽位索引 [0..127] (slot_record 数组大小 0x80 = 128 项)
- r1: u8 palette_entry -- 调色板条目 ID [0..31] (palette_map 数组大小 0x20 = 32 项, 对应 0x880..0x8a0)
- 返回: 无返回值 (仅副作用)

## 副作用
- [0x02023490 + 0x800 + slot_idx] := 旧 palette_map[palette_entry] (保存旧占用者)
- [0x02023490 + 0x880 + palette_entry] := slot_idx (记录新占用 slot)
