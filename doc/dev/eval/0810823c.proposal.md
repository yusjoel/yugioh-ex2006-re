# Naming Proposal: 0810823c

## 提案
- **proposed_name**: render_card_name_glyph_to_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
由 FUN_08107bdc (card_stats/font_jp 场景帧渲染函数) 在 [0x0202f3c0+0x1f] bit4 置位时调用, 负责将卡牌名称字形写入 sprite VRAM. 函数从 IWRAM 0x0202a4d0[+4] 读取 card_list_field 索引, 调用 read_card_list_field_by_index 获取卡片数量/类型字段 (r7); 若 r7<=0 则写入空字形后返回. 若 r7>0, 检查 IWRAM [0x02006c2c] bit[2:0] 决定字符集 (0->通用路径: resolve_card_gfx_pointer_by_type 取卡名字节串, char_code_to_glyph_index 转编码, lookup_sjis_font_index_by_char 转字形索引; 非0->select_charset_then_load_name 另取名称). 最终将字形索引拆分为高/低字节写入目标 VRAM 地址, 并通过 switch(r7-2) 分发不同卡片类型的后续 tile 操作.

## 参数签名
- 参数: 无 (void)
  - asm 0810823c: ldr r0, DAT_08108288 在入口立即加载常量覆盖 r0, 确认无输入参数
- 返回: r0 = int, 结果 (调用方不检查)

## 副作用
- [VRAM 0x0600xxxx + 偏移]: strb 写入字形高/低字节 (通过 r1 计算偏移)
- [VRAM 目标 + 2]: strb 写 0x00 (字形结束标志)
