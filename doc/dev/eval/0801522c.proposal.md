## plate comment (中文, ASCII 标点)
被多个场景 tick 调用 (indeg=6), 包括 tick_demo_scene_state_machine, name_input_page_tick, demo_shuen_state_machine 等. 功能为从 EWRAM sprite attr 数据区 (0x02023490+0x880) 读取最多 32 个精灵属性条目 (每条 8 字节), 写入 EWRAM OAM 缓冲区 (0x02023490+slot*8); 空 slot (sentinel=-1) 终止列. 最终调用 bios_cpu_fast_set 将未用 slot 的 OAM VRAM (0x07000000) 清零. 所有操作目标地址均由函数内部从 DAT_080152ac (0x02023490) 计算, 无外部 caller-set 参数. 副作用: 写 EWRAM OAM 缓冲 (0x02023490+) + bios_cpu_fast_set 清零 OAM VRAM (0x07000000).

## 参数签名
- 无外部参数 (void): r12/r8/r9/r10 均为函数内部计算值, 非 caller-set 参数
  - r12: 内部加载 DAT_080152ac=0x02023490 (EWRAM OAM 缓冲基址); 见 @ 08015236-08015238: ldr r0,DAT_080152ac; .hword 0x4684 (mov r12,r0)
  - r8_new: 内部计算 0x02023490+0x400 (r8 在 @ 08015240: .hword 0x4690 = mov r8,r2 被覆盖)
  - r9_new: 内部计算 -1 (sentinel); @ 0801524e-08015250: rsbs r2,r2,#0; .hword 0x4691 = mov r9,r2
  - r10_new: 内部计算 0x02023490+0x880; @ 08015246-0801524a: add r0,r12; .hword 0x4682 = mov r10,r0
- 返回: 无返回值 (void)

## 副作用
