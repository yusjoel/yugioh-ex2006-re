## plate comment (中文, ASCII 标点)
装备槽激活显示状态机的分发入口. 接收效果槽节点指针 (r0), 检查 guard_bit ([r0+4] bit2); 若置位则跳过. 读取 [0x0201b290+0x94*8] 处全局激活显示状态码, 根据状态码 0x80 / 0x7f 选择不同路径: 状态 0x80 时先调用 check_activation_display_state_is_confirmed, 若已确认则继续处理 -- 提取 zone/slot 坐标, 计算精灵偏移, 依次调用 enqueue_equip_slot_sprite_with_display_code (code=0xb), enqueue_sprite_attr_for_slot_indicator, enqueue_sprite_attr_with_type_select; 若未确认返回 0x80. 状态 0x7f 时调用 trigger_card_display_op31_if_not_active (op=0xf4) 并调用 init_zone_activation_display_fields, 返回 0x7f. 其余状态直接返回 0.

Constants:
- GUARD_BIT=0x4 (bit2 of flags byte [+4])
- STATE_DISPLAY_BASE=0x0201b290 (global display state IWRAM base)
- STATE_IDX_OFFSET=0x94*8=0x4a0 (display_state field offset)
- GPLP_BASE=gP1LifePoints (0x0201c4e0, player LP struct)
- SLOT_STRIDE=0x868 (per-player stride)
- EQUIP_SLOT_ARRAY_OFF=0x30 (base offset for equip slot array in LP struct)
- SPRITE_CODE=0xb (equip slot sprite type code)
- OP31_ARG=0xf4 (trigger_card_display_op31 argument)
- STATE_0x80=0x80 (activation confirmed, awaiting sprite commit)
- STATE_0x7f=0x7f (activation triggered, display init pending)
