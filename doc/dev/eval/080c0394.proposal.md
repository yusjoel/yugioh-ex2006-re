# Naming Proposal: 0x080c0394

## 提案
- **proposed_name**: copy_card_frame_nibbles_to_palette_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
将卡片边框的 nibble tile 数据按调色板偏移复制到 OBJ/BG VRAM. 调用方为 FUN_080c05b4 (card_image/card_stats/font_jp 渲染场景), 传入卡片属性结构指针 r2, 根据类型字段 (r1 >> 11 得 type_offset) 选取 DAT_080c03e8 (0x06010000 BG VRAM base) 或 DAT_080c03ec (0x05000200 调色板 VRAM) 作为写入目标, 然后调用 copy_bytes_by_halfword 完成字节拷贝. 末尾 `b LAB_080c0598` 为跳回外层状态机的尾跳.

Constants:
- 0x06010000 = BG tile VRAM base
- 0x05000200 = BG 调色板 VRAM base (偏移 0x200)
- r1 >> 11 = type 字段偏移 (选择调色板组)

## 参数签名
- r0: u16 tile_col -- tile 列起始坐标 [0..0x1ff] (BG tile map 宽 512 tiles)
- r1: u16 packed_type_y -- bits[10:0]=Y 坐标 [0..0x3ff], bits[15:11]=type 索引 [0..0x1f] (选 VRAM 写目标), 入口 lsls r1,r1,#0x10
- r2: ptr card_attr_struct* -- 卡片属性结构指针 (ldrh [r2,#0] = 结构首字段, 提供 tile 索引)
- 返回: void (尾跳 b LAB_080c0598, 无独立 r0 写入)

## 副作用
- [DAT_080c03e8 + type_offset] 或 [DAT_080c03ec + tile_idx*0x20]: 写 nibble tile 数据 (通过 copy_bytes_by_halfword)

## 行级注释 (精华)
- @ 080c039c: push + sub sp,#8 -- 本地栈 8 字节
- @ 080c03a2: lsls/lsrs r0 提取低 16 位 tile 列坐标
- @ 080c03a6: mov r8,r0 -- callee-save 保存 tile 列 (APCS r0 别名)
- @ 080c03aa: ldrh r0,[r2,#0] -- 读卡片属性结构首字 (tile 索引)
- @ 080c03bc: lsrs r1,r1,#0xb -- type 字段右移 11 位得索引
- @ 080c03be: ldr r7,DAT_080c03e8 -- 0x06010000 BG VRAM base
- @ 080c03c2: ba46 -> mov r10,r7 (保存 VRAM base)
- @ 080c03de: bl copy_bytes_by_halfword -- 按 halfword 拷贝 nibble 数据
- @ 080c03e4: b LAB_080c0598 -- 尾跳回外层状态机

## 调用图
- caller: addr 0x080c05b4 (tags: palette/card_image/card_stats/font_jp, role: 按 card_type 条件分支调用, r0=0xd0 r1=0x1c2 传入)
- callee: copy_bytes_by_halfword

## 置信度证据
- 层 IO 寄存器: DAT_080c03e8=0x06010000 (BG VRAM), DAT_080c03ec=0x05000200 (palette VRAM); 两路写入目标均为 GBA VRAM 地址段
- 层 callee: copy_bytes_by_halfword 为 nibble/tile 数据复制专用工具
- 层 caller: FUN_080c05b4 在 cmp r5,#0x16/0x17 (卡片类型判断) 后按分支调用, r2=DAT_080c0614 或 DAT_080c0688 两路地址
- 层 尾跳: `b LAB_080c0598` 是 dispatcher 状态机的 fall-through, 无独立返回值
