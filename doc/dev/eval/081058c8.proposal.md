# Naming Proposal: 0x081058c8

## 提案
- **proposed_name**: build_palette_row_to_obj_pal_slot
- **confidence**: med

## plate comment (中文, ASCII 标点)
按照当前动画帧计数器 0x0202f3c0[+0x28] 的相位, 为 card_list 场景构建一行调色板数据并写入 OBJ 调色板 slot 0x05000360. 对计数器值 [0xb..0xe] 范围内的每个颜色索引 (0..14), 由 0x09e31754 表查出基准 RGB565 颜色, 按计数器偏移量调整亮度后写入临时缓冲区; 越界索引直接透传原始颜色. 最后调用 copy_bytes_by_halfword 将 16 色 (0x20 字节) 写入 OBJ PAL 0x05000360, 帧计数器加 1 模 0x20 后写回. 被 caller 0x08105520 (display/window/bg/frame_counter) 每帧调用, 实现卡框调色板闪烁动画.

## 参数签名
- r0: (无入参, 内部从 0x0202f3c0[+0x28] 读帧计数器)
- r3: ptr 目标调色板写入指针 (由 caller 通过 r3 传入, 指向 sp 临时缓冲区)
- 返回: r0 = u32 1

## 副作用
- [OBJ PAL 0x05000360]: 写 0x20 字节 (16 色 RGB565)
- [0x0202f3c0+0x28] := (prev+1) % 0x20 (调色板动画帧计数器)
