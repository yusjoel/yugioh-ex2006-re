## plate comment (中文, ASCII 标点)
Function: 针对卡 ID 0x146f 或 0x1907 (配对卡组) 的装备槽资格检查. 先验证 owner_bit 与 equip_card.side[bit0] 相等且 slot_idx [0..4] 未越界, 再读取 equip card 的 card_id (ldrh [r0+0x0]). 若 card_id == 0x146f, 进入 0x1414 区域 chain_field 比较路径; 若 card_id == 0x1907, 进入 0x0000 区域 chain_field 比较路径. 两路均读取对应 zone 的 chain_field bits 并与常量 (pool DAT 0xa3d00000 / 0xc5500000) 比对; 相等则返回 1, 否则返回 0.

Side effects: 无外部写入.

Constants: SLOT_IDX_MAX=4, ZONE_BASE=0x0201c510, STRIDE=0x868, CARD_ID_A=0x146f (Cathedral of Nobles), CARD_ID_B=0x1907 (Transcendent Wings), MATCH_MASK_A=0xa3d00000, MATCH_MASK_B=0xc5500000.

## 参数签名

- r1: u8 owner_bit [0..1]
- r2: u8 slot_idx [0..4]
- 返回: r0 = u32 eligible (0=不合格, 1=合格)
