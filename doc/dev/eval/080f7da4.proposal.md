## plate comment (中文, ASCII 标点)
来自 system/s_opdobj.c. 给定一个 AOB 上下文指针 (r0),图案段指针 (r1) 和模式参数 (r2), 先将上下文结构体前 0x14 字节清零 (zero_fill_halfword_wrapper), 写入图案段指针到 [r0+0x0], 然后从 r2 中分离高 16 位 (tile 数量 -> [r0+0x10]) 与低 4 位 (图案模式 -> [r0+0x12] bit[3:0]), 检测图案数量是否大于 0x10 以决定 [r0+0x12] bit7 (大图案 flag), 并将 flag bit6 ([r0+0x12] bit6, init_flag) 写入. 最后调用 resolve_aob_pattern_entry_ptr 以索引 0 初始化当前图案指针. 被 14 个调用方共享, 是 AOB 对象生命周期的初始化入口.

Constants:
- AOB_CTX_SIZE_HALF = 0x14 (zero-fill 字节数, 10 halfword)
- AOB_LARGE_TILE_THRESHOLD = 0x10 (图案数量超此值设 large_tile flag)
- AOB_FLAG_LARGE = 0x80 (bit7 of [ctx+0x12])
- AOB_FLAG_INIT = 0x40 (bit6 of [ctx+0x12], r8 bit0 驱动)

## 参数签名
- r0: AOB_CTX* ctx_ptr -- AOB 对象上下文指针 (将被初始化)
- r1: void* p_ptnsect -- 图案段数据指针, 写入 [ctx+0x0]
- r2: u32 mode_param -- 复合参数: bits[31:16] = tile_count (写入 [ctx+0x10]), bits[3:0] = ptn_mode (写入 [ctx+0x12] bits[3:0])
- r3: u8 init_flag [0..1] -- 写入 [ctx+0x12] bit6 (AOB_FLAG_INIT)
- 返回: void (pop+bx)

## 副作用
- [r0+0x0] := p_ptnsect
- [r0+0x10] := tile_count (r2 >> 16)
- [r0+0x12] := ptn_mode | (large_tile_flag ? 0x80 : 0) | (init_flag ? 0x40 : 0)
- [r0+0xe] := 1 (帧计步器默认值)
- [r0+0x4] := 通过 resolve_aob_pattern_entry_ptr(ctx, 0) 设置
