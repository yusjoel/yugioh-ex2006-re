## plate comment (中文)
name_input 页面文字渲染的薄包装函数。由 name_input 页面渲染子树的两个上层函数调用：addr 0x08017b44（tags: game_str;name_input，场景文字行列渲染，调用 3 次）和 addr 0x08018774（tags: font_jp;name_input，当前被选中字符高亮显示，调用 1 次）；两者均尚未命名，通过 name_input EWRAM 缓冲区 0x02029250 + FUN_08018400 计算 vram_row 后压栈传入本函数；本函数先调 `setup_font_jp_ctx_obj_vram_row` 配置 JP 字体渲染上下文（目标 VRAM OBJ 行 + 图层模式），再以硬编码的模式参数（r1=1, r2=1, r3=7, arg5=8, arg6=0x80）调 `dispatch_text_render_by_mode`，将字符串渲染到 VRAM OBJ 瓦片（精灵层）。0x80 模式对应 dispatch 内的 JP 8 行字形 OBJ 渲染路径。

## 参数签名
- r0: `ptr` str_ptr — 指向游戏字符串的起始地址（由调用方从 `game_str_pointer_table` 或 name_input EWRAM 缓冲区解出）
- r1: `u16` x_pos — 屏幕 x 像素起始坐标（转发给 `setup_font_jp_ctx_obj_vram_row` 的 r0）
- r2: `u8` col_width — 字形列宽控制，调用方传 6（FUN_08017b44）或 0x11（FUN_08018774）
- r3: `u8` layer_mode — 图层控制标志，调用方均传 2（转发给 `setup_font_jp_ctx_obj_vram_row` 的 r2）
- `[sp+0]`（第 5 参数）: `u16` vram_row — VRAM OBJ 行基址偏移，由调用方预先调 `FUN_08018400` 计算后压栈
- 返回: r0 = void（无返回，仅副作用）

## 副作用
- 通过 `setup_font_jp_ctx_obj_vram_row` 写 `[0x02006ed0+0x15]`（font_jp 渲染上下文 mode_flags 字节，OR 写入 0x20 位，设置 OBJ 目标标志）
- 通过 `setup_font_jp_ctx_obj_vram_row` 写 `[0x02006ed0+0x8]`（font_jp 渲染上下文图层字段，按 layer_mode bit0 更新 bits 1:0）
- 通过 `setup_font_jp_ctx_obj_vram_row` 写 `[0x02006ed0+0x4]`（font_jp 渲染上下文 VRAM 行指针，从 `font_jp_base_table` 按图层/模式查表写入）
- 通过 `dispatch_text_render_by_mode` → `text_render_wrapper` 写 VRAM OBJ 瓦片区（0x06010000 基址，由 `setup_font_jp_ctx_obj_vram_row` 配置好的行偏移处）；写入 JP 字形像素数据
