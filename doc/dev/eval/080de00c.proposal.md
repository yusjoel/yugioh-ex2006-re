# Naming Proposal: 0x080de00c

- **confidence**: high

## plate comment (中文, ASCII 标点)
按槽索引 (0/1/2) 将牌包调色板数据从 ROM 复制到 BG 调色板 VRAM.
r0 为槽索引 [0..2], 超范围截断到 2;
按 slot*0x20 计算目标 BG 调色板 VRAM 偏移 (0x05000200 + slot*0x20),
从 0x09cebf30 表取 32 字节调色板, 调 copy_memory_dma3_with_cpu_fallback 写入;
再从 0x05000202+slot*0x20 调 copy_memory_dma3_with_cpu_fallback 复制 0x10 字节附属数据 (来自 0x09ccd292).
被主菜单/场景初始化在切换牌包展示时调用 (movs r0,#0/1/2 + bl 三连).

Constants:
- 0x05000200: GBA BG 调色板区起始 (pack slot 0)
- 0x09cebf30: pack 调色板数据表 (ROM, 每槽 0x20 字节)
- 0x05000202: 附属数据目标 (pack slot 0, +2 偏移)
- 0x09ccd292: 附属调色板/属性数据 (ROM, 0x10 字节)
- 0x20: 每个调色板槽大小 (32 bytes = 16 色 * 2 字节)
- 0x10: 附属数据大小 (16 bytes)

## 参数签名
- r0: u8 slot_index 牌包槽索引 [0..2] (超范围截断到 2)
- 返回: r0 = void (pop {r0}; bx r0 透传 lr; 函数末尾 pop {r4}; pop {r0}; bx r0)

## 副作用

- [0x05000202 + slot*0x20 .. +0x10]: := 附属数据 (copy 16 bytes from 0x09ccd292)
