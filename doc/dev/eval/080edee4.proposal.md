## plate comment (中文, ASCII 标点)
清零 BG2 tile VRAM 中指定行的数据. r0=row_index, r1=tile_width (halfword 数). 入口 lsls r0,r0,#0x10; lsrs r0,r0,#0xb 将 row_index 转换为字节偏移 (row * 0x800 >> 0xb = row * 0x20, 即每行 0x20 halfwords = 32 halfwords = 64 bytes 的行步). 加基址 0x06004000 (BG2 tile VRAM 区) 得到目标地址, 再以 r1 为 halfword 数调用 zero_fill_by_halfword. 是 zero_fill_bg_vram_row_range (0x080edea4) 的内层单行清零原语.

Constants:
- BG2_VRAM_BASE = 0x06004000 (DWORD_080edefc)
- ROW_STRIDE_SHIFT = 0x10 - 0xb = 0x15 (lsls 0x10 再 lsrs 0xb => row*0x20 bytes)

## 参数签名
- r0: u16 row_index - BG tile 行索引 [0..31] (GBA BG tile map 标准: 32 行 per screen, row*0x20 bytes per row)
- r1: u16 tile_width - 要清零的 halfword 数 [0..32] (GBA tile row 宽度上界: 30 tiles 显示宽度 + 2 buffer = 32 max)
- 返回: r0 = void (pop {r0}; bx r0)

## 副作用
- [0x06004000 + row_index*0x20 .. +tile_width*2]: := 0

## 行级注释 (<=30 行精华)
