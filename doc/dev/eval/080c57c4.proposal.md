## plate comment (中文, ASCII 标点)
根据卡片所在 zone (player_id r5, zone_type r1, zone_idx r2) 及当前卡片显示状态 (0x0201ff30 结构, +0x26/+0x28/+0x2a 字段) 计算 OAM 精确坐标, 写入 0x0201e2a0 相关缓存后通过循环检查激活位图. 由 FUN_080c6240/FUN_080c6268/FUN_080c6490 三个 wrapper 调用 (深度 8). 函数先调用 FUN_080c35ac 获取 zone 基础坐标; 再读 ctx+0x28 (card_type [1/3/5]) 按类型选 y 偏移 (±0x18 或 ±0x2a); 检查 ctx+0x8 的帧 tile 字段计算 x 偏移; 然后对激活 mask 中的每个 bit 位进行循环 (最多 11 个 bit), 逐 slot 计算最终 OAM 坐标并准备写入.

Constants:
- 0x02023130 = 卡片显示 ctx base (DAT_080c5810)
- 0x0201ff30 = 另一个卡片 ctx (DAT_080c5880/080c590c)
- 0x0201e2a0 = duel global ctx (DAT_080c583c)
- 0x2a = ctx 内 counter 字节偏移
- 0xb = zone 类型 (cmp r1,#0xb, 特殊分支)
- 0xf0/0x27/0x28 = y 坐标 clamp 边界
- 0x4c = DAT_0x02023130 内 card_type 偏移
