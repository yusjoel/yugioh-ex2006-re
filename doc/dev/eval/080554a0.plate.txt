Equip slot predicate dispatch function. Part of the check_equip_slot_eligible_* cluster. Reads card_entry[+2] bit0 to extract the player-side flag: if opposite side, calls check_equip_slot_eligible_by_cross_player_and_field6_zero; if same side, calls check_equip_slot_eligible_by_card_id_bst_special_cases. Both paths dispatch via bit0 and return the corresponding predicate result. Return mechanism: pop{r1}; bx r1.

Constants:
- SIDE_BIT=[+2].bit0

Inputs: r0=ptr equip_card_entry, r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..4]
Returns: r0 = bool (1=condition met; 0=not met)

Side effects:
- No external writes
