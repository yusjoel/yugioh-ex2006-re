## plate comment (中文, ASCII 标点)
装备槽类型资格验证谓词 (无槽位范围守卫版). 与同家族其他检查函数不同, 本函数不执行 slot_idx <= 4 的范围检查, 直接进入区域表查询. 主要流程: (1) 读取区域表中该 player/slot 的 is_present 位; (2) 若卡牌存在, 从 card word[0] 提取 level (bits[9:2]) 和 type_subtype_bit (bit[18]); (3) 将二者合成一个比较值并与 card_entry[+4] 的 halfword[+4] 的 level 字段比对; (4) 相等则说明已有相同类型卡牌占据此槽, 调用 query_slot_card_type_eligibility 再次确认类型兼容; (5) 兼容时返回 1, 不兼容返回 0.

Inputs: r0 = ptr equip_card_entry, r1 = player_id [0..1], r2 = slot_idx (unchecked)
Outputs: r0 = 1 if slot type is eligible, 0 otherwise
Side effects: none
Constants: PLAYER_BLOCK=0x868, ZONE_BASE=0x0201c510, SLOT_STRIDE=20

## 参数签名
- r0: ptr equip_card_entry (reads [+4]=packed_level_type u16)
- r1: u32 player_id [0..1]
- r2: u32 slot_idx (no upper bound enforced)
- 返回: r0 = u32 (1=type eligible, 0=ineligible)
