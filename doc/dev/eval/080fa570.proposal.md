## plate comment (中文, ASCII 标点)
tick 函数, 注册为 EWRAM 0x0202a7d0 区域动画条目的回调 (由 FUN_080fa7e4 caseD_0 通过 FUN_080edd90 注册, fn_ptr=0x080fa571). 每次调用检查 [0x02029eb0+0xe] bit0: 若已置位则跳过 (防重入); 否则置位 bit0 (进入中), 调用 dequeue_prng_anim_entry([ctx+0x12]) 取下一动画帧序号存入 [ctx+0x10], 检查 gPrng+0x1c0+0x584 处字节 bit0: 若 bit0=1 则清 bit1 (非双字节模式) 并退出. 若序号不为 0 则进入按 magic=0x5731/0x5733 的两路分支: 0x5731 -> 置位 [ctx+0x0] bit0; 0x5733 -> 同上并追加 copy_memory_dma3_with_cpu_fallback 拷贝动画帧数据. 最终清 bit1([ctx+0xe]). 由函数指针间接调用, callgraph indeg=0.

- 返回: void (pop {r4,r5,r6,r7}; pop {r0}; bx r0 - r0=lr, void)

## 副作用

- DMA 拷贝: magic=0x5733 时 copy_memory_dma3_with_cpu_fallback 写 8 bytes 帧数据
