## plate comment (中文, ASCII 标点)
渲染单张卡片完整显示区域, 包括卡图/名称/ATK-DEF 标签和类型图标. 由 play_ui_effect_33/34 触发 (blend/window/palette/card_image/card_stats/font_jp 场景). 流程: (1) 从 card_stats_table 按 card_id*11 读取属性字段; (2) 调用 render_card_image_to_vram 渲染卡图 (r1=0x246 目标 VRAM tile 偏移); (3) 按 card_type (r5) 分支: 类型 0x16/0x17 写专用边框 nibble tile, 类型 1..0x14 写标准 ATK/DEF nibble tile 行; (4) 调用 draw_card_name_to_bg_tile_vram 和 draw_card_atkdef_label_to_vram 写文字标签; (5) resolve_card_type_icon_ptr + copy_bytes_by_halfword 写类型图标.

Constants:
- 0x246 = render_card_image_to_vram 目标 tile offset (DAT_080c0610)
- 0x1c2 * 2 = 0x384 = type nibble 目标 tile offset (r1=0xe1 << 1)
- 0xb = card_stats_table 每条目字段数 (stride 11 words)
- 0x16/0x17 = card_type (融合/仪式卡边框特例)
- 0x050003a0/0x050003c0 = BG 调色板 VRAM base

## 参数签名
- r0: u16 card_id -- 卡片 ID [0..max_card-1], 用于索引 card_stats_table
- 返回: void (无返回值, 仅 VRAM 副作用)

## 副作用
- [BG VRAM 0x06010000 + 0x246*N]: 写卡图像素 (render_card_image_to_vram)

- [BG tile map]: draw_card_name_to_bg_tile_vram / draw_card_atkdef_label_to_vram
