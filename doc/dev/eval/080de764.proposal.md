# Naming Proposal: 0x080de764

## plate comment (中文, ASCII 标点)
将卡包卡片缩略图网格渲染到 OBJ VRAM. 接收 4 个参数 (r0=数据源指针, r1=打包坐标对1, r2=打包坐标对2, r3=步长计数). 函数先调用 zero_fill_halfword_wrapper 清空目标 VRAM 缓冲区, 然后以二维循环遍历卡片格, 从 EWRAM 卡数据 (0x0200af20) 读取每张卡的 tile 标识, 通过 OBJ VRAM 0x06008040 区域写入图块数据. 循环外层按行 (r2 高 16 位为行数), 内层按列 (r1 高 16 位为列数).

Constants:
- EWRAM_CARD_GRID = 0x0200af20 (EWRAM 卡片网格数据起始)
- OBJ_VRAM_GRID = 0x06008040 (OBJ VRAM 卡片网格写入区)

## 参数签名
- r0: void* data_src_ptr -- 卡数据源指针
- r1: u32 packed_xy1 -- 打包坐标对: lo16=x1, hi16=row_count [packed]
- r2: u32 packed_xy2 -- 打包坐标对: lo16=x2 (->) r10, hi16=col_stride -> sp[0]
- r3: u32 step_count -- 步长/列计数 -> r4
- 返回: void (pop {r0}; bx r0 Pattern B -- epilogue 于 080de914-080de916; pop {r0} 覆盖 bl 返回值后 bx r0, callee r0 丢失)

## 副作用
- [VRAM OBJ 0x06008040..]: 写入卡片缩略图 tile 数据 (二维网格区域)
- [EWRAM 0x0200af20..]: 读取但不写入

## 行级注释 (<=30 行精华)
- @ 080de764: push + 多个 .hword 0x46xx -- 保存 r7..r10 到 callee-save 槽
- @ 080de770: adds r5,r0,#0 -- r5=数据源指针
- @ 080de772: adds r4,r3,#0 -- r4=step_count
- @ 080de774: lsls/lsrs r0,r2,#16 -> r10=lo16(r2); lsrs r2,r2,#16 -> sp[0]=hi16(r2)
- @ 080de77e: lsls/lsrs r0,r1,#16 -> sp[4]=lo16(r1); lsrs r1,r1,#16 -> sp[8]=hi16(r1)
- @ 080de79a: bl zero_fill_halfword_wrapper -- 清空目标 OBJ VRAM 区域
- @ 080de7c8: 二维循环: 外层按行, 内层按格读取 EWRAM 卡数据并写入 VRAM
