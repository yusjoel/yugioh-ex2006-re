# Naming Proposal: 0x080f5e00

## 提案
- **proposed_name**: advance_lcg_rand_state
- **confidence**: high

## plate comment
执行一步 MSVC/ANSI C rand() 线性同余生成器 (LCG) 迭代: next = prev * 214013 + 2531011. 返回高 16 位 XOR 低 16 位. 具体: r0 = r0 * 0x343fd + 0x269ec3, 然后 r0 = ((r0 >> 16) | (addend_lo << 16)) = 高低半字拼接后零扩展. 由 FUN_080ef35c (0x080ef35c) 调用作 PRNG 包装器.

Side effects: 无外部写入; 纯算术.

Constants:
- LCG_MULTIPLIER = 0x343fd // 214013 (MSVC rand() 乘数)
- LCG_ADDEND = 0x269ec3 // 2531011 (MSVC rand() 加数)

## 参数签名
- r0: u32 prev_state 上一 LCG 状态值
- 返回: r0 = u32 下一 LCG 状态 (高 16 位 OR 加数低 16 位)
