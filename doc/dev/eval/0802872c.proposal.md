## 提案

- **confidence**: high

## plate comment (中文, ASCII 标点)
Function: 根据 r0 标志选择两种卡包图块加载路径, 并初始化调色板标志位. r0==0 时: 加载 pack tile set B (0x09ba050c, 0x30 tiles, 2bpp mode 0x4e) 到 VRAM 0xc00 和 pack tile set C (0x09b9fa20, 0x20 tiles, 0x2) 到 VRAM 0x800; r0!=0 时: 仅加载 pack tile set A (0x09b9e6e8, 0x10 tiles, mode 0x2) 到 VRAM 0xc00. 两条路径汇合后: copy_bytes_by_halfword 从 ROM 0x09b9e6c8 复制 0x20 halfwords 到 PAL_RAM 0x05000220; tile_2d_row_copy 从 ROM 0x09b9c6c8 复制 0x20x8 行到 VRAM 0x06010000; 设置 0x02023360+0x36 byte bit0 (调色板初始化标志). 出口 pop {r0}; bx r0 (Sub-case E, void).

Side effects:
- VRAM tile offset 0xc00 (或 0x800): pack tile data 写入 (via load_pack_tile_and_map_to_vram)
- PAL_RAM 0x05000220: 0x20 halfwords (64 bytes) palette copy
- VRAM 0x06010000: 0x20x8 = 0x100 行 tile 2D copy
- [0x02023360+0x36] bit0 := 1 (palette init flag)

Constants:
- VRAM_TILE_BASE_C = 0xc00 (0xc0<<4, OBJ tile index)
- VRAM_TILE_BASE_B = 0x800 (0x80<<4)
- PACK_TILES_A = 0x09b9e6e8 (r0!=0 path: 16 tiles, mode 2)
- PACK_TILES_B = 0x09ba050c (r0==0 path: 48 tiles, mode 0x4e)
- PACK_TILES_C = 0x09b9fa20 (r0==0 path: 32 tiles, mode 2)
- PACK_PAL_SRC = 0x09b9e6c8 // palette data source (32 halfwords)
- PAL_RAM_DEST = 0x05000220
- VRAM_BG_BASE = 0x06010000
- PAL_INIT_FLAG_OFFSET = 0x36 // [0x02023360+0x36] bit0

## 参数签名
- r0: u32 tile_set_selector -- 0=加载完整 tile set B+C; 非零=仅加载 tile set A [0..1]
- 返回: void (pop {r0}; bx r0, Sub-case E)

## 副作用
- VRAM: load_pack_tile_and_map_to_vram x1 或 x2 写入
- PAL_RAM 0x05000220: 64 bytes palette
- VRAM 0x06010000: tile_2d_row_copy 写入
- [0x02023360+0x36] |= 0x1 (palette init flag set)
