# Naming Proposal: 0x08045268

## 提案
- **proposed_name**: enqueue_sprite_attr_with_shape
- **confidence**: high

## plate comment (中文, ASCII 标点)
根据 r0 选择 OAM shape attr 后调用 enqueue_sprite_attr_record, 将 r3 拆分为 x/y 坐标传入.
r0==0: attr=0x3a (单精灵 shape A); r0!=0: attr=DAT_08045294=0x803a (扩展 shape B).
r1 (u8 after lsls/lsrs 0x18): OAM 附加字段 (type 或 palette 低字节), 与 0x100 (=0x80<<1) 合并后作为 r1 入队.
r2 和 r3: r3 高 16 位为 y_pos, 低 16 位为 x_pos, 经 lsls/lsrs 拆分后分别传入 enqueue_sprite_attr_record 的 r2/r3.
8 个 caller 含 FUN_0804559c (duel_field), FUN_0808e45c/FUN_0808e770/FUN_0808e85c (批次内/duel_field).

Constants: ATTR_SHAPE_A=0x3a, ATTR_SHAPE_B=0x803a (DAT_08045294), TYPE_FLAG=0x100 (=0x80<<1).

## 参数签名
- r0: u32 shape_mode - 0=attr=0x3a, non-0=attr=0x803a
- r1: u8 type_byte [0..0xff] - OAM type 字节, lsls/lsrs 截断后与 0x100 合并
- r3: u32 xy_packed - 高 16 位=y_pos [0..0x1ff], 低 16 位=x_pos [0..0x3ff]
- 返回: r0 = void (透传 enqueue_sprite_attr_record)

注: r2 不是 APCS 输入参数. 函数入口 `adds r3,r2,#0` 仅将 r2 保存到 r3 作 xy_packed 暂存, 随后 @0804527a `movs r2,#0x80 / lsls r2,#0x1` 立即将 r2 覆盖为内部常量 TYPE_FLAG=0x100. caller 传入的 r2 值不被本函数读取消费, 属 entry-instruction-param-clobber 模式.

## 副作用
- 通过 enqueue_sprite_attr_record (0x0803bd2c) 写 OAM 缓冲
