## plate comment (中文, ASCII 标点)
对给定场地槽 (r0=player_id, r1=slot_idx, r2=extra, r3=side_flag) 执行装备激活并更新精灵显示. 读取槽卡 id (bits[12:0]), 检查 slot_idx<=4 及激活标志非零; 构建 OAM attr 字 (以多个位掩码 0xfffffdff/0xffffc3ff/0xffffbfff/0xffff7fff/0xfffffe00/0xfffeffff/0xfffdffff 清除旧位后 OR 写入新 slot/player/flip 位); 调用 enqueue_sprite_attr_record 写入 OAM 缓冲. 按 side_flag 决定是否调用 set_field_slot_bit_with_sprite_update (r3=1); 随后针对特定 card_id (0x1005/0x1048/0x101e/0x1197/0x1868) 调用 apply_equip_activation_with_id_lookup 执行效果; 若有 LP 变化则调用 submit_lp_bar_sprite_row_by_type. 返回 1 = 成功, 0 = 未处理.

## 参数签名
- r0: u8 player_id [0..1] (归属方, 入口 .hword 0x4680=mov r8,r0 保存)
- r1: u8 slot_idx [0..4] (场地槽索引)
- r2: u16 extra_field (附加字段, 写入 sp[0x0])
- r3: u8 side_flag [0..1] (是否触发 set_field_slot_bit)
- 返回: r0 = u8 result (1=激活成功, 0=未处理)

## 副作用
- enqueue_sprite_attr_record: 写入 OAM 精灵 attr 缓冲
- set_field_slot_bit_with_sprite_update: 设置场地槽激活位并更新精灵 (slot=r1,type=0x15,val=1)
- apply_equip_activation_with_id_lookup: 执行装备效果激活 (写卡链记录)
- submit_lp_bar_sprite_row_by_type: 更新 LP 条精灵行 (type=9 或 0xb)
