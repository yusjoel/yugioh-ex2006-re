# Naming Proposal: 0x0804db50

## 提案
- **proposed_name**: dispatch_sprite_row_queue_by_state
- **confidence**: high

## plate comment (中文, ASCII 标点)
按精灵行队列的当前状态码 (读自 gSpriteRowBase+0x49c) 派发到对应的子处理函数. 入口先根据当前读指针 (base+0x480) 计算行数 stride, 若 stride >= 2 则构建尾部写地址并存入栈. 然后读取状态码 [base+0x49c]: 若 > 0x67 则调用 clear_sprite_row_queue_overflow_flag; 否则用状态码作为 index 跳转 dispatch 表 PTR_DAT_0804dbb8 (index 0..7 = 8 个具体处理函数, index 8..0x67 均指向 clear_sprite_row_queue_overflow_flag). 调用方 FUN_0804f2e0 (card_frame/duel_field) 在每帧处理时调用本函数. 副作用: 依状态派发的子函数可能修改 gSpriteRowBase 内部多个字段.

Constants:
- gSpriteRowBase = 0x0201b290
- read_ptr_offset = 0x90<<3 = 0x480
- state_code_offset = 0xba<<2 = 0x2e8 (row calc base)
- dispatch_limit = 0x67 (超出则调用 overflow handler)

## 参数签名
- r0..r3: (无 APCS 入参 -- 函数体首先从字面量池加载 gSpriteRowBase, 无读取 r0-r3)
- 返回: r0 = u32 passthrough, 两条路径:
  (a) state_code > 0x67 (asm:105662 @ 0804db9c bl FUN_0804f0c2): 来自 clear_sprite_row_queue_overflow_flag, 固定返回 1 (已清除溢出标志)
  (b) state_code in [0..7] (asm:105664-105667 @ 0804dba0 dispatch 表跳转): 来自对应 index 子处理函数的返回值, 各子函数含义独立 (0=busy/1=done 等)

## 副作用
- 依派发目标子函数而定; 可能修改 gSpriteRowBase 内多个状态字段

## 行级注释 (<=30 行精华)
