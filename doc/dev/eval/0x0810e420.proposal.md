# Naming Proposal: 0x0810e420

## 提案
- **proposed_name**: copy_bytes_with_waitcnt_rom_stub
- **confidence**: high

## plate comment (中文, ASCII 标点)
ROM 中与 copy_bytes_with_waitcnt (0x0810e460) 完全同构的字节拷贝存根, 由 init_sram_stubs_in_iwram (0x0810e4ec) 将其机器码从 ROM 地址 0x0810e421 复制到 IWRAM 0x030056f8 后在 IWRAM 中执行. 执行逻辑: 先将 WAITCNT (0x04000204) bits[1:0] 置 3 (SRAM 8 等待周期), 再逐字节将 r0(src) 中 r2(count) 字节复制到 r1(dst). SRAM 要求 8-bit 访问, WAITCNT 设置保证总线时序正确. 本函数本身无直接调用者; 其地址作为 ROM 源数据由 init_sram_stubs_in_iwram 引用.

Constants:
- WAITCNT=0x04000204 (等待状态控制寄存器)
- SRAM_WAIT_MASK=0x0000fffc (bits[1:0] 清零掩码)
- SRAM_WAIT_8CYCLES=0x3 (8 等待周期)

## 参数签名
- r0: ptr<u8> src 源字节地址 (EWRAM/ROM)
- r1: ptr<u8> dst 目标字节地址 (SRAM 0x0E000000 范围)
- r2: u32 count 字节数
- 返回: void (pop {r0}; bx r0 -> 无独立 r0 写)

## 副作用
- [WAITCNT 0x04000204]: bits[1:0] := 0x3 (SRAM 8 等待周期)
- [r1..r1+count-1]: 按字节写入 src 内容 (SRAM 写入)
