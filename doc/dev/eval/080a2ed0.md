## 修改清单

### #1 — R4 (高优先级)
**位置**: proposal 参数签名节 "返回:" 行
**问题**: "r0 = int32 (0=advance, 1=done)" 后缀 "-> void r0" 矛盾; 出口 pop{r1};bx r1 Sub-case E 不 void r0
**当前**: `返回: r0 = int32 (0=advance, 1=done; 出口 pop{r4,r5,r6,r7}; pop{r1}; bx r1 -> void r0)`
**应改为**: `返回: r0 = i32 (0=step 推进继续, 1=序列完成; 出口 pop{r4,r5,r6,r7}; pop{r1}; bx r1)`

### #2 — R6 (高优先级)
**位置**: proposal Constants 节

```

```
**应改为**:
