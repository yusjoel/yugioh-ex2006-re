## plate comment (中文, ASCII 标点)

- ROWS=2 // 2 行 (外层循环)
- ROW_GAP=0x2e // 行末指针跳过量 (字节)
- PAL_SHIFT=12 // 调色板索引位于 attr2 bit[15:12]
