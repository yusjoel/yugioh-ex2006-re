# Naming Proposal: 0x0801e6f4

## 提案
- **proposed_name**: open_card_info_page_from_list
- **confidence**: high

## plate comment (中文, ASCII 标点)
被 card_list 场景两个调度器 (FUN_080c64b8 state=0 分支, FUN_080d2c60 state=0 分支) 调用, 当玩家在卡牌列表界面选中一张卡时触发向卡片信息页面的转场. 函数先将调用方传入的 card_id (r0) 和 origin_page (r1=0) 零扩展到 u16, 再调用 card_list_on_select_to_info_page 执行主要的页面切换逻辑; 随后对 EWRAM card_info 场景状态结构体 [0x0201afb0]+0 的 byte 置位 bit2 (0x4), 标记"信息页面转场已激活". 两个调用方在此函数返回后均立即对另一状态字节再置位 bit4 (0x10), 完成双重激活握手.

Constants:
- 0x4: [0x0201afb0+0x0] bit2 = card_info_page_active_flag

## 参数签名
- r0: u16 card_id [0..N-1] -- 选中卡的卡片 ID, 低 16 位有效 (高位被零扩展掉)
- r1: u16 origin_page [0..0] -- 来源页面标识; 两个调用方均传 0 (card_list 主页)
- r2: ptr -- 卡牌名/描述字符串缓冲区基址 (0x0203eeb0), 透传给 card_list_on_select_to_info_page
- r3: ptr -- 辅助数据缓冲区基址 (0x02029eb0), 透传给 card_list_on_select_to_info_page
- 返回: 无返回值 (void); 函数末尾 pop {r0}; bx r0 为 THUMB 返回惯用法, r0 无语义

## 副作用
- [0x0201afb0+0x0] |= 0x4 -- card_info 场景 flag byte bit2 置位, 标记转场已激活
