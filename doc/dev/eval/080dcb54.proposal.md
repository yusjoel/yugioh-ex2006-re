# Naming Proposal: 0x080dcb54

## 提案
- **proposed_name**: load_overlay_bg_tiles_to_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
将文本遮罩对话框的 BG tile 数据从 ROM 复制到 VRAM, 配置 BG 显示参数.
入参 r0=(height<<16)|width 定义对话框尺寸, 从 gPrng+0x1d0 取当前遮罩对象指针;
读取对象中的 BG 字段和 BGxCNT 寄存器确定目标 tile/map 基址,
调用多次 copy_memory_dma3_with_cpu_fallback 将 tile 行写入 VRAM,
最后用 zero_fill_halfword_wrapper 清空边界.
由 text_overlay_create 和 FUN_080dd464 调用, 是遮罩 BG 初始化阶段.

Constants:
- gPrng+0x1d0 (=gPrng+0xe8*2): 当前遮罩对象指针 (IWRAM overlay struct ptr)
- 0x09cede5c: overlay BG tile 源数据表基址 (ROM)
- BG0CNT (0x04000008): BG0 控制寄存器
- 0xc0000000 (movs r2,#0xc0; lsl #0x13): VRAM OBJ tile 区基址 mask
- 0x000003ff: DAT_080dcd78 tilemap entry count (1023 tiles)

## 参数签名
- r0: u32 packed_size = (height << 16) | width, 对话框尺寸 [width 0..0xffff, height 0..0xffff]
- 返回: void (pop {r0}; bx r0 -> 无独立 r0 写, 透传 lr)

## 副作用
- [VRAM 0x060x...]: BG tile 数据写入 (多块 0x20 字节 DMA 复制)
- [BG VRAM tilemap]: 按行写 tile 属性 halfword (strh r0,[r7,#0x0] 循环)
- [VRAM +0x20 at end]: zero_fill_halfword_wrapper 清 0x20 halfwords
