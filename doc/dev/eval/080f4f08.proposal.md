# Naming Proposal: 0x080f4f08

## 提案
- **proposed_name**: copy_memory_dma3_with_cpu_fallback
- **confidence**: high

## plate comment (中文)
向目标地址复制 byte_count 字节，根据 gPrng+0x174 的模式控制位选择传输后端：bit12 置位时退化为 CPU halfword 循环 (copy_bytes_by_halfword)，bit13 置位时调用 BIOS CpuSet 字对齐拷贝，否则使用 DMA3 以 1024 字节 (0x200 halfword) 为块分多次触发，等待 DMA_ENABLE 位清零后继续下一块，尾余 (<= 0x3ff 字节) 由最后一次 DMA3 搬完。由 decode_card_image_6bpp (addr 0x0801d290) 及多个 scene_pack/card_image 场景调用，是游戏 VRAM/EWRAM 大块数据搬运的统一入口。

## 参数签名
- r0: ptr dst  目标地址 (VRAM/EWRAM/PALRAM 均可)
- r1: ptr src  源地址 (通常 ROM 0x08xxxxxx)
- r2: u32 byte_count  字节数 (任意大小；内部对 0x400 取模分块)
- 返回: void (无返回值，仅副作用)

## 副作用
- [DMA3SAD (0x040000d4)] := src (DMA 源地址)
- [DMA3DAD (0x040000d8)] := dst (DMA 目标地址)
- [DMA3CNT_L+H (0x040000dc)] := 0x80000200 (DMA3 使能 + 0x200 halfword count，触发传输)；每块传输后轮询 DMA3CNT_H bit15 等待完成
- 目标地址区间写入 src 数据

## 行级注释 (精华)
- @ 080f4f0e: 读 gPrng+0x174 (copy-mode 控制字)，bit12=CPU_halfword 模式，bit13=BIOS_CpuSet 模式
- @ 080f4f18: bit12 检测：0x80<<5=0x1000；置位则走 copy_bytes_by_halfword 软路径
- @ 080f4f30: bit13 检测：0x80<<6=0x2000；置位则 bios_cpu_set 字对齐拷贝
- @ 080f4f4c: 进入 DMA3 路径；DAT_080f4fc0=0x3ff 为单块阈值 (1023 字节上限)
- @ 080f4f60: str r1,[r3] <- DMA3SAD=src；str r5,[r3+4] <- DMA3DAD=dst
- @ 080f4f66: str r2,[r3+8] <- DMA3CNT=0x80000200 触发 512-halfword 块传输
- @ 080f4f70: 检查 DMA3CNT_H bit31 (0x80000000) 等待首次触发响应
- @ 080f4f76: 轮询等待 DMA3CNT_H bit31 清零 (DMA 完成)
- @ 080f4f7e: 每次循环 r4-=0x400 (剩余字节)，r5/r1+=0x400 (指针步进)
- @ 080f4f90: 尾块处理：count=ceil(r4/2) halfwords | DMA3CNT_H=0x8000 仅 enable
- @ 080f4fb2: 轮询等待尾块 DMA 完成

## 调用图
- 调用方 (caller):
  - `decode_card_image_6bpp` (addr 0x0801d290, tags: vram;card_image) — 卡图解码后搬运 tile 到 VRAM
  - addr 0x0801d15c (tags: 无, 待命名) — 调用 1 次，与 card_image 同模块上下文
  - addr 0x080d45fc (tags: scene_pack) — pack 场景数据搬运
  - addr 0x080d4d1c (tags: vram;palette;scene_pack) — pack 场景调色板搬运
  - addr 0x080d566c (tags: bg;palette;blend;card_image;font_jp 等) — 综合场景初始化
- 调用 (callee):
  - `copy_bytes_by_halfword` — CPU 软拷贝后备
  - `bios_cpu_set` — BIOS 字对齐拷贝后备
  - DMA3 硬件寄存器直操

- high: 层 2 (IO 寄存器簇: DMA3SAD/DAD/CNT_L/H 直操)；层 3 (调用已命名 callee copy_bytes_by_halfword + bios_cpu_set)；层 6 (调用方 decode_card_image_6bpp 语义明确，gPrng+0x174 模式字两个 bit 分支完整可读)
