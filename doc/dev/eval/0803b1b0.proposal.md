## plate comment (中文, ASCII 标点)

Constants:
- 0x0201c510 = gDuelFieldSlots
- 0x868 = player stride
- slot_entry = 20 bytes
- 0x18c7 / 0x19ef = 特殊效果卡牌 ID 白名单 (两张卡触发扩展掩码路径)
- 0x78 = 0b01111000 (zone 标志位组合, 位 3..6 置 1)
