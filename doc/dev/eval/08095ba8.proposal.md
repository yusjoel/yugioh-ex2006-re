## plate comment (中文, ASCII 标点)
初始化装备卡 (equip card) 的 OAM sprite row 条目.
从 [gP1LifePoints+0x1d68] 读 player_bit (r5), [+0x1d6c] 读基础 slot_a, [+0x1d70] 读 slot_b, 计算合并 slot_idx = slot_a + slot_b.
使用 player_stride=0x868 * (player_bit & 1) + slot_idx * 0x14 定位 gDuelFieldSlots 条目.
若 slot[+0x38] halfword 为 0 (槽未渲染), 调 enqueue_zone_card_sprite_attr_by_slot (FUN_0804394c) 并跳过 OAM init.
若 slot[+0x38] 非零: 构建 OAM attr0 word (合并 player_bit/r7 位掩码 + slot_idx 高位 + [gP1LifePoints+0x1d44]/[+0x1d48] 辅助 halfword) 并调 init_card_sprite_row_entry_alt;
或走备用路径 (slot 比较失败时) 使用不同 attr3 word 调 init_card_sprite_row_entry.
末尾清零 [gP1LifePoints+0x1d54] (pending state flag).
触发条件: FUN_0804ce78 (card_frame+card_name) 和 FUN_08085d4c (card_frame) 在装备卡显示序列中调用.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, slot_stride=0x14, slot_rendered_offset=0x38, gP1LifePoints offsets 0x1d44/0x1d48/0x1d54/0x1d64/0x1d68/0x1d6c/0x1d70.
