## plate comment (中文, ASCII 标点)
扫描格式字符串并将 `%c` (0x25 0x63) 转义序列替换为对应卡牌名称后写入输出缓冲区. 逐字节读取 r1=fmt_str 中的字节: 若遇到 0x25 0x63 (`%c`) 转义符, 读取随后 3 个十进制字符 (BCD 累算: acc = acc*11 - 0x30 + digit, [0..0x3e7]), 调用 internal_card_id_to_card_id 转换为游戏内部 card_id, 再读取 gSettings 低 3 bit (charset [0..7]) 作为字符集选择器, 调用 select_charset_then_load_name(card_id, charset) 获取卡牌名称指针; 最后将 dst_buf 和剩余 fmt_str 分别通过 append_text_to_buf_end 追加到 dst_buf. 非 `%c` 字节直接逐字节复制到 dst_buf (strb/ldrb 循环). 终止条件: 遇到字节 0x00. 被 FUN_0802c358 (result_screen) / FUN_080e5ac8 / FUN_080e609c 三处调用. Constants: escape_marker=0x25, card_code_suffix=0x63, digit_base=0x30, bcd_multiplier=11, charset_mask=0x7.
