# Naming Proposal: 0810372c

## 提案
- **proposed_name**: copy_deck_slot_card_data
- **confidence**: med

## plate comment (中文, ASCII 标点)
由 FUN_081031a4 (deck slot 总调度函数) 以 r1=1 调用, 负责将指定 deck_type (r0=[0..3]) 对应的卡片数据复制到目标缓冲区. 函数从 IWRAM 0x0202a4d0 选取对应 deck_type 的源区偏移 (type0: +0x2b9c 或 +0x1a6c, type1: +0x3ecc 或 +0x3ccc, type2: +0x44cc 或 +0x42cc, type3: +0x4acc 或 +0x48cc), 根据 r1 标志决定使用哪个源指针, 然后调用 copy_bytes_by_halfword 复制 0x200 (0x80<<2=0x200) 字节卡片数据; 另有 type0 特殊路径复制 0x1130 字节. 用于在场景切换时刷新 deck slot 数据缓冲区.

## 参数签名
- r0: u8 deck_type (deck 类型索引 [0..3]: 0=主卡组, 1=融合, 2=魔法陷阱, 3=仪式)
- r1: u8 source_flag (0=使用 A 源指针, 非零=使用 B 源指针, 对应不同数据版本)
- 返回: r0 = u32 (1=成功)

## 副作用
- [IWRAM 0x0202a4d0 + dst_offset]: 写入 0x200 或 0x1130 字节卡片数据 (经 copy_bytes_by_halfword)
