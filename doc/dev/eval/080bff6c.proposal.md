# Naming Proposal: 0x080bff6c

## 提案
- **proposed_name**: render_card_image_to_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
从 ROM 卡图数据表按卡牌索引 (r0) 和 VRAM 目标槽位 (r1) 加载卡图 tile 和调色板到 VRAM. 先根据 r0/r1 计算卡图 tile 源指针 (card_image_tiles + stride*card_idx), 然后调用 repack_nibbles_with_palette_offset 批量转换调色板索引后写入 PAL RAM (0x05000200), 再将 tile 数据复制到 BG VRAM (0x060148c0 + slot_offset). 全程处理 11 组 tile 行 x (每行若干 halfword), 最终写完整张卡图的 tile 和 palette 数据到 VRAM.

Constants:
- card_image_tiles = ROM 卡图 tile 数据表基址 (PTR_card_image_tiles)
- card_image_index = ROM 卡图索引表 (PTR_card_image_index)
- card_image_palettes = ROM 卡图调色板表 (PTR_card_image_palettes)
- VRAM_CARD_TILE_BASE = 0x060148c0 (BG VRAM 卡图写入基址)
- PAL_RAM_BASE = 0x05000200 (PAL RAM 调色板写入基址)
- DISP_REG = 0x080000ae (ROM header / BIOS 相关地址, 用于 card_id 区分)
- EWRAM_CTX = 0x02000000 + 0x6c2c = 0x02006c2c (EWRAM 游戏上下文 + 偏移)
- TILE_ROW_HALFWORDS = 0x4f (每行 79 halfword)
- OUTER_LOOP_COUNT = 0xa (外层 11 行循环, cmp r3,#0xa)

## 参数签名
- r0: u16 card_idx [0..max_card_idx-1] -- 卡牌索引 (lsls/lsrs 截断 u16)
- r1: u16 vram_slot [0..max_slot-1] -- VRAM 目标槽位 (决定 tile/palette 写入偏移)
- r2: u16 palette_slot [0..max_palette-1] -- 调色板槽位 (lsls/lsrs 截断 u16; 用于计算 repack 偏移)
- 返回: void (pop 序列+bx)

## 副作用
- [PAL RAM 0x05000200 + slot_offset]: 写入卡图调色板 (copy_bytes_by_halfword, r2=0x80 halfword)
- [VRAM 0x060148c0 + slot_offset]: 写入卡图 tile 数据 (strh 批量, 11 行 x 0x4f halfword)
