Drives the per-frame logic for the pack card list scene. Reads pack_ui_state+0x24 as the parameter and calls dispatch_pack_card_list_scene to dispatch the scene frame; if the return value is 1 (step complete), writes pack_ui_state+0x10e := 0x14 (total animation frames) / pack_ui_state+0x10c := 0x14 (reset elapsed frames) / pack_ui_state+0x4 := 0x10 (new step ID). Then calls tick_pack_oam_slots_and_overlay(2) to drive OAM animation. Returns the result of dispatch_pack_card_list_scene (r5 passthrough). Used as a step function by the pack scene state machine; indeg=0.
