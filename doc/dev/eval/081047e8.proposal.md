# Naming Proposal: 0x081047e8

## 提案
- **proposed_name**: dispatch_card_list_scene_state
- **confidence**: high

## plate comment (中文, ASCII 标点)
card_list 场景主状态机分派函数. 读取 0x0202f3c0[+0x1f] bit7 判断场景是否激活; 若未激活则进入 LAB_08104a34 (animating counter 路径). 激活时检查 0x0202a4d0[+0x18] (s16 mode) 决定进入"新场景初始化"还是"已激活场景更新"两大路径. 初始化路径: 检查 gSave 是否为 pass_input/banlist 模式, 选择合适的 page_state_dispatcher 表 (0x09e52804 或 0x09e52804+0x6c), 调用 page_state_dispatcher 后按 flag 决定调用 setup_card_list_scene_bg_regs / reset_card_list_scroll_offset / write_vram_bg_tilemap_card_list / render_card_type_text_row_to_sprite 等完整初始化链. 更新路径: 基于 0x0202f3c0[+0x38] 的 sub_state 字段进行 16 路 switch 分派, 各 case 处理卡牌选择/滚动/确认/取消等交互. 被 FUN_08108940 / FUN_08108da4 / FUN_08108eec 3 个场景驱动调用.

## 参数签名
- r0: (无入参, 内部从全局加载所有状态)
- 返回: r0 = u32 0/1 (0=本帧未完成, 1=本帧完成/场景切换)

## 副作用
- [0x0202f3c0+0x1f]: 按需更新 mode 标志位
- [0x0202f3c0+0x22/0x24/0x26]: 游标/滚动偏移更新
- [0x0202f3c0+0x2c]: 动画计数器递增
- OAM/VRAM: 通过 callee 链间接更新
