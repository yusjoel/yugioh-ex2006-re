Uses [0x0201b290+0x4a0] display_state as dispatch key to drive equip slot LP bar display state machine.
state=0x80: zeros [0x0201b290+0x4a4] counter, calls increment_lp_bar_display_counter, returns 0x7f.
state=0x7f: reads slot_count from gP1LifePoints[player_id]+0x14, iterates backward through equip slot array (step=-4), calls check_card_field5_is_nonzero per slot; if a non-zero slot is found calls enqueue_equip_zone_sprite_by_slot_ptr and returns 0x7f; if all zero returns 0x78.
state=0x78: increments [0x0201b290+0x4a4] by 1; if new value <= 1 returns 0x7f, else calls decrement_lp_bar_display_counter and returns 0.
Other state: returns 0.
Dispatched via runtime function pointer (indeg=0).

- DISPLAY_STATE_OFFSET=0x4a0 (DAT_08077454 - 4)
- COUNTER_OFFSET=0x4a4 (DAT_08077454 = 0x4a0+4)
