# Naming Proposal: 0x080000c0

## 提案
- **proposed_name**: init_cpu_stacks_and_irq_vector
- **confidence**: high

## plate comment (中文, ASCII 标点)
GBA ROM 启动入口 (crt0). 硬件复位后 CPU 跳转至此. 13 条 ARM 指令完成初始化: cpsr=0x12 (IRQ mode) + SP_irq=0x03007e00; cpsr=0x1f (System mode) + SP_sys=0x03007800; 将 dispatch_thumb_isr_from_arm (DWORD_080000fc) 写入 BIOS 中断向量 [0x03007ffc]; mov lr,pc; bx run_game_main 启动游戏 (不返回). 末尾 b 为不可达安全死循环.

Constants:
- IRQ_MODE=0x12; SYS_MODE=0x1f
- SP_IRQ=0x03007e00; SP_SYS=0x03007800
- BIOS_IRQ_VECTOR=0x03007ffc; IRQ_BRIDGE=dispatch_thumb_isr_from_arm

## 参数签名
- r0: void (ARM 复位后寄存器无语义初值; 入口立即 mov r0,#0x12 覆盖)
- 返回: void (bx r1 @ 0x080000ec 以 mov lr,pc 返回地址调用 run_game_main; 正常路径不返回; 末尾 b FUN_080000c0 不可达死循环)

## 副作用
- cpsr := IRQ mode (0x12), 随后 := System mode (0x1f)
- SP_irq := 0x03007e00
- SP_sys := 0x03007800
- [0x03007ffc] := dispatch_thumb_isr_from_arm (BIOS IRQ 向量槽写入)

## 行级注释 (精华)
- @ 080000c0: mov r0,#0x12 -- 准备 IRQ 模式值 (bits[4:0]=0b10010)
- @ 080000c4: msr cpsr_cf,r0 -- 切换 CPU 到 IRQ 模式
- @ 080000c8: ldr sp,[DAT_080000f8=0x03007e00] -- 设 SP_irq (128-byte IRQ 栈顶)
- @ 080000cc: mov r0,#0x1f -- 准备 System 模式值 (bits[4:0]=0b11111)
- @ 080000d0: msr cpsr_cf,r0 -- 切换 CPU 到 System 模式
- @ 080000d4: ldr sp,[DAT_080000f4=0x03007800] -- 设 SP_sys (主栈顶)
- @ 080000d8: ldr r1,[DAT_0800022c=0x03007ffc] -- 取 BIOS IRQ 向量地址
- @ 080000dc: adr r0,DWORD_080000fc -- 取 ARM IRQ 桥 stub 地址
- @ 080000e0: str r0,[r1] -- 将桥 stub 写入 BIOS IRQ 向量
- @ 080000e4: ldr r1,[DAT_08000230=0x080f4d91] -- 取 run_game_main Thumb ptr
- @ 080000e8: mov lr,pc -- LR = 0x080000f0 (不返回路径的安全锚)
- @ 080000ec: bx r1 -- 跳入 run_game_main (Thumb), 游戏启动
- @ 080000f0: b FUN_080000c0 -- 不可达; run_game_main 不返回
