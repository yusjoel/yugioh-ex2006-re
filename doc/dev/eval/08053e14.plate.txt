Equip card eligibility predicate: type match + monster space + field effect block. No set_code filter. Guards: (1) check_slot_card_can_be_equipped(slot[+2]bit0, r1, r2); (2) query_slot_card_type_eligibility(r0,r1,r2) must return 0; (3) count_available_monster_slots(slot[+2]bit0) -- if >0 passes directly; if ==0: side must match r1 AND check_slot_placement_blocked_by_field_effect(r1,r2) must return non-zero. Returns 1=eligible, 0=rejected. Read-only predicate, no side effects.
Inputs: r0=ptr equipping-card slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..0x14].
Outputs: r0=u32 bool (1=eligible, 0=rejected).
Side effects: none.
Constants: gDuelFieldSlots=0x0201c510 (via callees only).
