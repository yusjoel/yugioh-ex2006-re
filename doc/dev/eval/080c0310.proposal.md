# Naming Proposal: 0x080c0310

## 提案
- **proposed_name**: write_nibble_row_pair_to_bg_tiles
- **confidence**: high

## plate comment (中文, ASCII 标点)
向背景图块 VRAM 写入双行 nibble 序列. 调用方为 FUN_080c05b4 (card_image/palette/font_jp 场景), 负责将卡片图像的 nibble 调色板行写入 BG tile map. 本函数在 r8 (VRAM 目标偏移, 由 r2 传入并保入 callee-save) 基础上, 步进 0x20 字节, 共调用 write_nibble_sequence_to_bg_tiles 四次, 覆盖两列 x 两行共 4 个 tile 行. 每次写入后目标 VRAM 指针 +0x20, tile 基地址在低/高 16 位分别叠加 +8 偏移, 构成 2x2 tile 块写入.

Constants:
- 0x20 = BG map 行字节步长 (32 bytes = 16 tile entries)
- 0x8 = 相邻 tile 列偏移 (8 tiles)
- 0x06010000 = BG tile VRAM base (DAT_080c03e8)

## 参数签名
- r0: u16 tile_coord_lo -- 低 16 位第一列 tile 坐标 (写入第 1/3 行)
- r1: u16 tile_coord_hi -- 入口 mov r9,r1, 第二列 tile 坐标 (写入第 2/4 行的高 tile)
- r2: u32 vram_dest_offset -- 入口 mov r8,r2, VRAM 目标偏移 [0..BG tile map size]
- r3: u32 aux_tile_arg -- 入口 mov r10,r3, 辅助 tile 参数
- 返回: void (无返回值, 仅副作用)

## 副作用
- [0x06010000 + r8]: 写 nibble 序列第 1 行
- [0x06010000 + r8+0x20]: 写 nibble 序列第 2 行
- [0x06010000 + r8+0x40]: 写 nibble 序列第 3 行
- [0x06010000 + r8+0x60]: 写 nibble 序列第 4 行
