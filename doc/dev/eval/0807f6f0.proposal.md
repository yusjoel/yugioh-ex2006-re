## plate comment (中文, ASCII 标点)
根据 card_id (r0) 返回 equip display 类型码 [0..5].

0x157e: 返回 5. 0x19ef (Elemental Hero Erikshieler): 返回 4. 其他: 调用 find_equip_display_entry_by_card_id; 若未找到返回 0; 若找到且 entry[+6]==0 返回 2, 否则返回 3.

此返回值由 FUN_0807f7bc 等 equip slot 分发函数用于选择入队路径: 0=无 display entry, 2/3/4/5=不同 display 类型.

副作用: 无.
