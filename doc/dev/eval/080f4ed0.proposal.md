# Naming Proposal: 0x080f4ed0

## 提案
- **proposed_name**: copy_words_aligned
- **confidence**: high

## plate comment (中文, ASCII 标点)
将 r1 指向的源缓冲区以 word (32 bit) 为单位复制 ceil(r2/4) 个 word 到 r0 (r3) 指向的目标.
r2 传入字节数, 函数对其执行 (r2+3)>>2 向上取整得 word 计数, 然后以 ldmia/stmia 对循环复制.
r2==0 时直接返回. 纯工具函数, 被 commit_line_buffer_to_sprite_vram / pack_detail_bg_tile_load
等多个 VRAM 写入路径调用, 负责将内存块对齐复制到目标区域.

## 参数签名
- r0: void* dst (目标地址)
- r1: const void* src (源地址)
- r2: u32 byte_count (字节数, 向上对齐到 4 字节)
- 返回: r0 = void

## 副作用
- [dst .. dst+ceil(byte_count/4)*4]: 写入 src 内容

## 行级注释 (<=30 行精华)
- @ 080f4ed0: r3=dst, 准备; r0=(r2+3)>>2 = word 计数
- @ 080f4ed8: word_count==0 -> bx lr 直接返回
- @ 080f4eda: ldmia r1!, {r0} -- 读一个 word, src++
- @ 080f4edc: stmia r3!, {r0} -- 写一个 word, dst++
- @ 080f4ede: subs count; bne 循环
