# Naming Proposal: 0x08031768

## 提案
- **proposed_name**: remove_slot_from_equip_array_by_index
- **confidence**: high

## plate comment (中文, ASCII 标点)
从指定玩家的装备卡数组中按索引删除一个槽位, 通过向前移位保持紧密排列.
r0=player_id(bit0, [0..1]), r1=slot_ptr (被移除的槽指针, 保存至 r4).
读 gP1LifePoints+player*0x868+0x10 (equip 数组计数, 同时用作上限检查). 若 slot_index >= count 则跳过;
否则从目标位置起调用 write_word_from_deref_src 逐字移位, 将后续元素向前平移一格, 最后 count -= 1 写回 +0x10.
equip 数组基址: gP1LifePoints+player*0x868+0x260 (0x98<<2=0x260, 与 hand_array 不同字段).
由 FUN_08031954 调用, 在 equip 卡离场时清理数组.
Constants: player_stride=0x868; equip_count_offset=0x10;
equip_array_offset=0x98<<2=0x260; equip_array_base=gP1LP+player*0x868+0x260.

## 参数签名
- r0: u8 player_id [0..1] - 玩家索引 bit0; 由 movs r1,#1; ands r1,r0 提取 (@ 0x08031774)
- r1: u32 slot_index - 要删除的槽在 equip 数组中的位置 (保存至 r4)
- r2: u32* spare_ptr - write_word_from_deref_src 的源地址 (保存至 r6 via 0x4646=mov r6,r8)
- 返回: r0 = 1 (找到并删除) 或 0 (index >= count, 跳过), via 最终 pop{r1};bx r1

## 副作用
- [gP1LP+player*0x868+0x10] := count - 1 (equip 数组计数减 1, str r0,[r5,#0] @ 0x080317a2, r5=gP1LP+player*0x868+0x10)
- [gP1LP+player*0x868+equip_array+i..end] : 移位覆盖 (write_word_from_deref_src)
