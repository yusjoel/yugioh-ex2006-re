## plate comment (中文, ASCII 标点)
被 card display / game_str 渲染簇 (indeg=39) 广泛调用, 是将行缓冲区中的字形数据刷写到 BG tile VRAM 的核心工具函数. 入口参数 r0 为目标 VRAM 基地址 (如 0x06014000), r1 为调色板索引 (通常为 0). 函数先读 gFontState (0x02006ed0) 的 glyph 列数 (bits[22:18]) 与字节流指针, 然后分两路: 若 gFontState+0x14 bit7=1 则调用 write_glyph_nibble_rows_to_vram (FUN_080f370c) 以 nibble-mask 方式写入; 否则直接按 nibble 格式逐像素写入 4bpp VRAM tile. 每列处理完毕后 r8 (当前 VRAM 行基) 递增 0x400 推进到下一 tile 行. 副作用: 写目标 VRAM tile 数据区域.

## 参数签名
- r0: u16* vram_base - BG tile VRAM 目标基地址 (如 0x06014000), [0x06000000..0x07FFFFFF]
- r1: u8 palette_index - 调色板区块索引, 通常为 0, [0..15]
- 返回: void (无返回值, 仅 VRAM 副作用)

## 副作用
- [VRAM r0..r0+N]: 写 4bpp tile 像素数据 (按 gFontState 中的行列数确定范围)
- [0x02006ed0] (gFontState): 仅读取 glyph 列数/行数/源字节指针, 不写入
