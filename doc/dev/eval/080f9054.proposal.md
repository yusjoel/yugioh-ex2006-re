# Naming Proposal: 0x080f9054

## 提案
- **proposed_name**: apply_delta_to_hand_oam_entry
- **confidence**: high

## plate comment (中文, ASCII 标点)
对 EWRAM 0x02000006 手牌 OAM 条目数组中索引 r0 指定的单个条目低4位字段加上 r1(delta), 超过 0x8 则截断至 0x9. r0 低16位经 lsls#0x10/lsrs#0xf 变换为条目字节地址偏移量(word_index*2). 与 apply_delta_to_hand_oam_entries(0x080f8fd0) 区别: 本函数处理单条, 无 init_puzzle_wram_and_checksum 调用, 是叶子函数. 被 6 个 caller 调用, 包括 campaign (0x080282a0/0x080282c2), duel_puzzle+deck 管理(0x080d8be0/0x080e0d40), starter_deck(0x080f4468), game_str(0x080fbb60).

Constants:
- HAND_OAM_BASE = 0x02000006 (DAT_080f9094)
- CAP_VALUE = 0x9 (低4位上限)
- INDEX_SHIFT = 0xf (lsls#0x10 / lsrs#0xf -> word_index * 2)

## 参数签名
- r0: u16 entry_index[0..count-1] (手牌条目索引, 低16位有效)
- r1: s8 delta (低4位增量; adds r3,r1 保存 delta)
- 返回: r0 = void (bx lr)

## 副作用
- [0x02000006 + entry_index*2]: strb 低4位 += delta, cap 0x9
