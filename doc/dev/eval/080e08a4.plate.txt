Creates the pack purchase result text overlay. Calls game_str_id_to_row with str_id=0x138c (purchase result format string), reads price data from 0x02035eb0 and calls expand_format_decimal_width_to_buf to format the value into a stack buffer. Calls text_overlay_create at overlay position (0x1e, 0x14) to display the formatted purchase result text. Clears bit4 of pack_ui_state+0x140 (OAM enable; rsbs = -0x11 = ~0x10), calls tick_pack_oam_slots_and_overlay(2) to refresh OAM, and writes pack_ui_state+0x4 := 0x15 (result display state). Returns fixed 1. indeg=0.
