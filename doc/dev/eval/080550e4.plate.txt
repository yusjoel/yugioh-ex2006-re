check_equip_slot_eligible_by_prereqs_and_type
Equip slot eligibility predicate requiring slot occupied + prerequisites + type compatible.
Called during equip target selection.
Checks in order: (1) gDuelFieldSlots[player_id&1][slot_idx] bits[18:0]!=0 (occupied);
(2) check_zone_slot_equip_prerequisites passes; (3) query_slot_card_type_eligibility == 0 (type compatible).
Returns 1 if all pass. Simplest three-step predicate in this cluster.
Pure predicate, no external writes.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868
Inputs: r0=ptr equip_card_slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx (unchecked)
Returns: r0=u32 bool (1=eligible, 0=rejected)
