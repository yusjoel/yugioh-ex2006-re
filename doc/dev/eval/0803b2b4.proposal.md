# Naming Proposal: 0x0803b2b4

## 提案
- **proposed_name**: get_zone_slot_ptr
- **confidence**: high

## plate comment (中文, ASCII 标点)
决斗场区域槽指针解析器 (indeg=59). 根据 zone_type (r1) 和 player_side (r0) 及 slot_offset (r2), 从对应的 EWRAM 区段返回槽结构体指针. zone_type 0xb..0xf 分别对应 5 块固定区域数组 (Fusion/Special/Field 等, 步长 0x868*player + r2*4); zone_type 0..0xa 或 default 时, 若 r1+r2<=10 则取 gDuelFieldSlots (0x0201c510) 中主场地槽 (步长 0x14 = 20 bytes); 若 r1+r2>10 则取 gDuelExtraZone (0x0201bc54-0xc4=0x0201bb90 附近) 区域. 所有路径最终 return r0 + r1*4 或 r0 + r1*20 格式的 EWRAM 槽指针. 被全局 59 个不同调用方使用, 是决斗逻辑层的核心 slot-lookup 入口.

Constants:
- gDuelFieldSlots = 0x0201c510 (default main field)
- PLAYER_STRIDE = 0x868
- SLOT_ENTRY_SIZE = 0x14 (default case, main field)
- ZONE_ENTRY_SIZE = 4 (cases 0xb..0xf, each zone entry is word-sized)
- Zone bases: 0xb->0x0201c600, 0xc->0x0201c880, 0xd->0x0201c740, 0xe->0x0201c8f8, 0xf->0x0201cab0

## 参数签名
- r0: u32 player_side [0..1] (bit0=P1/P2; r3 保留; 计算 base + (r0&1)*0x868)
- r1: u32 zone_type [0..0xf+] (0xb..0xf=命名区域; 0..0xa=主场地; >0xf=default fallback)
- r2: u32 slot_offset [0..0xa] (主场地: slot index; 命名区域: word index; default: combined r1+r2<=10)
- 返回: r0 = u32* 指向 EWRAM 槽结构体或区域条目的首地址

## 副作用
- 无外部写入, 纯只读地址计算
