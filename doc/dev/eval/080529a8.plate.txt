Function: Composite equip slot eligibility check requiring chain score exactly equal to 4. Verifies in order: (1) slot_idx [0..4] in range; (2) chain_field nonzero; (3) query_slot_card_type_eligibility returns 0; (4) owner_bit matches 1-card.side[bit0] (r1 == 1-card.side); (5) field8 ([+0x8]) != 0; (6) eval_equip_chain_score_for_slot returns exactly 4. Returns 1 if all pass.

Params: r0=u8* card_ptr (equip card; [+0x2] bit0=side); r1=u8 owner_bit [0..1]; r2=u8 slot_idx [0..4]
Returns: r0=u32 eligible (0=ineligible, 1=eligible)
Side effects: none (pure query)
Constants: SLOT_IDX_MAX=4, ZONE_BASE=0x0201c510, STRIDE=0x868, CHAIN_SCORE_EXACT=4
