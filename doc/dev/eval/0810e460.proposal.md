# Naming Proposal: 0x0810e460

## 提案
- **proposed_name**: copy_bytes_with_waitcnt
- **confidence**: high

## plate comment (中文, ASCII 标点)
在设置 GBA ROM 等待状态控制寄存器 WAITCNT (0x04000204) 后执行字节级内存复制. 先读取 WAITCNT, AND 0xfffc (清除 bits[1:0] = SRAM 等待周期位), OR 0x3 (设为 8 等待周期), 写回 WAITCNT 以确保 SRAM 访问时序正确; 然后从 r0 (src) 逐字节复制 r2 (count) 个字节到 r1 (dst). 被 FUN_0810e588 (scene_duel_puzzle 父函数) 以 3 次循环调用, 用于向 SRAM (0x0e000000) 区域写入谜题存档数据.

## 参数签名
- r0: u8* src (源缓冲区指针)
- r1: u8* dst (目标缓冲区指针, 通常为 SRAM 地址)
- r2: s32 count (复制字节数; count=-1 时跳过复制直接返回)
- 返回: void

## 副作用
- [WAITCNT 0x04000204] halfword: bits[1:0] := 3 (SRAM 8 等待周期)
- [r1..r1+r2-1]: 逐字节写入 r0 处数据
