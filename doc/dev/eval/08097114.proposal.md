# Naming Proposal: 0x08097114

## 提案
- **proposed_name**: scan_card_type_effect_handler_table
- **confidence**: high

## plate comment (中文, ASCII 标点)
扫描 ROM 内固定卡类型效果处理函数表 (基址 0x09e47560, 最多 0x11=17 条目, 步长 0x10 字节), 逐条比较 entry[+0x0] 与 r1 (card_type); 命中则读取 entry[+0x8+r3*0x10] 处的函数指针并通过 invoke_r2 调用, 传入 r5/r4/r6/r3 四参数. 未命中全部条目则直接返回 void. 入口 r0=context_ptr (传给 invoke_r2 r0), r1=card_type (匹配键), r2=sub_param (传给 invoke_r2 r2). 与已命名邻居 dispatch_to_effect_handler_by_card_type (0x08097150) 结构对称, 但本函数仅传 3 参数 (r5/r4/r6 无 r3 sub_param 通道), 使用 invoke_r2 而对方使用 invoke_r3; 二者共享同一表基址 0x09e47560.

Constants:
- HANDLER_TABLE_BASE = 0x09e47560
- TABLE_ENTRY_COUNT = 0x11 (=17)
- ENTRY_STRIDE = 0x10
- ENTRY_TYPE_OFFSET = 0x0
- ENTRY_HANDLER_OFFSET = 0x8

## 参数签名
- r0: ptr context_ptr (传给 invoke_r2 r0)
- r1: u16 card_type (与表 entry[+0x0] 比较)
- r2: u32 sub_param (传给 invoke_r2 r2)
- 返回: r0 = u32 (0=全表未命中, @ 0x08097148 movs r0,#0; 命中路径调用 invoke_r2 后继续遍历至末端同返回 0; 出口 pop{r4,r5,r6}; pop{r1}; bx r1)

## 副作用
无外部 str/strh/strb 写入 (只读表扫描 + 间接调用)
