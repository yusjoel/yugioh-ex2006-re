## plate comment (中文, ASCII 标点)
title_ex scene 窗口淡入动画单步, 与 apply_demo_window_fade_in_step (0x08013af4) 结构对称. 计算 cur*80/max 得竖向偏移 r6. cur==max (淡入完成) 时: 配置 WININ bits[5:0]=0x3b, 清 WINOUT bit5, 写 WIN0H/初始 WIN0V, 修改 BLDCNT, 调用 gl_set_brightness + gl_set_blend2_level. 最后统一写 WIN0V=[WIN_CENTER+r6 : WIN_CENTER-r6]. indeg=0, 由运行时函数指针触发.

## 参数签名
- r0: u8 cur_frame - 当前帧计数 [0..max_frame]
- r1: u8 max_frame - 动画总帧数 [1..127]
- 返回: void (pop {r4,r5,r6}; pop {r0}; bx r0 - Sub-case E: r0=lr, 无独立返回值)

## 副作用
- 条件 (cur==max): [WININ 0x04000048] bits[5:0] := 0x3b, bit5 cleared
- 条件: [WINOUT 0x0400004a] bit5 := 0 (cleared)
- 条件: [WIN0H 0x04000040] := 0x00f0
- 条件: [WIN0H+4 = WIN0V 0x04000044] := 0x00a0 (then overwritten below)
- 条件: [BLDCNT 0x04000050] &= 0xffff9fff | r3
- 条件: gl_set_brightness(0x3f, 0), gl_set_blend2_level(0x3f, -16, cur)
- 无条件: [WIN0V 0x04000044] := [(0x50+r6)&0xff : (0x50-r6)&0xff]
