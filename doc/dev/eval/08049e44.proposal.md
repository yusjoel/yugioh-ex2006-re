## plate comment (中文, ASCII 标点)
被 3 个 duel_field 调用方调用 (0x0804a2c8, 0x0804a2e4, 0x0804a30c). 入口接收装备区槽位引用指针 (r3), 提取 card_id bits[12:0] 后调用 count_field_copies_of_card 检查场地上同名卡数量; 若大于 0 则置 field_copy_flag. 之后检查 check_card_field8_is_9 (r0=card_id, 特殊字段判断). 根据两项检查结果组合 OAM attr 字段 (包含 palette/flip/coord 位域), 调用 enqueue_sprite_attr_record 写入 sprite 缓冲. 最终在满足条件时调用 scan_field_slots_for_equip_sprite 进行进一步的槽位扫描. 函数返回构造后的 attr 值或 0.

## 参数签名
- r0: u8 player_id [0..1]
- r1: u8 slot_col [0..9] (场地列)
- r2: u16 card_id [0..0x1fff] (装备区卡 ID)
- r3: ptr slot_entry (指向装备槽位结构体, 含 card_id word 及 field8/field10 等字段)
- 返回: r0 = u32 oam_attr_or_zero (构造的 OAM attr 值, 0 表示未写入)

## 副作用
- 调用 enqueue_sprite_attr_record: 向 sprite 属性缓冲区写入装备槽位精灵
- 调用 scan_field_slots_for_equip_sprite (条件触发): 触发进一步的场地扫描
