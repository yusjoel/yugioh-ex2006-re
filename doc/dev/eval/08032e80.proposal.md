流程: r2 = (r0&1)*0x868 + gDuelFieldSlots; 内层 r4=0..4 遍历; 若格 active bit 为 0 或
[slot+0x8]=card_id 为 0 则跳过; 调用 get_slot_card_state_code(r6, r4); 返回值低 16 位

monster_zone_count=5.
