# Naming Proposal: 0x080f05d0

## 提案
- **proposed_name**: test_char_kinsoku_head
- **confidence**: med

## plate comment (中文)
由 font_jp 模块的文本排版函数（font_jp_080c76c0、font_jp_080f21e8）调用，判断指定字符是否属于"行頭禁則"字符集（即该字符不允许出现在行首）。函数先将 char_code 转换为字形索引，再查 font_jp_sjis_lookup_table 取得对应 SJIS 码，最后将 SJIS 码与预设的行頭禁則码点集逐范围比对并返回布尔结果。字符集涵盖小假名（ぁぃぅぇぉ、ァィゥェォッャュョヶ）、行末标点（、。）、连字符（‐）、全角斜线（／）及若干闭括号类字符；凡命中者返回 1，否则返回 0。与对称函数 FUN_080f0720（test_char_kinsoku_tail，检测行末禁則/开括号类）共同构成 JIS X 4051 禁則处理对。

## 参数签名
- r0: u16 char_code — 游戏自定义字符编码（经 char_code_to_glyph_index 映射到字形索引，再经 font_jp_sjis_lookup_table 取得 SJIS 码）；低 16 位有效，高 16 位被 lsl/lsr #0x10 截断
- 返回: r0 = u8 bool（1 = 该字符属于行頭禁則集、不得位于行首；0 = 可置于行首）

## 副作用
无外部副作用（函数体内零个 str/strh/strb 到非栈地址的写操作；仅读 font_jp_sjis_lookup_table 和调用 char_code_to_glyph_index）
