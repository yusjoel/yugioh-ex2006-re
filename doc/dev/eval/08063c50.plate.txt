Equip slot eligibility predicate, returns 0/1. Thin wrapper: loads fixed fn-ptr 0x08050a55 as the second argument, calls invoke_count_zone_pair_hits_full_range(slot, fn_ptr) to count the zone-pair hits of that predicate over the full range. Unlike the sibling trampolines (0x08061d5c etc.), this function has a higher threshold: returns 1 only when hit count > 1, otherwise returns 0 (cmp r0,#1; ble). Statically dispatched from the equip eligibility scan chain, indeg=0.

Constants:
- ZONE_PAIR_PREDICATE_FN=0x08050a55 (predicate fn-ptr passed to invoke_count_zone_pair_hits_full_range, +1 for thumb bit)
- HIT_THRESHOLD=1 (count > 1 is eligible, cmp #1; ble fails)
