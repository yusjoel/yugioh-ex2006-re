Called by duel_field slot scan function (indeg=1, 0x080551ea) as a pre-filter before check_card_field5_is_nonzero. Checks whether card_id belongs to equip card set G. BST whitelist: 0x159d, 0x1302, 0x14c7, 0x14de, 0x1529, range [0x1790..0x17c2], 0x17b9, 0x183a, 0x1936, 0x19c6, and others. Returns 1 if member, 0 otherwise. Pure leaf function; part of the equip card BST whitelist cluster (sets a through g).

Inputs: r0=u16 card_id [0..0x1fff].
Outputs: r0=u32 bool (1=member of equip set G, 0=not).
Side effects: none.
Constants: ANCHOR_ROOT=0x159d, ANCHOR_B=0x1302, ANCHOR_C=0x14c7, ANCHOR_D=0x17c2, ANCHOR_E=0x183a, ANCHOR_F=0x1936.
