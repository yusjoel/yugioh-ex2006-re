## plate comment (中文, ASCII 标点)
针对含特定保留 icid 的 equip slot 进行 zone 状态机分发. 读取 slot[+0] halfword = card_id; 若匹配 icid=0x162c 或 icid=0x184c (均为保留/未上市卡, cid=0xFFFF) 则置 r1=3; 若匹配 icid=0x1051 (亦保留, cid=0xFFFF) 则置 r1=5; 否则 r1=0. 再读取 gDuelFieldState+0x4a0 的当前 zone state: 0x80 -> 用 player_id 和 op_code=0xf5 调用 trigger_card_display_op31_if_not_active, 返回 0x7f; 0x7f -> 用 r1 (clamp <=0x20)+6 和 card_id 调用 init_effect_slot_display_context, 返回 0x7e; 0x7e -> 调用 enqueue_effect_slot_sprites_descending; default -> 返回 0. indeg=0.

- ICID_RESERVED_B = 0x184c (cid=0xFFFF, reserved; same as 0x162c branch; r1=3)
- ICID_RESERVED_C = 0x1051 (cid=0xFFFF, reserved; r1=5)
- gDuelFieldState = 0x0201b290
- EQUIP_STATE_OFFSET = 0x4a0 (= 0x94<<3)
- OP_CODE = 0xf5 (trigger_card_display_op31 arg)
