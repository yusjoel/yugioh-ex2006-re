# Naming Proposal: 0x0810ca9c

## 提案
- **proposed_name**: find_min_active_channel_priority
- **confidence**: high

## plate comment (中文, ASCII 标点)
扫描 IWRAM 0x03005408 的 8 个音频 channel 槽 (每槽 0x28 字节, 共 7+1 次迭代). 对每个槽检查 [+0x1f] bit7 是否为 1 (channel active 标志); 若 active 且 [+0x24] 字节 < 当前最小值, 则更新最小值. 初始最小值为 0x10; 返回所有 active channel 中 [+0x24] 字段的最小值. 由 FUN_0810cad0 (sound channel 分配器) 调用, 用于确定可抢占的最低优先级 channel.

Constants:
- CHANNEL_BASE=0x03005408 (sound channel array IWRAM base)
- CHANNEL_STRIDE=0x28 (每个 channel 槽字节数)
- CHANNEL_COUNT=8 (r3=7 down to 0)
- ACTIVE_BIT=0x80 (bit7 of [+0x1f])
- PRIORITY_INIT=0x10 (初始最小值上界)

## 参数签名
- 无 APCS 参数 (r0/r1/r2/r3 均在入口前 5 条指令被覆盖)
- 返回: r0 = u8 min_priority, 所有 active channel [+0x24] 的最小值 [0..0x10]

## 副作用
- 无外部地址写入 (只读扫描)

## 行级注释 (<=30 行精华)
- @ 0810ca9c: push + 初始化 r4=0x10 (最小值哨兵), r3=7 (倒计数), r2=channel_base
- @ 0810caa6: ldrb r1,[r2,#0x1f] -- 读 active 标志字节
- @ 0810caaa: ands r0,r1 with 0x80 -- 测 bit7 (active 标志)
- @ 0810caae: beq LAB_0810cabc -- 非 active channel 跳过
- @ 0810cab4: ldrb r0,[r2,#0x24] -- 读 priority 字节
- @ 0810cab6: cmp r0,r4 -- 与当前最小值比较
- @ 0810caba: 若更小则更新 r4 (新最小值)
- @ 0810cabc: subs r2,#0x28 -- 步进到下一 channel (反向遍历)
- @ 0810cac4: returns r4 (最小 priority 值)
