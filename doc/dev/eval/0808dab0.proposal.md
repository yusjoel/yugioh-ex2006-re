# Naming Proposal: 0x0808dab0

## 提案
- **proposed_name**: dispatch_effect_handler_by_card_id
- **confidence**: high

## plate comment (中文, ASCII 标点)
根据卡牌/效果 ID (r1) 在 ROM 效果记录表 (0x09e5a128) 中查找对应项, 找到后从表项 [+4] 读取函数指针并通过 FUN_0810e5d4 (bx r3 trampoline) 调用.
调用前清零 IWRAM 结构 [0x0201e4f0+0xc], 调用后将其值作为返回值返回给外层.
r1 的高 16 位先被截断, 仅用低 16 位 (card_id) 做索引查找.
被整个 spell/trap 激活/解析流程的 100+ 个 callsite 广泛调用, 是效果 dispatch 总入口.
Constants: effect_table = 0x09e5a128, gEffectContext = 0x0201e4f0, result_field = gEffectContext+0xc.

## 参数签名
- r0: u32 player_side; 激活玩家 [0..1]
- r1: u16 card_id; 要 dispatch 的效果卡 ID [0..0x1fff]; 高 16 位在入口被 lsls/lsrs 截断
- r2: u32 effect_param; 传给被调用效果处理函数的第三参数 (含义依 handler 而定)
- 返回: r0 = u32 handler_result; 读自 [gEffectContext+0xc], 由被调 handler 填写; 若 card_id 未在表中则返回 0

## 副作用
- [0x0201e4f0+0xc] := 0 (调用前清零结果字段)
- [0x0201e4f0+0xc] 在被调 handler 内部被写入 (间接副作用)
