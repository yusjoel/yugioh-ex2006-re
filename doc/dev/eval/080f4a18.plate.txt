General scene per-frame driver. Sets FLAGS bit0=1, increments frame counter(gPrng+0x20e). Checks DMA ch0/ch1 active flags(gPrng+0x213/0x217 bit7); if active increments corresponding ring slot counter +1 mod 0x7fffffff. If FLAGS bit1 not set: sets bit1; if fn_ptr(gPrng+0x1f4) non-zero calls invoke_r0; calls tick_sound_engine_dma_volume; finally clears bit1. Called each frame by puzzle scene main loop via system-init-written IWRAM fn-ptr slot.
