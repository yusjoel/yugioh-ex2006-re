## 修改清单

### #1 — R6 (优先级: 高)
**位置**: proposal Constants 块, OAM_ATTR_E0/OAM_ATTR_B0/OBJ_VRAM_BASE 行
**问题**: OAM_ATTR_E0/B0 的 lsls 推导算术错误: `movs r1,#0xe0; lsls r1,r1,#0xe` -> 0xe0 << 14 = 0xe0 * 0x4000 = 0x38_0000, 非 0xe0000000; 应验证实际 lsls 移位量; OBJ_VRAM_BASE = 0x06010100 的描述 "0x100 offset" 与常量名 BASE 矛盾, 应区分基址与偏移量
**当前**: `OAM_ATTR_E0 = 0xe0000000 (movs r0,#0xe0; lsls r0,r0,#0xe -> *16384)`; `OBJ_VRAM_BASE = 0x06010100 (movs r1,#0x80; lsls r1,#1 = 0x100 offset)`
**应改为**: 追踪 asm 中实际 lsls 移位量 (应为 #0x18 才能得到 0xe0000000); python 验证: `0xe0 << 0x18 = 0xe0000000`; OBJ_VRAM_BASE 改为正确基址值或改名为 OBJ_VRAM_OFFSET=0x100
