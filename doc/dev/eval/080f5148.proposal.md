# Naming Proposal: 0x080f5148

## 提案
- **proposed_name**: expand_format_text_to_buf
- **confidence**: high

## plate comment (中文, ASCII 标点)
扫描 r1 指向的格式模板, 将字节逐个复制到 r0 指向的输出缓冲区; 当遇到 "%s" (0x25 0x73) 时, 先以 NUL 截断当前缓冲区, 调用 append_text_to_buf_end 追加 r0 当前内容, 再调用 append_text_to_buf_end 追加 r2 指向的文本参数, 然后继续扫描剩余模板; 普通字节则直接复制. 实现一个单 %s 替换的极简 printf-like 文本展开, 被 scene_pack/card_name/bg/display 等多个模块用于将卡名或游戏文本内嵌到显示模板中.

## 参数签名
- r0: u8* dst_buf (输出缓冲区指针, 就地写入)
- r1: u8* fmt_str (格式字符串, 含 "%s" 占位符)
- r2: u8* arg_str ("%s" 占位符对应的替换字符串)
- 返回: void

## 副作用
- [r0..r0+N]: 写入展开后的字符串 (N 取决于 fmt_str 长度)
