# Naming Proposal: 0x080f5228

## 提案
- **proposed_name**: expand_format_decimal_to_buf
- **confidence**: high

## plate comment (中文, ASCII 标点)
扫描 r1 指向的格式字符串; 当遇到 "%d" (0x25 0x64) 占位符时, 读取 gSettings byte 低 3 位判断字符编码模式: 若为 0 (非日文) 则调用 format_decimal_halfword_to_buf (0x080f508c) 将 r2 的整数值以半字编码写入缓冲区, 否则调用 format_decimal_byte_to_buf (0x080f50f0) 以 ASCII 字节写入; 之后调用 append_text_to_buf_end 追加剩余格式字符串. 普通字节直接复制到 r0 的输出缓冲区. 实现依语言设置选择编码的 "%d" 格式展开, 被 result_screen/duel_field/vram/font_jp/settings 等多个高层模块调用.

## 参数签名
- r0: u8* dst_buf (输出缓冲区指针)
- r1: u8* fmt_str (格式字符串, 含 "%d" 占位符)
- r2: s32 value ("%d" 占位符对应的整数值)
- 返回: void

## 副作用
- [r0..r0+N]: 写入展开后的字符串
- [r5+0x0] strb := 0 (写 NUL 截断, 临时, 在追加前)
