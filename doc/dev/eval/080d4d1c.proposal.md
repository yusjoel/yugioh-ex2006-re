## plate comment (中文, ASCII 标点)
加载 pack 主界面 BG tile 图形数据和调色板. 从 ROM 0x09cce2b0+0xc 读取 huffman 压缩 tile 指针, 解压到 VRAM 0x0600d000; 从 0x09cce2d0+0xc 解压到 0x0600f000. DMA 复制 ROM 0x09cce2c0+0xc 处调色板 (32 字节) 到 BG 调色板槽 0x050001a0. pack 主界面进入时由帧驱动器调用, 0 参数纯副作用函数.

Constants:
- ROM_GFX_TABLE_A = 0x09cce2b0 (pack BG tile 数据表 A, +0xc 为 tile 指针)
- ROM_GFX_TABLE_B = 0x09cce2d0 (pack BG tile 数据表 B)
- ROM_PAL_TABLE = 0x09cce2c0 (pack BG 调色板表, +0xc 为调色板指针)
- VRAM_BG_TILE_A = 0x0600d000 (BG tile 目标区域 A)
- VRAM_BG_TILE_B = 0x0600f000 (BG tile 目标区域 B)
- BG_PAL_DST = 0x050001a0 (BG 调色板 pack 槽)
- PAL_SIZE = 0x20 (32 字节, 16 色调色板)
