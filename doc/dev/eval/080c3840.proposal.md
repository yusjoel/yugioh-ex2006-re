- **confidence**: high

## plate comment (中文, ASCII 标点)
将指定场地槽的 VRAM tile 区域用预定义调色板高字节数据覆写. 调用方提供 player_id/row/col 三个 u16 参数, 先调用 get_field_slot_tile_vram_addr 定位目标 VRAM 地址; 若地址为 0 则直接返回. 目标非 0 时, 从 ROM 内嵌调色板表 (0x09854df0, 0x120 字节 = 0x90 halfword) 读取预置颜色数据, 将每个 halfword 的高字节与调色板低字节 OR 合并后写入 VRAM. 副作用: VRAM [tile_addr..tile_addr+0x120) 被逐 halfword 改写. Constants: palette_table=0x09854df0, tile_count=0x90.

## 参数签名
- r0: u16 player_id [0..1]
- r1: u16 row [0..N-1] (字段行坐标, 传入前 uxth 截断)
- r2: u16 col [0..N-1] (字段列坐标, 传入前 uxth 截断)
- 返回: r0 = void (无返回值, 仅副作用)

## 副作用
- [get_field_slot_tile_vram_addr(player_id,row,col)..+0x120]: 写入 0x90 个 halfword, 每个为 palette_hi_byte OR palette_lo_byte 混合值
