# Naming Proposal: 0x0801d510

## 提案
- **proposed_name**: render_card_name_to_line_buf
- **confidence**: med

## plate comment (中文, ASCII 标点)
接收卡片索引 (r0), 从 card_stats_table 读取卡种字段判断是否为特殊宽度 (0x16/0x17),
再从 IWRAM 状态字 [0x02006c2c] 读取语言/charset 标志调用 select_charset_then_load_name
加载卡名字符串, 然后按双字节 JP 编码逐字素调用 render_glyph_jp_dual_layer 将卡名渲染进行缓冲区.
限宽逻辑 (cmp #0x5c) 防止卡名溢出单行. 被 FUN_0801d6b4 (card_image_decode_wrapper 下一级)
调用, 构成绘制卡片详情页卡名行的核心路径.

## 参数签名
- r0: u16 card_index (卡片索引, 用于查 card_stats_table 第 0xb*idx+0x6 偏移的宽度字段)
- 返回: r0 = 无明确含义 (void 或行宽计数, 调用方未使用)

## 副作用
- [0x02006ed0+field]: 写入 font/line-buf 状态字节 (通过 FUN_080f0bb4 路径间接)
- line buffer: 经 render_glyph_jp_dual_layer 写入当前行像素数据
