评估装备格目标槽合法性并在条件满足时执行激活. r0=player_side [0..1] -> r5, r1=slot_idx [0..4] -> r6, r2=check_mode (0=简化检查, 1=完整检查). 若 r2==0: 直接读 [0x0201afe0+r6*4+0x198] 确认 slot 是否已绑定; 若非 0 设 r4=-1 (需检查). 若 r2!=0: 调用 check_equip_card_valid_for_target_slot(r5, r6, 0) -> 若返回非 -1 则 r4=0 (通过). 之后调用 check_slot_field_action_eligibility(r5, r6); 若返回 0 则 r0=0 直接退出. 若通过: 根据 r4 状态进入扩展检查路径 (check_field_spell_last_warrior_placeable, check_card_stat_field8_is_6, check_field_spell_neo_daedalus_group_placeable, check_toon_world_equip_present; 以及 card_id=0x15fb/0x197b 的 count_field_copies_of_card); 全部通过: 调用 apply_slot_equip_activation_with_sprite(r5, r6, 0, 0) 执行激活. 返回 1=激活成功, 0=条件不满足. 被 FUN_080bc54c (player 0) 和 FUN_080bc5d4 (player 1) 调用 (indeg=2).
