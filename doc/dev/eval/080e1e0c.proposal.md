## plate comment (中文, ASCII 标点)
将 r0 所指结构中的 BG tile 数据复制到 VRAM. 入口读取 [r0] halfword 作为 tile 计数, 计算 tile_bytes = count*2; 以 [r0+4..] 起的 src 数据为源, 调用两次 copy_bytes_by_halfword: 第一次写入目标 VRAM 基址 0x06000000 (count*width 字节), 第二次写入 0x05000000 (palette 区域 tile_bytes 字节). 被 FUN_080e1e3c 在场景初始化时调用.

Constants:
  VRAM_TILE_BASE  = 0xc0<<0x13 = 0x06000000 // BG tile VRAM
  PAL_BASE        = 0xa0<<0x13 = 0x05000000 // palette VRAM
  COUNT_OFFSET    = 0x0                     // [r0]: tile count halfword
  DATA_OFFSET     = 0x4                     // [r0+4]: tile data start

## 参数签名
- r0: ptr  tile_desc_block  -- 指向描述块; [+0] = u16 tile_count, [+4..] = tile pixel data
- 返回: void (pop {r0}; bx r0)

## 副作用
- [0x06000000 .. +tile_count*width]: := tile pixel data (BG tile VRAM 写入)
- [0x05000000 .. +tile_bytes]:       := tile data bytes (palette 区域写入)
