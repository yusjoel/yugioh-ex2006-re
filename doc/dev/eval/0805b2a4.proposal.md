## plate comment (中文, ASCII 标点)
对卡牌结构体执行效果分发, 根据卡牌扩展属性字段9 (field9) 和其他条件决定走哪条效果路径. 首先检查 [r7+0x4] bit1 (0x2 掩码), 若已置位直接返回 0 (已处理过). 否则调用 check_card_effect_node_active 确认效果节点存活; 若节点不存在也返回 0. 节点存在后读取 [r7+0x4] bit2 (0x4 掩码) 区分"非魔法陷阱"路径: 若 bit2=0 跳转到大分支 (LAB_0805b3c2); 否则调用 get_card_extended_stat_field9 获取效果类型 [2..3] 以匹配具体效果子类, 并在 [r7+0x3] bit4/bit5 (0x30 掩码) 和卡牌 ID (0x1909=dark_magician_girl 判别式) 构成的联合条件下决定是否返回 0 或继续. 由 FUN_080954e8 (涵盖 card_frame/duel_field/font_jp/prng 的顶层场景函数) 调用.

Constants: card_entry_flag_offset=0x4, processed_bit=0x2, alt_path_bit=0x4, stat3_bits=0x30, card_id_special=0x1909, field9_range=[2..3].

## 参数签名
- r0: ptr card_entry (卡牌数据结构体指针; 入口 adds r7,r0,#0 保存到 r7)
- 返回: r0 = u32 should_continue (0 = 不执行效果; 1 = 需继续处理, 由后续分支决定)

## 副作用
- 无外部写入 (整个函数体含 LAB_0805b3c2 分支均无 str/strh/strb 指令; LAB_0805b3c2 调用 get_card_extended_stat_field9 后执行一系列 card_id 比较/算术和 ldrh/ldrb 读取, 两条出口均为 movs r0,#0 (LAB_0805b2ea) 或 movs r0,#1 (LAB_0805b46a) 加 pop+bx 返回; 全函数纯只读, 返回布尔判断结果)
