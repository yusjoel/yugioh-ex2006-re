# Naming Proposal: 0x080fae24

## 提案
- **proposed_name**: tick_pack_prng_anim_frame
- **confidence**: med

## plate comment (中文, ASCII 标点)
pack scene 动画帧 tick 函数, 由 0x080faf18 ([prng]) 调用. 检查 gPrng+0x744 bit0, 若为 1 则立即返回 0 (未就绪). 否则 dequeue_prng_anim_entry 取下一帧: 帧类型 4 -> 置 ctx bit5 (ANIM_VISIBLE_FLAG) 返回 1; 帧类型 8 -> 按 frame_idx ([0..0x3b] 有效, 0xffff=special) 从 PACK_FRAME_DATA_BASE 拷贝 0x118 bytes, 最后 write_sprite_row_to_vram_buffer 写 VRAM 行. 返回 1=继续, 0=等待/失败.

## 参数签名
- r0..r3: void (无 APCS 参数; 入口 sub sp,#4 是栈局部空间, r0 在 ldr 前被 gPrng 地址覆盖)
- 返回: r0 = u32 (1=动画帧已处理, 0=等待或失败)

## 副作用
- 条件写 [ctx-0xc+0x0] bit5 (帧类型4路径)
- 条件 copy_bytes_by_halfword 写 0x118 bytes 帧数据 (帧类型8路径)
- 条件 write_sprite_row_to_vram_buffer 写精灵 VRAM 行
