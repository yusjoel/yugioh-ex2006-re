Called by equip card target eligibility checker (0x0804bb6c check_card_is_equip_target_eligible) and 4 other duel_field callers (indeg=5). Checks whether card_id falls in the equip exclusion range: interval [0x15af..0x15fa], discrete IDs 0x1567 and 0x1570, plus interval [0x1953..0x1954]. Returns 0 when excluded (card is in range), returns 1 when not excluded (card is allowed for equip). NOTE: return value semantics are inverted relative to sibling equip_set functions -- 0=hit/excluded.

Inputs: r0=u16 card_id [0..0x1fff].
Outputs: r0=u32 bool (0=excluded/in range, 1=not excluded).
Side effects: none.
Constants: EXCLUDE_RANGE_1_MAX=0x15fa, EXCLUDE_ID_A=0x1567, EXCLUDE_ID_B=0x1570, EXCLUDE_RANGE_2=[0x1953..0x1954].
