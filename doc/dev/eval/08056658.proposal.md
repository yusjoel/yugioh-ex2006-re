## plate comment (中文, ASCII 标点)
装备区域槽位标志置位及精灵入队的综合操作函数. 由装备激活链调用, 处理两类路径: (1) 若 card_entry byte[+3] bits[5:4] == 0x20 (特殊装备类型标志), 直接跳过区域描述符查找进入精灵入队; (2) 否则读取 card[+0x14] bits[6:0] = slot_id, 调用 find_zone_descriptor_by_slot_id 获取 zone_descriptor, 比对 player_id 和 slot_group 是否与 card_entry 一致; 若匹配且 zone_descriptor 高 16 位 != 0xffff, 则调用 set_field_slot_bit_with_sprite_update(player_id, slot_group, bit=4, val=1) 置位槽位标志; (3) 无论路径如何, 最终调用 enqueue_sprite_attr_for_zone_card_id_lookup 将装备区域精灵入队. 失败路径 (player/slot 不匹配) 返回 -1 (rsbs r0,r0,#0).

Inputs: r0 = ptr equip_card_entry (reads byte[+2]=player/slot, byte[+3]=type_flags, [+0x14]=slot_id, [+4]=card_type_info)
Outputs: r0 = 1 (success) or -1 (player/slot mismatch)
Side effects:
- set_field_slot_bit_with_sprite_update: field_slot[player_id][slot_group].bit4 := 1 (if slot matches)
- sprite render queue: enqueue_sprite_attr_for_zone_card_id_lookup (player_id, slot_group, card_type_info)
Constants: TYPE_FLAG_MASK=0x30 (bits[5:4] of byte[+3]), TYPE_DIRECT=0x20, SLOT_ID_MASK=0x7f (bits[6:0] of [+0x14]), INVALID_ZONE=0xffff, FIELD_SLOT_BIT=4
