# Naming Proposal: 0x0804448c

## 提案
- **proposed_name**: dispatch_equip_zone_sprite_banisher_with_spell_check
- **confidence**: high

## plate comment (中文, ASCII 标点)
由 FUN_08086cdc (card_frame/duel_field/font_jp 等标签) 和 FUN_080a6cc8 (equip 相位函数) 两个 caller 调用 (indeg=2). 函数入口保存 r8 (callee-save: .hword 0x4647 = mov r7,r8; push {r7}), 以 r0=player_id, r1=slot_idx, r2=sub_zone_flag 为参数. 第一次调用 count_field_copies_of_card(0x1332 = Banisher of the Light) 决定初始 zone_state (r8=0xe/0xf); 若场上存在 Banisher 且 zone_slot_ptr 非空则继续: 调用 count_field_copies_of_card(0x19da) 检测第二张卡副本数; 若存在: 调用 check_card_type_is_spell 判断槽内卡是否为魔法牌, 若是则 r8=0xc (魔法专用 zone_state); 最终以 sp[0]=1, sp[4]=1 调用 dispatch_equip_zone_sprite_and_activation; 若条件不满足(无 Banisher 或 slot=NULL)则调用 dispatch_equip_zone_sprite 并返回. 额外: 若 get_card_extended_stat_field6 返回 1 则调用 enqueue_sprite_attr_type11(player_id, card_id=0x14e2, 2, 0). 副作用: 通过 dispatch_equip_zone_sprite_and_activation 更新 zone sprite 状态.

## 参数签名
- r0: uint8 player_id [0..1] (玩家 ID, 0=P1, 1=P2)
- r1: int32 slot_idx (装备槽索引, <0 则跳过全部 sprite 更新)
- r2: uint8 sub_zone_flag [0..1] (子区域标志, 转发至 dispatch)
- 返回: r0 = void (epilogue pop {r0} 覆盖 bl callee r0 为 lr 后 bx r0 跳转; 所有 caller 均不读返回值)

## 副作用
- [EWRAM zone sprite struct]: dispatch_equip_zone_sprite_and_activation 更新激活状态字段
- [sprite attr 队列]: enqueue_sprite_attr_type11 (若 field6==1) 写入 card_id=0x14e2 的 sprite attr
