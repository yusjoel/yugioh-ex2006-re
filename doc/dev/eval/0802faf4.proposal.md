# Naming Proposal: 0x0802faf4

## 提案
- **proposed_name**: find_node_by_value
- **confidence**: high

## plate comment (中文, ASCII 标点)
在 EWRAM 节点池 (0x0201d9c0, stride=8) 中沿链表遍历, 查找第一个满足条件的节点: [node+0](u16)==value(r1) 且 [node+2]&0xF (zone_type) 在 [0..5] 范围内 (有效区域). r0 为链表起始索引 (0 表示空链表, 直接返回 NULL). 找到则返回节点指针; 未找到则返回 0. 本函数是同模块内 find_node_by_value_and_zone_type 的简化变体 -- 后者需额外匹配 zone_type 参数, 本函数只过滤 zone_type<=5 (排除无效区域), 不做具体区域类型约束. 被 check_value_in_slot_chain (0x0802fc90), FUN_0802fcc0, FUN_0802fe60 等作为公共链表遍历内核调用.

## 参数签名
- r0: u16 head_index -- 节点池链表起始索引 [0..139] (0=空链表直接返回 NULL, 1..139 为有效节点索引)
- r1: u16 value -- 目标匹配值, 与 [node+0] 比较
- 返回: r0 = u32* -- 指向匹配节点的指针 (EWRAM 地址), 未找到时返回 0 (NULL)

## 副作用
无 (纯只读遍历, 无内存写入)
