## plate comment (中文, ASCII 标点)
将有符号整数 r3 以十进制从右到左渲染到 JP 字体行缓冲区, 使用固定 tile 基地址 0xffff824f
(负偏移, 对应特殊符号 tile). 与 render_decimal_digits_jp(+0x30 char base) 互为兄弟,
均采用 __modsi3 取余 / __divsi3 商迭代 / render_glyph_jp_dual_layer 逐位渲染. 差异在于
本函数 tile 基地址为 0xffff824f(-0x7db1) 而非 0x30, 表明用于渲染非 ASCII digit 的特殊
字形(如带圈数字或游戏自定义字符). r0=x_pos, r1=y_row, r2=color_attr, r3=decimal_value.
调用场景: FUN_080cb1cc (large card display hub, 0x080cbe64/0x080cbe70) 及其他 hub 函数.
Constants: tile_base=0xffff824f, digit_mod=10.
