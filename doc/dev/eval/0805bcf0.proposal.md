## plate comment (中文, ASCII 标点)
对 r0 (card_slot_ptr) 执行特殊召唤适格性的全面多层检查, 返回 1 (可特召) 或 0 (不可).
先读 slot[+0x0] (card_id) 调 check_card_field5_is_nonzero; 再调 check_card_field8_is_normal; 两个前置条件均需通过.
通过后: 读 slot[+0x4] bits[17:11] -> slot_id, 调 find_zone_descriptor_by_slot_id;
读 card summon_restriction 标志; 按 restriction==1 -> count_field_copies_of_card (0x148e/0x14da 两个卡 ID) 检查场上副本数;
按 zone_type [0..4] -> get_zone_card_attribute_by_type 查属性 + count_field_copies_of_card (0x166c) + check_value_in_slot_chain;
按 zone_type [5..0xa] -> check_value_in_slot_chain/check_value_in_effect_context_chain;
末段检查: count_occupied_monster_zones_with_effect_bonus >= 3 -> count_available_effect_zones(side, 0x1955, -1)==0 -> 不可;
check_card_field5_is_nonzero -> find_effect_node_in_zone (0x1679);
对于 zone_type [5..0xa]: bl check_card_normal_summon_eligible_full (FUN_0805bc48);
再查 count_field_copies_of_card (0x159d) + check card_id != 0x15ac + check_effect_slot_summon_path_eligible (FUN_0803088c);
最后 [slot[+2] & 0x303e] == 0x201c && count_field_copies_of_card(0x17b9) > 0 -> 可.
indeg=3, 被 FUN_0809f21c/FUN_080ad974/FUN_080bae6c 调用.
