# Naming Proposal: 0x080dc4b0

## 提案
- **proposed_name**: init_pack_card_slot_aob_from_ptn
- **confidence**: high

## plate comment (中文, ASCII 标点)
从 ROM pattern section 数据初始化包店卡牌槽 AOB(动画对象)上下文并设置属性标志. 触发条件: 唯一 caller FUN_080d50e4 (scene_pack) 在包店主页初始化时以槽位 AOB ctx 为参数循环调用. r0=sprite_id(u16, 高 16 bit 将写到 AOB ctx +0x10), r1=anm_variant(u8 [0..N]), r2=aob_ctx_ptr. 函数先从 0x09ce826c+0x1c 取 ROM ptnsect 指针, 然后调用 init_aob_ctx_from_ptnsect(aob_ctx_ptr, ptnsect_ptr, packed_id, 1); 之后对 [aob_ctx_ptr+0x13] 清 bit[2:1] 再 set bit1(= mode=1), 并将 sprite_id 写到 [aob_ctx_ptr+0x10] halfword.

Constants:
- ROM_PTNSECT_TABLE = 0x09ce826c (偏移 +0x1c = AOB ptnsect 指针)
- ATTR_CLEAR_MASK = ~0x6 (清 bits[2:1])
- ATTR_MODE_BIT = 0x2 (bit1 = mode flag)

## 参数签名
- r0: u16 sprite_id [0..65535] (精灵 ID, 高低 16 bit 打包写到 aob_ctx+0x10)
- r1: u8 anm_variant [0..N] (动画变体索引)
- r2: void* aob_ctx_ptr (AOB 上下文指针)
- 返回: void (pop {r0}; bx r0)

## 副作用
- [aob_ctx_ptr..]: 写 AOB ctx 初始化数据 (via init_aob_ctx_from_ptnsect)
- [aob_ctx_ptr+0x13]: bit[2:1] 清零后 set bit1 (mode=1)
- [aob_ctx_ptr+0x10]: 写 sprite_id halfword
