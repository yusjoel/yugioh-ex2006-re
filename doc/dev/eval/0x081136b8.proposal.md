## plate comment (中文, ASCII 标点)
GCC libgcc 双精度浮点相等比较函数 (__eqdf2): 解包两个 double (r0:r1=A, r2:r3=B) 后检测 NaN/Inf 类型; 若任一操作数为 NaN 则返回 1 (非零 = 不相等); 否则调用 __fpcmp_parts_d 比较尾数, 返回 0 表示相等, 非零表示不等.
被 _strtod_r 三次调用, 使用模式 "bl compare_double_eq; cmp r0,#0; bne not_equal".
GCC 约定: 返回 0 = 相等, 非零 = 不相等.

## 参数签名
- r0: u32 a_lo -- double A 低 32 位
- r1: u32 a_hi -- double A 高 32 位 (符号+指数+尾数高位)
- r2: u32 b_lo -- double B 低 32 位
- r3: u32 b_hi -- double B 高 32 位
- 返回: r0 = s32; 0 = A==B, 非零 = A!=B 或含 NaN

## 副作用
