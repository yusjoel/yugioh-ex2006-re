## plate comment (中文, ASCII 标点)
初始化决斗场卡牌精灵的 VRAM 布局与状态控制字节. 首先以 tile_2d_row_copy 将 ROM 中的 28 列 x 2 行图块数据复制到 VRAM 0x06013800 (BG tile VRAM 区域); 再两次调用 copy_bytes_by_halfword 分别复制调色板数据到 0x05000280 / 0x050002a0 (PAL VRAM). 随后调用 dispatch_duel_field_zone_oam_by_type (FUN_080c5b78) 执行区域 OAM 分派. 最后读取 gPrng+0x214 上下文的 zone_active_bits 字段 (offset 0x2, bit1), 若当前 zone 已激活则在 ctx+0x8 中轮转 slot_phase 计数 (4 bit, 自增并回环到 [0..0xf]); 否则进入反向轮转循环寻找下一个可用 slot_phase. 写入 ctx+0x8 (strb @ 080c61d0 / 080c6212). Constants: zone_active_mask=0x2, slot_phase_mask=0xf.
