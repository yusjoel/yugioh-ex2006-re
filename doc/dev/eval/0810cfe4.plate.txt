indeg=0, Sub-type A (no function pointer references). Takes r0=channel_id, r1=source_ptr, r2=type_code as input. First calls reset_sound_channel_entry(r0) to reset the channel. Then writes [base+0x38b] = r2+1 (type_code plus 1 written to channel type byte) and [base+0x8] = r1 (source_ptr written to channel source pointer field). Exit: pop{r4,r5}; pop{r0}; bx r0 (Sub-case E, preserves callee r0).

Constants:
- IWRAM 0x030050cc = audio engine control struct base
- [base+0x38b] = channel type byte (written as type_code+1)
- [base+0x8] = channel source data pointer field
