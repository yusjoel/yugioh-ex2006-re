若指针非空则调用 invoke_r0; 调用返回非零时视为步骤完成, 将 slot_index+1 写回并清除 gPrng

若 slot_index 为 0 或 2 则调用 return_void_pack_page_stub_a/b 跳过实际处理.
完成后继续检查新 slot_index 并调用 return_void_pack_page_stub_b.
返回: 0=步骤未完成, 1=到达空指针(序列结束).
