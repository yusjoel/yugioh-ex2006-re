Equip zone sprite enqueue function (slot status check variant). Receives card_slot_ptr(r0). Checks [card_slot+3] bits[5:4] == 0x20 (equipped state); if no match, returns 0. If match: extracts player_id (byte[+2] bit0) and slot_idx (halfword[+0]); calls get_node_entity_id_in_slot(player_id, slot_idx, type=0xb); then calls enqueue_equip_slot_sprite_attr(player_id, 0xb, slot_idx, 0) to write OAM sprite attr; if entity_id >= 0, calls push_to_effect_slot_array(card_slot_ptr, entity_id&0xffff). Returns r0=1. indeg=0: no bl callers visible; called via runtime fn-ptr dispatch.
Side effects: OAM sprite attr buffer write via enqueue_equip_slot_sprite_attr; effect_slot array append via push_to_effect_slot_array.
Constants: EQUIP_STATUS_BITS=0x30 (bits[5:4] of byte[+3]), EQUIP_FLAG=0x20, SLOT_TYPE=0x0b.
