# Naming Proposal: 0x08095498

## 提案
- **proposed_name**: submit_sprite_row_data
- **confidence**: high

## plate comment (中文, ASCII 标点)
将精灵行数据组装到 256 字节栈缓冲区后提交给写入流水线. 触发条件: 被 indeg=14 的多个场景调用方 (含 card_data/duel_field/font_jp 等 tag) 在精灵 tile 数据提交阶段调用. r0=sprite_id 零扩展写入 sp[0]; r1 为行偏移, 若 r1==-1 则跳过头部字段 sp[2] 写入且行计数起始为 1, 否则写 sp[2]=r1 且计数起始为 2; 若 r3>0 则调用 copy_bytes_by_halfword 将 r3 个 halfword 从 r2 复制到 sp[r5*2]; r5 同步更新为 (r5 + ceil(r3/2)). 随后: bl dispatch_sprite_row_write_by_type(sprite_id, 1); bl write_sprite_row_to_vram_buffer(sp, r5*2). Constants: SKIP_OFFSET=-1, stack_buf_size=0x100=256.

## 参数签名
- r0: u16 sprite_id [0..0xffff] (精灵 ID, lsls/lsrs #0x10 零扩展, 写入 sp[0])
- r1: s16 row_offset [-1..N] (行起始偏移; -1 表示跳过头部字段写入)
- r2: u16* src_data_ptr (源 halfword 数据指针, r3>0 时由 copy_bytes_by_halfword 消费)
- r3: u16 halfword_count [0..N] (源数据半字数; 0 时跳过复制)
- 返回: r0 = void (write_sprite_row_to_vram_buffer 返回值不被消费)

## 副作用
- [sp+0x0] := sprite_id (strh, 栈局部)
- [sp+0x2] := row_offset (strh, 条件写, r1!=-1 时)
- [sp+r5*2..] := src_data_ptr 内容 (copy_bytes_by_halfword 写, r3>0 时)
- 间接: dispatch_sprite_row_write_by_type -> 精灵行写入分派
- 间接: write_sprite_row_to_vram_buffer -> gPrng 精灵缓冲区 strh 写入
