# Naming Proposal: 0x080aa77c

## 提案
- **proposed_name**: dispatch_equip_entry_slot_phase_c
- **confidence**: med

## plate comment (中文, ASCII 标点)
equip 子条目控制结构体 (由 DWORD_080aa7ac 加载的指针) 阶段分派器, 被 FUN_080aaf64 和
FUN_080ab200 两个上游调用 (indeg=2). 从结构体 byte[0x13] 和 byte[0x14] 提取
combined_index = (byte[0x14] & 1) << 7 | byte[0x13] >> 1. 若 combined_index > 9
则 bl FUN_080aaf54 (越界返回 1). 否则 combined_index*4 索引跳转表 (DWORD_080aa7b0),
使用 .hword 0x4687=bx r7 (注: 0x4687 rd=bits[2:0]=7=pc, rm=bits[6:3]=0=r0) 间接跳转.
结构与 FUN_080a9734 对称, 但帧大小 0x8 vs 0x3c 且不恢复 r10.
Constants: STRUCT_BASE=0x0201e4d0 (DWORD_080aa7ac), byte_a=0x13, byte_b=0x14,
combined_index_range=[0..9], switch_table=0x080aa7b4 (DWORD_080aa7b0), out_of_range_exit=FUN_080aaf54.

## 参数签名
- r0/r1: 无独立输入 (r0 被内部 ldr r7,DWORD_080aa7ac 路径覆盖; r1 被 lsrs r1,r0,#0x1 @ 080aa78a 覆盖; .hword 0x464f=mov r7,r1 是 lr 保存模式的一部分, 非 APCS 输入)
- 返回: r0 = u32 0 (case 完成) 或 1 (越界 via FUN_080aaf54)

## 副作用
- 经跳转表 case 函数修改 equip 子条目结构体字段

## 行级注释 (精华)
- @ 080aa77e: .hword 0x464f=mov r7,r1 (注: 0x464f bits[6:3]=1 -> rm=r1, rd=7) -- 保存调用方 lr 至 r7 (pop/bx 退出模式, 非 APCS r1 输入)
- @ 080aa780: .hword 0x4646 (0x4646: H1=bit7=0,H2=bit6=1,rm=bits[6:3]=8,rd=bits[2:0]=6 -> mov r6,r8) -- callee-save
- @ 080aa786: ldr r7,DWORD_080aa7ac -- 加载结构体基址到 r7
- @ 080aa788: ldrb r0,[r7,#0x13] -- 读阶段字节 A
- @ 080aa792: lsls r0,r0,#7; orrs r0,r1 -- 合并 combined_index
- @ 080aa798: cmp r0,#9 -- 越界判断
- @ 080aa79c: bl FUN_080aaf54 -- 越界 -> 返回 1
- @ 080aa7a0: lsls r0,r0,#2 -- index*4
- @ 080aa7a6: ldr r0,[r0] -- 读跳转目标
- @ 080aa7a8: .hword 0x4687=bx pc(r0) -- 间接跳转

## 调用图
- caller: addr 0x080aaf64 (tags: 无; role: equip 阶段分派, 在 combined_index [0..7] 范围内调用)
- caller: addr 0x080ab200 (tags: 无; role: equip 子条目主控, 条件分支调用)
- callee: FUN_080aaf54 (越界出口)

## 置信度证据
- 层 1 (函数体): 标准 combined_index 提取 + 10-case jump table, 与家族对称
- 层 2 (caller 模式): 两个 equip 上游, indeg=2 确认共享
- 层 3 (.hword 解码): 0x4687 rd=7 (pc), rm=0 (r0): bx r0 via pc 写 = 间接跳转

## 置信度 / 升级路径
- qualifier "_c" 需确认与 FUN_080a9734 ("_b") 是否处理相同结构体但不同 combined_index 语义
- STRUCT_BASE: ASM 确认 DWORD_080aa7ac = 0x0201e4d0, 与家族其他成员相同
- switch_table: ASM 确认 DWORD_080aa7b0 = 0x080aa7b4 (紧接 literal pool 之后的跳转表)
- 升级路径: 追踪跳转表各 case 目标地址确认 combined_index [0..9] 的功能
