# Naming Proposal: 0x080fbea0

## 提案
- **proposed_name**: init_pack_vram_minimal
- **confidence**: high

## plate comment (中文, ASCII 标点)
pack scene 轻量版 VRAM/硬件初始化. 清 pack state flag, 关显示 (DISPCNT=0), 配置 BG0CNT/BG1CNT; 调用 reset_all_bg_scroll_regs_and_shadows 和 upload_pack_vram_and_palette; 清三块 VRAM (BG tile/OBJ tile/BG screen); 最后 load_pack_tile_and_map_to_vram 加载 pack tile. 与 init_pack_scene_vram_full (0x080fbf18) 相比省略字体渲染和 BG2/BG3 配置.

## 参数签名
- r0..r3: void (无参数)
- 返回: void (pop {r4}; pop {r0}; bx r0)

## 副作用
- [gPrng+0x174] := 0 (清 pack state flag)
- [DISPCNT 0x04000000] := 0 (显示关)
- [BG0CNT 0x04000008] := 0x4
- [BG1CNT 0x0400000a] := 0x105
- [VRAM 0x06004000..+0x10000]: zero_fill_by_halfword 0x8000 halfwords
- [VRAM 0x060c0000..+0x4000]: zero_fill_by_halfword 0x2000 halfwords
- [VRAM 0x06010000..+0x10000]: zero_fill_by_halfword 0x8000 halfwords
- VRAM: load_pack_tile_and_map_to_vram 写 pack tile 数据
