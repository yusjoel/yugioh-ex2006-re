## plate comment (中文, ASCII 标点)
LP 计数器 sprite 入队函数, 高频工具 (indeg=42), 被各类 equip/duel_field 显示函数调用.
r0 = player_side [0..1] (由 caller 在 bl 前通过 lsrs bit31 或 ldrb[+0x2]/lsls #0x1f/lsrs #0x1f 提取).
从 gP1LifePoints (0x0201c4e0) + 0x1CE0 (= 0xe7*32) 读取 LP 计数器状态 dword.
根据 player_side 选择 OAM attr0: player=0 -> 0x53 (Y=83, square 8x8), player=1 -> 0x8053
(Y=83, hidden/off-screen bit set, OBJ_DISABLE).
将 dword 低 16 位作为 attr1, 高 16 位作为 attr2, 调用 enqueue_sprite_attr_record(attr0, attr1, attr2, 0).
出口 pop {r0}; bx r0 (void 出口, r0 不携带返回值语义).
Constants: gP1LifePoints=0x0201c4e0, lp_counter_slot_offset=0x1CE0 (=0xe7<<5),
OAM_P1=0x53 (Y=0x53, normal), OAM_P2=0x8053 (Y=0x53, OBJ disable).

## 参数签名
- r0: u32 player_side [0..1] (0=P1, 1=P2; 由 caller lsrs #0x1f 或 lsls/lsrs #0x1f 从 bit 提取)
- 返回: void (pop {r0}; bx r0 -- r0 为恢复的 lr, 无返回值)

## 副作用
