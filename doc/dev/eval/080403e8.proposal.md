## plate comment (中文, ASCII 标点)
equip 动画帧驱动器. 读 [0x0201bcc0+0x810](动画步骤计数器) 判断当前动画阶段: 为 0 时进入首帧
逻辑, 以 r0 传入的模式码 [0..4] 触发 dispatch_card_display_op(op=0x4, card_slot=r0_arg, mode=0, flag=0),
同时写 gP1LifePoints+0x1cf4 := r0_arg, 调用 rebuild_equip_chain_refs, 并将计数器 +1; 非零时调用
play_ui_effect(0x4) 轮询动画完成, 完成后以 dispatch_card_display_op(op=0x24, 0, 0, 0) 清零显示状态,
再将计数器清零. 由 5 个模式分发 stub (0x08040450/0x0804045c/0x08040468/0x08040474/0x08040480)
包装后分别以固定 r0=0..4 调用本函数.
Constants: step_counter=[0x0201c4d0](0x0201bcc0+0x810); lp_equip_slot_ptr=gP1LifePoints+0x1cf4;
op_start=0x4; op_clear=0x24.

- 返回: r0 = void (pop {r0}; bx r0 尾返回, 无独立写 r0)
