## plate comment (中文, ASCII 标点)
根据当前玩家 ID (r0) 与 EWRAM 状态字 [0x0201e2a0+0x4] 中存储的对手方 ID (异或 1 取反) 进行比对, 确定使用哪段 VRAM 区域 (0x0600f000 基地址 + 偏移或 +8 字节), 然后将 LP 数值 (r1, 最大 0x0001869f=99999) 逐位分解为 10 进制各数字, 以连续写 halfword 方式填入 VRAM tile 索引区 (strh to [r4]).
触发场景: play_ui_effect_0e (0x080bf394) 在 duel field 刷新生命值显示时调用本函数, 以及 FUN_080ca8ec (duel field 初始化流程中调用). 副作用: 写入 VRAM 0x0600f000 区域内若干 halfword (tile 索引).

Constants:
- LP_VRAM_BASE = 0x0600f000 (生命值 tile VRAM 基地址)
- LP_DIGIT_AREA_OFFSET_P2 = 0x89*8 = 0x448 (对手区 tile 偏移)
- LP_DIGIT_AREA_OFFSET_P1 = +8 (己方区 tile 偏移)
- 0x9a*2 = 0x134 (tile 起始索引 base, 数字字符 tile)
- 0x0001869f = 99999 (LP 数值上界 clamp)
- EWRAM_GAME_CTX = 0x0201e2a0 (游戏状态结构体 EWRAM 地址)

## 参数签名
- r0: u16 player_id [0..1] - 当前玩家 ID (与 [0x0201e2a0+4] XOR 1 比较确定 VRAM 区域)
- r1: u32 lp_value [0..99999] - 要写入的 LP 数值 (超过 99999 则 clamp)
- 返回: void (无 r0 写入, pop+bx)

## 副作用
- [VRAM 0x0600f000 + player_offset + offset]: 写 4 个 strh (4 位 LP 数字 tile 索引), 从 r4 初始地址向下递减 2 字节步进, 共 5 次循环
