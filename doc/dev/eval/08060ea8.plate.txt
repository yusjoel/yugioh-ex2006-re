check_equip_slot_eligible_with_chain_absent_and_spell_dispatch

Equip slot eligibility predicate. Three-level condition check.
Cond 1: check_equip_slot_chain_absent(slot_ptr) -- if 0 -> return 0 (chain present).
Cond 2: check_spell_zone_slot_placeable(player_id) -- if 0 -> return 0 (no spell zone).
Cond 3: dispatch_effect_handler_by_card_id(player_id, card_id, 0) -- if > 1 -> return 1.
Differs from 0x08060e5c: no Crimson Ninja node check; starts directly from chain_absent.
Member of check_equip_slot_eligible cluster.

Inputs:  r0=SlotPtr* slot_ptr (byte[+2] bit0=player_id, halfword[+0]=card_id)
Returns: r0=u32 (1 if chain_absent AND spell_zone_ok AND dispatch > 1, 0 otherwise)
Callees: check_equip_slot_chain_absent, check_spell_zone_slot_placeable,
         dispatch_effect_handler_by_card_id
