## plate comment (中文, ASCII 标点)
处理 SIO 链路一帧牌组同步数据. 被 0x080ef958 (SIO 状态机) 在完成握手后调用. 函数先读取 IWRAM [+0x0341] 连接激活标志, 临时存储上一帧数据指针对 (d5/d6 交换), 更新轮次半字 [+0x0342], 清 active 标志; 若 active==0 直接跳至末尾 OR 合并字节并退出. 若 active != 0: 将 IWRAM 计数器 [+0x041c] 清零, 循环 2 轮 (i=0..1), 每轮计算 card_stats_table 偏移并累加 10 个卡牌 halfword 值到校验累加器, 比较累加结果 (lsls r1,r0,#16 == 0 分支 vs != 分支) 分别处理, 置 [OBJ_VRAM+0x4] 标志位; 末尾 OR [0x030003a0+0x0342] |= [+0x0341] 合并激活字节.

Constants:
- SIO_STATE_BASE=0x030003a0 // IWRAM SIO 结构基址
- ACTIVE_FLAG_OFF=0x0341 // 当前帧激活标志偏移
- ROUND_HALF_OFF=0x0342 // 轮次 halfword 字段偏移
- COUNTER_OFF=0x041c // 轮次计数器偏移
- OBJ_VRAM_FLAG=0x05000004 // OBJ 属性 VRAM 标志写入地址
