Function: Checks whether effect slot matches zone entry; if matched reads side/type and triggers equip activation.
Entry: r0=effect_slot_ptr. Calls check_effect_slot_matches_zone_entry(slot_ptr, 0, 0);
returns void if no match.
On match: calls read_effect_slot_side_and_type(slot_ptr, 0) to get packed result;
extracts side (bits[7:0]) and slot_type (bits[15:8]);
calls apply_slot_equip_activation_with_eligibility_check(slot_ptr, side, slot_type, sp[0]=0, 0).
Purpose: simplified equip activation trigger without additional zone slot state validation.
Side effects: Triggers equip activation via apply_slot_equip_activation_with_eligibility_check.
Constants:
  SP_FLAG=0x0  // sp[0]=0, activation flag cleared
