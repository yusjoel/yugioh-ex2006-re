# Naming Proposal: 0x0802ecbc

## 提案
- **proposed_name**: clear_equip_refs_for_leaving_slot
- **confidence**: med

## plate comment (中文, ASCII 标点)
当一张卡片离开场地时, 扫描所有魔法/陷阱区槽位 (zone 5..10), 查找其中对该离场卡片的装备链引用并清除. r0=slot_ptr (指向离场卡片场地槽的指针). 函数: 从 slot_ptr[0] 提取 player_id 和 zone_index; 遍历 zone 5..10 的所有玩家槽位; 对于处于特定状态 (状态字 bit 匹配) 的槽, 沿其装备链 (基址 0x0201d9c0) 遍历, 当节点匹配 DAT_0802eda4=0x00031368 且 halfword[4] == r8 (目标 zone_idx) 时调用 replace_slot_chain_ref_by_id 清除引用. 扫描完成后, 再调用 find_chain_node_by_dual_halfword + replace_slot_chain_ref_by_id 清理最后一个引用. 调用方 FUN_08032280 在玩家 id 匹配且 zone>0xa 且 zone!=0xe 时调用.

## 参数签名
- r0: word* slot_ptr - 指向离场卡片场地槽的指针 (sp[0] 保存); 高寄存器: r10=DAT_0802ed8c=0x0201c510 (内部加载)
- 返回: void (pop {r0}; bx r0)

## 副作用
- 通过 replace_slot_chain_ref_by_id 修改装备链节点 (写 0x0201d9c0+node_id*8+offset)
