# Naming Proposal: 0x0801626c

## 提案
- **proposed_name**: write_palt_block_to_vram
- **confidence**: med

## plate comment (中文, ASCII 标点)
将 PALT (palette) 数据块写入 GBA 调色板 VRAM. 接收资源结构体指针 (r0=src_entry) 和目标缓冲信息指针 (r1=dst_info). 根据 src_entry[+0x14] bits[3:0] 的类型字段区分 BG 调色板 (type 0-3, 写入 0x05000000) 和 OBJ 调色板 (type 4, 写入 0x05000200). 写入前检查 src_entry[+0x10] (signed x>=0), src_entry[+0x18] bit31 (可见性), 以及 dst_width 非零. 使用 bios_cpu_fast_set 执行实际写入. 由 FUN_08016a7c (资源列表应用器) 在遇到 PALT 标签时调用.

Constants: 0x05000000 = BG 调色板 VRAM 基址; 0x05000200 = OBJ 调色板 VRAM 基址.

## 参数签名
- r0: void* src_entry -- PALT 资源条目指针 (结构体, 含 type/x/visible/data 等字段)
- r1: void* dst_info -- 目标帧缓冲信息指针 ([+0x8] = width 备用值)
- 返回: r0 = u32 0 (固定返回 0, 表示操作完成)

## 副作用
- [VRAM palette 0x05000000 或 0x05000200]: bios_cpu_fast_set 写入调色板数据
- [src_entry 结构体]: 无修改
