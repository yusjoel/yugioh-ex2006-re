## plate comment (中文, ASCII 标点)
统计玩家场上满足"配对 + field5 非零"条件的格数, 支持两个路径:
路径 A (check_card_field5_is_nonzero != 0): 扫描怪兽区 (格 0..4), 过滤 r9 指定格,
  对每格调用 check_slot_card_pair_allowed(player, slot, r2, r10) 且 [slot+0x8]!=0, 则计数++.
路径 B (check_card_field5_is_nonzero == 0): 扫描魔陷区 (格 5..10), 过滤 r9 指定格,
  检查 active bit + card_id>0 + [slot+0x10]>>1 bit clear + card_id==r8, 则计数++.
Non-APCS 输入: r8=card_id_filter (caller-set); r9=skip_slot (caller-set);
r10=equip_ref (caller-set, 传给 check_slot_card_pair_allowed).
实际语义依赖 check_card_field5_is_nonzero(r6) 对 player 的判断: true -> 进入路径 A (怪兽区配对);
false -> 进入路径 B (魔陷区 card_id 过滤).
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, slot_entry_size=0x14,
monster_zone=0..4, trap_zone=5..10.
