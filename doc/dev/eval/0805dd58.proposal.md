## plate comment (中文, ASCII 标点)
激活判定谓词. 入参为 r0=主卡槽指针, r1=装备槽指针. 若 r1==NULL 则返回 0.
检查 r4(装备槽) +0x3 byte 的 bits[5:4] 是否为 0 (0x30 mask & value == 0); 非零返回 0.
读取主卡槽 card_id (r2/+0x0), 与三个已知枚举值比较: 0x134f / 0x1350 / 0x1351 (unknown card_ids; not in data.md).
按匹配分支分别调用 get_card_extended_stat_field6 检查返回 0x16 或 0x17,
再调用 get_card_extended_stat_field9 检查返回 2 或 4. 全部满足则返回 1.
注: 出口为 pop{r4,r5}; pop{r1}; bx r1, 返回值为 r0.

Inputs: r0 = card_slot_ptr (主卡槽指针); r1 = equip_slot_ptr (装备槽指针, 可为 NULL)
Outputs: r0 = 1 (全部条件满足) / 0 (任一不满足)
Side effects: 无外部写入.
Constants: EQUIP_FILTER_MASK=0x30, CARD_ID_A=0x134f (unknown card_id; not in data.md), CARD_ID_B=0x1350 (unknown card_id; not in data.md), CARD_ID_C=0x1351 (unknown card_id; not in data.md), FIELD6_THRESHOLD_LO=0x16 (22), FIELD6_THRESHOLD_HI=0x17 (23), FIELD9_THRESHOLD_A=2, FIELD9_THRESHOLD_B=4

## 参数签名

- 返回: r0 = u8 1(满足) / 0(不满足)
