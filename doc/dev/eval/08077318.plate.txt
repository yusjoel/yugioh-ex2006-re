Reads zone_count (3-bit field, [0..7]) from effect node [r4+6] bits[4:2]; if 0 immediately returns 0.
When zone_count > 0, calls read_effect_slot_zone_type(effect_node, zone_count-1) to get zone_type, then extracts player_id from [r4+2] bit0, calls find_hand_slot_idx_by_set_code_alt(player_id, zone_type) to get hand slot index.
If slot index >= 0, computes gHandZoneSlots[player_id][slot_idx] offset and calls enqueue_hand_card_sprite_alt_by_zone_slot(effect_node, slot_ptr).
Regardless of whether a slot is found, decrements [r4+6] bits[4:2] zone_count by 1 and writes back, returns 0x80.
Dispatched via runtime function pointer (indeg=0).

Constants:
- ZONE_COUNT_MASK=0x1c (bits[4:2] of [effect_node+6])
- PLAYER_STRIDE=0x868 (DAT_0807737c)
- gHandZoneSlots=0x0201cab0 (DAT_08077380)
