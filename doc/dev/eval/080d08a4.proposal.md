## plate comment (中文, ASCII 标点)
决斗场地已选中槽位的卡片详情面板完整渲染函数. 由 FUN_080cc208 和 FUN_080d2c60 调用 (indeg=2).
执行 8 个顺序渲染步骤:
(1) copy_bytes_by_halfword(dst=0x0600b0e0, src=0x0988ad78, size=0x3e0) -> 写 BG tile 框架图形;
(2) copy_bytes_by_halfword(dst=0x05000160, src=0x0988b158, size=0x40) -> 写 OBJ 调色板 (PAL VRAM);
(3) setup_line_buf_with_font_and_align(font=0x1b, align=2, flag=1, param=0) -> 配置 JP 字体行缓冲;
(4) 读取 gDuelCtx+0x6c2c+0x2e40 byte bits[2:0] (card_attr), 更新 card_info_ctx+0x8 byte 并设 bit1;
(5) 根据 card_attr bits[1:0] 查询 font_jp_base_table 并写入 card_info_ctx+0x4 (字体指针);
(6) text_render_wrapper(r0=2, r1=2, r2=7, r3=card_info_ctx) x2 -> 渲染两行卡名 JP 文字;
(7) zero_fill_by_halfword(buf=0x0600bc00, size=0x6c0) + commit_line_buffer_to_sprite_vram(buf=0x0600bc00, page=0);
(8) 继续 tile_2d_row_copy x 10+ 次拷贝卡片边框各分区 + write_line_buf_to_bg_tile_vram + game_str_id_to_row x3 + measure_string_pixel_width -> 居中对齐的卡片描述文字渲染.
副作用覆盖 BG VRAM (0x0600b0e0), OBJ PAL VRAM (0x05000160), OBJ tile VRAM (0x0600bc00),
EWRAM card_info_ctx (0x02006ed0+0x6c2c 区域), EWRAM line_buf_state.
Constants: BG_TILE_DST=0x0600b0e0; PAL_DST=0x05000160; SPRITE_BUF=0x0600bc00;
FONT_ID=0x1b; CARD_ATTR_OFFSET=gDuelCtx+0x6c2c+0x2e40; GAME_STR_ID=0x3e9.
