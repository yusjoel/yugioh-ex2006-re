## plate comment (中文, ASCII 标点)
被 8 个卡片列表显示函数调用 (indeg=10), 负责将一行卡片图标对应的 OAM 精灵条目写入 OAM 表.
r0=OAM 起始槽号 (mov r8,r0 保存), r1=OAM Y 像素坐标, r2=起始 X 像素坐标 (存至 sp+0x4), r3=卡片行数 (lo16).
内部逻辑: 以 r1-2 (count-2) 为循环驱动, 每轮对 7 个子槽 (r7=0..6) 依次调用 write_oam_entry_from_packed_args, 每个 OAM 槽 X 坐标按槽号偏移累加 (+2 或 +4 像素步长). r4 为每行 OAM 宽度标志 (1/2/4, 由剩余行数决定); r6 为每槽 palette/attr 字 (0x0000/0x4040/0x8040/0x8080 等, 由槽位 r7 和宽度 r4 分支计算). 每写完一行 7 槽, 更新 X 起点 r5 并递减剩余行计数, 直至为 0 退出循环.
Constants: STRIP_SLOTS=7 (r7 0..6); WIDTH_4=0x4, WIDTH_2=0x2, WIDTH_1=0x1; PAL_0x8040=0x00008040, PAL_0x8080=0x00008080, PAL_0x4040=0x00004040.

## 参数签名
- r0: u8 oam_start_slot - OAM 起始槽索引 (mov r8,r0 后参与地址计算), [0..255]
- r1: s16 y_pixel - OAM Y 像素坐标 (负数向上偏屏), [-128..160]
- r2: u16 x_start_pixel - 精灵行首 X 像素坐标, [0..511]
- r3: u16 card_row_count - 要渲染的卡片行数 (lo16; r9=count, loop count=count-2), [2..10]
- 返回: void (无返回值, 函数仅写 OAM)

## 副作用
- [gPrng sprite_table + slot*8 + 0..2] := OAM attr0/attr1/attr2 (via write_oam_entry_from_packed_args, 每行 7 个槽共 7 次调用)
