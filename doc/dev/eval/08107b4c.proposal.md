# Naming Proposal: 08107b4c

- **proposed_name**: dispatch_oam_write_by_mode
- **confidence**: high

## plate comment (中文, ASCII 标点)
根据当前场景模式标志决定调用哪个 OAM 写入函数: 若 [0x0202f3c0+0x1e] halfword 的 bits[13:12] == 0xc000>>7 (即 0x6002) 且 r3!=0, 则调用 write_obj_attr_packed (仅写属性); 否则调用 write_oam_entry_from_packed_args (完整 OAM 写入). 被多个 (indeg=14) 场景渲染函数频繁调用, 是 OAM 写入的中心分派点.

## 参数签名
- r0: u32 oam_index — OAM 条目序号 (保存至 r4)
- r1: u16 attr0 — OAM attribute 0 (高 16 位截断)
- r2: u16 attr1 — OAM attribute 1 (高 16 位截断)
- r3: u32 mode_flag — 非 0 时触发 write_obj_attr_packed 路径 (保存至 r5)
- 返回: r0 = u32 1 (fixed; success, no failure path)

## 副作用
- OAM: 写入 OBJ 属性 (通过 write_oam_entry_from_packed_args 或 write_obj_attr_packed)
