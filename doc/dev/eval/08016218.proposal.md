# Naming Proposal: 0x08016218

## 提案
- **proposed_name**: get_bgdt_second_blob_ptr
- **confidence**: med

## plate comment (中文, ASCII 标点)

Function: 在 GFX 资源链表中按 "BGDT" (0x54444742) 标签查找条目,
计算第二个内联数据 blob 的起始地址: entry_ptr + 0x1c + align_up([entry+0xc], 4).
其中 [entry+0xc] 为第一个 blob 的字节大小, align_up 向上取整到 4 字节边界,
从而跳过第一个数据 blob 定位到第二个 blob.
indeg=0; 为 BGDT 多 blob 数据布局访问工具.

Side effects: 无 (纯地址计算).

Constants:
- BGDT_TAG = 0x54444742 ("BGDT", DWORD_08016234)
- BGDT_DATA_OFFSET = 0x1c (第一个 blob 起始偏移)
- BGDT_SIZE_FIELD = [entry+0xc] (第一个 blob 字节大小)
- WORD_ALIGN = 4 (adds r0,#3; asrs/lsls #2 = ceil(x/4)*4)

## 参数签名
- r0: void* gfx_list_header (GFX 资源链表头指针)
- 返回: r0 = void* second_blob_ptr (BGDT 第二个内联数据 blob 起始地址; pop {r1}; bx r1 = Sub-case E)
