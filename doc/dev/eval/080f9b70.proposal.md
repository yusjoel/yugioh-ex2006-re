## plate comment (中文, ASCII 标点)
逐字节比较两段内存, 若全部相等返回 0, 遇到首个不等字节立即返回 1. 等价于 memcmp 的简化布尔版本. 由 FUN_080f9b98 (0x080f9b98) 在谜题初始化流程中调用, 以固定参数 r0=0x09e4f568(ROM 谜题种子), r1=0x02000000(EWRAM 工作区), r2=8 执行 8 字节完整性校验; 通过则跳 FUN_080f9c40 做 checksum 二次验证. 纯比较叶子, 无任何外部写副作用.

- r2: u32 count - 比较字节数 [1..n]
- 返回: r0 = u32 result (0=全部相等, 1=存在差异)
