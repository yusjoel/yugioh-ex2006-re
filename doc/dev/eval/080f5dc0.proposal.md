# Naming Proposal: 0x080f5dc0

## 提案
- **proposed_name**: copy_halfwords_rounded_up
- **confidence**: high

## plate comment
将 src (r1) 的字节数据复制到 dst (r0), 复制字节数为 ceil((r2+1)/2)*2 (即 r2+1 向上对齐到偶数后的字节数). 内部调用 copy_bytes_by_halfword (0x080f4ea4) 执行实际复制, 传入半字数 = ceil((r2+1)/2). 返回 r0 = 实际复制的半字数 (word_count). 与地址紧邻的 FUN_080f5de0 (0x080f5de0) 字节完全相同, 为 GCC 重复产生的双实例.

Side effects:
- [dst..dst+r4*2]: 写入 src 内容 (通过 copy_bytes_by_halfword)

Constants:
- ALIGN_BIAS = 1 // (r2+1)>>1 向上对齐为半字数

## 参数签名
- r0: void* dst 目标地址
- r1: const void* src 源地址
- r2: u32 byte_count 字节数 (内部 ceil 到偶数)
- 返回: r0 = u32 实际复制的半字数 (pop {r1};bx r1, Sub-case E)

## 副作用
- [r0..r0+ceil((r2+1)/2)*2]: 写入 src 数据
