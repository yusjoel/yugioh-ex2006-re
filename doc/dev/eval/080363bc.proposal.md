# Naming Proposal: 0x080363bc

## 提案
- **proposed_name**: check_slot_field_zone_card_eligible
- **confidence**: med

## plate comment (中文, ASCII 标点)
综合检查指定场地槽 (r0=player_id, r1=slot_idx) 是否为合格的场地区域卡槽. 首先从 0x0201c510+player*0x868+slot*0x14 定位槽结构, 读取 bit12 激活标志和 slot+0x10 的附加字段 (装备限制位 bit5 及 bit1). 若激活位为零或两个限制位均设置则立即返回 0. 随后调用 check_card_id_is_field_zone_special (FUN_0804c140) 过滤特殊场地卡; 再对卡 id 与 0x1826/0x17e4/0x1860 等做多级比较. 满足条件时调用 count_eligible_zone_slots_all_flags 验证对侧是否有合格槽, 最终返回 1 (合格) 或 0 (不合格).

## 参数签名
- r0: u8 player_id [0..1] (归属方)
- r1: u8 slot_idx [0..4] (场地槽索引)
- 返回: r0 = u8 eligible (1=合格, 0=不合格)

## 副作用
无外部写副作用 (只读检查函数).
