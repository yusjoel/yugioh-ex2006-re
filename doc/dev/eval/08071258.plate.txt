Predicate function. Accepts slot_ref_ptr (r0) and slot_ptr (r1). Reads 32-bit zone_word from [r0+0], ANDs with mask 0x00f0ffff, checks if result equals 0x14c0 (= 0xa6<<5, specific equip zone zone_type field encoding).

Returns 0 immediately if no match. If match: reads player_id from r1[+2] bit0, reads hword from r0[+4] shifted right 1 bit, calls submit_effect_zone_lp_and_shape_sprites(player_id, card_halfword) to submit LP and shape sprites.

Used as predicate callback for find_equip_chain_node_by_pred (THUMB fn-ptr 0x08071259 passed by scan_equip_chain_for_zone_pattern_sprites).

Side effects: indirectly writes sprite queue via submit_effect_zone_lp_and_shape_sprites.

Constants:
ZONE_WORD_MASK = 0x00f0ffff
ZONE_TYPE_EQUIP_PATTERN = 0x14c0 (= 0xa6<<5, equip zone zone_type field encoding)
