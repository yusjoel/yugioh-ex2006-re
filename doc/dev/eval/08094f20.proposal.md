# Naming Proposal: 0x08094f20

## 提案
- **proposed_name**: write_card_display_index_if_above_bit
- **confidence**: high

## plate comment (中文, ASCII 标点)
有条件地写入卡牌显示 index: 仅当参数 r1 (target_index) 大于 get_card_data_bit_by_index 的返回值时, 才调用 write_card_display_index_entry(r0, r1). 即只有当目标 index 高于当前 bit 提取值时才更新显示条目. 调用方场景: 多个 card_data/card_frame/duel_field 处理器在更新卡牌显示 index 时需要确保只写入更高优先级的 index, 本函数提供该 "only if greater" 语义. indeg=7, 被 5 个不同模块的调用方使用.

## 参数签名
- r0: ptr card_entry - 卡牌数据条目指针
- r1: u32 target_index [0..0xFF] - 待写入的显示 index 值
- 返回: void (无返回值, 仅副作用)

## 副作用
- 若 r1 > get_card_data_bit_by_index(r0, r1): write_card_display_index_entry(r0, r1) -- 更新卡牌显示 index
