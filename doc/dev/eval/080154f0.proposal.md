## plate comment (中文, ASCII 标点)

Function: 检查 GL_Scrollbar 是否仍可向前滚动 (还有未显示的后续条目).
读取 pThis[+0x6]=total_count (u16) 和 pThis[+0xb]=visible_count (u8),
计算 remaining = total_count - visible_count; 若 pThis[+0x4]=current_pos (u16) < remaining
