Checks whether card_id (r0) satisfies equip display criteria. Three-stage check: (1) card_id==0x157e: calls get_card_extended_stat_field6(r1=card_ptr); returns 1 if field6==1, else 0. (2) card_id==0x19ef (Elemental Hero Erikshieler): checks four criteria_code values (0x18a6=EHero Avian, 0x18a7=Burstinatrix, 0x18a8=Clayman, 0x18f9=Bubbleman) via check_card_equip_criteria_by_ext_field6; returns 1 on any match. (3) Other card_id: calls find_equip_display_entry_by_card_id in ROM table; on entry found uses entry[+2/+4/+6] three criteria_code values; returns 1 on any match. Returns 0 if not found or no match. No side effects. Constants: CARD_ID_A=0x157e, CARD_ID_ERIKSHIELER=0x19ef, CRITERIA_AVIAN=0x18a6, CRITERIA_BURSTINATRIX=0x18a7, CRITERIA_CLAYMAN=0x18a8, CRITERIA_BUBBLEMAN=0x18f9.
