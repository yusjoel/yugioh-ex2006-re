Sets the player display state bit after refreshing the equip-slot eligibility bitmap. First calls check_equip_slot_eligible_via_effect_node_and_bitmap(slot) to refresh the eligibility bitmap (return value not used for branching), then takes player_id from slot[+2] bit0 and calls set_player_state_bit_with_sprite_update(player_id, 0, 1) to set the player-side display state bit and trigger a sprite update. Returns 0 fixed. Called via fn-ptr by the equip display driver (indeg=0).
