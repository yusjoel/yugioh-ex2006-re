Function: Equip slot eligibility check for paired card group (card_id 0x146f or 0x1907). First verifies owner_bit equals equip_card.side[bit0] and slot_idx [0..4] in range, then reads equip card_id (ldrh [r0+0x0]). If card_id == 0x146f (Cathedral of Nobles), enters 0x1414-region chain_field comparison path; if card_id == 0x1907 (Transcendent Wings), enters 0x0000-region chain_field comparison path. Both paths read zone chain_field bits and compare against a constant mask (pool DAT 0xa3d00000 / 0xc5500000 respectively); match returns 1, mismatch returns 0.

Params: r0=u8* card_ptr (equip card; [+0x2] bit0=side, [+0x0] ldrh=card_id u16); r1=u8 owner_bit [0..1]; r2=u8 slot_idx [0..4]
Returns: r0=u32 eligible (0=ineligible, 1=eligible)
Side effects: none (leaf function, no external writes)
Constants: SLOT_IDX_MAX=4, ZONE_BASE=0x0201c510, STRIDE=0x868, CARD_ID_A=0x146f (Cathedral of Nobles), CARD_ID_B=0x1907 (Transcendent Wings), MATCH_MASK_A=0xa3d00000, MATCH_MASK_B=0xc5500000
