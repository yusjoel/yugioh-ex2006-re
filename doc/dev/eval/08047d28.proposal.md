## plate comment (中文, ASCII 标点)
计算指定玩家槽位是否可装备目标, 并在满足条件时将装备指示 sprite 属性入队. 入口接收 player_id (r0) 和 slot_idx (r1). 先用 memset 清零 0x18 字节的栈上临时结构; 读取 slot 卡牌状态位, 修改装备激活标志 (BIC+OR 操作于 slot_entry byte[2]); 随后以计算出的 bit_mask (1<<(player*16+slot)) 调用 update_equip_target_bitmap_for_field; 若返回非零且 slot 卡牌状态码==1 则调用 enqueue_sprite_attr_type11 提交装备箭头 sprite. 返回 1 表示装备可激活, 0 表示不可.

Side effects:
- memset: 清零 sp 上 0x18 字节局部结构体 (栈局部, 非外部副作用)
- [slot_entry byte+2]: 装备激活标志 BIC/OR 写入
- update_equip_target_bitmap_for_field: 写入装备目标 bitmap
- enqueue_sprite_attr_type11: 写入 OAM sprite 属性缓冲区 (条件执行)

Constants: bit_mask=1<<(player*16+slot), equip_slot_stride=0xe, DAT_08047d8c=0x14e2 (sprite attr param).

## 参数签名

- r1: u8 slot_idx -- 槽位索引 [0..10] -> r6
- 返回: r0 = u32 1 (装备可激活) / 0 (不可激活)

## 副作用
