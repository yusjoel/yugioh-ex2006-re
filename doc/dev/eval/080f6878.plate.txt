Writes a sprite entry to the gPrng OAM shadow buffer after checking slot availability (slot_flag[0] != 0x80). Same structure as write_oam_entry_with_slot_check (0x080f67f4): reads gPrng+0x400 slot flag; if slot is full returns immediately; otherwise computes attr0/attr1/attr2 from parameters, writes to the corresponding slot, and increments the count. r0=x_coord/entry_key, r1=y_coord, r2=color_mask, r3=extra_attr. .hword 0x469c (asm 423131) = mov r12,r3, saves extra_attr to r12 for use when writing attr2.

Constants:
- gPrng = 0x03000040
- SPRITE_TABLE_OFFSET = 0xde*2 = 0x1bc
- SLOT_FLAGS_OFFSET = 0x80*8 = 0x400 (slot flag array offset within gPrng struct)
- SLOT_FULL_MARK = 0x80 (slot-full marker value)
- X_MASK = 0xfffffe00 (attr1 X coordinate mask, 9 bits)

Inputs: r0=packed_x (low 16=x_coord; >>0x17 & 0x1ff for attr1 X [0..511]), r1=y_coord [0..255], r2=color_mask (color/palette attribute mask), r3=extra_attr (additional OAM attr value)
Returns: void (pop{r0};bx r0 Sub-case E)

Side effects:
- [gPrng_sprite_table_ptr + slot*8 + 0]: := attr0 (y + flags)
- [gPrng_sprite_table_ptr + slot*8 + 2]: := attr1 (x + size)
- [gPrng_sprite_table_ptr + slot*8 + 4]: := attr2 (tile + priority)
- [gPrng + 0x400 + 0]: slot count byte +1

Confidence: med. No static callers to confirm extra_attr meaning. Upgrade: scan gPrng OAM write hub for fn-ptr table referencing this function; or runtime breakpoint to capture r3.
