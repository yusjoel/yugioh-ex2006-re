# Naming Proposal: 0x08114070

## 提案
- **proposed_name**: compare_float_eq
- **confidence**: high

## plate comment (中文, ASCII 标点)
GCC libgcc 单精度浮点相等比较函数 (__eqsf2): 解包两个 float (r0, r1) 后检测 NaN (kind > 1 -> 返回 1 = 不相等), 正常路径调用 __fpcmp_parts_f 返回比较结果.
GCC __eqsf2 约定: 0 = A==B, 非零 = A!=B 或含 NaN. 调用方通常使用 "bl compare_float_eq; cmp r0,#0; bne not_equal" 模式.
该函数在静态调用图中 indeg=0 (未被任何函数直接调用), 无函数指针引用, 属于编译器生成的未使用符号 (dead code).
与 compare_double_eq (0x081136b8) 结构完全对称, 仅精度不同 (__unpack_f vs __unpack_d, __fpcmp_parts_f vs __fpcmp_parts_d, 参数减少至 r0/r1).

## 参数签名
- r0: f32 a -- 单精度浮点 A (IEEE 754 bit-pattern)
- r1: f32 b -- 单精度浮点 B (IEEE 754 bit-pattern)
- 返回: r0 = s32; 0 = A==B, 非零 = A!=B 或含 NaN

## 副作用
- 栈: 解包临时结构 (局部)
