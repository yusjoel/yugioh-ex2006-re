## plate comment (中文, ASCII 标点)
扩展版 playback slot 重初始化函数. 在 reinit_playback_slot_from_channel 基础上额外接收 r3 (param_a), sp[0x10] (param_b) 两个字节参数. 先清零 [r0+0xe], 调用 init_sound_channel_playback_slot; 再写 r3 到 [r0+0x10] (volume/priority byte), sp[0x10] 到 [r0+0x11] (envelope byte); 最后写 flags 到 [r0+0xe]. 用于音效引擎中需要同时设置播放音量和 envelope 参数的 channel 重触发路径. 被 sound engine tick 主循环 (0x0810c6a6 区域) 调用.

ENV_OFF=0x11 (envelope byte = sp[0x10])
