## plate comment (中文, ASCII 标点)
```
Function: 根据 LP state 机状态码分派 zone11 装备 sprite 或 LP row 更新.
入口 r0=effect_slot_ptr. 检查 [r0+0x4] bit2 (已激活标志); 已激活则返回 0.
读 LP state 机 (gP1LifePoints + 0x94*8 = 0x4a0 处 word) 做两路分派:
  state==0x7f: 读 gP1LifePoints+0x1da8 halfword (zone11 base);
    提取 player_id (bit0 反转), 以 zone_idx=0xb 调用 get_zone_slot_ptr;
    读 zone slot 的 card_type 和 LP 位字段, 按状态选 sprite_code (0x61 或 0x71),
    调用 enqueue_sprite_attr_type11(player_xor, card_id, sprite_code, card_info);
    再调用 enqueue_equip_zone_sprite_direct(player_xor, r8, 0x81).
  state==0x80: 读 gP1LifePoints 偏移 0xc 处 player_id0/1 slot 计数;
    若目标槽计数为 0 则返回 0; 否则调用 set_lp_row_type4_with_value(opponent_player, 0); 返回 0x7f.
  其他 state: 返回 0.
Side effects: OAM sprite 队列: enqueue_sprite_attr_type11 / enqueue_equip_zone_sprite_direct.
  LP row 写入: set_lp_row_type4_with_value (state 0x80 path).
Constants:
  ACTIVATED_BIT=0x4
  LP_STATE_0x7f=0x7f  LP_STATE_0x80=0x80
  STATE_OFFSET=0x4a0
  ZONE11_OFFSET=0x1da8  // gP1LifePoints+0x1da8 = zone11 entry base
  LP_SLOT_OFFSET=0x1ce8  // gP1LifePoints+0x1ce8 = LP slot count area
  SPRITE_CODE_A=0x61  SPRITE_CODE_B=0x71  // zone11 sprite codes
  ZONE_IDX_11=0xb  EQUIP_ZONE_FLAG=0x81
```
