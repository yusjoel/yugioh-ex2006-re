Drives audio engine N frames in bulk. Input r0=frame_count(signed). If frame_count<0: calls restart_sound_channel_blocking(-1, -frame_count) to reset channel then returns. If frame_count>=0: loads audio engine base 0x030050cc; loops r4=frame_count downto 0: each iteration calls tick_sound_engine_main with that base to advance one audio frame. Used by init paths needing to pre-advance audio by N frames.
