## plate comment (中文, ASCII 标点)
禁卡表场景每帧顶层驱动. 由 dispatch_banlist_scene_handler_frame 函数指针表调用.
读 gBanlistPasswordBuffer+0x662 bits[7:6] 选子模式 (0=tick_oam_slots, 1=scroll_by_state),
再无条件推进 bg_scroll/OAM/palette/blend 过渡; blend 过渡进行中或 exit_flag(+0x660 bit2)=0 返回 0,
过渡完成且 bit2=1 返回 1 (退出场景).

  EXIT_FLAG  = gBanlistPasswordBuffer+0x660 // bit2 = scene-exit request
