## plate comment (中文, ASCII 标点)
在多个 UI 场景 (card_stats 展示, settings 面板, banlist 画面) 中被调用, 负责将显示坐标写入 IWRAM slot 描述符. 函数以 r0 为 slot 索引, 以 4 字节步长偏移到 IWRAM 基址 0x0202a4d0 对应条目, 将 r1 写入偏移 +0x34 (x 坐标或宽度), r2 写入偏移 +0x36 (y 坐标或高度), 返回 r0=1 表示成功.

## 参数签名
- r0: u8 slot_idx (slot 索引, [0..13]: 各 caller 实测传入 1/2/7..13, 步长 4 字节)
- r1: u16 coord_x (写入 [base + slot_idx*4 + 0x34], 屏幕 x 坐标或宽度)
- r2: u16 coord_y (写入 [base + slot_idx*4 + 0x36], 屏幕 y 坐标或高度)
- 返回: r0 = u32 (1=成功)

## 副作用
- [0x0202a4d0 + r0*4 + 0x34] := r1 (slot x 坐标, halfword)
- [0x0202a4d0 + r0*4 + 0x36] := r2 (slot y 坐标, halfword)
