# Naming Proposal: 0x081016c0

## 提案
- **proposed_name**: load_card_mini_frame_tiles_by_type
- **confidence**: high

## plate comment (中文, ASCII 标点)
卡片列表界面初始化时调用, 根据 IWRAM 0x0202a4d0[+0] (card_type, int16) 分 3 路分支: ==1 走小卡框路径(0x06016a80, 0x09e25934), ==3 走大卡框路径(0x06016a80, 0x09e25c34), 其余直接返回. 两路均循环 tile_2d_row_copy 将 ROM 卡框 tile 拷贝到 VRAM OBJ 区, 并以 copy_bytes_by_halfword 将对应调色板写入 PAL_OBJ(0x05000360). 由 card_list_screen_init(0x080fdef4) 唯一调用.

## 参数签名
- r0: (unused at entry, function reads state from IWRAM 0x0202a4d0 directly)
- 返回: r0 = uint32 1 (always 1, success sentinel)

## 副作用
- [VRAM 0x06016a80+r4*0x60]: tile_2d_row_copy 写入卡框 tile 行数据 (0xc 行 2 列, 循环 11 次)
- [PAL_OBJ 0x05000360]: copy_bytes_by_halfword 写入 0x20 字节卡框调色板
- [PAL_OBJ 0x05000360] (type3 路径): 写入另一套 0x20 字节调色板 (card_mini_frame_pal_gap / 0x09e315b4)

## 行级注释 (≤ 30 行精华)
- @ 081016c0: 读 IWRAM 0x0202a4d0[+0] 为 card_type, 0=无框不处理, 1=小框, 3=大框
- @ 081016e0: type==1 分支: tile_2d_row_copy 拷贝小框 tile 到 VRAM OBJ 0x06016a80
- @ 081016e8: 循环 r4=0..10, 每次偏移 r4*0x40 行拷贝 1*2 tile
- @ 08101706: copy_bytes_by_halfword 写 card_mini_frame_pal_gap 调色板至 0x05000360
- @ 08101724: type==3 分支: 同结构但 tile 数据源不同(0x09e25c34), 偏移 r4*0x80

## 调用图
- caller: card_list_screen_init (0x080fdef4, tags: bg/vram/palette/card_frame, role: 界面初始化时按卡型加载卡框 tile)
- callee: tile_2d_row_copy (主 tile 拷贝), copy_bytes_by_halfword (调色板写入)
