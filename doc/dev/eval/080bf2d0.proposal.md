# Naming Proposal: 0x080bf2d0

## 提案
- **proposed_name**: draw_number_digits_to_oam
- **confidence**: med

## plate comment (中文, ASCII 标点)
将十进制数值分解为各位数字并写入 OAM 影子缓冲区 (用于 LP/数值显示).
r1 = number (待渲染的十进制整数, [0..8000] LP 值); r2 = player_flag {0,1} (保存到 r8).
Y 位置: gBannerState[+0x14] * 8 + 0x70 = 屏幕 Y 坐标.
X 起始: 基于 gBannerState[+0x14] * 8 + 0x70 区间 (r6), 每位数字向左偏移 0xc 像素.
digit tile = 0x204 + digit * 2 (tile 基址 0x81*4=0x204 起, 每个数字占 2 tile).
flag 字段: 读 DAT_0x0201e2a0[+0x4] bit0 XOR 1 → 若非零则 r1 |= 0x80 (palette 或 flip bit).
循环: r5 % 10 = 当前最低位数字 → 写入 OAM; r5 /= 10; 重复直到 r5 == 0.
最后再写一次末位确保 0 不被跳过. 调用 write_oam_entry_from_packed_args (已命名) 写入 OAM.
唯一 caller: play_ui_effect_0e (0x080bf394, vram/scene_duel_field/duel_field).

Constants:
- gBannerState (0x0201fec0)[+0x14]: Y/X 位置参数 byte
- DAT_080bf368 = gBannerState; DAT_080bf36c = 0x0201e2a0 (struct)
- 0x204 = 0x81*4: digit tile 基址; 0xc: 每个数字 X 间距; 0x70: Y 基准偏移
- 0x80: palette/flip flag bit; 0xa: 十进制 mod/div 基数
- 0x202: 某 OAM attr 常量 (DAT_080bf390)

## 参数签名
- r0: u8 palette_ctrl - gBannerState[+0x4] 读出的显示控制字节 [0..255], 与 [0x0201e2a0+0x4] bit0 XOR 决定 OAM palette/flip bit (@ 080bf2f0 eors r0,r1); 由 play_ui_effect_0e 入口 ldr r7,[gBannerState,#0x4] 传入 (r7 → r0 at callsite)
- r1: u32 number - 待渲染十进制数值 [0..8000] (LP 最大值 8000, 4 位; gBannerState[+0x8] 取 abs 后传入, callsite: adds r1,r6,#0)
- r2: u8 player_flag - 玩家队伍标志 {0, 1} (play_ui_effect_0e 从 gBannerState[+0xd] 读取是否 == 4 决定; 保存到 r8; callsite: .hword 0x4642 = mov r2,r8)
- 返回: void (无返回值)

## 副作用
- 调用 write_oam_entry_from_packed_args (已命名) N+1 次, 每次写入一个 OAM digit sprite entry
- 每次调用写入 gPrng 关联 OAM shadow buffer 的 attr0/1/2
