# Naming Proposal: 0x08090900

## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
卡片效果节点处理器调用器, 被 FUN_080a0840 (equip sprite 状态更新) 在场景满足时调用
(indeg=1). r0 = card_id (来自 FUN_080a0840 的 r4), r1 = slot_index (来自 r5).
先 bl find_card_effect_node_entry(r0, r1) 查找效果节点入口: 若返回 0 (未找到)
则 b LAB_0809091e (movs r0,#1; 返回 1). 若找到则检查 [node+0x10] (处理器函数指针):
若为 0 则同样返回 1. 若非零则 bl FUN_0810e5d0(r4, r5) (调用效果节点处理器),
返回值经 LAB_08090920 传递. 函数角色: "查找效果节点并调用其处理器, 若无节点则返回 1".
Constants: node_handler_offset=0x10.

## 参数签名
- r0: u32 card_id (来自 FUN_080a0840 r4, 即 slot 关联的 card_id)
- r1: u32 slot_index (来自 FUN_080a0840 r5, 即当前 equip slot)
- 返回: r0 = u32 1 (节点未找到或 handler 为 NULL, 路径 LAB_0809091e) 或 u32 handler_result (FUN_0810e5d0 返回, 路径 LAB_08090920; 语义待确认: 0=处理中, 非零=完成)

## 副作用
- 经 FUN_0810e5d0 修改效果节点状态 (具体字段取决于节点类型)
