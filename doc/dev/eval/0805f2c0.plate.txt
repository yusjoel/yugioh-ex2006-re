check_equip_chain_pair_card_id_matches
Extracts player_id (byte[+2] bit0) and zone_idx (bits[6:2]) from slot_ptr (r0).
Indexes gDuelFieldSlots (base=0x0201c510, player_stride=0x868) by (player_id, zone_idx).
Extracts bits[9:8] subfield (lsls#2; lsrs#0x18; lsls#1 chain) and bit22 flag from both
player_id side and (1-player_id) side slot descriptors.
Calls find_equip_chain_pair_across_field(player_id, zone_idx); XORs result with 0xffff;
uses rsbs/orrs/lsrs to test nonzero. If XOR result != 0xffff (real pair found) -> return 1, else 0.

Constants:
- gDuelFieldSlots_BASE = 0x0201c510
- PLAYER_STRIDE = 0x868
- ZONE_IDX_MASK = bits[6:2] of byte[+2]: lsls#0x1a; lsrs#0x1b
- INVALID_PAIR = 0xffff (no equip chain pair sentinel)

Inputs: r0 = SlotPtr* slot_ptr (byte[+2] bit0=player_id [0..1]; bits[6:2]=zone_idx [0..31])
Returns: r0 = u32 -- 1 if equip chain pair found (result != 0xffff), 0 otherwise
Side effects: none (pure query)

Callers: indeg=0; grep ".word 0x0805f2c1" asm/all.s -> 0 hits (Sub-type A dead code)
Callees: find_equip_chain_pair_across_field
