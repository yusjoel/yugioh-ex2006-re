## plate comment (中文, ASCII 标点)
为指定装备格 (r0=slot_ptr, r1=player_key) 计算并入队 OAM sprite 属性. 入口解码多个 callee-save 寄存器 (.hword 0x4657/464e/4645 = mov r7/r6/r5 = r0/r1/r2; .hword 0x4680=mov r8,r0; .hword 0x4691=mov r9,r1; .hword 0x4649=mov r9,r1). 调用 find_equip_chain_node_by_type_d(player_key, slot_idx) 获取装备目标节点 id; 若返回 0 (无目标) 跳转到 LAB_08048ff2 (静默退出). 否则将目标 id 与 cmp 0xffff 比对确认有效; 读 gDuelFieldSlots+slot 数据组装 OAM attr (多个位域 pack: attr0 bits[14:0]=card_graphic_id, attr1 bits[21:17]=equip_state, attr2=priority 字段等); 通过大型 switch (card_id r6) 调整 sprite tile/flip/mode 属性; 最终调用 enqueue_sprite_attr_record 入队. 由 FUN_08099aac (duel_field) 独占调用 (indeg=1).

## 参数签名
- r0: ptr slot_entry (gDuelFieldSlots 中某槽的指针) -> r8 (via .hword 0x4680)
- r1: u32 player_key (bit0=player_id [0..1]) -> r9 (via .hword 0x4691)
- r2: u16 slot_index [0..4] -> 保留用于 sub-computation
- 返回: r0 = void (无有意义返回值; 副作用为 enqueue_sprite_attr_record)

## 副作用
- OAM sprite 属性缓冲区: enqueue_sprite_attr_record 写入装备格 sprite
