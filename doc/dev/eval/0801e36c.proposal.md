## plate comment (中文, ASCII 标点)
card_info 场景的每帧状态更新函数, 被 FUN_0801e714 (card_info 场景主循环) 唯一调用. 共执行四步逻辑: (1) 读 IWRAM gPrng+FIELD_state_v1 (0xa4*2=0x148, 即 0x03000188) bits[1:0], 若非零则调用 sync_state_and_init_sprite(1) 触发 sprite 初始化; (2) 读 [0x0201afb0+0x6] 倒计时字段, 若非零则递减并在归零时返回 1; (3) 根据 gPrng+FIELD_state_v0 (0xa3*2=0x146) 的显示标志 bit7/bit6 调整 [struct+0x20] 的滚动偏移值; (4) 若 gPrng+FIELD_state_v1 bit2 设置且 [EWRAM_CARD_INFO_PAGE_BASE+CARD_INFO_PAGE_INPUT_OFFSET] bits[2:0] == 0, 则翻转 [struct+0x0] bit0 并调用 card_info_page_step_03_unknown. 最终返回 0 (继续更新) 或 1 (触发场景切换).

常量说明:
  FIELD_state_v0 = 0xa3*2 = 0x146  (gPrng+0x146 = 0x03000186: scroll direction flags; bit7=down, bit6=up)
  FIELD_state_v1 = 0xa4*2 = 0x148  (gPrng+0x148 = 0x03000188: sprite/page trigger flags; bit2=page flip, bits[1:0]=sprite init)
  EWRAM_CARD_INFO_PAGE_BASE = 0x02000000  (EWRAM 基址)
  CARD_INFO_PAGE_INPUT_OFFSET = 0x6c2c  (card_info_page 场景输入/状态结构体在 EWRAM 中的偏移)
