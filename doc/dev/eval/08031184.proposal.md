# Naming Proposal: 0x08031184

## 提案
- **proposed_name**: find_slot_idx_by_set_code
- **confidence**: high

## plate comment (中文, ASCII 标点)
在指定玩家 (r0 bit0) 的怪兽区手牌/槽位列表中, 查找 set_code (r1) 匹配的槽位索引.
通过 gP1LifePoints+0x10+player*0x868 读取槽位数量 r2,
再从 gP1LifePoints+player*0x868+0x98*4 (偏移 0x260) 开始逐条读取槽位字:
  提取 low 13 bits (card_id 或 set_code) = (lsls #0x2 lsrs #0x18)*2 + (lsls #0x12 lsrs #0x1f);
  与 r1 (target_set_code) 比较, 相等则返回当前索引 r3.
未找到则返回 -1 (rsbs r0,r0,#0).
被 caller 0x0803e5fc 用于按 set_code 定位手牌槽位; 0x080a5038 用于 AI 决策.
Constants: gP1LifePoints=0x0201c4e0, player_stride=0x868, count_offset=0x10, base_offset=0x98*4=0x260.

## 参数签名
- r0: u32 player_side 玩家编号 [0..1] (bit0 使用)
- r1: u16 target_set_code 目标集合代码 [0..0x1fff]
- 返回: r0 = s32 slot_idx 命中的槽位索引 [0..count-1], -1 = 未找到
