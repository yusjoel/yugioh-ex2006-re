## plate comment (中文, ASCII 标点)
将文件描述符 fd 解析为对应的标准流 FILE 指针或计算偏移.
依次比较 stdin/stdout/stderr 各自的 fd 字段 (FILE+0xe, ldrsh 读 16 位有符号); 匹配则返回对应流缓冲指针 (stdin=0x0300577c / stdout=0x03005780 / stderr=0x03005784 处存放的指针).
若均不匹配且 fd 与第三项相差 0x20 则返回调整值; 未知 fd 走 r0=r2-0x20 路径.
被 _swiread / _read / _swiwrite / _write / _swilseek 等调用, 作为 fd-to-FILE 映射.

Constants:
- STDIN_PTR_LOC=0x0300577c (stdin FILE* 存储地址, IWRAM)
- STDOUT_PTR_LOC=0x03005780 (stdout FILE* 存储地址, IWRAM)
- STDERR_PTR_LOC=0x03005784 (stderr FILE* 存储地址, IWRAM)
- IMPURE_PTR=0x09ed4d94 (_impure_ptr)
- FD_FIELD_OFFSET=0xe (FILE 结构体内 fd 字段偏移)
