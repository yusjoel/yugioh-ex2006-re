# Naming Proposal: 0x0810e5f0

## 提案
- **proposed_name**: invoke_r10
- **confidence**: high

## plate comment (中文, ASCII 标点)
单指令函数指针蹦床: 执行 bx r10, 跳转到 r10 所含目标函数. r10 是高位 non-APCS 寄存器. 被 3 个调用方使用: 0x080b4f68 (duel_field) 与 0x080f5d1c (display 相关路径). 与同族 invoke_r8 (0x0810e5e8) 同为高位寄存器蹦床.

## 参数签名
- r0..r3: 透传给被调函数
- r10 (non-APCS caller-set): ptr<fn> fnptr 目标函数指针
- 返回: r0 = 被调函数返回值 (透传)

## 副作用
- 无独立副作用

## 行级注释 (<=30 行精华)
- @ 0x0810e5f0: bx r10 -> 跳转到 r10 所含函数指针
