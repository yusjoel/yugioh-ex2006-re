# Naming Proposal: 0x080f56dc

## 提案
- **proposed_name**: clamp_blend_counter_with_bldalpha
- **confidence**: high

## plate comment
与 clamp_blend_counter_to_target (0x080f55fc) 同族, 区别在于写 BLDALPHA 而非 BLDY. 将 gPrng+0x200 处的 6-bit 混合步进 (bits[5:0]) 与目标值 r0 (target) 比较: 若当前步进 > target, 则将步进减去 target 后 AND 0x3f 写回, 并写 BLDALPHA (EVA/EVB) 和 BLDCNT; 若步进 <= target, 则清除 bit6 (blend_active 标志), 调用 disable_blend_and_clear_step 并返回 1. 写 BLDALPHA 时: EVA = (0x1f - step bits[5:0]), EVB = step bits[5:0], 合并为半字.

Side effects:
- [gPrng+0x200] byte: 更新 bits[5:0] (步进) 和 bit6 (active 标志)
- [BLDALPHA] (0x04000052): 写 (EVA << 8 | EVB) halfword (条件)
- [BLDCNT] (0x04000050): 写 r1 (bldcnt 控制字) halfword (条件)

Constants:
- BLEND_STEP_FIELD = gPrng+0x200 // bits[5:0]=step, bit6=active
- STEP_MASK = 0x3f // 6-bit 步进掩码
- ACTIVE_FLAG = 0x40 // bit6 = blend_active
- BLDALPHA = 0x04000052
- BLDCNT = 0x04000050

## 参数签名
- r0: u8 target 目标步进值 [0..0x3f]
- r1: u16 bldcnt 要写入 BLDCNT 的控制字
- 返回: r0 = u8 1=已到达/禁用 blend, 0=继续推进中 (pop {r1};bx r1, Sub-case E)

## 副作用
- [gPrng+0x200]: 更新步进
- [0x04000052]: BLDALPHA 写入
- [0x04000050]: BLDCNT 写入
