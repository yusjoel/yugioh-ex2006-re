# Naming Proposal: 0x080314d4

## 提案
- **proposed_name**: resolve_slot_card_id_for_pair
- **confidence**: high

## plate comment (ASCII-only, 中文汉字 + ASCII 标点)
被 FUN_08031564 (本批) 和 FUN_0803407c 等多个决斗场函数调用, 共 indeg=7.
功能: 按 r0 低 1 位指定玩家侧 (0=己方, 1=对方), r1 指定场地格索引,
从 gDuelFieldSlots 数组中读取该格条目 word[0] 的低 13 位获得 card_id.
若该 card_id 等于特殊值 0x19a6 或 0x19bc (=0x19a6+0x16) 两个特殊卡 ID,
则进一步检查 slot+0x10 处 word 的 bit5/bit1 标志 (配对禁用标志) 以及 slot+0x8 处 hword;
若标志均为 0 且 hword 非 0, 说明特殊配对条件成立, 返回其配对替代 ID (0x18f9 或 0x18f6).
任何不满足特殊条件的格直接返回原始 card_id; 格为空则返回 r2 (默认值透传).
副作用: 仅读, 无写.

Constants:
  0x0201c510 = gDuelFieldSlots base (EWRAM)
  0x868 = 单玩家侧的 slot 数组 stride (107 格 * 20 字节)
  stride 0x14 = 单 slot 条目字节数 (20 字节)
  0x19a6 = 特殊卡 ID A (需配对检查)
  0x19bc = 0x19a6+0x16 (特殊卡 ID B, 对应另一形态)
  0x18f9 = 特殊卡 A 的有效配对替代 ID
  0x18f6 = 特殊卡 B 的有效配对替代 ID

## 参数签名
- r0: u8 side_and_flags -- 低 1 bit = player_side [0..1] (0=自方, 1=对方); 高位忽略
- r1: u16 slot_index -- 场地格索引 [0..0x44]; 用于 slot_index*20 + side*0x868 定位
- r2: u32 default_id -- 若格为空(card_id==0)时透传返回的备用值
- 返回: r0 = u16 -- 有效 card_id: 若特殊卡配对条件成立则为替代 ID, 否则为槽内原始 card_id, 格空则为 r2

## 副作用
