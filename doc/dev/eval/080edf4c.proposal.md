# Naming Proposal: 080edf4c

## 提案
- **proposed_name**: write_tile_row_to_vram
- **confidence**: med

## plate comment (中文, ASCII 标点)
被 FUN_080ee010 (scene_pack VRAM 加载流程) 和 FUN_08023b6c (duel_field 初始化) 调用. 以 r3 指向的 tile 结构体为数据源, 按行迭代将 tile 数据写入 VRAM 目标地址 (0x06000800 区域). 每次迭代从源结构体读 2 个 u16 (tile_index / attr), 计算目标行偏移后以 strh 写入 VRAM. 副作用: 写入 [VRAM 0x06000800+ 按行偏移] 若干 halfword.

## 参数签名
- r0: u16 dest_tile_x  (写入目标列索引, 低 16 位有效)
- r1: u16 dest_tile_y  (写入目标行索引, 高 16 位右移后使用; 实际为 row * vram_pitch)
- r2: u16 width        (写入宽度, tile 单位)
- r3: ptr  src_tile_struct  (指向源 tile 结构体, [+0]=count, [+8..]=tile entry 数组)
- 返回: r0 = u16 last_tile_attr (最后一次写入的 tile 属性值)

## 副作用
- [VRAM 0x06000800 + row_offset]: strh tile_entry_value (写 tile 属性到 BG map VRAM, 多行)
