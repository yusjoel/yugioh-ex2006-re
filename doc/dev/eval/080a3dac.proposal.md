## plate comment (中文, ASCII 标点)
综合判断指定玩家场上是否有可激活的装备卡对 (以 slot_order 表为基础).
入口:
(1) count_available_monster_slots(player) -> 存入 r10;
(2) count_field_copies_of_card(0x13f2) -> 已有副本则立即返回 0;
(3) 从 ROM 表 DAT_080a3e90 (0x09e47898) 加载 3 字 slot_order_table 到 sp 上的 3 个槽 (ldmia/stmia);
双重循环 (外层 idx=0..2 遍历 slot_order 表, 内层 slot=0..4 遍历怪兽槽):
  读 sp[idx*4] 的 card_id 值到 r9 (内部工作寄存器, 每轮从 slot_order 表加载);
  内层: 遍历 player 场地 slot_idx=0..4, 读 card_id (lsls/lsrs low 13 bits) 与 r9 比较;
    命中且 check_slot_card_can_be_equipped(player, player, slot_idx)=1:
      设 sp[0x10]=1; 调用 check_slot_placement_blocked_by_field_effect;
      若未阻断则 r10++ (计数可激活槽).
外层迭代 player(1-player) 的对称扫描: 检查对方场地中匹配 r9 且未被阻断的槽.
最终: 若 r10>0 (有可激活槽) 或 sp[0x10]=0 (无可装备槽) 则返回 0;
  r10>3 -> 返回 1.
Constants: guard_card_id=0x13f2, slot_order_table=0x09e47898, player_stride=0x868, gDuelFieldSlots=0x0201c510.
