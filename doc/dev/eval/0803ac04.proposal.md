# Naming Proposal: 0x0803ac04

## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
查询决斗场地指定玩家/栏位中卡牌的综合状态码. 入口 r0=player_side, r1=slot_idx [0..4], r2=模式标志(-1 表示全属性扫描). 先从 gDuelFieldSlots[player][slot_idx] 读出 card_id (低 13 位), 若为 0 立即返回 0. 之后调用 FUN_080364b0(player, slot_idx) 和 FUN_08036674(player, slot_idx) 获取两组装备/效果属性, 再经 FUN_080eedf8(card_id) 取扩展属性字段 6. 在双层循环 (2 玩家 * 5 栏位) 内扫描 effect node pool (0x0201d9c0) 匹配多种卡牌常量, 按匹配类型分支设置 r7 (结果状态码). 返回值为 r7 的低 16 位. Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, slot_stride=20, effect_node_pool=0x0201d9c0.

## 参数签名
- r0: u32 player_side 玩家编号, bit0 选择 [0..1] 侧; 进入后存入 r10
- r1: u32 slot_idx 场地栏位索引 [0..4]
- r2: s32 mode_flags 查询模式标志; 调用方 FUN_0803abf0 固定传 -1
- 返回: r0 = u16 state_code 卡牌状态码 (0=无牌或条件不满足; 非 0=匹配的状态类别编号, 如 0xe/0x14/0x2/0x7 等), 含义由内部多路分支决定

## 副作用
无外部写入; 只读 EWRAM gDuelFieldSlots (0x0201c510) 和 effect node pool (0x0201d9c0).
