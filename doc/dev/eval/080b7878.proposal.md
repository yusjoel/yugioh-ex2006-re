## plate comment (中文, ASCII 标点)
检查 Premature Burial (0x1366) 或 Call of the Haunted (0x137d) 的装备激活条件.
入口 r0=zone_ptr -> r4 (struct[+2] bit0=player_side). 首先搜索己方装备区是否已有 Premature Burial:
find_equip_slot_by_card_id(player, 0x1366) >= 0 则直接返回 1. 若未找到, 检查对手是否有怪兽
(count_occupied_monster_zones(opponent)==0 -> 失败); 若对手有怪兽但己方无怪兽也失败.
若己方有怪兽: 检查对手是否有活跃装备 (count_equip_slots_active_only(opponent)>0); 若无则失败.
若通过以上检查: find_equip_slot_by_card_id(player, 0x137d) 找 Call of the Haunted 槽位 -> r1.
若 r1>=0: find_equip_chain_pair_across_field(player) 查找装备链配对 -> packed_slot_pair.
检查 packed_pair[bits[15:0]] != 0xFFFF (有效), 且关联槽位的 card_id 不是 Sangan (0x0fd6) 也不是
Witch of the Black Forest (0x11e4). 通过所有检查返回 1, 任一失败返回 0.
