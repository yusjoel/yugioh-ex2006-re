# Naming Proposal: 0x080f5e1c

## 提案
- **proposed_name**: clear_obj_shadow_by_palette_range
- **confidence**: high

## plate comment
遍历 OBJ shadow list (共 128 条目, 步长 8 字节, 基址从 [0x030001fc] 加载), 同时遍历 OAM (基址 0x07000000, 同步偏移). 对每对条目: 读 shadow[+4] 半字 AND 0x3ff 得到调色板索引 pal_idx; 若 pal_idx 在参数区间 [r0..r1] 内, 则清零 shadow[0] 和 shadow[2], 并写 0xc00 至 shadow[+4] (将 OBJ 设为 disabled 状态), 同时对 OAM 条目做相同操作. 循环展开为两次/迭代 (shadow 和 OAM 各检查一次).

Side effects:
- [OBJ_shadow_list + matched*8 + 0]: 写 0x0000
- [OBJ_shadow_list + matched*8 + 2]: 写 0x0000
- [OBJ_shadow_list + matched*8 + 4]: 写 0x0c00 (OBJ disabled 标志)
- [OAM + matched*8 + 0/2/4]: 同步写 0/0/0xc00

Constants:
- OBJ_LIST_PTR = 0x030001fc // IWRAM OBJ shadow list 基址指针槽
- OAM_BASE = 0x07000000
- PAL_IDX_MASK = 0x000003ff // 10-bit palette index mask
- OBJ_DISABLED = 0x0c00 // OAM attr0: bits[11:10] = 11 (disabled/prohibited)
- LIST_ENTRY_SIZE = 8 // 每条目步长

## 参数签名
- r0: u16 pal_idx_lo 调色板索引下界 [0..0x3ff]
- r1: u16 pal_idx_hi 调色板索引上界 [0..0x3ff]
- 返回: void (pop {r0};bx r0)

## 副作用
- [OBJ_shadow_list]: 批量清零匹配条目 shadow[+0]=0x0000, shadow[+2]=0x0000, 写 0x0c00 至 shadow[+4]
- [OAM]: 对应 OAM 条目同步更新 (shadow[+0/+2/+4] 同模式)
