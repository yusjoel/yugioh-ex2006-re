Equip activation predicate. Reads global field state gP1LifePoints+0x1cf4, requires value==1 (field_state==1). Extracts card slot byte[+2] bit0 as player_id, requires it differs from gP1LifePoints+0x1ce8 (active player ID, i.e. self is not the active player). Reads opponent (1-player_id) monster zone count at gP1LifePoints+opponent*0x868+0xc, requires >0. Returns 1 when all three conditions met, else 0. No external writes.

Constants:
  FIELD_STATE_OFFSET = 0x1cf4
  FIELD_STATE_REQUIRED = 1
  ACTIVE_PLAYER_OFFSET = 0x1ce8
  PLAYER_STRUCT_STRIDE = 0x868 (monster count at +0xc)
