## plate comment (中文, ASCII 标点)
装备区链式效果检测并更新精灵与位图. r0=player_id, 从 gP1LifePoints+0x1d24 读取计数器 (<=1, 共 2 次迭代). 每次: 以 r9[counter*4] 取当前 slot 数据, 调用 check_value_in_slot_chain(player, zone=0xb, slot_data) 检查链是否包含目标值; 若命中: 在栈上分配 0x18 字节结构体并写入 slot 信息和 flag bits (bit2 合并), 调用 query_equip_zone_bitmap_with_effect_guard(struct_ptr) 获取装备区位图; 若返回有效 bitmap: 调用 enqueue_equip_zone_sprite_by_side(player, slot, ...) 更新精灵, 再调用 prepare_slot_ctx_for_equip_bitmap(player, slot, slot_data) 更新位图上下文. 计数器递增, 首次命中返回 0. r9 为 ROM 数据表 0x09e47680 (2 个 slot 描述符入口). Constants: COUNTER_OFFSET=0x1d24, MAX_ITER=1, ZONE=0xb, STRUCT_SIZE=0x18, ROM_SLOT_TABLE=0x09e47680.
