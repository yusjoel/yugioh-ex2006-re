## plate comment (中文, ASCII 标点)
根据 gDuelCtx+0x2f53/0x2f54 合成 type_combined ([0..6]: bits[7:5]<<3 | bits[4:0]&0x1f), 若 type_combined==0 走 null 路径. 非 null: 读 gDuelCtx+0x2f58 获取 card zone type ([0..5]), 按 type 分支进入 4 类 OAM 写路径 (type 0->LAB_080d117e, type 1->LAB_080d120c, type 2->LAB_080d122c, type 3->LAB_080d1250). 每路径读 gPrng+0x83*4 halfword bits[7:4] % 3 or & 1 生成动画帧偏移, 构建 OAM packed args 后调用 write_oam_entry_from_packed_args. LAB_080d1280 段读 gDuelCtx+0x2f56 halfword (DWORD_080d1204) 提取 bits[12:5] 作为 zone slot 编码, 用于计算两条 write_oam_entry_from_packed_args 和 write_oam_entry_with_slot_check 的 OAM Y 坐标; 0x2f56 仅读不写. 被 FUN_080d1b2c 调用作为 zone card anim 的第一渲染阶段. Side effects: OAM 写 (via write_oam_entry_from_packed_args + write_oam_entry_with_slot_check). Constants: gDuelCtx=0x02020160, status_offset=0x2f53, low_offset=0x2f54, word_offset=0x2f58, slot_encode_offset=0x2f56 (read-only), gPrng anim_seed_offset=0x83*4=0x20c, oam_size=0x80.
