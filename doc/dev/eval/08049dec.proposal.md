# Naming Proposal: 0x08049dec

## 提案
- **proposed_name**: enqueue_effect_slot_sprites_descending
- **confidence**: high

## plate comment (中文, ASCII 标点)
Function: 以 r7=r0(display_mode) 为开关; 从 gP1LifePoints+0xea*0x20 处读 effect_slot_count,
从 (count-1) 倒序遍历, 每轮调用两次 get_effect_slot_entry_ptr_by_palette_id 获取当前和
下一槽的 entry ptr, 提取 bits[21:14]x2 + bit14 组成 sprite pair_code, 选择 x_base
(display_mode==0 用 0x56, 非0用 DAT_08049e40), 调用 enqueue_sprite_attr_record(type=0xd).
由 FUN_080665d4 (field spell/pair display chain) 和 FUN_0806abec (card_frame display chain)
在需要渲染 effect slot 列时调用. 无外部内存写, 仅向 sprite queue 追加记录.

Constants:
- gP1LifePoints = 0x0201c4e0 (via PTR_gP1LifePoints_08049e3c)
- EFFECT_SLOT_COUNT_OFFSET = 0xea * 0x20 = 0x1d40 (0xea << 5)
- X_BASE_0 = 0x56 (display_mode==0)
- SPRITE_ATTR_TYPE = 0xd

## 参数签名
- r0: u32 display_mode [0..nonzero] -- 0=use x_base 0x56, other=use DAT_08049e40 variant
- 返回: void (pop{r0};bx r0 尾退; enqueue_sprite_attr_record 返回值被丢弃)

## 副作用
- 全局 sprite attr queue: 条件性追加若干 type=0xd 记录 (每个有效 effect slot 一条)
