## plate comment (中文, ASCII 标点)
装备目标上下文初始化并更新位图函数. 入口 r0=player_id, r1=slot_idx, r2=附加值(可选), r3=flags. 在栈上分配 0x18 字节工作区后以 memset 清零; 将 r3 (halfword) 写入栈缓冲 [sp+0x0]; 读取 r2+0x2 的 byte 与 bit1 掩码合并后写回 [r2+0x2]; 计算槽位图 (1 << (player*0x10+slot_idx)); 最后调用 update_equip_target_bitmap_for_field (zone_flags=0xe, side_flags=0). 若槽在位图中有效则返回 1, 否则返回 0.

## 参数签名
- r0: u8 player_id [0..1] (归属方)

- r2: u8 extra_flag [0..1] (附加标志, 传 0 或 1)
- r3: u16 flags (写入缓冲区的标志字)
- 返回: r0 = u8 bitmap_hit (1=命中, 0=未命中)

## 副作用
