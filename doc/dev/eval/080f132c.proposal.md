# Naming Proposal: 0x080f132c

## 提案
- **proposed_name**: clear_tile_buf_col_range
- **confidence**: high

## plate comment (中文, ASCII 标点)
在 EWRAM font_jp tile 缓冲区中清除指定像素列范围对应的位 (AND mask). 被 banlist/font_jp 设置画面 (0x08019f24, 0x0801a9c4) 在 init_font_jp_ctx_bg2_char_vram 之后调用, 用于清空 tile 缓冲区的目标列区域以准备新字形写入. 函数根据 r1=y_pixel_row 计算 tile 行索引和字内行偏移, 从 [0x02006ed0+0x8] 读取 width_in_tiles, 再对 glyph_tile_buf 中每个覆盖字行 (高度 r0+0xa 列范围) 的 word 连续施以 AND mask 清零目标位. 分两分支: 总列范围 <=16 像素 (单 word 掩码) 和 >16 像素 (双 word 掩码 r3+r5).

Constants:
- FONT_CTX=0x02006ed0 // EWRAM font_jp 上下文
- COL_RANGE_THRESHOLD=0x10 // 16 像素判断临界值

## 参数签名
- r0: s16 x_pixel_start (清除起始像素列)
- r1: s16 y_pixel_start (清除起始像素行)
- 返回: void (pop {r0}; bx r0)

## 副作用
- [FONT_CTX glyph_buf + row_word_offset] &= clear_mask (AND 清零目标位列)
