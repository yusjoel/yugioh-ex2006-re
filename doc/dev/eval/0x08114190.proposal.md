# Naming Proposal: 0x08114190

## 提案
- **proposed_name**: compare_float_lt

## plate comment (中文, ASCII 标点)
GCC libgcc 单精度浮点小于比较函数 (__ltsf2): 解包两个 float (r0, r1) 后检测 NaN (kind > 1 -> 返回 +1 = 无序, 不满足 <), 正常路径调用 __fpcmp_parts_f.
GCC __ltsf2 约定: 负数 = A<B, >=0 = A>=B 或含 NaN. 调用方通常使用 "bl compare_float_lt; cmp r0,#0; bge not_less" 模式.
该函数在静态调用图中 indeg=0 (未被任何函数直接调用), 无函数指针引用, 属于编译器生成的未使用符号 (dead code).
与 compare_double_lt (0x081137e8) 结构完全对称, NaN 返回 +1 (无 rsbs), 是 6 个 float 比较函数中第 5 个.
