## plate comment (中文, ASCII 标点)
卡包选购页每帧被调用, 管理卡包展示入场动画的倒计时计数器. 若 pack_ui_state[0x724] 的 bit1 (已激活标志) 为 0, 则初始化倒计时为 5 并设置 bit1; 之后每帧将 [+0xc+0x6] 计数器减 1, 归零时清除 bit[1:0] 并返回 1 (表示动画播放完毕), 否则返回 0 (仍在倒计时中).

- TIMER_FIELD=0x6 // pack_ui_state+0xc 内的计数器字段偏移
- INIT_COUNT=5 // 入场动画帧数倒计时初值
- BIT_ACTIVE=0x02 // 已激活标志 bit1
- BIT_PAIR=0x03 // 清除 bit[1:0] 的掩码
