## plate comment (中文, ASCII 标点)
由 apply_zone_cursor_step 和 play_ui_effect_03 调用, 用于检查给定 OAM zone word 对应的卡 ID 缓存是否有效 (非空), 供后续光标推进或 UI 效果决策是否渲染该 zone.
流程: (1) r0=packed_oam_word; 保存低 16 位到 r4; (2) 调 resolve_zone_data_ptr_by_oam_word(r0=r4) 得 zone 数据指针 r7; (3) 从 r4 解包 player_id (bit7) 到 r3, zone_type (bits[6:0]) 到 r4, tile_byte (>>24 &0x7f) 到 r2; (4) 从 gDuelFieldCtx (0x0201e2a0) 读 field4 比较 player_id -- 置 r6 (is_current_player); (5) 检查 r4 == 0xd (特殊 zone): 读 gP1LifePoints[player_id*0x868+0x10] lp_word; 若 lp_word==0 则返回 0; 若非 0 则跳 LAB_080c70f4 -> 返回 0; (6) 检查 r4 其他值 (0xb/0xe/0xf) -> 读 LP 字段; (7) 通过 get_zone_card_attribute_by_type / ensure_card_id_cache_entry 查是否有卡 ID; (8) 返回 1 (有效) 或 0 (无效/空).
副作用: ensure_card_id_cache_entry 可能写 EWRAM 缓存.
Constants: player_bit=0x80, zone_type_mask=0x7f, tile_shift=24, tile_mask=0x7f, player_stride=0x868, special_zone_lp_offset=0x10, gDuelFieldCtx=0x0201e2a0, gP1LifePoints=0x0201C4E0.
