Equip effect dispatch function. Reads u16 type field from node [r0+0xc] and dispatches by value: type==1 -> extracts player_id (bit0 of [r0+2]) and calls tick_zone_sprite_pipeline_with_update_flag(player, 1) to advance zone sprite pipeline; type==2 -> extracts player_id then computes opponent player (1-player), calls apply_lp_delta_if_slot_active(opp_player, 1, 1) to apply LP change; other values skipped. Returns 0 fixed.

Side effects:
- type==1: advances zone sprite pipeline (indirect OAM update)
- type==2: triggers LP change via apply_lp_delta_if_slot_active
