# Naming Proposal: 0x080facd8

## 提案
- **proposed_name**: write_decimal_oam_by_digit_count
- **confidence**: high

## plate comment (中文, ASCII 标点)
将任意位十进制数 r2 按各位分解, 逐位写入 OAM 精灵条目, 直到商为 0 为止 (位数自适应). 每轮: r2 mod 10 得当前最低位, 转为 tile_id (digit+0x60); r2 div 10 得更高位; 写入 OAM. OAM y 坐标从 r1 开始每次 -8. 由 FUN_080fad10 (0x080fad10, tags: [card_stats]) 反复调用, 传入不同 x/y 坐标和 card_stats 字段值 (card_id, ATK, DEF 等). 与 render_decimal_oam_digit_pair (0x080fa4e4, 固定 2 位) 不同, 本函数循环直到商为 0, 支持任意位数.

## 参数签名
- r0: u16 x_pos - 精灵 x 坐标 (packed OAM attr 高半字)
- r1: u16 y_pos - 精灵 y 坐标起始 (每位 -8)
- r2: u32 decimal_value - 要渲染的十进制值 [0..n]
- 返回: void (pop {r4,r5,r6}; pop {r0}; bx r0)

## 副作用
- [OAM slot r0-0x8*n..r0]: 逐位写 OAM 条目 (via write_oam_entry_from_packed_args)

## 行级注释 (<=30 行精华)
- @ 080facea: lsls r0,r6,#0x10 - 将 y_pos (r6=r1) 移到高半字打包
- @ 080facec: orrs r0,r5 - OR 合并 x_pos (r5=r0) 为 OAM packed arg
- @ 080face4: bl __modsi3(r4, 10) - 取最低位
- @ 080facee: adds r2,#0x60 - digit 0..9 -> tile_id 0x60..0x69
- @ 080facf6: bl write_oam_entry_from_packed_args - 写 OAM
- @ 080facfe: bl __divsi3(r4, 10) - 移到下一位
- @ 080fad04: subs r5,#0x8 - y_pos -8 (向上一格)
- @ 080fad06: cmp r4,#0; bne - 继续到商为 0
