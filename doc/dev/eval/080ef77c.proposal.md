# Naming Proposal: 0x080ef77c

## 提案
- **proposed_name**: reinit_sio_link_with_timer3
- **confidence**: high

## plate comment (中文, ASCII 标点)
轻量级 SIO 重置: 禁用 IME, 屏蔽 IE serial bit, 读取 [0x030003a0+offset] 中存储的两个数据指针字段并将指向内存清零 (str 0 to [ptr]), 恢复 IME=1, 写 TM3CNT_L=0xb1fc (定时器 3 重载值) 并设置 TM3CNT_H=0x4000 (启动 Timer3, 无 cascade). 无 bios_cpu_set 调用, 比 init_sio_connection 更轻量. 被 FUN_080edd90 (sys,timer) 和 FUN_080ede28 (sys) 在 SIO 重置/断开时调用.

Constants:
- SIO_STATE_BASE=0x030003a0 // IWRAM SIO 结构基址
- TM3_RELOAD=0xb1fc // Timer3 重载值
- TM3_START=0x4000 // TM3CNT_H: enable, prescale=1

## 参数签名
- (无 APCS 输入; 函数体入口即读 IO 寄存器地址)
- 返回: void

## 副作用
- [IME] := 0 -> 1
- [IE] &= 0xff3f (屏蔽 serial)
- [ptr0] := 0 (ptr0 = [0x030003a0+offset].dword[0])
- [ptr1] := 0 (ptr1 = [0x030003a0+offset].dword[1])
- [TM3CNT_L] := 0xb1fc (重载值)
- [TM3CNT_H] := 0x4000 (启动 Timer3)
- [TM3CNT_H + 0xda (=TM3CNT_H+218?)] := 0xc0 (实际 offset: +0x1c+0xda = TM3CNT 地址序列)
