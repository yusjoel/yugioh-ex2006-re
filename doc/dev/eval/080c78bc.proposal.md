- **confidence**: med

## plate comment (中文, ASCII 标点)
被卡片显示主状态机 (switchD_080c79b4 case 0xd) 调用, 参数 r0 = palette_nibble (u8, 低 8 位用于 OAM 调色板字段设置). 初始化卡片图标相关的 BG VRAM 和调色板: (1) 按 r0 更新 gFontState+0x215 字节的 bit4 和 nibble (mask 0xf00f); (2) zero_fill 0x06014000; (3) tile_2d_row_copy 两次 (主 tile 区 0x06013400 和副区 0x06010800); (4) copy_bytes_by_halfword 复制 0x20 halfword 调色板到 OBJ palette 0x05000260; (5) 写 gFontState+0x215 = 0xd (完成标志 case 0xd). 副作用: VRAM tile, OBJ 调色板, gFontState nibble.

## 参数签名
- r0: u8 palette_nibble - 调色板 nibble 值 (低 8 位有效), 写入 gFontState+0x0a0e 的 bits[7:4], [0x00..0xFF]
- 返回: void (无返回值)

## 副作用
- [0x0201f440+0x0215]: bit4 置 1 (OR 0x10)
- [0x0201f440+0x0a0e]: strh - nibble 更新 (mask 0xf00f, OR r0<<4)
- [0x06014000..0x06017FFF]: zero_fill
- [0x06013400..+tiles]: tile_2d_row_copy from ROM 0x099082a4 (4col x 1row)
- [0x06010800..+tiles]: tile_2d_row_copy from ROM 0x09ccd2d0 (1col x 1row)
- [0x05000260..+0x40]: copy_bytes_by_halfword from ROM 0x09850c5c (0x20 halfwords)
- [0x0201f440+0x0a01]: strb 0xd (完成标志)
