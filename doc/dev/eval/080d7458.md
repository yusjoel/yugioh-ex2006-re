## 修改清单

### #1 — R4 (优先级: 高)
**位置**: proposal 参数签名节, 返回值行
**问题**: "返回: r1 = (Sub-case E...)" 格式错误: r1 是退出控制寄存器 (pop{r1}+bx r1 的跳转地址), 不是返回值; Sub-case E 下 r0 保持函数体最后写入值 (asm 359573: mov r0,r9 epilogue); "实为 void 效果" 未明确 dispatch callers 是否忽略 r0; R4 rubric 要求 void 应写 "void (仅副作用, r0 在 dispatch 调用方不使用)" 或明确 r0 的实际值
**当前**: `返回: r1 = (Sub-case E: pop{r1}+bx r1) -> r0 不被本函数覆盖; 实为 void 效果`
**应改为**: 追踪 asm epilogue 确认 r0 的实际值 (asm 359573 `.hword 0x4648` = mov r0,r9, r9 = callee-saved callee); 若 dispatch callers 忽略 r0, 则写 `返回: void (dispatch 调用方不使用返回值; r0 在 epilogue = mov r0,r9 恢复的 callee-save 值)`; 或若有语义含义则明确
