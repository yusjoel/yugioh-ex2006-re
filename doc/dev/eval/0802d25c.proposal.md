## plate comment (中文, ASCII 标点)
Function: 初始化卡包选择界面默认 VRAM/调色板 (无指定卡组的通用路径). 无 APCS 输入. 从 ROM 加载三组固定数据: ROM_PALETTE=0x09b97b28 (调色板), ROM_TILES=0x09b97d68 (tile 数据), ROM_TILEMAP=0x09b9bd68 (tilemap 数据). 依次执行: (1) zero_fill_by_halfword 清空 OBJ VRAM 0x06000800 和 0x06001000 (各 0x800 halfwords = 0x1000 字节); (2) upload_palette_rows_to_bg_vram(ROM_PALETTE, 8) 上传 8 行调色板; (3) 向 PAL_RAM 0x05000000 写 0 (清背景色); (4) upload_indexed_tile_rows_to_obj_vram(ROM_TILES+0x2000, 0x10) 上传 16 行 OBJ tile; (5) upload_tilemap_rows_with_offset(ROM_TILEMAP, 1, 0x10, 0x1e) 上传 tilemap 行; (6) 重复 upload_indexed_tile_rows_to_obj_vram(ROM_TILES+0x88*2=0x110, 0x14 rows); (7) upload_tilemap_rows_with_offset(tilemap_offset, 2, 0x88*2, 0x1e). 出口 pop {r0}; bx r0 (Sub-case E, void).

Side effects:
- VRAM 0x06000800 (0x1000 bytes): zero cleared
- VRAM 0x06001000 (0x1000 bytes): zero cleared
- BG palette: ROM_PALETTE (8 rows) uploaded
- PAL_RAM 0x05000000: cleared to 0
- OBJ VRAM: ROM_TILES data uploaded (16 + 20 rows)
- BG tilemap: ROM_TILEMAP rows uploaded

Constants:
- ROM_PALETTE = 0x09b97b28
- ROM_TILES = 0x09b97d68
- ROM_TILEMAP = 0x09b9bd68 + 0x96*8 = 0x09b9c218
- OBJ_VRAM_BASE_A = 0x06000800
- OBJ_VRAM_BASE_B = 0x06001000
- PAL_RAM_BASE = 0x05000000 (0xa0<<19)
- PALETTE_ROWS = 8
- TILE_ROWS_A = 0x10
- TILE_ROWS_B = 0x14
- TILEMAP_STRIDE = 0x1e
