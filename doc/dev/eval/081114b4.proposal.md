# Naming Proposal: 081114b4

## 提案
- **proposed_name**: grow_heap_via_sbrk
- **confidence**: med

## plate comment (中文, ASCII 标点)
dlmalloc 内部堆扩展函数. 接受 reent_ptr (r0) 和 size_request (r1) 参数, 通过两次调用 wrap_sbrk_r 向操作系统申请更多内存, 并更新 newlib reent 结构体 (0x09ed4d98 区域) 中的堆顶/堆大小统计字段 (0x09ed51b4 = footprint, 0x09ed51ac = max_footprint, 0x09ed51b0).

第一次 wrap_sbrk_r 探测可用连续地址; 若返回 -1 (失败) 则退出. 对齐调整后进行第二次 wrap_sbrk_r 获取对齐基址. 更新 footprint 字段并写入 chunk 头 (prev_foot/size). 若前驱 chunk 超过阈值 (r7>0xf), 还可调用 _free_r 释放前驱块.

调用场景: _malloc_r (0x08111610) 在 dlmalloc 内部搜索不到足够空闲块时, 通过本函数向 GBA semihosting 环境申请额外堆空间.

Constants:
REENT_BASE=0x09ed4d98 (newlib reent 结构体指针)
HEAP_SIZE_PTR=0x09ed51a4 (当前堆大小字段指针)
HEAP_BASE_PTR=0x09ed51a8 (堆基址指针)
FOOTPRINT=0x09ed51b4 (当前占用量字段)
MAX_FOOTPRINT_A=0x09ed51ac (最大占用量字段 A)
MAX_FOOTPRINT_B=0x09ed51b0 (最大占用量字段 B)
ALIGN_MASK=0xfffff000 (4KB 页对齐掩码)
ALIGN_BUMP=0x100f (对齐前加法, 补齐到 4KB 页)

## 参数签名
- r0: ptr reent_ptr (newlib reent 结构体指针, 来自 _malloc_r 调用方)
- r1: u32 size_request [1..+inf] 申请的字节数 (经 dlmalloc 内部对齐)
- r8: ptr caller-set (高寄存器, .hword 0x4680=mov r8,r0 保存 reent_ptr 别名; R3: r8 是 r0 的 callee-save 别名, 不是独立参数)
- r9: ptr caller-set (高寄存器, 来自 _malloc_r prologue 设置的 sbrk 哨兵值 -1; R3: 从 callsite 0x0811192a 前驱代码可见 r9 由 _malloc_r 设置)
- 返回: r0 = void (pop {r4,r5,r6,r7,pc} 普通 pc 返回; 无独立 r0 写出)

## 副作用
- [0x09ed51b4] := [0x09ed51b4] + size_adjusted (footprint 累计增量)
- [0x09ed51ac] := max([0x09ed51b4], [0x09ed51ac]) (更新最大占用量 A)
- [0x09ed51b0] := max([0x09ed51b4], [0x09ed51b0]) (更新最大占用量 B)
- [chunk_ptr+0x4] := size | flags (新分配 chunk 大小字段)
- [chunk_ptr+0x8] := 0x5 (prev 大小字段初始化)
- wrap_sbrk_r 两次调用: semihosting brk 系统调用推进堆顶
