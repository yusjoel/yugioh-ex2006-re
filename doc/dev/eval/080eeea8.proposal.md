# Naming Proposal: 080eeea8

## 提案

- **confidence**: high

## plate comment (中文, ASCII 标点)
属于 0x080eedf8..0x080eeed4 同族 sibling 簇, 每个函数仅在 "adds r0, #N" 中的 N 值上不同 (本函数 N=8), 读取 ROM 扩展卡片属性表中第 8 个 u16 字段. 输入 card_id; 若 <= 0x0fa6 (普通卡片上界 4006) 则直接返回 0; 否则将 card_id 减 0xfa7 得行号, 以行号 * 11 + 8 为 u16 偏移从 ROM 表 0x09821e04 读取对应字段值. 被 FUN_0804a9dc (卡片类型分类器) 及 FUN_0804ad70 调用, 用于判断卡片所属扩展属性类别.

## 参数签名
- r0: u16 card_id  (卡片 ID, 仅处理 > 0x0fa6 的扩展区卡片 [0x0fa7..0x0fa6+table_len-1])
- 返回: r0 = u16  extended_stat_field8  (ROM 扩展表 row[card_id-0xfa7] 的第 8 个 u16 字段; 超出范围返回 0)
