# Naming Proposal: 0x080f4fd0

## 提案
- **proposed_name**: copy_memory_dma3_chunked
- **confidence**: high

## plate comment
使用 DMA3 将 src (r1) 的数据复制到 dst (r0), 总字节数 r2. 若 r2 > 0xff (255), 按 256 字节块循环执行 DMA3 (每次传输 0x80 个半字 = 256 字节), 直至剩余量 <= 0xff; 最后将余量向上折算为半字数 (ceil(remain/2)) 再触发一次 DMA3 传输. 与 copy_memory_dma3_with_cpu_fallback (0x080f4f08) 同族, 本函数纯 DMA3 分块, 无 CPU 字节循环回退. 由 sprite/scene_duel_puzzle 模块 (0x080f4adc) 调用.

Side effects:
- [DMA3SAD] = src (写 DMA3 源地址寄存器)
- [DMA3DAD] = dst (写 DMA3 目标地址寄存器)
- [DMA3CNT] = 0x80000080 (触发 DMA3, 每次 128 halfword)
- 等待 DMA3CNT bit31 清零后继续
- [dst..dst+r2]: := src 内容

Constants:
- DMA3SAD = 0x040000D4 // DMA3 源地址寄存器
- DMA3CNT = 0x040000DC // DMA3 控制字
- DMA3_CTRL_128HW = 0x80000080 // enable | count=0x80 halfword (=256 byte)
- CHUNK_SIZE = 0x100 // 每次 DMA 块 256 字节
- THRESHOLD = 0xff // 大于此值才走 DMA 循环

## 参数签名
- r0: void* dst 目标地址
- r1: const void* src 源地址
- r2: u32 byte_count 总字节数 [0..inf]
- 返回: void (pop {r0};bx r0)

## 副作用
- [0x040000D4..+0xc]: DMA3 寄存器组 (SAD/DAD/CNT) 写入并等待完成
- [dst..dst+byte_count]: := src 内容

## 行级注释 (精华)
- @ 080f4fd8: cmp byte_count, 0xff -> 若 <=0xff 直接跳小块路径
- @ 080f4fde: r6 = 0x100 (DMA 步进 = 256 字节)
- @ 080f4fe2: DAT_080f504c = 0x80000080 (DMA3 控制字 enable+128HW)
- @ 080f4fea: 写 DMA3SAD, DMA3DAD, DMA3CNT 触发 DMA
- @ 080f4ff2: 两次读 DMA3CNT (wait state)
- @ 080f4ff8: AND bit31 -> 等待 DMA active 标志
- @ 080f5000: 自旋等待 bit31 清零
- @ 080f5008: DAT_080f5050 = 0xffffff00 = -256 -> r3 -= 256
- @ 080f500a: src += 0x100, dst += 0x100
- @ 080f5010: cmp r3,0xff -> bgt DMA 循环
- @ 080f5014: 余量路径: ceil(remain/2) 作半字计数触发末次 DMA
