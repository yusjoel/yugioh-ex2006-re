## plate comment (中文, ASCII 标点)
equip zone 精灵分发与激活核心函数. 被 FUN_080443c4 及多个 equip zone 扫描器以 sp[0x28]/sp[0x2c] 携带 zone_type/flags 调用. 函数入口解码 r0..r3 五个 callee-save 寄存器后, 依 sp[0x28]!=0 切换 sp[0x4] 为 0x1d/0x1e (LP row type). 核心逻辑: 读取区域状态字, 提取 card_type_id (bits[18:0]), 在约 20 个已知 card_id 分支树 (0x16f9=Manticore of Darkness/0x13e3=Archfiend of Gilfer/0x11bc=Minar/0x12a2=Skull-Mark Ladybug/等) 中分发; 命中时调用 enqueue_sprite_attr_record 或 enqueue_sprite_attr_for_zone_card_id_lookup/enqueue_sprite_attr_type11/apply_equip_activation_with_id_lookup. 末段: 调用 scan_field_slots_for_equip_sprite + submit_lp_bar_sprite_row_by_type; 若 sp[0x28]!=0 且 zone_type==0xe 则调用 scan_trap_zone_slots_for_equip_shape_sprite; 再调 scan_effect_zones_for_equip_activation_forced_requisition. 若 sp[0x2c]==1 且 find_effect_node_in_zone 命中, 则调 enqueue_equip_zone_sprite_by_side + submit_lp_change_indicator_with_chain_check. Side effects: writes OAM sprite attr buffer via enqueue_* callees; writes gP1LifePoints chain state via apply_equip_activation_with_id_lookup. Constants: OAM_ROW_TYPE_NORMAL=0x1e, OAM_ROW_TYPE_SPECIAL=0x1d, OAM_SHAPE=0x8045/0x45 (P2/P1), ZONE_11=0xb, card_id_tree_count~=20.

## 参数签名
- r0: u32 packed_side_flags (bit0=player_side [0..1]; saved to r7 via mov r7,r0 at entry)
- r1: ptr zone_slot_ptr (pointer to zone slot entry; saved to r9 at entry)
- r2: u32 zone_col_or_flags (saved to r6 via adds r6,r2,#0 at entry; also saved r10)
- r3: u32 extra_context_flag (sp[0x28] at call)
- sp+0x28: u32 is_trap_zone_context [0..1]
- sp+0x2c: u32 effect_check_mode [0..2]
- 返回: r0 = void (no explicit return value; function returns via pop {r0}; bx r0)
