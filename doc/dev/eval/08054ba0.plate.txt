check_equip_slot_eligible_by_equip_type_and_occupied
Equip slot eligibility predicate for equip/continuous spell cards (field6==0x16) with field9==4.
Symmetric to check_equip_slot_eligible_by_union_type_and_occupied (0x08054acc);
only difference is field6 target value 0x16 (equip/continuous type) vs 0x17 (Union type).
r0 is unused (clobbered at entry).
Checks in order: (1) compute gDuelFieldSlots[r1&1][r2] slot address;
(2) bits[18:0] = card_icid; (3) get_card_extended_stat_field6(card_icid) == 0x16 (equip type);
(4) get_card_extended_stat_field9(card_icid) == 0x4; (5) [slot+8] != 0 (slot has valid card).
Returns 1 if all pass, 0 otherwise. Pure predicate, no external writes.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, FIELD6_EQUIP_CONTINUOUS=0x16, FIELD9_SUBTYPE=4
Inputs: r0=(unused), r1=u8 player_id [0..1], r2=u8 zone_slot_idx (unchecked)
Returns: r0=u32 bool (1=eligible, 0=rejected)
