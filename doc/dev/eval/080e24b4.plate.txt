Renders card OAM sprite entries for the card pack scene.
No APCS parameters (indeg=0, r8 from caller frame).
First writes 7 blank OAM entries (r6=0..6); reads gMenuState[0x240] mode field bits[15:8].
Mode 0: exit immediately.
Mode 1..3: uses sprite param table A (0x09e5e9b0) to write 3 groups of OAM entries.
Mode 4..5: uses sprite param table B; writes 3 groups plus extra sprite.
Mode 6+: exit.
Calls write_oam_entry_from_packed_args extensively to configure OAM attr0/attr1/attr2.

Constants:
  SPRITE_TABLE_A  = 0x09e5e9b0     (sprite parameter table A)
  MODE_FIELD_OFF  = 0x90*4 = 0x240 (gMenuState[0x240] mode field offset)
  MASK_CARD_IDX   = 0x000007fe     (card index mask)
  OAM_Y_BASE_A    = 0x000080c0     (OAM attr0 Y base)
  OAM_X_MAIN      = 0x00001308     (OAM attr1 X main position)
  OAM_X_ALT       = 0x0000130b     (OAM attr1 X alternate position)
  MODE_CHECK_OFF  = 0x00000242     (mode additional check offset)

Inputs: none (indeg=0, r8=gMenuState base from caller frame).
Returns: void (pop {r3,r4,r5}; restore r8/r9/r10; pop; bx r0).
Side effects: writes multiple OAM entries to OAM region 0x07000000
              via write_oam_entry_from_packed_args.
