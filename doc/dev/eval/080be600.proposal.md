## plate comment (中文, ASCII 标点)

- gBannerState_OFFSET = 0x10 (状态编号字段偏移)

- 0xe000 = OBJ palette 属性高位掩码
- case 0: 读取 pack 设置字段, 计算 tile 布局偏移, 复制 tile 数据到 VRAM
