# Naming Proposal: 0x0810d690

## 提案
- **proposed_name**: init_sound_channel_playback_slot
- **confidence**: med

## plate comment (中文, ASCII 标点)
根据 flags (r1) 从三条路径之一选取 instrument table 指针, 再以 r1 低 12 位为 instrument_index 索引该表, 加载 instrument data 指针并从中提取播放参数. 将播放结构体 (r0 所指 ~0x1c 字节的 slot) 各字段初始化: 清零 [+0x13]/[+0x12], 写 r2 到 [+0xf], 写 0x3f 到 [+0x11]/[+0x10], 写 flags & 0xefff 到 [+0xc] halfword. 随后从 ROM 0x084c76b0 memcpy 10 words 到栈, 检查 [0x030050cc+0x38a] rate 字段, 按其计算 pitch 值存入 [r0+8]. 返回 channel flags 字节 (r3). 被 FUN_0810d78c / FUN_0810d7a4 包装调用.

Constants:
- INSTRUMENT_TABLE_DEFAULT=0x081d7ea0 (主 instrument ptr table)
- INSTRUMENT_TABLE_ALT=0x08114a90 (备用 instrument ptr table)
- PITCH_TABLE=0x084c4d28 (pitch LUT, halfword entries)
- RATE_TABLE=0x084c76b0 (rate coefficient table, 10 words)
- FLAGS_LOW12_MASK=0x0fff (instrument_index 提取掩码)
- FLAGS_EFFF_MASK=0xffffefff (AND mask for [+0xc])

## 参数签名
- r0: ptr slot_ptr, 指向待初始化的 channel playback slot (~0x1c bytes)
- r1: u32 flags_word [0..0xffff], bits[11:0]=instrument_index [0..0xfff], bits[15:13]=mode flags
- r2: u8 panning_byte, 写入 [slot+0xf] [0..0xff]
- 返回: r0 = u8 channel_flags (r3, 来自 instrument data 的 flags 字节)

## 副作用
- [slot + 0xf] := r2 (panning)
- [slot + 0x12] := 0 (cleared)
- [slot + 0x13] := 0 (cleared)
- [slot + 0x10] := 0x3f (初始 volume_L)
- [slot + 0x11] := 0x3f (初始 volume_R)
- [slot + 0xc] halfword := flags & 0xefff (channel status flags)
- [slot + 0x8] := pitch_value (根据 instrument data + rate 计算)
- [slot + 0x14] := ptr to instrument envelope data ([instrument+0xc])

## 行级注释 (<=30 行精华)
- @ 0810d690: 保存 r8 (0x4647=mov r7,r8); r4=r0 (slot), r7=r1 (flags)
- @ 0810d69e: r3 = r7 & 0xfff (instrument_index)
- @ 0810d6a6: r0 = r7 & 0xa000 -- 测 bit15+bit13 选 table 路径
- @ 0810d6b8: 若 bit13 不设: 加载 TABLE_ALT=0x08114a90
- @ 0810d6cc: 若两者都设: 从 [engine+0x1c] 取动态 table ptr
- @ 0810d6d0: r0 = table[r3*4] = instrument_data_ptr
- @ 0810d6d6: 初始化 slot flags/volume/panning 字段
- @ 0810d6f4: memcpy(sp, 0x084c76b0, 10 words) -- load rate coefficients
- @ 0810d700: if [engine+0x38a]==0: pitch=raw; else: scale by rate table
- @ 0810d726: [slot+8] := pitch_scaled (from pitch LUT at 0x084c4d28)
