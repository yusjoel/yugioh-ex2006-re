Common exit stub for FUN_080e3ee8 (pack scene event handler).
Executes: add sp,#8 (release 8-byte local frame); pop {r3,r4}; mov r8,r3; mov r9,r4 (restore r8/r9);
pop {r4,r5,r6,r7}; pop {r1}; bx r1 (return via saved lr).
Does not write r0; caller determines final return value before entering this stub
(r0=1 set by FUN_080e5608, r0=0 set by other paths).
Address 0x080e5618+ code (after bx r1) is a separate palette cursor update fragment:
reads gMenuState[0xe] pack cursor field, increments by 1, writes to [0x050003fe] (PAL RAM color index).
That fragment is installed as gPrng+0x1f4 per-frame callback by FUN_080e5658.

Constants:
- PAL_CURSOR_ADDR = 0x050003fe (palette color select register, pack cursor highlight)
