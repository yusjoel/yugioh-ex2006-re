check_equip_slot_eligible_by_prereqs_and_type_code_mismatch
Equip slot eligibility predicate requiring slot occupied + prerequisites + target type code differs from equip type code + type compatible.
Called via fn-ptr table or upper-level equip target enumeration logic.
Checks in order: (1) gDuelFieldSlots[player_id&1][slot_idx] bits[18:0]!=0 (occupied);
(2) check_zone_slot_equip_prerequisites passes;
(3) slot type_composite (= bits[29:22]*2 + bit13) != equip_slot[+4]bits[13:6] (type codes differ to allow);
(4) query_slot_card_type_eligibility == 0.
Returns 1 if all pass. Pure predicate, no external writes.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868,
  type_composite=(zone_word[29:22]<<1)|zone_word[13],
  equip_type_field=equip_slot[+4] bits[13:6]
Inputs: r0=ptr equip_card_slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx (unchecked)
Returns: r0=u32 bool (1=eligible, 0=rejected)
