# Naming Proposal: 0x080df368

## 提案
- **proposed_name**: copy_card_list_tile_rows_to_vram
- **confidence**: med

## plate comment (中文, ASCII 标点)
将卡包卡牌列表的 tile 行数据从 ROM 复制到 BG VRAM. 无独立 APCS 参数, 入口立即用 ldr r0,DAT 加载 ROM 表地址并 spill 到 r10. 外层循环 5 次 (r1 从 0 累加至 4, cmp r1,#4; bls), 内层每次处理 2 行 (r6=0..1, cmp r6,#1; bls). 每次迭代从 ROM 卡牌图形表 (0x09e49698) 和卡牌序列表 (0x09cebf3c) 读取 tile 源地址, 调用 tile_2d_row_copy 写入 BG VRAM 0x06010000 对应行. 由卡包卡牌列表渲染序列调用.

Constants:
- ROM_CARD_GFX_IDX = 0x09e49698 (卡牌图形索引表)
- ROM_CARD_GFX_A = 0x09e4969a (卡牌图形表 A)
- ROM_CARD_GFX_B = 0x09e49684 (卡牌图形表 B)
- BG_VRAM_CARD_LIST = 0x06010000 (BG VRAM 卡牌列表行写入基地址)
- ROM_CARD_SEQ = 0x09cebf3c (卡牌序列查找表)
- OUTER_LOOP = 5 (外层 5 次, cmp r1,#4; bls)
- INNER_LOOP = 2 (内层 2 次, cmp r6,#1; bls)

## 参数签名
- r0: void (入口 ldr r0,DAT_0x09e49698 立即覆盖 r0; .hword 0x4682=mov r10,r2 存 r2 但 r2 也未使用前)
- 返回: void (pop {r0}; bx r0)

## 副作用
- [BG VRAM 0x06010000..]: 写入卡牌列表 tile 行数据 (5x2 行)
