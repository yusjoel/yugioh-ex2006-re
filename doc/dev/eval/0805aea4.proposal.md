## plate comment (中文, ASCII 标点)
对装备卡执行完整激活流程: 规则校验 -> LP 检查 -> 槽位分配 -> 效果分派. 入口: r0=card_ptr (装备卡结构), r1=partner_ptr (可选, 装备目标指针 或 0). 首先调用 check_card_placement_rules 检查基础放置合规性; 不合规则跳出返回 0. 若 partner_ptr 非 0, 分别获取两张卡的 get_card_equip_zone_rank 并做优先级比较 (rank_self<rank_partner -> 不允许); 对特殊卡 0x19a3 额外要求 check_card_field5_is_nonzero. 然后调用 get_card_lp_cost_by_id 取装备代价, 与玩家当前 LP ([gP1LifePoints+player*0x868]) 比较; LP 不足或玩家 == 当前激活方 (0x0201e2a0) 则写 [gP1LifePoints+0x1d78]=0x17 并返回 0. LP 充足时搜索装备槽 (find_first_available_monster_slot), 更新卡结构 [card+2] 的 zone_bits, 调用 dispatch_card_effect_activation. 返回 dispatch 结果. Constants: special_equip_id=0x19a3, player_stride=0x868, lp_field_offset=0x1d78, activation_flag=0x17.
