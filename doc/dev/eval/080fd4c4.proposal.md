title_ex 场景 OBJ 图形资源全量初始化函数.
调用 fs_load(r0=?, r1=0) 加载文件系统资源后, 保存返回指针至 r7.
以 sp 缓冲区为目标调用 zero_struct_36bytes 两次 (各清零 0x24 字节结构体),
每次填入 OBJ tile 属性字段后调用 apply_gfx_resource_list 提交资源列表.
首次: tile 属性 bits[7:0]=0x03 (双色调模式), bits[7] 清零 (非 mosaic), palette mask 0xffffc07f, slot 0.
次次: 额外设置 bit7=1 (Horizontal-flip), size 字段 0xa0<<4=0xa00 写入 attr1 高位,
      颜色深度标记 0xe0<<9=0x1c000, 然后写 OBJ 调色板寄存器高半字.
退出: pop{r3,r4,r5}; .hword 0x4698/0x46a1/0x46aa (mov r8,r3; mov r9,r4; mov r10,r5); pop{r4,r5,r6,r7}; pop{r0}; bx r0 (Pattern B void).

  HFLIP_BIT = 0x80 (attr1 bit7 = horizontal flip)
  OBJ_PAL_DEST = 0x05000000 (OBJ palette base via 0xa0<<0x13)
