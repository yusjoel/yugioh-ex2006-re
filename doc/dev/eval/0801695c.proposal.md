# Naming Proposal: 0x0801695c

## 提案
- **proposed_name**: apply_objd_entry_to_sprite
- **confidence**: high

## plate comment (中文, ASCII 标点)
将一个 OBJD (Object Data) 资源条目的图块和属性数据应用到目标 OAM/精灵状态结构体. 入参 r0 为目标精灵结构体指针, r1 为 OBJD 条目指针. 函数读取条目的 data_len ([+0xc]), 用 __udivsi3 除以 tile_stride ([+0xa]) 得到行数, 写入 r0[+0x12]; 提取 tile_attr 等字段写入目标结构体各 OAM 字段. 若 OAM mode ([r0+0x14] bits[3:0]) == 4 (4bpp indexed) 且有 VRAM 目标偏移, 则调 copy_to_obj_tile_vram 写入 OBJ tile VRAM. 返回固定 0. 由 FUN_08016a7c 在遇到 "OBJD" 标签时调用.

Constants: "OBJD" = 0x444A424F; 模式 4 = 4bpp indexed tile mode.

## 参数签名
- r0: void* sprite_dst -- 目标精灵状态结构体指针 (OAM 相关字段)
- r1: void* objd_entry -- OBJD 资源条目指针 (含 data_len/tile_stride/tile_attr 等)
- 返回: r0 = u32 0 (固定, 表示处理完成)

## 副作用
- [sprite_dst+0x4]: 写入 tile data 起始偏移 (r1+0x20 处理后)
- [sprite_dst+0x12]: strh 写 tile 行数 (data_len / tile_stride)
- [sprite_dst+0x14]: 写 tile_attr bits[7:4] (palette 序号) 和 bits[3:0] (mode)
- [sprite_dst+0x1a]: 写 visible/flip 属性位
- [VRAM OBJ tile 0x06010000+]: 若 mode==4, 经 copy_to_obj_tile_vram 写入
