Per-frame OAM update for a single animation slot in the pack scene (r0=slot_index).
Reads animation sub-struct from pack_ui_state (0x03005850) offset 0x58:
[+0xc]=countdown, [+0x4]=x_start, [+0x8]=x_end, [+0xe]=elapsed, [+0x6]=y_start, [+0xa]=y_end.
Skips update if countdown==0.
Otherwise linearly interpolates current x/y (x_start + (x_end-x_start)*elapsed/total via bios_div),
assembles OAM attr (tile_idx<<1 + 0x100 | 0x2000), calls write_oam_entry_from_packed_args.

Constants:
- pack_ui_state = 0x03005850
- ANIM_SUBSTRUCT_OFFSET = 0x58 (animation sub-struct start in pack_ui_state)
- OAM_ATTR_X_BASE = 0x100 (0x80<<1; OAM attr x-coord base offset)
- OAM_ATTR_FLAGS = 0x2000 (0x80<<6; OAM attr2 priority/palette flags)
