## plate comment (中文, ASCII 标点)
激活判定谓词. 入参为卡槽指针 (r0). 保存调用方高寄存器 r8-r10 至 r5-r7 后, 将 r0 存入 r8 作为持久卡槽指针.
读取 gP1LifePoints+0x1cf4 (场地所有权标志字), 若值为 2 或 4, 进入针对该字段的额外判定路径.
在主判定路径中循环调用 eval_card_placement_flags_default 对每个可能位置评估放置标志.
若评估结果满足条件则返回 1 或 2, 否则返回 0.

Inputs: r0 = card_slot_ptr (卡槽指针)
Outputs: r0 = 2(特殊场地状态通过) / 1(普通通过) / 0(不满足)
Side effects: 无外部写入.
Constants: FIELD_STATE_OFFSET=0x1cf4, PLAYER_STRUCT_STRIDE=0x868
