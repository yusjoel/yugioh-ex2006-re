check_equip_slot_eligible_by_field8_9_prereqs_and_type
Equip card target zone eligibility predicate combining five conditions.
Callers: check_zone_slot_equip_prerequisites (0x08036770), query_slot_card_type_eligibility (0x0803670c).
Checks in order: (1) gDuelFieldSlots[player_id&1][slot_idx] bits[18:0] != 0 (slot occupied);
(2) slot_idx <= 4 (monster zone bound); (3) equip_slot[+2]bit0 != player_id (opposite side check);
(4) check_card_field8_is_9(card_icid)==0 (field8==9 cards cannot be equipped);
(5) check_zone_slot_equip_prerequisites passes; (6) query_slot_card_type_eligibility==0 (type compatible);
(7) [slot+8] != 0 (secondary occupied flag).
Returns 1 if all pass, 0 on any failure. Pure predicate, no external writes.
Constants: SLOT_IDX_MAX=4, gDuelFieldSlots=0x0201c510, player_stride=0x868
Inputs: r0=ptr equip_card_slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..4]
Returns: r0=u32 bool (1=eligible, 0=rejected)
