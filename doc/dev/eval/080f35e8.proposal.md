## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
从 IWRAM 渲染状态结构体 [0x02006ed0] 读取 tile 列数和行数, 然后以双色 (r1 低字节=前景色 4bpp 索引,
r1 高字节=背景色 4bpp 索引) 对一块矩形 tile 区域执行像素级 OR-mask 写入.
外层循环按 tile 行 (从结构体读取行/列计数乘积), 内层按列步进 0x40 字节/tile 行,
对每个非零像素 tile 执行 strh 到 VRAM 基址 (r0). r0 入口保存至 r2 供内层循环使用.
被 commit_line_buffer_to_sprite_vram 和两个未命名邻居调用, 是将行缓冲区内容刷入
OBJ VRAM 的最后一步位操作核心.

## 参数签名
- r0: void* dst_vram_base (目标 VRAM 基地址, 通常 0x06xxxxxx OBJ tile 区域; 入口第一条指令 adds r2,r0,#0 将其保存至 r2 供内层循环使用, r2 不是参数)
- r1: u16 color_pair (packed 双色: 低字节 = 前景色 4bpp palette 索引, 高字节 = 背景色 4bpp palette 索引; 入口经 lsls/lsrs u16 截断存入 r4)
- 返回: r0 = void

## 副作用
- [VRAM 0x06xxxxxx]: 对矩形 tile 区域内每个非空像素执行 strh 写颜色值 (两色 OR-mask)
