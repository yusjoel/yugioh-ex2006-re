## plate comment (中文, ASCII 标点)
为决斗场当前状态构建并更新装备目标有效位图. 函数分两大阶段: 阶段一对 player=0..1 x slot=0..4 遍历调用 count_equip_chain_default_flags, 将满足条件的槽位按 bit 写入内部位图 r9; 调用 FUN_08046538(build_equip_placement_valid_bitmap)获取装备放置有效位图并存 sp[0x10]; 阶段二对 player=0..1 x slot=0..10 再次遍历, 调用 check_card_type_is_spell 过滤魔法卡, 并按 zone_type(0xb/0xd) 分派精灵属性; 随后调用 FUN_0805b990 查询效果节点快照, 用 count_field_copies_of_card 统计场上卡数量后组合精灵标志写入 gP1LifePoints+offset 控制字段, 最后调用 FUN_0804659c(check_slot_equip_target_eligibility) 逐槽写入精灵属性. 由 25 个 duel_field 调用方触发, 是装备目标选择的核心公共工具(C_util_high). Side effects: 写 gP1LifePoints+0x10d4 区的控制字段(str r0,[r4,#0x0]); 调用 FUN_0804659c 间接写 OAM 精灵属性队列.
