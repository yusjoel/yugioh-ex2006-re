## plate comment (中文, ASCII 标点)
在指定玩家 (r0 bit0=player_side) 的场地槽中按卡 ID (r1=target_card_id) 线性扫描, 返回第一个匹配槽的索引或 -1. 函数读取 gDuelFieldSlots+side*0x868+slot_idx*0x14 处 32 位字的低 13 位 (lsls #2/lsrs #0x18 提取 zone_type; lsls #0x12/lsrs #0x1f 提取 side_bit), 将 zone_type<<1 | side_bit 与 r5=target_card_id 比较; 匹配则返回当前计数 r3 (槽编号 [0..count-1]); 全部不匹配则返回 -1 (rsbs). 被 check_spell_zone_slot_placeable / FUN_0803e474 / FUN_0803e594 / FUN_0804135c 等约 21 处调用, 用于在激活法术时定位特定卡所在槽位置.

## 参数签名
- r0: u32 player_side_and_flags (bit0 = player_side [0..1])
- r1: u16 target_card_id [0..0x1fff]
- 返回: r0 = s32 slot_index [0..count-1] 命中槽编号, 或 -1 (未找到)

## 副作用
无外部写入; 纯读取.
