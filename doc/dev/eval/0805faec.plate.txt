check_equip_eligible_by_turn_player_lp_or_chain
Extracts player_id (byte[+2] bit0) from slot_ptr (r0).
Reads curr_turn_player from gP1LifePoints+0x1ce8. Two paths:
(A) player_id != curr_turn_player: reads gP1LifePoints+0xc+player_id*0x868;
    if field > 3 -> r3=0 (ineligible); else r3=1. Returns r3.
(B) player_id == curr_turn_player: extracts zone_idx (bits[6:2]) and card_id (ldrh[+0]);
    calls check_value_in_slot_chain(player_id, zone_idx, card_id); forwards result.
Different eligibility paths depending on turn player relationship.

Constants:
- gP1LifePoints+0x1ce8: curr_turn_player
- gP1LifePoints+0xc: LP state field (per-player at +player*0x868)
- PLAYER_STRIDE = 0x868
- LP_STATE_THRESHOLD = 3 (field value > 3 means ineligible)

Inputs: r0 = SlotPtr* slot_ptr (byte[+2] bit0=player_id [0..1]; bits[6:2]=zone_idx [0..31]; ldrh[+0]=card_id)
Returns: r0 = u32 -- path A: 1 if LP_state <= 3, 0 if > 3; path B: result of check_value_in_slot_chain
Side effects: none (pure query)

Callers: indeg=0; grep ".word 0x0805faed" asm/all.s -> 0 hits (Sub-type A dead code)
Callees: check_value_in_slot_chain
