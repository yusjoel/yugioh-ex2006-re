Equip slot activation eligibility predicate, three-level composite condition:
(1) read gP1LifePoints[player*0x868+0x1c] (hand alt count), if <= 3 reject;
(2) read gP1LifePoints[player*0x868+0x14] (zone occupy count), if != 0 reject;
(3) read gP1LifePoints[player*0x868+0x10] (player status word), if <= 1 reject;
all pass returns 1, any failure returns 0.
Constants: HAND_COUNT_OFFSET=0x1c, ZONE_OCCUPY_OFFSET=0x14, PLAYER_STATUS_OFFSET=0x10,
PLAYER_STRIDE=0x868, HAND_COUNT_THRESHOLD=3, PLAYER_STATUS_THRESHOLD=1.
