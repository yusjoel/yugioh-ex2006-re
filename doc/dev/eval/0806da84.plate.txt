Effect node handler. Checks guard bit2; extracts player_id (bit0) and zone_idx (bits[6:2]) from [r0+2], calls test_equip_target_slot_zone13(effect_node, player, zone_idx) for equip target zone13 test; then calls enqueue_lp_counter_sprite_by_player(player) to enqueue LP counter sprite. Fixed return 0.

Inputs: r0=ptr effect_node ([+2]=flags u8 with player bit0 and zone bits[6:2], [+4]=guard_bits u8 bit2=guard).
Returns: r0=0 (void semantic, fixed return 0).
Side effects: writes sprite queue (via enqueue_lp_counter_sprite_by_player).
