## plate comment (中文, ASCII 标点)
equip LP bar 显示序列的 phase-B 步骤推进器, 与 tick_equip_lp_bar_display_phase_a (0x080a2234) 对称. 主要差异: 读取 0x0201e274 (替代 gP1LP+0x1d94 直接读) 处的 step 计数器; step=0 path 中写 [0x0201e28a] (equip zone 特定指针) 的 hword; step=1 path 中调用 enqueue_equip_zone_sprite_direct 而非 dispatch_equip_zone_sprite_banisher. 整体流程: step=0 -> increment_lp_bar_display_counter; step=1 -> check_activation_display_state_is_confirmed; step=2 -> decrement_lp_bar_display_counter. 高寄存器 prologue 与 phase_a 相同.

Constants:
- gP1LifePoints = 0x0201c4e0
- STEP_PTR = 0x0201e274
- ZONE_SLOT_PTR = 0x0201e28a
- LP_PACKED_OFFSET = 0x1da8
- LP_STRIDE = 0x868

## 参数签名
- r0: u32 player_id [0..1] (spilled via .hword 0x4680 = mov r8,r0)
- r1: u32 slot_param (str [sp,#0] on entry; step=0 path uses r1 as hword write target)
- r2: u32 direction_flag (cmp r2,#0 -> sp[4])
- 返回: r0 = i32 (0=step 推进继续, 1=序列完成; 出口 pop{r4,r5,r6,r7}; pop{r1}; bx r1)

## 副作用
- [0x0201e28a+0x1da8 offset] := hword (step=1 confirmed path)
- [0x0201e274] 推进 step counter
- increment_lp_bar_display_counter / decrement_lp_bar_display_counter 副作用
