# Naming Proposal: 08106d88

## 提案
- **proposed_name**: render_card_name_tiles_to_vram
- **confidence**: med

## plate comment (中文, ASCII 标点)
在卡牌信息显示页面中, 将卡名字符 tile 数据批量写入 VRAM (0x0600e800 区域). 由 FUN_081067e0 在每帧卡名区域刷新时调用. 函数根据 gPrng/state 中的字体宽度标志 (bit2 of byte+0x1e) 选择 6 格或 7 格列宽, 计算出每字符在 tile 网格中的行列位置, 再用 strh 逐 tile 写入目标 VRAM; 对每行最多写 16 个 halfword (0xf+1). 副作用: 修改 0x0600e800 起始的 OBJ tile VRAM 区域.

## 参数签名
- r0: (无外部输入; 函数体首指令即覆写 r2=DAT_08106dbc, r0=DAT_08106dc0, 所有调用寄存器在 prologue 前 4 指令内被覆写)
- 返回: r0 = u32 1 (fixed; success, no failure path)

## 副作用
- [0x0600e800 + stride]: strh 逐 tile 写入卡名字符数据

## 行级注释 (≤ 30 行精华)
- @ 08106d9c: ldrb byte[0x0202f3c0+0x1e], and 0x4 — 字体宽度标志 (bit2=1 => 6格宽, 0 => 7格宽)
- @ 08106da4: r7 = 7 (宽模式) 或 6 (窄模式) — 每行最大 tile 列数
- @ 08106db2: ldrsh [r2+0x66] — 卡名 tile 行偏移或字符数
- @ 08106dc6: bl __divsi3 — 计算 tile 列位置 (整除列宽)
- @ 08106dd4: bl __modsi3 — 计算 tile 行内偏移 (mod 3)
- @ 08106de4: DAT_08106e34=0xffff9000 — VRAM tile 写入基址掩码/偏移
- @ 08106df8: lsls r0,#0x4 — 每 tile 16 halfword (32 字节)
- @ 08106e02: 写循环: r3 从 0xf 到 0, 共 16 次 strh
- @ 08106e0a: strh 写入 [r1+VRAM_base]
