## plate comment (中文, ASCII 标点)
检测当前槽激活状态与缓存状态是否一致, 有变化时触发显示更新. 先在栈上分配 0x48 字节缓冲, 调用 fill_slot_activation_state_array(sp+4) 计算 5 个槽的当前激活状态; 与缓存在 [DAT_080975b0+0xec]/[+0xf0] 中的旧状态比对. 若状态一致则进一步调用 check_slot_card_activatable, memcmp 对比 0x44 字节详细数据, check_player_field_spell_chain_eligible, eval_slot_activation_eligibility_full 等校验; 任一校验失败则设 r6=1 (changed). 若 changed: 更新 [gP1LifePoints+0x1d28]=1, [gP1LifePoints+0x1d2c]=0 (激活刷新标志), enqueue_sprite_attr_record (sprite 0x801b/0x177a), 调用 dispatch_card_display_op(0xb) 和 set_field_slot_bit_with_sprite_update(slot,0x15,1). 由 FUN_08098264/FUN_08098564 (card display state machine) 调用. 返回 1=状态改变/已刷新, 0=无变化.

Side effects:
- [DAT_080975b0+0x8] := 0 (缓存失效标记, 变化时)
- [gP1LifePoints+0x1d2c] := 0, [gP1LifePoints+0x1d28] := 1 (激活刷新控制字)
- OAM sprite 属性缓冲区: enqueue_sprite_attr_record 写入
- dispatch_card_display_op(0xb,...): 卡显示操作
- set_field_slot_bit_with_sprite_update: slot 激活 bit 0x15 置 1

Constants: SPRITE_ATTR_ACT=0x177a, SPRITE_ATTR_ALT=0x801b, ACTIVATION_REFRESH_OFFSET=0x1d28, ACTIVATION_CTRL_OFFSET=0x1d2c.
