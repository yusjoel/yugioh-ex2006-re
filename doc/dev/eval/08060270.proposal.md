## plate comment (中文, ASCII 标点)
检查 slot_ptr 对应卡槽是否挂载于 zone_descriptor==0xf 的区域.
首先验证 byte[+3] bits[5:4]==0b10 (0x20), 这是特定魔法陷阱区类型标志;
若不匹配则返回 0.
随后以 (player_id, card_id, type_code=0xb) 调用 get_node_entity_id_in_slot
获取实体 ID; 若 <0 则返回 0.
将实体 ID >>2 转换为 slot_id 后调用 find_zone_descriptor_by_slot_id;
提取返回字的 bits[15:8], 检查是否 ==0xf; 是则返回 1, 否则返回 0.
Side effects: 无外部写入.

- 0x30: byte[+3] 掩码 (bits[5:4])
- 0x20: 目标类型值 (bits[5:4]==0b10, 特定 spell/trap zone)
- 0xb: get_node_entity_id_in_slot 的 type_code 参数 (equip chain node type)
- >>2: 实体 ID -> slot_id 转换 (entity_id / 4 = slot_id)
- 0xf: zone_descriptor bits[15:8] 目标值 (zone F)
