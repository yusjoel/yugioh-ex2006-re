# Naming Proposal: 0x080adf8c

## 提案
- **proposed_name**: check_special_card_activation_eligible
- **confidence**: med

## plate comment (中文, ASCII 标点)
针对特定卡片 ID 执行专用激活条件检查. r0=card_id 与一组硬编码特殊卡 ID (0x1366, 0x137d, 0x15e6) 比较; 匹配时从 0x0201e500+r1*4 处读取槽内 card_id, 再与另一组 ID (0x1596, 0x13c3, 0x1914) 比较, 最终返回 0/1 表示激活是否合法. 对 card_id=0x1914 分支: 调用 count_equipped_paired_slots_for_player 双玩家检测, 若任一方有装备配对则返回 0 (不可激活). 单一 caller: FUN_080ae050 (card_ids+duel_field 分发主控).

## 参数签名
- r0: u32 card_id [0..0x7fff] - 待检查的卡片 ID (与特殊 ID 集合比较)
- r1: u32 slot_index [0..N-1] - 槽索引, 用于从 0x0201e500+idx*4 读取关联卡 ID
- 返回: r0 = u32 eligible [0..1] - 1 表示可激活, 0 表示不满足条件

## 副作用
- 无外部写操作 (count_equipped_paired_slots_for_player 为只读)

- @ 080ae048: 默认返回 0 (不可激活)
