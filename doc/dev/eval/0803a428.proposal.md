## plate comment (中文, ASCII 标点)
本函数是 AI 卡牌评分流程的中间段, 在大型函数 (起始于 0x08037ec0 附近) 中以 bl 调用, indeg=1. 根据 sp[0x70] 和 sp[0x6c] 标志决定对 r7[0x14] (atk_score) 和 r7[0x18] (def_score) 做加法还是减法调整, 调整量来自多个栈变量的累加. 随后调用 count_field_copies_of_card (卡牌 0x1951=防御模式相关特定卡) 检测场上副本, 若存在且 r7[4]==4 或 r7[0xc] bit4 非 0, 将 atk_score 归零. 调用 test_slot_has_active_card 和 count_occupied_monster_zones_with_effect_bonus 对分数进一步修正 (2 个怪兽区满时翻倍). 调用 FUN_0802f3a8 统计链式卡数并对 atk_score 做 >>1 收缩处理. 最后调用 count_available_effect_zones 两次并对两个分数分别收缩. 函数末尾 clamp 两个分数不低于 0, 然后 fall-through 至 FUN_0803a520 (epilogue).

Constants: 0x1951=特定卡牌 ID (count_field_copies_of_card 参数), 0x1955=test_slot_has_active_card 参数, 0x1381=FUN_0802f3a8 filter_value, 0x1905=count_available_effect_zones 参数.
