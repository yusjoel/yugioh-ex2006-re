# Naming Proposal: 0x080a1a78

## 提案
- **proposed_name**: enqueue_lp_display_row_if_enabled
- **confidence**: high

## plate comment (中文, ASCII 标点)
LP 栏显示行条件性提交封装函数, 由字段显示调度链上层 9 个不同 LP 栏渲染调用点调用.
当 r1 (enable_flag) 为 0 时立即返回, 跳过显示行更新; 非零时计算 OAM 条件位 (r2 非零则 bit0 置位, r3 非零则 bit1 置位), 将 r0 (lp_ptr) 与 r4 (r1 zero-extended halfword) 组合后调用 set_lp_display_row_fields_and_commit.
副作用目的: 为 LP 显示行提供使能门控, 防止在 LP 未发生变化时无谓触发精灵提交.

## 参数签名
- r0: ptr lp_ptr  LP 行显示起始地址
- r1: u32 enable_flag  非 0 时允许提交 [0..any]; 0 直接返回
- r2: u32 val_c  用于 bit0 条件: rsbs/orrs/lsrs#0x1f 提取非零标志
- r3: u32 val_d  用于 bit1 条件: cmp#0, 非零则 r3 |= 2
- 返回: void (pop+bx lr)

## 副作用
- 若 enable_flag != 0: 间接写 gP1LifePoints LP 显示行字段 (通过 set_lp_display_row_fields_and_commit)
- 若 enable_flag == 0: 无任何写入

## 行级注释 (<= 30 行精华)
- @ 080a1a80: cmp r4,#0 -> beq LAB_end, enable_flag 为 0 时跳过全部更新
- @ 080a1a84: rsbs r0,r2,#0; orrs r0,r2 -> 计算 r2 是否非零的 bool (bit0)
- @ 080a1a88: lsrs r3,r0,#0x1f -> 将非零标志移到 bit0, 作为 OAM 条件标志
- @ 080a1a8e: movs r0,#2; orrs r3,r0 -> r3 非零时在 bit1 置位
- @ 080a1a92: lsls r2,r4,#0x10; lsrs r2,r2,#0x10 -> zero-extend r4 (r1 输入) 为 halfword
- @ 080a1a9a: 调用 set_lp_display_row_fields_and_commit 完成字段写入与精灵提交
