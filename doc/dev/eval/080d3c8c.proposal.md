## plate comment (中文, ASCII 标点)
对两个区域槽位 (r0, r1 各为 u16 slot index, zero-extend) 执行卡片属性比较并返回比较结果码. 入口: r8=gDuelCtx (内部加载 DAT=0x02020160), r9=card_stats_table, r10=DAT_080d3cc8=0x02020160 (internal load, 非参数). 主循环 2 次 (r7=0,1): 对每个 slot 调用 check_zone_slot_attr_visible; 若可见则从 card_stats_table 读取属性 word (slot_id*5*8+base) 通过 ldmia 批量复制 24 bytes; 根据 r1 (原参数) 与 0x16/0x17 比较决定返回码: r1==0x16 -> rsbs r0=-2; r1==0x17 -> rsbs r0=-3; 不匹配 -> 继续; 可见性检查失败 -> rsbs r0=-4. 与 FUN_080d3d28 / FUN_080d3dc4 构成三元兄弟簇, 差异在于返回码常量. Side effects: ldmia/stmia 批量写槽位属性到栈 (stack-local, 非外部副作用). Constants: gDuelCtx=0x02020160, card_stats_table=内部加载, slot_stride=5*8=40, loop_count=2, sentinel_16=0x16, sentinel_17=0x17.
