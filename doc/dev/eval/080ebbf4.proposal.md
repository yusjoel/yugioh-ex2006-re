## plate comment (中文, ASCII 标点)
语言选择页面的 tile/map 加载与文字渲染. 被 enter_language_selection_page (0x080ebfb8) 在 state=0 时紧接 init_lang_select_vram_and_regs 调用. 读 [0x080000ae] 高字节判断 ROM region (0x45=E 区则选备用 pack 地址), 调用 3 次 load_pack_tile_and_map_to_vram 加载背景 tile 和 map. 清零 0x06010000 VRAM. 复制两批调色板到 0x05000220. 设置 line_buf 起始位置 (x=0x18, font=2). 读 gSettings language bits 确定当前语言, 从 font_jp_base_table 取字体. 计算游戏标题文字宽度并居中, 调用 text_render_wrapper 渲染标题行和副标题行, 写入 BG tile VRAM. 循环 i=0..5 渲染 6 个语言选项字符串到 BG tile VRAM. 写 gPrng[+0x1f4] 函数指针 (0x080ebb15).

Constants:
- ROM_REGION_ADDR = 0x080000ae (region byte, 0x45='E' for US/EU)
- BG_TILE_VRAM = 0x06010040 (DAT_080ebe7c), 0x06010800 (DAT_080ebcd0), 0x06010a00 (DAT_080ebe8c)
- PALETTE_2DMAIN = 0x05000220 (DAT_080ebcc8)
- gSettings = [0x02000000+0x6c2c]
- gPrng+0x1f4 = 0xfa*2 = flag (fn ptr)
