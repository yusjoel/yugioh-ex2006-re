## plate comment (中文, ASCII 标点)
Function: 根据 gP1LifePoints+0x4a0 保存的场景状态码, 路由单个效果槽 (effect slot) 的链式精灵更新逻辑. 状态码 0x64/0x6e/0x7f/0x80 分别对应四条不同处理路径.

状态 0x80: 调用 dispatch_card_effect_activation(slot_ptr) 检查激活资格; 若返回非零则读 r4[+2] bit0 (player_id), 调用 count_field_zone_cards_with_field5 / check_zone_eligible_with_deck_flag 或 set_lp_display_row_type5; 返回 0x7f.
状态 0x7f: 读取 gP1LP+0x4a0 zone word, 提取 slot_id 和 player_id, 在 gDuelFieldSlots[player*0x868+slot*0x14] 中读取精灵 tile 索引, 调用 enqueue_sprite_attr_record 入队 OAM 精灵; 返回 0x7f.
状态 0x6e: 调用 trigger_card_display_op31_if_not_active(player_id, 0x11); 返回 0x64.
状态 0x64: 调用 check_zone_eligible_with_deck_flag(1-player_id, r1=1).

副作用: 通过 enqueue_sprite_attr_record 写精灵队列 (OAM 路径); 通过 set_lp_display_row_type5 写 LP 显示行.

Constants:
- STATE_FIELD_CARD_ACTIVATION = 0x80
- STATE_SPRITE_ENQUEUE = 0x7f
- STATE_TRIGGER_OP31 = 0x6e
- STATE_DECK_ELIGIBLE_CHECK = 0x64
- EFFECT_SLOT_STATE_OFFSET = 0x4a0 (0x94*8, from gP1LifePoints base)
- PLAYER_STRIDE = 0x868
- SPRITE_OP_PARAM = 0x3f (attr0 low byte)

## 参数签名
- r0: effect_node_ptr* ptr, 指向当前效果槽节点 (提供 player_id, slot_idx, card_id)
- 返回: r0 = u8 次态状态码 (0x64/0x6e/0x7f/0x80/0x0); 各路径确定返回不同值, 0 表示无动作

## 副作用
- OAM sprite queue: 通过 enqueue_sprite_attr_record 入队精灵属性 (0x7f 路径)

- trigger_card_display_op31_if_not_active: 修改 display op 状态 (0x6e 路径)
