## plate comment (中文, ASCII 标点)
由 FUN_0810796c (settings/card_frame 渲染函数) 循环调用, 用于计算特定 slot 位置上指定卡片的能力值加成 (bonus). 函数根据 IWRAM 0x0202f3c0+[0x00006c2c] 中的 lang_flag bit[2:0] 选取两套卡片数据表 (EN 版: 0x09e606f4; JP 版: 0x09e60894), 然后 switch 卡片类型字段 (偏移 0 处的 halfword, [1..4]): type3 对应 +(-19) 行偏移, type4 对应 +(-10) 行偏移, type1/2 走默认分支. r2 和 r3 为两个输出指针 (分别指向调用方栈上的 y_delta 槽和 x_bonus 槽), 将计算出的 y_delta 和 x_bonus 分别写入 *r2/*r3 供调用方合成 OBJ 属性.

## 参数签名
- r0: u8 slot_idx (deck slot 索引 [0..25], 乘 16 后偏移到卡片数据区; 实测 caller 传入最大 0x19)
- r1: u8 card_type_idx (卡片类型偏移 [0..2]: render_card_frame_scene 固定传 1, FUN_0810796c 传 [0..2])
- r2: u32* out_y_delta (输出: y 方向行偏移量, 由调用方栈地址传入)
- r3: u8 loop_idx (当前迭代编号, 透传)
- 返回: r0 = u32 (1=成功)

## 副作用
- *r2 := s16 y_delta (通过 r2 输出指针写入调用方栈上的 out_y_delta 槽)
- *r3 := s16 x_bonus (通过 r3 输出指针写入调用方栈上的 out_x_bonus 槽)
