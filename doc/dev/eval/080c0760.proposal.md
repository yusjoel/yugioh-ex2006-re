## plate comment (中文, ASCII 标点)
将卡图 tile 以 5x4 网格形式写入 OAM (Sprite 属性), 被 play_ui_effect_33 / play_ui_effect_34 共同调用. 根据 r0 (有符号 tile 偏移或帧计步值) 计算 OAM attr 标志位 (bit[7] = 有无 tile 数据), 对 5 行 x 4 列的 OAM 条目循环调用 write_oam_entry_with_tile_inc, 每行 tile 步进 0x20, 每列 attr 步进 4. 列数 = 4, 行数 = 5 (r5 从 0 到 4), 最终 OAM 以 5x4 矩阵覆盖卡图显示区域.

Constants:
- GRID_COLS = 4 (inner loop count, cmp r6,#3 ble)
- GRID_ROWS = 5 (outer loop count, cmp r5,#4 ble)
- OAM_ATTR_BASE = 0x80 = attr0 high byte (OBJ enable, 普通模式)
- OAM_ATTR_LARGE = 0x8080 = 0x80*0x100+0x80 (大 OBJ attr1 高位 flag)
- TILE_ROW_STEP = 0x20 (r7 每行步进 halfword 数)
- ATTR_STEP = 4 (r4 每列步进 4 字节)
- OAM_ATTR_COL3_FLAG = 0x40 (第 4 列 attr3 特殊标志 cmp r6,#3 / cmp r5,#4)
