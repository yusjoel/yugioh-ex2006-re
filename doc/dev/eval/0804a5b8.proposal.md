## plate comment (中文, ASCII 标点)
Function: 双层循环 (外层 r7=0..1 = player_side, 内层 r9=0..slot_count-1 = slot_idx),
对每个 monster slot 的卡 (card_type_category==3 即 Spell 类) 提取 pair_code 字段
(bits[21:14]x2 + bit14), 并带 flag(0x1c/0x18/0x40) 合成 sprite attr, 调用
enqueue_sprite_attr_record(type=0x3f). 同时搜索 effect node (find_effect_node_in_zone,
type=0xb) 并在找到时提交第二条带 pair_code 的 sprite attr. 外层结束后追加一条 type=0x5a
zero-sentinel 记录, 再对两个 player 调用 enqueue_lp_counter_sprite_by_player 提交 LP
数字 sprite. 由 FUN_080718c4 (LP bar 更新链) 调用. 副作用为向全局 sprite queue 追加多条记录.
