## plate comment (中文, ASCII 标点)
从墓地双数组 (gP1LP+0x5d0 和 gP1LP+0x788, 计数在 gP1LP+0x1c) 按索引删除一个元素并左移后续元素. r0=player_id [0..1], r1=slot_idx. 函数同时维护两个数组: word 数组 (gP1LP+0x5d0+player*0x868) 和 halfword 数组 (gP1LP+0x788+player*0x868); 删除时两者同步左移. 计数 -1. 若 slot_idx < new_count 执行 shift; 返回 1=成功, 0=越界. 调用方 FUN_0803720c 在搜索匹配后调用本函数.

- 返回: r0 = u32 (1=成功; 0=越界)

## 副作用
- [gP1LP+0x5d0+player_id*0x868+idx*4 .. +new_count*4]: word 数组左移
- [gP1LP+0x788+player_id*0x868+idx*2 .. +new_count*2]: halfword 数组左移
- [gP1LP+0x1c+player_id*0x868] -= 1
