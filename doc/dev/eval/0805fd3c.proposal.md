## plate comment
触发场景: 装备效果激活合法性判定, 经函数指针调用。高寄存器用于 callee-save (r8=r0 via .hword 0x4680, r9=r1 via .hword 0x4691 等)。
功能: (1) 提取 player_id (byte[+2].bit0), 用 stride 0x868 查 gP1LifePoints[player*0x868+0x10] -- 场地效果激活数量; 若 <= 1 则直接失败。(2) 遍历 0..10 号怪兽区槽: 对每槽提取 [+0] (zone_flag 区字段, bits[19:0]), 检查 bit19 是否置位; 再提取 bits[9:2] * player + offset 计算手牌槽位, 比较与当前槽的 kicker 字段; 若匹配则报匹配成功并检查 lsls#0x11+lsrs#0x17 提取的计数字段是否等于限制字段。
(3) 全部槽遍历后, 最终调用 get_lp_count_minus_zone_slot_offset 验证 LP 余量。
副作用目的: 多重区域遍历 + LP 余量双重门控; 确保装备卡激活的区域条件和 LP 条件均满足。

Constants:
  gP1LifePoints (0x0201c4e0): 玩家 LP / 场状态全局基址
  0x868: player stride
  +0x10: 场地效果激活计数字段偏移
  0xa: 怪兽区槽遍历上界 (0..10)
  +0x30: 怪兽区槽数组基址偏移
