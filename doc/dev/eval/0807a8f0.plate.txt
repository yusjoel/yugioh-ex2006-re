Hand effect node match display state machine; called per frame by the display main loop. Reads global display state at [0x0201b290+0x4a0] and dispatches. State 0x80: takes player from node+2, takes the match slot count from [gP1LifePoints+player*0x868+0xc] as the loop bound; for each slot computes coordinates from the zone table entry and calls find_effect_node_in_zone(coord, 0xb, 0x12a1) to find the effect node in the zone; if all hit calls set_lp_row_type2_with_sign_flag_only to write the LP row and advances returning 0x7f, any miss returns 0. State 0x7f: calls invoke_equip_hand_slot_oam_if_eligible(node) to handle hand slot OAM. Others return 0. Statically dispatched via fn-ptr by the display main loop (indeg=0).

CALLEE-COLUMN GREP: grepping callee=0x0807a8f0 => 0 hits

Params: r0=effect_node* (node+2=player byte bit0; loop uses it to compute coords from LP/zone tables)
Returns: r0=u32 next display state code {0x7f, 0} (0=miss/no advance; 0x7f=match complete)
Side effects: no direct external write; LP row and OAM done internally by set_lp_row_type2_with_sign_flag_only / invoke_equip_hand_slot_oam_if_eligible
Constants: STATE_BASE=0x0201b290; STATE_OFFSET=0x4a0 (0x94<<3); PLAYER_STRIDE=0x868; ZONE_QUERY_VALUE=0xb (find_effect_node_in_zone 2nd arg); ZONE_QUERY_TAG=0x12a1 (find_effect_node_in_zone 3rd arg DWORD)
Note: mov r7,r10 / mov r6,r9 / mov r5,r8 + push on entry save callee-save high registers (not params); mov r8,r0 etc are internal aliases (loop index/base)
Exit: pop {r1};bx r1 = Sub-case E (r0 preserved as return state code)
