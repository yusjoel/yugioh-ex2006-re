# Naming Proposal: 0x080c2ddc

## 提案
- **proposed_name**: write_digit_oam_column_with_scroll
- **confidence**: med

## plate comment (中文, ASCII 标点)
将一列十进制数字 (由 r0=oam_packed_y, r1=OAM tile base) 逐位分解并写入 OAM 条目, 支持横向卷动偏移. 由 FUN_080c2e58 在 OAM 数字渲染流程中调用. 函数先对 r0 取模 10 得到个位数字, 加 0x70 获取 tile 索引, 与 r1 (OAM Y/X packed 坐标) 和 r7 (colour 字段) 合并后调用 write_oam_entry_from_packed_args; 然后对 r4 整除 10 循环至 r4=0, 每次步进 x 方向 -0xc (减 12 像素). r3 若非 0 则追加 gPrng+0x20c 的 bit1 作为额外偏移.

Constants:
- 0x70 = digit tile 基索引 (tile '0' = 0x70)
- 0x3c2 = OAM tile/attr packed 基值 (DAT_080c2e54)
- 0xc = 每位数字 X 步长 (12 像素)
- 0xa = 十进制模数
- gPrng + 0x20c (0x83*4) = 随机数字节, bit1 用于 x 微调

## 参数签名
- r0: u16 oam_packed_y -- OAM Y 坐标和模式字段 (packed, 入口 adds r6,r0,#0 保存; FUN_080c2e58 caller adds r5,r0,#0 传入)
- r1: u16 oam_attr_base -- OAM 颜色/tile 属性基值, 入口 lsls r5,r1,#0x10 打包到高位与 packed_y ORR; FUN_080c2e58 调用处传入固定值 0x40 [0..0xff]
- r2: u32 x_base -- X 基础像素坐标 (入口 mov r8,r2 = callee-save)
- r3: u8 scroll_flag -- 非 0 时从 gPrng+0x20c 读取额外 bit1 x 偏移 [0..1]
- 返回: void (无返回值)

## 副作用
- OAM 缓冲区: write_oam_entry_from_packed_args 写入每位数字的 OAM 条目 (位数 = digit_count)
- x 坐标每位 -= 0xc (右到左逐位写入)
