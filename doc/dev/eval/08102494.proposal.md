# Naming Proposal: 0x08102494

## 提案
- **proposed_name**: search_card_list_subtable_by_key
- **confidence**: med

## plate comment (中文, ASCII 标点)
根据模式参数 r0 (0-3) 从 IWRAM 0x0202a4d0 中选取对应子表偏移 (0x140c/0x160c/0x180c/0x1a0c), 读取该子表的条目数 (halfword), 若非零则以 r1 的低 12 位 (r1 & 0xfff, card_id) 为关键字调用 bsearch_index_by_callback 在子表中二分查找匹配条目, 返回命中条目的高 4 bit (lsrs 0x4). 若子表为空或未命中则返回 0. 被 FUN_08100238 (vram/card_stats/font_jp) 调用, 用于 card_list 场景卡片信息显示前的分类子表定位.

## 参数签名
- r0: u8 mode (0-3, 选择子表; 对应偏移 0x140c/0x160c/0x180c/0x1a0c; 其他值视同 default)
- r1: u32 search_key (低 12 位 = 卡片 ID; asm 081024a8 对 r1 执行 r1 &= 0xfff 后用作 bsearch 关键字)
- 返回: r0 = u8 命中条目的高 4 bit 字段 (>=0); 0 = 未命中/空表

## 副作用
- 无 (只读 IWRAM)
