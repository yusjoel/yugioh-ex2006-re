# Naming Proposal: 0x08097150

## 提案
- **proposed_name**: dispatch_to_effect_handler_by_card_type
- **confidence**: med

## plate comment (中文, ASCII 标点)
线性扫描固定效果处理表 (DAT_0809717c=0x09e47560, ROM 表), 以 r1 (card_type) 为键查找匹配条目.
每条目 stride=0x10: 第一个 word [+0x0] = card_type 键; 第四个 word [+0xc+r3] = 处理函数指针.
找到匹配项后以 (r0=r5, r1=r4, r2=r6) 调用 FUN_0810e5d4 (效果处理子程序), 传入匹配偏移 r3=lsls r1,#4.
循环最多 0x11 (17) 次 (cmp r1,#0x11; bls -> 17 个条目).
触发条件: 被 FUN_08095ec4 (card display state 0x2 路径) 调用, 传入 monster slot entry 信息;
被 FUN_080bb414 (duel_field zone 激活) 调用.
返回: void.

## 参数签名

- r2: u32 sub_param -- 附加参数 (saved as r6); 传给 FUN_0810e5d4 的 r2
- 返回: void
