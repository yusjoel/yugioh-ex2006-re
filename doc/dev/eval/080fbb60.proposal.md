## plate comment (中文, ASCII 标点)
构建 starter_deck 选择界面的单个卡组显示条目.
r0=deck_index [0..5], 从 struct_deck_table (ROM 0x09e5fd54) 中按 deck_index*8 取卡组指针和槽位数.
清零 EWRAM 0x02001138 起 0x8c*2=0x118 字节的显示缓冲区 (zero_fill_by_halfword).
从 [0x02006c2c] bits[2:0] 读取 charset_id, 写入缓冲区 [+0x17].
取 game_str id = deck_index + 0x5e7 (Dragon's Roar=0x5e7, ..., Spellcaster's Judgement=0x5ec),
通过 game_str_id_to_row + game_str_pointer_table 解析为本地化卡组名字符串, strncpy 0x16 字节至缓冲区 [+0].
然后遍历 deck 卡牌条目 (最多 slot_count 张): 对每张牌调用 apply_delta_to_hand_oam_entry (hand OAM 更新),
将 card_id 写入 EWRAM 0x02001138 卡牌槽数组.
最后 copy_bytes_by_halfword 将 0x118 字节从 0x02001138 复制到 0x02001368 (显示目标缓冲区);
在 [0x02001368 + 0x4088] 处置位 bit1.
退出: pop{r3,r4,r5}; mov r8,r3; mov r9,r4; mov r10,r5; pop{r4,r5,r6,r7}; pop{r0}; bx r0.
