# Naming Proposal: 0x080c2d24

## 提案
- **proposed_name**: blit_card_frame_tile_row_to_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
将卡片中型边框 (card_medium_frame_tile_data) 的指定行拷贝到 OBJ/BG VRAM. 由 5 个 play_ui_effect (20/21/23/25/0c) 在 vram/card_frame 场景下共享调用. 入参 r0=card_image_index_entry (选择边框变体), r1=目标 VRAM 行索引, r2=边框内行偏移. 函数先查 card_image_index 表, 再查 DAT_080000ae 的 0x4a 标志决定是否叠加 +1 变体 (field_spell 边框); 最终从 card_medium_frame_tile_data 按行计算源地址, 目标地址为 OBJ VRAM 0x06010000 + r1*0x20, 调用 tile_2d_row_copy 完成 2D tile 拷贝 (8列x6行区域).

Constants:
- card_image_index = 0x09085b00 (DAT_080c2d7c)
- card_medium_frame_tile_data = 0x08fbc080 (DAT_080c2d8c)
- 0x06010000 = OBJ tile VRAM base (DAT_080c2d90)
- 0x080000ae = 全局标志字 (0x4a = 0x74 >> 8, field_spell 判断)
- 0x02000000 + 0x6c2c = IWRAM 标志字节 (DAT_080c2d84/88)
- 0x8 = 每行宽度 (8 tiles), 0x6 = 拷贝行数

## 参数签名
- r0: u16 frame_idx -- 边框变体索引 [0..N-1] (索引 card_image_index 表)
- r1: u16 vram_row -- 目标 VRAM 行 [0..BG_tile_rows-1], 映射到 0x06010000+r1*0x20
- 返回: void (无返回值, 仅写 OBJ VRAM)

## 副作用
- [0x06010000 + r1*0x20 .. +8*0x6*0x20]: tile_2d_row_copy 写 8x6 tile 块
