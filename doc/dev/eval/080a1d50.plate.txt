LP display row type 10 (0xa) single-value wrapper: truncates r1 to low 16 bits, calls set_lp_display_row_fields(r0, 0xa, r1&0xffff, 0) with fixed type=0xa. Symmetric with set_lp_row_type6_with_value (0x080a1c48), differs only in type value (10 vs 6). Called by LP display paths (0x08082ed8, 0x08084ca8, tags=[duel_field]).
Side effects: writes LP display row type=0xa field via set_lp_display_row_fields.
Constants: ROW_TYPE=0xa (10, fixed; movs r1,#0xa), MASK=0xffff.
