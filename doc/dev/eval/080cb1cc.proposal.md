## plate comment (中文, ASCII 标点)
大型卡牌展示渲染总入口, 根据 card_entry[+0] 中的 mode_field (bit[26:22], 17 个 case) 分派到
不同渲染路径. r0(r8)=side, r1=card_entry_ptr, r2=clear_flag. 首先从 card_stats_table 读取
字段 +5/+6/+7/+8/+9, 再通过大 switch(mode_field[0..0x10]) 路由: case 0-4 渲染 ATK/DEF
等基础属性; case 5-0xa 渲染各类特效数字; case 0xb-0xf 渲染 spell/trap 特殊属性; case 0x10
处理二面牌. 每个 case 先调 zero_card_display_vram_regions 清场, 再调
decode_card_image_tiles_to_vram 上传大图 tile, 再调 write_card_digit_tiles_to_vram 写数字,
render_card_name_to_sprite_vram 渲染名称, 最后 commit. indeg=9, 卡牌大图展示核心流程.
Constants: card_stats_table=0x098169b8, gDuelFieldSlots=0x0201c510, player_stride=0x868.
