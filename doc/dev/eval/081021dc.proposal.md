# Naming Proposal: 081021dc

## 提案
- **proposed_name**: load_card_list_entry_to_slot
- **confidence**: med

## plate comment (中文, ASCII 标点)
card_list 场景的卡槽数据加载入口. 根据 r0(list_type: 0=全库/1=format/2=...) 和 r1(card_index) 决定从哪张牌组数据区复制 6 列字段到 IWRAM 0x0202a4d0[+0x6c] 指向的目标槽区. list_type==0 时按 r1>>5 定位 u32 位图确认该卡已出现; list_type==1 时调用 get_card_data_format_id 验证 card_index 在 format 范围内; 验证通过后调用 build_card_list_slot_display_entries 构建槽显示条目, 并分别循环填写 read/write_card_list_field_by_row_col 各字段, 最终调用 init_deck_slot_data 初始化对应牌组槽. 被 FUN_08108f80(scene_card_list 顶层驱动) 以变化的 card_index 反复调用.

## 参数签名
- r0: u32 list_type [0..2] (0=全库, 1=format, 2=其他来源)
- r1: s32 card_index (卡片索引; 负值或越界时提前返回 0)
- 返回: r0 = u32 1 (成功) / 0 (越界/无效)

## 副作用
- [0x0202a4d0+0x6c .. +0x6c+7*4]: 写入 card_list 槽字段 (6 列 row_col + index + 标志)
- [0x02001250 or 0x02001138]: 复制 0x118 字节卡组数据 (copy_bytes_by_halfword)
- 间接: reset_all_deck_slots / populate_deck_slots_from_card_list / init_deck_slot_data 产生牌组槽副作用
