# Naming Proposal: 0x0804c958

## 提案
- **proposed_name**: init_card_sprite_row_entry
- **confidence**: high

## plate comment (中文, ASCII 标点)
初始化一个 sprite row 条目 (0x18 字节 OAM 属性块). 先以 memset 将目标结构体清零 (0x18 字节), 再将 r0 (card_id_word) 写入首 halfword.
然后将 r1 (attr_word 截断为 u16) 中的各字段拆包写入 OAM attr0/attr1/attr2 字节:
- bit31 -> attr0[1] (flip_y), bits[29:27] -> attr1[5:4] (priority/size), bits[23:16]>>6 -> attr1[7:6] (shape)
- bits[20:21] -> attr2[5:4] (palette), bits[15:9] -> attr2[6] (tile index)
之后检查 base (0x0201b290) + 0x4cc 处的活跃槽计数, 若 > 0 则遍历各槽调用 dispatch_card_effect_activation 尝试激活效果.
若激活成功则调用 submit_slot_card_sprite_row_entry 提交该条目.
三个 caller 均来自 FUN_08095ba8/FUN_08095ca0/FUN_08095d84 (duel_field tags), 传入 card_id (r0) 和 attr_packed (r1).

Constants: base=0x0201b290, slot_count_offset=0x4cc, attr_mask_1ff=0x1FF, attr_mask_803f=0xFFFF803F, entry_size=0x18.

## 参数签名
- r0: u16 card_id [0..0x172f] (游戏总卡数上界; 字段位宽 13-bit 静态上界 0x1fff) - 写入 entry[0..1] (halfword); 由调用方从 gDuelFieldSlots 低 13 位提取 (lsls/lsrs #0x13)
- r1: u16 attr_packed - OAM 属性打包字 [0..0xffff], 高位含 flip/size/shape/palette 字段
- 返回: r0 = void (以 bx r0 结束; 无固定返回值)

## 副作用
- memset 目标结构体 0x18 字节为 0
- strh [r0_target] := card_id halfword
- strb [target+0x2], strb [target+0x3]: OAM attr0/attr1 字节按字段拆包写入
- strh [target+0x4]: attr2 (tile index + palette) 写入
- 若激活成功: 调用 submit_slot_card_sprite_row_entry 提交完整 sprite row
