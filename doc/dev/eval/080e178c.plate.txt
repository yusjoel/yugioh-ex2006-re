Searches expert challenge record table (ROM 0x09e5e80c) for entry matching id (r0).
Loops up to get_expert_challenge_count() (=35) entries; compares ldrh[r5] with r6(id).
On match: returns slot index r4 [0..34].
On no match: rsbs r0,#1,#0 returns -1.
Symmetric sibling of find_puzzle_slot_by_id (0x080e325c), same translation unit.

Constants:
  EXPERT_TABLE_BASE = 0x09e5e80c  (expert challenge record array base)
  ENTRY_STRIDE      = 0xc         (12 bytes per record)
  NOT_FOUND         = -1          (rsbs r0,r0,#0)

Inputs: r0=u16 challenge_id [0..0x22].
Returns: r0=s32 (0..34=found slot index; -1=not found).
Side effects: none (read-only ROM table scan).
