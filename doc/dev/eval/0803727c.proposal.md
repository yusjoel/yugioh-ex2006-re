# Naming Proposal: 0x0803727c

## 提案

- **confidence**: high

## plate comment (中文, ASCII 标点)
从指定玩家的场上卡片数组中移除一个槽位元素, 并通过 swap 向前移位保持紧密排列.
r0 传入 player_id (bit0 取 [0..1]), r1 传入目标槽在数组中的序号. r9 通过 .hword 0x4681 (mov r9,r0) 保存 player_id 供后续 ands 操作使用.
读 gP1LifePoints+player*0x868+0x14 为场上卡数量 (count), 读 gP1LifePoints+player*0x868+0x10 为容量上限.
从数组末尾向前调用 swap_deref_words 逐步将目标槽移到末尾, 然后将 count 减 1.
数组 A 基址 gP1LP+player*0x868+0x260 (0x98<<2), 数组 B 基址 gP1LP+player*0x868+0x418 (0x83<<3).
Constants: player_stride=0x868; field_count_offset=0x14; capacity_offset=0x10; field_array_a_offset=0x98<<2=0x260; field_array_b_offset=0x83<<3=0x418; slot_sort_stride=0x4.

## 参数签名
- r0: u8 player_id [0..1] - 玩家索引, bit0 有效; 由 .hword 0x4681 (mov r9,r0) 保存
- r1: u32 slot_index - 要移除的槽在数组中的位置 (0-based)
- 返回: r0 = void (pop{r0};bx r0 尾返回)

## 副作用
