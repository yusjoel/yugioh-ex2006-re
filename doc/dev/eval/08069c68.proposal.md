## plate comment (中文, ASCII 标点)
```
Function: 验证 spell zone slot 可放置性, 遍历 effect slot 的 zone entries, 对每个有效 equip zone 发出 sprite.
入口 r0=effect_slot_ptr. 从 [r0+0x2] 提取 player_id (bit0),
调用 check_spell_zone_slot_placeable(player_id);
不满足则返回 void.
检查 [r0+0x6] bits[4:2] (zone entry count mask 0x1c); 若为 0 则返回 void.
调用 increment_lp_bar_display_counter.
从 [r0+0x6] 提取 entry_count (bits[7:5]=lsls #0x1b / lsrs #0x1d), 遍历 idx 从 entry_count-1 到 0:
  调用 read_effect_slot_zone_type(slot, idx) 获取 zone_type_word;
  调用 find_zone_descriptor_by_slot_id(zone_type_word) 获取 packed descriptor;
  提取 zone_type (bits[15:8]) 期望==0xe;
  若 zone_type==0xe: 提取 zone_idx (byte0) 和 zone_extra (word1),
    调用 get_zone_slot_ptr(player_id, 0xe, zone_extra),
    从 zone_slot[0] 提取 card_type_flag (bit13),
    计算 polarity = (player_id XOR card_type_flag) ? sign(rsbs) : 0,
    调用 enqueue_equip_zone_sprite_by_slot_ptr(zone_ptr, polarity).
完成后调用 decrement_lp_bar_display_counter.
Side effects: OAM sprite 队列: enqueue_equip_zone_sprite_by_slot_ptr 多次写入;
  LP bar: increment/decrement_lp_bar_display_counter.
Constants:
  ZONE_ENTRY_MASK=0x1c  // [r0+0x6] bits[4:2]
  ZONE_TYPE_EQUIP=0xe  // find_zone_descriptor 期望 type
  ZONE_CARD_TYPE_FLAG_BIT13=0x2000  // zone_slot[0] card type flag
```
