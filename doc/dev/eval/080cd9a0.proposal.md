## plate comment (中文, ASCII 标点)
被卡片显示状态机 (switchD_080c79b4) case 4 调用, r0 为卡片 slot 索引. 初始化卡片图像区域对应的 BG VRAM 和调色板: (1) zero_fill_by_halfword 清空 0x06014000 (0x4000 halfwords); (2) tile_2d_row_copy 从 ROM tile src 0x0988a0f8 到 VRAM 0x06013000, 18 列 x 3 行; (3) copy_bytes_by_halfword 复制 0x20 个 halfword 调色板数据到 OBJ 调色板 0x050002c0; (4) tile_2d_row_copy 副本到 0x06010c00; (5) 按 r0 (slot) 和 gFontState 标志位决定是否写 OAM 调色板 nibble (0xa0e 偏移, mask 0xf00f, 每 slot 对应不同颜色). 副作用: BG VRAM 0x06013000-0x06014000, OBJ palette 0x050002c0, OAM slot nibble.

## 参数签名
- r0: u8 slot_idx - 卡片 slot 索引, 决定调色板 nibble 分组, [0..4]
- 返回: void (无返回值)

## 副作用
- [0x06014000..0x06017FFF]: zero_fill (0x4000 halfwords)
- [0x06013000..+tile_size]: tile_2d_row_copy from ROM 0x0988a0f8 (18col x 3row)
- [0x050002c0..+0x40]: copy_bytes_by_halfword from ROM 0x0988a7b8 (0x20 halfwords = palette)
- [0x06010c00..+tile]: tile_2d_row_copy from ROM 0x0988aaf8
- [0x0201f440+0x0a0e]: 条件写 OAM palette nibble (slot nibble cycle, mask 0xf00f)
- [0x0201f440+0x0a01]: strb 0x4 (完成标志)
