## plate comment (中文, ASCII 标点)
根据装备卡结构中的 card_id 和辅助字段, 返回该卡在当前场地条件下需要支付的 LP 代价值. 函数入口从 [r0+0] 读取 card_id (u16), 从 [r0+2]/[r0+3] 读取 player_side 和 flag_bits. 若 field6==0x16 (连续型装备) 且相关标志位为 0, 调用 count_available_effect_zones 检查效果区余量, 余量为 0 则直接返回 0 (免费). 随后对 card_id 执行大型 BST+直接匹配, 将特定 ID 映射到 LP 代价值 (halfword: 0x01cd, 0x01cc, 0xfa*4, 等); 不在表中的 card_id 返回 0xfa8 (默认代价). 被 FUN_0805aea4 用于计算装备费用并与玩家当前 LP 比较. Constants: equip_type_continuous=0x16, default_cost=0xfa8.

## 参数签名
- r0: ptr equip_card_entry ([+0]=card_id u16, [+2]=player_side_flags, [+3]=flag_bits)
- 返回: r0 = u32 lp_cost (LP 代价值, 0=免费)
