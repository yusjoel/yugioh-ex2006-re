# Naming Proposal: 0x08103524

## 提案
- **proposed_name**: load_card_name_from_fs_by_index
- **confidence**: high

## plate comment (中文, ASCII 标点)
以卡牌索引号 r1 查找 FS 条目 (lookup_card_entry_by_index), 再通过 load_card_fs_entry_to_struct 将文件系统字符串加载到结构体; 随后对 r0 指向的目标缓冲区调用 zero_fill_by_halfword 清零 (大小 0x8c*2=0x118 字节), 然后 strncpy 复制卡名字符串并写入终止符. 最后从 IWRAM [0x02000000+0x6c2c] 读取语言 bit[2:0] 并写入 [r7+0x17]. 由三个 card_ids/card_stats/fs 上下文调用方 (FUN_081021dc, FUN_081026f4, FUN_08103020) 调用, 用于将单张卡的卡名字符串填入卡片信息结构体指定字段.

## 参数签名
- r0: ptr 目标卡片信息结构体基址 (写入名称字段 + [+0x17] 语言标记)
- r1: u16 卡牌索引 (作为 lookup_card_entry_by_index 参数)
- 返回: void (无显式 r0 返回值, 函数以 b LAB_08103594 跳出)

## 副作用
- [r0..r0+0x117]: 目标缓冲区先 zero_fill_by_halfword 清零
- [r7+0]: strncpy 写入卡名字符串 (去除前5字节头, 最多 strlen-9 字节)
- [r7+strlen-9]: 写入 0x00 (null 终止符)
- [r7+0x17]: 写入 IWRAM [0x02000000+0x6c2c] bit[2:0] (语言标记)
