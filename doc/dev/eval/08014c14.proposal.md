## plate comment (中文, ASCII 标点)
将 src 图块数据经 bios_cpu_fast_set 拷贝到 BG0 的字符 (char) VRAM 地址. 调用前以 assert 检查 src 指针 4 字节对齐 (gl_common.c:482), 违规则触发 suppress_assert_report. 对齐通过后: 调 get_bg0_char_vram_addr 获得 BG0 char 基址, 加上 dst_word_offset, 以 bios_cpu_fast_set copy 模式写入 word_count 个字. 与 copy_to_bg1/bg2/bg3_char_tiles 构成四函数 sibling 簇, 对应已命名的 copy_to_bgX_screen_map 簇.

Constants: 0x3 = 4 字节对齐掩码.

## 参数签名
- r0: u32* src -- 图块数据源地址, 必须 4 字节对齐
- r1: u32 dst_word_offset [0..0xFFF] -- 相对 BG0 char VRAM 基址的字 (word) 偏移量, 单位为字而非字节 (BG char 区最大 16KB = 0x4000 字节 = 0x1000 字, 上限为 0xFFF)
- r2: u32 word_count [1..0x1000] -- 拷贝字数 (原始值右移 2 位后传入 bios_cpu_fast_set; VRAM size cap)
- 返回: void (无返回值, 仅副作用)

## 副作用
- [VRAM BG0 char 区域]: bios_cpu_fast_set 将 src 数据写入 get_bg0_char_vram_addr() + dst_word_offset
