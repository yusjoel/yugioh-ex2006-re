SIO deck sync slot advance function. Called by SIO deck sync state machine (FUN_080eda30, tags: [sio,deck_sync]). Receives r0=deck_data_ptr. Computes target write slot address: reads gPrng+0x1c0 (sync_state base ptr) + offset 0xb1*8 (=0x588) write counter, locates current round target slot via (counter*7-counter)*2 + 0xb4*8 (=0x5a0); calls copy_bytes_by_halfword to copy 0xe bytes from r1(=r0 source) to target slot. Increments write counter mod 0x3f (6-bit ring buffer). Calls tick_sio_deck_sync_round to advance one SIO sync round. Returns void (Pattern B: pop{r0};bx r0).
