# Naming Proposal: 0x080f9c88

## 提案

## plate comment (中文, ASCII 标点)
duel_puzzle 场景进入时的轻量封装函数. 依次调用 init_puzzle_wram_and_checksum 完成谜题 WRAM 初始化, 再以固定源 0x02000000 + 长度 0x6ed0 调用 copy_with_waitcnt_and_verify_loop 将谜题数据拷贝到目标区域. 被 enter_duel_puzzle_page / enter_limited_duel_page / enter_theme_duel_page 等多个场景入口调用, 是 duel_puzzle 所有变体共享的 WRAM 预备序列.

## 副作用

- init_puzzle_wram_and_checksum 的所有副作用 (WRAM 零初始化 + 校验和)
