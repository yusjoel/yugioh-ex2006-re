# Naming Proposal: 0x0810d7c4

## 提案
- **proposed_name**: count_active_dma_slot_flags
- **confidence**: high

## plate comment (中文, ASCII 标点)
遍历 IWRAM 频率槽数组 (0x0300546c, 步长 0x1c, 共 12 项, 索引 0..11), 检查每项 [+0xe] 字节的 bit7 (0x80 掩码). bit7 置位则计数加一. 返回 bit7 置位的槽数量. callgraph indeg=0; 由 sound engine 在分配或决策路径中查询当前激活的 DMA 槽数目.

Constants:
- DMA_SLOT_BASE=0x0300546c (IWRAM DMA 条目数组基址)
- SLOT_STRIDE=0x1c (每条目字节跨度)
- SLOT_COUNT=12 (0..11 共 12 个槽)
- ACTIVE_MASK=0x80 (bit7 = 活跃标志)

## 参数签名
- 无 APCS 参数 (r0/r1/r2/r3 均在入口前覆盖)
- 返回: r0 = u32 active_count [0..12] (bit7 置位的槽总数)

## 副作用
- 无外部地址写入 (只读扫描)
