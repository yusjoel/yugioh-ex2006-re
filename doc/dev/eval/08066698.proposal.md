## plate comment (中文, ASCII 标点)
此函数读取 gDuelFieldState+0x4a0 (= 0x94<<3) 的 zone 状态字, 根据其值分三路分发: 状态==0x80 时读取玩家 LP gP1LifePoints+player*0x868+0x10 并在非零时调用 trigger_card_display_op31_if_not_active(player, 0xf5), 返回 0x7f; 状态==0x7f 时调用 init_effect_slot_display_context 初始化显示上下文并返回 0x7e; 状态==0x7e 时调用 enqueue_lp_counter_sprite_by_player 入队 LP 计数器精灵并返回 0; 其他状态返回 0. 由 slot 结构体提供 player_id (r1 [+0x2].bit0). indeg=0.

## 参数签名
- r0: u32 (zone state dispatcher context, unused in body - overwritten by ldr)
- r1: ptr slot_ptr ([+0x2].bit0 = player_id [0..1])
- 返回: r0 = u32 (状态转移值: 0x7f / 0x7e / 0 三种路径)

## 副作用
- 状态 0x80: 调用 trigger_card_display_op31_if_not_active 触发卡牌显示 op31
- 状态 0x7f: 调用 init_effect_slot_display_context 初始化效果 slot 显示上下文; 同路径还可能 enqueue_sprite_attr_record
- 状态 0x7e: 调用 enqueue_lp_counter_sprite_by_player 写 LP 计数器精灵队列
