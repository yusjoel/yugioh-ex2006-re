## plate comment (中文, ASCII 标点)
Neo-Daedalus 效果系列专用显示分发函数. 接收效果槽节点指针 (r4=r0). 读取全局状态码 [0x0201b290+0x94*8] (DWORD_0806b340+0x4a0). 状态 0x7e 时直接返回 0 (已完成). 状态 0x64 时调用 enqueue_lp_counter_sprite_by_player (player=bit0 of [r4+2]), 检查 [gP1LifePoints+0x4a4] 是否非零, 若非零调用 decrement_lp_bar_display_counter, 返回 0. 其余路径: 状态 0x7f/0x80 路径检查 card_id=[r4,#0] 与 0x1339 (比较), 0x1339 路径以 (player_id, r1=(1-player)*0xfa*2, r0=r4) 调用 submit_lp_indicator_with_slot_xor_flag; 0x133a 路径以 (player_id, 0xfa*4) 调用 submit_effect_zone_lp_and_shape_sprites. 再清零 [gP1LifePoints+0x4a4], 调用 count_available_monster_slots; 若为 0 返回 0x64. 调用 check_field_spell_neo_daedalus_group_placeable; 若为 0 返回 0x64. 调用 dispatch_effect_handler_by_card_id; 若为 0 调用 trigger_card_display_op31_if_not_active (op=0xd) 返回 0x64. 若成功检查 display_flag, 若为 1 写入 [gP1LifePoints+0xea*32=0x4a4]:=1 并进入 0x7e 处理; 否则查名称格式化 card_id 0x1339/0x133a 并调用 invoke_card_display_op_0x31_sub1 返回 0x7e. 状态 0x7e path: 调用 setup_equip_oam_entry_with_sprite_attr (two variants for 0x1339/0x133a).
