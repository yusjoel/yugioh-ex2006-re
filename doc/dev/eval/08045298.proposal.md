## plate comment (中文, ASCII 标点)
被 8 个调用方使用 (indeg=8), 含 duel_field 标签. 函数接收 player_id (r0), slot_idx (r1), zone_col (r2), 在 gDuelFieldSlots (0x0201c510) 中定位对应槽位, 读取 card_id (bits[12:0]), 调用 check_card_id_is_equip_set_a 判断是否为装备集合 A 成员. 若是: 根据 zone_col (r2!=0) 分支 -- zone_col==0 时使用 OAM base 0x3b (P1 侧) / 0x803b (P2 侧), 直接调用 enqueue_sprite_attr_record; zone_col!=0 时调用 get_equip_card_set_code_for_slot 获取装备集合码, 若非零再以相同 OAM base 写入精灵. 最终无返回值, 纯副作用写入 sprite 属性缓冲区.
