# Naming Proposal: 0x08040698

## 提案
- **proposed_name**: apply_card_flags_to_zone_bitmap
- **confidence**: high

## plate comment (中文, ASCII 标点)
读取当前状态结构体的卡片标志字段并将其 OR 合并到对应玩家区域的 bitmap 槽.
从 DAT_080406c4 加载状态基址, 读 hword[+0] bit15 -> r2=player_id, hword[+2] -> r4=card_flags,
hword[+4] -> extra_flags. 若 extra_flags == 0 跳过. 否则:
计算 gP1LP + player_id*(1 & bit0) * 0x868 + 0x8e*2=0x11c -> 区域 bitmap 基址,
muls player_offset, 读 [bitmap_base + player_offset] 后 orrs r0,r1 (r1=lsls card_flags),
然后通过 b LAB_080406e8 写回 (str @ 0x080406e8 区域内).
由主状态机 FUN_0803be4c 按帧调用将卡片标志写入场地 bitmap.
Constants: player_stride=0x868; zone_bitmap_base_offset=0x11c (0x8e<<1); card_flags_hword[+2].

## 参数签名
- 无 APCS 输入参数 (r0 在入口被 ldr DAT_080406c4 覆盖; state 从 IWRAM 读)
- 返回: r0 = void (via b LAB_080406e8 -> pop; bx lr 路径)

## 副作用
- [gP1LP+player*0x868+0x11c] |= card_flags (orrs+str 路径 @ LAB_080406e8)
