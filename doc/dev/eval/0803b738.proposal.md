## plate comment (中文, ASCII 标点)
按 zone_type (r1, [0xb..0xf]) 读取指定玩家 (r0=player_side) 的场地特定槽字段并返回其 32 位值. r0=player_side, r1=zone_type; zone_type-0xb 落在 [0..4]: 跳表分派 5 个 case (0xb/0xc/0xd/0xe/0xf), 每 case 计算 gDuelFieldSlots+side*0x868+固定偏移, ldr 返回该字. 偏移分别: 0xc (+0xc)/ 0xd (+0x10) / 0xe (+0x14) / 0xf (+0x1c) / 0xb (+0x18). 若 zone_type 不在 [0xb..0xf]: 走 default -- 计算 gDuelFieldSlots+side*0x868+zone_type*20; 读 [slot,#0] lsls #0x13 / lsrs #0x13 提取 card_id 低 13 位; card_id!=0 -> 返回 1, ==0 -> 返回 0. 被 FUN_080968f4 (本批) 调用, 用于在激活检查中读取特定区域的场地状态字.

## 参数签名
- r0: u32 player_side [0..1] (r3=r0 入口值, 由 adds r3,r0,#0 保存)
- r1: u32 zone_type [0xb..0xf] (特殊 zone) 或 [0..0xa] (普通 slot)
- 返回: r0 = u32 field_word (zone 0xb..0xf: 对应 gDuelFieldSlots 固定字; default: card_id!=0 ? 1 : 0)
