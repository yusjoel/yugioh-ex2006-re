## plate comment (中文, ASCII 标点)
duel field 场地 VRAM 完整初始化 hub, 被 play_demo_shuen / play_ui_effect_3b/3a / FUN_0801fec0 等 8 个调用方共享. 依次执行: (1) zero_fill_by_halfword 清空 VRAM OBJ tile 区 (0xc0*0x13 = 0x600*4 halfword); (2) store_ewram_ctx_ptr_and_clear_mode_flags 建立 EWRAM 状态; (3) reset_display_and_obj_vram 重置显示/OBJ; (4) apply_blend_fadeout_flat; (5) reset_all_bg_scroll_regs_and_shadows; (6) 设置 gPrng[0xba*2] = 1; (7) 配置 BG0CNT/BG1CNT/BG2CNT/BG3CNT 四个寄存器 (tile/screen 地址+大小); (8) 复制多组背景 tile/screen 数据; (9) 调用 init_duel_field_lp_aob_ctx 初始化 LP 动画; (10) 根据 EWRAM flag bit4 选择性复制额外 tile; (11) 写 VRAM palette tile 行; (12) 调用 init_duel_field_tile_indices / redraw_all_field_slot_tiles; (13) 设置 DISPCNT [r5+0x0] (开 BG 显示).

Constants:
- ZERO_FILL_TARGET = 0x0600 0000 + (0xc0 << 0x13 = wrong), actually r0=0xc0<<0x13=0x06000000 -- VRAM base
- ZERO_FILL_SIZE = 0xc0<<0x9 = 0x6000 halfword (OBJ VRAM clear)
- EWRAM_CTX_PTR = 0x02029eb0 (EWRAM 上下文基址)
- DISP_BASE = 0x0203eeb0 (display base)
- BG0CNT_VAL = 0x1f08 (BG0 char base=1, screen base=30, 256col, 32x32)
- BG1CNT_VAL = 0x1f08-0xff = 0x1e09 (BG1 配置)
- BG2CNT_VAL = 0x1e09-0x87 = 0x1d82 (BG2 配置)
- BG3CNT_VAL = 0x1c0b (BG3 配置)
- gPrng_SLOT = gPrng + 0xba*2 = gPrng + 0x174 (prng 状态槽)
- PTR_hud_gap_tiles = hud_gap_tiles (HUD 间隔 tile)
- DISPCNT_MASK = 0xf8<<5 = 0x1f00 (BG enable bits)
