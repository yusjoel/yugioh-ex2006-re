# Naming Proposal: 0x08047f50

## 提案
- **proposed_name**: render_slot_card_sprite_from_descriptor
- **confidence**: med

## plate comment (中文, ASCII 标点)
以打包的槽描述符 word (r1) 驱动卡牌 sprite 完整渲染流水线. r0=slot_entry_ptr -> r6; r1=slot_descriptor (含 player_bit bits[9] / type_field bits[13:10] / player_id bits[12] 等). 解包各字段后检查 r2 (flags?) 和 type [0..4] 有效性; 构造 OAM attr word r4 (多字段 OR/AND mask 操作); 调用 enqueue_sprite_attr_record 提交主 sprite; 若有装备卡则 scan_field_slots_for_equip_sprite; check_card_field5_is_nonzero 后 scan_field_slots_for_attached_sprite_by_id; dispatch_card_effect_sprite_render_by_card_id; submit_lp_bar_sprite_row_by_type(0x16/0x1b); count_field_copies_of_card; dispatch_card_effect_zone_action_by_card_id. 与 render_slot_card_sprite_and_effects (0x08048020) 构成 sibling, 本函数接收打包描述符, 后者接收 player_id 分离参数.

Side effects:
- OAM sprite 属性缓冲区: enqueue_sprite_attr_record 写入主 sprite
- LP 条: submit_lp_bar_sprite_row_by_type(type=0x16 or 0x1b) 写入
- 区域效果: dispatch_card_effect_zone_action_by_card_id

Constants: TYPE_MAX=4, PLAYER_BIT_SHIFT=0x16 (to extract bit[9]), TYPE_FIELD_SHIFT=0x12/0x1c, gDuelFieldSlots=0x0201bc54.

## 参数签名
- r0: ptr slot_entry -- 卡槽结构体指针 -> r6
- r1: u32 slot_descriptor -- 打包槽描述符 (bit[9]=player_bit, bits[13:10]=type_field [0..4]) -> sp[0x0]
- (r2: 非参数 -- 函数入口 08047f6e lsrs r2,r0,#0x13 在任何条件分支前覆盖 r2; caller 0x0809a932 callsite 未显式设置 r2; r2 由内部 [r6+0x0] 解引用计算, 入参值被丢弃)
- 返回: r0 = u32 1 (已渲染) / 0 (type>4 或无卡跳过)

## 副作用
- OAM 缓冲区: enqueue_sprite_attr_record 主 sprite + 装备/附着 sprite (条件)
- LP 条缓冲区: submit_lp_bar_sprite_row_by_type
- 区域效果: dispatch_card_effect_zone_action_by_card_id
