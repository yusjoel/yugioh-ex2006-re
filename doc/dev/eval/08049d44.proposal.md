# Naming Proposal: 0x08049d44

## 提案
- **proposed_name**: enqueue_pair_zone_sprite_attr_by_card_id
- **confidence**: med

## plate comment (中文, ASCII 标点)
Function: 遍历当前玩家侧 (由 r8=r0=player_side) 的装备对卡槽列表 (基址 gP1LifePoints
+0x1ce8*player_side+0x10, stride=0x868), 对每个槽调用 check_card_pair_allowed(card_id,
slot_cid); 若通过则提取 pair_code (bits[21:14]x2 + bit14) 组合成 sprite 参数, 调用
enqueue_sprite_attr_for_zone_slot_packed. 场景: 由 FUN_0806d960 在装备对卡触发时调用.
副作用为向 sprite attr queue 追加若干记录.

Constants:
- gP1LifePoints = 0x0201c4e0 (via DWORD_08049dc4)
- PLAYER_STRIDE = 0x868 = gDuelFieldSlots 每玩家跨度
- PAIR_SLOT_COUNT_OFFSET = 0x10
- SPRITE_ATTR_TYPE_REC = 0xd (enqueue_sprite_attr_for_zone_slot_packed arg)

## 参数签名
- r0: u32 player_side [0..1] -- via .hword 0x4680 (mov r8,r0) at entry; r6 = sp[0x10] = r2 original
- r1: u16 card_id [0..0x172f] -- 低 16 位 (lsls/lsrs #0x10 at 0x08049d54); target card to match
- r2: u32 target_slot_idx [0..4] -- 由 caller FUN_0806d960 @ 0x0806da12 经 find_first_available_monster_slot_for_player 返回值赋入; 目标 monster zone slot 索引, 传入 enqueue_sprite_attr_for_zone_slot_packed
- 返回: u32 bool (1=found and enqueued, 0=not found); movs r0,#0x1 @ 0x08049dc0 / movs r0,#0x0 @ 0x08049dd8

## 副作用
- 全局 sprite attr queue: 条件性追加若干 type-packed 记录 (enqueue_sprite_attr_for_zone_slot_packed)
