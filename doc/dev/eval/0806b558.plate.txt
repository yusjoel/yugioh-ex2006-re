Effect node handler. Reads card_id from effect_node [r0+0], calls enqueue_sprite_attr_type11 with player=0, type=1, flag=0 to enqueue a zone sprite for that card. Shortest variant in the sibling cluster (3 effective instructions).

Constants: TYPE=0x1 (type11 sprite type param).

Inputs: r0=ptr effect_node ([+0]=card_id u16, [+2]=flags u8, [+4]=guard_bits u8).
Returns: r0=0 (void semantic, fixed return 0).
Side effects: writes sprite queue (via enqueue_sprite_attr_type11).
