Initializes pack slot structs within pack_ui_state.
No static bl callers (indeg=0); invoked via function pointer.
Single outer pass (r6 from 0 increments to 1 then exits): clears 4 fields (str r7/strh r7 x3),
then 8 inner iterations accumulate bit fields (ldrh+lsls+adds+str),
finally writes initial values: [r1+0x20]:=1 (enable flag), [r1+4]:=0xa (initial count 10).

Constants:
- pack_ui_state = 0x03005850
- SLOT_ENABLE_FIELD = 0x20 (slot enable flag field offset, strh 1)
- SLOT_COUNT_FIELD = 0x4 (slot initial count field offset, strh 0xa=10)
- INNER_LOOP = 8 (sub-field zero passes per slot)
