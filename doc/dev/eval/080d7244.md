## 修改清单

### #1 — R6 (优先级: 高)
**位置**: proposal Constants 块, COLOR_ATTR 行
**问题**: `COLOR_ATTR = 0xb0c00000 (movs r4,#0xb0; lsls r4,#0xc -> 0xb0000)` 自相矛盾: 声明值 0xb0c00000 但推导结果 0xb0 << 12 = 0x000b0000; python 验证: `0xb0 << 0xc = 0xb0000` (不等于 0xb0c00000)
**当前**: `COLOR_ATTR = 0xb0c00000 (movs r4,#0xb0; lsls r4,#0xc -> 0xb0000)`
**应改为**: 追踪 asm 080d7256 处的实际指令序列, 确认 lsls 的移位量; python 验证推导值; 若 lsls #0xc 则值为 0x000b0000, 应改为 `COLOR_ATTR = 0x000b0000 (movs r4,#0xb0; lsls r4,r4,#0xc -> 0xb0 << 12 = 0xb0000)`
