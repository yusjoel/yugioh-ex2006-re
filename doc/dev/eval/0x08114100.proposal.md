# Naming Proposal: 0x08114100

## 提案
- **proposed_name**: compare_float_gt
- **confidence**: high

## plate comment (中文, ASCII 标点)
GCC libgcc 单精度浮点大于比较函数 (__gtsf2): 解包两个 float (r0, r1) 后检测 NaN, NaN 路径执行 rsbs r0,r0,#0 -> 返回 -1 (无序, 不满足 >), 正常路径调用 __fpcmp_parts_f.
GCC __gtsf2 约定: 正数 = A>B, 零或负数 = A<=B 或含 NaN. 调用方通常使用 "bl compare_float_gt; cmp r0,#0; ble not_greater" 模式.
该函数在静态调用图中 indeg=0 (未被任何函数直接调用), 无函数指针引用, 属于编译器生成的未使用符号 (dead code).
与 compare_double_gt (0x08113750) 结构完全对称, NaN 返回 -1 (rsbs) 是 gt/ge 与 eq/ne/lt/le 的关键区分点.

## 参数签名
- r0: f32 a -- 单精度浮点 A (IEEE 754 bit-pattern)
- r1: f32 b -- 单精度浮点 B (IEEE 754 bit-pattern)
- 返回: r0 = s32; 正数 = A>B, 零或负数 = A<=B 或含 NaN

## 副作用
