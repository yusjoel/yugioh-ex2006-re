## plate comment (中文, ASCII 标点)
当需要根据装备卡的 card_id 计算并写入 LP 增减量到输出缓冲区时调用. 函数接受卡槽指针 r0 和输出地址 r1 (r7), 先将 [r7+0] 和 [r7+4] 清零, 然后以大型 switch 分支按 card_id 路由到对应的 LP 增减计算子函数: 包括 write_equip_lp_delta_scaled_by_lp_count (0x161d, Des Koala), write_equip_lp_delta_by_opponent_side (0x13a8, Woodland Sprite), write_equip_lp_delta_by_own_side (0x118a, Ameba), write_equip_lp_delta_by_alt_player, write_equip_lp_delta_negated_atk, write_equip_lp_delta_minar (0x11bc, Minar), write_equip_lp_delta_dark_rabbit 以及数十个其他具名装备卡效果. 末端通过 restore_equip_effect_frame 清理栈帧. 固定返回 0 via pop {r3}; bx r3 (Sub-case E).

Constants:
- CARD_ID_DES_KOALA=0x161d (Des Koala; scaled LP count path)
- CARD_ID_WOODLAND_SPRITE=0x13a8 (Woodland Sprite; opponent side path)
- CARD_ID_AMEBA=0x118a (Ameba; own side path)
- CARD_ID_MINAR=0x11bc (Minar)
- player_stride=0x868
- gDuelFieldSlots=0x0201c510
- gDuelFieldState=0x0201c5d8

## 参数签名
- r0: u32* slot_ptr (装备卡槽指针; byte[+2] bit0=player_id, byte[+3] bit25=facing, halfword[+0]=card_id, halfword[+8]=ATK)
- r1: u32* lp_output_ptr (LP 增减量输出地址; [+0]=player0_delta, [+4]=player1_delta)
- 返回: r0 = u32 0 (固定; pop {r3}; bx r3 退出机制使 r0 为 caller 设置值, 函数自身不写 r0)
