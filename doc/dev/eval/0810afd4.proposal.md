## plate comment (中文, ASCII 标点)
声道 3 波形表写入函数. 从 ROM 波形数据表中按乐器索引和模式槽号取一条 16 字节条目,写入 GBA WAVE_RAM (0x04000090),然后切换 SOUND3CNT_L (0x04000070) 所选 bank 并重新使能声道 3. 实现双缓冲: 先向未播放的 bank 写数据,再通过 SOUND3CNT_L 切换到该 bank 播放. 若 wave_slot==0 则走静音路径, 向 WAVE_RAM 写全零. r1 bit7=1 时使用备用乐器表 (0x081143a0) 并将低 7 位作为乐器索引; bit7=0 时使用主表 (0x084be710). 三个调用方均在声道 3 播放前调用, 角色为波形切换.

Constants:
- WAVE_RAM (0x04000090) = 声道 3 波形 RAM, 16 字节/bank (GBA 双 bank)
- SOUND3CNT_L (0x04000070) = NR30: bit7=ch3 使能, bit6=选 bank
- 0x084be710 = 主乐器波形数据表 (每乐器 16 个模式 x 16 字节 = 256 字节)
- 0x081143a0 = 备用乐器波形数据表 (相同结构)
- 偏移公式: (instr_idx * 16 + wave_slot) * 16 字节
- 0x200 = [snd_ctx+0x364] bit9 = 当前播放 bank 跟踪位
- 0x80 = SOUND3CNT_L: ch3 使能 + bank0; 0xC0 = ch3 使能 + bank1

## 参数签名
- r0: u32* snd_ctx  声道 3 状态结构体指针 (内部 IWRAM 声音上下文; [+0x364] 存 bank 跟踪位)
- r1: u8 instr_idx  乐器/音色索引 [0..255]; bit7=1 选备用表, bits[6:0]=[0..127] 为实际索引
- r2: u8 wave_slot  波形模式槽号 [0..15]; 0=静音 (全零写入 WAVE_RAM)
- 返回: void (pop{r4}; pop{r0}; bx r0 -- Sub-case E, r0 无语义)

## 副作用
- [WAVE_RAM+0x0..+0xf] := 16 字节波形数据 (来自 ROM 表偏移, 或全零静音路径)
- [snd_ctx+0x364] halfword: bit9 取反 (切换 bank 跟踪状态)
- SOUND3CNT_L (0x04000070): strh (0x80 或 0xC0), 使能 ch3 并选新 bank
