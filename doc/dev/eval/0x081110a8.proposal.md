# Naming Proposal: 0x081110a8

## 提案
- **proposed_name**: invoke_cleanup_r
- **confidence**: high

## plate comment (中文, ASCII 标点)
newlib stdio atexit 清理入口: 自动绑定全局重入指针后调用 _cleanup_r, 冲洗并关闭所有打开的 stdio FILE 缓冲区.
触发场景: 进程退出时由 exit() 通过 atexit 机制回调; 在 __sinit (0x081110b8) 初始化 stdio 时以函数指针形式注册.
副作用: 透传至 _cleanup_r -> 冲洗所有 __sFILE 写缓冲, 关闭非标准流.

Constants:
- IMPURE_PTR=0x09ed4d94 (_impure_ptr, newlib 全局重入结构指针)

## 参数签名
- r0: 无输入 (入口立即被 ldr r0,DAT_081110b4 覆盖)
- 返回: r0 = void (透传 _cleanup_r 的返回值, 通常忽略)

## 副作用
- 透传至 _cleanup_r: 冲洗/关闭所有 stdio 缓冲区 (间接副作用)

## 行级注释 (<=30 行精华)
- @ 081110aa: 加载 _impure_ptr 地址常量 (0x09ed4d94)
- @ 081110ac: 解引用取 struct _reent* 实际指针
- @ 081110ae: 调用 _cleanup_r 执行 stdio 清理
