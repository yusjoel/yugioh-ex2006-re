# Naming Proposal: 0x080ee988

## 提案
- **proposed_name**: resolve_card_gfx_pointer_by_type
- **confidence**: med

## plate comment (中文, ASCII 标点)
按卡片 ID 查卡片属性表 (card_stats_table), 先读 [0x080000ae] 判断区域码是否为 0x4a (日版特判),
再用属性字段 (offsets 0x16*id+0x0) 与多个边界值 (0x1497/0x1498/0x1499) 做多路分支,
结合 IWRAM [0x02000000+0x6c2c] 中的 byte&0x7  作为阵营/属性子类索引,
最终返回图形数据指针 (ROM 段内地址, 供调用方写入 sprite 参数). 该函数是卡面辅助图形
(怪兽属性图标/魔陷/效果等) 的路由核心, 每次绘制卡片信息页时被调用.

## 参数签名
- r0: u16 card_index (卡片索引, 0-based, 经 0x16 步长乘法访问 card_stats_table)
- 返回: r0 = const void* 指向对应属性/类型图形数据的 ROM 地址; 匹配失败时返回 fallback 指针

## 副作用
(无外部写操作, 纯查表返回指针)

## 行级注释 (<=30 行精华)
- @ 080ee988: 暂存 card_index 至 r2, 准备多路查表分支
- @ 080ee98a: 读 [0x080000ae] 区域标识寄存器
- @ 080ee98e: 右移 8 bit 取上位字节 = 区域码
- @ 080ee990: 与 0x4a ('J') 比较 -- 日版 ROM 走特殊分支
- @ 080ee996: 用 0x16 步长乘法在 card_stats_table 中定位当前卡行
- @ 080ee99e: 取属性字段 (偏移 0 处 halfword)
- @ 080ee9a2: 与魔法牌上限 0x1498 比较 -- 区分怪兽/魔法/陷阱大类
- @ 080ee9d4: 属性值 == 0x1497: 再读 IWRAM[0x02006c2c]&0x7 做阵营细分
- @ 080eea30: 属性值 == 0x1498: 另一阵营细分路径
- @ 080eea8c: 属性值 == 0x1499: 第三阵营细分路径
- @ 080eeae4: 属性值 == 0x149a (+1): 第四阵营细分路径
- @ 080eeb3c: fallback 路径 -- 按 card_index*4 查指针表后加偏移
- @ 080eeb48: 所有分支汇聚于此, bx lr 返回 r0 = 图形指针
