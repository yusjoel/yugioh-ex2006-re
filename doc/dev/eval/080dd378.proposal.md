# Naming Proposal: 0x080dd378

## 提案
- **proposed_name**: copy_overlay_tile_row_to_palette
- **confidence**: med

## plate comment (中文, ASCII 标点)
将遮罩 overlay 的 tile 行数据复制到目标地址, 并追加调色板数据.
r0 = 目标 VRAM 地址, r1 = tile_row_index;
从 tile 行索引乘 4 得偏移, 查 0x09cede60 ROM 表取源 tile 行指针,
调 copy_bytes_by_halfword 复制 0x20 字节 tile 数据;
再从 0x09ccd292 追加 0x10 字节调色板/属性数据.
由 text_overlay_create 和 FUN_080dd3a8 等多个 overlay 显示函数调用.

Constants:
- 0x09cede60: overlay tile row pointer 表 (ROM), 每条目 4 字节 ptr
- 0x09ccd292: overlay 调色板/属性数据 (ROM)
- 0x20: tile 行数据大小 (32 bytes = 16x16 4bpp 一行)
- 0x10: 调色板/属性块大小 (16 bytes)

## 参数签名
- r0: void* dst_vram_ptr 目标 VRAM 地址
- r1: u16 tile_row_index tile 行索引 [0..N-1] (N 由表大小决定, 静态不可见)
- 返回: void (pop {r0}; bx r0 透传 lr)

## 副作用
- [dst_vram_ptr..+0x20]: := tile 行数据 (copy_bytes_by_halfword 写)
- [dst_vram_ptr+0x2..+0x12]: := 调色板/属性数据 (copy_memory_dma3_with_cpu_fallback 写 0x10 字节)

## 行级注释 (<=30 行精华)
- @ 080dd378: push {r4,lr}; r4=dst (adds r4,r0,#0)
- @ 080dd37c: lsls r1,r1,#0x10 + lsrs r1,r1,#0xe = tile_row_index * 4 (word 偏移)
- @ 080dd37e: DAT_080dd3a0 = 0x09cede60 (tile row ptr table)
- @ 080dd380: r1 = tile_row_table + row_index*4
- @ 080dd384: ldr r1,[r1] = tile row 源指针
- @ 080dd38a: copy_bytes_by_halfword(dst=r4, src=r1, size=0x20)
- @ 080dd38e: r4 += 2 (写完 tile 后目标地址 +2)
- @ 080dd390: DAT_080dd3a4 = 0x09ccd292 (palette source)
- @ 080dd396: copy_memory_dma3_with_cpu_fallback(dst=r4+2, src=0x09ccd292, size=0x10)
