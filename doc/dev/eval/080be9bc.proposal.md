## plate comment (中文, ASCII 标点)

## 参数签名
- r0: u8 mode_id -- AOB 精灵模式选择器, {0, 5, 7, 8}; 其他值 -> 返回 0
- r1: u16 aob_anm_entry_idx -- 传入 init_aob_ctx_with_anm_entry 的动画条目索引 [0..255]
- 返回: r0 = u32 status (0=mode 无效跳过, 1=成功加载)

## 副作用

- [0x0201fedc+0x13] |= 0x11 (可见 + mode flag)
- [0x0201fedc+0xe] := 0x2 (动画播放模式)
