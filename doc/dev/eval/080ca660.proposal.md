## plate comment (中文, ASCII 标点)
将压缩的卡牌图像 tile 数据从 ROM 解码并写入 VRAM. r0=card_id(或 -1 表示空白), r1=slot_index,
r2=flip_flag. 若 r0==-1 且 r1==-1 则加载空白图像 ROM 地址 0x0985117c. 主路径通过 __modsi3
和 __divsi3 迭代提取 4 位像素对, 重新打包为 GBA 4bpp tile 格式, 写入 EWRAM 中间缓冲区
0x020232c0, 然后再分批写入 VRAM 0x06008120(正面) 或 0x060081a0(背面). 以 card_id 选取 3
组不同的 ROM tile 源表 (0x0985117c/0x0985131c/0x0985145c). 唯一 caller 为 FUN_080cb1cc
(large card image display pipeline). Constants: VRAM_front=0x06008120, VRAM_back=0x060081a0,
EWRAM_buf=0x020232c0, max_card_id=0x0001869f.

## 参数签名
- r0: s32 card_id - 卡牌 ID [-1=blank..0x0001869f]; -1 触发空白图像路径
- r1: s32 slot_index - 显示槽位索引 [-1=blank path, 0..max]; 影响 VRAM 写入目标
- r2: u8 flip_flag - 0=正面 VRAM, 非0=背面 VRAM [0..1]
- 返回: r0 = void (无显式返回值; 副作用写 VRAM)

## 副作用
- [VRAM 0x06008120 or 0x060081a0]: 写入解码后 4bpp tile 数据 (0x80 halfword 清零后重写)
- [EWRAM 0x020232c0]: 临时中间缓冲区 (tile 组装)
