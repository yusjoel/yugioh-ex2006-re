提取 bits[8:1] (lsls #0x17 / lsrs #0x18 = byte[1]) 作为 current_rank [0..3+]:
- rank==0: 检查 gDuelCtx[0x93*8]=[+0x498] 标志; 若为 0 则写 halfword[0x14] 置 bit[1]=2
  (rank=1 状态), 然后进 rank==1 分支;
- rank==1: 检查 gDuelCtx[+0x48c] (via DAT_0804f3b4=0x48c); 若非零查 gDuelCtx[+0x488]
  (即 [+0x48c-4]); 若 +0x488!=0 则调用 compact_equip_zone_rank3_entries() 并返回 1;
  否则递增 halfword[0x14] rank 字段 (+1), 进 rank==2;
- rank==2: 检查 gDuelCtx[+0x48c] 是否有 sprite row anim; 若有 bl dispatch_sprite_row_anim_by_state;
  否则递增 rank 进 rank==3;
- rank==3: 检查 gDuelCtx[+0x498] (0x93*8); 若非零 bl dispatch_sprite_row_queue_by_state;
  否则递增 rank.
返回 0 (初始/默认) 或 1 (compact 完成). 由 indeg=0 状态机驱动.
