## plate comment (中文, ASCII 标点)
向 EWRAM 中的 tile 属性缓冲区写入调色板索引. 由 duel_field 相关的多个函数调用 (indeg=5).
r0 为 tile 槽位序号 [0..255]; 超出 255 的值直接返回不写入.
r1 为调色板索引 (写入 halfword 高字节: bits[15:8]).
目标地址: [0x0201e4f0 + 0x410 + 2*r0], 即 EWRAM tile 属性表第 r0 项 (halfword).
操作: 读原 halfword -> 保留 bits[4:0] (tile 序号低 5 位) -> 设 bits[15:8] = r1 -> 写回.
此函数在决斗场景初始化/更新中为每个 tile slot 设置调色板, 不影响 tile 索引低位.
Constants: BUF_BASE=0x0201e4f0; TILE_ATTR_OFFSET=0x410; TILE_IDX_MASK=0x1f; PAL_SHIFT=8.

## 参数签名
- r0: uint32 tile_slot [0..255] (tile 属性表槽位序号; >255 直接返回)

- 返回: r0 = (void) 无返回值语义; bx lr 无 r0 修改路径 (函数无返回值, 仅副作用)

## 副作用
- [0x0201e4f0+0x410+2*tile_slot]: halfword bits[15:8] := palette_index, bits[4:0] 保持不变
