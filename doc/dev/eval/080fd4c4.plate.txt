title_ex scene OBJ graphics resource full initialization function.
Calls fs_load(r0=?, r1=0) to load file system resource, saves return pointer to r7.
Calls zero_struct_36bytes twice (each clears 0x24 byte struct) using sp buffer as target,
fills OBJ tile attribute fields each time, then calls apply_gfx_resource_list to submit resource list.
First pass: tile attr bits[7:0]=0x03 (dual-color mode), bit7 cleared (non-mosaic), palette mask 0xffffc07f, slot 0.
Second pass: additionally sets bit7=1 (Horizontal-flip), size field 0xa0<<4=0xa00 written to attr1 high bits,
           color depth flag 0xe0<<9=0x1c000, then writes OBJ palette register high halfword.
Exit: pop{r3,r4,r5}; .hword 0x4698/0x46a1/0x46aa (mov r8,r3; mov r9,r4; mov r10,r5); pop{r4,r5,r6,r7}; pop{r0}; bx r0 (Pattern B void).
Constants:
  TITLE_EX_CTX = 0x02029eb0
  OBJ_ATTR_MODE_MASK = 0x03 (attr0 bits[1:0] OBJ mode)
  HFLIP_BIT = 0x80 (attr1 bit7 = horizontal flip)
  OBJ_PAL_DEST = 0x05000000 (OBJ palette base via 0xa0<<0x13)
  ATTR1_SIZE_FIELD = 0xa0<<4 = 0xa00 (attr1 size field encoding)
  COLOR_DEPTH_FLAG = 0xe0<<9 = 0x1c000
