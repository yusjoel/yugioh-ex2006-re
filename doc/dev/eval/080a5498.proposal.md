## plate comment (中文, ASCII 标点)
检查玩家 r0 的基础槽 r1 加偏移 r2 (合并 slot_idx=r1+r2<=4) 上的装备卡能否激活配对. 先验证合并槽 <=4, 再读 [0x0201e4d0] byte bit0 确认当前激活方; 槽上卡的 lsls #0x13 active 检测 (gDuelFieldSlots+0x868*side+slot*20); 若 [0x0201e4d0+8] count>0, 在 count 个禁止对列中查找 (player,slot) 组合 -- 命中则返回 0; 否则走 check_slot_card_can_be_equipped -> count_available_monster_slots -> check_slot_placement_blocked_by_field_effect 综合决策; 最后以 check_equip_slot_pair_can_activate_full 自身做集合码分派, 按装备集 (set_code 0x112e/0x128c/0x1758/0x176c/0x17c6/0x18b9/0x18b8/0x18c0/0x1894/0x19a3/0x19a4/0x19a5/0x19f0/0x19f6/0x19f7/0x19f8) 调用 check_card_pair_allowed/count_slot_chain_copies_of_card/eval_equip_chain_score_for_slot 等; 通过则返回 0x800, 不通过返回 0. 被 FUN_080a3b74 (本批, 装备扫描主循环) 及 FUN_080a5714 (本批) 调用.

## 参数签名
- r0: u32 player_side [0..1]
- r1: u32 base_slot_idx [0..4]
- r2: u32 slot_offset [0..4]; r4 = r1+r2, 合并后必须 <=4
- 返回: r0 = u32 (0x800=可激活, 0=不可激活)
