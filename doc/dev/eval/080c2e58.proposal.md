## plate comment (中文, ASCII 标点)
计算整数 r1 的十进制位数, 并按位数分配 OAM 坐标后调用 write_digit_oam_column_with_scroll (FUN_080c2ddc) 渲染数字. 由 FUN_080c2eac 在卡片数字显示流程中调用. 函数先将 r1 反复整除 10 计数 (r4 = digit_count [1..N]), 再按 r5 (符号/修饰) * 100 + r4 * 3 + r4 * 2 * 100 + 0x52 计算 OAM X 基值; 最后传入 r2=scroll_flag, r3=符号修正值调用 FUN_080c2ddc.

Constants:
- 0xa = 除数 (十进制)
- 0x64 = 100 (坐标计算)
- 0x52 = 82 (OAM x base offset)
- 0x2 = OAM tile 属性大小 (halfword)

## 参数签名
- r0: u16 oam_packed_y -- OAM Y/mode packed 坐标 (入口 adds r5,r0,#0)
- r1: u32 number -- 要显示的十进制数 [1..max_lp] (计算位数用)
- r2: u8 scroll_flag -- 传递给 FUN_080c2ddc (gPrng jitter 开关)
- 返回: void (无返回值)

## 副作用
- OAM 缓冲区: 经 FUN_080c2ddc -> write_oam_entry_from_packed_args 写入 digit_count 个 OAM 条目
