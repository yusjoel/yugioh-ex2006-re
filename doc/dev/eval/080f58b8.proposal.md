## plate comment (中文, ASCII 标点)
blend+frame_counter 工具族的"递减"变体 (indeg=17). 从 gFrameCounter byte (gPrng+0x200 = 0x03000240) 提取 bits[5:0] (当前 blend_step, 0..63), 减去入参 r0 (delta). 若结果 > 0 则将新 blend_step 写回 gFrameCounter 并将 BLDY (0x04000054) 设为新值; 若 blend_step 递减至 <= 0 则调用 disable_blend_and_clear_step 彻底关闭混合, 返回 1. 返回 0 表示混合仍在进行.

## 参数签名
- r0: u8 delta    (本帧递减步数, 通常为 4; 调用方 FUN_0801e328 传入 0x4)
- 返回: r0 = u8 blend_done  (1=混合已完成并清除, 0=混合仍进行中)

## 副作用
- [gFrameCounter byte (0x03000240)]: bits[5:0] -= delta (blend_step 递减, 夹紧到 0)
- [BLDY (0x04000054)]: := new_blend_step  (写入新亮度系数; 为 0 时由 disable_blend_and_clear_step 清除 BLDCNT)
