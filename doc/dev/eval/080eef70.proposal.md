# Naming Proposal: 0x080eef70

## 提案
- **proposed_name**: get_card_extended_stat_field4_raw
- **confidence**: high

## plate comment (中文, ASCII 标点)
从 ROM 扩展卡片属性表 (0x09821e04, 11 halfword/行) 读取字段 4 (列索引 4) 的 u16 值. card_id <= 0x0fa6 时返回 0. 否则: row=card_id-0xfa7; offset=(row*11+4)*2; 读取 u16. 与 lookup_rom_card_attribute_table_a (0x080eef0c, 同为列 4 但附 0xffff 哨兵过滤) 为对称兄弟: 本函数不做哨兵检查, 直接返回原始值. 被 0x080878c8 (卡片属性测试场景) 在 check_card_field5_is_nonzero 之后调用, 对返回值做上界比较.

Constants:
- TABLE_BASE=0x09821e04 // ROM 扩展卡片属性表基址
- NORMAL_CARD_BOUND=0x0fa6 // 普通卡 id 上界
- ROW_STRIDE=11 // halfword/行

## 参数签名

- 返回: r0 = u16 extended_stat_field4_raw (无哨兵过滤; card_id <= 0x0fa6 时为 0)
