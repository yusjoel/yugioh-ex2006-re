## plate comment (中文, ASCII 标点)
indeg=0, 无调用方; 由函数指针表在场景帧调度时跳入. 从 gPrng+0x204 (= gPrng + 0x81*4) 读取当前场景步骤索引 (bits[17:10], 8 位), 乘以 4 查步骤函数表 (基址 0x09e589a4 = ROM 步骤表 A), 取得步骤函数指针并经 invoke_r0 调用. 若步骤函数返回非零 (步骤完成), 将 gPrng+0x204 中 bits[21:14] 的步骤索引字段加 1 (mod 256), 写回; 若返回零 (步骤未完成), 调 return_void_handler 并返回 r0=0. 步骤表为空时跳至 LAB_0801c2a4 直接返回 r0=1. 退出路径: pop {r4}; pop {r1}; bx r1 (Sub-case E, r0 非 pop 寄存器).

Constants:
- STEP_TABLE_BASE_A = 0x09e589a4 (ROM 步骤表 A 基址)
- gPrng = 0x03000040 (全局状态基址)
- STEP_IDX_FIELD_OFFSET = 0x204 (gPrng+0x81*4)
- STEP_IDX_BITS = [21:14] (lsls r0,#0xa; lsrs r0,#0x18 -> 净右移 14 位, 提取 8 位步骤索引; python: (val<<0xa)>>0x18 等价于 val>>0xe & 0xff)
- STEP_ADVANCE_MASK = 0xffc03fff (步骤字段清零掩码)

## 参数签名
- r0: (入口 ldr 覆盖 r0) 无输入参数, void
- 返回: r0 = u32 done_flag (1=步骤表空/完成, 0=当前步骤未完成)

## 副作用
- [gPrng+0x204] := 步骤索引字段 +1 (mod 256) 写回, 当步骤函数返回非零时

## 行级注释 (<=30 行精华)
- @ 0801c256: 加载 ROM 步骤表 A 基址 0x09e589a4 -> r1
- @ 0801c258: 加载 gPrng 基址 -> r0

- @ 0801c262: lsls r0,#0xa; lsrs r0,#0x18 => 提取 bits[21:14] = 8 位步骤索引 (净右移 14 位)
- @ 0801c266: 步骤索引*4 + 步骤表基址 => 步骤函数指针地址
- @ 0801c26c: 步骤函数指针为 0 => 步骤表空, 跳 LAB_0801c2a4 (返回 1)
- @ 0801c270: invoke_r0 => 调用当前步骤函数
- @ 0801c274: 步骤返回 0 => 未完成, 跳 LAB_0801c28e

- @ 0801c28e: return_void_handler => 清理后返回 r0=0
- @ 0801c2a4: 返回 r0=1 (步骤表空或完成)
- @ 0801c2a8: pop {r1}; bx r1 (Sub-case E, r0 为函数返回值, r1 为 lr)
