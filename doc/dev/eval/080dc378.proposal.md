## plate comment (中文, ASCII 标点)
将卡牌 tile 行数据从 ROM 复制到包店 OBJ VRAM 指定槽位, 并视需要复制调色板. 触发条件: 包店初始化场景中(callers pack_banner_080d566c, pack_banner_080d6d30, pack_list_page_init)在加载卡图 tile 时调用. r0=card_slot_index (0..N, 用于计算 VRAM 偏移 r0<<5, 写入 0x06010000+r0*32), r1=sprite_attr (OBJ attr 值). 函数先以 r0*0x20 为偏移在 0x06010000 处调用 tile_2d_row_copy 复制 4x2 tile 行(取 [0x09ce822c+0x8] 即 ROM tile ptr); 若 r1<=0xf 则额外将调色板 [0x09ce824c+0x8] 的 0x20 字节 DMA 复制到 0x05000200+r1*0x20.

Constants:
- OBJ_VRAM_BASE = 0x06010000 (OBJ tile VRAM 基址)
- ROM_TILE_TABLE = 0x09ce822c (ROM 卡牌 tile 指针表)
- ROM_PAL_TABLE = 0x09ce824c (ROM 卡牌调色板表)
- OBJ_PAL_BASE = 0x05000200 (OBJ 调色板 VRAM 基址)
- TILE_STRIDE = 0x20 (= r0<<5, slot * 32 字节)
- TILE_COPY_COLS = 4; TILE_COPY_ROWS = 2 (tile_2d_row_copy 参数)
- PAL_COPY_SIZE = 0x20 (32 字节 = 16 色调色板)
- PAL_LIMIT = 0xf (r1 > 0xf 时跳过调色板复制)

## 参数签名
- r0: u16 tile_id_base [0..N] (tile 基准 ID, VRAM 偏移 = tile_id_base*32; caller 传入如 0xc3<<2=0x30c)
- r1: u8 pal_slot_index [0..0xf] (OBJ palette slot 索引; >0xf 跳过调色板复制)
- 返回: void (pop {r0}; bx r0)

## 副作用
- [0x06010000+r0*0x20..+tile_size]: 写 ROM 卡牌 tile 数据 (via tile_2d_row_copy)
- [0x05000200+r1*0x20..+0x20]: 写 ROM 卡牌调色板 (via copy_memory_dma3_with_cpu_fallback, 仅 r1<=0xf 时)
