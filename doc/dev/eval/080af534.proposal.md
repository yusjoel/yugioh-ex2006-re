## plate comment (中文, ASCII 标点)
无 push 叶子函数. 对 r0 (card_id) 执行大规模二分查找式比较, 检查其是否属于预定义的特定卡片 ID 集合. 集合中的 ID 包括 0x14ac, 0x130c, 0x10f4, 0x12ac, 0x1302, 0x140e, 0x134a, 0x1468, 0x147c, 0x1645, 0x15ee, 0x1636, 0x1770, 0x166c, 0x172c, 0x1855, 0x185c, 0x1992 等. 命中 LAB_080af696 路径返回 1; 命中 LAB_080af68c 路径返回 (r1==0 ? 1 : 0); 不命中 LAB_080af69a 返回 0. 被 7 个 caller 调用, 是卡片激活资格判断的核心白名单过滤器.

## 参数签名
- r0: u32 card_id [0..0x7fff] - 待检查的卡片 ID
- r1: u32 mode_flag [0..1] - 仅在 LAB_080af68c 路径使用: r1==0 则返回 1, 否则返回 0 (行为取反)
- 返回: r0 = u32 eligible [0..1] - 1 表示 card_id 在白名单中且满足 mode_flag 条件, 0 表示不在
