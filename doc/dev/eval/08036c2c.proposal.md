# Naming Proposal: 0x08036c2c

## 提案
- **proposed_name**: build_effect_zone_entry
- **confidence**: med

## plate comment (中文, ASCII 标点)
为指定玩家侧 (player_side) 的 zone_idx (>=5, 即魔法/陷阱区) 构建并提交一个效果区条目. 流程: (1) 调 FUN_0803b2b4(player_side, zone_idx) 取格位结构体指针 r4; (2) 在栈上分配 0x18 字节缓冲区并清零; (3) 将 player_side & 1 写入缓冲 [+2].bit0, zone_idx & 0x1f 写入 [+2].bits[1..5]; (4) 从 r4 读取 card_id (bits[0..12]) 写入 [r1+0]; (5) 将 card_id 的附加字段打包写入 [+4] (保留掩码 0xffff803f 的低 6 位清零再 OR); (6) 清除 [+3] 中 0x31 对应位; (7) 调 FUN_0805a9a8(buf) 提交该条目进入效果链. zone_idx <= 4 直接返回 0 (仅处理魔法/陷阱/装备区).

Constants:
- mask_zone_type = 0x1f
- buf_stride = 0x18 bytes (local stack)
- FUN_0803b2b4 = get_zone_slot_ptr
- FUN_0805a9a8 = commit_effect_zone_entry
- 0xffff803f = [+4] halfword keeper mask

## 参数签名
- r0: u32 player_side [0..1] (bit0=P1/P2)
- r1: u32 zone_idx [5..10] (0..4 时直接返回 0; 5=Magic1..10=Equip)
- 返回: r0 = u32 (0 = zone_idx<=4 短路退出; FUN_0805a9a8 的返回值传递)

## 副作用
- [sp local buf +2]: player_side bit0 + zone_type bits[1..5] 写入
- [sp local buf +3]: 清除 0x31 对应位
- [sp local buf +4]: card_id 附加字段打包写入 (保留 0xffff803f 位)
- FUN_0805a9a8 内部: 向效果链注册该条目 (涉及 gDuelEffectZone 等结构)
