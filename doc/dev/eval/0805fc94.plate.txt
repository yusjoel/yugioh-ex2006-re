Equip slot eligibility predicate. Multi-condition composite check.
(A) If r1 != NULL and r1[+0].card_id == slot_ptr[+0].card_id -> return 0 (same card, no activation).
(B) Check slot_ptr[+2] bits[10:4] == 0x480 (zone_type); check slot_ptr[+0x14] != 0 (chain node present);
    verify gP1LifePoints player flag matches slot player; check global [0x0201bb90+0x8] == 0 (no block);
    compute chain node addr and call check_card_stat_field8_is_6 and eval_equip_chain_score_for_slot;
    if chain score > 4 -> fail; call count_equip_slots_with_active_chain to confirm no active chain.
Pure predicate, no external writes.

Constants:
  0xfc0 (0xfc<<4): zone_type mask bits[10:4]
  0x480 (0x90<<3): zone_type target value (equip zone type)
  0x0201bb90: global field state structure base
  0x868: player stride
  0x0201c510: hand slot array base
  0x1318: count_equip_slots_with_active_chain config constant
  0x4: chain score upper bound (score <= 4 passes)

Inputs: r0=SlotPtr* slot_ptr (byte[+2] bit0=player_id [0..1]), r1=SlotPtr* compare_ptr (nullable)
Returns: r0 u32 (0=ineligible; 1=eligible no-owner; 2=eligible chain-satisfied)
Callees: check_card_stat_field8_is_6, eval_equip_chain_score_for_slot, count_equip_slots_with_active_chain
