## plate comment (中文, ASCII 标点)
检查决斗场地滚动动画阶段是否满足继续条件. 由 FUN_080d136c / FUN_080d2ef4 / FUN_080d4478 调用.
读取 [0x0201e4f0+0x4] (phase_counter); 根据三个范围分派:
[0..5]: 返回 0 (阶段过早, 不满足条件).
[1..5]: 返回 0 (同上; bcs/bcc 组合).
[6..37] (0x6..0x25): 读取 [0x02020160+0x2e40] byte (scroll_flag); 若为 0 返回 0, 否则返回 1.
[38..71] (0x26..0x47): 读取 scroll_flag, 同时调用 get_clamped_tile_row_count (08094290),
  若 scroll_flag < clamped_count 则返回 0, 否则返回 1.
[>71]: 返回 1 (阶段完成).
返回 1 = 条件满足可推进, 0 = 尚未就绪.
Constants: PHASE_BASE=0x0201e4f0; PHASE_OFFSET=0x4; SCROLL_FLAG_ADDR=0x02020160+0x2e40;
RANGE1=[0..5] 0; RANGE2=[6..37] flag; RANGE3=[38..71] flag+clamp; RANGE4=[72+] 1.
