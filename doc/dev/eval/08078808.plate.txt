Reads LP state machine 0x0201b290[0x94*8=0x4a0] and routes by state:
State 0x80: calls check_neo_daedalus_placement_eligible(effect_node, second_arg); skips if returns 0. If card_id == CARD_ID_WATER_DRAGON=0x1951 (Water Dragon): iterates zone_count zones, for each zone calls read_effect_slot_zone_type + find_hand_slot_idx_by_set_code + check_zone_slot_equip_eligible; counts eligible slots. If available_monster_slots >= eligible_count: calls increment_lp_bar_display_counter, clears [state_base+0x4a4], returns 0x7f.
  If card_id != 0x1951: directly calls increment_lp_bar_display_counter + clear + returns 0x7f.
State 0x7f: iterates zone entries, calls find_hand_slot_idx_by_set_code + check_zone_slot_equip_eligible; if eligible calls invoke_setup_equip_oam_with_attr2 to write OAM; increments [state_base+0x4a4]. Returns 0x7f/0x7e.
State 0x7e: calls decrement_lp_bar_display_counter. Returns 0.

Constants:
- STATE_BASE=0x0201b290
- STATE_OFFSET=0x94*8=0x4a0
- COUNTER_OFFSET=0x4a4
- CARD_ID_WATER_DRAGON=0x1951 (Water Dragon)
- HAND_ZONE_SLOTS=0x0201c8f8
- PLAYER_STRIDE=0x868
