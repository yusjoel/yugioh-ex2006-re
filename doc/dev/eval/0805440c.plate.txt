check_equip_slot_eligible_by_icid_mismatch_and_prereqs
Equip card target zone eligibility predicate requiring target slot card_icid differs from equip card_icid.
Caller: check_zone_slot_equip_prerequisites (0x08036770) during equip target selection.
Checks in order: (1) slot_idx <= 4; (2) gDuelFieldSlots[player_id&1][slot_idx] bits[18:0] != 0 (occupied);
(3) [slot+8] != 0 (secondary flag valid); (4) check_zone_slot_equip_prerequisites passes;
(5) ldr [slot+0] bits[18:0] = target card_icid, ldrh [equip_slot+0] = equip card_icid low 16 bits,
equal => reject (prevents equip card targeting same-ID card).
Returns 1 if icid differs, 0 if same or any prior check fails. Pure predicate, no external writes.
Constants: SLOT_IDX_MAX=4, gDuelFieldSlots=0x0201c510, player_stride=0x868
Inputs: r0=ptr equip_card_slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..4]
Returns: r0=u32 bool (1=eligible, 0=rejected)
