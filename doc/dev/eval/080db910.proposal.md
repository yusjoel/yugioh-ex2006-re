# Naming Proposal: 0x080db910

## 提案
- **proposed_name**: copy_card_medium_frame_to_obj_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
将指定卡牌 (r0=icid 或 frame_idx) 的中号卡框图形数据从 ROM 复制到 OBJ VRAM 目标缓冲 (r1=VRAM 目标指针). r2=调色板字节偏移, r3=0 时用 DMA+循环调色板修正一次性复制; r3!=0 时分 6 段, 每段 DMA 复制 0x100 字节 + 调色板修正后将 vram 目标前进 0x300 字节. 在 mode=JAPAN (IWRAM[0x02006c2c] 字节低 3 位非零) 时使用不同 card_image_index 入口. 复制后对非零像素加调色板偏移量 r2.

Constants:
- CARD_IMAGE_INDEX=card_image_index // 卡图索引表 (0x095b5c00)
- CARD_FRAME_DATA=card_medium_frame_tile_data // 中号卡框图形基址 (0x08fbc080)
- FRAME_SIZE_SINGLE=0x600 // 0xc0<<3=0x600 字节: 单段复制模式大小
- FRAME_TILE_COUNT=0x2ff // 0x2ff+1=0x300 halfwords: 单次调色板扫描上界
- FRAME_SEGMENTS=6 // r3!=0 时分 6 段复制, 每段 0x100 halfwords
- SEG_DMA_BYTES=0x100 // 0x80<<1: 多段模式每次 DMA 复制字节数 (080db9b0-080db9b4)
- SEG_R4_ADVANCE=0x300 // 0xc0<<2: 多段模式 r4 (vram_dst) 每轮前进字节数 (080db9d4-080db9d8 palette-fixup 分支)
- LANG_FLAG=0x02000000+0x6c2c // IWRAM 语言标志地址
- LANG_MASK=0x7 // 低 3 位: 日版字体标志

## 参数签名
- r0: u16 card_frame_id -- 卡框图形索引 (映射至 card_image_index 表)
- r1: u16* vram_dst -- OBJ VRAM 目标指针
- r2: u8 palette_offset -- 调色板字节偏移量 (叠加到非零 tile 像素)
- r3: u8 multi_segment -- 0=单次全量复制, 非0=分 6 段复制
- 返回: r0 = void; `pop{r0}; bx r0` 退出

## 副作用
- OBJ VRAM [r1..r1+0x600] 或 [r1..r1+0x600*6]: 写入卡框图形数据
- 非零 tile 像素加 r2 调色板偏移 (inline 扫描循环)
