# Naming Proposal: 0x0810e5c8

## 提案
- **proposed_name**: invoke_r0
- **confidence**: high

## plate comment (中文, ASCII 标点)
单指令函数指针蹦床: 执行 bx r0 直接跳转到 r0 所含地址 (THUMB 模式 bit0=1). 调用方在 bl 本函数之前将目标函数指针加载至 r0, r1..r3 携带参数透传给目标函数. 被大量场景/卡牌逻辑调用 (indeg=34), 用途涵盖: 场景切换回调、卡牌效果表函数指针间接调用、display 子系统分派等. 与同族蹦床 invoke_r1/r2/r3 (0x0810e5cc/d0/d4) 共同构成 GBA ROM 的 APCS 寄存器级函数指针分派簇.

## 参数签名
- r0: ptr<fn> fnptr 目标函数指针 (THUMB 地址 bit0=1); 同时充当跳转目标, 不传递给被调函数
- r1: u32 arg1 透传给被调函数
- r2: u32 arg2 透传给被调函数
- r3: u32 arg3 透传给被调函数
- 返回: r0 = 被调函数返回值 (透传)

## 副作用
- 无独立副作用; 由被调函数决定

## 行级注释 (<=30 行精华)
- @ 0x0810e5c8: bx r0 -> 跳转到 r0 所含函数指针 (单指令蹦床)
- @ 0x0810e5ca: .byte 0xc0,0x46 = nop (对齐填充)
