## plate comment (中文, ASCII 标点)
验证装备卡目标区域的合法性, 针对特定卡 ID 范围执行不同的效果槽检查. 首先验证 r1 (target_ptr) 非 null 且与 r0 (card_entry) player_id (bit0 XOR byte[+3].bit5) 不同 (跨场配对). 然后通过对 target_ptr[+0] card_id 的多段二分搜索将卡分入不同校验路径: 0x0ffa, 0x1246 范围直接读效果槽; 0x131c-0x1685/0x1686 范围调用 read_effect_slot_side_and_type; 特殊卡 0x149b / 0x1364 / 0x134d / 0x16b8 有独立路径. 主要检查: (1) 读 gDuelFieldSlots_A (0x0201c510) 对应槽位 card_id 是否非 0; (2) 提取 player/slot 与 card_entry 比对是否同一槽; (3) 调用 get_card_extended_stat_field6==0x17 (continuous equip). 通过则调用 build_zone_activation_entry_blocked 或返回 1; 不匹配返回 0. 通过函数指针调用.

Inputs: r0 = ptr equip_card_entry (byte[+2] bit0=player_id, byte[+3] bit5=opposite_flag; r8 spill); r1 = ptr target_card_entry (r3 spill; [+0]=target_card_id)
Outputs: r0 = u32 (1=zone activation entry built or target valid; 0=invalid/not applicable)
Side effects: build_zone_activation_entry_blocked called in some paths (writes activation entry)
Constants: CARD_IDs=[0x0ffa (Reaper of the Cards), 0x11f0 (Greenkappa), 0x1246 (Harpie's Feather Duster), 0x131c (unknown card_id; not in data.md), 0x134d (Driving Snow), 0x1364 (Nobleman of Extermination), 0x149b (Bait Doll), 0x1685 (Dark Scorpion - Gorg the Strong), 0x1686 (Dark Scorpion - Meanae the Thorn), 0x16b8 (Crimson Ninja)] (equip-related cards); SLOTS_A=0x0201c510 (gDuelFieldSlots_A); PLAYER_STRIDE=0x868; FIELD6_CONTINUOUS_EQUIP=0x17; INVALID_ZONE=0xffff
