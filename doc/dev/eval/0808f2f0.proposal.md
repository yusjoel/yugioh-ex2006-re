# Naming Proposal: 0x0808f2f0

## 提案
- **proposed_name**: enqueue_exchange_slot_sprite_attrs
- **confidence**: med

## plate comment (中文, ASCII 标点)
被 FUN_080a0334 (duel_field, indeg=1) 以 r0=player_id, r1=zone_col, r2=equip_set_idx 调用. 处理 icid=0x14ac (Exchange, 5292) 装备槽的精灵属性提交. 调用 find_equip_chain_pair_across_field(player, zone, equip_set_idx) 查找跨场地装备链配对; 若返回 0xffff (无配对) 则直接返回. 配对有效时: 提取 low byte (=zone_col_A -> r7) 和 byte[8..15] (=zone_col_B -> r1); 调用 enqueue_equip_set_slot_sprite_by_zone_col; 调用 get_equip_card_set_code_for_slot -> set_code+1<=2 则跳过后续; set_code+1>2 则调用 enqueue_equip_chain_slot_sprite_attr (mode=1). 若 r4==0 (初次循环): 检查 [slot+0x40] bit5 (进一步过滤), 若通过提取卡 id 字段调用 enqueue_sprite_attr_for_zone_card_id_lookup, 再计算 owner-mismatch 位并调用 enqueue_equip_slot_bitmap_update. Side effects: 向精灵 OAM 队列提交 Exchange 装备槽相关精灵属性和位图更新. Constants: icid_filter=0x14ac (5292, Exchange 卡名待 icid 内部表确认), no_pair_sentinel=0xffff, equip_flag_offset=0x40 (bit5=过滤位), card_id_field_offset=0x30, set_code_threshold=2 (set_code+1<=2 跳过).

## 参数签名
- r0: u32 player_id [0..1] - 玩家侧 (通过 0x4647=mov r7,r8 或父寄存器传入; 实为 r6=r0)
- r1: u32 zone_col [0..4] - 场地列 (-> r5)
- r2: u32 equip_set_idx - 装备集合索引 (-> r4)
- 返回: r0 = void (通过 pop{r0}; bx r0 返回)

## 副作用
- 通过 enqueue_equip_set_slot_sprite_by_zone_col: OAM 队列写入
- 通过 enqueue_equip_chain_slot_sprite_attr: OAM 队列写入
- 通过 enqueue_sprite_attr_for_zone_card_id_lookup: OAM 队列写入
- 通过 enqueue_equip_slot_bitmap_update: 位图队列写入
