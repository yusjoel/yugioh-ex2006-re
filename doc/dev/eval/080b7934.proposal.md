## plate comment (中文, ASCII 标点)
检查在场上存在 Gravity Bind (0x140e) 或 Level Limit Area B (0x17a6) 等等级限制牌的情况下,
装备效果激活是否仍然有效. 入口 r0=zone_ptr -> r5. 提取 player_bit, 对手 = 1-player_bit.
第一步: count_equip_slots_active_only(opponent) -> r6; 若 r6==0 (对手无装备) 直接返回 0.
第二步: count_equip_whitelist_cards_in_monster_zone 双方比较; 若己方数量更多返回 1 (有优势).
若 r6>1 且己方活跃装备>=对手, 则继续检查; 否则进入核心检查.
核心: check_equip_effect_zone_preconditions(self) -> 0 则返回 0.
查场上是否有 count_field_copies_of_card(0x140e=Gravity Bind) 或 (0x17a6=Level Limit Area B).
若两者都不在场则返回 0.
find_best_activatable_slot_score_for_player(self, -1, 0) -> r4=score.
比较 r4 与 LP 阈值 (DWORD_080b79e4=gP1LifePoints+player*0x868 处 LP) 和下界 DWORD_080b79ec=0x095f=2399.
若在范围内: compare_zone_max_scores_by_player -> <=0 则失败, >0 返回 1.

Constants:
