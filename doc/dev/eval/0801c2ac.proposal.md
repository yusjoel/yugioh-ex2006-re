## plate comment (中文, ASCII 标点)
场景切换时调用的全局 GL 显示状态重置函数. 由 FUN_0801cf74, FUN_0801cfcc 及 play_ui_effect_3b 等多个场景转场 hub 调用, 负责在进入新场景前将显示系统恢复到已知初态. 执行顺序: (1) bios_cpu_set 32-bit fill 模式将 EWRAM 0x02029eb0 起 192 字节 (48 word) 清零 (覆盖 gDemoState 前置区域); (2) gl_clear_vram_palram_scroll 清除 VRAM/palette RAM/scroll 寄存器; (3) 向 DISPCNT (0x04000000) 写 0x1741 (BG mode 1, OBJ 1D mapping, BG0+BG1+BG2+OBJ 启用), 向 BG0CNT (0x04000008) 写 0x1D81, BG1CNT 写 0x1E82, BG2CNT 写 0x1F8B (各 BG 层优先级/字符基地址/画面基地址设定); (4) gl_set_brightness(0x3F, -16) 设置淡入起始亮度; (5) gl_state_init 初始化 GL 内部状态; (6) gl_clear_frame_callbacks 清除所有帧回调. 返回固定值 1 (成功). Constants: DISPCNT_VAL=0x1741 / BG0CNT_VAL=0x1D81 / BG1CNT_VAL=0x1E82 / BG2CNT_VAL=0x1F8B / ZERO_FILL_CTRL=0x05000030(fill+32bit+48words) / BRIGHTNESS=-16(0x3F, 0x10).
