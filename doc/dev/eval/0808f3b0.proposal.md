# Naming Proposal: 0x0808f3b0

## 提案
- **proposed_name**: scan_field_slots_for_attached_sprite_by_id
- **confidence**: med

## plate comment (中文, ASCII 标点)
扫描双方场地两侧的全部 9 个 slot 位置, 寻找匹配特定 card_id (DAT_0808f44c=0xa5f80000 对应的 13 位 ID 0x14bf), 命中后调用 enqueue_sprite_attr_with_shape 提交 sprite 入队, 用于在该 slot 上方贴出附属 sprite. 外层循环 i=[0..1] (player side); 内层循环 j=[5..9] (slot index 5 到 9 即 monster zone+spell zone 共 5 格). 单进单出, sp[4]=outer_index, 无外部状态写入 (纯计数与显示队列 enqueue). 只与 0x14bf 这一张卡 (静态可见) 触发. 4 个 caller 全部 duel_field tag (FUN_08047218/FUN_08047f50/FUN_08048020/FUN_08048364), 静态从扫描范围 (双方全场) + sprite 入队可见 0x14bf 是触发全场效果的特定卡.

## 参数签名
- r0: u32 card_field_bit13 [0..1] -> r10 (callee-save alias; 4 caller 全部以 `lsls #0x12 + lsrs #0x1f` 自 [card_record+0] 抽 bit13 作 r0; 在 0808f408 `mov r7,r10` 处转发为 enqueue_sprite_attr_with_shape 第 1 参 — 触发 sprite 显示的 card 标志位)
- r1: u32 sprite_kind_id [=1, fixed] -> r9 (callee-save alias; 4 caller 全部 `movs r1,#0x1` 即固定立即数 1; 在 0808f410 `mov r7,r9` 处经 lsls 后转发作 enqueue 第 3 参 — sprite kind/shape 标识)
- 返回: void (无显式 r0 写, 仅 enqueue 副作用经 enqueue_sprite_attr_with_shape)

> caller r0/r1 构造证据 (4 处全同):
> - 0x0804768e: `lsls r0,r0,#0x12 / lsrs r0,r0,#0x1f / movs r1,#0x1` (FUN_08047218 内)
> - 0x08047fcc: `lsls r0,r0,#0x12 / lsrs r0,r0,#0x1f / movs r1,#0x1` (FUN_08047f50 内)
> - 0x080481f0: `lsls r0,r0,#0x12 / lsrs r0,r0,#0x1f / movs r1,#0x1` (FUN_08048020 内)
> - 0x080484ec: `lsls r0,r0,#0x12 / lsrs r0,r0,#0x1f / movs r1,#0x1` (FUN_08048364 内)

## 副作用
- enqueue_sprite_attr_with_shape() : 经 callee 写入 sprite attr 队列 (queue_base=0x0201bcc0+0x808)
