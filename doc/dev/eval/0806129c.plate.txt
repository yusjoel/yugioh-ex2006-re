(1) read gP1LifePoints[player*0x868+0x1c] (hand alt count), if <= 1 reject;
(2) call count_paired_slots_both_sides(BLS-Envoy=0x16cb) and count_paired_slots_both_sides(CED-Envoy=0x16e4);
    if both return 0 reject; if either Envoy has a paired slot, return 1.

ICID_CED_ENVOY=0x16e4 (Chaos Emperor Dragon - Envoy of the End, passcode=82301904),
