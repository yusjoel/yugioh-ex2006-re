# Naming Proposal: 0x080f61e4

## 提案
- **proposed_name**: write_obj_attr_packed
- **confidence**: med

## plate comment (中文, ASCII 标点)
向 OBJ 属性缓冲 (gPrng+0x1bc = 0x030001fc 处的精灵属性表) 写入一个精灵的 attr0/attr1/attr2 三个半字. 从 r0 低 16 位取 attr0 (Y 坐标/形状/颜色模式), 高 16 位取 attr_extra; 从 r1/r2 取 attr1 和 attr2 参数. 用 0xfffe00 掩码合成 attr0 字段后写入已命名条目槽, 再写 attr1, 并将 attr2 的 tile_idx 部分合并写入 [+4]. 最后将该槽的使用计数 byte ([entry+0x400]) 加 1. 被多个高层 sprite 设置函数调用以提交 OBJ 属性到 shadow 缓冲.

## 参数签名
- r0: u32 packed_attr (bits[15:0]=attr0 (Y/shape/mode), bits[31:16]=attr_extra (X/size 辅助))
- r1: u16 attr1_x (X 坐标及 flip/size bits)
- r2: u16 attr2_tile (tile_idx 及 palette/priority)
- 返回: void

## 副作用
- [gPrng+0x1bc + slot*8 + 0]: halfword := 合成的 attr0
- [gPrng+0x1bc + slot*8 + 2]: halfword := 合成的 attr2_tile 部分
- [gPrng+0x1bc + slot*8 + 4]: halfword := attr_extra 字段
- [gPrng+0x1bc + slot + 0x400]: byte += 1 (使用计数)
