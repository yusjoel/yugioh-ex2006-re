## plate comment (中文, ASCII 标点)
叶子函数. 检查 card_id (r0) 是否为三个特殊场地区域卡之一: 0x170a, 0x170a-0xb8=0x1652, 或 0x17d2. 这三个卡 id 代表具有特殊场地判定逻辑的区域卡. 若匹配任一则返回 1, 否则返回 0. 被 FUN_080363bc 调用以在装备槽检查前过滤特殊区域卡.

## 参数签名
- r0: u16 card_id [0..0x1fff] (待检查的卡 id)
- 返回: r0 = u8 is_special (1=为特殊场地区域卡, 0=否)
