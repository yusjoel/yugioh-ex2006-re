## plate comment (中文, ASCII 标点)
刷新当前 text overlay 的调色板行数据到 OBJ palette VRAM. 从 gPrng+0x1d0 取 overlay_ptr; 若为 null 返回 void. 读 [overlay_ptr+0x14] flags bit0: bit0=1 从 OBJ palette VRAM (0x05000200 + tile_row_idx*0x20) 调 copy_overlay_tile_row_to_palette; bit0=0 从 BG palette RAM (0x05000200 = DAT_080dd4a8) 调. 两路均读 [overlay_ptr+0x4] 为 tile_row_idx, 计算 palette 行地址. 由 FUN_080d6d30 (pack 帧驱动) 单一调用.

- gPrng+0x1d0: 全局 overlay 结构体指针
- 0x05000200: OBJ palette base + 0x200 (DAT_080dd4a8)
- PALETTE_STRIDE=0x20 // tile_row_idx*0x20 = palette 行偏移

## 副作用
