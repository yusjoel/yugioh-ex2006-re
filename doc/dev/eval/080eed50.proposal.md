# Naming Proposal: 0x080eed50

## 提案
- **proposed_name**: get_game_text_ptr_by_str_type_b
- **confidence**: high

## plate comment (中文, ASCII 标点)
被 card_frame/duel_field 两类 caller (0x080659e8, 0x0806cbe8, 均带 game_str+duel_field tags) 在获取卡片效果/描述文字时调用. r0=0 直接返回 fallback 地址 0x09e4f348; 否则将输入 ID 加偏移 0x212 后调 game_str_id_to_row 映射为行号, 读取 EWRAM [0x02006c2c] 低 3 位作为语言列选择器 (lang_code), 计算 game_str_pointer_table 中对应语言列的指针偏移后返回 game_str_ja 基址加偏移所指字符串. 与同翻译单元 FUN_080eeda4 (偏移 0x23a) 构成 B/C 类字符串族. 无外部写副作用.

Constants:
- ID_OFFSET_B=0x212 // 字符串族 B 的 base id 偏移
- LANG_CODE_ADDR=0x02006c2c // EWRAM 语言/设置字节
- FALLBACK_PTR=0x09e4f348 // id=0 时返回的空字符串地址

## 参数签名
- r0: u16 game_str_id [0..0xffff]; 0 返回 fallback
- 返回: r0 = const char* 对应语言的字符串指针 (指向 game_str_ja 区)

## 副作用
(无外部写)

## 行级注释 (<=30 行精华)
- @ 080eed52: r0==0 时直接走 fallback 路径, 避免计算无效行
- @ 080eed56: 加 0x212 将输入 id 映射到 B 族字符串起始行
- @ 080eed5a: game_str_id_to_row 将全局行号转为 pointer_table 行索引
- @ 080eed70: [0x02006c2c] 低 3 位 = 当前语言代码 (0=JA,1=EN,...)
- @ 080eed74: 提取 bits[2:0] 作为语言列选择器
- @ 080eed78: 乘以 4 得到 pointer_table 中的列偏移 (每条目 4 字节)
- @ 080eed7c: 读取对应语言指针, 加 game_str_ja 基址得最终字符串地址
- @ 080eed98: fallback: 直接返回 0x09e4f348 (空字符串)
