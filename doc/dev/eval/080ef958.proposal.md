## plate comment (中文, ASCII 标点)
每帧由 SIO 甲板同步驱动层 (FUN_080efb10 / FUN_080efe48 / FUN_080efeec) 调用, 负责推进对战双人组牌同步握手状态机的单帧逻辑.
入参 r7(来自 caller sp 保存) 是当前帧上下文指针, 函数读取 IWRAM [0x030003a0+0x33f] 的连接状态字节: 0=主动握手路径 (配置 IME/IE/IF/SIOCNT 并发起传输), 1=等待轮询路径 (调用 process_sio_deck_sync_frame 后判断返回值 bit[1:0] 决定是否 bl start_sio_master_if_ready), 其余值=跳过所有路径.
副作用: 在主动握手路径中向 IME/IE/IF/SIOCNT 写入中断配置, 向 [0x030003a0+0x33e] 和 [0x030003a0+0x4c4] 写状态字节; 最终将 [0x030003a0+0x434] halfword 写入 process_sio_deck_sync_frame 返回值并条件更新 bit7.

Constants:
- IWRAM_SIO_BASE = 0x030003a0
- SIO_STATUS_OFFSET = 0x33f (状态字节, 0=init/1=poll/other=skip)
- SIO_LINK_OFFSET = 0x33e (连接标志字节)
- FRAME_STATUS_OFFSET = 0x434 (帧状态 halfword)
- IE_MASK = 0x0000ff7f (清除 IF 专用 mask)
- IF_ACK = 0x00c0 (确认 SIO VBlank/timer 中断)

## 参数签名

- 返回: r0 = 从 [0x030003a0+0x434] 读回的最终状态 halfword (pop{r1};bx r1 出口, ldrh r0,[r2,#0x0] 是最后赋值)
