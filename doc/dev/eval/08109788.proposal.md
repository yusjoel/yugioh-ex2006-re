# Naming Proposal: 0x08109788

## 提案
- **proposed_name**: resolve_card_frame_palette_by_type
- **confidence**: med

## plate comment (中文, ASCII 标点)
根据卡片类型编号 (r0, 范围 0-12) 从 ROM 查找对应卡框调色板数据指针, 合并 r1 (子偏移, 移位 8 位) 后返回. 各 case 加载 ROM 地址 0x09e265b4-0x09e2ddb4 段内的调色板数据指针 (per-type 调色板块). 返回值 = palette_ptr + (r3<<8), 即调色板基地址加行偏移; 若 r2==0 则返回 0 (无效类型). 在 FUN_081014fc 中由 FUN_08109848 的返回值作为 r1 传入, 两者构成 type->palette 的两级分派.

## 参数签名
- r0: u8 card_type (卡片类型编号, 0-12; 超出范围返回 0)
- r1: u8 sub_offset (调色板行内偏移, 左移 8 后加到基址; 来自上游查表结果)
- 返回: r0 = u32 调色板行指针 (ROM 地址; 0 = 无效)

- 无
