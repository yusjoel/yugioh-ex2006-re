# Naming Proposal: 0x080ef65c

## 提案

## plate comment (中文, ASCII 标点)
SIO 连接初始化入口. 被 FUN_080edd90 (tags: sys,timer) 在建立链接阶段调用. 执行步骤: (1) 禁用 IME 并屏蔽 IE 的 serial bit (ands 0xff3f), (2) 以 bios_cpu_set fill 模式 (r2=0x05000116, src=[sp]=0) 将 IWRAM [0x030003a0] 起 0x116 个字清零, (3) 初始化三个数据指针字段 (d4/d5/d6 偏移), (4) 逐个卡牌槽 (1 个槽, loop count=1) 设置 unknown_flags 为 0xff, (5) 清零 halfword 字段 [+0x0346], (6) RCNT=0 (关闭 GPIO), (7) 设置 SIOCNT=0x4000 (SIO normal mode, 32bit) | 0x4003, (8) 写 SIO 状态字 [+0x34c]=0xc; (9) 写 SIOSTAT [+0x360]=0x1000, (10) 注册 SIO callback (写 0x080ef535 到 [+0x42c]), (11) 读 SIOCNT 到 [+0x434] 备用, (12) 重新开启 IE serial bit, 恢复 IME=1.

Constants:
- SIO_STATE_BASE=0x030003a0 // IWRAM SIO 结构基址
- ZERO_FILL_CTRL=0x05000116 // bios_cpu_set: fill mode, 0x116 words
- SIO_MODE_NORMAL32=0x4003 // SIOCNT 模式字 (32bit normal)
- SIO_BAUD_BITS=0x4000 // SIOCNT baud rate bits
- SIO_CALLBACK=0x080ef535 // SIO 接收回调 (handle_sio_recv_packet+1)
