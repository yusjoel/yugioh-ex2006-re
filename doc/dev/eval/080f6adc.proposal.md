# Naming Proposal: 0x080f6adc

## 提案
- **proposed_name**: write_pack_obj_attr_by_dir
- **confidence**: med

## plate comment (中文, ASCII 标点)
根据方向码调整屏幕坐标并将 OBJ sprite 写入 OAM 影子缓冲区 (pack/puzzle 场景用).
r0 = 打包坐标 (高 16 bit = y, 低 16 bit = x); r1 低 16 = dir_code (方向/角度离散码);
r2 低 16 = 附加参数 (保存栈上备用); r3 = affine 参数.
函数首先验证 gPrng+0x1bc 对应 slot 的 availability 字节 (0x80 = 满, 直接退出);
若可用则根据 dir_code (0x0/0x40/0x80/0xc0/0x4040/0x8000/0x8080/0x80c0 等离散值)
对 (x, y) 各减 4/8/16/32 像素以居中对齐不同旋转角度下的 sprite.
随后写入 OAM attr0 (y & 0xff | 0x300 affine 双尺寸标志), attr1 (x & 0x1ff | affine_idx<<9), attr2 (从 slot 复制).
调用 write_obj_affine_scale_diagonal (0x080f6074) 写入缩放矩阵.
最后递增两个使用计数字节 (buf_base+r8 和 buf_base+0x401).
唯一 caller: FUN_080bcc6c (blend/window/display/palette, 疑似 banner 场景 OBJ 状态机).

Constants:
- gPrng+0x1bc (0xde<<1): OBJ 影子缓冲区基址; gPrng+0x400+slot: slot 可用标志 (0x80=满)
- 0x4040 / 0x8000 / 0x8080 / 0x80c0: 方向码枚举值 (需 runtime 确认含义)
- DAT_080f6b5c = 0xfffffe00: attr1 X 坐标掩码 (~0x1ff)
- DAT_080f6cc8 = 0x401: slot 使用计数偏移; 0xc0<<2 = 0x300: OBJ affine double-size 标志位

## 参数签名
- r0: u32 packed_pos - 高 16 bit = y [0..159], 低 16 bit = x [0..239] (屏幕像素坐标)
- r1: u16 dir_code - 方向/角度离散枚举 {0x0, 0x40, 0x80, 0xc0, 0x4040, 0x8000, 0x8080, 0x80c0}; caller 0x080bcc6c 静态传入 0xc0 (movs r1,#0xc0 @ 080bd038)
- r2: u16 oam_attr_word - 打包 OAM 属性半字 (低 16 有效); caller 0x080bcc6c: r12=mov r12,r2 后 mov r2,r12; r2 值为 (loop_idx*8 + 0x300) | 0x4000, loop_idx=[0..2], 枚举 {0x4300, 0x4308, 0x4310}
- r3: u32 affine_composite - [31:16]=affine_slot_hi (frame_counter<<8 + 0x100) & 0xffff; [15:0]=scale_lo (0x100 - frame_counter*32) & 0xffff; 传递给 write_obj_affine_scale_diagonal
- 返回: void (无返回值)

## 副作用
- [gPrng+0x1bc->entry+0x0] := attr0 (y | affine flag, strh)
- [gPrng+0x1bc->entry+0x2] := attr1 (x | affine_idx<<9, strh)
- [gPrng+0x1bc->entry+0x4] := attr2 (从 slot 复制, strh)
- bl write_obj_affine_scale_diagonal: 写入 PA/PB/PC/PD 到 affine entry
- [gPrng+0x1bc+r8] := use_count+1 (strb)
- [gPrng+0x401+slot] := use_count2+1 (strb)
