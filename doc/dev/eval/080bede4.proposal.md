## plate comment (中文, ASCII 标点)
pack 卡包展示界面每帧调用的 AOB 动画状态机 tick. 从 gBannerState 读取阶段字节 [+0x10], 按 0/1/other 三路分发:
- phase=other(>=2): 清除 [+0x0] bit1 flag; 写 0x02023130+0x215 位域掩码; 返回 0.
- phase=0: 加载 ROM palette + tiles 至 0x050002a0 / 0x06014000; 初始化 AOB 上下文 (gBannerState+0x1c); 调用 sync_state_and_init_sprite; 若 r6==0xb 则同步玩家 LP 减量并刷新 refresh_player_field_slot_tiles + update_zone_oam_card_count_tag; 推进 phase+1; 返回 1.
- phase=1: 对 r6 (0..0xf) 做 switch dispatch 选取动画帧坐标; 调用 transform_zone_oam_coords_by_player; render_aob_frame_to_oam; tick_aob_frame_counter; 若帧计数器到 0 则推进 phase+1; 返回 1.

- gBannerState = 0x0201fec0 (pack banner 状态结构)
- BG_PAL_DST = 0x050002a0, OBJ_TILE_DST = 0x06014000 (VRAM 写目标)
- ZONE_TYPE_B = 0xb (触发 LP 同步的 zone type)
- gP1LifePoints = 0x0201c4e0, PLAYER_STRIDE = 0x868 (LP 结构)
