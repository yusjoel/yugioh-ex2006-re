indeg=0 (Sub-type A: no static callsite, no fn-ptr reference).
Game custom vsprintf %s expansion path.

Scans format string r1 in a single pass and outputs to destination buffer r0.
When control sequence "@%s" (bytes 0x40 0x25 0x73, advance 6) or "%s" (0x25 0x73,
advance 2) is encountered, calls append_text_to_buf_end to append the substring
to the buffer end then appends the remaining format string.
All other bytes are copied one-by-one via strb.
Terminates at null byte at end of r0.

r0 = ptr destination output buffer (output bytes written via r5++)
r1 = ptr format string (scan source via r4++)
r2 = ptr substring pointer (passed to append_text_to_buf_end)
Returns: void (pop{r4,r5}; pop{r0}; bx r0)

Constants:
  CTRL_PREFIX = 0x40   (game string control escape prefix)
  FORMAT_SPEC = 0x25   (= '%')
  TYPE_STR = 0x73      (= 's')

Side effects:
  [r0..r0+N] bytes := expanded string (written byte by byte)
