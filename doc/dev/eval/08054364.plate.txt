Equip card eligibility predicate requiring target slot on opposite side + whitelist pass + slot occupied. Guards: (1) read slot[+2] bit0 vs r1 -- same side rejects; (2) if r2<=4, check_slot_card_is_equip_whitelist(r1,r2) -- fail rejects; (3) gDuelFieldSlots[r1&1][r2] bits[18:0] non-zero. No [+8] check, no set_code check, no type check. More compact than 0x08051abc: only opposite-side + whitelist + occupied. Read-only predicate, no side effects.
Inputs: r0=ptr equipping-card slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..0x14].
Outputs: r0=u32 bool (1=eligible, 0=rejected).
Side effects: none.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868.
