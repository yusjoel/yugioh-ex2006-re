# Naming Proposal: 08106c10

## 提案
- **proposed_name**: render_card_name_text_to_bg
- **confidence**: high

## plate comment (中文, ASCII 标点)
在卡牌信息页面的 BG 图层上渲染当前选中卡的卡名文字. 函数首先清空 0x0600e800 区域 (0x800 halfword), 再通过 card_data_query 查询卡名字符串; 配置 font_jp 渲染管线 (setup_line_buf_with_font_and_align, align=中央), 置 bit6 标志后调用 text_render_wrapper 输出至 BG tile 缓冲区. 若卡名需要两行渲染 (ldrh+0x0e 判断超过阈值), 则清除 bit5 标志后再次配置并渲染第二行. 最终更新 [0x0202f3c0+0x6a] 为按字体宽度折算的行宽. 由 FUN_081067e0 在卡名区域需要刷新时调用.

## 参数签名
- r0: (无外部输入, 函数从全局读取 card_id 与字体状态)
- 返回: r0 = 1 (固定成功)

## 副作用
- [0x0600e800..+0x1000]: zero_fill_by_halfword 清空 (0x800 halfword = 0x1000 字节)
- [0x06009400..+0x2a00]: zero_fill_by_halfword 清空 (0xa8<<6=0x2a00 字节)
- [0x0202f3c0+0x8]: 置 bit1 (渲染状态 flag)
- [0x0202f3c0+0x1e]: 更新 bit2/bit5 (字体宽度/双行标志)
- [0x0202f3c0+0x6a]: strh 行宽值 (按字体宽度计算)
- [0x02006ed0]: 写 0x0202f440 (scene state block 更新)
- [0x02006ed0+0x8]: 更新 DISPCNT/BG0CNT tile 数量 bit (bit6=0x40)
