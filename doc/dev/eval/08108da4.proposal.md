## plate comment (中文, ASCII 标点)
deck_edit 场景中卡牌列表页面的每帧驱动函数. 每帧由 enter_deck_edit_page 注册的场景调度表调用. 首先调用 dispatch_card_list_scene_state 执行当前状态机分派, 将返回值 (是否发生场景转换) 保存; 随后调用 render_card_list_oam_entries 刷新 OAM 精灵列表, 以及两个占位存根以统一帧结束接口. 若 dispatch 返回非零 (即发生状态转换), 则读取 [0x0202a4d0+0x1e] 场景状态字 (5 种 0-4), 通过跳转表分派到对应的后续场景初始化分支: 状态 0 为退出/还原, 状态 1-4 分别写场景类型 ID 1-4 至 [ctx+0x18] 并遍历 card_index 调用 check_card_index_in_format_range 筛选首条有效卡牌, 最终调用 return_one_card_list_stub 清理并切换到下一场景状态. 返回 0 表示帧内无转换, 1 表示本帧完成转换.
