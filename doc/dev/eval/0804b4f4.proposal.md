# Naming Proposal: 0x0804b4f4

- **confidence**: high

## plate comment (中文, ASCII 标点)
判断卡牌 ID 是否属于"场地依赖召唤限制"类型. 以二分搜索树(BST)形式硬编码了全部受限卡的 ID 集合, 并按限制类型分组返回. 当 r0=1 时, caller 后续调用 count_field_copies_of_card 确认该牌的特定场地卡是否已在场; 当 r0=2 时, caller 走另一路径做不同校验(如记录标志位). r0=0 表示普通卡, 无额外限制. 主要在决斗场地放置/使用卡牌的有效性检查流程中被调用.

Constants:
- FIELD_RESTRICTION_NONE = 0 (普通卡, 无场地限制)
- FIELD_RESTRICTION_TYPE1 = 1 (类型 A: 需检查特定场地卡份数)
- FIELD_RESTRICTION_TYPE2 = 2 (类型 B: 走独立旗标逻辑)

## 参数签名
- r0: u16 card_id -- 卡牌数据库 ID, [0x100c..0x18c2] (函数内实际覆盖范围, 来自字面量池边界值)
- 返回: r0 = u8 restriction_type -- 0=无限制, 1=类型 A 场地依赖, 2=类型 B 场地依赖

## 副作用
- 无外部写入; 纯查找函数
