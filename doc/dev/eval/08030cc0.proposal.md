- **confidence**: high

## plate comment (中文, ASCII 标点)
将一张卡片注册到玩家魔法/陷阱区 (zone_type 5..10) 的指定槽位. 入参 r0=player_id [0..1], r1=zone_idx [5..10], r2=card_slot_ptr, r3=counter_ref. 函数执行: (1) 清零目标槽 20 字节; (2) 复制卡片 word 到槽位 word[0]; (3) 递增场地槽计数器; (4) 写入槽位元数据 (slot[2]=serial, slot[3]=0, slot[4]=0); (5) 修改 field8 状态字节 (equip_face_bits); (6) 写入 slot[6] 链接字; (7) 两次调用 write_field_slot_bit_by_player (bit 0x14 和 bit 0x7). 与 place_card_into_monster_zone_slot 共享相同基地址 0x0201c510 和槽位 stride 20 字节, 但 slot[3]=0 且无装备链逻辑, slot[6] 字段不同. 调用方 FUN_08032280 default 分支在 zone_type>4 时路由至本函数.

## 参数签名
- r0: u32 player_id [0..1] - 玩家索引 (bit0 有效)
- r1: u32 zone_idx [5..10] - 魔法/陷阱/场地区槽位索引
- r2: word* card_slot_ptr - 指向待放入卡片的 word 指针 (sp[0x0] 保存)
- r3: word* counter_ref - 计数器/链接字指针 (r8 保存)
- 返回: void (pop {r0}; bx r0 尾调用返回)

## 副作用
- [0x0201c510 + player_id*0x868 + zone_idx*20 .. +19]: 初始化 20 字节槽位
- [slot+0x0]: 写入 card_word
- [0x0201c510 + player_id*0x868 + 0x1cb4]: 槽计数器 +1
- [slot+0x4]: strh serial
- [slot+0x6]: strh 0 (无 equip_qualifier)
- [slot+0x8]: strh 0 (魔法/陷阱区无 card_type_bits)
- [slot+0xc]: str 链接字 (r12)
- field8 byte: 更新 equip_face_bits
