- **confidence**: high

## plate comment (中文, ASCII 标点)
遍历 OAM 手牌条目数组(EWRAM 0x02000006), 统计其中低4位不为0的活跃条目数量. 从 ROM 0x095b7cca 读取条目总数(u16), 从 EWRAM 0x02000006 起每2字节取一条目. r4 初值=0 时: 若条目 [3:0] 字段 (lsls#0x1c / lsrs#0x1c 提取) 大于0则计数+1; r4 != 0 时跳过此判断(仅返回绝对计数 r3). indeg=0, 运行时函数指针调用.

Constants:
- HAND_OAM_COUNT_ADDR = 0x095b7cca (ROM 处手牌条目总数)
- HAND_OAM_BASE = 0x02000006 (EWRAM 手牌 OAM 条目数组基址)
- ENTRY_STRIDE = 2 (每条目 2 字节)
- ACTIVE_MASK = 0xf (低4位字段)

## 参数签名
- r0: u32 filter_mode, 入口 adds r4,r0 -> 若 r4=0: 只计活跃(低4位>0)条目; 若 r4!=0: 绝对计数
- 返回: r0 = u16 count (活跃或绝对条目数)
