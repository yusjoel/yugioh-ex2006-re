# Naming Proposal: 0x080c7af8

## 提案
- **proposed_name**: copy_card_frame_tiles_by_type
- **confidence**: med

## plate comment (中文, ASCII 标点)
将 ROM 中的卡片边框 tile 数据复制到 OBJ VRAM, 并根据卡片类型跳转到对应的内联数据段.
由 FUN_080c8688 (card list scene tick) 调用.
Step 1: 调用 copy_bytes_by_halfword(dst=0x0600a7c0, src=0x09889fd8, count=0x90 halfwords=0x120 bytes),
将卡片边框基础 tile 图形写入 VRAM.
Step 2: 读取 gFontState+0x0a01 (card_type byte [0..13]), 超出范围返回 r0=1.
Step 3: lsls r0,#2 作为跳转表索引, 取指针表 (PTR_PTR_080c7b2c) 对应 entry 到 r0,
然后 .hword 0x4687 = mov pc,r0 (computed-goto) 跳入对应 ROM 内联 OBJ tile 数据段.
Constants: VRAM_FRAME=0x0600a7c0; ROM_TILE_SRC=0x09889fd8; COPY_SIZE=0x120;
CARD_TYPE_OFFSET=gFontState+0x0a01 [0..13]; JUMP_TABLE=0x080c7b30 (14 entries).

## 参数签名
- r0: (void) 无 APCS 输入; 入口 5 条指令全为内部加载 (ldr r0/r1 from literal pool, movs r2)
- 返回: r0 = uint32 两条路径: (card_type <= 13) computed-goto via mov pc,r0 跳入 case 段 (r0 由 case 段自行设置); (card_type > 13) movs r0,#1 返回 1 (oob_signal)

## 副作用
- [0x0600a7c0..0x0600a8df]: 写 0x120 字节卡片边框 tile 数据 (copy_bytes_by_halfword 副作用)
- [各 case 内联代码段]: 具体 VRAM 写入依卡片类型 case 而定 (ROM_INCBIN 段内容)
