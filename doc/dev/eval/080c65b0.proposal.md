## plate comment (中文, ASCII 标点)
驱动卡牌精灵 OAM 动画序列的状态机调度器. 从 gPrng+0x214 (gPrng[0x85]) 读取 u32 帧计数器, 屏蔽符号位后除以 60 (0x3c), 与 179 (0xb3) 比较: 若帧数超过阈值, 读取 gPrng+0x222 (offset 0x222) 处的 zone_activation_flags 字节, 清除 bit0/bit1 后置 bit2 (strb @ 080c65dc) 标记 zone 处于激活动画后期. 随后读取 ctx+0x28 (phase_state 字节) 并进行四路分派: phase 0 调用 tick_duel_field_fadein_step + ensure_card_id_cache_entry + open_card_info_page_from_list (淡入); phase 1 调用 tick_card_info_page_by_state (信息页滚动); phase 2 调用 init_duel_field_vram_layout + render_duel_field_zone_info (VRAM 刷新); phase 3 调用 tick_duel_field_fadeout_step (淡出). 非终结 phase 返回 0 (继续), 终结 phase 返回 1 (序列完成), 并在完成时自增 phase_state (strb). Constants: frame_threshold=0xb3, frames_per_phase_unit=0x3c, zone_activation_bit2=0x4.

## 参数签名

- 返回: r0 = u32 done_flag (0=继续, 1=序列完成)
