equip slot eligibility predicate, indeg=0 (Sub-type A: no fn-ptr reference). r0=slot_ptr (target equip zone), r1=card_ptr (equip card pointer). If card_ptr is null returns 0. Checks if card_ptr is zone-pair restricted (check_card_is_zone_pair_restricted), if restricted returns 0. Checks if card_ptr field5 is nonzero (check_card_field5_is_nonzero), if nonzero: extracts card_ptr[+0x2] bits[6:1] as zone_slot_idx; if zone_slot_idx-5 in [0..5] skips status check, otherwise reads card_ptr[+0x3] bits[5:4] as status_flags. If status_flags nonzero returns 0. Then iterates effect node list stored at slot_ptr[+0x4], calls read_effect_slot_side_and_type for each node comparing against slot_ptr player_id/slot_group; found match returns 1, no match after loop returns 0.

Constants:
- ZONE_IDX_FIELD_OFFSET=5 (zone_slot_idx >= 5 is field zone area)
- ZONE_IDX_RANGE=5 (bits[6:1] - 5 must be in [0..5])
- STATUS_MASK=0x30 (byte[+0x3] bits[5:4])
