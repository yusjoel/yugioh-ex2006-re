## plate comment (中文, ASCII 标点)
精灵怪兽 LP 动画状态机 tick 函数: 读取 gP1LifePoints+0x4a0 处的动画状态字 (0x94*8), 根据当前状态执行对应阶段:

- 状态 0x80: 调用 increment_lp_bar_display_counter; 若对应 player LP != 0 则调用 enqueue_lp_display_row_if_enabled; 返回 0x7f.
- 状态 0x7f: 类似, 但处理另一 player 的 LP 显示; 返回 0x7e.
- 状态 0x7e: 调用 enqueue_lp_display_row_if_enabled 再次入队; 返回 0x7d.
- 状态 0x7d: 调用 decrement_lp_bar_display_counter; 返回 0x0.

调用场景: indeg=0; 通过运行时函数指针分派. 与 tick_lp_compare_init_display_seq (0x08040338) 为同一 tick_*_display_seq 簇.

副作用: 通过 enqueue_lp_display_row_if_enabled 写 LP 显示队列; increment/decrement 修改 LP bar 计数器.

Constants: LP_ANIM_STATE_OFFSET=0x4a0 (0x94*8, gP1LifePoints 基址偏移), player_stride=0x868, LP_OFFSET=0xc, STATE_INIT=0x80, STATE_STEP1=0x7f, STATE_STEP2=0x7e, STATE_FINISH=0x7d.

## 参数签名
- r0: effect_node* ptr  effect node 指针 ([+2] bit0 = player_id)
- 返回: r0 = u32 next_state (0x7f/0x7e/0x7d 推进下一状态, 0x0 表示完成)

## 副作用
- increment_lp_bar_display_counter / decrement_lp_bar_display_counter 修改 LP bar lock 计数
- enqueue_lp_display_row_if_enabled 写 LP 行显示队列
