# Naming Proposal: 0x080ed858

## 提案
- **proposed_name**: write_sprite_row_to_vram_buffer
- **confidence**: med

## plate comment (中文, ASCII 标点)
将一行精灵 halfword 数据写入 VRAM 显示缓冲区, 支持两种行数模式 (<=6 行单通道 / >6 行双通道). 触发条件: 由 FUN_08095498 (topo 782, indeg=14) 和 FUN_0802826e / FUN_08027c98 (player_profile tag) 等调用, 在精灵 tile 数据提交阶段执行. r0 (内部别名 r8) 为缓冲区写起点偏移; r1 为行数. 检查 [0x03000000+0x18] (IWRAM 基址 + 0x18 = 某全局 display 就绪标志), 若为 0 则跳过. 若行数 r7 (=(r1+1)/2) <=6 (cmp r7,#6 bhi): 每行写 strh [gPrng_entry+r3+r5_offset] 到 [dst+r2*2] (6 条 ldrh/strh); 若 r7>6 则走扩展路径: 同样按行写但同时更新 r6 (模 0x3f), 并通过 IME (0x04000208) 关/开中断保护写入, 在写完后更新 gPrng+0x464+8 的计数字段并置位 gPrng+0x584 byte. 副作用: strh 写 gPrng 精灵缓冲区 (<=6 行路径); IME 开关 + strh 写 gPrng+0x464 区 + strb 写 gPrng+0x584 (>6 行路径).

## 参数签名
- r0: u16 dst_offset [0..N] (写入目标在精灵缓冲区中的 halfword 偏移; 入口后 .hword 0x4680=mov r8,r0 保存至 r8, callee-save alias)
- r1: u16 row_count [0..N] (行数; 入口 adds r7,r1,0 -> r7=row_count; (r7+1)/2=半行数)
- (r2 非 APCS 输入: FUN_08027c98 callsite @08027d50 前最后两指令为 adds r0,r6,#0 + movs r1,#0x16; r2 在 bl 前未被显式设置, 不是有效传入参数; 函数为双参数)
- 返回: r0 = u32 (0=skip, 1=done)

## 副作用
- [gPrng+0x464+r_offset+r2*2]: strh 写精灵 tile 行 (<=6 路径)
- [IME] := 0/1 (>6 路径, 中断临时关闭)
- [gPrng+0x46c]: str 更新计数字段
- [gPrng+0x584]: strb 置位标志
