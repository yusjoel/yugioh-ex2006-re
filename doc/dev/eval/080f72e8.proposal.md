# Naming Proposal: 0x080f72e8

## 提案

- **confidence**: high

## plate comment (中文, ASCII 标点)
由 play_ui_effect_15 (card_frame/card_ids/duel_field) 和 play_card_zoom_in (card_ids/duel_field) 调用, 用于向 gPrng sprite table 中的目标 entry 写入 OAM attr 对, 并根据 flip_mode 参数对 x/y 坐标施加对应的偏移量 (±4/±8/±0x10/±0x20 像素), 最后递增 entry 计数器.
流程: (1) push r4-r11; 保存旧 r8/r9/r10; mov r9,r2; mov r10,r3 (保存 r2/r3 到 callee-save 高寄存器); (2) 解包 r0 -> r3=xy_low (低16), r4=r0>>16; r2=r1>>16; sp[0]=r1&0xFFFF; (3) 读 gPrng sprite table count (gPrng+0x1bc+0x400 byte) -- 超 0x80 则 early exit; (4) sp[0]==0x20 则 early exit; (5) 16-entry switchD dispatch on r3 (flip_mode = original r3 via r10): case 0 -> 不偏移; case 0x40 -> y-=4; case 0x80 -> y-=0x10; case 0xc0 -> y-=0x20; ... 各 case 对 xy 坐标施加 subs 偏移; (6) 调 write_oam_entry_attr_pairs(r3=x,r4=y,r2=attr_pair) 写 attr; (7) strb +1 两处计数字节.
副作用: write_oam_entry_attr_pairs callee 写 gPrng sprite 表 attr 字段; strb [entry+count1] += 1; strb [entry+count2] += 1.
Constants: SPRITE_COUNT_OFFSET=0x400, MAX_SPRITE_COUNT=0x80, X_MASK=0x1ff (DAT_080f74cc=0x1ff), TILE_STRIDE=0x401 (DAT_080f74d0=0x401), flip_mode_table=0x4040/0x8000/etc.

## 参数签名
- r0: u32 packed_xy (低16=x坐标, 高16=y坐标; 用于定位 entry 及 flip 偏移基准)
- r1: u32 packed_attr (高16=attr_hi; 低16=sub_type 传 sp; 低16决定 switchD 分支)
- r2: u32 attr2_hi_packed (保存到 r9; 传给 write_oam_entry_attr_pairs r1 参数; 格式: 高16/低16 attr pair)
- r3: u32 attr2_lo_packed (保存到 r10; 传给 write_oam_entry_attr_pairs r2 参数; flip_mode switchD key)
- 返回: r0 = void

## 副作用
- write_oam_entry_attr_pairs callee 写 gPrng sprite 表 attr 字段 (4 halfwords).
- [gPrng sprite entry + tile_count_offset] += 1 (通过 strb)
- [gPrng sprite entry + DAT_080f74d0(0x401) offset] += 1 (通过 strb)
