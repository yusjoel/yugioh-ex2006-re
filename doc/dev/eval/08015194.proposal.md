# Naming Proposal: 0x08015194

- **proposed_name**: fill_gl_palram_buf_0xf0
- **confidence**: high

## plate comment (中文, ASCII 标点)
由 gl_state_init 初始化链的末尾环节 FUN_08015160 调用, 负责将调色板 RAM 子区域全部填充为 0xf0(半字 fill 模式). 触发场景: 每次 GL 状态初始化时, 先 bios_cpu_set 清零 gl state struct, 再由 FUN_08015160 设置高字节标记, 最后调用本函数以 0xf0 填充目标区域 0x200 字节, 确保调色板条目处于已知默认值状态(非零). 副作用: bios_cpu_set fill 写入 EWRAM 0x02023490 起始 0x100 半字(0x200 字节).

## 参数签名
- r0: void (入口被 mov r0, sp 覆盖, 实际 src = sp 指向的字面量 0xf0; 无 APCS 参数输入)
- 返回: 无返回值(pop {r0}; bx r0 为函数返回机制, 非语义返回值)

## 副作用
- [0x02023490..+0x200]: 以 0xf0 填充 0x100 个半字 (GL state struct 调色板子区域默认值)
