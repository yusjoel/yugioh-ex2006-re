# Naming Proposal: 0x080c2880

## 提案
- **proposed_name**: init_field_slot_aob_ctx_b
- **confidence**: med

## plate comment (中文, ASCII 标点)
初始化 duel_field slot 的动画对象 (AOB) 上下文结构, 对应 op_code=0x0b 场景 (dispatch_card_display_op case_b). 先从 DAT_080c28fc (0x0201fe60) 取 slot 基础结构指针, 将 r1 的低 8 位 <<3 后作为 palette 偏移字段写入 [base+4][10:3], 再将 r0 存入 [base+8], r2 存入 [base+c]. 随后对 [base+0x48] 子结构调用 init_aob_ctx_from_ptnsect(ptr, r1_dat, r2_dat, 1). 完成后置位 [base+0x48+0x13] bit0, 再根据 gP1LifePoints[0x1ce8]..[gDuelActivation+4]^player_id 比较写 init 参数 (2 或 3), 最终调用 init_aob_ctx_with_anm_entry 并清理 [base+0]/[base+2] 的高位. Constants: base_struct=0x0201fe60, mask=0xfffff807, ptnsect_id=0x09889b80^0x00800002, gP1LP_offset=0x1ce8, gDuelActivation=0x0201e2a0.

## 参数签名
- r0: ptr arg0 传给 [base+8] (含义随场景, 通常为 data pointer, [0..0x03ffffff])
- r1: u8 palette_slot 低 8 位提取 [0..0xff], <<3 写入 base[4] 位域 [3..10]
- r2: ptr arg2 传给 [base+c] (通常为 sprite sheet pointer)
- 返回: r0 = void, 无返回语义 (bx r0 从栈恢复 lr)

## 副作用
- [0x0201fe60+4] [10:3] := r1&0xff<<3 (palette 字段写入)
- [0x0201fe60+8] := r0 (data ptr 写入)
- [0x0201fe60+c] := r2 (sprite ptr 写入)
- [0x0201fe60+0x5b] bit0 := 1 (init done flag)
- [0x0201fe60+0] [高位清除]: ands DAT_080c2918 (0xfff807ff)
