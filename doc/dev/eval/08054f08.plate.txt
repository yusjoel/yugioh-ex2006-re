check_equip_slot_eligible_by_spell_type_and_prereqs
Equip slot eligibility predicate verifying target slot card is spell type + prerequisites + type compatible.
Callers: query_slot_card_type_eligibility (0x0803670c), check_card_type_is_spell (0x0804adc8).
Checks in order: (1) slot_idx <= 4; (2) gDuelFieldSlots[player_id&1][slot_idx] card_icid != 0 (occupied);
(3) check_card_type_is_spell(card_icid) != 0 (target slot is spell card);
(4) [slot+8] != 0 (valid); (5) query_slot_card_type_eligibility == 0 (type compatible).
Returns 1 if all pass. Pure predicate, no external writes.
Constants: SLOT_IDX_MAX=4, gDuelFieldSlots=0x0201c510, player_stride=0x868
Inputs: r0=ptr equip_card_slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..4]
Returns: r0=u32 bool (1=eligible, 0=rejected)
