# Naming Proposal: 0x080fa4cc

## 提案
- **proposed_name**: suppress_display_output
- **confidence**: high

## plate comment (中文, ASCII 标点)
发布版 4 参数空输出函数. 函数体: push {r0,r1,r2,r3} 将所有 APCS 入参压栈, add sp,#0x10 立即弹出,
bx lr 返回. 等效于接收 4 个参数后立即丢弃, 无任何输出或副作用. 调用方包括 banlist/settings 初始化
(0x08017a24, r0=ptr, r1=pixel_offset), play_ui_effect_2f (0x080c1e9c, r0=ptr, r3=context),
FUN_080eb4d4 / FUN_080ed550 (游戏各模块循环内 r0=ptr 传入). 用于在 release build 中消音调试输出
(类似 printf/log stub). 与 suppress_assert_report (0x080fa4dc) 同为发布版 noop 族.

Constants:
- 无魔数.
