## plate comment (中文, ASCII 标点)
在 gEffectContext (0x0201e4f0) 的槽属性表中查找与目标调色板 ID (r0) 匹配的条目.
表项步长为 2 字节, 每项高 8 位 (bits[15:8]) 存储调色板 ID.
若找到匹配项, 将该项的槽索引写入 gEffectContext+0x8 (当前激活槽).
若未找到, 写入 -1 (rsbs r0,r0,#0 = 0-1 = 0xffffffff) 到 gEffectContext+0x8.
调用方 (0x0808081a, 0x0808312a) 在需要切换激活槽前调用此函数.
Constants: gEffectContext=0x0201e4f0, slot_table_offset=0x82*8=0x410, item_stride=2, palette_id_shift=8, SLOT_IDX_FIELD=0x8, NOT_FOUND=-1 (0xffffffff).

## 副作用
