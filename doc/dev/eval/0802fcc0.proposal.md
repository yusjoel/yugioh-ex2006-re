## plate comment (中文, ASCII 标点)
检查当前效果激活上下文 (gDuelEffectCtx, 0x0201bb90) 中是否存在 value==r2 的链节点. 先将输入的 (r0, r1) 与上下文的 [+0x0] 和 [+0x1c] 字段比较: 若两者均匹配则使用 side=0 的区域链 (0x0201bc54[0], [+0xa]=chain_head), 否则使用 side=1 的区域链. 再调 find_node_by_value 查找 value==r2 且 zone_type<=5 的节点. 找到返回 1, 未找到返回 0. 常见场景: 效果连锁判断时检查某卡效果 ID 是否已在激活方/非激活方的效果上下文链中登记.

Constants:
- 0x0201bb90 = gDuelEffectCtx (当前效果激活上下文基址)
- 0x0201bc54 = gDuelEffectCtx+0xc4 (上下文内置区域链数组, stride=20 bytes)
- [gDuelEffectCtx+0x0] = activation_player (激活玩家标识)
- [gDuelEffectCtx+0x1c] = context_slot_ref (激活槽参考值)

## 参数签名
- r0: u32 query_player -- 与 gDuelEffectCtx[+0x0] (activation_player) 比较的玩家标识
- r1: u32 query_slot_ref -- 与 gDuelEffectCtx[+0x1c] 比较的槽参考值 [0..11]
- r2: u16 value -- 目标值, 与链中节点 [node+0] 比较
- 返回: r0 = u32 bool -- 1 表示对应上下文链中存在 value 节点, 0 表示不存在
