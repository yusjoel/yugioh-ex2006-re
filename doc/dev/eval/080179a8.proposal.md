# Naming Proposal: 0x080179a8

## 提案
- **proposed_name**: encode_char_to_line_buf
- **confidence**: med

## plate comment (中文, ASCII 标点)
Function: 接收单个 Shift-JIS 字符码 (r0 低 16 位), 通过 char_code_to_glyph_index 查询字形索引; 若无字形则直接更新计数器返回. 若有字形: 在栈缓冲区构建 2 字节字符表示 (高字节+低字节), 调用 append_text_to_buf_charlen 追加到输出行缓冲区 r1(=r9), 并递增 r5 (行内字符计数) 和 r7 (全局字符计数). 每当 r5 达到 11 (0xb), 额外追加一个从 ROM 常量 0x09e3b2b4 读取的分隔符字节序列 (3 字节) 并重置 r5=0. 函数结束时将 r5 和 r7 分别写回 *r2 和 *r3.
Trigger: 由 FUN_08017a24 (banlist/settings 字体渲染) 逐字符处理 JP 字符串时调用.
Side effects: append_text_to_buf_charlen 向输出缓冲区 (r9) 追加字节; *r2 := r5 (行内字符计数更新); *r3 := r7 (全局计数更新).

Constants:
- LINE_BREAK_INTERVAL=0xb=11 (每 11 字符插入换行分隔符)
- LINE_BREAK_BYTES=0x09e3b2b4 (ROM 地址, 3 字节换行分隔符序列)

## 参数签名
- r0: u16 char_code Shift-JIS 字符码 (低 16 位有效) [0..0xffff]
- r1: u8* line_buf_ptr 输出行缓冲区 (透传到 append_text_to_buf_charlen; via r9)
- r2: u32* line_char_count_ptr 行内字符计数指针 (读写, *r2 = r5 on entry, updated on exit)
- r3: u32* global_char_count_ptr 全局字符计数指针 (读写, *r3 = r7 on entry, updated on exit)
- 返回: void (pop {r0}; bx r0 Pattern-B exit)

## 副作用
- [line_buf_ptr + offset]: 追加 2 字节字符表示 (via append_text_to_buf_charlen)
- [line_buf_ptr + offset]: 若达到 11 字符则额外追加 3 字节换行分隔符
- [*r2] := r5 (行内字符计数)
- [*r3] := r7 (全局字符计数)
