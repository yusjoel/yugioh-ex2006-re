# Naming Proposal: 0x080904f4

- **confidence**: high

## plate comment (中文, ASCII 标点)
在效果节点查找表中用二分搜索定位指定卡牌的效果节点描述符. 从 [r0+0] 读取 card_id (u16), 从 [r0+3] bits[5:2] 读取效果类型 (4 bit, [0..3]); 按类型分发到四张排序表: type=0 -> 0x09e3f19c (0x2a3 项), type=1 -> 0x09e430fc (0x187 项), type=2 -> 0x09e455bc (0x8e 项), type=3 -> 0x09e46324 (0xb7 项). 在选定表中对 card_id 做标准二分搜索 (每项 0xc 字节, 首 word 为 key). 找到则返回节点描述符指针; 未找到返回 0. 函数本身是纯查询叶子函数. Constants: entry_size=0xc, type_max=3.

## 参数签名

- 返回: r0 = ptr effect_node_descriptor (0 若未找到)
