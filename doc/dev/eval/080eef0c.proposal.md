- **confidence**: med

## plate comment (中文, ASCII 标点)
在 ROM 中的 card attribute 表 (0x09821e04, stride=0x16=11*2 bytes/row) 查找给定 card index
并返回特定字段 u16 值.
流程: r1=r0 (card_index); 若 r1 <= 0xfa6 (=4006, 边界检查) 返回 0;
否则: r1 += 0xfffff059 (= r1 - 0xfa7 = r1 - table_base_index);
row = r1; col_offset = (0xb*row + 4) * 2 (= row*22 + 8);
base = 0x09821e04 + col_offset + table_base; ldrh [result];
若 result == 0xffff (sentinel) 返回 0, 否则返回 result.
兄弟函数 FUN_080eef44 (col_offset=(0xb*row+3)*2=row*22+6),
FUN_080eef70 (col_offset=(0xb*row+4)*2, 区别未知).
Constants: table_base=0x09821e04, index_min=0xfa7 (boundary check via cmp > 0xfa6),
row_stride=0xb*2=22 bytes, col_offset_A=8 (halfword 4 in row), sentinel=0xffff.

## 参数签名
- r0: u32 card_index; 卡牌索引; [0xfa7..0x1fff]; <= 0xfa6 直接返回 0; 上界由 card_id_mask=0x1fff 确定 (card_id 13-bit 字段)
- 返回: r0 = u16 attribute_value (0=不在表中或 sentinel 0xffff; 非零=属性值)

## 副作用
- 无外部写入; 纯只读 ROM 表
