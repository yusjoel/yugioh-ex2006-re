Expands 4bpp color index (r1) into pixel masks MSB-nibble-first and OR-writes into VRAM dst (r0) row by row. Checks gPrng+0x14 bit7 (HIGH_COLOR_MODE_FLAG=0x80): if set, forwards to blit_tile_color_to_vram_region; otherwise expands nibble to double-nibble then double-byte, iterates outer loop row 0..row_count-1 (from gPrng+0x8), inner loop 16 columns, AND-mask then OR-write each halfword. Called by font_jp render path (0x080dced0) for per-row tile coloring.

Params: r0=u16* dst VRAM row base, r1=u16 color 4bpp index [0x0..0xf]. Returns void (pop{r0};bx r0).

Side effects: writes VRAM[dst..dst+row_count*0x80] halfwords (OR pattern per nibble).

Constants:
HIGH_COLOR_MODE_FLAG = 0x80 (gPrng+0x14 bit7)
MASK_NIBBLE0 = 0xfff0 (AND mask bits[7:4])
MASK_NIBBLE1 = 0xff0f (AND mask bits[11:8])
MASK_NIBBLE2 = 0xf0ff (AND mask bits[15:12])
MASK_NIBBLE3 = 0x0fff (AND mask bits[3:0])
