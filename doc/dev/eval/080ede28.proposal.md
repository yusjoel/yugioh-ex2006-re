# Naming Proposal: 0x080ede28

## 提案
- **proposed_name**: teardown_sio_link_session
- **confidence**: high

## plate comment (中文, ASCII 标点)
SIO 连接轻量级关闭/断开函数, 由 pack 场景状态机和 campaign step 处理器在 SIO 链路需要重置时调用. 执行: (1) 清零 IME (禁用中断); (2) ldrh IE, ands 0x0000ffdf (屏蔽 bit5 = serial 中断位), strh 回写 (禁用 serial 中断); (3) strh 1,[IME] 恢复中断使能; (4) str 0,[0x03000000+0x18] 清除 SIO 中断回调指针; (5) bl reinit_sio_link_with_timer3 重置 SIO 链路和 Timer3. 与 setup_sio_link_session (0x080edd90) 互为对称: setup 设置 IE serial 位并注册回调, teardown 清除 IE serial 位并注销回调.

Constants:
- IE_SERIAL_MASK_OFF = 0x0000ffdf (DAT_080ede54, = ~0x20, 清 serial bit)
- IWRAM_SIO_BASE = 0x03000000 (DAT_080ede58)
- SIO_CALLBACK_FIELD = +0x18
