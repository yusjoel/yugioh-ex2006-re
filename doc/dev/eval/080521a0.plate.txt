Equip slot eligibility predicate, called via function pointer (indeg=0). Unlike most variants, requires slot_idx > 4 (cmp r4,#4; ble fail -- slot_idx <= 4 rejected). Sequence: (1) Compute gDuelFieldSlots[r6&1][r4] slot addr, check bit19 occupancy (0 -> reject) and [slot+8]!=0 (0 -> reject). (2) cmp r4,#4; ble fail (re-confirm slot_idx > 4). (3) check_card_equip_eligible_for_slot(r5,r6,r4,r3=0) (r3=0, unlike most variants which use r3=1). (4) Read [r5+0x14]: bit0 (side) vs r6, byte[+0x14] player, bits[15:8] vs r4. (5) Extract set_code from [r5+4] bits[14:8], call find_field_slot_by_set_code_global(set_code); reject if < 0. (6) Unpack return (byte0=player2, byte1=slot2), call find_zone_chain_node_by_card_id_pair. Return 1 on all pass.

Constants:
- gDuelFieldSlots = 0x0201c510
- player_stride = 0x868
- zone_entry_size = 0x14
- SLOT_IDX_MIN_GUARD = 5 (slot_idx <= 4 rejected)
- setcode_extract: [r5+4] bits[14:8] = lsls #0x11; lsrs #0x17
