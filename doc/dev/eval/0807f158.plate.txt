Two-step operation: enqueue_field_slot_sprite_with_state_update and test_equip_target_slot_zone11. r1=effect_node_ptr (via .hword 0x4647=mov r7,lr + .hword 0x4680=mov r8,r0), r0=caller-set ptr. First reads from gDuelFieldSlots (0x0201c510) indexed by [byte2] player_id and slot_idx to compute two zone entry addrs; extracts tile_col_count (bits[9:2]) and flip_bit (bit14); compares tile_col_count*2+flip_bit with slot[+4] bits[7:1] (capacity); if equal calls enqueue_field_slot_sprite_with_state_update(player_id, slot_idx, tile_col_count); then re-extracts player_id/slot_idx and calls test_equip_target_slot_zone11. Side effects: write state and enqueue OAM sprite via enqueue_field_slot_sprite_with_state_update; run zone11 equip target check via test_equip_target_slot_zone11. Constants: gDuelFieldSlots=0x0201c510, PLAYER_STRIDE=0x868, BYTE4_FLAGS: bit1-7=capacity, bit8=mark.
