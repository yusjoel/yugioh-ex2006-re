Accepts effect_node_ptr (r0). Reads [r0+0xc] hword (effect type code), dispatches two paths:

type == 1: reads [r0+2] bit0 (player_id), calls apply_lp_delta_if_slot_active(1-player_id, 1, 1) to apply LP change; returns 0.
type == 2: reads [r0+2] bit0 (player_id), calls enqueue_equip_zone_sprite_attr_full(1-player_id, r1=2, r2=1) to enqueue full equip zone sprite attributes; returns 0.
Other types: returns 0 directly.

Selects LP application or sprite enqueue path based on effect slot [+0xc] type field.

Side effects: conditionally triggers LP change via apply_lp_delta_if_slot_active (type=1 path); writes sprite queue via enqueue_equip_zone_sprite_attr_full (type=2 path).

Constants:
TYPE_LP_APPLY = 1
TYPE_SPRITE_ENQUEUE = 2
LP_DELTA_AMOUNT = 1
SPRITE_PLAYER_FLAG = 2
