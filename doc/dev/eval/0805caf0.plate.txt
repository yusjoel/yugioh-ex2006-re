Type-dispatch equip slot eligibility predicate branching on type_code 0x80 vs spell-500.
Extracts card_entry[+2] bits[11:6] via mask 0xfc0 as type_code.
If type_code == DIRECT_EQUIP_TYPE (0x80):
  Extracts player_id (bit0), slot_group (bits[5:1]), card_id ([+0] halfword).
  Calls check_slot_has_node_by_card_id(player_id, slot_group, card_id) and returns result.
If type_code != 0x80:
  Calls check_spell_type500_deck_states_differ(card_entry) and returns result.

Constants:
  TYPE_MASK         = 0xfc0  (0xfc<<4, extracts bits[11:6] from halfword[+2])
  DIRECT_EQUIP_TYPE = 0x80

Inputs:  r0 = ptr equip_card_entry ([+2] bit0=player_id [0..1]; bits[5:1]=slot_group [0..31]; bits[11:6]=type_code; [+0]=card_id u16)
Returns: r0 = u32  (pass-through; 1=eligible, 0=not eligible)
Callees: check_spell_type500_deck_states_differ (0x0805e09c), check_slot_has_node_by_card_id (0x0802fdf4)
Callers: indeg=0; grep ".word 0x0805caf1" asm/all.s -> 0 hits (no fn-ptr ref)
