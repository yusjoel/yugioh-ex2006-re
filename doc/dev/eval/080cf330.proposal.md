# Naming Proposal: 0x080cf330

## 提案
- **proposed_name**: init_card_stat_tile_and_scroll
- **confidence**: med

## plate comment (中文, ASCII 标点)
被卡片显示状态机 (switchD_080c79b4) case 0xa 调用, r0 为卡片索引 (ushort). 初始化卡片数值显示区域: (1) zero_fill_by_halfword 清空 0x06014000; (2) tile_2d_row_copy 从 ROM 0x0988ab18 到 VRAM 0x06010c00 (1列x1行); (3) 读 gFontState 标志位 (0xa17/0xa18), 仅当双标志均为 0 时写入三个 scroll 寄存器 (gFontState+0x0a06/0x0a08/0x0a0a), 值来自 r0 分解后的三字节 (r5=低字节, r4=高字节, r6=中字节); (4) strb 0xa 写完成标志 [gFontState+0x0a01]. 副作用: BG VRAM, gFontState scroll 字段.

## 参数签名
- r0: u32 scroll_pack - 打包的 scroll 三字节参数 (高16bit=r6中字节, 中8bit=r5低字节, 低8bit=...), [0..0xFFFFFF]
- 返回: void (无返回值)

## 副作用
- [0x06014000..0x06017FFF]: zero_fill
- [0x06010c00..+tile]: tile_2d_row_copy from ROM 0x0988ab18
- [0x0201f440+0x0a06]: 条件 strh r5 (scroll value 0)
- [0x0201f440+0x0a08]: 条件 strh r4 (scroll value 1)
- [0x0201f440+0x0a0a]: 条件 strh r6 (scroll value 2)
- [0x0201f440+0x0a01]: strb 0xa (完成标志)
