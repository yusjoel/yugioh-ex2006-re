# Naming Proposal: 0x08105784

## 提案
- **proposed_name**: check_card_index_in_format_range
- **confidence**: med

## plate comment (中文, ASCII 标点)
验证给定的卡牌序号是否在当前卡组列表槽位允许的格式范围内. 入参 r0 为待检卡牌在列表中的线性序号. 函数读取 [0x0202a4d0+0x18] 槽类型字段: 若为 4 (CUSTOM 格式), 则调用 get_card_data_format_id 获取卡牌的格式 ID 并与序号比较; 对其他槽类型则直接以固定上界 (CARD_LIST_MAX_INDEX 或 [0x0202a4d0+0x24]+0xc) 对序号做范围检查. 由 FUN_08108da4 (deck_edit 状态机, 内嵌卡牌列表遍历) 在初始化时逐条调用以筛选可显示的卡牌条目. 返回 1 表示序号合法, 0 表示越界.

## Constants:
- CARD_LIST_MAX_INDEX = 0x3b (59) -- 非 CUSTOM 格式时卡牌列表序号的固定上界
- IWRAM_CARD_BITMAP_BASE = 0x02000000+0x6c28 -- IWRAM 内卡牌可见性位图基址 (CUSTOM 格式路径使用)

## 参数签名
- r0: s32 card_index -- 候选卡牌线性序号, [0..max_card_count-1]
- 返回: r0 = u32 is_valid (1=在范围内, 0=越界)

## 副作用
无外部写入.
