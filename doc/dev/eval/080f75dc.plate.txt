Copies the content of one 8x8 4bpp tile slot in BG VRAM to another. r0=dst tile index, r1=src tile index; each multiplied by 32 (lsls/lsrs via <<16>>11) and added to BG VRAM base 0x06010000, then copy_bytes_by_halfword copies 32 bytes. Called by FUN_080f7614 (0x080f7614, batch tile row copy upper function).

Constants:
- BG_VRAM_BASE = 0x06010000 (BG tile data bank 1)
- TILE_SIZE = 0x20 (32 bytes, 8x8 4bpp tile)
- TILE_SHIFT = 0xb (r0<<16>>0xb = r0*32)

Inputs: r0=dst_tile_index [0..0x3ff], r1=src_tile_index [0..0x3ff]
Returns: void (pop{r0};bx r0 Sub-case E)

Side effects:
- [BG_VRAM_BASE + dst_tile_index*32 .. +32): overwritten with 32 bytes from source tile
