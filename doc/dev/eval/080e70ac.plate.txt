Per-frame tick that updates scroll position fields of the pack scroll list.
Reads gMenuState[0x29] bits[6:3] (STEP_MASK=0x78); if all zero: returns 0 (scroll done).
If bit2 (0x4) set: reads [+0x26] and signed[0x2c]*8, computes new position written to [+0x26];
  updates [+0x25]; calls sync_scroll_highlight_to_gprng.
Otherwise (bits[1:3] set): only updates [+0x27] = ldrsh[0x2c]*8 + [0x27].
Decrements bits[6:3] step count via (-1 mod 0xf) << 3 and writes back to [0x29].
If bits[6:3] cleared: updates [0x28] offset and [0x27] position.
Checks bit2 of [0x29] to decide whether to call sync_state_and_init_sprite(0).
Called by FUN_080e7188 (pack scroll frame main controller).

Constants:
  NAV_BYTE_OFF = 0x29      (gMenuState[0x29] navigation flag byte)
  POS_A_OFF    = 0x26      (scroll position field A)
  POS_B_OFF    = 0x25      (scroll position field B)
  POS_C_OFF    = 0x27      (scroll position field C)
  STEP_MASK    = 0x78      (bits[6:3] step counter)
  FULL_MASK    = 0xfffffc7f ([0x28] clear mask)

Inputs: none (reads gMenuState directly; r1 loaded from DAT).
Returns: r0=u32 (1=scroll still active, 0=scroll complete; pop {r1}; bx r1).
Side effects: updates gMenuState[0x25/0x26/0x27/0x28/0x29] scroll position fields.
