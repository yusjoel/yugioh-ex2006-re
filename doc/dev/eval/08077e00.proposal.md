# Naming Proposal: 0x08077e00

## 提案
- **proposed_name**: enqueue_equip_zone_sprite_by_state_and_equip_count
- **confidence**: med

## plate comment (中文, ASCII 标点)
从装备区上下文 [r0+0x2] 提取玩家 ID (bit0) 和槽位索引 (bits[6:2]), 计算两路装备区数组索引 (x*5*4 = x*20). 通过 r8 (caller-frame 继承寄存器, 非 APCS 参数) 访问 IWRAM 装备槽数组基址 (0x0201c510). 汇总当前帧装备计数 r2 (bit5 flag + bit26:24 slot count), 与上下文 [+0x4] bits[14:8] 的期望计数比较. 不匹配则返回. 匹配后读取 LP 状态机 (0x0201b290[0x94<<3]): 0x80 路径调用 set_lp_row_type18_with_value; 0x7f 路径读取 DWORD_08077ec8=0x1d78 偏移后调用 enqueue_sprite_attr_with_mode (mode=3).

Constants:
- EQUIP_SLOT_STRIDE=0x868 (每玩家装备槽步长)
- EQUIP_SLOT_BASE=0x0201c510 (装备槽数组基址, 经 r8 继承)
- LP_STATE_BASE=0x0201b290 (LP 状态机基址)
- LP_STATE_OFFSET=0x94<<3=0x4a0 (状态变量偏移)
- SPRITE_DATA_OFFSET=0x1d78 (精灵数据在 r8 的偏移, DWORD_08077ec8)
- STATE_0x80=0x80 (set_lp_row_type18_with_value 触发状态)
- STATE_0x7f=0x7f (enqueue_sprite_attr_with_mode 触发状态)

## 参数签名
- r0: ptr equip_zone_ctx_ptr -- 装备区上下文指针 ([+0x2] bit0=player_id, bits[6:2]=slot_idx; [+0x4] bits[14:8]=expected_count)
- 返回: r0 = void (pop {r1}; bx r1 机制, r0=0 固定)

## 副作用
- 经 set_lp_row_type18_with_value 或 enqueue_sprite_attr_with_mode 写 OAM/LP 显示缓冲
