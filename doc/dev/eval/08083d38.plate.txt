Equip card display 3-state machine frame stepper. Reads IWRAM [0x0201b290+0x4b0] state (0/1/2). State 0: enqueues sprite from player_base[0/0x1c]; if confirm_flag==1 calls select_equip_target_slot returns 0, else step+1. State 1: count_effect_node_zone_activations==0 returns 1; else dispatch_equip_card_display_op_by_card_id + set mode, step+1. State 2: check_activation_display_state_is_confirmed confirmed then enqueue sprite step+1, else step-1. Others return 1. Dispatched via equip activation display state machine fn-ptr table.
