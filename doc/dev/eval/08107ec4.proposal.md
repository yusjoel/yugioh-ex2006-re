# Naming Proposal: 0x08107ec4

## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
被 FUN_080fefaa (display/blend/window/bg/card_stats) 和 FUN_080ff94c (card_stats) 两处调用, 用于在卡牌统计面板中渲染卡牌属性徽章 (attribute badge) 的 OAM 精灵. 函数首先对 [0x0202f3c0+0x5a..+0x5d] 四字节执行 OR 0xFF (标记已用 tile 槽), 再读取 [0x0202a4d0] 作为卡牌索引, 调用 read_card_list_field_by_index 取属性字段值后减 ATTRIBUTE_FIRST_VALID(=2), 对结果做 9 路 switch (case 0-8) 分派不同的属性类型处理块. 各 case 从 card_stats_table 按行读取对应属性的 tile 坐标数据 (11 列, 含 0xffff 边界检查), 以 __divsi3/__modsi3 计算 tile 行列后调用 dispatch_oam_write_by_mode 写 OAM 精灵; tile 偏移上界为 BADGE_TILE_OFFSET_MAX=0xFA(=250).

Constants:
  ATTRIBUTE_FIRST_VALID   = 2     // card_attribute enum: first valid value is 2; subtract before switch
  BADGE_TILE_OFFSET_MAX   = 0xFA  // =250; upper bound tile offset for attribute badge tile_id loop

## 参数签名
- r0: s16 card_entry_index 卡牌列表索引 [0..list_length-1]
- 返回: r0 = u32 1 (固定)

## 副作用
- [0x0202f3c0+0x5a] ~ [+0x5d]: 各字节 OR 0xFF (4 字节, 标记 tile 槽占用)
- [0x0202f3c0+0x50] := 0 (strh), [+0x56] := 0, [+0x58] := 0, [+0x60] := 0 (初始化 4 个 halfword)
- 间接通过 dispatch_oam_write_by_mode 写 OAM 精灵
