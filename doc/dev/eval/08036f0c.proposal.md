# Naming Proposal: 0x08036f0c

## 提案
- **proposed_name**: insert_card_into_field_list_by_zone_desc
- **confidence**: high

## plate comment (中文, ASCII 标点)
在指定玩家的场上槽位列表中按区域描述符查找目标卡, 并通过 write_word_from_deref_src + strh 将其插入至目标位置.
r0 = player_side (整体 u32 传入, bit0 有效), r1 = target zone_desc (u16, [0..0xffff]).
读 gP1LP+player*0x868+0x1c 为场上槽计数; 场上槽数组 A 基址 gP1LP+player*0x868+0x5d0 (0xba<<3),
辅助数组 B 基址 gP1LP+player*0x868+0x788 (0xf1<<3).
内部循环: 从 count-1 向 0 逐步比较各槽 zone_desc (同 08036e40 位域提取法);
命中后调用 write_word_from_deref_src + strh 拷贝, 并将区域描述符写入目标偏移 r9;
未找到则后退步进继续. 由主状态机各阶段在需要将特定卡片插入场上槽列表时调用 (zone type=0xf).
Constants: player_stride=0x868; field_count_offset=0x1c; field_array_a_offset=0x5d0 (=0xba<<3);
field_array_b_offset=0x788 (=0xf1<<3); list_base=0x0201cab0; list_neg_offset=0xfffffa4c (-0x5b4).

## 参数签名
- r0: u32 player_side (bit0=[0..1]) - 玩家索引; str r0,[sp,#0x0] 保存后 ldr 取回
- r1: u16 zone_desc [0..0xffff] - 目标区域描述符; lsls #0x10/lsrs #0x10 提取低 16 位; str r1,[sp,#0x4]
- 返回: r0 = void (pop{r3..r7;r4..r7};pop{r0};bx r0 尾返回)

## 副作用
- [gP1LP+player*0x868+0x5d0 + idx*4..end]: 通过 write_word_from_deref_src 移位场上槽条目
- [gP1LP+player*0x868+0x788 + idx*2..end]: 通过 strh 移位区域描述符辅助数组
- [sp+0..0xc]: 栈局部临时变量, 不计入外部副作用
