# Naming Proposal: 0x080146cc

## 提案
- **proposed_name**: update_brightness_fade_flag
- **confidence**: high

## plate comment (中文, ASCII 标点)
由 gl_set_brightness 在设置亮度目标值后调用, 根据亮度状态结构体(EWRAM 0x02023480)中的当前值(offset +0)和目标值(offset +1)符号确定 fade 状态标记, 并写回 offset +8. 若两个值均 >= 0(正常范围), 则将 +8 的低 2 位清零并置 bit1(=fade 激活); 若任一值 < 0(无效/钳制), 则置 +8 为 3(= idle/disabled). 副作用: [0x02023480+8] 写入新 flag 字节.

## 参数签名
- r0: void (入口第 1 条为 ldr r2, DAT_080146ec 加载内部地址, r0 在入口后被 movs r0,#0x1 覆盖; 无 APCS 参数)
- 返回: r0 = u8 新 flag 值 (写入 [0x02023480+8] 后同步返回, gl_set_brightness 不使用)

## 副作用
- [0x02023480+0x8]: 写入 brightness fade flag 字节 (bit1=fade 激活, 0x3=idle)

## 行级注释 (≤ 30 行精华)
- @ 080146cc: 加载 gl_bright_state 基址 0x02023480 到 r2
- @ 080146ce: r0 = 1 (offset 索引)
- @ 080146d0: r0 = [r2+1] (signed) = brightness 目标值; < 0 → idle
- @ 080146d6: r0 = [r2+0] (signed) = brightness 当前值; < 0 → idle
- @ 080146de: r0 = -4 (= 0xFFFFFFFC); 用于清 flag byte 低 2 位
- @ 080146e0: r0 = 0 - 4 = -4 (rsbs)
- @ 080146e2: r1 = [r2+8] = 当前 flag 字节
- @ 080146e4: r0 = r1 & (-4) = 清低 2 位
- @ 080146e6: r1 = 2 (fade 激活 bit)
