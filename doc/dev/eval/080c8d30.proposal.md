# Naming Proposal: 0x080c8d30

## 提案
- **proposed_name**: refresh_zone_effect_buff_cache
- **confidence**: med

## plate comment (中文, ASCII 标点)
读取 gPageState[+0x210] (0x02023340) 中的打包 u16 渲染状态 (bit7=player_flag, bits[0..6]=mode, bits[8..14]=sub_idx), 解包为 player_flag(r0), mode+sub_idx(r1), 和缓存表地址 0x020230c4(r2), 然后调 FUN_0803a7f0 重新计算当前视图下所有格位的效果 ATK/DEF 增减量并写入缓存. 4 处调用方均在 refresh_duel_field_zone_info 或场景切换之后立即调用 (与 FUN_080c8bf0 生命点渲染 + FUN_080c8904 sprite 渲染成组出现), 负责在 zone 显示切换后同步刷新效果增减量缓冲.

Constants:
- gPageState = 0x02023130
- render_state_offset = 0x210 (0x84 << 2)
- packed_addr = 0x02023340
- effect_buff_cache = 0x020230c4
- bit7 = player_flag; bits[0..6] = mode; bits[8..14] = sub_idx

## 参数签名
- 无输入参数 (从 gPageState 自行读取状态)
- 返回: r0 = FUN_0803a7f0 的返回值 (通常 void/unused; 调用方均不使用返回值)

## 副作用
- [0x020230c4..]: FUN_0803a7f0 将各格位效果 ATK/DEF 增减量写入此缓存 (具体范围由格位数决定, 每 zone 22 字节)
