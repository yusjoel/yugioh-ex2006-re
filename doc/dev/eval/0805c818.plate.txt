Validate equip card target zone legality, dispatching different effect slot checks based on target card_id range. First verify r1 (target_ptr) non-null and player_id (bit0 XOR byte[+3].bit5) differs (cross-field pair). Then binary search target_ptr[+0] card_id into dispatch paths: 0x0ffa, 0x1246 directly read effect slot; 0x131c-0x1685/0x1686 call read_effect_slot_side_and_type; special cards 0x149b/0x1364/0x134d/0x16b8 have dedicated paths. Main checks: (1) gDuelFieldSlots_A (0x0201c510) slot card_id nonzero; (2) extract player/slot vs card_entry same slot; (3) get_card_extended_stat_field6==0x17 (continuous equip). On pass call build_zone_activation_entry_blocked or return 1; no match returns 0. Called via function pointer.

Inputs: r0 = ptr equip_card_entry (byte[+2] bit0=player_id, byte[+3] bit5=opposite_flag; saved to r8); r1 = ptr target_card_entry ([+0]=target_card_id)
Outputs: r0 = u32 (1=zone activation entry built or target valid; 0=invalid)
Side effects: build_zone_activation_entry_blocked called in some card_id paths (writes activation entry)
Constants: CARD_IDs=[0x0ffa (Reaper of the Cards), 0x1246 (Harpie's Feather Duster), 0x131c, 0x134d (Driving Snow), 0x1364 (Nobleman of Extermination), 0x149b (Bait Doll), 0x1685 (Dark Scorpion - Gorg the Strong), 0x1686 (Dark Scorpion - Meanae the Thorn), 0x16b8 (Crimson Ninja)], SLOTS_A=0x0201c510 (gDuelFieldSlots_A), PLAYER_STRIDE=0x868, FIELD6_CONTINUOUS_EQUIP=0x17, INVALID_ZONE=0xffff
