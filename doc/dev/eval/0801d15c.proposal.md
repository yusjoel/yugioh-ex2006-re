# Naming Proposal: 0x0801d15c

## 提案
- **proposed_name**: copy_palette_bank_by_slot
- **confidence**: med

## plate comment (中文, ASCII 标注)
由 FUN_0801d208 (tile map 更新函数) 调用. 接受 r0 = 打包参数, 提取 bits[11:4] (8 位调色板槽索引 bank_idx [0..255]), 计算目标地址 = 0x05000000 + bank_idx*32 (PALRAM 每槽 32 字节 = 16 个 RGB15 颜色), 以 r1 为源地址调 copy_memory_dma3_with_cpu_fallback 复制 0x20 字节 (1 个 16-color palette bank). 退出: pop {r0}; bx r0 (Sub-case E, r0=lr).

Constants:
- PALRAM_BASE = 0x05000000 (0xa0 << 0x13 = 0xa0 * 524288, 静态验证: python -c "print(hex(0xa0<<0x13))" -> 0x5000000)
- PALETTE_BANK_SIZE = 0x20 (32 字节 = 16 个 u16 颜色 = 1 个 16-color 调色板组)
- BANK_IDX_BITS = bits[11:4] of r0 (8 位, [0..255])

## 参数签名
- r0: u32 packed_slot (bits[11:4] = 调色板槽索引 [0..255])
- r1: u16* src_palette (源调色板数据指针, DMA 源地址)
- 返回: void (pop {r0}; bx r0 = Sub-case E, r0 为 lr, 无返回值语义)

## 副作用
- [PALRAM 0x05000000 + bank_idx*32] := 0x20 字节 (1 调色板组 DMA 写入 PALRAM)

## 行级注释 (<=30 行精华)
- @ 0801d15e: lsls r0,#0x10; lsrs r0,#0x14 => bank_idx = bits[11:4] of r0 (8 位槽索引)
