## plate comment (中文, ASCII 标点)
render_decimal_digits_jp (0x080f2c8c) 的变体: 使用 load_glyph_row_pair (0x080f1b60) 替代 render_glyph_jp_single_layer, 且每渲染一位固定向左移动 8 像素 (subs r5,#0x8), 不从 [0x02006ed0+0x8] 动态读宽度. 循环逻辑相同: r4 (decimal_value) % 10 -> char_code (+0x30), bl load_glyph_row_pair, r5 -= 8, r4 /= 10, 直到商为 0. 适用于需要双行字形对 (load_glyph_row_pair 加载两行) 且固定 8px 字宽的渲染场景. indeg=0, 为 dead-code 或通过函数指针调用.

Constants:
- CHAR_DIGIT_BASE=0x30 // ASCII '0' 数字基字符码
- DIGIT_STEP=0x8 // 每位固定 8 像素步进 (替代动态字形宽度查询)

## 参数签名
- r0: u16 x_start (起始渲染 x 像素位置, 右到左递减) [0..239]
- r1: const u8* gfx_ptr (字形图形数据指针, 传给 load_glyph_row_pair)
- r2: u16 width (行宽度参数, 零扩展到 u16) [0..0xffff]
- r3: u32 decimal_value (要渲染的无符号整数值)
- 返回: void (pop {r0}; bx r0 -- Sub-case E: r0 透传 load_glyph_row_pair 上游; 实际 void)

## 副作用
- 调用 load_glyph_row_pair 写 font_jp tile 缓冲区 (逐位右到左渲染, 固定 8px 步进)
