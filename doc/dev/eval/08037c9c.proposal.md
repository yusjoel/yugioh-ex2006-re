## plate comment (中文, ASCII 标点)
计算给定区位 (player_side, slot_idx) 上特效卡对 ATK/DEF 的增减量, 返回打包的 (s16 atk_delta << 16 | s16 def_delta). 流程: (1) 从 gDuelFieldSlots (0x0201c510) 读取 player_side*(0x868) + r2*20 偏移处的格位 card_id (bits[0..12] -> r4); (2) r9=0, r7=0 初始化; (3) 若 query_slot_effect_eligibility_nonzero(r5, r8) != 0 直接返回 0; (4) 按 card_id 进行大型 switch 分支, 各分支检查 [r6+0xc] 等位标志位, 命中则设 r7 = ATK buff (常见值 +500=0x1f4 或 +200=0xc8), r9 = DEF buff; (5) 无匹配返回 packed(r9, r7). 两处调用方: FUN_08039274 将返回值分解为 s16 低/高字分别累加入总 buff 表; FUN_0803a7b0 仅判断非零后返回 3 (命中标志).
