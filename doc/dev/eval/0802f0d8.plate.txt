Called by FUN_0803e130 (duel event display hub case 0x38 sub-handler). r2=slot_type (lsls r2,#3 gives 8-byte stride index), r3=flag (0 or nonzero, controls path), [sp+0]=node_extra_val (written to [node+0x4] halfword). Computes target node address from DAT_0802f0f4=0x0201d9c0 (zone node array base).
When flag==0 (r4==0): clears low 4 bits of [node+2] (AND 0x0f), writes r0 to [node+0] halfword, returns 0.
When flag!=0: checks zone_type (bits[3:0] of byte[node+2]) <=5 and flag <=5. If met, reads [node+0] upper byte as slot_ref_hi, computes new zone ref index with current slot_type, looks up zone_stat_table to update [node+0] halfword. Updates [node+2] byte: clears flag field (AND ~0x10), ORs flag low nibble, updates halfword[node+4].
Side effects: [0x0201d9c0+r2*8+0x0] halfword written (zone node ref update); [0x0201d9c0+r2*8+0x2] byte written (zone type/flag field); [r3+0x4] halfword updated (node extra field via stack param).

Constants: ZONE_NODE_BASE=0x0201d9c0, ZONE_TYPE_MAX=5, NODE_STRIDE=8.
