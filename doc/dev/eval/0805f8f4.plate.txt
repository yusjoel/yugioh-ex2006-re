check_spell_zone_placeable_with_opponent_lp14
Extracts player_id (byte[+2] bit0) from slot_ptr (r0); computes opponent = 1-player_id.
Reads gP1LifePoints + 0x14 + opponent*0x868; if zero -> return 0 (opponent LP state inactive).
Calls check_spell_zone_slot_placeable(player_id); if return==0 -> return 0; else -> return 1.
Dual gate: opponent LP state nonzero AND own spell zone placeable.
