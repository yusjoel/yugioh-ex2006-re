## plate comment (中文, ASCII 标点)
被 FUN_080a0334 (duel_field, indeg=1) 以 r0=player_id, r1=zone_col, r2=equip_set_idx 调用. 处理 icid=0x0ff9 (Relinquished, 4089) 装备槽的精灵属性提交. 首先检查 gDuelFieldSlots[player*0x868+zone*0x14+0x40] bit4 (装备标志); 非零且 get_equip_card_set_code_for_slot(player, zone)<=3 时调用 enqueue_equip_set_slot_sprite_by_zone_col(player, zone, 1). 继续检查 bit5 (进一步过滤), 若通过则提取 [slot+0x30] 的卡 id 相关字段, 调用 enqueue_sprite_attr_for_zone_card_id_lookup. 再双重循环 player=[0..1] x equip_slot=[0..4]: 调用 get_slot_card_state_code, 若状态==2 且 find_equip_chain_node_by_slot_pair 找到节点则调用 enqueue_sprite_attr_with_mode(mode=7). Side effects: 向精灵 OAM 队列提交 Relinquished 装备槽相关精灵属性. Constants: icid_filter=0x0ff9 (由 caller FUN_080a0334 的 cmp 确定; 对应卡名待 icid 内部表确认, 非 0x1281=Relinquished), gDuelFieldSlots=0x0201c510, player_stride=0x868, equip_flag_offset=0x40 (bit4=装备标志, bit5=额外过滤位), card_field_offset=0x30, mode_enqueue_val=7.
