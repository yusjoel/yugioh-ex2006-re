# Naming Proposal: 0x080f5d1c

## 提案
- **proposed_name**: bsearch_index_by_callback
- **confidence**: med

## plate comment (中文, ASCII 标点)
对大小为 r2 的有序数组执行二分查找, 比较函数通过 r10 (高寄存器, 由 .hword 0x4641 编码的 mov r1,r8 等指令传入) 以函数指针形式调用 FUN_0810e5f0 (bx r10). 每次用中间索引乘以步长 r3 (元素大小) 计算元素地址, 调用比较回调: 返回 0 则命中, 返回负则向低半区, 返回正则向高半区. 找到时将结果索引 (r5+1) 写入 IWRAM 地址 0x030001b6 (halfword), 未找到时写入 gPrng+0x17a (halfword). 被 card_stats 等模块用于在已排序表中定位条目.

## 参数签名
- r0: ptr base_ptr (数组基地址, 传入后存入 r8 供内层循环使用; asm: mov r8,r0 at 080f5d28)
- r1: u32 key (比较目标值, 传入后存入 r9; asm: mov r9,r1 at 080f5d2a)
- r2: u16 count (数组元素数量, 零扩展后保存在 sp+0x0)
- r3: u16 row_width (元素步长字节数, 零扩展后存入 r7 用于 mid*row_width 计算)
- [sp+0x28] (栈第 5 参数): 回调函数指针; asm 于 080f5d2c 以 ldr r0,[sp,#0x28] 取出后 mov r10,r0 存入高寄存器供内层循环 bx r10 调用
- 返回: r0 = u16 found_index+1 (命中时, 写入 0x030001b6 且 r0=r5+1); 未命中时返回 count (ldr r0,[sp,#0x0] 取回原始 r2, miss 路径标记)

## 副作用
- [0x030001b6] halfword := 找到的索引+1 (命中时)
- [gPrng+0x17a 0x030001ba] halfword := 结果值 (未命中时写 r4)

## 行级注释 (<=30 行精华)
- @ 080f5d1c: 保存 r8/r9/r10 (高寄存器), 分配 8 字节局部存储
- @ 080f5d28: mov r8,r0 / mov r9,r1 将 base_ptr 和 key 存入高寄存器
- @ 080f5d2c: ldr r0,[sp,#0x28] 取栈第 5 参数 (回调函数指针); 080f5d2e: mov r10,r0 存入高寄存器供 bx r10 调用
- @ 080f5d30: 提取 r2 低 16 位为 count (零扩展), 保存到 sp+0x0
- @ 080f5d36: 提取 r3 低 16 位为 row_width, 存入 r7
- @ 080f5d3e: 初始二分区间: lo=r2=0, hi=r5=count-1
- @ 080f5d40: mid = (lo+hi)/2 (带符号右移 1 位)
- @ 080f5d4a: mid * row_width 计算元素偏移 (r4=mid, r7=row_width)
- @ 080f5d56: bl FUN_0810e5f0 (实际为 bx r10 调用比较回调)
- @ 080f5d5e: 回调返回 0 (命中): r5=mid-1, 跳转 LAB_080f5d72 检查越界
- @ 080f5d72: cmp r6,r8 检查当前元素地址是否越界 (r8=base_ptr)
- @ 080f5d82: r0=r5+1 写入 0x030001b6 halfword (命中索引+1); 函数返回 r0=r5+1
- @ 080f5d9e: 未命中: 写 r4 到 gPrng+0x17a; ldr r0,[sp,#0x0] 返回原始 count
