Scores all 5 equip target slots and returns the best slot index. Called by three equip activation paths (0x08082290, 0x08083560, 0x080b5d98); scans slot [0..4] excluding exclude_slot to find the highest-scored slot.
Each slot passes four filters: check_equip_slot_eligible_by_card_id_and_prereqs -> get_slot_field5_score -> check_slot_equip_eligibility_by_type -> check_slot_full_activation_eligibility. Then adjusts score per equip card_id:
- Shooting Star Bow - Ceal (0x165d): score += -1000 (0xfffffc18), cap at 0x3e7
- Ring of Magnetism (0x1318) / Twin Swords (0x1661): score += -500 (0xfffffe0c), cap at 0x5db
- Necklace of Command (0x1841): score = 0x80<<9 - score (mirror)
- Metalmorph (0x1238): return this slot immediately on card_id match
- Spirit Reaper (0x1596)..Armed Samurai (0x186c): score += 0xfa<<1 = 0x1f4
- Gearfried (0x13c3): filters chain scenarios via count_equip_chain_default_flags
If r3=1 (first-eligible mode), second pass returns first slot passing check_equip_slot_eligible_by_card_id_and_prereqs. Returns [sp+0x4] best slot index; -1 if no eligible slot.
