# Naming Proposal: 0x080171d4

## 提案
- **proposed_name**: xor_buf_bytes
- **confidence**: high

## plate comment (中文, ASCII 标点)
Function: 对字节缓冲区中连续 r1 个字节逐字节执行 XOR 0x39 操作 (原地加解密). 若 r1<=0 则立即返回. 由 FUN_0801722c 在字符帧处理管线中调用, 用于对从 ROM/EWRAM 读取的字符帧数据执行对称 XOR 解密, 还原为明文字节流.
Trigger: 在帧完整性校验 (validate_complement_checksum) 之前对帧载荷缓冲区调用; XOR 密钥固定为 0x39.
Side effects: 原地修改 [r0..r0+r1-1] 共 r1 个字节, 每字节 ^= 0x39.

Constants:
- XOR_KEY=0x39 (固定对称 XOR 密钥)

## 参数签名
- r0: u8* buf_ptr 缓冲区起始地址 (任意可写地址)
- r1: s32 byte_count 字节数 [>0 有效; <=0 立即返回不作修改]
- 返回: void (bx lr 直接返回)

## 副作用
- [r0..r0+r1-1]: 每字节 ^= XOR_KEY (0x39)
