# Naming Proposal: 0x08047a38

## 提案
- **proposed_name**: query_equip_target_bitmap_with_zone_struct
- **confidence**: high

## plate comment (中文, ASCII 标点)
带区域结构体的装备目标位图查询函数. r0=player_id([0..1]), r1=slot_idx([0..4] 怪兽区槽), r2=card_id(内部 ID). 在栈上分配 0x18 字节的 zone_struct, 调用 memset 清零. 计算 player_zone_bit = 1 << (player*16+slot), 将 player_bit 写入 zone_struct[2]. 以 zone_struct 基址调用 update_equip_target_bitmap_for_field(player_zone_bit, zone=0xf, card_id) 更新位图. 返回 zone_struct 中目标位图与 player_zone_bit 的 AND 结果(非 0=有可用目标). 与 query_equip_target_bitmap_default(固定 side=2/zone=0xe) 互为 sibling, 区别在于本函数从 player/slot 动态计算 zone_bit.
Constants: ZONE_STRUCT_SIZE=0x18, ZONE_PARAM=0xf.

## 参数签名
- r0: u8 player_id [0..1] (目标玩家)
- r1: u8 slot_idx [0..4] (怪兽区槽索引, 用于计算 zone_bit)
- r2: u16 card_id [0x0000..0xffff] (装备卡 ID, 传给 update_equip_target_bitmap_for_field)
- 返回: r0 = u8, 非 0=该槽/玩家有有效装备目标, 0=无目标

## 副作用
- 栈: 0x18 字节本地 zone_struct(sp-relative, 函数返回后释放, 不计入外部副作用)
- update_equip_target_bitmap_for_field 内部可能写全局位图状态
