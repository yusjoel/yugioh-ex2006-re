## plate comment (中文, ASCII 标点)
settings/card_list 数值渲染工具函数, 负数或无符号绝对值路径包装. 接收目标缓冲区指针(r0)和有符号整数值(r1), 取 r1 的绝对值(bge skip / rsbs r4,r5,0)后以十进制逐位分解(循环 __modsi3 / __divsi3 /10 提取各位, 最多 15 位). 若原值为负则从 game_str_ja 取负号字形写入 [r1+0]; 最后按倒序将各位数字以 stmia 填入输出缓冲, 与 format_decimal_with_sign_pos 构成正负对.

## 参数签名
- r0: uint8* dst_buf 目标字符串缓冲区指针
- r1: int32 value 有符号整数值 (通常 < 0 时被选中, 也接受 0)
- 返回: r0 = uint32 1 (always)

## 副作用
- [r0..r0+N]: 写入 "-N" 或 "0" 格式十进制字符串 (digit-by-digit 填入)
- [dst_buf+0]: 若 value<0 则从 game_str_ja[0x14] 取负号字形写入 (strh @ 0810a144); 此处 r1 = r8 = 入口 r0 (dst_buf), 入口 r1 (value) 已在 0810a108 保存至 r5, 不再持有 r1; 写目标为 dst_buf 而非 entry_r1
