## plate comment (中文, ASCII 标点)
激活判定叶子谓词 (无 push, 无 bl 调用). 入参为卡槽指针 r0.
提取 flags halfword (+0x2) 并施加 mask 0xfc0; 若结果不等于 0x480 (法术类型枚举 A) 则返回 0.
读取 DAT_0805d9c4 (=0x0201bb90) 所指 IWRAM 全局字, 与 player_id 对应的激活牌组标识比较.
若全局牌组标识与当前玩家匹配则返回 1, 否则返回 0.

Inputs: r0 = card_slot_ptr (卡槽指针)
Outputs: r0 = 1 (类型 0x480 且当前牌组属于该玩家) / 0 (不满足)
Side effects: 无外部写入.
Constants: SPELL_TYPE_MASK=0xfc0 (0xfc<<4), SPELL_TYPE_A=0x480 (0x90<<3), ACTIVE_DECK_GLOBAL=0x0201bb90
