## plate comment (中文, ASCII 标点)
将卡牌 tile 行数据(第二字段偏移)从 ROM 复制到包店 OBJ VRAM 指定槽位, 并视需要复制调色板. 触发条件: 唯一 caller pack_list_page_init (0x080d971c) 在列表页初始化时调用. 函数结构与 load_pack_card_tile_row_to_obj_vram (0x080dc378) 完全对称, 区别仅在于读取 ROM 指针表偏移为 [r1,#0x10](而非 #0x8), 对应 ROM_TILE_TABLE 的第二组字段.

Constants:
- OBJ_VRAM_BASE = 0x06010000
- ROM_TILE_TABLE = 0x09ce822c (偏移 +0x10 = 第二字段)
- ROM_PAL_TABLE = 0x09ce824c (偏移 +0x10)
- OBJ_PAL_BASE = 0x05000200
- TILE_COPY_COLS = 2; TILE_COPY_ROWS = 2
- PAL_LIMIT = 0xf

## 参数签名
- r0: u16 tile_id_base [0..N] (tile 基准 ID, VRAM 偏移 = tile_id_base*32; caller 传入如 0xd3<<2=0x34c)
- r1: u8 pal_slot_index [0..0xf] (OBJ palette slot 索引; >0xf 跳过调色板)
- 返回: void (pop {r0}; bx r0)

## 副作用
- [0x06010000+r0*0x20..]: 写 ROM 卡牌 tile 行 (via tile_2d_row_copy, 2x2 tiles)
- [0x05000200+r1*0x20..+0x20]: 写调色板 (via copy_memory_dma3_with_cpu_fallback, 仅 r1<=0xf)
