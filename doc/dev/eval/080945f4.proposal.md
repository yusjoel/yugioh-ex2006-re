- **confidence**: med

## plate comment (中文, ASCII 标点)
在 gEffectContext (0x0201e4f0) 的槽属性表中查找与目标调色板 ID (r0) 匹配的条目, 返回该条目在附加数据表中的指针.
表项步长: 属性表 2 字节/项 (ptr r3), 附加数据表 4 字节/项 (ptr r2, 基址+0x10).
若找到匹配项 (bits[15:8] == r0), 返回附加数据表中对应项的地址 (r2).
若未找到, 以未命中索引 r1*4 + gEffectContext+0x10 为基础计算越界地址返回 (仍有效作为默认 slot 条目入口).
调用方 (0x08049e04 等) 用返回指针读取槽扩展数据.
Constants: gEffectContext=0x0201e4f0, slot_table_offset=0x82*8=0x410, extra_table_offset=0x10, attr_stride=2, extra_stride=4, PALETTE_ID_SHIFT=8.

## 参数签名

- 返回: r0 = ptr effect_slot_extra_entry (gEffectContext+0x10 区域对应项的地址)
