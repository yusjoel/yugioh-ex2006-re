check_equip_slot_eligible_with_whitelist_prereqs_and_type
Equip slot eligibility predicate combining whitelist check + prerequisites + type validation.
Callers: check_slot_card_is_equip_whitelist (0x08030a30), check_zone_slot_equip_prerequisites (0x08036770),
  check_card_equip_eligible_for_slot (0x08036870) during equip target selection.
Checks in order: (1) slot_idx <= 4 AND check_slot_card_is_equip_whitelist(player_id, slot_idx) passes (whitelist);
  if whitelist passes, skip slot address check and proceed; (2) compute slot address, bits[18:0] != 0 (occupied);
  (3) check_zone_slot_equip_prerequisites passes; (4) check_card_equip_eligible_for_slot(equip_slot, player_id, slot_idx, r3=1) passes.
Returns 1 if all pass. Pure predicate, no external writes.
Constants: SLOT_IDX_MAX=4, gDuelFieldSlots=0x0201c510, player_stride=0x868, ELIGIBLE_FLAG=1
Inputs: r0=ptr equip_card_slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..4]
Returns: r0=u32 bool (1=eligible, 0=rejected)
