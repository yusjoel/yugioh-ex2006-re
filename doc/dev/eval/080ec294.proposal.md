## plate comment (中文, ASCII 标点)
按卡片图标槽位索引将图标调色板和 tile 数据上传到 OBJ VRAM 及调色板 RAM. r0=slot_index [0..?]. 调用 copy_words_aligned 将 icon_palettes_base + slot_index*0x20 的 0x20 words (32 words=128 字节) 拷贝到调色板 RAM 目标地址 0x05000240 + slot_index*0x20; 再调用 tile_2d_row_copy 将 icon_tiles_base 中对应 tile 数据 (slot_index*9*0x20 + icon_tiles_base, 3x3 tiles) 写入 OBJ VRAM 0x06011000 + slot_index*9*0x20. 被 pack/卡牌图标显示路径的两个 callee 调用.

Constants:
- PALETTE_BASE = 0x05000240 (DAT_080ec2c0)
- PAL_STRIDE = 0x20 words (lsls slot,#5)
- icon_palettes_base = DAT_080ec2c4 (ROM 图标调色板表基址)
- TILE_VRAM_BASE = 0x06011000 (DAT_080ec2c8)
- icon_tiles_base = DAT_080ec2cc (ROM 图标 tile 表基址)
- TILE_SLOT_STRIDE = slot*9 (lsls slot,#3 then adds slot => *9), *0x20

## 参数签名
- r0: u16 slot_index - 图标槽位索引 [0..13] (OBJ palette RAM 0x05000240+slot*0x20 上界: 14 slots fit in 0x1C0 bytes to 0x050003FF)
- 返回: r0 = void (pop {r0}; bx r0)

## 副作用
- [0x05000240 + slot*0x20 .. +0x7f]: 写入图标调色板数据 (0x20 words)
- [0x06011000 + slot*9*0x20 .. ]: 写入图标 tile 数据 (3x3 区域)

## 行级注释 (<=30 行精华)
- @ 0x080ec294: r4=slot_index
- @ 0x080ec29a: lsls r1,r4,#5 => slot*0x20 字节偏移; r0=0x05000240+偏移
