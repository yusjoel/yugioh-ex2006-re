# Naming Proposal: 0x0804c1b8

## 提案
- **proposed_name**: get_card_effect_zone_check_sides
- **confidence**: high

## plate comment (中文, ASCII 标点)
根据卡牌 ID 返回"效果区域检查侧位"掩码, 用于判断放置该牌前需要检查哪一侧(对手/自己/双方)的效果区域槽位占用状态. 返回值为 2 位掩码: bit0=1 表示需检查对手侧效果区域, bit1=2 表示需检查己方侧效果区域, 0 表示无需检查. 仅在 0x0805a9a8 综合放置验证流程中被调用, 调用方用返回值与 count_available_effect_zones 联动决定是否阻断放置.

Constants:
- EFFECT_ZONE_CHECK_NONE = 0 (无须检查效果区)
- EFFECT_ZONE_CHECK_OPPONENT = 1 (bit0: 检查对手侧)
- EFFECT_ZONE_CHECK_SELF = 2 (bit1: 检查己方侧)
- EFFECT_ZONE_CHECK_BOTH = 3 (两侧均须检查)

## 参数签名
- r0: u16 card_id -- 卡牌数据库 ID, 全范围; 硬编码 BST 覆盖特定受限卡集合
- 返回: r0 = u8 side_mask -- [0..3], 2 位掩码: bit0=对手侧, bit1=己方侧

## 副作用
- 无外部写入; 纯查找函数

## 行级注释 (<=30 行精华)
- @ 0x0804c1b8: adds r1,r0,#0 -- 保存 card_id 到 r1 供比较
- @ 0x0804c1ba: 加载 BST 根节点 0x16c1 (ID 5825) 作为第一级划分点
- @ 0x0804c1c0: card_id == 0x16c1 -> LAB_0804c2ca (返回 1, 对手侧)
- @ 0x0804c1c4: card_id > 0x16c1 -> 高半区 LAB_0804c24c
- @ 0x0804c2ca: movs r0,#1 -- 需检查对手侧效果区
- @ 0x0804c2d4: movs r0,#2 -- 需检查己方侧效果区
- @ 0x0804c2d8: movs r0,#3 -- 需检查双侧效果区
- @ 0x0804c2dc: movs r0,#0 -- 无须效果区检查

## 调用图
- caller: addr 0x0805a9a8 (tags: -, role: 综合放置验证, 以返回掩码驱动 count_available_effect_zones 双路检查)
- callee: (无)

## 置信度证据
- 层 1 (返回值为 2 位掩码): LAB_0804c2ca=1, LAB_0804c2d4=2, LAB_0804c2d8=3, LAB_0804c2dc=0; 四路对应精确的 2-bit 掩码编码
- 层 2 (caller 使用模式): FUN_0805a9a8 逐 bit 检测返回值后各自调用 count_available_effect_zones(opponent_side/player_side, card_id, -1), 与 bit0=对手/bit1=己方 完全对应 (asm 0x0805ab4a-0x0805ab7e)
- 层 3 (结构对称): 函数体与 FUN_0804c16c / FUN_0804b4f4 为同簇 BST 分组函数, 同属卡牌放置前置校验模块
