# Naming Proposal: 0x080fd3a0

## 提案
- **proposed_name**: apply_title_ex_gfx_resource
- **confidence**: med

## plate comment (中文, ASCII 标点)
为 title_ex scene 应用一套 GFX 资源描述符. 读取 TITLE_EX_CTX+0x388 resource_ptr; memcpy 两段 8 字节 ROM 描述符 (TITLE_EX_RES_A/B) 到栈; zero_struct_36bytes 清工作结构体; 按参数填写 OAM 字段 (tile_group/tile_base_idx/palette/priority); 按 tile_shape 是否为 0 设置 visible flag; 最后 apply_gfx_resource_list 写入. 被 0x080fd49c ([scene_title_ex]) 以 slot_index=0/1/2/3 等值调用.

## 参数签名
- r0: u8 slot_index - OAM 资源槽索引, 低 4 位为 tile_group [0..n]
- r1: ptr oam_entry_t - OAM 条目指针 (r8 保存)
- r2: u8 tile_shape - tile 形状 [0..15]
- r3: u8 tile_base_idx - tile 基址索引 [0..127]
- [sp,#8]: u8 layer_z - 层深度 (stack arg 5)
- [sp,#0xc]: u8 palette_bank - 调色板索引 (stack arg 6)
- [sp,#0x10]: u8 visible_flag - 显示标志 (stack arg 7)
- 返回: void (pop {r3,r4,r5}; mov r8,r3; mov r9,r4; mov r10,r5; pop {r4,r5,r6,r7}; pop {r0}; bx r0)

## 副作用
- [oam_entry+0x14] bits[3:0] := tile_group (from r0&0xf)
- [oam_entry+0x17] |= 0x40 (priority bit)
- [oam_entry+0x18] bits[6:0] := tile_base_idx
- [oam_entry+0x18] bits[14:7] := palette_bank<<7
- VRAM/OBJ: apply_gfx_resource_list 写入
