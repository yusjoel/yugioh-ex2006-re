## plate comment (中文, ASCII 标点)
渲染当前卡包的名称文字和价格数字到 OBJ VRAM / sprite 行缓冲. 从 pack_ui_state 读取卡包计数 (上限 0x5f5e0ff), 通过 font_jp_base_table 选择字体, 调用 render_decimal_digits_jp 绘制数量, 再调用 render_text_with_u16_width 绘制卡包名称字符串. 随后调用 zero_fill_halfword_wrapper 清空 OAM tile 区域, commit_line_buffer_to_sprite_vram 提交到 OBJ VRAM. 最后向 OAM 映射区 0x0600f8e8 写入 tile 索引序列 (10 个槽位 x 2 行). 入口 r0 为某偏移量 (由 .hword 0x4680 存入 r8), 无其他显式 APCS 参数.

Constants:
- pack_ui_state = 0x03005850 (IWRAM pack 场景状态基地址)
- PACK_COUNT_OFFSET = 0x6c38 (pack_ui_state 内卡包计数字段偏移)
- MAX_PACK_COUNT = 0x5f5e0ff (计数夹拍上限)
- OAM_TILE_BUF = 0x0600f8e8 (OAM tile 映射写入区域)
- FONT_LINE_BUF = 0x00008008 (行缓冲基地址常量)

- GAME_STR_LANG_FLAG = 0x00006c2c (EWRAM 语言/区域标志偏移)

## 参数签名
- r0 -> r8: u32 base_offset -- pack_ui_state 内相对偏移 (由 .hword 0x4680 spill 到 r8, 非标准 APCS)
- 返回: r0 = u32 0x14 (固定 20; movs r0,#0x14 在 pop {r1};bx r1 epilogue 前写入; pop {r1} 不覆盖 r0, r0 透传给 caller; 已查 3 个 caller 080de700/080dfc56/080e0e3e 均在 bl 后立即覆盖 r0, 不使用返回值; 语义为帧/状态常量, 具体含义待 runtime 确认)

## 副作用
- [VRAM OBJ sprite 行缓冲]: 写入卡包名称+数量文字 tile 数据
- [OAM tile 映射 0x0600f8e8..+0x2f]: 写入 10 组 tile 索引 (strh 循环 x10 x2 行)
