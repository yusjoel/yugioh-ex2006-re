## plate comment (中文, ASCII 标点)
根据 IWRAM 状态码 ([0x0201b290+0x94*8]) 分发 Banisher of the Light 装备区域精灵或 LP indicator.

0x80 路径: 清零 [IWRAM+0x4a4]; 从 gP1LifePoints[player_id*0x868+0xc] 读取 equip display slot ptr, 若非零则以 r2=0 调用 dispatch_equip_zone_sprite_banisher_by_field_count, 并将 [IWRAM+0x4a4]+=1; 返回 0x7f.

0x7e 路径: 调用 count_field_copies_of_card(0x1332=Banisher of the Light); 若场上无副本则调用 submit_lp_indicator_with_slot_xor_flag(player_id_inv, card_id_copy_count*0xc8).

0x7f 路径: increment_lp_bar_display_counter; 清零 [IWRAM+0x4a4]; 返回 0x7f.

副作用: [IWRAM+0x4a4] write (0 or +=1); OAM sprite via dispatch_equip_zone_sprite_banisher_by_field_count.

Constants:
- STATE_80=0x80, STATE_7F=0x7f, STATE_7E=0x7e
- CARD_ID_BANISHER=0x1332 (Banisher of the Light)
- LP_COUNT_SCALE=0xc8 (gP1LifePoints index scale)
- gP1LifePoints=0x0201c4e0 (DWORD_0807f060)
- PLAYER_STRIDE=0x868, IWRAM_BASE=0x0201b290, counter_offset=0x4a4
