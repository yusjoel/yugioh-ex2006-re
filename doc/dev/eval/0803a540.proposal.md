## plate comment (中文, ASCII 标点)
校验决斗场地特定栏位是否满足装备/链接规则, 返回 bool. 入口 r0=player_side, r1=card_id, r2=target_side, r3=slot_idx [0..4]. 先调用 get_slot_card_state_code(player_side, slot_idx) 取栏位状态码存入 r7; 再调用 FUN_0803b1b0(player_side, card_id) 取辅助位掩码存入 r9 (MOV r9,r0). 之后根据 r7 的值分支: r7==STATE_EQUIP_TYPE_A 走 LAB_0803a56c (检查 player_side==target_side, 再用 effect_code_A 调用 FUN_08032548, 命中则读 card atk 字段 [r0+6] 返回); r7==STATE_EQUIP_TYPE_B 走 LAB_0803a5a4 (类似检查, 用 effect_code_B); 其余走 LAB_0803a5c0 (提取 bit [1..6] 后与 FUN_0803b1b0 结果做按位逻辑). 返回 1=规则满足, 0=不满足. Constants: gDuelFieldSlots=0x0201c510, STATE_EQUIP_TYPE_A=0xd, STATE_EQUIP_TYPE_B=0xf, effect_code_A=0x13a0(movs r2,#0x9d; lsls r2,#5), effect_code_B=0x1399(DAT_0803a5bc).

## 参数签名
