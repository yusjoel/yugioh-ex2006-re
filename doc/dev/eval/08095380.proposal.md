# Naming Proposal: 0x08095380

## 提案
- **proposed_name**: pack_sprite_row_attr_words
- **confidence**: high

## plate comment (中文, ASCII 标点)
将调用方传入的四个 halfword 字段 (x_pos/y_pos/palette/flags) 拼合为两个 32-bit sprite-row 属性字, 再连同 count=6 的 strideword 传给 submit_sprite_row_data 提交到 OAM 缓冲区. 第一个属性字由 r0[15:0] | (r1[15:0]<<16) 构成; 第二个属性字从 sp[4] 读入, 先 AND mask DAT_080953bc, 再 OR r2[15:0], AND DAT_080953c0, OR r3[15:0] 叠入. 然后置 r1 = -1 (全掩码) 后调用 submit_sprite_row_data(base_ptr, -1, stride+2, 6). 被多个 card-display / duel-field 场景 caller 调用, 统一封装 sprite row 属性合并写入流程. Constants: submit_sprite_row_data count=6, stride=r2+2.

## 参数签名
- r0: u16 x_or_slot_word 第一属性字低 16 位 (入口 lsls/lsrs 截取, [0..0xffff])
- r1: u16 y_or_attr_high 第一属性字高 16 位源 (入口 lsls 截取后 orrs 入, [0..0xffff])
- r2: u16 palette_or_stride 第二属性字第二域 (lsls/lsrs 截取, [0..0xffff])
- r3: u16 flags_or_tile 第二属性字第三域 (lsls/lsrs 截取, [0..0xffff])
- sp+4: u32 base_attr_word 第二属性字初始底值 (调用方写入栈 0x4 槽)
- 返回: r0 = void (submit_sprite_row_data 返回值直接透传, 无独立语义)

## 副作用
- 调用 submit_sprite_row_data, 后者写入 OAM sprite-row 缓冲区 (外部副作用由 submit_sprite_row_data 承担)
