# Naming Proposal: 0x080a1b58

## 提案
- **proposed_name**: set_lp_row_type2_with_sign_flags
- **confidence**: high

## plate comment (中文, ASCII 标点)
与 set_lp_row_type2_with_attr_flags (0x080a1b1c) 类似, 但参数语义不同.
r2 (lp_delta) 的符号位通过 rsbs r0,r2,#0; orrs r0,r2; lsrs r4,r0,#0x1f 提取: 为负或零则 r4=0, 为正则 r4=1.
若 r3 (extra_flag) 非零则 flags|=0x8.
强制 flags|=0x10 并截断.
额外强制 flags|=0x20 并截断.
调用 set_lp_display_row_fields(r5=lp_row_ptr, 2, r1_in&0xffff, flags).
用于 LP 变化量 (正/负增量) 的显示行更新, flags 中包含符号方向信息.
调用方 (0x08057116, 0x08057ec0 等) 在 LP 增/减动画时调用.
Constants: ROW_TYPE=2, SIGN_BIT=0x8, FORCED_BIT4=0x10, FORCED_BIT5=0x20, DELTA_MASK=0xffff.

## 参数签名
- r0: ptr lp_row_ptr (保存到 r5)
- r1: u32 lp_value_raw -> u16 lp_value (传给 set_lp_display_row_fields 第三参数)
- r2: s32 lp_delta (用于提取符号位; 负/零->sign=0, 正->sign=1)
- r3: u32 extra_flag [0..1] (非零->flags|=0x8)
- 返回: void (pop {r4,r5}; pop {r0}; bx r0)

## 副作用
- 通过 set_lp_display_row_fields 写 LP 显示行字段
