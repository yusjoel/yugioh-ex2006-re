- **confidence**: med

## plate comment (中文, ASCII 标点)
根据 r0 (effect slot index), 从 gEffectContext+0x10 (=0x0201e500) 读取对应条目 [+r0*4], 再从另一表 [0x0201e500+0x80*8+r0*2] 读取 halfword 并提取 bits[4:0] (zone_type). 若 zone_type-0xb 在 [0..4] 范围内 (即 zone_type in [0xb..0xf], 5 个合法值), 以 zone_type-0xb 为 5-entry jump table (0x080943d0) 的索引跳转; 否则走 error 路径 (r6=1, 跳 LAB_080943e4). jump table 目标均在 0x080943e8 附近 (ROM_INCBIN 区域). 唯一 caller: FUN_080d136c 内部 0x080d170e, 在 zone card anim dispatch 链中传入从 gDuelCtx 区域动画表读出的 effect slot index. Side effects: 间接写 (由 jump table handler). Constants: gEffectContext=0x0201e4f0, slot_table=0x0201e500 (=gEffectContext+0x10), attr_table=0x0201e500+0x80*8=0x0201e900, jump_table=0x080943d0, zone_type_valid_range=[0xb..0xf] (5 entries, index 0..4).

- r0: u32 effect_slot_index [0..0x7f] (传入 r0*4 作 slot_table 偏移; r0*2 作 attr_table 偏移; callsite 0x080d170e 传 ldr r0,[sp,#0x28] — 来自 FUN_080d136c 中 str r0,[sp,#0x28] at 0x080d1678, 值为 ldrh from gDuelCtx+zone_anim_table 的 zone slot id halfword. 上界由 attr_table 容量约束: attr_table 偏移 0x400 = 0x80*8 bytes, 每条目 8 bytes, slot_table 共 0x80=128 条目, 故 effect_slot_index 上界 = 0x7f.)
