# Naming Proposal: 0x080f43c4

## 提案
- **proposed_name**: compute_card_type_highlight_color
- **confidence**: high

## plate comment
根据卡牌类型索引 (type_code) 和亮度标志 (use_highlight) 返回 BGR555 高亮色. type_code 传入前减 1 (switch 接受 0..7 共 8 个 case): case 1=怪兽(暖橙), case 2/3=魔法(蓝绿), case 4/5=陷阱(紫红,共用), case 6/8=绿色系, case 7=黄色. use_highlight != 0 时对 R/G/B 分量各做 x*3/4 折算 (asrs #2 之前乘 3), 返回经亮度调制的 BGR555; use_highlight == 0 时直接组合三通道分量.

Side effects: 无外部写入; 纯计算返回值.

Constants:
- TYPE_MONSTER = 1  // case 1: R=0x1f G=0x17 B=0x0 (橙)
- TYPE_SPELL_2 = 2  // case 2/3: R=0x0 G=0x1f B=0x1f (青)
- TYPE_TRAP_4 = 4   // case 4/5: R=0x1f G=0x1 B=0x0 (红紫)
- TYPE_GREEN_6 = 6  // case 6/8: R=0x0 G=0x1f B=0x0 (绿)
- TYPE_YELLOW_7 = 7 // case 7: R=0x1f G=0x0 B=0x1f (洋红/黄)
- BGR555_R_SHIFT = 0  // bits[4:0]
- BGR555_G_SHIFT = 5  // bits[9:5]
- BGR555_B_SHIFT = 10 // bits[14:10]

## 参数签名
- r0: u16 type_code 卡牌类型编码 [1..8], 内部使用 type_code-1 作 switch 索引
- r1: u8 use_highlight 亮度折算标志 [0=直接组合, 1=x*3/4 折算]
- 返回: r0 = u16 BGR555 高亮色
