Renders BG tilemap for the pack scroll list with animation counter control.
r0=reset_flag [0..1] (1=decrement [+8] counter, 0=increment and check upper bound).
r1=row_data ptr (ldrb [r1+8] = row_count upper bound).
First calls setup_pack_blend_callback.
Loop r4=0..row_count-1: if r4==r5 (current selected slot), skip.
  Computes delta = [+8] - r4; clamps to min(delta, 7).
  Queries ANIM_TABLE[delta*4] for tile_attr; adds 3.
  Calls write_scroll_list_tilemap_row(r4, tile_attr+3, 2).
After loop (r6!=0 = decrement path): [+8]-=1; if [+8]<=0 return 1.
After loop (r6==0 = increment path): [+8]+=1; if >= row_count+7 return 1.
Not done: returns 0.
Called by FUN_080e7e0c (pack main scene switch dispatcher).

Constants:
  ANIM_TABLE  = 0x09e5ee14  (row animation tile attr lookup table, 8 entries)
  COUNTER_OFF = 0x8         (gMenuState[0x8] animation counter byte)
  MAX_DELTA   = 7           (maximum table lookup offset)

Inputs: r0=u32 reset_flag [0..1], r1=ptr row_data.
Returns: r0=u32 (1=animation complete; 0=still in progress; pop {r1}; bx r1).
Side effects: updates gMenuState[0x8] animation counter;
              writes tile attributes to BG tilemap via write_scroll_list_tilemap_row.
