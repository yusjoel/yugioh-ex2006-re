# Naming Proposal: 0x080de0bc

## 提案
- **proposed_name**: encode_pack_confirm_oam_attr
- **confidence**: high

## plate comment (中文, ASCII 标点)
将牌包确认状态布尔值编码为 OAM attr 打包值.
r0 = is_confirmed (0=否, 非零=是);
rsbs r1,r0,#0; orrs r1,r0 -> r1 = sign(r0) (r0!=0 -> 1); 提取 bit31 作 [0..1] 标志;
计算: flag * 0x19 + 0x55 = 目标 y 位置 (0=0x55, 1=0x6e); python 验证: 1*0x19+0x55=0x6e;
返回 r0 = (y_attr << 0x10) | 0xa3 (低 8 位 x 属性).
被 pack 场景的确认按钮 OAM 渲染路径调用.

Constants:
- 0x55: y 基准 (is_confirmed=0 时, 未选中位置)
- 0x6e: y 偏移结果 (is_confirmed=1 时, 0x55+0x19=0x6e; python: hex(0x19+0x55)='0x6e')
- 0x19: y 步长系数 (r1*2+r1=r1*3; *8=r1*24; +r1=r1*25=r1*0x19)
- 0xa3: OAM 低 8 位 x 属性 (movs r1,#0xa3; orrs r0,r1 -> 低 8 位)

## 参数签名
- r0: u32 is_confirmed 确认标志 (0=否, 非零=是)
- 返回: r0 = u32 packed_oam_attr = (y_pos << 0x10) | 0xa3 (y_pos=0x55 or 0x6e; 低 8 位 x=0xa3)
