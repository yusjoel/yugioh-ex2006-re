# Naming Proposal: 0x080c9374

## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
将 ROM 中的 nibble 压缩调色板行数据写入 VRAM 目标地址. r0=VRAM 写入目标指针, r1=tile 行索引
(u16), r2=写入行数(u8). r8(non-APCS) 为当前迭代计数器(调用前由 caller 设置). 每行从 ROM 数据源
ldr [r1] 读取 16-bit 基础值后写 strh, 再按 nibble 位段逐字节检测非 0 值, 用掩码
0xff0f/0xf0ff/0x0fff 清除对应 nibble 后 OR 写入新值, 步进 +2(halfword). 外层循环受
gSettings[+8](0x02006ed0+8) 的字体宽度字段 [bits 21:14] * r2 控制总行数, r8 >= max 时退出.
此函数由 FUN_080c992c 和 FUN_080c9ac8 调用. indeg=2.
Constants: gSettings=0x02006ed0, mask_nibble_hi=0xff0f, mask_nibble_mid=0xf0ff,
mask_nibble_lo=0x0fff.

## 参数签名
- r0: u16* vram_dest - VRAM 写入目标 halfword 指针 (如 0x06016400 等 BG tile 区域)
- r1: u16 tile_row_index - ROM tile 源数据行索引 [0..12] (caller FUN_080c9ac8 传入计算值; FUN_080c992c 传入 0; 上界由 gSettings bits[9:2]*row_count 控制, row_count <= 13=0xd)
- r2: u8 row_count - 本次写入行数 [1..max]; gSettings 字体宽度字段确定上界
- r8 (non-APCS): u32 current_row_iter - 当前已处理行计数器 (caller 初始化, 函数内递增)
- 返回: r0 = void

## 副作用
- [r0 VRAM 目标区域]: strh 写入 nibble 调色板行数据 (每行 2 halfword, 步进 +2)
