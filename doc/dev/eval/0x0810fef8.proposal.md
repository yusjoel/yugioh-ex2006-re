# Naming Proposal: 0x0810fef8

## 提案
- **proposed_name**: flush_stream_callback
- **confidence**: high

## plate comment (中文, ASCII 标点)
单层 fflush(3) 包装函数, 作为 _fwalk 回调使用. __srefill (0x0810ff00) 在需要遍历所有打开流并刷新缓冲区时, 将本函数地址 (THUMB ptr 0x0810fef9) 作为回调传递给 _fwalk; _fwalk 对每个打开的 FILE* 调用 callback(reent, fp). 本函数: push{lr}; bl fflush(r0); pop{pc}. 无直接 bl 调用者, 通过 DAT_0810ffd8 以函数指针形式被引用.

## 参数签名
- r0: ptr<FILE> fp 目标文件流指针 (由 _fwalk 传入)
- 返回: r0 = fflush 返回值 (0=成功, -1=失败)

## 副作用
- 刷新 r0 指向的 FILE 缓冲区 (通过 fflush)

## 行级注释 (<=30 行精华)
- @ 0x0810fef8: push {lr} (保存 lr 以便调用 fflush)
- @ 0x0810fefa: bl fflush (0x08110f28) -> 刷新单个流
- @ 0x0810fefe: pop {pc} -> 返回 fflush 结果

## 调用图
- caller: form(c): 无直接 bl/b 调用者; .word 0x0810fef9 出现在 DAT_0810ffd8 (位于 __srefill 函数体内), 通过 ldr r1, DAT_0810ffd8; bl _fwalk 以函数指针传递. grep ".word 0x0810fef9" -> 1 处命中, 为函数指针使用而非 bl.
- callee: fflush (0x08110f28)

## 置信度证据
- L1: 函数体 8 字节 (push+bl+pop), 全静态
- L3: DAT_0810ffd8 = 0x0810fef9 (THUMB ptr 指向本函数) 在 __srefill 中作为 _fwalk 回调
- L6: fflush (0x08110f28) 是已命名 callee; _fwalk 回调模式与 fflush 内部回调 (DAT_08110f40=0x08110f29) 结构一致
