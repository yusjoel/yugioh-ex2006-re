## plate comment (中文, ASCII 标点)
按卡片 ID 与卡片状态分派渲染 sprite attr 记录的中央 dispatcher: 解析入参 r0 中的 8 个 bit 字段 (sp[0x10] 平等性标志 / sp[0x14] 是否 0xe / sp[0x18] bit15 / sp[0x1c] bit14), r1 指向 card_record 解码 card_id (lsls/lsrs #0x13 取 13 位 card_id 写入 r6), 还有 r2 拆 4 个 bit 标志. 主体是一棵庞大的 card_id 二分搜索树 (0x1591/0x1342/0xfd6/0x10dd/0x1185/0x11e4/0x133a/0x1333/0x17b7/0x17af/0x1881/0x19d7 等), 命中后跳到不同 LAB_0804XX 完成 enqueue_sprite_attr_record + submit_lp_bar_sprite_row_by_type 的 sprite 提交流程. 4 个 caller 全 duel_field, 用于装备/效果触发后的卡片 sprite 显示.

## 参数签名
- r0: u32 card_attr_packed (8 个 bit 字段; sp[0x0] 保存)
- r1: ptr<CardRecord> card_record_ptr (sp[0x4] 保存; [r1+0]=card_attr_word, lsls #0x13 取 card_id 写 r6)
- r2: u32 flags (拆 4 bits: bit0/bit1/bit2/bit3 写 r5/r4/r1/r2 副本)
- 返回: u32 (具体值因路径而异; 走 LAB_08045ab4 = 1, 走 LAB_080457cc = 1, 失败/无匹配 = 0; 静态可见多入口)

## 副作用
- enqueue_sprite_attr_record() : 多处 sprite attr 队列入队
- enqueue_sprite_attr_with_shape() : sprite 提交
- submit_lp_bar_sprite_row_by_type() : sprite row data 提交
- FUN_0802f6e4 / FUN_0803009c (本 batch) : 节点池查询
- FUN_08043240 / FUN_08045240 / FUN_08048674 (本 batch) : enqueue 子工具
