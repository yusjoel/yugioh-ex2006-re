## plate comment (中文, ASCII 标点)
装备槽玩家匹配与 field6 空位检查谓词. 与 check_equip_slot_cross_player_type_eligible 相反, 本函数要求目标槽位的卡片与传入 player_id 属于同侧 (player_id 不同则失败). 然后查区域表 is_present; 通过后再检查 card[+8] 非零 (ATK 存在) 且 card[+6] 为零 (field6 尚未分配). 两者同时满足则返回 1 (可用于装备). 场景: 在已分配某类装备卡后检查是否还有可接受第二张装备卡的空位.

Inputs: r0 = ptr equip_card_entry, r1 = player_id [0..1], r2 = slot_idx (no range guard)
Outputs: r0 = 1 if same-player slot has ATK!=0 and field6==0, 0 otherwise
Side effects: none
Constants: PLAYER_BLOCK=0x868, ZONE_BASE=0x0201c510, SLOT_STRIDE=20

## 参数签名
- r0: ptr equip_card_entry (reads byte[+2] bit0 for owner player_id)
- r1: u32 player_id [0..1]
- r2: u32 slot_idx (no upper bound)
- 返回: r0 = u32 (1=slot valid for secondary equip, 0=invalid)
