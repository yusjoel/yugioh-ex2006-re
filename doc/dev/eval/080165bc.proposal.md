# Naming Proposal: 0x080165bc

## 提案
- **proposed_name**: apply_bgdt_entry_to_bg
- **confidence**: high

## plate comment (中文, ASCII 标点)
将一个 BGDT (Background Data) 资源条目的图块和 screen map 数据应用到目标 BG 对象. 入参 r0 为目标 BG 状态结构体指针, r1 为 BGDT 条目指针. 函数从条目中提取 priority/palette 等属性字段写入目标结构体, 然后根据条目的图块矩形尺寸最多三次调用 write_tile_region_to_bg_screen 写入 screen map 数据; 每次写入前调 calc_bg_screenmap_block_offset 计算跨 screen block 的字节偏移. 若条目携带 char tile 数据且 bg_index 有效, 则分派到 copy_to_bg0/1/2/3_char_tiles 写入字符平面. 返回固定 0. 由 FUN_08016a7c (资源列表应用器) 在遇到 "BGDT" 标签时调用.

## 参数签名
- r0: void* bg_dst -- 目标 BG 状态结构体指针 (含 priority/palette/tile_pos 等字段)
- r1: void* bgdt_entry -- BGDT 资源条目指针 (含 priority/tile_rect/char_data 指针等)
- 返回: r0 = u32 0 (固定, 表示处理完成)

## 副作用
- [bg_dst+0x14]: 写入 priority 位域 (bits[6:5]) 和 palette 属性
- [bg_dst+0x16]: 写入 tile 属性字段
- [VRAM screen map]: 经 write_tile_region_to_bg_screen 写入最多 3 次 tile region
- [VRAM char 平面]: 若有 char data, 经 copy_to_bgX_char_tiles 写入
