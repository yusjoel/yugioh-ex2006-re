# Naming Proposal: 0x080f5758

## 提案
- **proposed_name**: tick_blend_step_with_bldalpha
- **confidence**: high

## plate comment
与 tick_blend_step_with_bldcnt (0x080f5668) 同族, 区别在于写 BLDALPHA 而非 BLDY. 先写 BLDCNT (r1 参数), 再将 gPrng+0x200 bits[5:0] 步进加上 delta (r0), 若超过 0x1e 则钳位到 0x1f, 写回 gPrng+0x200 并写 BLDALPHA. 达到 0x1e 上界时返回 1 (完成), 否则返回 0. BLDALPHA 写法: (0x1f-step) 作 EVA (bits[5:0]), step 作 EVB (bits[12:8]).

Side effects:
- [BLDCNT] (0x04000050): 写 r1 控制字
- [gPrng+0x200] byte: 步进 += delta, 钳位至 0x1f
- [BLDALPHA] (0x04000052): 写 EVA/EVB halfword

Constants:
- BLEND_STEP_FIELD = gPrng+0x200 // bits[5:0]=step, bit6=active
- STEP_MASK = 0x3f // 6-bit 步进掩码
- ACTIVE_FLAG = 0x40 // bit6 清零掩码 (rsbs #0x40)
- MAX_STEP = 0x1e // 返回完成的阈值
- CAP_STEP = 0x1f // 步进钳位上界
- BLDALPHA = 0x04000052
- BLDCNT = 0x04000050

## 参数签名
- r0: u8 delta 每帧步进增量 [1..0x1e]
- r1: u16 bldcnt 写入 BLDCNT 的控制字
- 返回: r0 = u8 1=步进已达 0x1f (完成), 0=继续推进 (pop {r1};bx r1, Sub-case E)

## 副作用
- [0x04000050]: BLDCNT 写入
- [gPrng+0x200]: 步进累加
- [0x04000052]: BLDALPHA 写入
