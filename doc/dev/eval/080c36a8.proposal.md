# Naming Proposal: 0x080c36a8

## 提案
- **proposed_name**: write_palette_tile_row_to_vram
- **confidence**: med

## plate comment (中文, ASCII 标点)
当 duel field 显示初始化或场地 BG 重建时调用 (indeg=1, tags: vram palette scene_duel_field). 函数从 ROM 数据表 (0x09e49254/0x09e49258) 和 VRAM base 0x0600e800 开始, 以 r7=0..1 (两行或两层) / r2=0..0x15 (列, 22 列) 的双层循环, 每次读取两个 ROM word (palette_index 和 tile_index), 将 tile_index<<5 | palette_offset 合成 halfword 写入 VRAM BG tile map. 外层 r7==1 时, tile_index 在 0..8 范围内加 0xC00 (即 0xC00=BG mode/OAM mask) 以选择第二套 tile 集. 循环结束后以 copy_bytes_by_halfword 将 palette 数据 (0x100 halfwords, 0x0200 bytes) 从 ROM (0x08510460) 复制到 BG palette (0x05000020).
Constants: VRAM_BG_TILE_MAP=0x0600e800, BG_PALETTE_VRAM=0x05000020, ROM_PALETTE_SRC=0x08510460, ROM_TILE_TABLE_A=0x09e49254, ROM_TILE_TABLE_B=0x09e49258, TILE_SET_MASK=0xC00, col_count=0x15 (22 cols), row_count=2, palette_copy_size=0x100 halfwords=0x200 bytes.

## 参数签名
- r0: void -- 无 APCS 参数; 入口即 ldr VRAM_base=0x0600e800 (内部加载), .hword 0x4681=mov r9,r0 (内部设 VRAM base), .hword 0x468a=mov r10,r1 (内部行计数)
- 返回: void
注: 入口 .hword 0x4657/0x464e/0x4645 callee-save r10/r9/r8; r9/r10 由函数内部自行设置, 非独立 caller-set. callsite 0x080cc9c2 (FUN_080cc904) 确认 bl 前无 r8/r9/r10 写入.

## 副作用
- [VRAM 0x0600e800 + offsets]: 写入 BG tile map halfwords (tile_index | palette_flag | tile_set_bit), 共 2*22=44 个 halfwords per call context.
- [VRAM 0x05000020..0x0500021f]: 从 ROM 0x08510460 复制 0x200 字节 BG palette.
