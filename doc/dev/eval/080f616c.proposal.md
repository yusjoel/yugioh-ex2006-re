## plate comment (ASCII-only)
高频 OAM 写入原语 (indeg=83), 被 card_stats/font_jp/opp_wins 等多模块调用.
接收打包参数: r0 低 16 位为精灵 X 坐标 (9 位有效), 高 16 位为 OAM-Y; r1 为 tile 索引;
r2 为 attr2. 从 gPrng 定位精灵表条目, 写入 OAM attr0/attr1/attr2 三个半字,
并递增条目 tile 计数字节. 与 write_oam_entry_with_tile_inc (0x080f6450) 结构相同
但参数布局略有差异.

- r0: u32 packed — 低 16 位: x_coord (u16, OAM X 坐标 9 位有效); 高 16 位: oam_y (u16, Y 坐标)

- r2: u16 attr2 — OAM attr2 (调色板/优先级/tile 号高位)
- 返回: r0 = void

## 副作用

- [gPrng->sprite_table + slot*8 + 0x2] := attr1 — OAM attr1 (X 坐标 | tile 索引)
