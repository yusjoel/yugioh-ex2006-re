# Naming Proposal: 0x08014470

## 提案
- **proposed_name**: copy_str_unbounded
- **confidence**: high

## plate comment (中文)
由 banlist 禁卡名称录入、名字输入页（name_input_page_exit）、密码输入（pass_input）及游戏字符串渲染等多处 text-input 上下文调用。调用方需要将一条以 0x00 结尾的字符串（支持 1 字节或高字节置位的 2 字节编码）完整复制到目标缓冲区，而不限制复制长度。本函数通过向 banlist_password_enter_char 传入 r2=0x05F5E0FF（99,999,999，实际无上限哨兵）实现无界复制，返回值为实际写入的字符单元数。

## 参数签名
- r0: ptr src — 源字符串起始地址（EWRAM 或 ROM），以 0x00 结尾；字符单元可为 1 字节（bit7=0）或 2 字节（bit7=1 高字节，后跟低字节）
- r1: ptr dst — 目标缓冲区起始地址（IWRAM 或 EWRAM），需足够容纳源字符串全部内容
- 返回: r0 = u32 chars_written — 实际写入的字节单元数（同 banlist_password_enter_char 返回值；等于源字符串中字符单元总数）

## 副作用
- [dst .. dst+N]: 写入 src 字符串的全部字符单元（1 字节或 2 字节编码），并在末尾写入 0x00 终止符；N 由源字符串长度决定
- 无 IO 寄存器写入；无 VRAM/PALRAM/OAM 操作

## 行级注释 (≤ 30 行精华, 按 ROM 地址排)
- @ 08014470: push {lr} — 保存返回地址，本函数为轻量 wrapper，仅占 5 条指令
- @ 08014472: ldr r2, DAT_0801447c — 加载常量 0x05F5E0FF（= 99,999,999）作为 max_chars 参数；值域远超任何合法字符串长度，相当于"不限制"语义
- @ 08014474: bl banlist_password_enter_char — 委托实际复制逻辑；该函数处理 1/2 字节编码并写入终止符，返回写入字符单元数
- @ 0801447c: .word 0x05f5e0ff — 无界哨兵值 99,999,999（= 10^8 - 1），硬编码于字面量池
