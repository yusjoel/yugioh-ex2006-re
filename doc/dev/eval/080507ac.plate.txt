indeg=0, called via function pointer. Entry with card_ptr/player_side/slot_idx params. Pre-filters: player_side must not equal card_ptr[+2] bit0 (card owner side) else return 0; slot_idx>4 -> return 0; target slot card_type_bits (bits[12:0]) must be nonzero. Then calls: (1) query_slot_card_type_eligibility(card_ptr, player, slot) -> nonzero means ineligible, returns 0; (2) check_card_equip_eligible_for_slot(card_ptr, player, slot, r3=0) -> zero means ineligible, returns 0. Both checks passing -> returns 1.

Inputs: r0=u32* card_ptr ([+2]=owner_bits; bit0=player_side); r1=u32 player_side [0..1]; r2=u32 slot_idx [0..4].
Outputs: r0=u32 bool (1=eligible, 0=not eligible).
Side effects: none.
Constants: gDuelFieldSlots=0x0201c510; PLAYER_STRIDE=0x868; SLOT_STRIDE=0x14; SLOT_IDX_MAX=4.
