Checks if an equip zone entry and an effect slot entry match for cross-player equip chain eligibility.
r0=equip_zone_ptr (struct[+0]=card_id u16, struct[+2] bit0=player_side),
r1=slot_ptr (effect slot struct; null -> return 0).
Compares player_bit from both structs; same side -> return 0 (no cross-side equip).
If different: iterates up to [slot_ptr+4] bits[18:16] effect links, calling
read_effect_slot_side_and_type(slot_ptr, index) for each.
Checks side matches equip zone player, type <= 4, bitmap bit match.
Then calls check_card_field5_is_nonzero, check_card_field8_is_9 (exclusion),
and check_slot_equip_eligibility_by_type(side, type, 1). All pass -> return 1.

Constants:
- EFFECT_LINK_COUNT_FIELD=[slot_ptr+4] bits[18:16]
- EFFECT_TYPE_MAX=4
- gDuelEffectZones=0x0201c510
- player_stride=0x868
