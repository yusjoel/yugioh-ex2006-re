# Naming Proposal: 0x080ee3a8

## 提案
- **proposed_name**: apply_palette_offset_to_tile_row
- **confidence**: med

## plate comment (中文, ASCII 标点)
当 scene_duel_field 需要对一段 BG tile 数据按调色板偏移进行修改时调用 (indeg=5, class D). 函数从栈 sp[0x28] 读取 tile_count (外层循环次数, 非 APCS 传入 r10), 以 r4=tile_count (递减) 和 r5=src_ptr (halfword 步进) 构成内层 tile 遍历循环. 对每个 halfword tile entry: 检查 [src] & 0x3ff (tile index field) 非零才处理; 读 sp[0x4] (palette_mask) 与 tile_value OR, 再将 [src] & 0xf000 (palette bank) 加上 r6 (palette_offset lsl 0xc) 合成新 tile halfword 写入 dst [r3+]. 外层由 r10 计数驱动再次迭代. 用于将 duel field BG tile 行的调色板索引批量替换为指定 palette_bank, 实现高亮/变色效果.
Constants: TILE_INDEX_MASK=0x3ff, PALETTE_BANK_MASK=0xf000, PALETTE_FIELD_MASK=0xf0000000 (sp[4] palette_mask).

## 参数签名
- r0: u32 dst_tile_count (per inner loop)
- r1: ptr dst_tile_halfword_array  -- 目标 BG tile map 地址
- r2: u16 palette_bank_hi [bits31:24] / palette_offset_lo [bits23:16] -- 拆分出 r6=palette_offset, r8=palette_bank
- r3: u8 palette_flags [0..0xff]
- sp[0x28]: u16 outer_loop_count (r10)
- sp[0x4]: u32 palette_mask (写入每 tile 的基础 palette 值)
- 返回: void
注: 入口 .hword 0x4680 @ 0x080ee3cc = mov r8, r0 (内部设 palette_offset from r2 bits); .hword 0x4692 @ 0x080ee3d0 = mov r10, r2 (内部设 palette_bank from r2). r8/r10 均由函数内部自行计算, 非独立 caller-set. callsite 0x080caa4e 确认 bl 前无 r8/r10 写入.

## 副作用
- [r1 .. r1 + tile_count*2]: strh 写修改后的 tile halfwords (调色板 bank 替换后的 tile 数据)
