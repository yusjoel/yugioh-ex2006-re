## plate comment (中文, ASCII 标点)
demo_shuen_state_machine 每帧调用的 demo 精灵动画槽位批量更新函数. r0=total_count (全部动画实体数量). 将 ROM 坐标表 (0x09e3cfbf, 40 字节 = 20 对坐标) memcpy 到栈上, 计算循环上界 r7 = total_count / 11, 然后对槽位索引 r5 从 0 到 min(r7, 19) 逐一调用 advance_shuen_cell_anim_frame(slot=r5, step=-1, x=table[r5*2], y=table[r5*2+1]). 通过 -1 (自动模式) 驱动每个精灵槽的帧推进和序列跳转, 各槽坐标由 ROM 表预设. 负责 shuen demo 场景中所有 OBJ 精灵的逐帧动画与 OAM 提交. Constants: MAX_SLOTS=0x13(19) / GROUP_SIZE=0xB(11) / COORD_TABLE=0x09e3cfbf.

## 参数签名
- r0: u32 total_count -- 动画实体总数 [0..209] (除以 11 得有效槽位上界; 由 demo_shuen_state_machine 根据当前活跃精灵数量传入)
- 返回: r0 = void (无返回值; bx r0 返回调用方 lr)

## 副作用
- OBJ VRAM / OAM: 每次循环调用 advance_shuen_cell_anim_frame, 批量更新所有活跃精灵槽的 cell 动画帧状态和 OAM 属性
