## plate comment (中文, ASCII 标点)
当动画帧步进控制字节 (base 0x0201b870 + 0x300 偏移处) 的 bit0 为 0 时, 表示本帧动画槽空闲, 调用 dequeue_prng_anim_entry 推进一个动画条目.
若 dequeue_prng_anim_entry 返回非零 (成功出队), 则进一步调用 read_prng_entry_flag_clear 清除该槽标志, 并检查 get_lp_display_state_word 的返回值决定下一步路径.
若返回值为 0 则分支至 switch-case 0 (LP 显示状态未就绪), 否则加载 gP1LifePoints + 0x1d0c 偏移处的 LP 数据写出.
调用场景: 由 FUN_08094dac (game loop hub, indeg 多标签) 作为 LP/动画帧推进环节调用, indeg=1.

Constants: base=0x0201b870, busy_flag_offset=0x300 (= 0xc0 << 2), bit0=busy_bit.
