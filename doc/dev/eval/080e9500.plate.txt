r0=NNS_G2dCellAnimation* pCellAnim, r1=NNS_G2dAnimSequence* pSequence.
Asserts: pCellAnim!=NULL (file=g2d_CellAnimation.c, line=0x100);
         pSequence!=NULL (line=0x101);
         pSequence->type (halfword [+6]) == 1 = NNS_G2D_ANIMATIONTYPE_CELL (line=0x103).
Calls get_anim_ctrl_frame_offset(pCellAnim) to get current frame offset.
Stores pSequence into [pCellAnim+0x18] (pCurrentCell field).
Calls set_cell_anim_sequence_raw(pCellAnim, frame_offset).
If that returns 0: calls set_anim_ctrl_position_fwd(pCellAnim) to reset frame to start.
Finally calls apply_cell_anim_frame(pCellAnim) to apply OAM data.
