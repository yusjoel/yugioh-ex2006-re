# Naming Proposal: 0x0802eb94

## 提案
- **proposed_name**: replace_chain_refs_for_slot
- **confidence**: high

## plate comment (中文, ASCII 标点)
当某个场地区域格子 (zone slot) 离开场地时, 调用本函数清理该格子在装备链节点池中残留的引用. 以 r0 传入的 zone_slot 指针为起点, 读取 slot[+0xa] 作为链头索引, 再以 node_pool (0x0201d9c0, stride=0x8) 为基址遍历整条链, 对每个节点调用 replace_slot_chain_ref_by_id 将失效引用替换. 副作用: 逐节点修改 equip_node_pool 中的引用字段, 无直接 IO 寄存器写入.

## 参数签名
- r0: void* zone_slot_ptr -- 离开场地的 zone slot 结构指针 (slot[+0xa] = 链头 node_id)
- 返回: void (pop{r0};bx r0 尾返回, 无语义返回值)

## 副作用
- [0x0201d9c0 + node_id*8 + ...]: 通过 replace_slot_chain_ref_by_id 修改节点引用字段 (传递式副作用)
