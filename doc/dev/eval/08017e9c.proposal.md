## plate comment (中文, ASCII 标点)

Trigger: settings/font_jp 场景中每次需要刷新 BG 显示行时; r0 = string row ptr, r1 = display row index.
Side effects: [0x06000000 + r1*0x580 + 0x20 .. +1408 bytes]: bios_cpu_set 清零; render_jp_string_row 写 JP 字符 tile 数据.

- BG_BASE=0xc0<<0x13=0x06000000 (BG VRAM 基址)
- CLEAR_CTRL=0x05000160 (bios_cpu_set 控制字: len=0x160=352 words, copy mode)
- LANG_MASK=7 (gState[0x6c2c] 低 3 位, 0=EN, 非0=JP)
- JP_FONT_STRIDE=2 (EN), JP_FONT_STRIDE=4 (JP)
- RENDER_WIDTH=0xc=12 (render_jp_string_row 宽度参数)
