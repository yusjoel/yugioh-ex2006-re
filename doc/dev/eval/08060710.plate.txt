Equip slot eligibility predicate for Neo Daedalus group + card tier comparison + equip guard chain.
(1) XOR player_id ^ team_bit = effective_player; call check_field_spell_neo_daedalus_group_placeable(effective_player).
(2) Extract zone_idx (bits[6:2]); call get_slot_effect_card_value(player_id, zone_idx) to get current slot effect value.
(3) Call classify_equip_card_id_tier_abcx(slot_ptr) for card tier; fail if effect value < tier (blt).
(4) Call check_slot_card_can_be_equipped(effective_player, player_id, zone_idx).
(5) Call count_monster_slots_for_player(slot_ptr, effective_player) -- if > 0 -> succeed immediately.
    If 0 -> check player direction equal + check_slot_placement_blocked_by_field_effect; all pass -> return 1.
Pure predicate, no external writes.

Constants:
  classify_equip_card_id_tier_abcx: card tier A/B/C/X classifier

Inputs: r0=SlotPtr* slot_ptr (byte[+2] bit0=player_id [0..1], byte[+3] bit1=team_flag, bits[6:2]=zone_idx [0..31])
Returns: r0 u32 (1=all conditions pass, 0=any fail)
Callees: check_field_spell_neo_daedalus_group_placeable, get_slot_effect_card_value, classify_equip_card_id_tier_abcx, check_slot_card_can_be_equipped, count_monster_slots_for_player, check_slot_placement_blocked_by_field_effect
