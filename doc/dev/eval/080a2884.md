## 修改清单

### #1 — R4 (高优先级)
**位置**: proposal 参数签名节 "返回:" 行
**问题**: "r0 = int32 (0=advance, 1=done)" 后缀 "-> void r0" 矛盾; 出口 pop{r1};bx r1 Sub-case E 不 void r0
**当前**: `返回: r0 = int32 (0=advance, 1=done; 出口 pop{r4,r5,r6,r7}; pop{r1}; bx r1 -> void r0)`
**应改为**: `返回: r0 = i32 (0=step 推进继续, 1=序列完成; 出口 pop{r4,r5,r6,r7}; pop{r1}; bx r1)`

### #2 — R6 (高优先级)
**位置**: proposal Constants 节
**问题**: (A) 7 个 card_id 字面量 [0x0001..0x1fff] 均无括号卡名; (B) `CARD_ID_1365 = 0x135b-0x30 ?` 含占位符 `?` 且算式错误 (0x135b-0x30=0x132b≠0x1365); (C) 0x135b/0x16d3 在 data.md 无记录须写 gap-marker
**当前**: 
```
- CARD_ID_1579 = 0x1579 (Monster Relief icid)
- CARD_ID_17C3 = 0x17c3 (Familiar Knight icid)
- CARD_ID_1888 = 0x1888 (Good Goblin Housekeeping icid)
- CARD_ID_135B = 0x135b
- CARD_ID_137C = 0x137c
- CARD_ID_16D3 = 0x16d3
- CARD_ID_1365 = 0x135b-0x30 ?
```
**应改为**: 
```
- CARD_ID_1579 = 0x1579 (Monster Relief)
- CARD_ID_17C3 = 0x17c3 (Familiar Knight)
- CARD_ID_1888 = 0x1888 (Good Goblin Housekeeping)
- CARD_ID_135B = 0x135b (reserved -- cid=0xFFFF, no card assigned)
- CARD_ID_137C = 0x137c (Dust Tornado)
- CARD_ID_16D3 = 0x16d3 (reserved -- cid=0xFFFF, no card assigned)
- CARD_ID_1365 = 0x1365 (The Shallow Grave)
```
