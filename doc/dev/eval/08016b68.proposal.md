# Naming Proposal: 0x08016b68

## 提案
- **proposed_name**: dispatch_jp_char_handler
- **confidence**: med

## plate comment (中文, ASCII 标点)
Function: 接收一个 Shift-JIS 双字节字符编码 (r0), 计算相对于基准值 0x8148 的偏移索引; 若偏移超出范围 [0..0x152] 则跳至共用返回-0 出口 LAB_080171d0; 否则从 ROM 跳转表 (基址 0x08016b88, 每条目 4 字节) 加载对应的处理函数指针并通过 `mov pc, r0` 跳转执行.
Trigger: 由 FUN_0801722c (字符帧解码循环) 在每个字符编码通过 XOR 解码后调用, 用于将 Shift-JIS 区间内的字符码派发给各自的渲染/转换子程序.
Side effects: 完全取决于目标处理函数; 本身无独立写内存操作.

Constants:
- CHAR_BASE=0x8148 (Shift-JIS 二区起始编码)
- CHAR_RANGE=0x152 (允许的最大偏移, 即 338 个字符)
- TABLE_BASE=0x08016b88 (函数指针跳转表地址, 每条目 4 字节)

## 参数签名
- r0: u16 char_code Shift-JIS 编码 [0x8148..0x829a]
- 返回: void (tail-call 至跳转表目标函数; 越界时透传至 LAB_080171d0 返回 r0=0)

## 副作用
- 无独立外部写操作; 副作用由目标函数承担.

## 行级注释 (精华)
- @ 08016b68: r2 = 0xffff7eb8 = -0x8148 (char_code - CHAR_BASE)
- @ 08016b6a: r1 = char_code + (-0x8148) = zero-based index into dispatch table
- @ 08016b6c: r0 = 0xa9<<1 = 0x152 (range upper bound)
- @ 08016b72: if index > 0x152, fall through to default (returns 0)
- @ 08016b74: index out of range -> jump to LAB_080171d0 (movs r0,#0; bx lr)
- @ 08016b76: r0 = index * 4 (word stride)
- @ 08016b78: r1 = TABLE_BASE (0x08016b88)
- @ 08016b7c: r0 = *(TABLE_BASE + index*4) (load fn ptr)
- @ 08016b7e: mov pc, r0 (tail-call to handler)
