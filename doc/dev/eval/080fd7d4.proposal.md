## plate comment (中文, ASCII 标点)
根据帧计数器线性映射 BG1 滚动坐标的工具函数.
输入 r0 = time_param (范围 [0..0x3c=60]); 计算公式:
  offset = (0x3c - r0) * 8 / 0x3c = 8*(1 - r0/60)
  result = 8 - offset = 8 * r0/60
最终 set_bg1_scroll_xy(result, result): 水平和垂直同步滚动同一距离.
当 r0=0 时 result=0; 当 r0=0x3c=60 时 result=8.
线性动画进入效果: 从 (0,0) 渐变至 (8,8).
退出: pop{r0}; bx r0 (Pattern B void).
Constants:
  FRAME_MAX = 0x3c = 60 (帧计数器满值)
  SCROLL_MAX = 8 (像素最大滚动距离)
