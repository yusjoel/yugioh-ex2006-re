## plate comment (中文, ASCII 标点)
从 ROM 数据块加载背景 tileset 像素和调色板到 GBA VRAM.
r0 = 数据块指针, 格式: [count u16][palette_data (count*2 bytes)][width u16][height u16][pixel_data (width*height bytes)].
调用 copy_bytes_by_halfword(dst=0x06000000, src=pixels_ptr, count=width*height) 写入 BG char VRAM;
再调用 copy_bytes_by_halfword(dst=0x05000000, src=palette_ptr, count=count*2) 写入 BG palette RAM.
退出: pop{r4,r5,r6,r7}; pop{r0}; bx r0 (Pattern B void, r0 被 lr 覆盖).
由 game_str/starter_deck 场景步分发链间接触发, 用于场景背景 tileset 初始化.
Constants:
  BG_CHAR_VRAM = 0xc0<<0x13 = 0x06000000 (GBA BG 字符 VRAM 基址)
  BG_PALETTE_RAM = 0xa0<<0x13 = 0x05000000 (GBA BG 调色板 RAM 基址)

## 参数签名
- r0: ptr  数据块基址 (ROM 资源指针, 包含 palette+pixels)
- 返回: void (pop {r0}; bx r0 = Pattern B void)

## 副作用
- [0x06000000..+width*height-1]: BG char VRAM 写入 tileset 像素数据
- [0x05000000..+count*2-1]: BG palette RAM 写入调色板数据
