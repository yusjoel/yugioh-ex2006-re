# Naming Proposal: 0x0804794c

## 提案
- **proposed_name**: enqueue_equip_slot_bitmap_update
- **confidence**: high

## plate comment (中文, ASCII 标点)
计算 (r0*16+r1) 的槽位位掩码(1<<(player*16+slot)), 然后以 (r0 xor r2)(player_xor_flag), r3(card_slot_ptr), 和计算出的位掩码调用 prepare_slot_ctx_for_equip_bitmap(FUN_0804790c); 返回 bitmap & slot_bit 是否非零(1=有效槽位在位图中). 被 43 个 duel_field 调用方(C_util_high)使用, 是装备目标选择触发的统一入口. Side effects: 通过 FUN_0804790c 间接写 gP1LifePoints 控制字段及 OAM 精灵属性队列.

## 参数签名
- r0: u8 player_id [0..1] - 玩家侧
- r1: u8 slot_idx [0..9] - 槽位索引
- r2: u8 player_xor_flag [0..1] - 与 player_id xor 后传给 FUN_0804790c 的 player 参数
- r3: ptr card_slot_ptr - 卡槽指针, 传给 FUN_0804790c
- 返回: r0 = u8 slot_in_bitmap - 1=该槽位在有效装备目标位图中, 0=不在

## 副作用
- 通过 FUN_0804790c -> FUN_08047724 间接写 gP1LifePoints 控制字段及 OAM 队列
