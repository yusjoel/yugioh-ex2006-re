# Naming Proposal: 0x080f758c

## 提案
- **proposed_name**: upload_sprite_tile_and_palette
- **confidence**: high

## plate comment (中文, ASCII 标点)
将精灵图块数据和调色板数据上传到 GBA VRAM. r0 低16=sprite_tile_id, r1=tile_struct_ptr (指向含图块宽度/数据/调色板的结构体), r2=palette_slot_id. 先用 tile_id>>11 计算 VRAM OBJ 图块区写入地址 (0x06010000 + tile_id*2), 从结构体偏移 +8 读取行数(stride), 取 +0 halfword*2+8 处的图块数据, 调用 copy_bytes_by_halfword 写入 OBJ VRAM. 再用 palette_slot_id*2 计算 OBJ PALRAM 地址 (0x05000200 + palette_slot_id*2), 从结构体 +8 读调色板起始, 调用 copy_bytes_by_halfword 写入. 返回 r0=tile_row_count (ldrh r0,[r6,#0] @ 080f75ca; 出口 pop {r1}; bx r1, Sub-case E, r0 不被 pop 覆盖). indeg=0, 运行时函数指针调用.

Constants:
- OBJ_VRAM_BASE = 0x06010000 (GBA OBJ 图块区基址)
- OBJ_PALRAM_BASE = 0x05000200 (GBA OBJ 调色板 RAM 基址)
- TILE_ID_VRAM_SHIFT = 11 (r0>>11 = VRAM 字节偏移, 因 tile_size=32 字节, tile_id*32 = tile_id<<5; lsrs#0xb = >>11 -> 实为 tile_id*2)

## 参数签名
- r0: u16 sprite_tile_id[0..32767], 低16位有效; VRAM 地址 = 0x06010000 + (tile_id>>0xb)*2
- r1: ptr tile_struct (包含: [+0]=tile_count u16, [+8]=tile_data ptr, [+0x10]=palette_ptr, ...)
- r2: u16 palette_slot_id[0..255]; PALRAM 地址 = 0x05000200 + palette_slot_id*2
- 返回: r0 = u16 tile_row_count (来自 ldrh r0,[r6,#0] @ 080f75ca; 出口 pop {r1}; bx r1 -- Sub-case E, r0 透传, 非 void)

## 副作用
- [0x06010000 + tile_id_vram_offset]: copy_bytes_by_halfword 写入 tile_data (图块像素数据)
- [0x05000200 + palette_slot_id*2]: copy_bytes_by_halfword 写入 palette_data (调色板条目)
