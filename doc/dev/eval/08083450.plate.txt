Equip target selection 4-state machine frame stepper. Reads IWRAM [0x0201b290+0x4b0] state (0/1/2/3). State 0: clears effect_node flag bits, calls count_effect_node_zone_activations; activations <=1 returns 1; else triggers op31 display, on confirm_flag selects select_equip_target_slot or set_equip_activation_state_by_mode, writes step+1/+2 returns 0. State 2: triggers op31(0x93) + set mode, step+1. States 1/3: check_activation_display_state_is_confirmed then enqueue sprite + step+1, else step-1. Other states return 1. Dispatched via equip activation display state machine fn-ptr table.
