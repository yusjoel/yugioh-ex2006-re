## 修改清单

### #1 — R4 (高优先级)
**位置**: proposal "## 参数签名" 返回行 + plate comment 出口描述
**问题**: asm 0x08093490 入口为 `push {lr}`, 出口为 `pop {r0}; bx r0`。`pop {r0}` 将栈上保存的 LR 恢复到 r0, 覆盖 dispatch_card_display_op 的返回值。此模式强制 void 返回 (feedback_r4_exit_mechanism_voids_return)。
**当前**: `返回: r0 = u32 dispatch_result (透传自 dispatch_card_display_op; 1=完成/0=无效)`
**应改为**: `返回: void (pop {r0}; bx r0 出口: r0 被保存的 LR 覆盖, callee 返回值丢弃)`; plate comment 中 "(透传 dispatch 返回值)" 改为 "(void 出口: pop {r0} 恢复 LR)"
