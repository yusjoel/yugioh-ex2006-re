# Naming Proposal: 0x08018774

## 提案
- **proposed_name**: refresh_selected_char_obj_tile
- **confidence**: med

## plate comment (中文)
由 `banlist;font_jp;settings` 模块下的 3 个待命名 caller（`0x080187e0`、`0x08018838`、`0x0801950c`）调用，在名字输入界面每次切换/确认字符时触发。函数读取 IWRAM `0x02029564`（游戏状态基址 `0x02029250 + 0xc5*4`）处的 2-bit ping-pong 槽位选择子，切换到对端槽位（bit0 XOR 1），调用 `zero_obj_vram_tiles` 清空该槽位的 34 块 OBJ VRAM 瓦片，再调用 `render_jp_text_to_vram_obj` 把当前选中假名写入那 34 块瓦片，最后将翻转后的槽位值写回原地址，完成双缓冲换页，防止字符更新时 OBJ VRAM 可见撕裂。

## 参数签名
- r0: void（无入参；所有数据从 IWRAM 固定偏移读取）
- 返回: void（无返回值，仅 OBJ VRAM 副作用 + IWRAM 槽位位域写回）

## 副作用
- [VRAM OBJ `0x06010000 + tile_idx * 32`, + 34 × 32 B] := 0（`zero_obj_vram_tiles` 用 BIOS CpuSet SWI 0x0B word-fill 清零；`tile_idx` 为 `0x012c`(300) 或 `0x014e`(334) 之一，取决于翻转后的槽位）
- [VRAM OBJ 同段] := 当前选中假名字形数据（`render_jp_text_to_vram_obj` 写入 17 × 2 block 瓦片，调色板 bank 2）
- [`0x02029564`] bits[1:0] := 原值 bits[1:0] XOR 1（ping-pong 槽位翻转写回，strb @ `0x080187c6`）
