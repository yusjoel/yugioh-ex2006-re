Start specified audio channel playback and synchronously wait for completion (blocking). indeg=0, Sub-type A. Receives r0=channel_id. Writes 0x030050cc+0x364 |= 0x2001 (DMA pending+enable). If ctrl word &0x81 nonzero loops calling tick_sound_engine_main waiting for DMA sync. If channel_id >= 0 calls reset_sound_channel_entry/start_sound_channel_playback, clears [+0x381]/[+0x37e]. Then waits for bit7 clear; reads [+0x18] loop count r6; waits for [+0x18] < r6 or bit7 clear. On completion writes [+0x364] |= 0x1 then &= 0xdfff (clear bit13). Side-effects: [+0x364] multiple writes, [+0x381] strb written, [+0x37e] := 0. Returns r0=r6=[+0x18] final value (Sub-case E: pop{r1};bx r1).
