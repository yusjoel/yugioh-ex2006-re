## plate comment (中文, ASCII 标点)
GCC libgcc 单精度浮点大于等于比较函数 (__gesf2): 解包两个 float (r0, r1) 后检测 NaN, NaN 路径执行 rsbs r0,r0,#0 -> 返回 -1 (无序, 不满足 >=), 正常路径调用 __fpcmp_parts_f.
GCC __gesf2 约定: >=0 = A>=B, 负数 = A<B 或含 NaN. 调用方通常使用 "bl compare_float_ge; cmp r0,#0; blt not_ge" 模式.
该函数在静态调用图中 indeg=0 (未被任何函数直接调用), 无函数指针引用, 属于编译器生成的未使用符号 (dead code).
与 compare_double_ge (0x0811379c) 结构完全对称, NaN 返回 -1 (rsbs) 与 compare_float_gt (0x08114100) 相同; 本函数是 6 个 float 比较函数中第 4 个 (按地址升序对应 eq/ne/gt/ge/lt/le).
