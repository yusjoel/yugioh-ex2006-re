# Naming Proposal: 0x080c412c

## 提案
- **proposed_name**: render_field_slot_card_tile_by_id
- **confidence**: high

## plate comment (中文, ASCII 标点)
从 packed slot descriptor (r0) 解包 player_id/zone_type/sub_idx, 查询对应 VRAM slot 地址 (get_field_slot_tile_vram_addr), 偏移 0x120 字节后读取缓存 card_id. 若缓存为空 (0) 则从 r1 (u16 card_id_raw) 调 internal_card_id_to_card_id 转换并写入缓存, 再调 ensure_card_id_cache_entry 确保图像已加载. 最终调用 render_field_slot_card_tile 完成 tile 渲染. 对应 dispatch_card_display_op case 0x1b (card icon render for duel field slot). Constants: VRAM_offset=0x120 (0x90*2), ensure_cache=ensure_card_id_cache_entry, gDuelActivation=0x0201e2a0.

## 参数签名
- r0: u32 slot_descriptor 打包的 slot 描述字 [各位域: bit0=player_id, bit[5:1]=zone_type, bit[13:6]=sub_idx, bit[14..]=flags]
- r1: u16 card_id_raw 原始卡 ID [0..0x1fff], 当缓存为空时写入并作 internal 转换源
- 返回: r0 = void (b LAB_080c41fc 无独立返回语义; bx lr via pop)

## 副作用
- [VRAM+0x120] := u16 converted_card_id (经 internal_card_id_to_card_id 转换后写入)
- 间接: ensure_card_id_cache_entry 可能触发图像数据加载到 sprite cache
- 间接: render_field_slot_card_tile 写入 OBJ tile VRAM
