Pack card-select scene frame count advance step function. Dispatched by dispatch_pack_card_select_substep (0x080e0fb8) via ROM step-table 0x09e495f4. Increments pack_ui_state+0x10c (elapsed frames) and writes back; if incremented value >= pack_ui_state+0x10e (target frames), clears both fields and sets r5=1 (step done). If not done calls render_pack_slot_cover_oam_sprite(1), then reads elapsed frame count mod 0xc (get_bios_div_remainder); if remainder <= 5 calls tick_pack_oam_slots_and_overlay(2). Returns r5 (0=continue/1=target reached).
