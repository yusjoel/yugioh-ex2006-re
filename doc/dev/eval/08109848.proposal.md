# Naming Proposal: 0x08109848

## 提案
- **proposed_name**: resolve_card_gfx_row_by_type
- **confidence**: med

## plate comment (中文, ASCII 标点)
根据卡片类型编号 (r0, 有效值 2-12, 内部先减 2) 从 ROM 跳转表选出对应图形数据块的起始指针 (r1) 和条目数 (r3), 然后在该块中线性搜索与 r1 (传入值 = r4) 匹配的条目, 返回该条目偏移 +2 处的 s16 值 (图形行索引). 若超出范围或未找到则返回 -1. 各 case 数据位于 ROM 0x09e60fc0-0x09e610d4, 是 card_list 场景显示时 per-type 图形行查找的核心函数.

## 参数签名
- r0: u8 card_type (卡片类型, 有效范围 2-12; 函数内 -2 后按 0-10 分派)
- r1: s16 key (要查找的匹配键值, 来自 read_card_list_field_by_index 的返回值)
- 返回: r0 = s16 图形行索引 (>=0); -1 = 未找到/越界

- 无
