Per-frame driver for the pack scene blend fadeout animation. Reads pack_ui_state+0x10c (elapsed frames), decrements, then computes the current blend brightness coefficient as elapsed*16/total. Writes BLDCNT := 0x3f84 (all layers blend to white) and BLDY := computed coefficient. When elapsed reaches zero: resets pack_ui_state+0x10e/0x10c to 0, reads pack_ui_state+0xc+0x1a (status field) bits 0/1 to select next step: bit0=1 -> state 0x12, bit1=1 -> state 0x14, else -> state 0x14. Writes pack_ui_state+0x4 := next_state and returns r6=1. Otherwise calls tick_pack_oam_slots_and_overlay(2) and returns 0. indeg=0, fn-ptr entry.
