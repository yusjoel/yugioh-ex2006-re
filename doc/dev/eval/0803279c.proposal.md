## plate comment (中文, ASCII 标点)
统计当前决斗场地上指定 card_id 的有效在场张数 (两侧共计), 返回计数. 调用前先用 FUN_0804ad48 检查该卡是否属于"扩展属性 field5 非零"的特殊类型; 若该类型不适用则跳至备用分支 (调用 FUN_080eee7c 检查 field9). 主路径: 对 player=[0..1], slot_idx=[0..4] 双层循环, 从 gDuelFieldSlots 读取各槽的 card_id (word & 0x1FFFF), 与 r9 (入口 r0 的副本) 比对; 命中后检查 [slot+0x10+offset] 的两个状态 bit (bit5 反向, bit1 反向) 以及 [r7+0] 的对应 bit 位是否为 0 (未被封禁); 全条件满足则 r8 += 1. 函数返回 r8 (u32 count). 高 indeg (117) 场景: 上层规则判断"场上是否已有 X 张该卡", 用于限制唯一性规则 (如"场上限 1 张"). Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, slot_entry=20 bytes, gDuelFieldSlots_side1=0x0201c5d8 (=0x0201c510+0xc8).

## 参数签名
- r0: u16 card_id 要统计的卡牌 ID [1..0xfa6] 或扩展 ID; 入口通过 MOV r9,r0 保存为比较基准; r8 清零为计数器
- 返回: r0 = u32 count 该 card_id 在全场地有效在场的张数 (含双方); 调用方通常 cmp r0,#0 判断是否已有在场副本

## 副作用
无外部写入; 只读 gDuelFieldSlots (0x0201c510) 和 DAT_0801c5d8 侧 2 基地址 (0x0201c5d8).
