## plate comment (中文, ASCII 标点)
Function: 初始化卡包场景 VRAM 和显示状态. 无 APCS 输入参数 (r0 在入口被 ldr gPrng 覆盖). 执行顺序: (1) 向 gPrng+0xba*2=gPrng+0x174 写 0x601 (显示控制值); (2) 向 DISPCNT=0x04000000 写 0 (关闭显示); (3) 调用 reset_display_and_obj_vram (清空 OBJ VRAM 和显示寄存器); (4) 调用 store_ewram_ctx_ptr_and_clear_mode_flags (写 EWRAM 上下文指针, 清除 mode flags); (5) 向 BG0CNT-BG3CNT 连续写 4 个 halfword (bg_ctrl[0..3]={0x4,0x105,0x206,0x307}); (6) 调用 reset_all_bg_scroll_regs_and_shadows + upload_pack_vram_and_palette; (7) 三次 zero_fill_by_halfword 清零 0x06004000/0x06010000 及另一区域 (r4=0x8000 halfwords = 0x10000 bytes each call). 出口 pop {r0}; bx r0 (Sub-case E, r0 被 pop 覆盖 -> void).

Side effects:
- [gPrng+0x174] := 0x601
- [DISPCNT=0x04000000] := 0
- [BG0CNT=0x04000004] := 0x0004
- [BG1CNT=0x04000006] := 0x0105
- [BG2CNT=0x04000008] := 0x0206
- [BG3CNT=0x0400000a] := 0x0307
- VRAM 0x06004000 (0x10000 bytes): zero fill
- VRAM 0x06000800 (0x8000 halfwords): zero fill via upload_pack_vram_and_palette
- VRAM 0x06010000 (0x10000 bytes): zero fill
- EWRAM ctx ptr: via store_ewram_ctx_ptr_and_clear_mode_flags

Constants:
- DISPCNT = 0x04000000
- BG0CNT = 0x04000004
- PRNG_CTRL_FIELD_OFFSET = 0xba*2 = 0x174
- PRNG_CTRL_VALUE = 0x601
- BG0_CTRL = 0x0004 // BG0 priority 0, tile base 0
- BG1_CTRL = 0x0105 // BG1 priority 1, tile base 1
- BG2_CTRL = 0x0206 // BG2 priority 2, tile base 2
- BG3_CTRL = 0x0307 // BG3 priority 3, tile base 3
- VRAM_OBJ_BASE = 0x06004000
- VRAM_BG_BASE = 0x06010000
- ZERO_FILL_SIZE = 0x80<<8 = 0x8000 halfwords (= 0x10000 bytes per call)
