# Naming Proposal: 0x080c6800

## 提案
- **proposed_name**: transform_zone_oam_coords_by_player
- **confidence**: high

## plate comment (中文, ASCII 标点)
根据当前对手玩家侧 (r0 vs [0x0201e2a0+4]^1) 和 zone 类型 (r1, [0..15]) 对 OAM 坐标 (r2=x, r3=y) 进行镜像变换, 返回调整后的 packed 坐标 (y<<16|x). 由 FUN_080bede4/FUN_080c5444/FUN_080c699c/FUN_080c8aa8 在 duel_field/card_ids 场景调用. r1 分派到 switch 表 (16 case): case 1/1 默认为正/镜像两路 (player_id^1 flip), 每 case 按 zone 类型的布局位置对 x (±0x18/0x78/0x90) 和 y (±0x18/0x30) 施加偏移, 并由 player_id 一致性决定正向还是取反.

Constants:
- 0x0201e2a0 = duel 全局 ctx base (DAT_080c6838)
- [ctx + 4] = 当前对手 player_id (eors r3,#1 取当前自方)
- 0x4c/0xac = r2 基础 (case-default: player_id 匹配用 0x4c, 否则 0xac)
- 0x44/0x2c = r3 基础 (case-default)
- 0x18/0x30/0x78/0x90 = 各 zone 类型的像素偏移
- switch 表 16 entry (r1=[0..15]), 多数为 caseD_1 (default)

## 参数签名
- r0: u8 player_id -- 查询玩家 ID [0..1] (与 ctx.current_player^1 比较确定镜像)
- r1: u8 zone_type -- zone 类型索引 [0..15] (分派 switch 选择偏移规则)
- r2: u16 x_coord -- 输入 X 坐标 [0..0x1ff] (被调整)
- r3: u16 y_coord -- 输入 Y 坐标 [0..0xff] (被调整)
- 返回: r0 = u32 packed_result -- bits[31:16]=adjusted_y, bits[15:0]=adjusted_x

## 副作用
- 无外部写入 (纯计算函数, 仅返回值)
