# Naming Proposal: 0x08014af0

## 提案
- **proposed_name**: calc_bg_screenmap_block_offset
- **confidence**: high

## plate comment (中文, ASCII 标点)
根据 bg_index (r0=[0..3]) 查询对应 BGxCNT 的 screen_size 字段, 再结合 tile_x (r1) 和 tile_y (r2) 计算目标图块所在 screen block 相对于 screen map 基址的字节偏移量. GBA screen map 中每个 32x32 图块区域占 2KB (0x800 字节), 超出 32 格的坐标需跨 screen block 寻址. 返回值供调用方叠加到 BGxCNT 的 screen_map 基址后作为实际写入目标地址. 被 FUN_080165bc (BGDT 应用器) 在写 tile region 前调用.

Constants: 0x800 = 1 screen block size (32x32 tiles, 2KB); screen_size 0=32x32, 1=64x32, 2=32x64, 3=64x64.

## 参数签名
- r0: u8 bg_index [0..3] -- BG 编号, 用于选择 bgX_cnt_get_screen_size
- r1: u16 tile_x [0..63] -- 水平图块坐标
- r2: u16 tile_y [0..63] -- 垂直图块坐标
- 返回: r0 = u32 screen block 字节偏移 {0, 0x800, 0x1000, 0x1800}

## 副作用
- 无外部副作用; 内部调用 bgX_cnt_get_screen_size 读取 BGxCNT 寄存器 (只读)
