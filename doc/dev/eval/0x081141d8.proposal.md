# Naming Proposal: 0x081141d8

## 提案
- **proposed_name**: compare_float_le
- **confidence**: high

## plate comment (中文, ASCII 标点)
GCC libgcc 单精度浮点小于等于比较函数 (__lesf2): 解包两个 float (r0, r1) 后检测 NaN (kind > 1 -> 返回 +1 = 无序, 不满足 <=), 正常路径调用 __fpcmp_parts_f.
GCC __lesf2 约定: <=0 = A<=B, 正数 = A>B 或含 NaN. 调用方通常使用 "bl compare_float_le; cmp r0,#0; bgt not_le" 模式.
该函数在静态调用图中 indeg=0 (未被任何函数直接调用), 无函数指针引用, 属于编译器生成的未使用符号 (dead code).
与 compare_double_le (0x08113834) 结构完全对称, NaN 返回 +1 (无 rsbs), 是 6 个 float 比较函数中第 6 个 (最后一个).

## 参数签名
- r0: f32 a -- 单精度浮点 A (IEEE 754 bit-pattern)
- r1: f32 b -- 单精度浮点 B (IEEE 754 bit-pattern)
- 返回: r0 = s32; <=0 = A<=B, 正数 = A>B 或含 NaN

## 副作用
