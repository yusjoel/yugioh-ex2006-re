# Naming Proposal: 0x0810017c

## 提案
- **proposed_name**: write_card_list_slot_tiles_to_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
card_list 界面单槽 OBJ tile 写入函数. 接收 r0=slot_index ([0..N]), 以 r0*24(r0*3<<3) 计算到 ROM 数据表 (0x09e5fda0) 中该槽结构体偏移. 外层循环 r5=0 to [base+0xf]-1 (row_count), 内层循环 r3=0 to [base+0xe]-1 (col_count), 每次以 ldrh 取 tile_id([src+r5*2*col+r3*2]), 加 [base+0x10](tile_base_offset) 再 OR [base+0x14](pal_idx) <<0xc, 用 strh 写入 VRAM OBJ 0x0600f800 (DAT_081001dc) 目标行列偏移. 循环后从 [base+0x12](tile_width) 遍历, 以 copy_bytes_by_halfword 追加第二 tile 层.

## 参数签名
- r0: uint32 slot_index 槽位索引 [0..0xd] (max 14 槽, 依据: FUN_081014e4 clear_all_card_list_slot_flags 循环 r4=0..0xd=13, 共 14 次)
- 返回: r0 = uint32 1 (always)

## 副作用
- [VRAM OBJ 0x0600f800 + row_offset + col_offset]: strh tile_id | (pal_idx << 12) 写入 tile 属性
- [VRAM OBJ 0x0600f800 + extra_row_offset]: copy_bytes_by_halfword 追加 tile_width * 0x20 字节
