## plate comment (中文, ASCII 标点)
统计在 r9/r8 所指定二维 zone 表中, 满足 zone flag 标记为 0x40 或 0x80 且
check_card_field5_is_nonzero(card_id) 返回 true 的格数.
参数: r0=player_side [0..1] (bit0, 存 r5); non-APCS r9=player_stride 乘数 (caller-set);
non-APCS r8=zone 数组基址 (caller-set, 指向 gP1LifePoints + player*r9 + 0xba*8 区域).
内层双循环 (player=0..1 x slot=0..count): 读 zone flag 字节; ==0x40 或 ==0x80 则进入
check_card_field5_is_nonzero 路径, 命中则 r6++.
返回 r6=满足条件的格数.
Non-APCS 输入: r9=player_stride (caller-set, 乘以 player_side 偏移); r8=zone_base (caller-set).
Constants: gP1LifePoints=0x0201c4e0, flag_byte_offset=0xf1*8 (0x788), zone_flag_A=0x40, zone_flag_B=0x80.

- 返回: r0 = u32 count [0..max]; 满足条件格数
