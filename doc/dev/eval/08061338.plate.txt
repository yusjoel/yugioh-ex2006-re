Equip slot activation eligibility predicate, checks paired slot effect type and zone field5:
(1) r1 (second_slot_ptr) non-NULL check;
(2) compare r1_slot player_id XOR byte[+3].bit6 with (1-r0_slot.player_id) for opposing side match;
(3) iterate effect slots on r1_slot (up to slot[+4] 3-bit count), find effect type == 0xe;
(4) for type 0xe slot, read zone_type via read_effect_slot_zone_type, look up
    gP1LifePoints[+0x10e0+zone_idx*4] and call check_card_field5_is_nonzero;
    returns 1 if field5 nonzero.
Constants: EFFECT_TYPE_E=0xe, ZONE_FIELD5_BASE=0x87<<5=0x10e0, PLAYER_STRIDE=0x868.
