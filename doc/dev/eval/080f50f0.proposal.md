# Naming Proposal: 0x080f50f0

## 提案
- **proposed_name**: format_decimal_byte_to_buf
- **confidence**: high

## plate comment (中文, ASCII 标点)
将 r1 传入的十进制整数按最多 10 位拆分为 ASCII 数字字节 ('0'+digit), 从低位到高位填入栈帧缓冲区 (以 '0'=0x30 初始化全部槽位), 然后调用 append_text_to_buf_end 把有效位内容追加到 r0 指向的目标文本缓冲区. 与 format_decimal_halfword_to_buf (0x080f508c) 互为姐妹函数: 本函数输出 ASCII 字节编码数字 (适用于 JP 模式或字节宽度字符集), 后者输出半字编码数字. 由 FUN_080f5228/FUN_080f528c 在 gSettings bits[2:0]!=0 (日文或宽字符模式) 时调用.

## 参数签名
- r0: u8* dst_buf (目标文本缓冲区指针)
- r1: s32 value (待格式化的十进制整数, 非负)
- r2: u8* fmt_tail (格式化后追加的剩余模板指针)
- 返回: void

## 副作用
- [栈帧 sp+0x0..sp+0xa]: 写入最多 11 字节 ASCII '0' 初始化值及数字字节 (临时)

## 行级注释 (<=30 行精华)
- @ 080f50f0: 分配 0xc 字节栈帧, r1=0x30 (ASCII '0') 作为填充值
- @ 080f50fe: 以 '0' 初始化所有槽, 向低地址循环
- @ 080f510a: 在缓冲区末尾写 NUL 终止符

- @ 080f512a: value<=0 则终止循环
- @ 080f513a: 调用 append_text_to_buf_end 追加有效数字到 dst_buf
