# Naming Proposal: 080364b0

## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
检查 player_side 一侧 slot_idx 号槽位上的卡牌是否满足效果发动条件. 函数先验证槽位有卡 (card_id != 0), slot_idx <= 4, 全局阶段标志 [0x0201B750] == 0; 任一不满足则立即返回 0. 通过后将 card_id 与约 10 个特定魔法/陷阱牌 ID 白名单对比, 并依次调用 check_card_matches_active_effect_slot / count_slot_equip_list_matches / check_slot_card_is_equip_type / FUN_0803279c / FUN_08032654, 将各路径结果以 bit OR 方式累积进 r7, 最终以 0 (不符合) / 2 (装备链命中) / 3 (特殊效果命中) 形式返回. 兄弟函数 FUN_08036674 处理另一套卡牌 ID 白名单, 两者共享调用方集合.

Constants:
- 0x0201c510 = gDuelFieldSlots (EWRAM 槽位数组基址)
- 0x868 = player stride (每玩家侧槽位块字节数)
- slot_entry = 20 bytes, slot[0] bits 0..12 = card_id
- slot[0x8] = u16 chain head / card state flag
- slot[0x10+offset] = equip/spell info word
- 0x0201b290 = gDuelPhaseFlags (game phase state base)
- 0x4C0 = 0x98*8 (phase flag offset → 0x0201B750)
- 0x1709 / 0x13cd / 0x12a8 / 0x164e / 0x17d3 / 0x1814 / 0x1814+6=0x181a = 效果条件卡牌 ID 白名单
- 0x10f4 = check_card_matches_active_effect_slot 调用时使用的代理牌 ID
- 0x1693 = count_slot_equip_list_matches ref_card_id 参数
- 0x1667 = FUN_0803279c 参数
- 0x17a1 = FUN_08032654 参数

## 参数签名
- r0: u32 player_side (bit0 = 侧别, 0=P1/1=P2)
- r1: u32 slot_idx [0..4] (槽位索引, 5 表示超界直接返回 0)
- 返回: r0 = u32 eligibility_flags (0=不满足; 2=装备链命中; 3=特殊效果命中)

## 副作用
无外部写入; 仅读 EWRAM gDuelFieldSlots 和 gDuelPhaseFlags.
