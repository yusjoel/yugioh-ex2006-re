# Naming Proposal: 0x080f0754

## 提案
- **proposed_name**: encode_4bpp_nibbles_to_tile_row
- **confidence**: high

## plate comment (中文, ASCII 标点)
由 FUN_080f07ec 和 FUN_080f08ec (字形行渲染循环) 在每字符逐行编码时调用. 入参: r0=目标 tile 行指针 (VRAM word ptr), r1=y 行偏移, r2=x 列偏移, r3=color 值, sp[0x14]=像素编码字 (r7 caller-frame 值).
函数从 ROM 表 0x09e4f422 (字形编码 lookup table) 按像素字提取上下半字节索引, 组合出 4bpp nibble 对; 经过 x*15-x*15 = 0 net 运算计算颜色乘积; 最终将颜色编码 nibble 写入目标 word [r0+0x0] 和 [r0+0x20] (两行), 若像素字非零还写 [r0+0x40].
副作用: 写入 tile VRAM word at r0, r0+0x20, (r0+0x40).

Constants:
- NIBBLE_LUT = 0x09e4f422 (ROM 字形 nibble 编码表, 16 条目)
- TILE_ROW_STRIDE = 0x20 (4bpp tile 行字节数 = 32)
- MAX_NIBBLE_IDX = 0x0f (nibble 索引掩码)

## 参数签名
- r0: ptr 目标 tile word 指针 (写 [r0]/[r0+0x20]/[r0+0x40])
- r1: s32 y_offset 行偏移 (右移 3 位得 tile 行号, 低 3 位是像素行内偏移)
- r2: s32 x_offset 列偏移 (右移 1 位得 nibble 列)
- r3: u32 color_value 颜色值 (乘以 nibble 系数写入 tile word)
- r7 (caller-frame, sp[0x14]): u32 pixel_word 像素编码字 (bits[31:24]/[27:24]/[23:16] 为三行 nibble 索引)
- 返回: void (pop {r4,r5,r6,r7}; pop {r0}; bx r0)

## 副作用
- [r0 + 0x0] word := BIC/OR color nibble (行 0)
- [r0 + 0x20] word := BIC/OR color nibble (行 1)
- [r0 + 0x40] word := BIC/OR color nibble (行 2, 条件写, pixel_word 高字节非零时)

## 行级注释 (<=30 行精华)
- @ 080f075a: lsls r4,r3,#0x10 -> 截断 r3 到 u16 pixel_word
- @ 080f0762: lsrs r2,r4,#0x1c -> 提取高 nibble (bit[31:28]) 为 LUT 索引
- @ 080f0772: ldrh r1,[r1,#0] -> 从 nibble LUT 取高半字
- @ 080f0776: ldrh r2,[r2,#0] -> 从 nibble LUT 取低半字
- @ 080f077a: 组合 orrs r3,r2 -> 完整 nibble 字
- @ 080f077c: lsls r2,r3,#4; subs r2,r2,r3 -> 计算 nibble mask (x*15)
- @ 080f0784: muls r2,r3 -> 颜色 * nibble 系数
- @ 080f0788: str r1,[r0,#0] -> 写目标 tile word 行 0
- @ 080f07ba: cmp r4,#0 -> 若第 3 行 pixel nibble 为 0 则跳过 [r0+0x40]
