## plate comment (中文, ASCII 标点)
与 enqueue_zone_equip_sprite_if_slot_matches (0x0806d514) 结构对称, 但使用不同的基址寄存器 (r8 = gDuelFieldSlots via .hword 0x4688, r12 = DAT_0806d768 = 0x0201c510). 从 effect_node [r7+2] 提取 player_id 和 zone_type, 计算区域偏移, 对比 col 与 [r7+4] bits[9:3] 是否匹配; 若匹配且 [slot+8] != 0, 读取 LP 字段 [0x1cb8] 确认 player 侧, 调用 enqueue_sprite_attr_with_mode 入队精灵.

调用场景: indeg=0; 仅通过运行时函数指针调度到达. 与 0x0806d514 为同一簇内 variant.

副作用: 通过 enqueue_sprite_attr_with_mode 写精灵队列; [sp+0] 写 mode=0 (栈局部).

Constants: gDuelFieldSlots=0x0201c510 (DAT_0806d768), player_stride=0x868 (DAT_0806d764), lp_extra_offset=0x1cb8 (DAT_0806d76c), SPRITE_TYPE=0x12/0x22 (type based on LP player check).
