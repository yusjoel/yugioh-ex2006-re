## plate comment (中文, ASCII 标点)
从动画状态结构体中读取调色板子偏移 [state+0x8], 并将调色板数据拷贝到 OBJ 调色板区域指定槽位. r0=anim_state_ptr, r1=pal_slot_index. [state+0x8] 为 sub_offset; state+sub_offset+0x4 为调色板数据源指针; [state+sub_offset+0x0] 为调色板颜色数量 (halfword). pal_slot_index 乘以 32 字节 (lsls #0x18 >> 0x13 = *32) 后加 OBJ_PAL_BASE (0x05000200) 得目标地址; 复制颜色数量*2 字节. 调用 copy_bytes_by_halfword. 叶子函数. indeg=0.

- OBJ_PAL_BASE = 0x05000200 (OBJ palette VRAM)
- PAL_ENTRY_SIZE = 2 (bytes per color)
- PAL_SLOT_SIZE = 0x20 (32 bytes = 16 colors * 2; slot_index<<5)
- PAL_SLOT_SHIFT = 0x18 (<<0x18 >> 0x13 = <<5 = *32)
- PALETTE_SUB_OFFSET = state+0x8 (sub offset field)
