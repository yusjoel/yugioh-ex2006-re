## plate comment (中文, ASCII 标点)
title_ex scene 单个卡包调色板条目加载. r0=pack_idx 经两步除法 + 模运算定位 EWRAM 0x02029eb0 内调色板数据: 先 pack_idx/0xf0 -> r5 (行组), 再 pack_idx/0x14 mod 0xc -> r1 (列 [0..11]). 计算 src = EWRAM_base + r5*384 + 0x88 + r1*32 (即 ctx 内 grid 布局的 per-pack 调色板区域). 调用 bios_cpu_set(src, 0x050001e0, 0x04000008) 将 8 halfword (16 bytes) 调色板数据从 EWRAM 拷贝到 BG 调色板 RAM 末尾区域 (0x050001e0). 被 FUN_080fda04 (title_ex scene 主驱动, tags: title_ex) 以 pack_idx 调用.

## 参数签名
- r0: u32 pack_idx - 卡包序号, 用于 grid 定位 [0..N-1]
- 返回: void (pop {r4,r5,r6}; pop {r0}; bx r0 - Sub-case E: r0=lr, 无独立返回值)

## 副作用
- [BG palette 0x050001e0..+0x10]: 从 EWRAM ctx 对应偏移拷贝 16 bytes 调色板数据
