Function: 基于卡类型的 equip slot 资格判定, 不含 prerequisites 检查. r0=card_ptr,
r1=player_side, r2=slot_idx.
先检查 gDuelFieldSlots (player_side, slot_idx) 的 card_type_bits[12:0] 是否非零;
再检查 card_ptr[+2] bit0 (owner) == player_side -> 失败 0 (equip 目标须属对手侧);

若 slot[+8]==0, 调用 query_slot_card_type_eligibility(card_ptr, player_side, slot_idx),
返回值==0 (eligible) 则返回 1, 否则 0.
比其他同族函数少了 check_zone_slot_equip_prerequisites 调用.
indeg=0, 纯 predicate, 无副作用.
