# Naming Proposal: 0x080edf00

## 提案
- **proposed_name**: upload_tile_and_palette_from_struct
- **confidence**: med

## plate comment (中文, ASCII 标点)
将一个复合数据结构中的 tile 图像数据和调色板数据分两次通过 copy_bytes_by_halfword
分别上传到 OBJ VRAM (0x06004000+) 和调色板 RAM (0x05000000+).
r0=tile_index (用于调色板 RAM 写偏移: tile_index*2 + 0x05000000; u16 截断存入 r4),
r1=src_tile_ref (用于 VRAM 写偏移: src_tile_ref*32 + 0x06004000; lsls r1,#16 >> r0,#11 计算),
r2=data_struct 指针, [r2+0]=width halfword, r6=r2+width*2+8 为调色板子结构.
被两个 bg/vram/palette 相关 caller 调用, 是将字体/图标资源一次性写入 VRAM 和调色板的工具函数.
返回 [r6] (调色板子结构第一个 halfword).

## 参数签名
- r0: u16 tile_index (调色板 RAM 写偏移来源: 0x05000000+tile_index*2; 入口 lsls/lsrs u16 截断存入 r4)
- r1: u16 src_tile_ref (VRAM 写偏移来源: 0x06004000+src_tile_ref*32; 入口 lsls r0,r1,#16 后 lsrs r0,#11 计算)
- r2: const void* data_struct (数据结构指针; [+0]=width halfword, 内含 tile/palette 数据)
- 返回: r0 = u16 [data_struct+width*2+8] (调色板子结构首个 halfword)

## 副作用
- [VRAM 0x06004000 + src_tile_ref*32]: 写入 tile 图像数据 (width<<5 字节)
- [PAL 0x05000000 + tile_index*2]: 写入调色板数据 ([r6]*2 字节)
