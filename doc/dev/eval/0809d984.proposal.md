## plate comment (中文, ASCII 标点)
由 equip 激活主循环驱动器 (0x08094c60) 调用. 函数是装备激活显示状态机的主分派函数, 以 [gP1LifePoints+0x1d1c] 作为阶段计数器 (phase counter, 0..0x14=21 阶), 通过跳转表 (0x0809da00, 21 个 case) 路由到各子阶段处理程序. 入口先检查 Last Turn 扫描条件 ([gP1LifePoints+0x1ce8+player*0x868+0x11c] 状态字 bit23) 并调用 scan_equip_zone_for_last_turn_activation; 若激活成功返回 0. 各 case 的职责: case 0 提交 OAM sprite attr (enqueue_sprite_attr_record) 并清零两个子计数器; case 1 提交 LP 条 sprite (submit_lp_bar_sprite_row_by_type); case 2 increments phase counter + 清零子状态; case 3 扫描 equip chain 槽 (0..9), 对 icid=0x0fee/0x150e 匹配条目分别调用 enqueue_equip_set_slot_sprite_by_zone_col 或 enqueue_sprite_attr_for_zone_card_id_lookup + enqueue_equip_slot_bitmap_update; case 4 扫描对手侧 equip 槽 (0..9), 同上分支; case 5 双 player 双 zone 全场扫描 (find_equip_chain_pair_across_field + check_equip_eligibility_via_request_buf + enqueue_equip_slot_bitmap_update + query_equip_zone_slot_target_bit); case 6 扫描 equip chain node (find_equip_chain_node_min_count_by_pred) 并提交 sprite; case 7 条件 card name 显示 (card_name_lookup_by_internal_id + format_game_text + FUN_080933b4) 或 LP 显示 (enqueue_lp_display_row_if_enabled) 或 equip bitmap 更新; case a/b 扫描 ROM 卡牌列表 (0x09e476b0) 激活节点 (FUN_0810e5cc 逐项调用, 最多 0x22 项); case c 扫描另一 ROM 列表 (0x09e47738, 最多 0x18 项); case 0x14 扫描第三 ROM 列表 (0x09e4779c, 最多 4 项). 返回 0 (继续) 或 1 (阶段完毕).
