# Naming Proposal: 0x08014ea0

## 提案
- **proposed_name**: measure_str_bytelen
- **confidence**: high

## plate comment (中文)
由 `FUN_08014eb4`（GL/GL_File.c 中的字符串搜索函数）在执行子串搜索前调用，用于分别测量 `pSrc`（被搜索串）和 `pKey`（搜索关键字）的字节长度，以确定搜索范围上界。本函数逐字节遍历直到遇到空字节，返回不含终止符的字节数。与 `count_str_charlen`（0x0801455c，多字节字符计数）不同，本函数只做原始字节计数，不感知游戏自定义编码宽度。调用方将两次返回值之差加一作为搜索循环次数上限。

## 参数签名
- r0: `const u8*` str — 指向待测量的空字节终止字符串，范围任意有效内存地址（调用方在 `FUN_08014eb4` 中分别以 `pKey` 和 `pSrc` 传入）
- 返回: r0 = `u32` bytelen — 字符串字节长度，不含终止 `\0`（等同于 C `strlen` 语义）

## 副作用
无外部副作用（纯读操作，仅使用 r0/r1/r2 局部寄存器，无写回外部内存，无栈帧）。
