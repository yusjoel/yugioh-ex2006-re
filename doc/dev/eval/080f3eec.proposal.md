# Naming Proposal: 0x080f3eec

## 提案
- **proposed_name**: blit_tile_nibble_row_lsb
- **confidence**: high

## plate comment
将 4bpp 色彩索引 color 按低位优先(LSB nibble first)顺序展开为像素掩码, 并逐行 OR-写入目标 VRAM 地址 dst. 与 blit_tile_nibble_row_msb (0x080f34dc) 互为镜像: 掩码顺序从 0x0fff -> 0xfff0 -> 0xff0f -> 0xf0ff (LSB first vs MSB first). 由 font_jp/game_str 渲染路径调用. 先检查 gPrng+0x14 bit7 高色深标志, 若置位透传给 blit_tile_color_to_vram_region; 否则展开 nibble 并按双层循环写入 VRAM (外层 row, 内层 16 列).

Side effects: 写 VRAM[dst..dst+row_count*0x80] halfword; dst 每次推进 0x400 (row 间距 0x80*8); 无 IO 寄存器副作用.

Constants:
- HIGH_COLOR_MODE_FLAG = 0x80 // gPrng+0x14 bit7
- MASK_NIBBLE0 = 0x00000fff // LSB nibble AND mask (bits[3:0])
- MASK_NIBBLE1 = 0x0000fff0 // nibble1 mask (bits[7:4])
- MASK_NIBBLE2 = 0x0000ff0f // nibble2 mask (bits[11:8])
- MASK_NIBBLE3 = 0x0000f0ff // nibble3 mask (bits[15:12])
- ROW_STRIDE = 0x400 // dst 行间距 (0x80 << 3)

## 参数签名
- r0: u16* dst VRAM 行起始地址
- r1: u16 color 4bpp 颜色索引 [0x0..0xf]
- 返回: void (pop {r0};bx r0 - r0 被 lr 覆盖)

## 副作用
- [r0..r0+row_count*0x80]: OR-write u16 按 LSB nibble-first 顺序写 tile 像素行
