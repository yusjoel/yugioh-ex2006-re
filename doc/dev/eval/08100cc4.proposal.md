# Naming Proposal: 0x08100cc4

## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
由 FUN_080fefaa (display/blend/window/bg/card_frame/card_stats/font_jp/frame_counter 场景帧主循环) 唯一调用, 负责将卡牌列表中 4 行 (r6: 0..3) 的行指示精灵写入 OAM. 函数首先检查 [0x0202a4d0+0x16] bit0 是否置位, 若未置位则跳过所有写 OAM. 对每行: 从 [0x0202f3c0+0x78] 处的行数组首地址 (r3) 读当前行 entry, 以 [entry+0x10] 取 y 偏移, 加当前行索引作为新 y; 计算 OAM attr0 (y | OAM_ATTR0_OBJ_MODE_MASK=0xC00, bits[10:11] = OBJ mode field, window/blend/normal), 连续调用两次 write_oam_entry_priority_aware 写两个相邻 sprite (主体 + 副体, tile 偏移 TILE_4BPP_BYTE_STRIDE=8 bytes = 1 tile in 4bpp 8x8).

Constants:
  OAM_ATTR0_OBJ_MODE_MASK = 0xC00  // attr0 bits[10:11]: OBJ mode field (normal/window/semi-transparent/bitmap), not priority
  TILE_4BPP_BYTE_STRIDE        = 8      // bytes per 4bpp 8x8 tile; used as tile offset between adjacent sprites

## 参数签名
- r0..r3: (无参数, 全部从全局状态读取)
- 返回: r0 = u32 1 (固定)

## 副作用
- 间接通过 write_oam_entry_priority_aware (FUN_08107b90) 写 OAM 缓冲区 (每行 2 个精灵, 共 8 次调用)
