## plate comment (中文, ASCII 标点)
FUN_0810cda0 (sound channel 停止/切换函数) 的内部延续入口. r5 = 0x030050cc IWRAM 引擎基址; r1 = 偏移 0x38b. 读取 [base+0x38b] 字节 (level 计数): 若 >0 则在对应 level 的 0x20-byte 控制块中设置 loop_active 标志 ([r5 + (level-1)*0x20 + 0x3e] := 1). 随后将 playback 指针前进: next_ptr([+8]->[+4]), 下一 next_ptr([+10]->[+0xc]) 均前移并清零原槽; 更新 channel_id halfword 及状态 halfword [+0x364] (or bit7, and ~0x5000). 由 FUN_0810cda0 fall-through 进入, callgraph indeg=0.

- LOOP_CTRL_STRIDE=0x20 (每个 loop control block 大小)
- LOOP_ACTIVE_OFF=0x3e (loop_active flag 字节在 control block 内偏移)
- STATUS_OFF=0x364 (0xd9*4, channel 状态 halfword 偏移)
