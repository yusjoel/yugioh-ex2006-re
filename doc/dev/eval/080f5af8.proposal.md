# Naming Proposal: 0x080f5af8

## 提案
- **proposed_name**: blend_palette_entries_with_factor
- **confidence**: med

## plate comment
对调色板条目数组做 alpha 混合. 从 gPrng+0x20e 读取 6-bit 混合系数 factor (AND 0x3f), 对 src (r1) 指向的 count (r2) 个 BGR555 条目逐个处理: 提取 R/G/B 三通道 (5-bit), 各乘以 factor 后右移 5 位 (定点乘), 若结果为负则加 0xff 修正, 再钳位到 [0..0x1f]; 将结果打包为 BGR555 写入 dst (r0). r3 为 Q16 定点混合基准: bits[31:16] 用作正向加法基准 (路径 B, factor>0x1f), bits[15:0] 保留为零基准; indeg=0, 无 callsite 可追踪 r3 构造语义. 由 blend/display 路径调用.

Side effects:
- [r0..r0+count*2]: 写入混合后的 BGR555 halfword

Constants:
- BLEND_FACTOR_ADDR = gPrng+0x20e // 混合系数 halfword (AND 0x3f 使用)
- CHANNEL_MASK = 0x1f // 5-bit 通道掩码
- FIXED_SHIFT = 5 // 定点乘除: value*factor >> 5
- FIX_NEG = 0xff // 负值修正量 (adds #0xff before asrs)

## 参数签名
- r0: u16* dst 输出调色板数组
- r1: const u16* src 源调色板数组
- r2: u8 count 条目数 [1..255]
- r3: u32 blend_base_q16 混合基准 Q16 定点值: bits[31:16] = 正向加法基准 (路径 B factor>0x1f 使用, lsrs r0,r3,#0x10 提取后 subs r3,r3,r0); bits[15:0] = 零基准 (lsls r3,r3,#0x10 保留低位); indeg=0 无 callsite 可验证, 描述为静态机械操作推导
- 返回: void (pop {r0};bx r0)

## 副作用
- [r0..r0+count*2]: 混合后 BGR555 写入
