# Naming Proposal: 0x080c0204

## 提案
- **proposed_name**: write_nibble_to_bg_tile_cell
- **confidence**: med

## plate comment (中文, ASCII 标点)
在 BG tile VRAM 内指定的二维坐标 (tile_x=r1, tile_y=r0) 写入单个 nibble 颜色值 (r2=palette_idx, r3=vram_row_stride). 先将 tile_x / tile_y 坐标转换为 VRAM halfword 地址 (VRAM_BASE = 0x06010000, 以 1024 halfword 行步进), 根据 tile_y 奇偶确定写高 nibble 还是低 nibble, 修改目标 halfword 并写回. 被 FUN_080c0274 (批量 nibble 写入循环) 两次调用.

Constants:
- VRAM_BG_TILE_BASE = 0x06010000 (BG tile 数据 VRAM 基址)
- TILE_ROW_STRIDE = 0x400 (1024 halfword/行 = 0x800 字节)
- TILE_X_STRIDE = 0x40 (64 halfword/列 = 0x80 字节, lsls r1,r0,#0xa)
- NIBBLE_HIGH_MASK = 0xff00 (高 nibble 位置掩码)
- NIBBLE_LOW_MASK = 0x00ff (低 nibble 位置掩码)

## 参数签名

- r1: s16 tile_y [5..13] -- tile 行坐标 (有符号; 转换为行偏移: y/8*64 halfword). Callsite (FUN_080c0274 @ 080c02be/080c02e0): r1 = r10 + r7, 其中 r10 = hi16(FUN_080c0274.r0) in {5,6}, r7 = 外层循环计数 [0..7]; 观测范围 [5..13].
- r2: u8 palette_nibble [0..15] -- 要写入的调色板索引 (nibble, 4 位)

- 返回: void (pop+bx)
