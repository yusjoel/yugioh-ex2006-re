# Naming Proposal: 0x08100980

## 提案
- **proposed_name**: render_card_name_label
- **confidence**: high

## plate comment (中文, ASCII 标点)
card_list / card_stats 场景中渲染单张卡片名称的核心函数. r0 为卡片 ID, r1 为渲染模式标志 (bit1 为 0 = 走 resolve_card_gfx_pointer_by_type 路径, bit1 为 1 = 走 select_charset_then_load_name 路径; caller FUN_08100968 通过 lsls/lsrs 提取 [0x0202a4d0+0x16] 的 bit1 后传入). 名称加载后若长度 <= 26 则直接 strcpy 到栈缓冲区, 否则截断为 26 字节并补 NUL. 随后调用 text_render_wrapper 渲染名称 (含阴影/双行), 并更新 [0x02006ed0+8] 的字体标志位 (bit1 控制当前字体 charset). 副作用: 向 OBJ VRAM 写入字符 tile (通过 text_render_wrapper).

## 参数签名
- r0: u16 card_id (卡片编号, 传给 resolve_card_gfx_pointer_by_type 或 select_charset_then_load_name)
- r1: u8 render_flags (bit1: 0 = 走 resolve_card_gfx_pointer_by_type 路径, 1 = 走 select_charset_then_load_name 路径; 由 caller 从 [0x0202a4d0+0x16] bit1 提取)
- 返回: r0 = 1 (始终成功)

## 副作用
- [0x02006ed0 + 8]: 字节, bit1 根据 charset 更新 (or/and 操作)
- [0x02006ed0 + 4]: 字, 更新为当前字体 base table 指针
- VRAM (OBJ tile 区): text_render_wrapper 写入卡片名称字符 tile
