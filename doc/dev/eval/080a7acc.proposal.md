# Naming Proposal: 0x080a7acc

## 提案
- **proposed_name**: check_equip_target_slot_in_active_table
- **confidence**: med

## plate comment (中文, ASCII 标点)
装备目标格合法性检查, 被同模块内的 equip 放置决策分发树通过函数指针 (0x080a7d38 / 0x080a7d44) 调用. 触发条件: r0=player_id, r1+r2=slot_idx (合并值), 需满足 slot<=10 且全局结构体 [0x0201e4d0] byte[0] bit0 == player_id. 逻辑: 计算 gDuelFieldSlots[player*0x868 + slot*0x14] 格的 card_word, 提取 card_id (bits[12:0]=r6); 若 card_id==0 则失败. 再检查 r6 是否命中 table@(gDuelActivationTable+0x5ac), 命中则返回 0x800 (1<<11), 表示该格在激活表中; 否则返回 0.
Constants: STRUCT_BASE=0x0201e4d0, gDuelFieldSlots=0x0201c510, PLAYER_STRIDE=0x868, SLOT_STRIDE=0x14, ACT_TABLE_BASE=0x0201b290, ACT_TABLE_OFF=0x5ac, HIT_RETURN=0x800 (=0x80<<4).

## 参数签名
- r0: u8 player_id [0..1] -- 玩家编号 (与 struct[0] bit0 比较)
- r1: u8 base_slot_idx [0..4] -- 格子基索引
- r2: u8 slot_offset [0..5] -- 格子偏移 (r4 = r1+r2, 合并后 [0..10])
- 返回: r0 = u32 activation_hit -- 0=未命中/不合法, 0x800=在激活表中命中
