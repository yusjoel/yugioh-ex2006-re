## plate comment (中文, ASCII 标点)
装备激活前置入口: 当 r1 (entity_id, u16) 为 0 时, 先用 r0 的 sign_bit 与 r0 的低 13 位 (mask 0x1fff) 调用 find_slot_idx_in_dual_list_by_id 解析出实际 entity_id, 再调 apply_equip_activation_via_packed_attr 构造装备记录并激活. 当 r1 已非 0 时跳过 lookup 直接调用. 调用 apply_equip_activation_via_packed_attr 后若返回 0 则函数返回 0 (失败短路), 否则返回 1. 是装备链入口的标准 indirection wrapper. indeg=61 高频复用, 5 个已知 caller 全 duel_field tag (FUN_080432bc/FUN_08043714/FUN_080439e0/FUN_08043d90/FUN_080440b8), 用法一致.
