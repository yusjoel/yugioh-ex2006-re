## 修改清单

### #1 — R3 (高优先级)
**位置**: `080f8f94.proposal.md` 参数签名节 r0 行
**问题**: `filter_mode` 为数值型参数, 语义等价 boolean (0=只计活跃; 非0=绝对计数), 必须附 [range] 或语义枚举
**当前**: `r0: u32 filter_mode, 入口 adds r4,r0 -> 若 r4=0: 只计活跃(低4位>0)条目; 若 r4!=0: 绝对计数`
**应改为**:
```
r0: u32 filter_mode [0=count_active_only, nonzero=count_all] (0 时仅计低4位>0的条目; 非0时绝对计数全部条目)
```
