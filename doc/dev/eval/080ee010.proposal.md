# Naming Proposal: 080ee010

## 提案
- **proposed_name**: load_pack_tile_and_map_to_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
scene_pack 场景的 VRAM tile/palette/map 加载入口. 接收 tile_slot(r0), palette_index(r1), struct_ptr(r2) 三个参数, 先调用 upload_tile_and_palette_from_struct 完成 tile 图形数据和调色板上传, 再调用 write_tile_row_to_vram (FUN_080edf4c) 将 tile map 数据写入 BG VRAM. 被 card_image_decode_wrapper / FUN_08023b6c / FUN_0802b590 等多个场景初始化函数调用, 是 pack/卡图 BG tile 加载的二合一封装.

## 参数签名
- r0: u16 tile_slot    (VRAM tile 槽索引, u16 截断后传给两个 callee)
- r1: u16 palette_idx  (调色板索引, u16 截断, 传给 upload_tile_and_palette_from_struct)
- r2: ptr struct_ptr   (tile+palette 数据结构体指针, 传给两个 callee)
- r3: ptr tile_map_struct_ptr  (tile map 数据结构体指针, 直接转发给 write_tile_row_to_vram 的 r3; 在 callee 内以 ldrh [r3,#0] 读取行宽等 map 元数据, 与 r2/struct_ptr 独立)
- 返回: r0 = u16 最后写入的 tile 属性值 (来自 write_tile_row_to_vram 返回值, u16 截断)

## 副作用
- 经由 upload_tile_and_palette_from_struct: [VRAM tile 区 + palette 区] 写入 tile 图像数据
- 经由 write_tile_row_to_vram: [VRAM BG map 0x06000800+] 写入 tile map
