# Naming Proposal: 0x08032e20

## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
统计指定玩家 (r0 bit0=player_side) 怪兽区槽位中, 同时满足以下条件的装备槽数量:
(1) 槽位 card_id (low 13 bits) 等于 r12 (non-APCS caller-set 参数);
(2) 槽位 [+0x10] 字段 bit5 == 0 (非禁用标志) 且 bit1 == 0 (另一标志清零);
(3) ldrh[slot+0x8] (卡 ID 状态字) != 0;
(4) slot[+0xc] (攻击力/数值) >= r2 (atk_threshold).
通过 r2 参数 (atk_threshold) 区分高低强度, 满足则 r5++.
调用方 FUN_080a45f4 / FUN_080a4648 传入不同阈值 (DAT_080a463c=0x19b2) 控制行为.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, slot_entry=0x14, monster_zone=5, flag_bit5=0x20, flag_bit1=0x2.

## 参数签名
- r0: u32 player_side [0..1] (bit0 取 player)
- r1: (入口后被 .hword 0x468c 覆盖为 callee-save; 实际入参仅 r0/r2)
- r2: u32 atk_threshold 攻击力/数值阈值 (slot[+0xc] >= 此值才计数) -- 由 caller 指定, 无静态范围约束
- r12 (non-APCS, caller-set): u16 target_card_id 要匹配的卡 ID [0..0x1fff]
- 返回: r0 = u32 count 满足条件的槽位数量 [0..5]
