## plate comment (中文, ASCII 标点)
语言选择页面 (Language Selection) 的 VRAM 和 IO 寄存器初始化. 被 enter_language_selection_page (0x080ebfb8) 在 state=0 时调用. 写 gPrng[+0x174]=1 标记页面进入状态, 清零 DISPCNT 关闭显示. 调用 reset_display_and_obj_vram 和 store_ewram_ctx_ptr_and_clear_mode_flags 清空状态. 读 [0x02000000+0x6c2c] (gSettings language 字段) 提取位段写入 0x020297e0 EWRAM 状态字. 设置 BG0CNT=0x4, BG1CNT=0x105, BG2CNT=0x206, BG3CNT=0x307. 调用 reset_all_bg_scroll_regs_and_shadows 和 upload_pack_vram_and_palette. 清零三块 BG VRAM: 0x06004000 / 0x06000000 / 0x06010000 各 0x8000 halfword.

Constants:
- gPrng+0x174 = 0xba*2 = flag_offset (语言页面进入标志)
- DISPCNT = 0x04000000 (0x80<<0x13)
- BG0CNT=0x4, BG1CNT=0x105, BG2CNT=0x206, BG3CNT=0x307
- 0x06004000: OBJ tile VRAM base
- 0x06000000 (0xc0<<0x13): BG VRAM base zero-fill area
- 0x06010000: BG tile VRAM base
- EWRAM gSettings = [0x02000000+0x6c2c]
