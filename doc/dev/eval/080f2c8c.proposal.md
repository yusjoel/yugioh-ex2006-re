# Naming Proposal: 0x080f2c8c

## 提案
- **proposed_name**: render_decimal_digits_jp
- **confidence**: high

## plate comment (中文, ASCII 标点)
将无符号整数 r3 以十进制拆位 (% 10 取余 + +0x30 ASCII 偏移) 从最低位到最高位逐位渲染到 JP 字体行缓冲区, 实现右对齐数字显示. 每轮循环调用 __modsi3 取个位 -> +0x30 得字符码 -> bl render_glyph_jp_single_layer 渲染 -> __divsi3 除 10 -> x 坐标左移 (宽度由 [0x02006ed0+0x8] bit0 决定: 0=宽 10px/JP, 1=窄 5px/ASCII), 直至商为 0 退出. 被 render_duel_field_zone_info, FUN_080d912c, FUN_080dba64, FUN_080de2bc 等卡牌数值显示函数调用, 用于渲染 LP/ATK/DEF 等数值字段 (通常 2 次: 主色 + 阴影色).

Constants:
- 0x30: ASCII digit base ('0')
- 0x02006ed0+0x8: gSettings character width flag (bit0: 0=wide JP 10px, 1=narrow 5px)

## 参数签名
- r0: u16 x_pos [0..239] -- 数字右边缘 x 坐标 (像素); 每渲染一位向左移 5 或 10 px
- r1: u8 y_row [0..31] -- 行缓冲区行号, 透传给 render_glyph_jp_single_layer
- r2: u16 color_attr [0..0xffff] -- JP 字体调色板/颜色属性, 透传给 render_glyph_jp_single_layer; 典型值: 0x8002 (主色), 0x7 (阴影色)
- r3: u32 decimal_value [0..0xffffffff] -- 待渲染的无符号整数; 若为 0 则不渲染任何字符
- 返回: 无返回值 (void)

## 副作用
- [行缓冲区, y_row 行, x_pos 左侧各位] : 逐位写入 JP 字体 glyph 像素 (通过 render_glyph_jp_single_layer 内部写 VRAM/行缓冲)
