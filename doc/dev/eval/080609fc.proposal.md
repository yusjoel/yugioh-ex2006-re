## plate comment (中文, ASCII 标点)
本函数是装备牌目标格筛选谓词, 实现四级条件判断.
条件 1: halfword[+2] & 0xfc0 == 0x580 (zone_type 字段为 0x580).
条件 2: slot[+0x14] bit9 != player_id (方向性标志不等于归属方).
条件 3: slot[+0x14] bit14 == 0 (某激活标志未置位, bge 跳过表示正数即 bit14=0 通过).
条件 4: slot[+0x14] bits[22:19] == 0xe (4-bit 区域索引为 14 = zone E).
全部通过后读取 gP1LifePoints+player*0x868+zone_id*4+0x10e0 位置的卡牌 low-13-bit
card_id, 调用 check_card_field5_is_nonzero 确认 field5 非零.
与 check_slot_at_zone_e_with_field5_active (0x08061018) 相比多了 bit14==0 条件.
