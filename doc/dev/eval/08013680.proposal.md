# Naming Proposal: 0x08013680

## 提案
- **proposed_name**: setup_demo_sprite_entry_alt
- **confidence**: med

## plate comment (中文, ASCII 标点)
由 FUN_08013740 (mode=1 或 mode=2 时) 分派调用, 与 setup_demo_sprite_entry (0x08013578) 结构近乎相同, 区别在于入口参数排布和栈帧大小略有差异 (-0x34 vs -0x38), 且不含 BIOS 版本检测分支. 同样负责初始化演示精灵的 OAM attr0/1/2 字段并调用 apply_gfx_resource_list 提交. 加载的资源列表模板为 0x09e396c8 ("demo/exodia/exodia01_obj.LZncer"). Constants: ATTR1_X_MASK=0x7f / ATTR0_PAL_MASK=0xf / ATTR1_FLIP_BIT=0x40 / ATTR2_MASK=0xffffc07f.

## 参数签名
- r0: u8 sprite_slot [0..3] - 精灵槽号, 用于计算 OAM 条目偏移
- r1: u8 x_pos [0..127] - 精灵 X 坐标 (写入 attr1 低 7 位)
- r2: u8 palette_idx [0..15] - 调色板索引 (写入 attr0 低 4 位)
- r3: ptr - 指向 gDemoState 内字段 (与 0x08013578 对称, 用于隐藏 bit 判断)
- [sp+0]: u32 - tile base 或优先级参数 (从 [sp+0x54] 加载, 见 0x08013694)
- r8/r9/r10: callee-saved (非输入参数) -- 入口 .hword 0x4657/0x464e/0x4645 将其暂存至 r7/r6/r5 后压栈, 随即在 0x0801368c (.hword 0x4681 mov r9,r0) / 0x0801368e (.hword 0x468a mov r10,r1) / 0x08013692 (.hword 0x4698 mov r8,r3) 覆写为 APCS 入口参数的局部副本; asm/all.s:443 add r2,r9 中的 r9 已是 slot*4 计算后的新值 (非原始入口 r9); 尾声 .hword 0x4698/0x46a1/0x46aa 原值还原; 原始入口 r8/r9/r10 值从未读取作运算输入 (AAPCS callee-saved 寄存器保存模式, 非 non-APCS 隐式参数)
- 返回: 无返回值 (仅副作用)

## 副作用
- [gDemoState OAM 缓冲区 +slot*8+0x14]: attr0 写入
- [gDemoState OAM 缓冲区 +slot*8+0x17]: attr1 高字节写入
- [gDemoState OAM 缓冲区 +slot*8+0x18]: attr2 halfword 写入
- [DISPCNT] 通过 apply_gfx_resource_list 间接更新
