# Naming Proposal: 0x080d3830

- **confidence**: high

## plate comment (中文, ASCII 标点)
将决斗场地指定槽位的卡片图标 tile 渲染到 OBJ VRAM, 由 080d08a4/080d136c/080d1bb4/080d4268 调用 (indeg=4).
r0 = slot_index. 读取 gDuelCtx+0x2f53 byte (card_status), 提取 bits[7:5] (r3=高3位) 和 bits[4:0] (r0=低5位);
若 (r3<<3 | r0) == 0 (无效状态) 则跳到零位向量路径 (LAB_080d3874): 直接写 OAM 地址.
否则: 解引用 slot_index struct (stride 0x28) 内的 card_id halfword; 使用 ldmia/stmia 拷贝 3 word 两轮共 9 word 到 r0 目标区 (内嵌卡片元数据).
计算 slot_mod5 = slot_index % 5 (bl __modsi3), 求 VRAM 行偏移:
  r0 = (slot_mod5*4 + 0x1e0) << 5 = tile row base + OBJ VRAM 0x06010000 offset.
调用 tile_2d_row_copy(src=base+slot_offset, dst_row=0, width=4, height=2) 写 4x2 tile 块到 OBJ VRAM.
最后检查 gDuelCtx+0x2f52 halfword bits[12:5] (card_frame_state) 并与 6/7 比较, 决定是否调用附加处理.
Constants: DUEL_CTX=0x02020160; CARD_STATUS_OFFSET=0x2f53; CARD_LOW_MASK=0x1f; STRIDE=0x28;
MOD_DIVISOR=5; TILE_VRAM=0x06010000; TILE_WIDTH=4; TILE_HEIGHT=2.
