## plate comment (中文, ASCII 标点)
equip 槽扫描显示动画的帧驱动函数. 从 [0x0201bcc0] 读取 player_id (r6=bit15),
并根据步骤计数器 [0x0201c4d0] 二态分发:
步骤 0: 对 slot=0..4 逐一枚举, 每个 slot 再对 equip chain 中 count=0..8 (共 9 个)
的节点搜索: 从 card_data_base (0x0201c510) + player_stride + slot*0x868 + 0x64 起
以 stride 0x14 遍历 9 个节点字 (lsls/lsrs 取 bits[12:0] 为 card_id),
与当前 r8(equip_chain_pool_ptr) 的 slot_ref 比较, 匹配时调用
dispatch_card_display_op(op=0x3b, player_id, card_id|0x100, slot_flag) 触发显示;
全部遍历后写步骤计数器 +1; 步骤 >= 1: play_ui_effect(0x3b) 轮询动画完成,
完成后写 [base+0x80c] := 0 清步骤锁.
由主状态机 FUN_0803be4c 在 equip 槽扫描高亮显示阶段按帧调用.
Constants: step_counter=0x0201c4d0=base+0x810; card_data_base=0x0201c510;
equip_chain_pool=0x09e3f104 (ROM 查找表); player_stride=0x868;
slot_count=5 [0..4]; node_count=9 [0..8]; node_stride=0x14;
op_highlight=0x3b; effect_highlight=0x3b; card_id_mask=0x1FFF (bits[12:0]).
