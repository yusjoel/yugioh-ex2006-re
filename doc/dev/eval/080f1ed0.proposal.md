# Naming Proposal: 0x080f1ed0

## 提案
- **proposed_name**: scan_string_to_char_limit
- **confidence**: high

## plate comment (中文, ASCII 标点)
遍历字符串直到字符计数 r3 达到上限 r1 或遇到 NUL. 使用与 get_char_width_class (0x080f02a4) 完全相同的跳转表分发 (179 条目, 基于 byte-0x9 索引). case 0x25 (空格控制字符): 仅推进字节指针 r2 (不计数); case 0x2e ('.') 后跟 0x2e: 额外计一行 r3+1 并跳回; default (普通字节): r2+=1, r3+=1. 入口: r2=str_ptr, r1=char_limit, r3=0. 当 r3>=r1 或遇 NUL 退出, 返回 r0=当前字节指针 (end_ptr).

Constants:
- SWITCH_TABLE_BASE=0x080f1ef4 // 179 条目跳转表
- CASE_DOUBLE_BYTE=0x25 // 双字节字符控制码 (跳过 1 额外字节)
- CASE_PERIOD=0x2e // 句点, 后跟 0x2e 时计行
- INPUT_OFFSET=0x9 // 所有索引先减 0x9 后查表

## 参数签名
- r0: const char* str_ptr (字符串起始地址)
- r1: u16 char_limit [0..0xffff] (最多遍历字符数)
- 返回: r0 = const char* end_ptr (遍历终止位置的字节指针)
