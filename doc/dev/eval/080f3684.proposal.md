# Naming Proposal: 0x080f3684

## 提案
- **proposed_name**: blit_tile_byte_row
- **confidence**: high

## plate comment
将 tile 源数据按字节颗粒度写入 VRAM 目标行. 每个像素槽读两字节(lo byte 和 hi byte), 非零时分别 AND+OR 写入 dst halfword. 与 blit_tile_nibble_row_msb/lsb 同族, 区别在于本函数使用单字节像素步进(src+=1, dst+=2 每像素), 不做 nibble 展开, 适用于 8bpp 或 8bpp 模拟的 tile 数据. 从 gPrng+0x8 读 tile 宽度和行数确定循环边界.

Side effects: 写 VRAM[r0..r0+row_count*0x80] halfword (按字节颗粒度 AND+OR 各像素); 无 IO 寄存器副作用.

Constants:
- BYTE_MASK_LO = 0xff00 // AND mask for low byte (r0=0x46bc decode: bits[6:4]=1=r8, bits[2:0]=4=r4 -> mov r12,r4; 实为 0xff00 -> r8)
- BYTE_MASK_HI = via r8 (0xff<<8=0xff00 准备于入口)

## 参数签名
- r0: u16* dst VRAM 行起始地址
- 返回: void (pop {r0};bx r0 - r0 被 lr 覆盖)

## 副作用
- [r0..r0+row_count*0x80]: OR-write u16 按字节颗粒度写 tile 像素行
