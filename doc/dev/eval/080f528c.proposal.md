# Naming Proposal: 0x080f528c

## 提案
- **proposed_name**: expand_format_decimal_width_to_buf
- **confidence**: high

## plate comment
格式串展开器, 扩展版本, 在 expand_format_decimal_to_buf (0x080f5228) 基础上增加宽度修饰符支持. 逐字节扫描格式串 r1 (src), 写入输出缓冲区 r0 (dst). 识别三种 format specifier: (1) %%d -> 普通十进制展开, 根据 gPrng+0x6c2c bit[2:0] 决定调用 format_decimal_halfword_to_buf 还是 format_decimal_byte_to_buf; (2) %%Nd (N 为单个数字 '0'..'9') -> 宽度 N 位十进制展开, 不足时左侧补空格; (3) 其他字符直接复制. 由 font_jp/game_str/pack/settings 多个渲染路径调用, 用于 HUD 数值格式化.

Side effects:
- [r0..]: 写入展开后的文本 (NUL 结尾)

Constants:
- FMT_PERCENT = 0x25 // '%'
- FMT_D = 0x64 // 'd'
- PAD_CHAR = 0x20 // ' ' (空格填充)
- LOCALE_FLAG_ADDR = 0x02006c2c // gPrng base + 0x6c2c
- LOCALE_MASK = 0x7 // bits[2:0] 控制 halfword/byte 输出格式

## 参数签名
- r0: char* dst 输出缓冲区
- r1: const char* fmt 格式字符串 (支持 %d / %Nd, N='0'..'9')
- r2: u16 value 要展开的十进制数值 [0..65535 or 0..255 by locale]
- r3: u8 use_decimal 非零时使用十进制展开 (0 时直接跳 format_decimal_byte_to_buf 路径)
- [sp+0x1c]: u8 stack_flag 第 5 个参数 (影响展开路径选择)
- 返回: void (pop {r0};bx r0)

## 副作用
- [r0..r0+N]: 写入展开字符串 (N 由格式串和 value 决定)
