# Naming Proposal: 0x080de27c

## 提案
- **proposed_name**: decompress_pack_scene_gfx
- **confidence**: high

## plate comment (中文, ASCII 标点)
对卡包场景所需的两块压缩图形资源执行哈夫曼解压, 并将调色板数据 DMA 复制到 PAL RAM. 第一块 ROM 压缩流 (0x09ceb930) 解压至 OBJ VRAM 0x06004020; 第二块 (0x09ceb938) 解压至 BG VRAM 0x0600e000. 然后从 ROM 0x09ceb934 读取 0x40 字节调色板数据, 经 copy_memory_dma3_with_cpu_fallback 写入 PAL RAM 0x050001c0 (obj palette 槽 28-31). 无参数, 由上层卡包场景初始化路径调用, 在场景切入时一次性执行.

Constants:
- ROM_GFX_A = 0x09ceb930 (OBJ tiles huffman 压缩数据指针表入口)
- VRAM_OBJ_DST = 0x06004020 (OBJ VRAM 解压目标地址)
- ROM_GFX_B = 0x09ceb938 (BG tiles huffman 压缩数据指针表入口)
- VRAM_BG_DST = 0x0600e000 (BG VRAM 解压目标地址)
- ROM_PAL = 0x09ceb934 (调色板源地址)
- PAL_DST = 0x050001c0 (PAL RAM 目标地址)
- PAL_SIZE = 0x40 (复制字节数 = 32 colors * 2 bytes)

## 参数签名
- r0: void (无参数)
- 返回: void (pop {r0}; bx r0 -- 无独立 r0 写入)

## 副作用
- [VRAM OBJ 0x06004020]: 写入解压后 OBJ 图块数据
- [VRAM BG 0x0600e000]: 写入解压后 BG 图块数据
- [PAL RAM 0x050001c0..0x050001ff]: 写入 32 色调色板 (0x40 字节)
