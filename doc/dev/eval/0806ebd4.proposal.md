## plate comment (中文, ASCII 标点)
由装备链刷新路径调用. 接受两个参数: r0=slot_ptr (装备效果槽指针), r1=secondary_ptr (可为 NULL 的辅助指针, 仅 0x7e 路径使用). 先读 slot[4] bit2 门控, 置位则直接返回 0. 通过 gP1LifePoints+0x4a0 (0x94<<3 偏移) 读取装备链显示状态码, 分三路分发:
状态 0x7f: 读 gP1LifePoints+0x1da8 引用计数; 非零时读 slot[2] bit0 得 player_id, 以 r1=player_id, r2=0x7, r3=1 调用 set_lp_row_type1_with_attr_flags 提交 LP 行属性; 返回 0 (早退, 不修改状态码).
状态 0x80: 从 slot[2] bit0 提取 player_id 取反, 以 sp[0]=1, r1=1, r2=0, r3=0 调用 dispatch_equip_slot_scan_with_field6_guard; 非零则调 set_lp_display_row_all_slots 返回 0x7f, 零则返回 0x7e.
状态 0x7e: 若 secondary_ptr 为 NULL 则返回 0; 否则读 secondary_ptr[0] 卡 id 调 get_card_extended_stat_field6, 若 field6==0x16 则设置 secondary_ptr[4] bits 0x2|0x4|0x8, 调 enqueue_field_slot_sprite_with_state_update + update_equip_target_bitmap_zone14; 返回 0.

Constants:
  STATE_OFFSET        = 0x4a0 (= 0x94<<3)
  LP_REFCOUNT_OFFSET  = 0x1da8
  CARD_FIELD6_EQUIP   = 0x16
  SLOT_FLAG_BITS      = 0x2|0x4|0x8
  LP_ROW_ATTR_FLAGS   = 0x7  (set_lp_row_type1_with_attr_flags 的 attr_flags 参数)

## 参数签名
