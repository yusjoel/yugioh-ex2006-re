## plate comment (中文, ASCII 标点)
跨玩家装备槽类型资格检查谓词. 在装备目标选择时用于确认目标槽位属于对方玩家且类型兼容. 首先从 card_entry byte[+2] bit0 读取卡片归属的 player_id, 若与传入的 player_id 相同则立即返回 0 (不允许同侧装备). 通过后, 查询区域表 is_present + 类型相容性: 调用 query_slot_card_type_eligibility 验证卡牌类型兼容. 兼容 (返回 0) 时本函数返回 1.

Inputs: r0 = ptr equip_card_entry, r1 = player_id [0..1], r2 = slot_idx (no range guard)
Outputs: r0 = 1 if cross-player slot is type eligible, 0 otherwise
Side effects: none
Constants: PLAYER_BLOCK=0x868, ZONE_BASE=0x0201c510, SLOT_STRIDE=20

## 参数签名
- r0: ptr equip_card_entry (reads byte[+2] for player_id at bit0)
- r1: u32 player_id [0..1] (must differ from card's owner)
- r2: u32 slot_idx (caller-validated)
- 返回: r0 = u32 (1=eligible cross-player slot, 0=same-side or ineligible)
