## plate comment (中文, ASCII 标点)
overlay 帧渲染入口. 从 gPrng+0x1d0 读取 overlay 状态结构指针, 若非零则写入帧尺寸字段 ([+0xe]/[+0xa]=r0 low16, [+0x10]/[+0xc]=r0 high16), 根据 [+0x14] bit0 选择普通或备用 tile 路径, 两路各自: 调色板行更新 (copy_overlay_tile_row_to_palette), 加载背景 tile (load_overlay_bg_tiles_to_vram 或 _alt), 渲染覆盖文本 (render_overlay_text_to_bg_vram), 最后清零 [+0x1c] 并调用 tick_overlay_animation_step. r0=packed frame size (high16=height, low16=width), r1=palette row index, r2=text ptr.
