# Naming Proposal: 0x080f70c4

## 提案
- **proposed_name**: push_oam_entry_to_aob_slot
- **confidence**: med

## plate comment (中文, ASCII 标点)
将 r2 指向的 OAM attr 数据 (3x halfword) 写入 gPrng+0x6f0 处的 AOB 槽位数组, 并递增槽位写指针. 由 FUN_080f8000/FUN_080f83a4/FUN_080f8a24 三个未命名 caller 在 AOB 渲染流程中调用. 函数先读 [gPrng+0x6f0] 处的当前写指针字, 取低字节作为槽位索引; 若索引字节 = 0x80 (满标志) 则直接返回; 否则按索引*8 定位槽位写入 r2[0]/[2]/[4] 三个 halfword (attr0/attr1/attr2), 再将写指针 +1 回写.

Constants:
- gPrng + 0x6f0 (0xde * 2 * 2 = 0x378 * 2? -- 实: 0xde * 2 = 0x1bc? lsls r1,#1: 0xde<<1=0x1bc, adds r4=gPrng+0x1bc? Wait: movs r1,#0xde; lsls r1,r1,#1 = 0x1bc, adds r4=gPrng+0x1bc)
- 0x80 = 满标志 (cmp r1,#0x80)
- 每个 AOB 槽位 8 字节 (lsls r1,r1,#3)

## 参数签名
- r2: ptr oam_attr_data* -- 待写入的 OAM attr 数据指针 [r2+0]=attr0, [r2+2]=attr1, [r2+4]=attr2
- 返回: void (无返回值)

注: r0 和 r1 在入口被内部加载立即覆盖 (r0: ldr r0,PTR_gPrng @ 080f70c8; r1: movs r1,#0xde; lsls r1,r1,#1 @ 080f70ca), 均非 APCS 输入参数.

## 副作用
- [gPrng + 0x1bc + slot_idx*8 + 0]: 写 attr0 halfword
- [gPrng + 0x1bc + slot_idx*8 + 2]: 写 attr1 halfword
- [gPrng + 0x1bc + slot_idx*8 + 4]: 写 attr2 halfword
- [gPrng + 0x1bc, byte 0]: slot 写指针 +1

## 行级注释 (精华)
- @ 080f70c8: ldr r0,PTR_gPrng; movs r1,#0xde; lsls r1,r1,#1 -- r1=0x1bc

- @ 080f70d0: ldr r3,[r4,#0] -- 读写指针字
- @ 080f70d2: movs r1,#0x80; lsls r1,r1,#3 -- r1 = 0x400 (AOB 数组 base 偏移)
- @ 080f70d8: ldrb r1,[r0,#0] -- 读槽位写指针 (低字节)
- @ 080f70da: cmp r1,#0x80 / beq LAB_080f70fe -- 满则跳过
- @ 080f70de: lsls r1,r1,#3 -- slot_idx * 8
- @ 080f70e0: adds r1,r1,r3 -- 定位到槽位
- @ 080f70e2: ldrh r0,[r2,#0]; strh r0,[r1,#0] -- attr0
- @ 080f70e6: ldrh r0,[r2+2]; strh r0,[r1+2] -- attr1
- @ 080f70ec: ldrh r0,[r2+2 offset]; strh r0,[r1+4] -- attr2
- @ 080f70f8: ldrb r1,[r0,#0]; adds r1,#1; strb r1,[r0,#0] -- 写指针 +1
