## plate comment (中文, ASCII 标点)
读取 BG0CNT 寄存器 (0x04000008) 的 char_base_block 字段 (bits [3:2]), 计算并返回 BG0 字符/图块数据在 VRAM 中的实际起始地址. 公式: addr = 0x06000000 + char_base_block * 0x4000. 无副作用, 纯计算返回. 与 get_bg1/bg2/bg3_char_vram_addr 构成四函数 sibling 簇, 对应 get_bgX_screen_vram_addr 簇的字符平面版本.

## 参数签名
- r0: (无参数, 入口前 3 条指令即已用 sp trick 读取寄存器)
- 返回: r0 = u32 BG0 char VRAM 基址 [0x06000000 .. 0x06007000, 步进 0x4000, char_base_block 取值 [0..3]]

## 副作用
- [BG0CNT 0x04000008]: ldrh 读取后经 sp trick 回写原值 (净副作用: 无)

## 行级注释 (<=30 行精华)
- @ 08014a10: sub sp,#4 + ldr PTR_BG0CNT + ldrh/mov sp/strh sp-trick 读取 BG0CNT 到栈
- @ 08014a1c: lsls #0x1c / lsrs #0x1e -- 提取 bits[3:2] = char_base_block (0..3)
- @ 08014a20: lsls #0xe -- char_base_block * 0x4000, 即每个 char block 占 16KB
- @ 08014a22: movs r1,#0xc0; lsls r1,r1,#0x13 -- r1 = 0xC0 << 19 = 0x06000000 (VRAM 基址)
- @ 08014a26: adds r0,r0,r1 -- addr = 0x06000000 + CBB * 0x4000
