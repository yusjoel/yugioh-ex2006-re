## plate comment (中文, ASCII 标点)
被卡片显示簇 (FUN_080ce218/080cd33c/080cf3b0 等, indeg=12) 调用, 将以 null 结尾的 JP 文本串逐字符渲染到 BG tile 行缓冲区. 参数 r0=x 像素起始列, r2=字符串指针, r3=调色板属性 (高字节), r8/r9 等高寄存器由 caller 设置 (tile stride 等). 逐字节扫描: 0x0A 换行, 0x40 特殊控制字符 (字符间距调整), 双字节 JP 字符 (高字节 bit2..0 != 0) 先判断折行位置 (test_char_kinsoku_head + test_char_kinsoku_tail), 再调用 render_glyph_jp_single/dual_layer 写像素到 line buffer; 空格 (0x20) 推进 x 坐标; 最终把渲染完成后的 x 宽度写回 [0x0201f440+0x0a16].
