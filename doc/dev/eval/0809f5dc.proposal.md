## plate comment (中文, ASCII 标点)
通用魔法/陷阱区装备激活扫描器(packed OAM attr 版). r0=player_id([0..1]), r1=card_id(16 位内部 ID). 首先检查 gP1LifePoints+0x1d24 循环计数器是否为 0; 若为 0 则初始化为 5, 进入正向扫描路径: 遍历槽 0..9, 组装 packed_attr(player_bit/slot/card_id 掩码合并), 调用 test_slot_has_active_card 验证活跃卡, 命中则调用 apply_equip_activation_via_packed_attr(packed_attr, slot_data, 0); 若 apply 返回非 0 则转调用 FUN_080a1d04(set_lp_display_row_all_slots) 输出 LP 显示行. 若计数器初始非 0 则走反向路径(从已有计数位置继续), 调用 FUN_0804cc8c(submit_slot_card_sprite_row_packed) 提交精灵行条目. 两条路径均完成后重置计数器为 0.
Constants: COUNTER_OFFSET=0x1d24, CARD_ID_MASK=0xffff, SLOT_COUNT=10(0..9), OAM_MASK1=0xf8<<13=0x1f0000, OAM_BASE=0x84<<19=0x4200000.

## 参数签名
- r0: u8 player_id [0..1] (调用方玩家, bit31 写入 OAM)
- r1: u16 card_id [0x0000..0xffff] (内部卡片 ID, 与 0xffff 掩码 AND 后写入 packed_attr)
- 返回: r0 = u8, 0=至少命中一次(激活或精灵提交), 1=全未命中或计数器耗尽

## 副作用
- [gP1LifePoints+0x1d24]: 循环计数器: 初始化为 5 或递增至 9, 结束后清 0
- OAM sprite queue: 通过 apply_equip_activation_via_packed_attr 写入激活属性; 或通过 FUN_0804cc8c 提交精灵行条目
- LP 显示行: 通过 set_lp_display_row_all_slots(player, card_id) 更新
