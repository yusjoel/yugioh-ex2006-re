# Naming Proposal: 0x080dcb44

## 提案
- **proposed_name**: get_pack_info_attr2
- **confidence**: med

## plate comment (中文, ASCII 标点)
从 pack_info_table 读取指定牌包条目偏移 +0x2 处的 halfword 字段.
r0 为牌包索引, 函数乘以 0x10 得条目偏移, ldrh 读取 +0x2 字段后返回.
caller 080d88dc 取返回值存入 r1 后执行 cmp r1,#0x5 (等于 5 时走随机数路径);
caller 080d89fe 取返回值后执行 ands r0,#0xf (提取低 4 位作子字段).
字段语义为 pack_info 条目内的 bitfield, 确切定义需 runtime 交叉验证.

Constants:
- pack_info_table: 牌包信息表基址 (ROM 0x09e5e2e8)
- 0x10: 每个 pack_info 条目大小 (16 字节)
- +0x2: 条目内 halfword 字段偏移

## 参数签名
- r0: u8 pack_index 牌包索引 [0..N-1]
- 返回: r0 = u16 pack_info[pack_index].field_0x2

## 副作用
- (无写操作, 纯读函数)

## 行级注释 (<=30 行精华)
- @ 080dcb44: ldr r1 = pack_info_table 基址
- @ 080dcb46: r0 << 4 = pack_index * 16 (条目大小)
- @ 080dcb48: r0 += r1 -> 条目基址
- @ 080dcb4a: ldrh r0,[r0,#0x2] -> 读取 +2 halfword
- @ 080dcb4c: bx lr 返回
