Per-frame driver for the pack cover display fade-in blend animation. Reads pack_ui_state+0x136 (remaining frames); if non-zero: computes BG2 affine X coefficient as (0xf-elapsed)*0x800/0xf and writes BG2X (0x04000028); computes BLDALPHA weight as elapsed<<4/0xf and writes to BLDALPHA (0x04000052) and BLDCNT (0x04000050:=0x1b44); also writes BG2PA/BG2PB/BG2PC/BG2PD affine matrix. Regardless of elapsed state, calls tick_overlay_animation_step(1). If tick_overlay_animation_step returns 1 (animation done): clears DISPCNT OBJ bit (~0x400), writes BLDCNT:=0x3f3f and BLDALPHA:=0x10 (full opaque), resets OAM substructure [+0x44+0x0:=5/+0x2:=1/+0x10:=1], writes pack_ui_state+0x10c/+0x10e:=0x1e and pack_ui_state+0x4:=0xe. Calls tick_pack_oam_slots_and_overlay(2). Returns r6. indeg=0.
