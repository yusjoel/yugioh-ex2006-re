# Naming Proposal: 0x0801722c

## 提案
- **proposed_name**: decode_char_frame_to_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
名称输入场景中的字符帧解码主函数. 接收输入缓冲区指针(r0), 字符计数(r1), 编码模式(r2), VRAM 目标基址(r3), 在约 0x5a0 字节的栈帧内完成以下流程: (1) 按模式 0/1 读取双字节字符并调用 dispatch_jp_char_handler 转换, 填充内部栈缓冲区; (2) 调用 pack_bytes_to_vram_bits 将字节序列压缩为 VRAM 位图格式; (3) 调用 xor_buf_bytes 对结果异或扰码; (4) 调用 validate_complement_checksum 校验补码校验和, 不通过则调用 suppress_display_output 并返回 -1; (5) 通过两层位域解码循环将字符属性写入 VRAM 目标地址区域. 成功返回经解码的位域计数值, 失败返回 -1.

Constants:
- STACK_FRAME_SIZE = 0x5a0 // 主栈帧大小(字节)
- MODE_IDENTITY = 0 // 模式 0: 直接读字符
- MODE_BYTE_SWAP = 1 // 模式 1: 高低字节交换
- BIOS_CPUSET_CTRL = 0x01000168 // fill=0, count=0x168/4=90 words, 清零栈缓冲区
- CHAR_DECODE_LIMIT = 0x86 // 第一阶段位域解码循环上界(0x86 iterations)
- PACK_COUNT = 0x40 // pack_bytes_to_vram_bits 字符数参数

## 参数签名
- r0: u8* src_buf - 输入字符缓冲区指针 (读取双字节字符对)
- r1: u16 char_count - 待处理字符数 [1..N, caller-set]
- r2: u8 encode_mode - 编码模式 [0..1] (0=直接, 1=字节交换)
- r3: u8* vram_target - VRAM 目标写入基址
- 返回: r0 = s32, 成功返回已解码位域项数(>=0), 失败(校验和不符)返回 -1

## 副作用
- [vram_target+...]: 通过 pack_bytes_to_vram_bits + 位域写入循环写入 VRAM 字符图块属性数据
- [sp+0x5a4]: 暂存 checksum 期望值(来自 xor_buf_bytes 结果)
- 校验失败时调用 suppress_display_output (副作用: 中止显示输出; 参见 suppress_display_output 函数体)
