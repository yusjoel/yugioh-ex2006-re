Renders card type text row to BG tile VRAM 0x06012800 for the card pack scene.
r0=pack_card_slot [0..4]. Reads gSettings.lang to init line buffer font (same pattern as
render_pack_card_desc_to_bg_tile). Looks up icid from gMenuState[0x1c] card list at
slot*3*4 offset; adds TYPE_STR_OFFSET (0x3e8) and calls game_str_id_to_row.
Selects game_str_pointer_table / game_str_ja offset by gSettings.lang bits[2:0].
Calls expand_card_name_escape_to_buf; if gMenuState[0x20] callback non-null calls invoke_r1.
Selects specific string by language; calls render_text_to_bg_row_at_12800 to write BG tile.
Called by FUN_080e73b4 during pack main scene rendering.

Constants:
  BG_TILE_DEST     = 0x06012800  (render_text_to_bg_row_at_12800 target)
  TYPE_STR_OFFSET  = 0xfa*4 = 0x3e8  (type string base id offset; 0xfa=250, 250*4=1000=0x3e8)
  gMenuState_BASE  = 0x02006ed0
  CARD_LIST_OFF    = 0x1c        (gMenuState[0x1c]: card list pointer)
  LANG_FIELD       = [0x02000000+0x6c2c]
  game_str_ja      = 0x09db9c10  (Japanese string data base)

Inputs: r0=s32 pack_card_slot [0..4].
Returns: void (pop; bx r0).
Side effects: writes card type text BG tile row to 0x06012800
              via render_text_to_bg_row_at_12800.
