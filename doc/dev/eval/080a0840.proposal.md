# Naming Proposal: 0x080a0840

## 提案
- **proposed_name**: update_equip_sprite_state_by_slot_status
- **confidence**: med

## plate comment (中文, ASCII 标点)
equip sprite 槽位状态更新器, 被 FUN_080a0a8c (equip sprite 序列控制器) 在
DAT_080a0ab0 (0x0201b870) + 0x301 对应 bit (bit31-4=bit27) 为 1 时调用 (indeg=1).
从 0x0201b870 + r2 (=0xc4*3=0x24c) 读取 sprite_buf 状态字节, 根据其值 (0/1/2) 进行
三路处理: 0 -> 清零两处 sprite_buf slot (0x1ac/0x1b4 偏移), 递增状态计数;
1 -> 执行主路径 (读 DAT_080a08d4+DAT_080a08d8 偏移存储 card_id, 调用
invoke_card_effect_node_handler(card_id, slot)); 2 -> [另一分支].
副作用包括写 sprite_buf 相关字段和更新计数器.
Constants: sprite_buf_base=0x0201b870 (DAT_080a0874), slot_idx_base=0xc4,
sprite_buf_offset=0x0201b590 (DAT_080a0878), status_byte_offset=0x30d (DAT_080a087c, 直接 ROM 字面量),
card_id_store_base=0x0201b290 (DAT_080a08d4), counter_offset=0x484 (DAT_080a08d8).

## 参数签名
- r0: (无独立输入, ldr r2,DAT_080a0874 = 0x0201b870 覆盖)
- 返回: r0 = u32 0 (本帧继续, status=0 清零路径) 或 u32 handler_result (status=1 路径, 来自 invoke_card_effect_node_handler; 0=处理中, 非零=完成; 语义待确认)

## 副作用
- [0x0201b870+slot_offset]: str r1 (清零 slot_state)
- [0x0201b870+slot_offset+8]: str r1 (清零 adjacent slot)
- [0x0201b870+slot_offset+0]: strb count++ (递增状态)
- [0x0201b290+0x484] = [0x0201b714] := r4 (card_id 存储, status=1 路径)
- [0x0201b590+counter_offset]: ldrb+adds+strb (计数递增) via invoke_card_effect_node_handler
