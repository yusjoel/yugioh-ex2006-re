Equip card eligibility predicate requiring target slot on opposite side + equip valid flag + optional field6 score match. Guards: (1) r2<=4; (2) read slot[+2] bit0 vs r1 -- same side rejects (requires opposite); (3) gDuelFieldSlots[r1&1][r2] bits[18:0] non-zero; (4) ldrh [slot,#8]!=0 (equip valid flag); (5) check slot[+6] bits[4:2] (mask 0x1c): if non-zero, get_slot_field6_score(r1,r2) must equal slot[+8]; if zero, passes directly. Read-only predicate, no side effects.
Inputs: r0=ptr equipping-card slot, r1=u8 player_id [0..1], r2=u8 zone_slot_idx [0..4].
Outputs: r0=u32 bool (1=eligible, 0=rejected).
Side effects: none.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, field6_type_mask=0x1c.
