## plate comment (中文, ASCII 标点)
nnsys/g2d/g2d_Image.c 第 829/830 行. 将调色板条目逐批上传到 2DMAIN 调色板 VRAM. 入口保存 r10->r7->r9->r6->r8->r5 到 callee-save, r0 到 r8, r1 到 r6, r2 入栈, r3 到 r10. 对 pCmpInfo 条目列表按 r5 循环: 读取条目色数 (ldrh at [r6+i*2]), 乘以每条目字节数 (r7 = 0x20 或 0x200), 计算目标地址 = [pSrc+0xc] + dest_index*stride + 0x05000200, 调用 bios_cpu_fast_set 写入 r2 字节. type 必须 <=2 (assert 行 0x33e=830). pImgProxy, pSrc, pDst, pCmpInfo 均 assert non-NULL.

Constants:
- PALETTE_2DMAIN_BASE = 0x05000200
- stride = 0x20 (32 bytes, type==3 path) 或 0x200 (512 bytes, type==4 path)
- 0x1fffff mask: 写入字节数掩码 (DAT_080eadbc)
- assert 行号 0x33d=829, 0x33e=830
