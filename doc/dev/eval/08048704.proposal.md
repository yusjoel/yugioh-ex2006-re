# Naming Proposal: 0x08048704

## 提案
- **proposed_name**: enqueue_sprite_attr_for_slot_indicator
- **confidence**: high

## plate comment (中文, ASCII 标点)
根据 player_side (r0) 选择 OAM attr 值: r0==0 时使用 0x002b, r0!=0 时使用 0x802b (player-2 扩展模式). 将 r1 (slot/位置值) 截断为 16 位后, 以固定 r2=1, r3=0 调用 enqueue_sprite_attr_record, 提交格位指示器 sprite. 共 15 个调用者分布在 duel_field / card_frame / LP bar 等多处. OAM attr 0x2b/0x802b 对应格占用指示图块.

## 参数签名
- r0: u32 player_side [0..1] (0->attr 0x002b, 1->attr 0x802b)
- r1: u32 slot_or_pos [0..0xffff] (高 16 位被截断)
- 返回: void (pop {r0}; bx r0 epilogue, 调用方不使用返回值)

## 副作用
- OAM attr buffer: enqueue_sprite_attr_record(attr=0x2b 或 0x802b, slot_or_pos&0xffff, r2=1, r3=0)
