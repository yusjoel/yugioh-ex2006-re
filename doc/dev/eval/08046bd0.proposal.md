## plate comment (中文, ASCII 标点)
按 card_id 分派 zone 动作的 dispatcher: 从 r0 (ptr<CardRecord>) 取 [r0+0]&0x1fff = card_id_13bit -> r8. 解码 r3 拆位: bit3 取反 -> r1, bit1/10/2 -> sp[0x10..0x18]. 主体是 30+ card_id 二分搜索树 (0x1625/0x1468/0x12d3/0x1366/0x150e/0x17b7/0x17af/0x1881/0x19d7/0x15e6 等), 命中后跳到 LAB_08046f08/LAB_08047114/LAB_08046f00/LAB_08046db8/LAB_08047012 等子处理. 部分路径递归调用本函数, 部分跳到 FUN_08047114/080470a4. 5 caller (FUN_08047218/08047f50/08048020/08048268/08048364) 全 duel_field, 与 0x0804559c 同 dispatcher 簇, 处理装备/效果 zone-level 动作.
