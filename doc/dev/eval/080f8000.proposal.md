# Naming Proposal: 0x080f8000

## 提案
- **proposed_name**: render_aob_frame_to_oam
- **confidence**: high

## plate comment (中文, ASCII 标点)
将 AOB (animation object) 当前帧的 OAM attrs 写入 AOB OAM 缓冲区; tile 数据拷贝到 VRAM 作为实现细节. 由 11 个 caller 共享, 涵盖 play_ui_effect_37/38/3b + FUN_080bc918/FUN_080bede4/FUN_080bf5a0/FUN_080bf7f8 等 blend/vram/palette/duel_field/card_frame 全场景. 入参 r0=aob_ptr (动画对象指针), r1=packed_xy (低 16 位=X 偏移, 高 16 位=Y 偏移), r2=flip_flags (低字节), r3=pal_idx (调色板索引低字节). 函数先解析 aob 结构 (r0+0x12/0x13 标志字节) 确定 tile mode/flip/pal; 按帧数据中的 shape/color 字段分派到约 16 个 case (0x00/0x10/0x20/0x40/0x50/0x60/0x80/0x90/0xa0/0xc0/0xd0/0xe0), 每个 case 设置 r10 (tile stride) 和 r5 (行数); 对每个 OBJ 对象: 从 [gPrng/ptn.data] 拷贝 tile 数据到 VRAM 0x06010000 (copy_bytes_by_halfword), 组装 OAM attr0/1/2 并 push 到 AOB OAM 缓冲区 (FUN_080f70c4). 多态场景: r2 bit7 决定是否水平翻转 tile 起始地址.

Constants:
- 0x06010000 = OBJ tile VRAM base (DAT_080f81e8 / DAT_080f829c)
- 0x1ff = OAM attr1 tile mask (DAT_080f82a0/080f83a0)
- 0xa6 * 2 = 0x14c = assert line number (suppress_assert_report 哨兵)
- 每 case 的 r5/r10 组合对应 OBJ 形状 (1x1/1x2/2x2/4x4 等)
- bit[5:4] of aob.flag13 = 0x20 -> 启用 palette-from-frame

## 参数签名
- r0: ptr aob_ctrl* -- AOB 控制块指针 (r0+4 指向 ptn, r0+0x10 = base_x, r0+0x12/13 = flag 字节)
- r1: u32 packed_xy -- bits[15:0]=delta_x, bits[31:16]=delta_y (加到 aob.base_pos)
- r2: u8 flip_flags -- bit7=H-flip tile base, bits[1:0]=OAM attr1 flip [0..3]
- r3: u8 pal_idx -- OAM 调色板索引 [0..15]
- 返回: r0 = u16 累积 tile 行偏移 (正常路径), 或 0 (空帧路径 LAB_080f838e)

## 副作用
- [0x06010000 + tile_dest]: 写帧 tile 图形数据 (copy_bytes_by_halfword)
- [AOB OAM buffer + slot*6]: 写 attr0/1/2 三个 halfword (FUN_080f70c4)
