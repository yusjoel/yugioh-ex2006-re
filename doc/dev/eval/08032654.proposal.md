## plate comment (ASCII-only, 中文汉字 + ASCII 标点)
超高频工具函数 (indeg=59), 被决斗场 duel_field 几乎所有效果放置判断路径调用.
功能: 统计玩家侧 (r0) 的场地中, 针对给定卡片 (r1), 有多少效果区格位尚未被占用可用.
首先调用 FUN_0804ad48(card_id) 检查该卡是否具有扩展数据表 field5 (即 "有特殊效果计数"),
以此决定搜索哪个区域:
  - 有 field5: 在 gDuelFieldSlots 偏移 0x10a4 处起的 5 格 (r3=0..4) 内, 对每格检查 card_id 匹配+配对标志+活跃性, 并通过位域 (1<<(side*16+slot_idx)) 判断该位置是否已被占用; 未占用则 r8 计数 +1.
  - 无 field5: 调用 FUN_080eee7c(card_id) 取扩展 field9; 若 field9==2 则在 0x0201c5d8 (slot[10]) 处检查单格; 否则循环 r3=0..9 扫描 gDuelFieldSlots 基址区.
参数 r2 = exclude_slot 作为排除索引 (传 -1 则不排除任何格).
返回 r8 = 可用效果格数量; 调用方用非零判断来决定是否允许该卡的效果激活.

Constants:
  0x0201c510 = gDuelFieldSlots base (EWRAM)
  0x10a4 = 效果区分区偏移 (gDuelFieldSlots+0x10a4 = 0x0201d5b4)
  0x0201c5d8 = gDuelFieldSlots+0xc8 = slot[10] (特殊区单格)
  0x868 = 单玩家侧 slot stride
  0x14 = 单 slot 条目步长

## 参数签名
- r0: u8 side_flags -- 低 1 bit = player_side [0..1]
- r1: u16 card_id -- 目标卡片 ID
- r2: s32 exclude_slot -- 排除的格索引 [0..0x44] 或 -1 (不排除); 函数内通过 r9 保存
- 返回: r0 = u32 -- 可用效果格数量 (0 表示无可用格; 非零表示可激活)

## 副作用
- 无外部写入 (仅读 gDuelFieldSlots 和扩展卡属性表)
