## 修改清单

### #1 — R4 (高优先级)
**位置**: proposal "## 参数签名" 返回行 + plate comment 出口描述
**问题**: asm 0x08096a4c 出口唯一路径 `pop {r4,r5}; pop {r0}; bx r0` (LAB_08096a94 汇合后): pop {r0} 始终将保存的 LR 加载到 r0, 覆盖任何 callee 返回值。equip 路径 bl commit_equip_target_slot_by_card_id 后的 b LAB_08096a94 和状态写路径均经由同一 pop {r0} 退出。强制 void。
**当前**: `返回: r0 = u32 result (equip 路径: 透传 commit_equip_target_slot_by_card_id 返回值; 状态写路径: void/未定义)`; plate: "(透传 commit 返回值或 void)"
**应改为**: `返回: void (pop {r4,r5}; pop {r0}; bx r0 出口: r0 被保存的 LR 覆盖, 无论哪条路径均丢弃 callee 返回值)` ; plate 改为 "(void 出口)"
