# Naming Proposal: 0x081140b8

## 提案
- **proposed_name**: compare_float_ne
- **confidence**: med

## plate comment (中文, ASCII 标点)
GCC libgcc 单精度浮点不等比较函数 (__nesf2): 结构与 compare_float_eq (0x08114070) 完全相同, 解包两个 float 后检测 NaN (kind > 1 -> 返回 1), 正常路径调用 __fpcmp_parts_f.
GCC __nesf2 约定: 返回非零 = 不相等 (与 __eqsf2 返回值语义相同, 调用方用 beq/bne 区分用途).
该函数在静态调用图中 indeg=0 (未被任何函数直接调用), 无函数指针引用, 属于编译器生成的未使用符号 (dead code).

## 参数签名
- r0: f32 a -- 单精度浮点 A (IEEE 754 bit-pattern)
- r1: f32 b -- 单精度浮点 B (IEEE 754 bit-pattern)
- 返回: r0 = s32; 非零 = A!=B 或含 NaN, 0 = A==B

## 副作用
- 栈: 解包临时结构 (局部)
