# Naming Proposal: 0x080c7950

## 提案
- **proposed_name**: copy_game_text_to_card_name_vram
- **confidence**: high

## plate comment (中文, ASCII 标点)
将游戏字符串写入卡片名称 VRAM 缓冲区, 对应 dispatch_card_display_op case 0x31. 先调用 zero_card_name_vram_buf (FUN_080c786c) 清空 32KB VRAM 区, 再对 r1 (game_str_id) 调用 resolve_game_str_ptr 检查是否有效 (非空). 若有效则再次调用 resolve_game_str_ptr 取字符串指针, 再调用 copy_cstr_to_buf(vram_base+1, str_ptr) 将字符串内容复制到 VRAM. 三参数: r0=zone_descriptor/player, r1=game_str_id, r2=extra_flags (存入 r5 备用). Constants: vram_base=DAT_080c7984, vram_offset=+1 (skip first halfword), game_str_tag=font_jp/game_str.

## 参数签名
- r0: u32 zone_descriptor zone/player 描述字 [0..0xffffffff], 存入 r7 供后续使用
- r1: u16 game_str_id 游戏字符串 ID [0..0xd7ea] (实测表上界, game_str_id_remap_table @ 0x08000250 共 1651 项, 最大 logical_id=0xd7ea; callsite 0x0809347c 传入字面量 0xe7), 传给 resolve_game_str_ptr; bit17+ 置位时视为 raw pointer passthrough
- r2: u32 extra_flags 额外标志 [0..2] (函数内 case_2 路径 cmp r5,#0x2; 多数 callsite 传入 0; 在 case_4/5/6/7/9/a/d 路径直接转发给各 init/render callee)
- 返回: r0 = void (bx r0 via pop)

## 副作用
- [DAT_080c7984 .. +0x7fff]: 全部清零 (经 zero_card_name_vram_buf)
- [DAT_080c7984+1 ..]: 游戏字符串内容 (经 copy_cstr_to_buf, 按 game_str 格式)
