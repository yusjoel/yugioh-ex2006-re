# Naming Proposal: 0x0801b7a0

## 提案
- **proposed_name**: read_encoded_char_pair_from_state
- **confidence**: med

## plate comment (中文, ASCII 标点)
由调用方传入源字节指针 r0,目标缓冲指针 r1。读取 EWRAM 全局状态字节 [0x02006c2c+0x00000000] = [0x02006c2c] 的低 3 位 (bits[2:0]), 若非零则跳过双字节提取; 若为零 (OCG/日文模式) 则进一步检测源字节 bit7 (0x80 掩码), 若 bit7 置位则将源字节对 (r0[0], r0[1]) 写入目标缓冲 (r1[0], r1[1]), 同时将 0 写入 r1[1], 并返回 r0=2 (双字节步进量). 若状态非零或 bit7 未置位, 则仅将 r0[0] 写入 r1[0] 并返回 r0=1 (单字节步进量). 本函数用于在迭代解码字符串时根据当前编码模式决定逐字节步进还是双字节步进, 是文字渲染/字符串解析管线的低层辅助叶子.

Constants:
- STATE_ADDR = 0x02006c2c (EWRAM 编码模式标志, bits[2:0]=0 => OCG 模式)
- DOUBLE_BYTE_LEAD_MASK = 0x80 (源字节 bit7 = 双字节引导标志)
- STEP_DOUBLE = 2 (r0 返回值, 双字节步进)
- STEP_SINGLE = 1 (r0 返回值, 单字节步进; LAB_0801b7d4 路径)

## 参数签名
- r0: u8* src_char_ptr (源字符串当前位置指针)
- r1: u8* dst_buf_ptr (输出缓冲, 至少 2 字节)
- 返回: r0 = u32 byte_step (2=双字节字符已写入 dst[0..1], 1=单字节字符已写入 dst[0])

## 副作用
- [r1+0x0] := r3[0] (src_char_ptr[0], 字符字节 0 写入目标)
- [r1+0x1] := r3[1] (OCG 双字节路径: src[1]; 非双字节路径: 0x00)
- [r1+0x2] := r4=0 (双字节路径: bits[2:0]=0 写入, 表示不含高位标志)

## 行级注释 (<=30 行精华)
- @ 0801b7a4: 加载 EWRAM 基址 0x02000000 + 偏移 0x6c2c = 编码模式标志字节地址
- @ 0801b7aa: mask = 0x7, 提取 bits[2:0] 决定 OCG/TCG 编码模式
- @ 0801b7b0: bits[2:0]!=0 (TCG 模式) => 跳至 LAB_0801b7d4 (单字节路径)
- @ 0801b7b6: 检测 src[0] bit7: 是否为双字节引导字节
- @ 0801b7bc: bit7 未置 => 跳至 LAB_0801b7d4 (单字节路径)
- @ 0801b7be: OCG 双字节: 写 src[0] -> dst[0], src[1] -> dst[1], 0 -> dst[2]
- @ 0801b7c6: 返回 r0=2 (双字节步进)
- @ 0801b7d4: 单字节路径: 写 src[0] -> dst[0]
- @ 0801b7d8: 写 0x00 -> dst[1] (清空第二字节)
- @ 0801b7dc: 返回 r0=1 (单字节步进)
