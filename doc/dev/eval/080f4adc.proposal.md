# Naming Proposal: 0x080f4adc

- **confidence**: high

## plate comment (中文, ASCII 标点)
由拼图场景帧驱动 FUN_080f4b78 每帧调用, 负责将 OBJ shadow list 数据 DMA 提交到 OAM 并重置列表状态.
函数检查 gPrng+0x174 (IWRAM flag halfword) bit0: 若为 0 则整体跳过. bit0=1 时执行: 若 bit15 置位则先调用 sort_obj_shadow_list_by_priority 排序; 随后计算源地址 [gPrng+0x1bc], 调用 copy_memory_dma3_chunked (0x400 * 0x80 = 0x400 halfwords, 即 128 OBJ * 4 halfwords) 将 shadow list DMA 拷贝到 OAM; 然后 clear_obj_list_entries_range(0, 128) 清空 0..127 OBJ 列表槽; 最后将 [gPrng+0x1bc]+0x401 和 +0x400 两个标志字节写 0 (重置列表头/尾指针).

Constants:
- IWRAM_FLAG_OFFSET = 0x174 (gPrng+0x174 flag halfword; bit0=enable, bit15=sort_needed)
- SHADOW_LIST_OFFSET = 0x1bc (gPrng+0x1bc OBJ shadow list 基指针)
- DMA_COPY_SIZE = 0x400 halfwords (0x80 OBJ * 8 bytes = 0x400 bytes)
- OAM_ENTRY_COUNT = 0x80 (128 OBJ)
- LIST_FLAG_OFFSET1 = 0x401 (shadow list head 标志, DAT_080f4b38)
- LIST_FLAG_OFFSET2 = 0x400 (shadow list tail 标志, movs r5,#0x80; lsls r5,r5,#0x3 -> 0x80<<3=0x400, python: assert 0x80<<3==0x400)

## 参数签名
- 返回: void (pop{r4,r5}; pop{r0}; bx r0)

## 副作用
- OAM (0x07000000) <= copy_memory_dma3_chunked (条件: bit0=1)
- [gPrng+0x1bc][0x401] := 0x00 (list head 重置)
- [gPrng+0x1bc][0x400] := 0x00 (list tail 重置)
- clear_obj_list_entries_range: OBJ 列表 0..127 清空
