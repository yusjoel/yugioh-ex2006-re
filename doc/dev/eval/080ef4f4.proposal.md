- **confidence**: high

## plate comment (中文, ASCII 标点)
检查 IWRAM 链接状态 ([0x030003a0+0x033f] != 0 且 [0x030003a0+0x0344] != 0) 后启动 SIO 主机传输. 两个条件均满足时: 写 SIOCNT+2 (SIO 速率控制字 0xfefe), 读 SIOCNT 并置 bit7 (START=1) 写回 SIOCNT+0, 最后写 TM3CNT_H=0xc0 启动定时器 3 驱动 SIO 时序. 仅在联机对战握手阶段由 SIO 状态机 (0x080ef958) 在确认连接就绪后调用.

Constants:
- SIO_STATE_BASE=0x030003a0 // IWRAM SIO 连接状态结构基址
- READY_FLAG1_OFF=0x033f // 连接就绪标志 1 偏移
- READY_FLAG2_OFF=0x0344 // 连接就绪标志 2 偏移
- SIOCNT_RATE=0xfefe // SIO 速率/格式控制字
- TM3CNT_H_ENABLE=0xc0 // Timer3 使能 (prescale=4, enable=1)
