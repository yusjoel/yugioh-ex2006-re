Dispatches LP row sprite based on global activation display state code, using [r0+8] bit0 (token_player_bit) as player_id parameter. Receives effect_slot_node ptr (r0). Extracts [r0+8] bit0 (token_player_bit) into r2. Checks guard_bit ([r0+4] bit2); if set skips. Reads global state code [0x0201b290+0x94*8]: state 0x80: calls apply_lp_delta_if_slot_active (r0=r2, r1=1, r2=1, r3=0), returns 0x7f. State 0x7f: calls enqueue_lp_display_row_if_enabled (r0=r2, r1=1, r2=0, r3=1), returns 0x7e. Other or guard returns 0.

Params: r0=ptr effect_slot_node ([r0+4] bit2=guard_bit, [r0+8] bit0=token_player_bit)
Returns: r0=u8 new_state (0x7f/0x7e or 0=guard/skip)
Side effects: updates LP delta via apply_lp_delta_if_slot_active (state=0x80); writes LP display row via enqueue_lp_display_row_if_enabled (state=0x7f)

Constants:
- GUARD_BIT=0x4 (bit2 of [r0+4])
- TOKEN_PLAYER_BIT=bit0 of [r0+8] halfword
- STATE_DISPLAY_BASE=0x0201b290
- STATE_IDX_OFFSET=0x94*8=0x4a0
- DELTA_FLAG=1 (apply_lp_delta r2 arg)
- ROW_R2=0; ROW_R3=1 (enqueue_lp_display_row args for state=0x7f)
- STATE_0x80=0x80 -> returns 0x7f; STATE_0x7f=0x7f -> returns 0x7e
