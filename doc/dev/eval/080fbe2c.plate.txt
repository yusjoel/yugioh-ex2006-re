Puzzle scene initialization function. Writes [gPrng+0x174]=1 (marks scene active), clears [0x020297e4] bits0/1, calls verify_puzzle_ewram_integrity to verify EWRAM integrity (result written to [0x020297e4] bit0; if verification fails sets bit1 as error flag), then sequentially calls reset_affine_bg_matrix_and_scroll, store_ewram_ctx_ptr_and_clear_mode_flags(0x02029eb0), reset_display_and_obj_vram(0x02039eb0), reset_all_bg_scroll_regs_and_shadows, apply_blend_fadeout_flat, finally writes BG2CNT=1. Called by FUN_080fdd3c (tags: [puzzle_scene, page_handler]; role: puzzle scene page handler frame driver, routes to this function after verify_puzzle_ewram_integrity succeeds).

Constants:

PUZZLE_FLAGS_ADDR=0x020297e4 (puzzle EWRAM flags byte)
PUZZLE_EWRAM_OK_BIT=0x1 (bit0: verify success flag)
PUZZLE_EWRAM_ERR_BIT=0x2 (bit1: verify failure error flag)
PACK_CTX_A=0x02029eb0 (pack A/puzzle EWRAM context base address)
