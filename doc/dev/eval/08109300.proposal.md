## plate comment (中文, ASCII 标点)
由 FUN_080ff56c (card_stats+settings 场景) 唯一调用, 负责将指定卡帧槽位的 tile 数据和调色板写入 VRAM. 函数接收三个参数 (r0=slot_index, r1=palette_id, r2=card_type), 保存至栈; 读取 [0x02006c2c] bit[2:0] 选择两套 ROM 查找表 (DAT_08109340 或 DAT_081094c0, 均为 card_stats_entry 数组基址); 按 slot_index*5*4 定位目标 slot_entry. 调用 copy_bytes_by_halfword 复制 0x280 字节 (0xa0*4) 的 tile 数据至 VRAM 0x06009400; 然后对 slot_entry 的每个 col/row 调用 resolve_card_frame_palette_by_type + tile_2d_row_copy 将调色板索引写入 VRAM 0x06011000. 最后调用 copy_bytes_by_halfword 向 VRAM 0x0600E800 写入 OAM tile 头信息, 再调用 load_card_frame_tile_row_by_index 和 copy_card_frame_tile_rows_to_vram (081099f0) 完成 tile 行复制; 对 [0x0202f3c0+0x1e] OR 0x8 (bit3) 置位标记渲染完成.

## 参数签名
- r0: s16 slot_index [0..N] (卡帧槽位索引, 用于 slot_type*5*4 定位)
- r1: s16 palette_id (调色板 ID, 用于 resolve_card_frame_palette_by_type)
- r2: s16 card_type (卡片类型, 用于区分有效/无效槽位; -1 表示无效)
- 返回: r0 = u32 0 (无效 slot) 或 1 (渲染完成)

## 副作用
- [VRAM 0x06009400]: 写入 0x280 字节 tile 数据 (copy_bytes_by_halfword)
- [VRAM 0x06011000]: 写入 OBJ tile 行 (tile_2d_row_copy, 每列)
- [VRAM 0x0600E800]: 写入 OAM tile 头 halfword 序列
- [0x0202f3c0+0x1e] |= 0x8 (bit3): 标记渲染完成 (@ 081095a8/081095b0)
- [0x0202f3c0+0x40/0x42/0x38]: 写入 tile 宽/高/slot_type 字段
