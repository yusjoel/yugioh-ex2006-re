## plate comment (中文, ASCII 标点)
若 r1 (enable_flag) 为 0 则立即返回 (无操作).
否则构建 flags 位域: bit0 = (r2==1); bit1 = (r3!=0); bit2 = (r2==8); bit3 = (r2==7).
flags 被截断为低 16 位后作为第四参数传给 set_lp_display_row_fields(r0=player, r1=1, r2=r1_in&0xffff, r3=flags).
行类型固定为 1 (LP 显示行类型 1, 对应 LP 数值行).
调用方 (0x0806ec54) 在装备 LP 消耗处理完成后更新 LP 显示行.
Constants: ROW_TYPE=1 (固定), ATTR_CODE_MONO=1, ATTR_CODE_FIELD=7, ATTR_CODE_EQUIP=8, FLAGS_MASK=0xffff.
