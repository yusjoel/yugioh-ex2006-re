## plate comment (中文, ASCII 标点)
被 8 个 duel_field 调用方调用, 用于在格子激活判断链中结合牌组 flag 进行二次验证. 若 r1 (secondary_check) 为 0, 则先调用 check_field_effect_zone_activation_eligible 得到默认结果存入 r4; 若 r1 非 0 则直接以 r1 为比较目标. 随后调用 get_player_deck_flag_bit1 获取玩家牌组 bit1 标志, 比较两者: 若相等则返回 (跳过后续); 否则以 r0=0x51 (或 0x8051) / r1=r4 (low 16 位) / r2=r3=0 调用 enqueue_sprite_attr_record 推入精灵队列. 本函数将区域激活资格检测与精灵更新触发合并为单一调用点.

## 参数签名
- r0: u32 player_side [0..1]
- r1: u32 secondary_check: 0=调用 check_field_effect_zone_activation_eligible 取默认值, 非 0=直接用该值作比较基准
- 返回: r0 = void (pop {r4,r5}; pop {r0}; bx r0, THUMB non-standard return)

## 副作用
- 经 enqueue_sprite_attr_record: 向 OBJ 精灵队列写入 attr0=0x51 (或 0x8051) / attr1=r4[15:0] / attr2=0
