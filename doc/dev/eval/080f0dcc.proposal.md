# Naming Proposal: 0x080f0dcc

## 提案
- **proposed_name**: write_byte_to_glyph_tile_buf
- **confidence**: high

## plate comment (中文, ASCII 标点)
向 EWRAM font_jp 字形 tile 缓冲区的指定像素位置写入单字节颜色值. 以 r0=x_pixel, r1=y_pixel, r2=color_byte 为输入, 从 [0x02006ed0+0] 读取 VRAM 基地址指针, 读取 [0x02006ed0+0x8] 的 width_in_tiles (bits[21:16]), 计算 tile 内偏移: tile_col=(x&7)*4, tile_row=(y&7)*32, x_tile=(x>>3), y_tile=(y>>3), byte_offset = (y_tile*width_tiles+x_tile)*64 + tile_row + tile_col, 写入 r2 到 glyph_buf_base+byte_offset. 用于逐像素填充字形 tile 缓冲区.

Constants:
- FONT_CTX=0x02006ed0 // EWRAM font_jp 上下文
- TILE_SIZE_SHIFT=6 // tile 大小 64 字节 = 1<<6
- PIXEL_BYTE_SHIFT=2 // 4bpp: x&7 * 4 = 每像素 4 位 x 2 = 字节偏移

## 参数签名
- r0: s16 x_pixel (像素列坐标)
- r1: s16 y_pixel (像素行坐标)
- r2: u8 color_byte (写入值)
- r12 (via `.hword 0x4647` = mov r7,r12 @ prologue, caller-set): 保存 caller 的 r12 — 不是独立参数
- 返回: void (pop {r0}; bx r0)

## 副作用
- [glyph_buf_base + byte_offset] := r2 (字节写入字形 tile 缓冲)
