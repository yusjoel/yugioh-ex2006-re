## plate comment (中文, ASCII 标点)
被决斗场地 tile 渲染函数 (indeg=6) 调用, 计算某个场地 slot 对应的 BG tile VRAM 地址. r0 = player_side (0/1), r1 = slot_pos [0..16], r2 = palette_select (0xFF 归零). 先将 r2 规范化 (0xFF -> 0), 再按 r1 做 switch 分发: slot 0..4 -> r3=0, r2=slot (列组 A); slot 5..9 -> r3=5, r2=slot-5 (列组 B); slot 10..11 -> r2=6; slot 12..15 -> r2=6; slot 16 -> r2=0. 计算 row_offset = (r3+r2)*9 (tile row stride), byte_offset = row_offset*2*0x20 = row_offset * 0x40. 根据 player_side 与 [0x0201e2a0+4] XOR 1 比较选择 VRAM 基址: player_side 匹配 -> 0x060031c0, 否则 -> 0x06000040. 返回 VRAM 地址 = base + row_offset * 0x40.

## 参数签名
- r0: u8 player_side - 玩家方向 (0=自方, 1=对方), [0..1]
- r1: u8 slot_pos - 场地 slot 位置索引, [0..16]
- r2: u8 palette_select - 调色板选择 (0xFF 时归零), [0x00..0xFF]
- 返回: r0 = u16* vram_tile_addr - 对应 slot 的 BG tile VRAM 基地址 (4bpp, 0x06000040 or 0x060031c0 + offset)
