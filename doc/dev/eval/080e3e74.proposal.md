# Naming Proposal: 0x080e3e74

## 提案
- **proposed_name**: format_card_name_to_buf
- **confidence**: high

## plate comment (中文, ASCII 标点)
将指定内部卡 ID 对应的卡名, 按当前游戏模式标志选择格式模板展开到目标缓冲区. r0=目标缓冲区指针, r1=内部卡 ID (icid). 读取 EWRAM+0x6c2c 的低 3 位 (游戏模式标志 0..5), 根据模式从 5 个 ROM 格式字符串表 (基址 0x09dc0094, 0x09def018, 0x09de2b74, 0x09dd6804, 0x09dcae7a 等) 选择对应格式串. 然后调用 card_name_lookup_by_internal_id 取卡名字符串, 再调用 expand_format_text_to_buf 将格式串展开写入 r0 指向的缓冲. 若 r0=0 (null buf) 则直接跳过所有操作. 主要由卡包场景的卡牌详情渲染路径调用.

Constants:
- EWRAM_GAME_FLAGS = 0x0200_6c2c (游戏模式标志字段地址)
- GAME_MODE_MASK = 0x7 (低 3 位 = 模式索引 [1..5])
- ROM_FORMAT_TABLE_1 = 0x09dcae7a (mode=1 格式串基址)
- ROM_FORMAT_TABLE_2 = 0x09dd6804 (mode=2)
- ROM_FORMAT_TABLE_3 = 0x09de2b74 (mode=3)
- ROM_FORMAT_TABLE_4 = 0x09def018 (mode=4)
- ROM_FORMAT_TABLE_5 = 0x09dc0094 + 0x0003ab4e (mode=5 偏移)

## 参数签名
- r0: char* dst_buf -- 目标文字缓冲区指针; 为 0 时跳过所有操作
- r1: u16 icid -- 内部卡 ID, 用于 card_name_lookup_by_internal_id
- 返回: void (pop {r0}; bx r0 -- 无独立 r0 写)

## 副作用
- [dst_buf..]: 写入格式化卡名文字字符串
