# Naming Proposal: 0x080f4018

## 提案
- **proposed_name**: blit_tile_nibble_row_with_xstride
- **confidence**: high

## plate comment
与 blit_tile_nibble_row_lsb 同族, 增加第三参数 x_stride: r1 左移 5 位作为每行 dst 横向步进 (x_stride = r1<<5 = col * 32 字节). dst 每行基址 = gPrng+0x0[base] + row*x_stride, 支持按指定列偏移写入 tile 像素. 仍检查 gPrng+0x14 bit7, 无高色深转发逻辑 (不调用 blit_tile_color_to_vram_region, 直接走 nibble 展开路径). 使用 0x0fff/0xfff0/0xff0f/0xf0ff 掩码顺序 (LSB first).

Side effects: 写 VRAM[gPrng+0x0[base]+row*x_stride..] halfword; 无 IO 寄存器副作用.

Constants:
- HIGH_COLOR_MODE_FLAG = 0x80 // gPrng+0x14 bit7
- MASK_NIBBLE0 = 0x00000fff // LSB first nibble AND mask
- MASK_NIBBLE1 = 0x0000fff0
- MASK_NIBBLE2 = 0x0000ff0f
- MASK_NIBBLE3 = 0x0000f0ff
- X_STRIDE_SHIFT = 5 // r1 << 5 = x_stride in bytes

## 参数签名
- r0: u16* dst VRAM 行起始基址
- r1: u16 x_col_offset 列偏移 [0..31], x_stride = r1 << 5
- r2: u16 color 4bpp 颜色索引 [0x0..0xf]
- 返回: void (pop {r0};bx r0 - r0 被 lr 覆盖)

## 副作用
- [gPrng+0x0+row*x_stride..]: OR-write u16 按 LSB nibble-first 写 tile 像素行
