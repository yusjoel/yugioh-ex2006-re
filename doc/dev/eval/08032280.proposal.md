# Naming Proposal: 0x08032280

## 提案
- **proposed_name**: dispatch_card_placement_by_zone_type
- **confidence**: high

## plate comment (中文, ASCII 标点)
按 zone_type (r1) 将卡片放置操作路由到对应的区域处理函数. 函数体为 6-case switch + default 双分支分发器: case 0xb=装备区类型检查插入 (FUN_08037630), case 0xc=直接装备区插入 (FUN_08031630), case 0xd=手牌插入或追加 (FUN_08031578 / FUN_080315f8), case 0xe=墓地区检查插入 (FUN_08036cb8), case 0xf=墓地区带参插入 (FUN_08036d08), case 0x10=通用分支; default<=4=怪兽区 (place_card_into_monster_zone_slot), default>4=魔法/陷阱区 (place_card_into_spelltrap_zone_slot). switch 结束后根据玩家 id 匹配及 zone 范围, 可选调用 clear_equip_refs_for_leaving_slot 和 clear_equip_chain_for_zone_slot. indeg=10, 场地操作总入口之一.

## 参数签名
- r0: u32 player_id [0..1] - 玩家索引
- r1: u32 zone_type [0..0x10] - 目标区域类型编码
- r2: word card_data - 附加数据 (传递到 case handlers 或用于手牌 insert/append 区分)
- r3: word* slot_ref - 卡片槽位引用 (传递给各 case 处理函数)
- sp[0x24]: u8 extra_byte - 第 5 参数 (传递到 place_card_into_monster_zone_slot)
- 返回: void (pop {r0}; bx r0)

## 副作用
- 根据 zone_type 分发, 写入对应玩家场地槽位或数组 (由子函数完成)
- 可选: 调用 FUN_0802ecbc 清理装备链引用
- 可选: 调用 FUN_0802edac 清理 zone 链节点
