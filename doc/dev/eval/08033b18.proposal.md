## plate comment (中文, ASCII 标点)
统计指定玩家场地上装备槽中符合白名单条件的槽数量.
入口: r0=player_id_ptr, r1=card_ptr (r9 alias), r2=start_count (r6=r2), r3=allow_face_down_flag (r8 alias).
遍历 gDuelFieldSlots[player*0x868+slot*0x14] 共 r8 个槽 (从 slot=0 开始):
  - 检查 active bit (lsls #0x13) -- 若 0 则跳过.
  - 若 slot <= 4: 调用 check_slot_card_is_equip_whitelist(r0=player_id, r1=slot_idx) 验证白名单.
  - 若通过白名单: 检查 [slot+0x8] halfword (附加条件): 根据 allow_face_down_flag (r6) 决定是否计入.
  - 满足条件则 r2++ (累计数).
返回 r2 (最终计数).
5 个 caller 含 FUN_080acc30/FUN_080bb0f8/FUN_080bb414 (duel_field), FUN_08033b08 (批次内 wrapper).

Constants: gDuelFieldSlots=0x0201c510 (DAT_08033b78), player_stride=0x868 (DAT_08033b74), slot_stride=0x14, active_bit_shift=0x13, max_slot_guard=4.
