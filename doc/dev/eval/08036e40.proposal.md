# Naming Proposal: 0x08036e40

## 提案
- **proposed_name**: insert_card_into_hand_list_by_zone_desc
- **confidence**: high

## plate comment (中文, ASCII 标点)
在指定玩家的手牌列表中按区域描述符查找目标卡, 并将其通过 swap_deref_words 移位插入至目标位置.
r0 = player_side (bit0), r1 = target zone descriptor (u16, [0..0xffff]).
读 gP1LP+player*0x868+0x14 为手牌计数, 手牌数组基址 gP1LP+player*0x868+0x418 (0x83<<3).
内部循环: 从当前 count-1 开始向 0 逐步比较每个槽的 zone_desc 字段 (lsls/lsrs #0x2/#0x18 取 bits[23:16], lsls/lsrs #0x12/#0x1f 取 bit[13]);
命中后调用 swap_deref_words 将目标槽换到目标位置, 再用 write_word_from_deref_src 拷贝后续槽;
若未找到则直接跳过. 由主状态机各阶段在需要将特定卡片移动至手牌数组前端时调用.
Constants: player_stride=0x868; hand_count_offset=0x14; hand_array_a_offset=0x418 (=0x83<<3);
list_b_base=0x0201c8f8; list_b_neg_offset=0xfffffbfc (-0x404).

## 参数签名
- r0: u8 player_side [0..1] - bit0 取玩家索引
- r1: u16 zone_desc [0..0xffff] - 待查找区域描述符; lsls #0x10/lsrs #0x10 提取低 16 位
- 返回: r0 = void (pop{r0};bx r0 尾返回, 无独立 r0 写)

## 副作用
- [gP1LP+player*0x868+0x418 + idx*4..end]: 通过 swap_deref_words + write_word_from_deref_src 移位手牌条目
- [sp+0x0]: 临时保存 r3 (table_ptr), 栈局部, 不计入外部副作用
