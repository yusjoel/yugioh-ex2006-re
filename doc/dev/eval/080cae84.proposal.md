## plate comment (中文, ASCII 标点)
根据 card_id 对应的数值(如 ATK/DEF 等), 将十进制数字拆位后查 VRAM FA 区域的数字 tile 索引
并写入 OBJ tile VRAM 0x0600fa40. 首先通过 player_id/slot_index 从 gDuelFieldSlots 查到
card_id(r6) 和一个计数值 r5; 若 card_id == 0x1909 则对 r5 做补运算. 再通过 get_card_effect_category,
check_card_id_is_equip_set_b, check_card_id_is_equip_set_a 三级分类选取 tile base 偏移
(0x1b5/0x1b6/0x1b4). 然后循环 __divsi3/__modsi3 拆十进制位, 每位查 tile 索引写入
VRAM 0x0600fa40. 若 r5<=0 则清零该区域. Constants: gDuelFieldSlots=0x0201c510,
player_stride=0x868, VRAM_digit=0x0600fa40, card_id_special=0x1909,
tile_base_effect=0x1b5, tile_base_setB=0x1b6, tile_base_setA=0x1b4,
digit_base_tile=0x1a6(=0xd3<<1).
