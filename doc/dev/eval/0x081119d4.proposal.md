## plate comment (中文, ASCII 标点)
dlmalloc 互斥锁占位函数 (解锁桩): 函数体仅 bx lr, 不执行任何操作.
在 _free_r / _malloc_r / _malloc_trim_r / _realloc_r 退出临界区后被调用, 用于在单线程嵌入式环境中替代真正的互斥锁释放.
GBA 无 RTOS 上下文, 因此解锁为空操作; 与 stub_malloc_lock (0x081119d0) 成对出现.
