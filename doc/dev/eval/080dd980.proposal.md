## plate comment (中文, ASCII 标点)
将 HSV (色相/饱和度/明度) 颜色值转换为 GBA RGB555 格式并返回.
r0=hue_phase (0..0x168-1 色相相位, 函数内通过除以 0x168 和取余得到 0..5 的 6-sector 索引),
r1=saturation (0..0xff), r2=value (0..0xff/亮度).
内部依次计算 p/q/t 中间值, 以 switch(sector 0..5) 分派 R/G/B 通道赋值方案,
经 bios_div 归一化后打包为 GBA 15-bit 颜色 (R[4:0], G[9:5], B[14:10]).
被 overlay 颜色渐变/fadeout 路径调用, 每帧对一段颜色缓冲区按 HSV 旋转产生色彩动效.

Constants:
- HUE_PERIOD=0x168=360 (色相周期, r0 对 0x168 取余得 sector)
- SATURATION_MAX=0xb4=180 (饱和度归一化因子)
- VALUE_MAX=0xff=255
- RGB_CHANNEL_BITS=0x1f (5-bit 通道掩码)
- G_SHIFT=5 (G 通道移位), B_SHIFT=10 (B 通道移位)

## 参数签名
- r0: u16 hue_phase [0..0x167] (色相输入, mod 0x168 得到 sector 0..5)
- r1: u8 saturation [0..0xff] (饱和度, 0=灰, 0xff=全饱和)
- r2: u8 value [0..0xff] (亮度)
- 返回: r0 = u16 packed GBA RGB555 color
