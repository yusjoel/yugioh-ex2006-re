## plate comment (中文, ASCII 标点)

Function: 在 GFX 资源链表中按 "PALT" (0x544c4150) 标签查找调色板条目,
读取 [+0x8] 字段 (条目数 / 大小计数) 并左移 1 位 (*2) 得到字节大小返回.
若未找到条目则返回 0.
PALT 调色板条目每项 2 字节 (GBA 15-bit 颜色), 故 count*2 = total byte size.
indeg=0; 为 PALT GFX 查询工具函数族成员.

Side effects: 无 (纯查询).

Constants:
- PALT_TAG = 0x544c4150 ("PALT", DAT_080161d4)
- PALT_COUNT_FIELD = [+0x8] (条目/颜色数量)
- BYTE_SIZE = count * 2 (每 GBA 颜色 2 字节)
