## plate comment (中文, ASCII 标点)
读取目标槽位 (r0=player_side bit0, r1=slot_idx) 的装备卡集合代码 (set_code).
流程:
(1) 定位 gDuelFieldSlots[player_side][slot_idx] (步长 0x14), 读 slot[+0] 的 card_id (low 13 bits);
(2) 调用 check_card_id_is_equip_set_a(card_id): 若非 equip set A -> 返回 0;
(3) 若属于 equip set A, 检查 slot[+0] lsls #0x13 字段是否等于 0xa5600000 (特定活跃标志);
(4) 若等于: 检查 slot_idx <= 4 (有效怪兽区), 再调用 find_equip_chain_pair_across_field(player, slot_idx);
    对返回值 lsls #0x10 后与 0xffff0000 比较 -- 若相等则返回 0 (无配对节点);
(5) 若不等 (有配对): 读 gDuelFieldSlots[player][slot_idx]+0xc 的 halfword 返回 (set_code);
(6) 若不等于活跃标志: 直接读 slot[+0xc] halfword 返回.
返回值: 0=无效/无配对, 非 0=set_code halfword.
调用方在 080a533c / 080a57b8 等装备配对检查链中使用此返回值匹配 set_code.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, slot_entry=0x14, active_flag=0xa5600000, no_pair_sentinel=0xffff0000.

## 参数签名
- r0: u32 player_side 玩家编号 [0..1] (bit0 使用)
- r1: u32 slot_idx 槽位索引 [0..4]
- 返回: r0 = u16 set_code 装备卡集合代码 (0=无效或无配对)
