## plate comment (中文, ASCII 标点)
LP 显示变化指示提交器: 把数值 r1 (clamped to <=0xffff) 与 r0 (player_id) 组合成 sprite attr record, 通过 enqueue_sprite_attr_record + submit_lp_bar_sprite_row_by_type 显示在 LP bar 区域. 提交前做 3 重 chain 检查  -  如果 r2!=0 且 check_value_in_slot_chain(player, 0xb, 0x1805) 命中 (slot 0xb 已存在 0x1805 类型节点), 或同样检查 0x1850 命中, 或 count_available_effect_zones 返回 0  -  则跳过提交直接返回 0. 命中后调用 FUN_0808f938 (refresh_opponent_field_slots) 与 submit_lp_bar_sprite_row_by_type 完成显示更新, 返回 1. 16 个 caller 全 duel_field, 用于伤害/恢复/装备/特殊效果触发后的 LP 数字浮动显示.

## 参数签名
- r0: u32 player_id [0..1] (lp 归属方; 转发给 check_value_in_slot_chain 的 packed_player)
- r1: u16 amount [0..0xffff] (要显示的数值; 0=skip 直接返回 0)
- r2: u32 chain_check_flag (非零时启用 0x1805 chain 检查路径; 0 跳过)
- r3: u32 enqueue_payload (转发给 enqueue_sprite_attr_record 的 r3 参与组合 attr 高位 -> r7 callee-save)
- 返回: u32 success (0=skip 或被 chain 拦截, 1=提交成功)

## 副作用
- enqueue_sprite_attr_record() : 写 sprite attr 队列 0x0201bcc0+0x808
- submit_lp_bar_sprite_row_by_type() : 写 sprite row data, 类型 0x10
- FUN_0808f938() : opponent 侧场扫描 (本 batch 0x0808f938)
- check_value_in_slot_chain() : 仅读 (3 处)
