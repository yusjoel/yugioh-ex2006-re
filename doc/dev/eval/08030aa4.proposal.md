## plate comment (中文, ASCII 标点)
接收决斗场 slot 坐标 (r0=player_side bit0, r1=slot_idx), 从 EWRAM 决斗场数组 (base 0x0201c510, player_side stride 0x868, slot stride 20 字节) 读取 slot 的 dword 数据, 取低 13 位得到 card_id. 依次与特定卡片 ID (0x172f / 0x1636 / 0x1809 / 0x1472) 比较: 命中则调用 check_node_in_slot_chain (FUN_0802fdc0, r0=side, r1=slot_idx, r2=0x1472, r3=5) 做进一步验证并返回其结果; 均不命中则调用 check_card_field8_is_normal (FUN_0804ad70) 以 card_id 判断是否为 field8 正常扩展类型. 被多个决斗场景 (duel_field / 0x0803xx / 0x0805xx / 0x0809xx) 调用, 用于判断指定格上的卡片是否属于可产生效果的装备/魔法牌类别.

常量说明:
  0x0201c510 = gDuelFieldSlots (决斗场 slot 数组基址, gP1LifePoints+0x30)
  0x868 = player_side stride (每方 slot 区字节数)
  slot entry stride = 20 bytes (r1*5*4)
  0x172f / 0x1809 / 0x1472 = 特定装备/魔法卡 ID (hardcoded whitelist)
  0x1636 = 第二个特定卡片 ID (= 0x172f - 0xf9; DAT_08030a6c=0x1636 asm:47150; 待 CSV 比对确认具体卡名)

## 参数签名
- r0: u32 player_side  (仅 bit0 有效; 0=P1 侧, 1=P2 侧)
- r1: u32 slot_idx  (决斗场 slot 索引, [0..4] 怪兽区或 [0..4] 魔法/陷阱区, 具体依调用上下文)
- 返回: r0 = bool  is_equip_type  (1 = 是装备/特效魔法牌类型; 0 = 否)

## 副作用
