Called as a function-pointer entry in the duel_field equip-slot eligibility dispatch pipeline.
Triple filter: bit19=1 AND slot_idx<=4 AND [slot+8]!=0. Then check_zone_slot_equip_prerequisites.
Reads card_ptr[+0] halfword (card_id) and dispatches on two specific IDs:
  0x12cd (Chain Destruction): traverses gDuelEquipNode list at 0x0201b290+0x4cc, checks node type
    [0x6..0x8] with player/slot match, compares get_slot_field5_score vs threshold 0xfa*8=0x7d0.
  0x184b (Rare Metalmorph): get_slot_card_state_code(player, slot) low 16 bits == 7 -> eligible.
Any other card_id -> return 0. Pure read-only query.

Constants:
- gDuelFieldSlots = 0x0201c510 (DAT_08051420)
- PLAYER_STRIDE = 0x868 (DAT_0805141c)
- SLOT_STRIDE = 0x14
- SLOT_IDX_MAX = 4 (cmp r4,#0x4 @ 080513f4)
- CARD_ID_0x12cd = 0x12cd (Chain Destruction, DAT_08051424)
- CARD_ID_0x184b = 0x184b (Rare Metalmorph, DAT_08051428)
- gDuelEquipNode_base = 0x0201b290 (DAT_08051478)
- NODE_LIST_OFFSET = 0x4cc (DAT_0805147c)
- NODE_TYPE_MIN = 0x6 (cmp r0,#0x6 @ 0805144e)
- NODE_TYPE_MAX = 0x8 (cmp r0,#0x8 @ 08051448)
- SCORE_THRESHOLD = 0x7d0 (0xfa*8, movs r1,#0xfa; lsls r1,r1,#0x3 @ 0805146a)
- STATE_CODE_7 = 0x7 (cmp r0,#0x7 @ 080514a2)
