# Naming Proposal: 0x08100968

## 提案
- **proposed_name**: dispatch_render_card_name_with_flags
- **confidence**: high

## plate comment (中文, ASCII 标点)
render_card_name_label (0x08100980) 的一层轻量封装. 从 IWRAM 0x0202a4d0 (card_list 状态基地址) 偏移 0x16 处读取一个字节, 取 bit1 (lsls/lsrs 提取) 作为 r1 渲染标志, 连同 r0 (card_id, 由外部 FUN_08100238 传入) 一起调用 render_card_name_label. 目的是将 IWRAM 中的 charset/display 状态标志透明地注入渲染调用, 调用方无需感知标志字段位置.

## 参数签名
- r0: u16 card_id (透传给 render_card_name_label, 来自 FUN_08100238 传入)
- 返回: r0 = 1 (来自 render_card_name_label)

## 副作用
- 与 render_card_name_label 相同 (font 状态字节 + VRAM tile 写入)

## 行级注释 (<=30 行精华)

- @ 0810096c: ldrb r1,[r1,#0x16] (读取字节偏移 0x16 的标志字段)
- @ 0810096e: lsls r1,r1,#0x1e (提取 bit1)
- @ 08100970: lsrs r1,r1,#0x1f (bit1 -> r1 = 0 or 1)
- @ 08100972: bl render_card_name_label(card_id, flags)
