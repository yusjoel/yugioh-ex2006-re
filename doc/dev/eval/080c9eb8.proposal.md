# Naming Proposal: 0x080c9eb8

## 提案
- **proposed_name**: write_decimal_digits_to_oam
- **confidence**: med

## plate comment (中文, ASCII 标点)
被卡片数值显示函数 (FUN_080c9f50 等) 多次调用 (indeg=3), 将十进制整数分解为个位数字并逐位写入 OAM 精灵条目. 参数 r0 = attr0 base (OAM y 坐标/属性), r2 = 要显示的整数值, r3 = max_digit_count (最大位数, 通常为 2), stack[0x2c] = tile_base 偏移. r5=r2 为剩余值; 循环用 __modsi3 取个位 (r0%10), 以 0xae + digit 作为 OAM tile 索引, 调用 write_oam_entry_from_packed_args 写精灵; 再 /10 推进; 直到 r5=0 或已写 max_digits 位. 若位数不足 max_digits, 继续以 0xae (空白 tile) 补写剩余位. 副作用: OAM 精灵数据区.

## 参数签名
- r0: u16 oam_attr0_base - OAM attr0 初始值 (y 坐标 + 形状 bits), [0..0x3FFF]
- r1: u16 x_pos - OAM attr1 x 坐标, [0..0x01FF]; callsite asm/all.s:315822 (FUN_080c9f50 @ 080ca008) `.hword 0x4649` = `mov r1,r9` 传入 r9=0x68 (104 px) 作为 x_pos
- r2: u32 value - 要分解显示的十进制整数值, [0..9999...]
- r3: u8 max_digits - 最大显示位数, [1..6]
- r9: u16 x_pos - OAM attr1 x 坐标 (sprite x 9-bit 字段), [0..0x01FF]; caller-set, not AAPCS; FUN_080c9f50 在 bl 前通过 `mov r1,r9` 将 r9 传入 r1; callsite asm/all.s:315769-315770 (FUN_080c9f50 @ 080c9f9c/9e) `movs r1,#0x68 @ 080c9f9c; .hword 0x4689 @ 080c9f9e` = `mov r9,r1` 设置 r9=0x68 (x_pos=104 px), 后续 asm/all.s:315822 `mov r1,r9` 在 bl FUN_080c9eb8 前将其转入 r1
- [sp+0x2c]: u8 attr2_priority_flags - 第 5 参数 (栈传入); caller 在 callsite 通过 `str r6,[sp,#0x0] @ 080ca1a6` 压栈; 函数内 `ldr r0,[sp,#0x2c] @ 080c9ecc` 加载后 `lsls r0,r0,#0xc` 移位写入 OAM attr2 priority 域, [0..3]
- 返回: void (无返回值)

## 副作用
- [OAM attr0/1/2 per digit]: write_oam_entry_from_packed_args 写入每个数字精灵 (tile index = 0xae + digit)
