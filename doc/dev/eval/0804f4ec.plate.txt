Function: Multi-condition equip slot eligibility check. r0=card_ptr, r1=player_side,
r2=slot_idx. Pre-filters: card_ptr[+2] bit0 (owner player bit)==player_side -> returns 0
(equip target must belong to opponent side); slot_idx > 4 -> returns 0.
After passing, reads (player_side, slot_idx) slot card_type_bits[12:0] from gDuelFieldSlots;
if 0 returns 0.
Calls check_zone_slot_equip_prerequisites(card_ptr, player_side, slot_idx);
then calls query_slot_card_type_eligibility(card_ptr, player_side, slot_idx);
if type_eligibility returns 0 (type match, note bne polarity) returns 1, else 0.
indeg=0, pure predicate, no side effects.

Constants:
- gDuelFieldSlots = 0x0201c510 (DAT_0804f544)
- PLAYER_STRIDE = 0x868 (DAT_0804f540)
- OWNER_BIT_MASK = bit0 of [card_ptr+2] (lsls/lsrs #0x1f)
- SLOT_IDX_MAX = 4 (cmp r4,#0x4)

Inputs: r0=card_ptr, r1=player_side [0..1], r2=slot_idx [0..4]
Returns: r0=bool (1=eligible, 0=not eligible)
