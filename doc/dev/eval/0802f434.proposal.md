# Naming Proposal: 0802f434

## 提案
- **proposed_name**: count_slot_equip_list_matches
- **confidence**: med

## plate comment (中文, ASCII 标点)
接收决斗场 slot 坐标 (r0=player_side, r1=slot_idx) 与两个参考参数 (r2/r9, r3/r8), 从 EWRAM slot 结构偏移 +0xa 读取装备链表头节点索引; 若为 0 则立即返回 0. 否则以 node_idx*8 + base (base=0x0201c510+0x14b0=0x0201D9C0) 遍历 8 字节节点链表: 读节点字段中的卡片 ID / 属性 / 关联方格标识, 通过多重条件 (包括 r8 比较) 统计满足条件的节点数. 被 FUN_0802f3e0 (FUN_0802f434 的直接上游, 负责选择 count 路径) 调用, 以及 0x080364b0/0x080352b0 (duel_field 决斗规则核心) 调用, 用于统计指定格上某类装备/附属卡的数量.

常量说明:
  0x0201c510 = gDuelFieldSlots base
  0x14b0 = 装备/附属节点池相对偏移 (gDuelFieldSlots+0x14b0=0x0201D9C0)
  slot+0xa = u16 链表头节点索引 (0 表示空链)
  node stride = 8 bytes (node_idx*8)
  0xfffa0000 / 0xffffeb50 = 节点内卡片 ID 字段的修正偏移 (signed)

## 参数签名
- r0: u32 player_side  (bit0 = 0/1 对应 P1/P2)
- r1: u32 slot_idx  (决斗场 slot 索引, [0..4])
- r2 (r9): u16 ref_card_id_a  (参考卡片 ID 或表偏移, 传入节点比较逻辑)
- r3 (r8): u16 ref_card_id_b  (参考卡片 ID, 用于节点 cmp r8,r3 过滤条件)
- 返回: r0 = u32  match_count  (满足条件的装备/附属节点数量, [0..N])

## 副作用
- (仅读 EWRAM, 无写操作)
