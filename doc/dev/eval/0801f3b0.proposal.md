# Naming Proposal: 0x0801f3b0

## 提案

- **confidence**: high

## plate comment (中文, ASCII 标点)
从 gPrng 结构体的固定偏移字节读取一个标志位并返回其反值. 以 gPrng + 0x1C0 (0xe0<<1=0x1c0) 为基址, 再加偏移 0x584 (DAT_0801f3cc) 定位目标字节, 读取该字节后通过 bics r0,r1 计算 NOT(r1) AND r0 -- 即 r0=0x1 & ~[目标字节], 相当于返回该字节 bit0 为 0 时返回 1, bit0 为 1 时返回 0. 结果为"标志清除状态"布尔值. 由 FUN_080954e8 (含 prng 标签) 调用, 作为 prng 初始化或状态检查的前置条件.

Constants: gPrng_offset=0x1c0 (0xe0<<1), entry_offset=0x584, flag_bit=0x1.

## 参数签名
- r0: (void) 无输入 -- 函数体前两条指令即用字面量覆盖 r0 和 r1
- 返回: r0 = u32 flag_is_clear (1 = bit0 为 0 即标志未置; 0 = bit0 已置)
