## plate comment (中文, ASCII 标点)
推进卡牌图标动画一帧. 读取 gPrng[+0x146] 的 bit9 判断动画是否激活, 以及 gGameState 中的
mode_flags 判断是否处于可运行状态. 从 gCardCtx[0x02023348+0x218] 读取动画状态字段,
按 bits[18:16] 的 anim_mode(0/1/2) 分派: mode 0: 读 gPrng 随机数控制 tile 滚动 + 更新
gCardCtx[+1/+2] 偏移; mode 1: 递增 gCardCtx[+2](y_offset), 满 8 后重置; mode 2: 递减
gCardCtx[+2](y_offset), 满 -8 后重置. 每模式内均调用 write_nibble_palette_rows_to_vram
写调色板行 (基地址 0x06016400/0x06016600). 最终调用 write_oam_card_icon_strip 两次更新 OAM.
返回 1=动画完成需后续处理, 0=仍在进行.
Constants: gPrng=0x03000040, gPrng_offset=0x146, gGameState=0x02023130,
gCardCtx=0x02023348+0x218.

- 返回: r0 = u32 (0=动画进行中, 1=激活完成/跳帧)
