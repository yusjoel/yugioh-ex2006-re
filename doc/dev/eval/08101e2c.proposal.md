## plate comment (中文, ASCII 标点)
由 FUN_080fefaa (display/blend/window/bg/card_frame/card_stats/font_jp/frame_counter 场景帧主循环) 唯一调用, 每帧负责绘制卡牌列表滚动条的 OAM 精灵组. 首先检查 [0x0202f3c0+0x7a] 当前列表长度是否 > 4, 若否则跳过整个渲染. 满足条件后: 读取 [0x0202a4d0+0x10] 作为滚动位置基准, 从 [0x0202f3c0+0x7a] 减 4 得到可滚动范围, 以 SCROLLBAR_BASE_Y=0x52*4/__divsi3 计算 thumb 块高度; 循环对 N 个 thumb tile 调用 dispatch_oam_write_by_mode (OAM 索引 0x9be0/0x9be1/0x9be3/0x9be4/0x9be9), 并对两端固定端帽精灵 (SCROLLBAR_TOP_CAP_PACKED=0x002f00ec, SCROLLBAR_BOT_CAP_PACKED=0x008900ec) 写固定 OAM 条目; 最终将 thumb 中心 x 坐标写入 [0x0202f3c0+0x1c].

  SCROLLBAR_TOP_CAP_PACKED  = 0x002f00ec // =(0x2f<<16)|0xec; top end-cap sprite packed position (x=0x2f=47, y=0xec=236)
  SCROLLBAR_BOT_CAP_PACKED  = 0x008900ec // =(0x89<<16)|0xec; bottom end-cap sprite packed position (x=0x89=137, y=0xec=236)
