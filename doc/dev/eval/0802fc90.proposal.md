## plate comment (中文, ASCII 标点)
从 gDuelFieldSlots (0x0201c510) 按 (r0 bit0=side, r1=slot_index) 定位 20 字节槽记录, 读取 [slot+0xa] (u16 chain_head_index), 然后调 find_node_by_value 在节点池 (0x0201d9c0) 中查找 [node+0]==r2 (value) 且 zone_type<=5 的节点. 找到返回 1, 未找到返回 0. 本函数是 check_node_in_slot_chain (0x0802fdc0) 的简化变体 -- 后者需额外传 zone_type 参数精确匹配, 本函数仅做值匹配. indeg=107, 是 duel field 核心布尔查询函数之一, 广泛用于效果激活条件判断 (例如检查某卡效果 ID/卡 ID 是否已在某槽的链中存在).

Constants:
- 0x0201c510 = gDuelFieldSlots (玩家区域槽基址)
- 0x868 = player stride (每玩家结构体占 0x868 字节)
- slot_entry = 20 bytes (每槽 20 字节)
- [slot+0xa] = u16 chain_head_index (链表起始索引)

## 参数签名
- r0: u32 packed_player_id -- bit0=side (0=P1, 1=P2), 其余位忽略
- r1: u32 slot_index -- 槽索引 [0..11] (0..4=怪兽区, 5=场地, 6..10=魔陷区, 11=全局效果链)
- r2: u16 value -- 目标值, 与链中节点 [node+0] 比较
- 返回: r0 = u32 bool -- 1 表示链中存在 value 节点, 0 表示不存在
