Find hand slot by series code and apply LP delta for slot function. Caller indeg=0, belongs to 0x0807xxxx equip/effect sprite driver cluster. Entry r0=effect_slot_entry*, r1=player_id (or related scalar). Reads [r4+4] activation flag hword as series_code param, calls find_hand_slot_idx_by_set_code(r1=player_id, r2=series_code_from_[r4+4]); if found (return value >=0), calls apply_lp_delta_for_slot_player(r4=slot_ptr, r5=player_id); if not found returns 0 directly. Side effects: writes LP delta record (via apply_lp_delta_for_slot_player).
