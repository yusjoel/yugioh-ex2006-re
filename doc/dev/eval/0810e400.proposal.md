# Naming Proposal: 0x0810e400

## 提案
- **proposed_name**: get_bios_div_remainder
- **confidence**: high

## plate comment (中文, ASCII 标点)
调用 BIOS SVC 0x6 (Div, r0/r1 输入), BIOS 将商写回 r0, 余数写入 r1. 随后 `adds r0,r1,#0` 将 r0 覆盖为 r1 (余数), 返回余数. 与 bios_div (0x0810e3fc, 直接返回商) 互为 sibling; 后者保留商, 本函数丢弃商返回余数. 被 scene_pack / card_image 区域 (~33 个 caller) 大量调用, 用于取模运算 (如 sprite 行/列坐标计算).

Constants:
- BIOS_DIV=SVC 0x6 (Div: r0=numerator, r1=denominator -> r0=quotient, r1=remainder)

## 参数签名
- r0: s32 numerator, 被除数
- r1: s32 denominator, 除数
- 返回: r0 = s32 remainder (BIOS Div 的 r1 输出, 即 numerator % denominator)

## 副作用
- 无外部地址写入

## 行级注释 (<= 30 行精华)
- @ 0810e400: svc 0x6 -- BIOS Div (quotient->r0, remainder->r1)
- @ 0810e402: adds r0,r1,#0 -- r0 := r1 (remainder overwrites quotient)
- @ 0810e404: bx lr -- return remainder
