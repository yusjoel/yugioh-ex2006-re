## plate comment (中文, ASCII 标点)
pack 场景卡片精灵 OAM 写入函数簇成员之一. 根据 dir 参数(r1 低16位)调度 x/y 偏移量(15 个方向分支, 每方向偏移 +-4/8/0x10/0x20 像素), 随后向 gPrng 精灵表对应 slot 写入 OAM attr0/1/2 六字节, 并递增两个计数字节. attr0 = 0x0700 (shape=square, mode=affine_double, mosaic=on). 调用 write_obj_affine_rot_scale 填写仿射矩阵. 与同族 write_pack_obj_attr_by_dir_tall_mosaic(0x080f6604), write_pack_obj_attr_by_dir_tall_diag(0x080f6ec8), write_pack_obj_attr_by_dir_sq_pairs(0x080f7108) 构成四兄弟簇, 仅 attr0 常量和仿射 callee 不同.

Constants:

- MAX_SPRITE_SENTINEL = 0x80 (slot ptr == 0x80 -> 跳过写入)
- SUB_TYPE_SKIP = 0x20 (sub_type == 0x20 -> 跳过写入)
- SLOT_OFFSET = 0xde*2 = 0x1bc (gPrng 精灵 slot ptr 偏移)
- STRIDE_OFFSET = 0x400+1 = 0x401 (计数字节偏移, DAT_080f644c=0x401)
- X_MASK = 0x1ff (attr1 x 坐标掩码, DAT_080f6448=0x1ff)

## 参数签名

- r2: u16 affine_scale (传给 write_obj_affine_rot_scale 的缩放参数)

- 返回: r0 = void (pop {r0}; bx r0 退出, r0 = 保存的 lr)
