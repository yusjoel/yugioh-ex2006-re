# Naming Proposal: 0x080bc794

## 提案
- **proposed_name**: init_field_slot_aob_ctx_a
- **confidence**: med

## plate comment (中文, ASCII 标点)
初始化 duel_field slot 的动画对象 (AOB) 上下文结构 (基址 DAT_080bc7d4), 对应 dispatch_card_display_op case 0x01 和 case 0x21. 先对结构调用 zero_fill_by_halfword(base, 0x6c) 清零 0xd8 字节, 然后写入 r0 到 [base+4], r1 到 [base+8]. 置 [base+c] := r8 (caller-set 高寄存器, 第三参数通过 .hword 0x4690=mov r8,r2 保存再从 .hword 0x4640=mov r0,r8 恢复). 置位 [base+0] bit0 (init done flag), 再从 gP1LifePoints 偏移处读 player bit, OR 0x4 后写入外部 ctrl 字节. Constants: base_struct=DAT_080bc7d4, zero_len=0x6c (halfwords = 0xd8 bytes), player_flag_bit=0x4.

## 参数签名
- r0: ptr arg_data 写入 [base+4], 通常为 sprite/data ptr
- r1: ptr arg_target 写入 [base+8], 通常为 render target ptr
- r2: ptr arg_extra 经 .hword 0x4690(mov r8,r2) 保存, 再从 .hword 0x4640(mov r0,r8) 恢复后写入 [base+c]
- 返回: r0 = void (bx r0 恢复 lr)

## 副作用
- [DAT_080bc7d4 .. +0xd7]: 全部清零 (zero_fill_by_halfword, 0x6c halfwords)
- [DAT_080bc7d4+4] := r0
- [DAT_080bc7d4+8] := r1
- [DAT_080bc7d4+c] := r2 (经 r8 转存)
- [DAT_080bc7d4+0] bit0 := 1 (init flag)
- [gP1LifePoints+offset] bit2 := 1 (player activation flag)
