# Naming Proposal: 0x080f1440

## 提案
- **proposed_name**: render_glyph_jp_4bpp_dual_layer
- **confidence**: high

## plate comment (中文)
由 `font_jp_080f21e8` 在检测到 `[0x02006ed0+0x15] & 0x10 == 1`（4bpp 模式标志）时调用，作为 `render_glyph_jp_dual_layer` 的 4bpp 替代路径。接受 u16 char_code，经 `char_code_to_glyph_index` 映射后查 `font_jp_charset_table` / `font_jp_stride_table` 定位字形位图，以 4bpp word 写（`str r0,[r4] + adds r4,#0x20` 双写）输出到 OBJ sprite tile 缓冲区（`*gfx_state`）。按 `glyph_width + (x & 7) > 16` 分溢出路径（跨 tile 列）和单列路径两支。

## 参数签名
- r0: u16 char_code — 日文字符编码，范围 [0, 0xFFFF]，传入 `char_code_to_glyph_index` 转为字形索引
- r1: i16 x_pixel — 渲染目标像素横坐标；`x_pixel >> 3` = tile 列索引，`x_pixel & 7` = tile 内 4bpp nibble 列偏移，用于 tile 边界溢出判断
- r2: i16 y_pixel — 渲染目标像素纵坐标；`y_pixel >> 3` = tile 行索引
- r3: u16 color_or_attr — 低 8 位（r4 & 0xFF = color_idx_u8）作为前景色乘数参与 4bpp nibble 生成；高位含义待 runtime 验证
- 返回: void（无返回值，仅副作用写 OBJ tile 缓冲区）

## 副作用
- `[*[0x02006ed0] + tile_row_offset]` := 4bpp 字形行 word（每行写两次，地址间距 +0x20，对应 sprite tile 内两个 4bpp 横向分区）；写入目标为 OBJ sprite tile 缓冲区（`*gfx_state` 指向地址）
- 无 IO 寄存器（`0x04000000+`）操作
