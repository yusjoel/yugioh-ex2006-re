check_equip_slot_eligible_by_effect_dispatch_result

Equip slot eligibility predicate. Minimal wrapper around effect dispatch.
Extracts player_id from slot byte[+2] bit0 and card_id from halfword[+0].
Calls dispatch_effect_handler_by_card_id(player_id, card_id, 0).
Returns 1 if result > 1, else 0.
No additional pre-conditions beyond the dispatch call itself.
Member of check_equip_slot_eligible cluster.

Constants:
  DISPATCH_MODE = 0 -- r2=0 passed to dispatch_effect_handler_by_card_id

Inputs:  r0=SlotPtr* slot_ptr (byte[+2] bit0=player_id [0..1], halfword[+0]=card_id)
Returns: r0=u32 (1 if dispatch_effect_handler_by_card_id result > 1, 0 otherwise)
Callees: dispatch_effect_handler_by_card_id
