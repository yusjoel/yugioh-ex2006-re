## plate comment (中文, ASCII 标点)
由 FUN_080a8c30 (equip 主控 hub, 按装备卡 id 段分派) 独占调用. 函数先检测装备 struct[0x12] bit1 (0x2 掩码); 若未置位则委托 dispatch_equip_state_by_combined_phase_index 处理通用相位推进, 返回其结果. 若置位, 继续计算 combined_index = (struct[0x14]&1)<<7 | struct[0x13]>>1, 范围 [0..5], 通过 6 条目跳转表 (PTR_PTR_080a8234 -> 080a8238) 分派至各阶段 handler; 索引越界 (>5) 进入 LAB_080a8394 并返回 0. 副作用: 由 jump table 目标函数决定, 本函数仅负责索引计算与分派.

## 参数签名
- 无 APCS 输入参数 (hub 直接 bl, 不传参)
- 返回: r0 = int32 相位状态码 (dispatch_equip_state_by_combined_phase_index 返回值, 或 jump table 各 case 返回值, 或 0 表示越界)

## 副作用
