# Naming Proposal: 0x08018838

## 提案
- **proposed_name**: delete_banlist_name_last_char
- **confidence**: med

## plate comment (中文, ASCII 标点)
Function: 对 banlist 名字输入缓冲区执行退格删除操作. 读取 gState[0x31e] (字符计数); 若为 0 则返回 0 (缓冲区空, 无法删除). 否则: 调用 advance_text_ptr_by_charlen(gState+0x2c2, count-1) 定位到最后一个字符位置, 调用 copy_str_unbounded 将该字符复制到 ROM 辅助缓冲区 (0x09e3b0b0), 将 gState[0x31e]--1 写回 (逻辑截断最后一个字符), 调用 refresh_selected_char_obj_tile 更新光标/字符显示, 返回 1 (成功). 由 FUN_08018884 和 FUN_08018938 (banlist/settings 键盘处理器) 在用户按退格时调用.
Trigger: banlist 密码或名字输入界面用户按下退格/取消键; 缓冲区非空时执行删除.
Side effects: gState[0x31e] := count-1; [0x09e3b0b0..]: copy_str_unbounded 写被删字符数据; refresh_selected_char_obj_tile 更新 OBJ tile.

Constants:
- BANLIST_BUF_OFFSET=0x2c2 (gState+0x2c2: 名字输入字节缓冲区基址)
- CHAR_COUNT_OFFSET=0x31e (gState+0x31e=0x2c2+0x5c: 当前字符计数字节)
- AUX_BUF=0x09e3b0b0 (ROM 辅助缓冲区地址, copy_str_unbounded 目标)

## 参数签名
- 返回: r0 = u8 result (1=删除成功, 0=缓冲区空无法删除)

## 副作用
- [gState+0x31e] := count-1 (字符计数减 1, 截断最后字符)
- [0x09e3b0b0..]: 被删字符数据 (via copy_str_unbounded)
- OBJ tile: refresh_selected_char_obj_tile 更新光标显示
