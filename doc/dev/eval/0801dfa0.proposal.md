## plate comment (中文, ASCII 标点)
被 FUN_0801e714 (display/card_data/card_desc/card_image/card_info/card_stats/font_jp/frame_counter) 唯一调用, 是卡片信息场景的逐帧滚动位置更新函数. 从 EWRAM 结构体 0x0201afb0 读取字段 [+0x14] (帧计数器), 若超过 0xe8=232 则将帧计数器继续递增并以帧数计算滚动偏移量, 写入 [+0x18] (像素 Y 偏移) 和 [+0x1c] (子计数器); 若帧计数器未超阈值则清零并停止滚动. 最终写 VRAM 0x03000240 (gFrameCounter 偏移处) 的对应字段以同步 HW 位置.

## 参数签名
- (无参数; 直接读取 EWRAM 全局结构体 0x0201afb0)
- 返回: r0 = u16 scroll_pos  (当前计算出的滚动像素位置, 0 表示停止)

## 副作用
- [0x0201afb0 + 0x1c]: +1 递增子帧计数器, 并在到达上限时归零
- [0x0201afb0 + 0x18]: := scroll_y_pixel (写入计算的 Y 偏移)
- [gPrng + 0x3e2] (via strh at 0x0801dff2): := scroll_y_pixel (同步到 IWRAM; 0x3e2 = RNG_STATE_FIELD_X, card_info 场景用此偏移存当前滚动像素位置)
