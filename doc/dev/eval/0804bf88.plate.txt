Called by duel_field equip zone activation checker (indeg=1, 0x0805d6cc). Determines whether card_id belongs to equip card set D. BST whitelist covers range [0x10dc..0x12ec], discrete IDs 0x12ce, 0x1307, 0x132b, 0x1804, and others. Returns 1 if member, 0 otherwise. One of four sibling equip card ID whitelist functions (set A/B/C/D) covering different ID ranges. Pure leaf, no side effects.

Inputs: r0=u16 card_id [0..0x1fff].
Outputs: r0=u32 bool (1=in set D, 0=not).
Side effects: none.
Constants: SET_D_ANCHOR_ROOT=0x12ec, SET_D_ANCHOR_B=0x12ce, SET_D_ID_A=0x1325, SET_D_ID_B=0x1307, SET_D_ID_C=0x132b, SET_D_ID_D=0x1804.
