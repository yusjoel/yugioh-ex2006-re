Function: Scans effect slot array for entries with card_extended_stat_field6==0x17,
emits OAM zone slot sprite attr records for each matching slot
(enqueue_zone_slot_sprite_attr_if_occupied x2 + enqueue_sprite_attr_for_slot_indicator
+ enqueue_sprite_attr_type10_halfword).
Entry: r0/r1 as two effect slot ptrs (saved to r8/r10), r2=zone_bitmap_ptr.
Guard: if [r1+0x4] bit2 != 0 returns void immediately; if r2==0 skips.
Scans three card_id ranges (0x0ffa..0x131c/0x16b8 etc.) to select handler path;
on match calls check_effect_slot_matches_zone_entry + get_card_extended_stat_field6
before emitting sprite queue entries.
Side effects: Writes multiple records via enqueue_zone_slot_sprite_attr_if_occupied /
enqueue_sprite_attr_for_slot_indicator to OAM sprite queue;
sets zone bitmap bit4 flag via strb [r2+0x4] |= 0x10.
