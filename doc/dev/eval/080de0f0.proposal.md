## plate comment (中文, ASCII 标点)
根据坐标参数 (r0=tile_x, r1=size_mode) 计算卡包槽 OAM tile 索引和属性字. size_mode=3 时高位附加 0x30000 (优先级/调色板标记); size_mode=2 时返回固定基准 tile 0x20000; 否则若 tile_x==5 则特殊路径, 其余按 r1*5+r0+1 生成 tile 索引. 用于包含多种卡包显示尺寸的场景 OAM 配置. caller 通常从 pack_ui_state 动画子结构的 [+0] 和 [+2] 两个有符号短整数读取 x/y 坐标后传入.

Constants:
- OAM_PRIO3_MASK = 0x30000 (size_mode=3 高位标记)
- OAM_PRIO2_MASK = 0x20000 (size_mode=2 高位标记)
- OAM_ALT_TILE_BASE = 0x10000 (tile_x==5 特殊路径标记)
- TILE_X_SPECIAL = 5 (触发特殊路径的 tile_x 值)

## 参数签名

- r1: s16 size_mode -- OAM 尺寸/优先级模式 [0..3]
- 返回: r0 = u32 packed_tile_attr -- 打包 tile 索引+高位属性字
