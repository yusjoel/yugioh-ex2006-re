Function: After dual-target zone slot match passes, validates zone entry match, evaluates equip slot score,
and emits XY-split sprite attributes.
Entry: r0=effect_slot_ptr. Extracts player_id/slot_type from [r0+0x2], locates dual-side
zone slot array (base=0x0201c510, stride=0x868) and compares card_type aggregate with target;
returns void if mismatch.
On match: checks [zone_slot+0x8] LP presence; on pass calls
check_effect_slot_matches_zone_entry(slot_ptr, 0, &stack_result) -- returns void if no match.
Extracts side (byte0) and type (byte1) from stack_result, locates zone slot entry,
checks entry[0] bit13 (card type flag) and [entry+0x8] count; on pass calls
eval_slot_score_entry_full(r0=side, r1=type, r2=zone_ptr).
Takes min of sp[0x1c]/sp[0x20] scores with cap 0xffff, shifts left 0x10 then orrs as dual-halfword,
calls enqueue_sprite_attr_with_xy_split(player_id, packed_xy).
Side effects: Writes XY-split attr to OAM sprite queue via enqueue_sprite_attr_with_xy_split.
Constants:
  BASE_STRIDE=0x868
  BASE_ADDR=0x0201c510
  SCORE_CAP=0xffff  // score ceiling
  ENTRY_FLAG_BIT13=0x2000  // zone entry card type flag (lsls #0x13 check)
