## plate comment (中文, ASCII 标点)
检查决斗场地指定槽位的卡片属性是否满足"可见"条件, 供多处 display pipeline 调用 (indeg=14).
r0 = slot_index [0..N-1]. 函数计算槽位在 gDuelCtx (0x02020160) struct 中的偏移:
offset = slot_index*5*8 = (r0*5)<<3; 读取 [gDuelCtx + 0x24 + offset] byte (card_type 字节).
同时读取 [0x0201e4f0+0x4] (phase_counter) 和 [0x0201e2a0+0x4] (active_zone_card).
若 phase_counter == 4: 比较 card_type 与 active_zone_card; 若相等则跳过 get_zone_card_attribute_by_type (视为不可见, 返回 0).
否则: 调用 get_zone_card_attribute_by_type(card_type, attr_type=0xf) 检查属性 bit0xf.
返回 1=属性满足(可见) / 0=不满足.
Constants: DUEL_CTX=0x02020160; CARD_TYPE_OFFSET=0x24; STRUCT_STRIDE=0x28 (=5*8);
PHASE_BASE=0x0201e4f0; ACTIVE_ZONE_BASE=0x0201e2a0; ATTR_TYPE=0xf.
