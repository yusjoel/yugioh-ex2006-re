## plate comment (中文, ASCII 标点)
链节点计数函数, 在给定链头(r0=chain_head 节点索引)中统计同时满足 card_id==r1 且 type_lo4==r2 条件的节点数. r4 为命中计数器, 初始为 0. 对每个节点: lsls r0,r0,#0x3 计算节点地址 (0x0201d9c0+index*8), ldrb [+2] 取 type 字节, lsls/lsrs #0x1c 提取低 4 位(type_lo4), 若 type_lo4 > 5 则跳过; ldrh [+0] 取 card_id 与 r6(target_card_id) 比对, 不匹配则跳过; lsrs r0,r1,#0x1c 再次取 type_lo4 与 r5(target_type) 比对, 三重条件全通过则 r4++. ldrh [+6] 取 next 指针, next==0 退出循环. 与 count_chain_nodes_by_card_id 相比增加了 type_lo4==target_type 的第三道过滤.
Constants: NODE_BASE=0x0201d9c0, NODE_STRIDE=8, TYPE_OFFSET=2, CARDID_OFFSET=0, NEXT_OFFSET=6, TYPE_MAX=5.

## 参数签名

- r2: u8 target_type [0..5] (目标节点 type 低 4 位; >5 的节点被自动跳过)
- 返回: r0 = u32 match_count (满足 card_id && type_lo4 双条件的节点数; 0=无命中)
