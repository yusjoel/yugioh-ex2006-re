Effect node handler. Checks guard bit. Calls check_effect_slot_matches_zone_entry for slot_index=0 and 1 in turn; exits if either returns 0. After both match, reads side+type fields, looks up [slot+8] occupancy flag from gDuelFieldSlots for both slots; exits if either is zero. When both slots occupied: computes get_slot_field5_score/2+1 as display parameter, calls enqueue_slot_card_sprite_if_eligible once per slot. Uses __divsi3 for integer division. Dual-slot variant of submit_effect_zone_sprites_if_unguarded.

Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, SLOT_DIV=0xa (__divsi3 divisor).

Inputs: r0=ptr effect_node ([+0]=card_id u16, [+2]=flags u8 with player bit0, [+4]=guard_bits u8 bit2=guard).
Returns: r0=0 (void semantic, fixed return 0).
Side effects: writes sprite queue (via enqueue_slot_card_sprite_if_eligible x2).
