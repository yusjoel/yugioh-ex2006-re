# Naming Proposal: 0x080f7528

## 提案
- **proposed_name**: write_tile_rows_to_vram_by_mode
- **confidence**: high

## plate comment (中文, ASCII 标点)
按模式 (src=0 清零/src!=0 拷贝) 将 tile 行数据写入 2D OBJ VRAM, 是 tile_2d_row_copy 的条件清零变体. 由 FUN_080c5b78/FUN_080dc4ec (scene_pack) 在 pack-banner 场景调用. 入参 r0=dest (VRAM 目标基址), r1=src (源 tile 数据指针, 为 0 时执行清零), r2=halfword_stride (每行拷贝 halfword 数, 即 r2>>0xb), r3=row_count, [sp+0x18]=extra_tile_offset. 若 r1(src)=0 则对每行调用 zero_fill_by_halfword; 否则对每行调用 copy_bytes_by_halfword. 每行 dest += 0x400 (OBJ VRAM 2D 行步长 0x80*8).

Constants:
- 0x400 = OBJ VRAM 2D 行步长 (0x80 * 8, movs r0,#0x80; lsls r0,r0,#3)
- r2>>0xb = halfword stride (lsrs r7,r2,#0xb)
- [sp+0x18] = extra tile offset (lsls r0,r0,#5 * [sp+0x18])

## 参数签名
- r0: ptr vram_dest* -- OBJ tile VRAM 目标基地址
- r1: ptr tile_src* -- 源 tile 数据指针 (为 0 时清零 [0..max_tile_data])
- r2: u16 packed_stride -- 高 11 位为 halfword stride (r2>>0xb)
- r3: u16 row_count -- 要处理的行数 [0..max_rows]
- [sp+0x18]: u16 tile_col_offset -- 列偏移 (<<5 为 x 像素偏移)
- 返回: void (无返回值)

## 副作用
- [dest + i*0x400]: 若 src!=0 则 copy_bytes_by_halfword; 若 src=0 则 zero_fill_by_halfword (i in [0..row_count-1])
