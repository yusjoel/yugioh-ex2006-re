## plate comment (中文, ASCII 标点)
在玩家完整卡组(主卡组+副卡组+额外卡组)中统计 card_id r0 出现的次数. 从 EWRAM 0x02001150 读取主卡组数量, 遍历主卡组数据(+0x1154, stride=2), 与 card_stats_table[card_id*0x16+0] 比较. 再读副卡组数量(+0x1151)和数据(+0x11f4), 额外卡组数量(+0x1152)和数据(+0x1212). 三段遍历累加到 r4, 返回总计数. 被 card_stats(0x080ef02c, [banlist;card_stats]) 调用.

Constants:
- DECK_BASE = 0x02000000
- MAIN_COUNT_OFFSET = 0x1150 (主卡组数量)
- MAIN_DATA_OFFSET = 0x1154 (主卡组数据, stride=2)
- SIDE_COUNT_OFFSET = 0x1151 (副卡组数量)
- SIDE_DATA_OFFSET = 0x11f4 (副卡组数据)
- EXTRA_COUNT_OFFSET = 0x1152 (额外卡组数量)
- EXTRA_DATA_OFFSET = 0x1212 (额外卡组数据)
- CARD_STATS_STRIDE = 0x16 (card_stats_table 每张卡步进)

## 参数签名
- r0: u16 card_id (目标卡牌 ID)
- 返回: r0 = u8 count (三区合计出现次数[0..255])
