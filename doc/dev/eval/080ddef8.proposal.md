## plate comment (中文, ASCII 标点)
牌包兑换/密码页面状态机步骤 3: 处理输入并更新选择光标 OAM.
读取 gPrng+0x148 (按键状态字段) bit7=0x80 -> A 确认键, bit6=0x40 -> B 取消键;
A 键: 置 [pack_ui_state+0xc+0x2] = 1 (选择确认);
B 键: 清 [pack_ui_state+0xc+0x2] = 0 (取消);
按 [+0x2] 的值 (0/1) 选择光标尺寸 (0x10/0x20 pixels), 调 write_oam_entry_from_packed_args 写光标 OAM;
再次读 gPrng+0x148: bit0=1 -> 步骤完成 (return 1, 前进); bit1=2 -> 写选择标志 [+0x4] bit0 后 return 1; 否则 return 0.
属于 0x09e495d8 dispatch table 的第 3 项.

Constants:
- gPrng+0x148 (0xa4*2=0x148): 输入按键状态字段 (IWRAM)
- pack_ui_state+0xc: exchange/password 子结构基址
- [+0x2]: 选择状态 (0=未选, 1=已选)
- 0x80: A 键 pressed mask
- 0x40: B 键 pressed mask
- 0x10 / 0x20: 光标 OAM height pixel 值
- 0x8: OAM attr1 tile ID 字段
- 0x1: gPrng+0x148 bit0 = A 按下确认
- 0x2: gPrng+0x148 bit1 = B 按下取消
