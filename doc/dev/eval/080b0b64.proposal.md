## plate comment (中文, ASCII 标点)
将 gDuelFieldSlots 中两个玩家侧的前 5 个格子条目 (各 0x64 字节) 复制到由 r0 指定的目标缓冲区. 第一次调用 copy_bytes_by_halfword(dst=r4, src=gDuelFieldSlots, len=0x64) 拷贝 P1 侧 slot 0..4; 然后 dst+=0x64, src+=0x868 (P2 偏移); 第二次 copy 拷贝 P2 侧 slot 0..4. 与 FUN_080b0b90 (restore_field_slots_from_buffer, 方向相反) 构成保存/恢复对. 上层 FUN_080b135c 在选优格子前先通过本函数快照当前场地状态, 评估完毕后不需还原. indeg=3. Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, copy_size=0x64 (5 slots*0x14).
