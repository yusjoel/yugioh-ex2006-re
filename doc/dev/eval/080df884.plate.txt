Brightness-blend render for the pack slot cover sprite. Reads current x/y from pack_ui_state+0xc+0x44 OAM substructure to compute tile attributes. If [+0x44+0xc] (animation state) is 0: loads color data from ROM cover data table (0x09cebf30) into palette 0x05000220, increments frame counter [+0x44+0xe] (resets after 0x27=39 frames), computes a brightness coefficient based on frame count (linear for <=0x13, reflected from 0x28 above 0x13), and performs per-channel RGB linear interpolation blend on 6 pixels written back to the palette. If [+0xc] != 0: computes smooth x/y via bios_div interpolation using target/current position delta and frame count. Finally calls render_overlay_oam_sprite_tiled to write the OAM entry. Called by 6 pack scene step handler functions.
