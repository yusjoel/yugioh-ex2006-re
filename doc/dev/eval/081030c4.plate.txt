indeg=0 dead-code or indirect call entry. Sequentially: (1) calls reset_all_deck_slots() to zero all slot state; (2) loops slot_idx=0..3 calling init_deck_slot_data(slot_idx) to initialize each slot's detail data. Differs from reinit_deck_slots_and_data (0x081030e0) in that this function skips the populate_deck_slots_from_card_list step (does not refill the card list), only zeroing + struct init. Returns r0=1.

Constants:
- 4 = total deck slot count (loop count 0..3)
- IWRAM 0x0202a4d0 = card_list scene main state (deck slot data base, accessed via init_deck_slot_data)
