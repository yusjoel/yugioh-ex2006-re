## plate comment (中文, ASCII 标点)
给定 card_id (r0), 将卡片名称/ATK/DEF 数值/卡图 tile 全部渲染并提交到精灵 VRAM. 流程: 初始化行缓冲区和字体 ctx; 加载日文卡名并渲染; 若 CHARSET_FLAG 非零则追加英文名第二行; 渲染 ATK/DEF 数值; commit_line_buffer_to_sprite_vram 提交精灵 tile; 拷贝 medium/mini 卡框 tile 到 OBJ VRAM. 由 pack scene state machine (0x080fa07c) 和 pack anim state machine (0x080fa138) 在卡片预览面板初始化/刷新时调用.

- 返回: void (epilogue pop {r0}; bx r0, r0=lr 不透传有效返回值)
