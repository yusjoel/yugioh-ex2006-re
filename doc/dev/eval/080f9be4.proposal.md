## plate comment (中文, ASCII 标点)
将 r0 低 3 位写入 EWRAM [0x02000000+0x6c2c] 的低 3 位, 更新谜题工作区的字符集/编码标志字节. bit[1:0]=charset_id (0=OCG, 其他值=非 OCG 编码), bit2=辅助标志. 先以 0x8 (NOT 后掩 bit3) 清空低 3 位, 再 OR 写入. 由场景初始化函数如 FUN_080f46dc (0x080f46dc, tags: [dma;sys;display]), FUN_080f4d90 (0x080f4d90, tags: [frame_counter;prng;settings]) 在谜题/设置加载时传 r0=0 或 r0=1 调用, 以及 FUN_080fb134 (0x080fb134, tags: [vram;display;bg;card_stats;font_jp;frame_counter;settings]) 在渲染前刷新字符集. 副作用: [0x02000000+0x6c2c] 低 3 位 := r0&7.

## 参数签名
- r0: u16 charset_id - 字符集标识低 3 位 [0..7] (0=OCG, 1=TCG/US, 其他备用)
- 返回: void (bx lr 直接返回, 无 r0 输出)

## 副作用
- [0x02000000+0x6c2c] bits[2:0] := r0 & 0x7 (谜题 EWRAM 字符集标志)
