## plate comment (中文, ASCII 标点)
音效引擎 DMA 通道访问权查询函数. r0=entity_id 为请求访问的实体 ID. 读取 IWRAM 音效引擎结构体 (0x030050cc) [+0x364] 状态半字的 bit7 判断 DMA 是否正在运行: bit7=1 (DMA 活跃) 时, 若 entity_id<0 直接返回 1 (任意实体允许), 否则读 [+0x36a] 当前占用实体 ID 并比较, 相同返回 1 (同实体可继续), 不同返回 0 (被其他实体占用); bit7=0 (DMA 空闲) 时, 读 [+0x366] 挂起实体 ID, 若为负返回 0, 若 entity_id<0 或与挂起 ID 相同返回 2 (挂起匹配), 否则返回 0.

调用场景: 音效引擎分配/请求路径在申请 DMA 通道前先调用本函数确认访问权, 返回值 0=不可用/冲突, 1=立即可用, 2=挂起匹配.

Constants:
ENGINE_BASE=0x030050cc (IWRAM 音效引擎结构体基址)
STATUS_OFF=0x364 (0xd9*4, DMA 通道状态半字)
ACTIVE_BIT=0x80 (bit7 = DMA 运行中标志)
ENTITY_PENDING_OFF=0x366 (挂起实体 ID 半字字段)
ENTITY_ACTIVE_OFF=0x36a (当前活跃实体 ID 半字字段)

## 参数签名
- r0: s16 entity_id [-1..+32767] (-1=任意实体; >=0 为具体实体 ID)
- 返回: r0 = u8 access_code {0=不可用/冲突, 1=立即可用(DMA 活跃路径), 2=挂起匹配(DMA 空闲路径)}
