判断某张装备卡是否可以装备到指定场地槽. indeg=37, C_util_high.
入口: r0=card_ptr (r5), r1=slot_ptr (r7), r2=target_slot_idx (r4), r3=player_id (r9, .hword 0x4699=mov r9,r3).
Phase 1: 从 card_ptr[+0x2] 提取 field5 (lsls #0x1a / lsrs #0x1b, bits [6:2]), 减 5 后截断为 u16, 若 > 5 则跳 Phase 2.
Phase 2 (field5 [0..5] 范围): 从 field5 (lsrs... = 0 时置 r8=1) 经 .hword 0x4680=mov r8,r0 保存结果.
然后: 从 slot_ptr[+0x8] (halfword) 读取 zone 槽状态; 若为 0 则跳 LAB_08036978 (特殊判断).
读 slot[+0] (word), lsls #0x13 后 lsrs #0x13 (去 active bit) 得 card_type, 对比 DAT_080368dc (=0x150c) / DAT_080368e0 (=0x1645):

LAB_08036938: 若 r8!=0 且 slot_idx<=4 且 slot[0x8]!=0: bl query_zone_chain_count_with_eligibility -> 若>0: bl map_card_id_to_anim_type, bl check_slot_card_is_equip_whitelist, 综合判断后返回 0 (可装备) 或 1 (不可).
LAB_08036990: 返回 1 (不可装备).
LAB_0803690e: 返回 0 (可装备).
