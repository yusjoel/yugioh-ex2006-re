Reads LP state machine 0x0201b290[0x94*8=0x4a0] and routes through three states:
State 0x80: calls increment_lp_bar_display_counter. Returns 0x7f.
State 0x7f: iterates slot=[0..4] over 5 equip slots. For each slot calls invoke_effect_node_with_active_flag_3arg(effect_node, player, slot); skips if returns 0. Reads EQUIP_SLOT_BASE[player*0x868+slot*0x14+0x8] halfword; if == 0 calls dispatch_slot_sprite_attr_with_equip_head_flag(player, effect_node, slot, 1). Reads [+0x6] halfword; if == 0 calls apply_slot_equip_activation_with_eligibility_check(effect_node, player, slot, 0, 1). r9 advances +0x14 per slot. Returns 0x7e.
State 0x7e: calls decrement_lp_bar_display_counter. Returns 0.
Other states: returns 0.

Constants:
- STATE_BASE=0x0201b290
- STATE_OFFSET=0x94*8=0x4a0
- EQUIP_SLOT_BASE=0x0201c510 (DWORD_08079644)
- PLAYER_STRIDE=0x868 (DWORD_08079640)
- SLOT_STRIDE=0x14 (add r9,r2 with r2=0x14 per iteration)
- SLOT_MAX=4 (cmp r6,#0x4)
