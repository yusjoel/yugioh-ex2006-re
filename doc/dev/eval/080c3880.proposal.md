## plate comment (中文, ASCII 标点)
更新场地指定槽位的 tile 显示状态. 输入 player_id/slot_idx/extra 三个 u16, 先调用 get_field_slot_tile_vram_addr 获取 VRAM 地址(保存到 r7). 当 slot_idx [0..0xa] 且 check_slot_placement_blocked_by_field_effect 返回 0 (无阻挡) 时, 调用 blit_field_slot_tile_with_palette_hi 写入高亮调色板数据. 当 slot_idx > 0xa 或被阻挡时: 若 VRAM 地址有效则调用 zero_fill_by_halfword 清零该 tile 区域 (0x90 halfword = 0x120 字节). 副作用: 根据阻挡条件有选择地写 VRAM tile 或清零 tile. Constants: slot_range_max=0xa, tile_size=0x120.

## 副作用
