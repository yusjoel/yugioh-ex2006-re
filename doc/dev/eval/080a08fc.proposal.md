## plate comment (中文, ASCII 标点)
被 FUN_080a0a8c (equip slot 状态路由器) 在 bit5 (0x20) 检查分支中调用. 从 EWRAM 0x0201b870+0x310 读取 equip slot 计数 (r2), 计算末尾 slot 指针 (r5=count>0 ? base+count*0x18-0x18 : 0). 再读 offset 0x30e 的状态字节, 按值 0/1/2 分派: 0 -> 写零到两个 EWRAM 字段并递增计数; 1 -> invoke_effect_node_action_if_found; 2 -> submit_sprite_row_data. 返回 1 表示当前 tick 处理完毕.

Constants: equip_slot_base=0x0201b870, slot_count_offset=0x310 (0xc4*4), slot_stride=0x18, status_byte_offset=0x30e (DAT_080a0944=0x30e).
