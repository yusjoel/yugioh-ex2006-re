# Naming Proposal: 0x080bad10

## 提案
- **proposed_name**: check_lp_below_zone_count_threshold
- **confidence**: high

## plate comment (中文, ASCII 标点)
检查玩家 LP 是否低于"场上占用格数*300"阈值. 计算双方全场格 (count_occupied_all_field_zones(0)+count_occupied_all_field_zones(1)) 与 gP1LifePoints[+0xc] 及 [+0x874] 两个字段之和, 得到 total_count; 计算阈值 total_count*300. 从 zone_ptr->byte[2] 提取 player_id (bit0), 取反得 opponent_id, 以 opponent_id*0x868 偏移查 gP1LifePoints 得对方 LP; 若 LP <= total_count*300 则返回 1, 否则返回 0. 通过 pop{r1}+bx r1 退出 (Sub-case E).

Constants:
- gP1LifePoints = 0x0201c4e0 (DWORD_080bad60)
- FIELD_COUNT_OFFSET_A = 0xc (gP1LifePoints+0xc, 额外计数字段 A)
- FIELD_COUNT_OFFSET_B = 0x874 (gP1LifePoints+0x874, DWORD_080bad64)
- PLAYER_STRIDE = 0x868 (DWORD_080bad68)
- LP_FACTOR = 300 (= 4*5*16-4*5 = lsls*2 + adds + lsls*4 - subs 乘法链)

## 参数签名
- r0: ptr zone_ptr (field zone 指针, byte[2] bit0 = player_id)
- 返回: r0 = u32 flag (1=LP <= zone_count*300, 0=LP 充足)
