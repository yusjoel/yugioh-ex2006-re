Per-frame driver for the pack reveal card name overlay fade-out animation. Checks pack_ui_state+0x140 bit4; if not set, checks gPrng+0x148 bit0 (A button) and sets bit4 if pressed to trigger display. Calls tick_overlay_animation_step with r2=0 (no trigger) or r2=1 (A pressed) to advance animation. If the animation step completes (return 1): resets pack_ui_state+0xc+0x38/+0x3a/+0x3c substructure, writes pack_ui_state+0x10c/0x10e:=0x1e (animation frame counts), writes pack_ui_state+0xc+0x24:=0 (card display position field reset), writes pack_ui_state+0x4:=0xe (next state). Calls tick_pack_oam_slots_and_overlay(2) each frame to refresh OAM. Returns r6 (0=in progress, 1=complete). indeg=0.
