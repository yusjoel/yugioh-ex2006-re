# Naming Proposal: 0x081014fc

## 提案
- **proposed_name**: setup_card_list_tile_rows
- **confidence**: med

## plate comment (中文, ASCII 标点)
card_list 场景 VRAM tile 初始化函数. 从 IWRAM 0x0202a4d0 (r7) 读取当前选中卡片字段, 调用 read_card_list_field_by_index / resolve_card_gfx_row_by_type / resolve_card_frame_palette_by_type 构成三级查表链, 再以 tile_2d_row_copy 将卡框 palette 数据拷贝到 VRAM 0x06010880 (r6). 外层循环 r4=0..5 执行 6 次, 每次偏移 VRAM 目标地址 r4*128 字节, 覆盖 6 行 tile 数据. 由 card_list_screen_init 和 FUN_080fffc4 调用, 是卡片列表界面卡框 tile 批量写入的核心.

## 参数签名
- 无参数 (通过 IWRAM 0x0202a4d0 和固定 VRAM 地址工作)
- 返回: r0 = 1 (始终成功)

## 副作用
- [VRAM 0x06010880 + r4*0x80]: tile_2d_row_copy 写入卡框 palette 行数据 (每轮 4 列 x 2 行, 共 6 轮)
- [VRAM 0x06010900 + r4*0x80]: 另一目标地址, 同样通过 tile_2d_row_copy 写入

## 行级注释 (<=30 行精华)
- @ 081014fe: r7 = 0x0202a4d0 (card_list IWRAM 状态)
- @ 08101500: r6 = 0x06010880 (VRAM tile 目标基址 A)
- @ 08101504: ldrsh r0,[r7,#4] -> 当前卡片字段作为 index
- @ 08101506: bl read_card_list_field_by_index -> 卡片类型键
- @ 0810150e: bl resolve_card_gfx_row_by_type -> 图形行号 r1
- @ 08101516: bl resolve_card_frame_palette_by_type -> palette 指针 r1
- @ 08101522: bl tile_2d_row_copy(r6, r1, col=4, rows=2) -> 写 VRAM
- @ 08101526: r4=0 外层循环初始化
- @ 08101528: VRAM 偏移 = r4<<7 (每行 128 字节)
- @ 0810153c: r4 += 4 (步进, 每迭代跨 4 列)
- @ 0810155c: r4 > 5 则退出
