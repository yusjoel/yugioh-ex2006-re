## plate comment (中文, ASCII 标点)
将当前 pack 已选卡张数百分比格式化后渲染到 OBJ VRAM sprite 行缓冲区. 入参 r0=VRAM 目标地址, r1=pack_index [0..4], r2=selected_count (已选卡数). 通过 game_str_id=0x13ee 查 game_str_pointer_table 得到格式字符串; 调 get_pack_total_card_count(r1) 得到 total_count, 计算 selected_count/total_count*100 得百分比 r2 [0..100], 夹在 [1..99] 或取 100 (全选). 调 expand_format_decimal_width_to_buf 将百分比写入栈缓冲; 随后调 setup_line_buf_pos_and_font + text_render_wrapper 两次渲染双色文字; 最后调 commit_line_buffer_to_sprite_vram 写入 r8 所指 VRAM. 由 FUN_080d4e48 和 FUN_080d8e98 调用.

Constants:
- GAME_STR_ID=0x13ee // pack card count format string ID
- PCT_MAX=0x64=100 // 百分比上限
- PCT_MIN=1 // 百分比下限 (至少 1%)
- PCT_FULL=0x64=100 // 全选或 total==0 时显示
- IWRAM_LANG_FLAG=[0x02000000+0x6c2c] // language selection byte
- FONT_IDX=2

## 参数签名

- r2: u16 selected_count [0..total_count] - 已选卡张数 (上界由 get_pack_total_card_count 返回值决定)
