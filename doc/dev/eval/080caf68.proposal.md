## plate comment (中文, ASCII 标点)
渲染卡牌名称字符串到 OBJ sprite VRAM. 由 FUN_080cb1cc 调用一次. 入口通过隐式非 APCS 寄存器
r8(player_id)/r9(caller context flag) 接收参数. 函数先用 select_charset_then_load_name 加载
卡牌名称字符串指针(r5), 再调用 setup_line_buf_with_font_and_align 初始化 JP 字体行缓冲区,
zero_fill_by_halfword 清零 OBJ VRAM 0x0600a8e0, 用 measure_string_pixel_width 检查宽度是否
超过 0xef 像素; 若超出跳过渲染, 否则两次调用 text_render_wrapper(main color 和 shadow color),
最后 commit_line_buffer_to_sprite_vram(0x0600a8e0) 写入 VRAM.
Constants: VRAM_name=0x0600a8e0, max_width=0xef, font_flag_addr=0x0201e2a0.

## 参数签名
- r0: (via r8, non-APCS) u32 player_id - bit0=side [0..1]
- r1: (via r9, non-APCS) u32 caller_context_flag - eors 用于 color_attr 选择 [0..1]
- 返回: r0 = void (副作用写 VRAM)

## 副作用
- [VRAM 0x0600a8e0..+0x800]: zero_fill_by_halfword 清零后 commit_line_buffer_to_sprite_vram 写入 JP 字体名称 tile
