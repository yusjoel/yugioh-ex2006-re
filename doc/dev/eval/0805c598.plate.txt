Equip slot eligibility five-check predicate. Extracts player_id (bit0) and slot_idx (bits[5:1]) from card_entry[+2]. Five checks:
(1) gP1LP[+0x1ce8] == player_id: mismatch returns 0 (activation context player match).
(2) gP1LP[+0x1cf4] == 1 (activation phase ==1): mismatch returns 0.
(3) gP1LP[effective_player*0x868 + slot_idx*0x14 + 0x38] nonzero: if 0 returns 0.
(4) check_slot_card_can_be_equipped(player_id, player_id, slot_idx): 0 returns 0.
(5) count_effect_node_zone_activations(card_entry) > 1: returns 2 if satisfied, else returns 0.
Only returns 2 when all checks pass.

Constants:
- PLAYER_CTX_OFF=0x1ce8
- STAGE_OFF=0x1cf4
- STAGE_REQUIRED=1
- PLAYER_STRIDE=0x868
- SLOT_SIZE=0x14
- FIELD_OFF=0x38
- ZONE_COUNT_THRESHOLD=1 (count > 1 returns 2)
