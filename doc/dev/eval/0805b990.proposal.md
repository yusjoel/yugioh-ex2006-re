## plate comment (中文, ASCII 标点)
首先调用 populate_effect_node_snapshot(FUN_0805b5f0)将当前效果区节点状态填入栈上快照结构(sp+0x0, 0x48字节区域). 随后以 player=0..1 x slot=0..9 双重循环遍历场地槽位, 对每个 card_id 非零的槽位进行一系列适用性检查: check_card_is_zone_pair_restricted / check_card_field8_is_normal / 对特定卡 ID(DAT_0805ba54)的特殊规则 / monster zone(slot<=4) vs magic/trap zone(slot>4) 分派不同子路径. 符合条件时调用 FUN_08044e30(update_duel_field_slot_sprite_state)更新对应槽精灵状态. 被 FUN_08047724(update_equip_target_bitmap_for_field) / FUN_0806d960 / FUN_08090218(duel_field) 触发. Side effects: 调用 FUN_08044e30 间接写 OAM 精灵属性队列及 gP1LifePoints 控制字段.
