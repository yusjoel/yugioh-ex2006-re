Renders the pack slot cover OAM sprite. Calls compute_pack_oam_attr_by_type with fixed base offset 0x80<<0xa=0x20000 to get attribute encoding. Reads pack_ui_state+0xc+0x10c (animation frame counter): if non-zero, computes an adjusted x offset via linear interpolation from [+0x10c] / [+0x10e] fields; if zero, uses the raw attribute directly. Finally calls render_overlay_oam_sprite_tiled with the computed attributes and fixed r1=0x0002000d (packed w/h) / r2=0x00020090 (tile attributes), r3=r7 (ctx_ptr). Called by 9 pack scene step functions.
