# Naming Proposal: 0x0804394c

## 提案

- **confidence**: med

## plate comment (中文, ASCII 标点)
读取 gDuelFieldSlots[player_side][slot_idx] 的 slot 状态, 若 bit9 置位 (slot 已占用), 则构建 OAM sprite 属性记录并调用 enqueue_sprite_attr_record.
r0 (player_side) 的 bit0 决定 OAM 基础 attr 值: bit0==0 使用 0x8035 (固定attr_base_a), bit0!=0 使用 DAT_0804399c=0x8035 (同值, 但路径分叉用于 tile id 差异).
r1 (slot_idx) 用于计算 slot 地址: idx*5 (lsls+adds+lsls = idx*(4+1)) -> *0x868 player offset.
从 slot[+0x8] (ldrh) 读辅助标志; 根据其是否为 0 决定 r2=0 或 r2=1 (flip/variant flag).
将 (attr=0x8035, slot_idx_masked, r2, 4) 传入 enqueue_sprite_attr_record.
被 FUN_08095ba8 在装备 sprite 初始化序列中调用.
Constants: gDuelFieldSlots=0x0201c510, player_stride=0x868, slot_stride=0x14 (5*4=0x14), OAM_count=4.
OAM_ATTR0_BASE=0x8035: Y_pos[7:0]=0x35 (53), bit15=1 (double-size off/OBJ disable when attr1.bit9=0), bit14-13=00 (normal OBJ mode), bit12=0 (non-mosaic), bit11-10=00 (4bpp color mode), bit9-8=00 (square shape).

## 参数签名
- r0: u32 player_side -- [0..1]; bit0 决定 OAM 基础 attr 路径
- r1: u32 slot_idx -- 场地槽索引 [0..10]; 用于计算 slot offset = idx*0x14
- 返回: void

## 副作用
- 通过 enqueue_sprite_attr_record(attr, slot_idx_masked, flip_flag, 4) 向 OAM sprite 属性缓冲区写入 4 个 attr word
