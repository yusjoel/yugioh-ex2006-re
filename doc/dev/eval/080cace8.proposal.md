## plate comment (中文, ASCII 标点)
清零卡牌展示相关的多个 VRAM/IO 缓冲区. 依次: 清零 OBJ VRAM 0x0600a8e0(0x800 halfword),
若 gGameState[+0x8](0x02023130+8) 非 0 则额外清零 BG VRAM 0x06006340(0x600 halfword),
OBJ VRAM 0x06008120(0x100 halfword) 和 0x06008020(0x100 halfword), 清零 IO 寄存器对
0x0600f904[0..1], 清零 window 区 0x0600fa40[0..+6], 最后清零 0x06008120(0x4) 和
0x060081a0(0x4). 调用方为 FUN_080cad78 以及 FUN_080cb1cc 内多个 case. indeg=4, 纯副作用函数.
Constants: OBJ_VRAM=0x0600a8e0, BG_VRAM=0x06006340, TILE_VRAM=0x06008120/0x06008020,
DIGIT_VRAM=0x0600fa40, gGameState=0x02023130.
