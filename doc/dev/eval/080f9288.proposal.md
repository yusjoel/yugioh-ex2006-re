## plate comment (中文, ASCII 标点)
将牌组槽 r1 的卡组数据复制到牌组槽 r0. 使用公式 280*n (lsls#3 + adds + lsls#2 - subs + lsls#3) 计算 src=r1 和 dst=r0 在 EWRAM 0x02000000 中的字节偏移. 复制三个标志字节 (+0x1268, +0x1269, +0x126a), 再以 stride=2 的内循环复制 0x4f+1=80 个卡槽数据 halfword (偏移 +0x130c). 完成后调用 init_puzzle_wram_and_checksum 同步校验. indeg=0, 运行时调用.

Constants:
- DECK_BASE = 0x02000000
- SLOT_STRIDE = 280 = 0x118 (lsls3+add+lsls2-sub+lsls3 计算)
- FLAG0_OFFSET = 0x1268
- FLAG1_OFFSET = 0x1269
- FLAG2_OFFSET = 0x126a
- CARD_DATA_OFFSET = 0x130c (DAT_080f930c)
- CARD_DATA_COUNT = 80 (cmp r7,#0x4f; ble loop -> 0..0x4f=80 条)

- 返回: r0 = void (pop {r0}; bx r0)
