apply_title_ex_window_fade_in_step
Single step of title_ex scene window fade-in animation, structurally symmetric with apply_demo_window_fade_in_step (0x08013af4). Computes cur*80/max for vertical offset r6. When cur==max (fade-in complete): configures WININ bits[5:0]=0x3b, clears WINOUT bit5, writes WIN0H/initial WIN0V, modifies BLDCNT, calls gl_set_brightness + gl_set_blend2_level. Finally always writes WIN0V=[(WIN_CENTER+r6):(WIN_CENTER-r6)]. indeg=0, invoked via runtime function pointer.
Constants:
  WININ = 0x04000048
  WINOUT = 0x0400004a
  WIN0H = 0x04000040
  WIN0V = 0x04000044
  BLDCNT_MASK = 0xffff9fff (clear BLDCNT bits[13:12])
  WININ_EFFECT_MASK = 0x3b (WININ bits[5:0]: BG0-3 + OBJ + effect enable)
  WIN_CENTER = 0x50 (window center Y coordinate: screen 160 rows / 2 = 0x50)
