## 修改清单

### #1 — R6 (优先级: 高)
**位置**: proposal Constants 块, PRESENCE_STRUCT_OFFSET 行
**问题**: `PRESENCE_STRUCT_OFFSET = 0x32*0x20+0x58 = 0x698` 推导错误: `ldrh r3,[r1,#0x32]` 的 0x32 是寄存器偏移量 (加载 r1[+0x32] 处的 halfword 到 r3), 然后 `lsls r0,r3,#5` 将读出的 r3 值 *32 (非将偏移量 0x32 参与计算); 0x698 不是固定静态偏移, 是运行时 r3 值决定的动态地址; 应将此项标注为运行时动态计算, 或移除固定值假设
**当前**: `PRESENCE_STRUCT_OFFSET = 0x32*0x20+0x58 = 0x698 (ldrh r3,[r1,#0x32]; lsls r0,r3,#0x5 -> *32; +0x58)`
**应改为**: 移除 0x698 固定值; 改为 `STRUCT_LDRH_OFFSET = 0x32 (r1[+0x32] = slot_row halfword)` 和 `PRESENCE_FIELD_OFFSET = 0x58 (r0 += 0x58 -> presence bitfield)`; 说明目标地址为运行时 `r1 + r3*32 + 0x58` (r3 = slot_row 动态值)
