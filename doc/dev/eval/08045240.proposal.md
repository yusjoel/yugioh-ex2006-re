# Naming Proposal: 0x08045240

## 提案
- **proposed_name**: enqueue_sprite_attr_with_xy_split
- **confidence**: high

## plate comment (中文, ASCII 标点)
sprite attr 入队 wrapper: 把入参 r2 (32-bit packed_xy = y_high<<16|x_low) 拆成 r2 (低 16 = x_pos, lsls/lsrs #0x10) 与 r3 (高 16 = y_pos), 然后选择 attr1 (=0x3a if r0==0, =0x803a if r0!=0; 即 OAM type 0xa shape A vs B), 把 r1 (lsls/lsrs #0x18 截取低 8 bit 作为 attr1 子字段) 一起调用 enqueue_sprite_attr_record(attr1, r1, x_pos, y_pos). 是 enqueue_sprite_attr_with_shape (PROGRESS #681, 0x08045268) 的简化版本  -  后者多一步 r1 |= TYPE_FLAG=0x100, 本函数不做这步, 因此命名上呼应"with_xy_split". 25 caller 集中在 duel_field 装备/卡片 sprite 流程.

## 参数签名
- r0: u32 attr_select_flag (0=选 attr1=0x3a, 非零=选 0x803a)
- r1: u32 attr_aux_byte [0..0xff] (lsls/lsrs #0x18 截取低 8 位; 直接转发为 callee r1)
- r2: u32 packed_xy (低 16 = x_pos[0..0x1ff], 高 16 = y_pos[0..0x3ff]; lsls/lsrs 拆分)
- 返回: void (透明 forward; callee 不返回值)

## 副作用
- enqueue_sprite_attr_record() : 写 sprite attr 队列 0x0201bcc0+0x808
