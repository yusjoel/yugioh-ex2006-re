## plate comment (中文, ASCII 标点)
将 ROM 包店卡牌调色板数据复制到 OBJ 调色板 VRAM 指定 slot. 触发条件: 4 个 caller(pack_banner_080d566c, pack_banner_080d6d30, game_str_080d713c, game_str_080d91e0 -- 包店初始化/切换页面时)在加载调色板后调用, r0=pal_slot_index([0..0xf]). 若 r0>0xf 直接跳过返回; 否则计算 0x05000200+r0*0x20 作 OBJ 调色板目标, 从 ROM 表 0x09ccd290 复制 0x20 字节(16 色调色板).

Constants:
- OBJ_PAL_BASE = 0x05000200 (OBJ 调色板 VRAM 基址)
- ROM_PAL_DATA = 0x09ccd290 (ROM 调色板数据)
- PAL_SIZE = 0x20 (32 字节 = 16 色)
- PAL_LIMIT = 0xf ([0..15] slot 范围)

## 参数签名
- r0: u8 pal_slot_index [0..0xf] (OBJ 调色板 slot 索引; >0xf 时不执行)
- 返回: void (pop {r0}; bx r0)

## 副作用
- [0x05000200+r0*0x20..+0x20]: 写 ROM 调色板数据 (via copy_memory_dma3_with_cpu_fallback, 仅 r0<=0xf)
