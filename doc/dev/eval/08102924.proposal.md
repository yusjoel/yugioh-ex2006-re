## plate comment (中文, ASCII 标点)
由 FUN_08103350 (card_stats) 和 FUN_0810329c (card_stats) 以 deck_type=0/1/2/3 批量调用, 将一张卡插入指定 deck slot 数组中的有序位置. r0=IWRAM 基址 (->r8), r1=deck_slot_mode (->r4) 决定目标 slot 偏移 (0->0xb7*4, 1->0x140c, 2->0x160c, 3->0x180c), r2=card_id (->r7, & 0x0fff), r3=insert_mode (->stack). 使用 bsearch_index_by_callback 在已排序数组中定位插入点; 若找到则更新现有条目的 type nibble; 若未找到则在末尾追加并通过 strh/移位更新计数字段 [slot+0x1a0c] 和 [slot+0x1a14]. 函数修改 IWRAM 0x0202a4d0 的 deck slot 结构体并返回 0 (插入成功) 或通过 LAB 返回当前计数.

## 参数签名
- r0: ptr IWRAM 基址 (mov r8,r0 保存; 调用处传入 0x0202a4d0)
- r1: u32 deck_slot_mode (mov r4,r1; 0=main deck, 1/2/3=extra/side slot)
- r2: u16 card_id (mov r7,r2; 低 12-bit 有效, & 0x0fff)
- r3: u32 insert_type/submode [0..1] (str r3,[sp,#0x8] 保存到栈)
- 返回: r0 = s32 0=成功插入, 或当前 slot 下标

## 副作用
