## plate comment (中文, ASCII 标点)
vija 场景单个 OBJ slot 的每帧动画状态机 tick. 由 FUN_0801cadc 以 stride=8 循环调用, 传入 IWRAM 0x02029eb0+0x98+i*8 处的 slot 控制块指针 (i in [0..4]). 函数读取 r0 指向结构体的 byte[0] 作为主状态码 (phase, [0..0x1e]), byte[1] 作为子计数器/序列索引. 内部含两级嵌套 switch: 外层按主 phase 路由, 内层按当前 phase 映射 x 坐标变体 (0x30/0x50 两档). 活跃 phase (1/0xa/3/0x1e/4/5) 驱动 OBJ 位置插值: 根据子计数器插值 x/y 坐标, 调用 drive_vija_obj_cell_anim 更新 OAM; 或调用 update_dual_cell_anim_oam_pos 同步双槽. 子计数器归零时推进主 phase. Phase 2 调用 advance_scene_phase_counter 获取全局进度, 再调用 update_dual_cell_anim_oam_pos. Phase 5 以固定 x=-1, y=0x78, z=0x50 调用两次 drive_vija_obj_cell_anim 并退出. Phase 0 及无效 phase 直接 return. 副作用: 修改 slot 结构体 byte[0]/byte[1], 以及 OAM 对应条目.
Constants: PHASE_MAX=0x1e, X_VARIANT_A=0x30(px), X_VARIANT_B=0x50(px), SIN_TABLE=0x09e399d0.
