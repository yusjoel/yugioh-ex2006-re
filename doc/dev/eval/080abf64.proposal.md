## plate comment (中文, ASCII 标点)
对指定玩家 r0 的怪兽区槽 r1 进行评分计算, 结果写入 r2 所指向的评分条目结构. 槽基址 = 0x0201c510 + (player_id & 1) * 0x868 + card_slot_index * 0x14. 读取槽内 [+0x8] halfword 作为现有评分标志: 若非零则直接调用 eval_slot_score_entry_full 全量评分; 若为零则读取槽 [0] 的 card_id, 检查关联槽 [+0x11] 的 bit7 (激活标志); 激活时用 eval_slot_score_entry_full 评分, 未激活时调用 get_card_extended_stat_field5 按 field5 值选择固定分值 (field5<=4: 0x96<<3=0x4b0; >4: 0x834 或 0xe1<<3=0x708). 写入 score_out 的 0x00/0x04/0x08/0x10/0x14/0x18 六个字段.

## 参数签名
- r0: u32 player_bit_field - bit0=player_id [0..1], 用于 zone_table 行选择 (stride 0x868)
- r1: u32 card_slot_index [0..N-1] - 怪兽区槽索引 (stride 0x14 = 20 字节/条目)
- r2: ptr score_out - 输出评分结构指针 (字段 0x00/0x04/0x08/0x10/0x14/0x18 被写入)
- 返回: r0 = void (无返回值, 通过 score_out 副作用输出)

## 副作用

- [score_out + 0x04]: := 0 (LAB_080abfc0 路径)
- [score_out + 0x08]: := 0 (LAB_080abfc0 路径)
- [score_out + 0x10]: := get_card_extended_stat_field5 返回值
