## plate comment (中文, ASCII 标点)
Magical Scientist(0x1619) 专属的全区槽装备链精灵扫描器. r0=player_id([0..1]). 使用 gP1LifePoints+0x1d24 作为循环计数器(初始值应 <=9), 遍历槽索引 0..9(共 10 个). 每个迭代: 将计数值除以 5 得到 player_side, 取余得到 slot_idx. 检查槽的激活位(lsls r0,#0x13 nonzero). 若已激活: 调用 check_value_in_slot_chain(player, slot, card_id=0x1619) 验证卡片在链中; 命中后调用 query_equip_zone_slot_target_bit(player, slot, 0, 0x1619) 查询装备目标位图; 若位图为 0 则调用 enqueue_equip_slot_sprite_attr(player, slot, 0x1619, r3=1) 推入精灵属性. 与 scan_all_zone_slots_for_equip_chain_sprite_update 结构对称, 但多了 query_equip_zone_slot_target_bit 过滤.
Constants: CARD_ID=0x1619=Magical Scientist, COUNTER_OFFSET=0x1d24, SLOT_STRIDE=0x868, SLOT_COUNT=10.
