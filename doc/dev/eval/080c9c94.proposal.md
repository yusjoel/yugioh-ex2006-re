## plate comment (中文, ASCII 标点)
被卡片显示大状态机 (FUN_080c76c0 的父 hub) case 6 和另一 hub 调用 (indeg=2), 是卡片显示特效序列的步进调度器. 从 gCardState+0x1 (0x02023130+1) 读取当前步骤索引 (0..8), 以 switch 表分发 9 个 case: case 0 初始化 WIN1H/WIN1V/WIN0H 窗口寄存器和 BLDALPHA/BLDCNT (fade-in 准备); case 1 设置 DISPCNT bit[14:13]= LCD blend mode; case 2/6 渐变 BLDALPHA (每次 +1, 最大 4, 完成后置 BLDCNT=0xCC); case 3/5 渐变 BLDY (每次 +1, 最大 4, 完成后重置步骤); case 4 调用 tick_card_icon_anim_step 推进图标动画; case 7/8 重置 DISPCNT 并清空 WIN 寄存器. default 路径调用 disable_blend_and_clear_step 并返回 1 (完成). 返回 0 = 仍在执行, 1 = 序列完成.
