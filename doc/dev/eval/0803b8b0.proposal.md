# Naming Proposal: 0x0803b8b0

## 提案
- **proposed_name**: write_field_slot_bit_by_player
- **confidence**: high

## plate comment (中文, ASCII 标点)
对指定 player 的指定槽位的控制字执行单 bit 的置位或清位操作. 以 gP1LifePoints + player_side<<10 (player*0x868 中 bit0 乘以 0x868) + slot_idx*0x14 + 0x40 为目标字地址 (slot_entry_size=0x14=20 bytes, base_offset=0x40 为 flags 字段), 根据 r3 (set_flag): r3 非零时读字后 OR (1<<r2) (置位); r3 为 0 时读字后 BIC (1<<r2) (清位). 结果写回同一地址. indeg=11, 被 duel_field 和 card_data 场景下的 11 个 caller 共享.

Constants: gP1LifePoints=0x0201c4e0 (via PTR), player_stride_factor=0x868, slot_entry_size=0x14=20, flags_offset=0x40.

## 参数签名
- r0: u32 player_side [0..1] (决斗方; bit0 参与 ands#1 后乘 0x868)
- r1: u32 slot_idx [0..9] (场地槽位索引; 乘以 slot_entry_size=0x14)
- r2: u32 bit_pos [0..31] (要操作的位位置; 用于 lsls r2, r5 生成掩码)
- r3: u32 set_flag [0..1] (0 = 清位 BIC; 非零 = 置位 OR)
- 返回: r0 = void (str 后直接 pop/bx)

## 副作用
- [gP1LifePoints + player_side*0x868 + slot_idx*0x14 + 0x40] := word OR/BIC (1<<bit_pos)
