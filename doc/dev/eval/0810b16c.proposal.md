## plate comment (中文, ASCII 标点)
声音系统 Timer0 播放速率设置函数. r0=rate_index [0..4]; 若大于 4 则钳制为 0. 将 rate_index 写到 0x030050cc[+0x38a]; 清零 TM0CNT_L (停止计时器); 从 ROM 表 0x084c7634[rate*4] 加载速率常量, OR 0x80000000 (自动重载 bit) 后写入 TM0CNT_L 启动. 再循环 3 次更新 IWRAM 0x03005608 的前 3 个频率槽: 从 0x084c7568[rate*2] 取乘数, 与各槽 [+0x0] 相乘右移 0xc 后写入 [+0x8]. 无返回值 (pop{r4};pop{r0};bx r0 -- Sub-case E void).

Constants:
- 0x030050cc[+0x38a] = 当前 rate_index 字段
- TM0CNT_L (0x04000100) = Timer0 计数/重载寄存器
- 0x084c7634 = 速率常量表 (5 条目 x 4 bytes)
- 0x80000000 = TM0CNT 自动重载 bit (bit31 = cascade/reload enable in GBA = 实际为 Timer 使能 + reload)
- 0x03005608 = 频率槽 IWRAM 基址 (3 slots, stride 0x14)
- 0x084c7568 = 频率乘数表 (每条 2 bytes)
- asrs r0,r0,#0xc = 定点 Q12 右移 (乘后取高位)
- rate_index [0..4]; >4 -> clamp to 0

## 参数签名
- r0: int32 rate_index (播放速率索引 [0..4]; >4 时钳制为 0)
- 返回: void (pop{r4};pop{r0};bx r0 -- Sub-case E, N=0)

## 副作用
- [0x030050cc+0x38a]: strb r3 写 rate_index
- TM0CNT_L (0x04000100): str 0 (停计时器), 再 str rate_word | 0x80000000 (启计时器)
- [0x03005608+n*0x14+8], n=0..2: strb 写新频率乘积 (Q12 定点)
