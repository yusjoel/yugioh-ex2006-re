## plate comment (中文, ASCII 标点)
渲染卡牌名称到 BG tile VRAM, 唯一调用方为 FUN_080c05b4 (card image 显示页初始化 hub). 先调用 setup_line_buf_pos_and_set_font_flag (r0=0xe, r1=2) 建立 JP 字体 line buffer 上下文, 然后读取 EWRAM 状态确定字体方向 (bit0/bit1 选择字体基址指针), 再调用 render_card_name_to_line_buf (r0=card_idx) 将卡名渲染到 line buffer, 最后检查 card_stats_table 中卡的属性类型 (field offset 6 与 0x16 比较, 选择竖排/横排字体映射表), 调用 write_line_buf_to_bg_tile_vram 写入目标 BG VRAM 区域.

Constants:
- FONT_POS_X = 0xe = 14
- FONT_TYPE = 0x2 = JP font
- CARD_STATS_TYPE_FIELD = 6 (card_stats_table 条目偏移 6)
- CARD_TYPE_VERTICAL_LIMIT = 0x16 = 22 (小于等于此值用竖排字体映射)
- VRAM_NAME_ROW_DST = 0x06017840 (BG VRAM 名称行目标基址)
- VRAM_NAME_ROW_OFF = 0x808 (行偏移)
- PTR_font_jp_base_table = 字体基址指针表 (已命名全局)
- card_stats_table = 卡牌属性表 (已命名全局)
