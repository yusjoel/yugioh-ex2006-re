## plate comment (中文, ASCII 标点)
以 r0=card_id 为键执行多分支 BST 检查, 根据 card_id 所属的特定卡牌集合返回放置许可状态. 存在三条返回路径: (A) LAB_080ad954: r0=((r2!=0)?1:0) 依赖 r2 的非零标志; (B) LAB_080ad962: 固定返回 1 (允许); (C) LAB_080ad970: 固定返回 0 (不允许); (D) LAB_080ad966: 条件路径依赖 r1 是否非零. BST 覆盖的 card_id 范围横跨 0x11bc..0x19fe, 包含大量特定怪物卡 ID. 上层 FUN_080b58e8 以 card_id=r5, r1=saved_slot_ptr, r2=1 调用本函数, 用于筛选手牌中可被放置的卡牌. indeg=4. Constants: BST card_id range 0x11bc..0x19fe; return 0=forbidden, 1=allowed.
