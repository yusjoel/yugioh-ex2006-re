# Naming Proposal: 0x08080d6c

## 提案

- **confidence**: high

## plate comment (中文, ASCII 标点)
从效果节点结构体的槽位数组中读取指定槽位的"侧位"与"类型"两个字段, 打包后返回. 结构体布局: [base+0..3]=头部字段, [base+4]=控制字(bits[17:15]=槽位总数 N, [0..7]), [base+8..]=槽位数组(每槽 2 字节步长). 返回值低字节为 side flag(bit0=归属玩家侧 0/1), 高字节(bits[15:8])为 4 位 type nibble(代表效果/区域类型, 如 0xe=14=特定效果类型). 被 93 个 caller 以相同的移位序列(`lsls r0,r0,#0x10; lsrs r0,r0,#0x18`)提取 type nibble, 或以 `lsls r1,r0,#0x18; lsrs r1,r1,#0x18` 提取 side bit.

Constants:
- EFFECT_SLOT_STRIDE = 2 (字节, 每槽位步长)
- EFFECT_NODE_ARRAY_OFFSET = 8 (槽位数组相对基地址的字节偏移)
- EFFECT_NODE_COUNT_SHIFT = 15 (bits[17:15] in [base+4] 存储槽位数 N)

## 参数签名
- r0: ptr effect_node -- 效果节点结构体基地址
- r1: u8 slot_index -- 槽位下标 [0..6] (上界 N-1, N = [base+4].bits[17:15], max 7)
- 返回: r0 = u16 packed_fields -- r0[0]=side(0=P1 侧, 1=P2 侧), r0[11:8]=type_nibble(4 位效果类型, 0..15)

## 副作用
