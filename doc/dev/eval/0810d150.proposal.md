## plate comment (中文, ASCII 标点)
IWRAM sprite 管理结构体 (0x030050cc) 的 entry 初始化函数 (indeg=10). 接收 sprite/entity ID (r0). 若 r0 bit15 置位则先在结构体偏移 0x89*4=0x224 处的 0x28-byte entry 数组中线性搜索 [+0x1f] bit7 = 1 且 [+0xe] signed == r0 的已有 entry; 若找到则复用 (跳至 LAB_0810d1da), 否则在固定槽位写入初始化数据: halfword[0xda*4] := r0 (entity_id), byte[0x387] := 0x10 (sprite_type), halfword[0x36e/0x370/0x372/0x37a] := 0, halfword[0xde*4] := 0xffff, halfword[0xdf*4] := 0x3f3f. 被 FUN_080f9ab4 (indeg=77) 驱动, 最终服务于卡片/场景对象的 OBJ/sprite 状态初始化.

## 参数签名
- r0: u16 entity_id   (sprite/entity 编号, bit15=1 时触发搜索已有 entry)
- r12: ptr sprite_mgr_base  (IWRAM sprite 管理结构体基址, 调用方须预设; = 0x030050cc)
- 返回: void

## 副作用
- [0x030050cc + 0xda*4]: halfword := entity_id
- [0x030050cc + 0x387]: byte := 0x10  (sprite_type)
- [0x030050cc + 0x36e, +0x370, +0x372, +0x37a]: halfword := 0  (位置/动画字段清零)
- [0x030050cc + 0xde*4]: halfword := 0xffff
- [0x030050cc + 0xdf*4]: halfword := 0x3f3f
