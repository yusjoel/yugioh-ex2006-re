# Naming Proposal: 0x08014398

## 提案
- **proposed_name**: tick_prng_step_sequence
- **confidence**: med

## plate comment (中文, ASCII 标点)

Function: 读取 gPrng+0x204 处打包字段 bits[21:14] 得到当前步骤索引, 以该索引*4 在 ROM 函数指针表
(0x09e587d4) 查找步骤回调并通过 invoke_r0 调用; 若步骤函数返回非零表示当步完成, 递增索引
(mod 256) 写回 bits[21:14]; 若步骤函数返回 0 则调用 return_void_handler 并返回 0;
若步骤函数指针为 NULL 则返回 1 (序列结束哨兵).

Side effects: 当步完成时更新 [gPrng+0x204] bits[21:14] (步骤计数器 +1 mod 256).

Constants:
- gPrng = 0x03000040 (IWRAM global 状态)
- STEP_FIELD_OFFSET = 0x204 (gPrng 内字偏移)
- STEP_TABLE = 0x09e587d4 (ROM 步骤函数指针数组)
- STEP_SHIFT = 14 (bits[21:14] 提取: lsls #0xa / lsrs #0x18)
- STEP_MASK = 0xffc03fff (写回清零掩码)

## 参数签名
- r0: (无独立输入, 入口 ldr r0,gPrng 覆盖 r0 -- 内部加载)
- 返回: r0 = u8 sequence_done (1=步骤表空/序列结束; 0=正常步骤执行或步骤未完成)

## 副作用
- [gPrng+0x204]: bits[21:14] := (old_step+1) & 0xff (仅当步骤函数返回非零时)
