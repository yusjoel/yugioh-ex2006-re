# Naming Proposal: 0x080f4ee8

## 提案
- **proposed_name**: copy_memory_by_word_blocks
- **confidence**: high

## plate comment
将 src (r1) 的内容复制到 dst (r0), 复制字节数 r2 向上对齐到 8 字节后除以 8 得到 word-pair 块数. 每次迭代用 ldmia/stmia 同时传输 2 个 word (8 字节), 实现快速块复制. 与 copy_bytes_by_halfword (0x080f4ea4) 和 copy_memory_dma3_with_cpu_fallback (0x080f4f08) 同族, 专用于 8 字节对齐场景的 CPU 侧批量复制.

Side effects:
- [dst..dst + ceil(r2/8)*8]: := src 内容 (8 字节块)

Constants:
- BLOCK_SIZE = 8 // ldmia/stmia 每次传 2 word = 8 字节
- ALIGN_BIAS = 7 // (r2+7)>>3 向上对齐

## 参数签名
- r0: void* dst 目标地址
- r1: const void* src 源地址
- r2: u32 byte_count 字节数 (向上对齐到 8)
- 返回: void (pop {r0};bx r0)

## 副作用
- [r0..r0+ceil(r2/8)*8]: 覆盖写入 src 数据

## 行级注释 (精华)
- @ 080f4eea: r4 = src (callee-save)
- @ 080f4eec: r3 = dst
- @ 080f4eee: r0 = (byte_count + 7)
- @ 080f4ef0: r2 = r0 >> 3 = ceil(byte_count/8) 块数
- @ 080f4ef2: 若块数为 0 直接跳出
- @ 080f4ef6: ldmia r4!,{r0,r1} 读 8 字节
- @ 080f4ef8: stmia r3!,{r0,r1} 写 8 字节
- @ 080f4efa: 块计数--; 继续
