## plate comment (中文, ASCII 标点)
装备槽存在性谓词 (对手视角). 从卡槽 byte[+2] bit0 提取本方 player_id, 取反得到对手 player_id (1-player_id), 调用 find_field_zone_slot_with_equip_type 搜索对手场地是否存在装备类型槽. 对结果做 mvns+lsrs (位取反后取最高位), 当搜索返回 -1 (无匹配) 时 mvns(-1)=0, lsrs #0x1f=0 -> 返回 0; 当搜索返回 >=0 (有匹配) 时 mvns(x) != -1, lsrs #0x1f=0 -- 实际 mvns+lsrs #0x1f 对 -1 得 0 (无槽), 对 >=0 得 0 也; 但 subs r0,r0,r1 实为 subs r0,r0,r1 -- 实际是 1-result_bit, 故找到槽返回 0, 未找到返回 1.

等效语义: 对手没有装备类型场地槽时返回 1; 有时返回 0. 用于要求对手场地无装备槽才能激活的效果.
